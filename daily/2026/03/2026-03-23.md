## Major news & releases

### Keystone: Anthropic harness post

**Anthropic publishes "Harness design for long-running application development" — three-agent planner / generator / evaluator architecture.** Anthropic's engineering team posted the formal harness-design write-up by Labs engineer Prithvi Rajasekaran. The piece extends the November 2025 "Effective harnesses for long-running agents" post with a three-agent harness — planner, generator, evaluator — pushing Claude further on frontend design and long-running autonomous software engineering. Core moves: separate planning from generation; calibrate a dedicated evaluator agent with few-shot examples and scoring criteria to fight the self-overrating problem; use a different prompt for the very first context window (the "initializer" pass that builds the feature-list.json and init.sh). _Why it matters:_ This is the reference architecture every coding-agent vendor is now reading against, and a meaningful signal of how Anthropic is thinking about the next generation of Claude Code (the harness that will eventually leak on 31 March via a missing `.npmignore`). It's also the most detailed first-party documentation on the harness/host vs. model decomposition underlying Claude Managed Agents. [Anthropic — harness design](https://www.anthropic.com/engineering/harness-design-long-running-apps) · [Anthropic on X](https://x.com/AnthropicAI/status/2036481033621623056) · [InfoQ — three-agent harness](https://www.infoq.com/news/2026/04/anthropic-three-agent-harness-ai/)

**Anthropic harness post triggers immediate community uptake — practitioner blogs, GitHub samples, reference forks.** Within hours, the post drew detailed practitioner walk-throughs and reference implementations: Rick Hightower's "two agents, one feature list, zero context overflow" Medium piece walks the architecture; a GitHub repo (`anthropics/cwc-long-running-agents`) and a ZenML LLMOps DB entry document the multi-context-window pattern. AddyOsmani.com and a Hacker News thread amplified the architectural framing. _Why it matters:_ Sets the agent-platform conversation for the rest of the quarter — planner/generator/evaluator becomes shorthand in vendor pitches (Anysphere, Cognition, Magic, Replit). Cursor 3's "Agents Window" launch on 2 April is the most visible product expression of the pattern. ## Research highlights

- **The Y-Combinator for LLMs: Solving Long-Context Rot with λ-Calculus** — Amartya Roy, Rasul Tutunov, Xiaotong Ji, Matthieu Zimmer. Recasts long-context degradation as a fixed-point problem; recursion-based mitigation borrowed from λ-calculus. _Category:_ arXiv:2603.20105 — long-context / cs.CL. [arXiv](https://arxiv.org/abs/2603.20105)
- **Hyperagents** — Jenny Zhang, Bingchen Zhao, Wannan Yang, Jakob Foerster. Agents as compositional functions over other agents; meta-agent architecture beyond ReAct-style monolithic loops. _Category:_ arXiv:2603.19461 — multi-agent / cs.AI. [arXiv](https://arxiv.org/abs/2603.19461)
- **A Subgoal-driven Framework for Improving Long-Horizon LLM Agents** — Taiyi Wang, Sian Gooding, Florian Hartmann, Oriana Riva. Explicit subgoal decomposition as a structural prior for long-horizon agents — counter to the "scale will solve it" stance with concrete gains. _Category:_ arXiv:2603.19685 — long-horizon agents. [arXiv](https://arxiv.org/abs/2603.19685)
- **Breaking the Capability Ceiling of LLM Post-Training by Reintroducing Markov States** — Yurun Yuan, Tengyang Xie. RL post-training is bottlenecked by collapsing trajectories into a single state; reintroduce Markov states to recover headroom. _Category:_ arXiv:2603.19987 — post-training / RL. [arXiv](https://arxiv.org/abs/2603.19987)
- **LoopRPT: Reinforcement Pre-Training for Looped Language Models** — Guo Tang, Shixin Jiang, Heng Chang, Nuo Chen. RL signal during pretraining of looped/recurrent-depth language models — recipe for the "compute-elastic" architecture line. _Category:_ arXiv:2603.19714 — pretraining / cs.CL. [arXiv](https://arxiv.org/abs/2603.19714)
- **WorldAgents: Can Foundation Image Models be Agents for 3D World Models?** — Ziya Erkoç, Angela Dai, Matthias Nießner. Probes whether foundation image models can act as agents over 3D world models — where multimodal agents stop being VQA wrappers and start being environment-acting policies. _Category:_ arXiv:2603.19708 — multimodal / 3D. [arXiv](https://arxiv.org/abs/2603.19708)
- **BEAVER: Training-Free Hierarchical Prompt Compression via Structure-Aware Page Selection** — Zhengpei Hu, Kai Li, Dapeng Fu, Chang Zeng. Training-free prompt compression by hierarchical structure-aware page selection — inference-time mechanism for long-context RAG with realistic chunked inputs. _Category:_ arXiv:2603.19635 — RAG / cs.CL. [arXiv](https://arxiv.org/abs/2603.19635)
- **Reasoning as Compression: Unifying Budget Forcing via the Conditional Information Bottleneck** — Fabio Valerio Massoli, Andrey Kuzmin, Arash Behboodi. Unifies test-time budget-forcing techniques under a conditional information-bottleneck view. _Category:_ arXiv:2603.08462 — reasoning / cs.LG. [arXiv](https://arxiv.org/abs/2603.08462)
