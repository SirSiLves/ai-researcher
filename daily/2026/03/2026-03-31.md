## Research highlights

- **EpochX: Building the Infrastructure for an Emergent Agent Civilization** — Huacan Wang, Chaofa Yuan, Xialie Zhuang, Tu Hu. Infrastructure paper for large-scale multi-agent systems with persistent state — concrete framework for the agent-platform / multi-agent-society thread that has been mostly toy environments. _Category:_ arXiv:2603.27304 — cs.MA. [arXiv](https://arxiv.org/abs/2603.27304)
- **Emergent Social Intelligence Risks in Generative Multi-Agent Systems** — Yue Huang, Yu Jiang, Wenjie Wang, Haomin Zhuang. Identifies emergent social-intelligence risks specific to MAS — direct contribution to the still-thin governance literature on agent-to-agent dynamics beyond single-agent jailbreaks. _Category:_ arXiv:2603.27771 — cs.CL. [arXiv](https://arxiv.org/abs/2603.27771)
- **Marco DeepResearch: Unlocking Efficient Deep Research Agents via Verification-Centric Design** — Bin Zhu, Qianghuai Jia, Tian Lan, Junyang Ren. Recenters deep-research agent design around verification rather than generation — concrete recipe for cutting wall-clock + token cost of deep-research stacks. _Category:_ arXiv:2603.28376 — cs.CL. [arXiv](https://arxiv.org/abs/2603.28376)
- **Towards a Medical AI Scientist** — Hongtao Wu, Boyun Zheng, Dingjie Song, Yu Jiang. AI-scientist agent grounded in medical workflows — useful pushback on the generic "deep research" framing by attaching the agent to domain-specific verification + audit. _Category:_ arXiv:2603.28589 — cs.CL. [arXiv](https://arxiv.org/abs/2603.28589)
- **Kernel-Smith: A Unified Recipe for Evolutionary Kernel Optimization** — He Du, Qiming Ge, Jiakai Hu, Aijun Yang. LLM-driven evolutionary optimisation for GPU kernels — concrete entry in the "LLMs writing performance-critical systems code" line alongside DeepSeek-V3-style kernel work and AVO. _Category:_ arXiv:2603.28342 — cs.LG. [arXiv](https://arxiv.org/abs/2603.28342)
- **TAPS: Task Aware Proposal Distributions for Speculative Sampling** — Mohamad Zbib, Mohamad Bazzi, Ammar Mohanna, Hasan Abed Al Kader Hammoud. Task-aware proposals for speculative decoding — concrete inference-stack mechanism for the low-acceptance regime where speculative gains evaporate. _Category:_ arXiv:2603.27027 — cs.CL. [arXiv](https://arxiv.org/abs/2603.27027)
- **HISA: Efficient Hierarchical Indexing for Fine-Grained Sparse Attention** — Yufei Xu, Fanxu Meng, Fan Jiang, Yuxuan Wang. Hierarchical indexing for fine-grained sparse attention — long-context architecture mechanism with fidelity + throughput claims. _Category:_ arXiv:2603.28458 — cs.LG. [arXiv](https://arxiv.org/abs/2603.28458)
- **MuSEAgent: A Multimodal Reasoning Agent with Stateful Experiences** — Shijian Wang, Jiarui Jin, Runhao Fu, Zexuan Yan. Multimodal reasoning agent built around explicit stateful experience memory — concrete instantiation of "agent memory as first-class component" in the multimodal setting. _Category:_ arXiv:2603.27813 — cs.CL. [arXiv](https://arxiv.org/abs/2603.27813)
