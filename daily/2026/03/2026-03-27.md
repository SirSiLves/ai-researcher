## Research highlights

- **Intern-S1-Pro: Scientific Multimodal Foundation Model at Trillion Scale** — Yicheng Zou et al. Trillion-parameter scientific multimodal foundation model from Shanghai AI Lab — concrete entry in the "science-native foundation model" line. _Category:_ arXiv:2603.25040 — foundation models / cs.CL. [arXiv](https://arxiv.org/abs/2603.25040)
- **Voxtral TTS (technical report)** — Alexander H. Liu et al. Mistral's TTS technical report extending the Voxtral family — paired with Thursday's open-weights launch. _Category:_ arXiv:2603.25551 — speech / cs.CL. [arXiv](https://arxiv.org/abs/2603.25551)
- **SlopCodeBench: Benchmarking How Coding Agents Degrade Over Long-Horizon Iterative Tasks** — Gabriel Orlanski et al. Specifically measures degradation ("slop accumulation") of coding agents across long iterative sessions; fills the SWE-bench drift gap. _Category:_ arXiv:2603.24755 — coding agents / cs.CL. [arXiv](https://arxiv.org/abs/2603.24755)
- **FinMCP-Bench: Benchmarking LLM Agents for Real-World Financial Tool Use under the Model Context Protocol** — Jie Zhu et al. Financial tool-use benchmark explicitly built around MCP — concrete data point on whether MCP holds up as the agent-tool-interop substrate. _Category:_ arXiv:2603.24943 — MCP / finance. [arXiv](https://arxiv.org/abs/2603.24943)
- **Revisiting On-Policy Distillation: Empirical Failure Modes and Simple Fixes** — Yuqian Fu et al. Identifies concrete failure modes in on-policy distillation pipelines and proposes minimal fixes — practical reference for the post-training stack. _Category:_ arXiv:2603.25562 — post-training / cs.LG. [arXiv](https://arxiv.org/abs/2603.25562)
- **AVO: Agentic Variation Operators for Autonomous Evolutionary Search** — Terry Chen et al. Uses agents as the variation operators in an evolutionary search loop — concrete "LLM-as-mutator" pattern. _Category:_ arXiv:2603.24517 — agent search / cs.LG. [arXiv](https://arxiv.org/abs/2603.24517)
- **Reaching Beyond the Mode: RL for Distributional Reasoning in Language Models** — Isha Puri et al. RL recipe explicitly targeting distributional rather than mode-collapsed reasoning — pushback on the mode-seeking behavior of standard RLHF/RLVR. _Category:_ arXiv:2603.24844 — RL / cs.LG. [arXiv](https://arxiv.org/abs/2603.24844)
- **MemMA: Coordinating the Memory Cycle through Multi-Agent Reasoning and In-Situ Self-Evolution** — Minhua Lin et al. Coordinates the read/write/forget cycle of agent memory across multiple agents with in-situ self-evolution. _Category:_ arXiv:2603.18718 — agent memory / cs.AI. [arXiv](https://arxiv.org/abs/2603.18718)
- **S2D2: Fast Decoding for Diffusion LLMs via Training-Free Self-Speculation** — Ligong Han et al. Training-free speculative-decoding analog for diffusion LMs. _Category:_ arXiv:2603.25702 — diffusion LM / cs.CL. [arXiv](https://arxiv.org/abs/2603.25702)
