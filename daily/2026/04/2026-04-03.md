## Major news & releases

### Microsoft governance day

**Microsoft ships Agent Governance Toolkit — open-source runtime security for autonomous agents.** First toolkit to address all 10 OWASP agentic-AI risks with deterministic, sub-millisecond policy enforcement (p99 latency below 0.1ms). Seven-package system in Python, TypeScript, Rust, Go and .NET; the Agent OS package is a stateless policy engine that intercepts every agent action before execution. Live integrations with LangChain, CrewAI, Google ADK, Microsoft Agent Framework, plus Dify, LlamaIndex, OpenAI Agents SDK, Haystack, LangGraph and PydanticAI. Compliance tooling maps to EU AI Act, HIPAA and SOC 2. 9,500+ tests, continuous fuzzing via ClusterFuzzLite, SLSA-compatible build provenance, OpenSSF Scorecard, CodeQL and Dependabot. Microsoft has signalled it wants the project to move into a foundation home for community governance. _Why it matters:_ The most credible attempt yet at a vendor-neutral agent governance runtime, explicitly framed for the EU AI Act's 2 August GP-AI deadline. Sub-millisecond enforcement is the latency budget that lets governance run in-line on every tool call without breaking the agent loop. [Microsoft Open Source Blog](https://opensource.microsoft.com/blog/2026/04/02/introducing-the-agent-governance-toolkit-open-source-runtime-security-for-ai-agents/) · [Microsoft community — architecture deep dive](https://techcommunity.microsoft.com/blog/linuxandopensourceblog/agent-governance-toolkit-architecture-deep-dive-policy-engines-trust-and-sre-for/4510105) · [Help Net Security](https://www.helpnetsecurity.com/2026/04/03/microsoft-ai-agent-governance-toolkit/) · [Phoronix](https://www.phoronix.com/news/Microsoft-AI-Agent-Governance) · [byteiota explainer](https://byteiota.com/microsoft-agent-governance-toolkit-open-source-ai-security/) · [Digital Applied implementation notes](https://www.digitalapplied.com/blog/microsoft-agent-governance-toolkit-runtime-security)

## Research highlights

- **SKILL0: In-Context Agentic Reinforcement Learning for Skill Internalization** — anonymous (cs.AI/cs.LG). In-context RL with dynamic curriculum that lets agents internalise tool-use skills during training, then operate zero-shot at inference without heavy context overhead of skill libraries. Tested on ALFWorld and Search-QA. _Category:_ arXiv:2604.02268 — cs.AI. [arXiv](https://arxiv.org/abs/2604.02268)
- **Therefore I am. I Think** — anonymous (cs.CL/cs.AI). Interpretability result: reasoning models encode action/tool-call decisions in pre-generation activations before textual deliberation begins. Linear probes + activation steering confirm — the chain may be partly post-hoc rationalisation. _Category:_ arXiv:2604.01202 — cs.CL. [arXiv](https://arxiv.org/abs/2604.01202)
- **CORAL: Towards Autonomous Multi-Agent Evolution for Open-Ended Discovery** — anonymous (cs.MA). Multi-agent framework with persistent memory and asynchronous execution targeting open-ended math/optimisation discovery; explicit knowledge-reuse channel between agents — beyond debate-style aggregators. _Category:_ arXiv:2604.01658 — cs.MA. [arXiv](https://arxiv.org/abs/2604.01658)
- **Investigating Autonomous Agent Contributions in the Wild** — anonymous (cs.SE/cs.AI). Empirical analysis of AI coding agents on OSS projects: higher PR activity but elevated code-churn and lower survival rates vs. human-authored code. Concrete data point for the agent-productivity vs. agent-debt argument. _Category:_ arXiv:2604.00917 — cs.AI. [arXiv](https://arxiv.org/abs/2604.00917)
- **Apriel-Reasoner: RL Post-Training for General-Purpose and Efficient Reasoning** — anonymous (cs.CL/cs.LG). 15B reproducible RL recipe with multi-domain training, domain sampling, explicit length penalty pushing the Pareto frontier of accuracy-vs-tokens. _Category:_ arXiv:2604.02007 — cs.CL. [arXiv](https://arxiv.org/abs/2604.02007)
- **Ask or Assume? Uncertainty-Aware Clarification-Seeking in Coding Agents** — anonymous (cs.SE/cs.AI). Multi-agent scaffold detects underspecified SWE-bench tasks and proactively asks clarifying questions instead of guessing; well-calibrated uncertainty improves task resolve rate on OpenHands + Claude Sonnet 4.5. _Category:_ arXiv:2603.26233 — cs.AI. [arXiv](https://arxiv.org/abs/2603.26233)
- **AutoMIA: Improved Baselines for Membership Inference Attack via Agentic Self-Exploration** — anonymous (cs.LG/cs.CR). Agentic framework that automatically searches the MIA attack space with closed-loop self-evaluation; model-agnostic stronger baselines. _Category:_ arXiv:2604.01014 — cs.LG. [arXiv](https://arxiv.org/abs/2604.01014)
- **The Latent Space: Foundation, Evolution, Mechanism, Ability, and Outlook** — anonymous (cs.CL/cs.LG). Position paper: latent-space computation (continuous representations, no discretisation bottleneck) is becoming substrate for both language and multimodal models. Synthesises latent-reasoning literature into one frame. _Category:_ arXiv:2604.02029 — cs.CL. [arXiv](https://arxiv.org/abs/2604.02029)
