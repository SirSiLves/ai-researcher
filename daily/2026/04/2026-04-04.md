## Research highlights

_Saturday — arXiv has no Saturday submission slot; HF Papers `/date/2026-04-04` redirects to Friday 2026-04-03. Picks below are the strongest items from that Friday cohort that match the focus areas, surfaced as Saturday backfill (non-overlapping with Sunday)._

- **SKILL0: In-Context Agentic Reinforcement Learning for Skill Internalization** — Zhengxi Lu, Zhiyuan Yao. Trains agents on a curriculum that begins with full skill context and progressively withdraws it, so skills end up baked into model weights rather than retrieved at runtime. Practical alternative to skill-bank retrieval; counterpoint to the "graph-of-skills at inference" line. _Category:_ arXiv:2604.02268 — cs.AI. [arXiv](https://arxiv.org/abs/2604.02268)
- **CORAL: Towards Autonomous Multi-Agent Evolution for Open-Ended Discovery** — Ao Qu, Han Zheng. MIT framework with shared persistent memory, asynchronous multi-agent execution, and heartbeat-based interventions. Reports concrete co-evolution wins (e.g. kernel engineering 1363→1103 cycles with four agents) — directly relevant to the agent-evolution thread. _Category:_ arXiv:2604.01658 — cs.MA. [arXiv](https://arxiv.org/abs/2604.01658)
- **Apriel-1.5-OpenReasoner: RL Post-Training for General-Purpose and Efficient Reasoning** — Rafael Pardinas, Ehsan Kamalloo. ServiceNow's 15B reasoning model RL-trained across five domains with a difficulty-aware length penalty; produces 30-50% shorter reasoning traces at competitive accuracy. Important data point for the "concise-reasoning vs. longer-chains" debate. _Category:_ arXiv:2604.02007 — cs.CL. [arXiv](https://arxiv.org/abs/2604.02007)
- **The Latent Space: Foundation, Evolution, Mechanism, Ability, and Outlook** — Xinlei Yu, Zhangquan Chen et al. (37 authors). Position survey arguing latent space is becoming a native substrate for language models — alternative to explicit token-level generation. Vocabulary check for the latent-reasoning / continuous-thought cluster (CoCoMix, COCONUT, etc.). _Category:_ arXiv:2604.02029 — cs.CL. [arXiv](https://arxiv.org/abs/2604.02029)
- **Signals: Trajectory Sampling and Triage for Agentic Interactions** — Shuguang Chen, Adil Hafeez. DigitalOcean's lightweight, signal-based framework for picking valuable agent trajectories without LLM-as-judge or human review. Computes structured interaction/execution/environment signals and beats random sampling + heuristic filters on informativeness. _Category:_ arXiv:2604.00356 — cs.AI. [arXiv](https://arxiv.org/abs/2604.00356)
- **GPA: Learning GUI Process Automation from Demonstrations** — Zirui Zhao, Jun Hao Liew. Salesforce single-demo GUI agent: vision-only replay with Monte Carlo localisation, deterministic readiness calibration, local execution for privacy. Reports superior stability vs Gemini 3 Pro on process replay — "boring but reliable" counter-example to the LLM-driven CUA approach. _Category:_ arXiv:2604.01676 — cs.AI. [arXiv](https://arxiv.org/abs/2604.01676)
- **Investigating Autonomous Agent Contributions in the Wild** — Razvan Mihai Popescu, David Gros (TU Delft). 110K open-source PRs across Codex, Claude Code, Copilot, Jules, Devin: agent participation rising, but agent-written code shows higher churn than human-written. _Category:_ arXiv:2604.00917 — cs.AI. [arXiv](https://arxiv.org/abs/2604.00917)
- **Executing as You Generate: Hiding Execution Latency in LLM Code Generation** — Zhensu Sun, Zhihao Lin. Eager runs code in parallel with token generation via AST-based chunking; up to 55% end-to-end latency reduction for coding agents. _Category:_ arXiv:2604.00491 — cs.SE. [arXiv](https://arxiv.org/abs/2604.00491)
