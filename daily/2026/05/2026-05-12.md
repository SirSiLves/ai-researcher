## Research & papers

**ComplexMCP: Evaluation of LLM Agents in Dynamic, Interdependent, and Large-Scale Tool Sandbox** — anonymous (cs.AI). _Takeaway:_ First MCP-native evaluation that models tool interdependence and dynamic state — fills the gap between toy MCP demos and production MCP servers where calls mutate the environment for later calls. _Category:_ arXiv:2605.10787. [link](https://arxiv.org/abs/2605.10787)

**MCP-Cosmos: World Model-Augmented Agents for Complex Task Execution in MCP Environments** — cs.MA. _Takeaway:_ Bolts a learned world model onto an MCP client so the agent simulates likely outcomes of tool calls before invoking. Directly relevant to anyone wiring Anthropic/OpenAI agents into multi-tool MCP stacks. _Category:_ arXiv:2605.09131. [link](https://arxiv.org/abs/2605.09131)

**Safe, or Simply Incapable? Rethinking Safety Evaluation for Phone-Use Agents** — HF-trending. _Takeaway:_ Argues current phone-use-agent safety benchmarks reward incapable agents; proposes capability-controlled evaluation. Important framing for governance teams scoring computer-use/mobile-agent vendors. _Category:_ arXiv:2605.07630. [link](https://arxiv.org/abs/2605.07630)

**A Single Neuron Is Sufficient to Bypass Safety Alignment in Large Language Models** — HF-trending. _Takeaway:_ Identifies one neuron whose suppression removes refusal across multiple aligned models — striking interpretability/safety finding with obvious red-team and governance implications. _Category:_ arXiv:2605.08513. [link](https://arxiv.org/abs/2605.08513)

**Rethinking Agentic Search with Pi-Serini: Is Lexical Retrieval Sufficient?** — cs.IR. _Takeaway:_ Stress-tests whether expensive embedding retrieval actually beats BM25 once an agent is in the loop; finds lexical retrieval is competitive or better in agentic-search workloads. Counters the vector-DB-everywhere reflex. _Category:_ arXiv:2605.10848. [link](https://arxiv.org/abs/2605.10848)

**Route Before Retrieve: Activating Latent Routing Abilities of LLMs for RAG vs. Long-Context Selection** — cs.CL. _Takeaway:_ Treats the RAG-vs-long-context decision as a per-query routing problem; shows LLMs already encode the signal to pick. Practical recipe for hybrid retrieval stacks. _Category:_ arXiv:2605.10235. [link](https://arxiv.org/abs/2605.10235)

**Can Agent Benchmarks Support Their Scores? Evidence-Supported Bounds for Interactive-Agent Evaluation** — cs.AI. _Takeaway:_ Derives statistical confidence bounds for agent-benchmark scores; agent leaderboards typically report point estimates from few runs. Should change how vendors publish eval numbers. _Category:_ arXiv:2605.10448. [link](https://arxiv.org/abs/2605.10448)

**Shepherd: A Runtime Substrate Empowering Meta-Agents with a Formalized Execution Trace** — cs.AI / HF. _Takeaway:_ Formal trace format so meta-agents (agents that orchestrate other agents) can reason over what their workers did — close cousin to OpenTelemetry-for-AI. _Category:_ arXiv:2605.10913. [link](https://arxiv.org/abs/2605.10913)

**PRISM: Generation-Time Detection and Mitigation of Secret Leakage in Multi-Agent LLM Pipelines** — cs.AI. _Takeaway:_ Inline guardrail detects and redacts secrets (API keys, PII, internal URLs) as agents stream; practical safety primitive for multi-agent MCP pipelines. _Category:_ arXiv:2605.10614. [link](https://arxiv.org/abs/2605.10614)

**Designing Intelligent Enterprise Agents: A Capability-Aligned Multi-Agent Architecture** — cs.MA. _Takeaway:_ Reference architecture for enterprise multi-agent deployments aligned to a capability taxonomy; useful skeleton for SAP/Salesforce/ServiceNow-style stacks. _Category:_ arXiv:2605.08258. [link](https://arxiv.org/abs/2605.08258)

**Safe Multi-Agent Behavior Must Be Maintained, Not Merely Asserted: Constraint Drift in LLM-Based Multi-Agent Systems** — cs.MA. _Takeaway:_ Documents how safety constraints quietly erode across multi-agent rounds even when each agent passes single-turn safety tests. _Category:_ arXiv:2605.10481. [link](https://arxiv.org/abs/2605.10481)
