## Methodology notes
- Stage uses score_slow (slow EMA, α=0.05, ~14-day half-life). Direction uses score_fast vs score_slow ratio: surging > 1.50, rising > 1.10, fading < 0.90, else steady.
- Source weights and caps live in `sources.json → radar_config`. Topics in ≥3 source types get a 1.5x convergence multiplier.
- Breadth = distinct orgs talking this week, primary subject (not author). High breadth flag at ≥5 orgs/7d.
- Clusters are curated (topic→cluster map) for this run because per-day collector files create too much shared-evidence noise for graph-based clustering.
