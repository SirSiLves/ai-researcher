## Research highlights

- **Advancing Mathematics Research with AI-Driven Formal Proof Search** — Tsoukalas, Kovsharov, Shirobokov, Surina. First large-scale eval of LLM-driven Lean proof search on *open* problems: autonomously resolves 9/353 Erdős problems at a few hundred dollars each and 44/492 OEIS conjectures. Already in use by working math research groups. ([arXiv 2605.22763](https://arxiv.org/abs/2605.22763))
- **Boiling the Frog: A Multi-Turn Benchmark for Agentic Safety** — Bisconti, Prandi, Pierucci, Sartore. Argues single-turn safety evals miss the deployed-agent risk surface; benchmarks whether tool-using agents can be steered into harmful actions through gradual multi-turn escalation. ([arXiv 2605.22643](https://arxiv.org/abs/2605.22643))
- **AMEL: Accumulated Message Effects on LLM Judgments** — Temkit. 75,898 API calls across 11 models showing LLM judges drift toward the prevailing polarity of prior items in the same conversation (d = -0.17, p < 10^-46). Direct concern for anyone running LLM-as-judge eval pipelines in batches. ([arXiv 2605.22714](https://arxiv.org/abs/2605.22714))
- **Memory-R2: Fair Credit Assignment for Long-Horizon Memory-Augmented LLM Agents** — Yan, Bahloul, Nie, Schwarzmann. Notes that GRPO-style group-relative RL breaks for memory-augmented agents because rollouts diverge once they write/update/delete memory differently. Proposes a fair credit-assignment scheme — a training-loop fix, not a benchmark. ([arXiv 2605.21768](https://arxiv.org/abs/2605.21768))
- **Trace2Skill: Verifier-Guided Skill Evolution for Long-Context EDA Agents** — Du, Pinckney. Test-time scaling for a hardware-design agent that treats the natural-language skill as an evolvable policy. Pattern generalises well beyond Verilog. ([arXiv 2605.21810](https://arxiv.org/abs/2605.21810))
- **Cross-domain benchmarks reveal when coordinated AI agents improve scientific inference from partial evidence** — Wong, Buehler. Four scientific tasks with frozen panels and explicit nulls, used to define *three operating regimes* under which coordinated agents beat simpler workflows. A rare empirical answer to "do we actually need a multi-agent system here?". ([arXiv 2605.22300](https://arxiv.org/abs/2605.22300))
- **GraphRAG on Consumer Hardware: Benchmarking Local LLMs for Healthcare EHR Schema Retrieval** — Fernandes, Kanjilal. Implements Microsoft's GraphRAG against real EHR schema docs with Llama 3.1 and other locally-deployed open models. Useful data point for local vs hosted GraphRAG in regulated domains. ([arXiv 2605.20815](https://arxiv.org/abs/2605.20815))
- **Bridging the Cold-Start Gap: LLM-Powered Synthetic Data Generation for Natural Language Search at Airbnb** — Wei, Li, Guo, Liu. Production case study on bootstrapping an NL search system with LLM-generated queries and labels — useful template for shipping retrieval at scale before you have data. ([arXiv 2605.21812](https://arxiv.org/abs/2605.21812))
