## Top papers
- **Bridging Protocol and Production: Design Patterns for Deploying AI Agents with Model Context Protocol** — Vasundra Srinivasan. _Why notable:_ One of the first peer-style papers to treat MCP as a real production protocol; names identity propagation, tool budgeting, error handling as the deployment gaps. [arXiv:2603.13417](https://arxiv.org/abs/2603.13417)
- **Sell Me This Stock: Unsafe Recommendation Drift in LLM Agents** — Zekun Wu, Adriano Koshiyama. _Why notable:_ Stronger models show *worse* safety violations on manipulated tool data — counter-intuitive scaling result. [arXiv:2603.12564](https://arxiv.org/abs/2603.12564)
- **Strategic Navigation or Stochastic Search? How Agents and Humans Reason Over Document Collections** — Łukasz Borchmann, Jordy Van Landeghem. _Why notable:_ Multimodal agents match human accuracy on document search but rely on brute-force compensation for weak strategic planning. [arXiv:2603.12180](https://arxiv.org/abs/2603.12180)
- **Meta-Reinforcement Learning with Self-Reflection for Agentic Search** — Teng Xiao, Yige Yuan. _Why notable:_ Cross-episode self-reflection as concrete agent-memory pattern. [arXiv:2603.11327](https://arxiv.org/abs/2603.11327)
- **DIVE: Scaling Diversity in Agentic Task Synthesis for Generalizable Tool Use** — Aili Chen, Chi Zhang. _Why notable:_ Argument-grade evidence for "synth-data quality, not size" in tool-using LLMs. [arXiv:2603.11076](https://arxiv.org/abs/2603.11076)
- **IndexCache: Accelerating Sparse Attention via Cross-Layer Index Reuse** — Yushi Bai, Qian Dong. _Why notable:_ ~75% sparse-attention indexer compute cut; long-context inference economics. [arXiv:2603.12201](https://arxiv.org/abs/2603.12201)
- **Examining Reasoning LLMs-as-Judges in Non-Verifiable LLM Post-Training** — Henry Liu et al. _Why notable:_ LLM-as-judge reliability for non-verifiable tasks. [arXiv:2603.12246](https://arxiv.org/abs/2603.12246)
- **Video-Based Reward Modeling for Computer-Use Agents** — Lin Xinso et al. _Why notable:_ Reward-spec for autonomous computer-using agents. [arXiv:2603.10178](https://arxiv.org/abs/2603.10178)
