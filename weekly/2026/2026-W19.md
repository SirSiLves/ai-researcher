## Top papers

**Coordination as an Architectural Layer for LLM-Based Multi-Agent Systems** — Nechepurenko, Shuvalov. Production multi-agent failure rates are 41–87% from coordination defects, not model defects; coordination deserves separate treatment from agent logic. [arxiv 2605.03310](https://arxiv.org/abs/2605.03310)

**RAG over Thinking Traces Can Improve Reasoning Tasks** — Arabzadeh, Ma, Min, Zaharia. Retrieving solution traces (not documents) lifts AIME by +56% on Gemini-2.5-Flash; counters "RAG doesn't help reasoning." [arxiv 2605.03344](https://arxiv.org/abs/2605.03344)

**MemFlow: Intent-Driven Memory Orchestration for Small Language Model Agents** — Chen, Li, Wang. Training-free intent-routing on frozen Qwen3-1.7B achieves 2× accuracy; useful counterweight to "you need frontier models for agentic memory." [arxiv 2605.03312](https://arxiv.org/abs/2605.03312)

**SURE-RAG: Sufficiency and Uncertainty-Aware Evidence Verification for Selective RAG** — Qiu, Han, Huang. Set-level sufficiency verification (not per-passage) yields 0.9075 Macro-F1 on HotpotQA-RAG with 37% fewer unsafe answers. [arxiv 2605.03534](https://arxiv.org/abs/2605.03534)

**QKVShare: Quantized KV-Cache Handoff for Multi-Agent On-Device LLMs** — Honavar, GVSL. Token-level mixed-precision KV handoff between on-device agents; 8K-context TTFT 1029.7ms → 397.1ms. [arxiv 2605.03884](https://arxiv.org/abs/2605.03884)

**Position: Safety and Fairness in Agentic AI Depend on Interaction Topology, Not Model Scale** — Shifts evaluation from per-model alignment to system topology + governance architecture as the load-bearing safety factor. [arxiv 2605.01147](https://arxiv.org/abs/2605.01147)

**Beyond Similarity Search: A Unified Data Layer for Production RAG Systems** — Budigi, Sirigiri. PostgreSQL+pgvector unified layer eliminates staleness and tenant-leakage pathologies; 92% latency reduction on filtered queries. [arxiv 2605.03275](https://arxiv.org/abs/2605.03275)

**International AI Safety Report 2026** — Bengio + 100+ experts, 30+ nations. Flags "evaluation gap" as central challenge: pre-deployment tests don't reliably predict real-world utility or risk. [internationalaisafetyreport.org](https://internationalaisafetyreport.org/publication/international-ai-safety-report-2026)
