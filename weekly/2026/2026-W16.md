## Top papers

**Dive into Claude Code: The Design Space of Today's and Future AI Agent Systems** — Jiacheng Liu, Xiaohan Zhao. Reverse-engineered architectural anatomy of Claude Code with comparison to OpenClaw; closest thing yet to a "how this is actually built" reference for frontier coding agents — baseline reading for any agent-platform team. [arxiv 2604.14228](https://arxiv.org/abs/2604.14228)

**Don't Retrieve, Navigate: Distilling Enterprise Knowledge into Navigable Agent Skills for QA and RAG** — Yiqun Sun, Pengfei Wei. Corpus2Skill turns document collections into hierarchical skill directories that agents navigate instead of consuming flat retrieval results — beats traditional RAG on enterprise QA where structure matters. [arxiv 2604.14572](https://arxiv.org/abs/2604.14572)

**UniDoc-RL: Coarse-to-Fine Visual RAG with Hierarchical Actions and Dense Rewards** — Jun Wang, Shuo Tan (DeepGlint). Progressively refines visual evidence from retrieval through image selection to active region cropping with a dense reward; up to 17.7% gains over prior RL-based visual-RAG methods. [arxiv 2604.14967](https://arxiv.org/abs/2604.14967)

**KV Packet: Recomputation-Free Context-Independent KV Caching for LLMs** — Chuangtao Chen, Grace Li Zhang. Reusable cached documents via trainable soft-token adapters instead of recomputation; near-zero FLOPs and lower TTFT than recomputation baselines — concrete inference-economics win. [arxiv 2604.13226](https://arxiv.org/abs/2604.13226)

**Modality-Native Routing in Agent-to-Agent Networks: A Multimodal A2A Protocol Extension** — Vasundra Srinivasan. MMA2A inspects A2A Agent Card capability declarations to route voice / image / text in their native modality; 52% task completion vs 32% for text-only systems on vision-dependent tasks. [arxiv 2604.12213](https://arxiv.org/abs/2604.12213)

**A Survey on the Security of Long-Term Memory in LLM Agents: Toward Mnemonic Sovereignty** — Zehao Lin, Chunyu Li. Surveys persistent-memory threats (poisoning, unauthorized access, cross-session corruption) and proposes "mnemonic sovereignty" as a verifiable governance frame across write/storage/retrieval/execution/sharing/deletion. [arxiv 2604.16548](https://arxiv.org/abs/2604.16548)

**SafeDream: Safety World Model for Proactive Early Jailbreak Detection** — Bo Yan, Weikai Lin. Lightweight external safety world model that combines statistical detection with contrastive analysis to flag multi-turn jailbreaks ~1.0–1.2 conversation turns before compliance — moves jailbreak defense from per-turn refusal to trajectory-level prediction. [arxiv 2604.16824](https://arxiv.org/abs/2604.16824)

**Cyber Defense Benchmark: Agentic Threat Hunting Evaluation for LLMs in SecOps** — Alankrit Chona, Igor Kozlov. 106 real attack procedures, 86 MITRE ATT&CK sub-techniques wrapped as a Gymnasium RL environment; even Claude Opus 4.6 only flags 3.8% of malicious events on average — sharp reality check on agentic SecOps. [arxiv 2604.19533](https://arxiv.org/abs/2604.19533)

**DR³-Eval: Towards Realistic and Reproducible Deep Research Evaluation** — Qianqian Xie, Qingheng Xiong (NJU-LINK). Benchmark using authentic user-provided materials paired with a static research corpus and a multi-dimensional rubric — surfaces real retrieval-robustness and hallucination gaps in current "deep research" agents. [arxiv 2604.14683](https://arxiv.org/abs/2604.14683)

**The Past Is Not Past: Memory-Enhanced Dynamic Reward Shaping (MEDS)** — Yang Liu, Enxi Wang, Yufei Gao et al. Clusters past failure representations and penalizes rollouts in dense error clusters; up to 4.13 pass@1 gain — a fix for the RL-collapsing-diversity failure mode that standard entropy regularization misses. [arxiv 2604.11297](https://arxiv.org/abs/2604.11297)

**MCPThreatHive: Automated Threat Intelligence for Model Context Protocol Ecosystems** — Yi Ting Shen, Kentaroh Toyoda. Open-source platform that automates the MCP threat-intelligence lifecycle (collection → AI-driven extraction/classification → knowledge graph) and operationalizes the MCP-38 threat taxonomy. [arxiv 2604.13849](https://arxiv.org/abs/2604.13849)
