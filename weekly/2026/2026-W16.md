## Top papers
- **Dive into Claude Code: The Design Space of Today's and Future AI Agent Systems** — Liu, Zhao. _Why notable:_ Reverse-engineering anatomy of Claude Code as production agent system with OpenClaw comparison — closest "how this is actually built" reference for frontier coding agents. [arXiv:2604.14228](https://arxiv.org/abs/2604.14228)
- **Modality-Native Routing in Agent-to-Agent Networks (MMA2A)** — Srinivasan. _Why notable:_ A2A protocol extension routing voice / image / text in native modality; 52% vs 32% task completion on vision-dependent tasks. [arXiv:2604.12213](https://arxiv.org/abs/2604.12213)
- **Cyber Defense Benchmark: Agentic Threat Hunting Evaluation for LLMs in SecOps** — Chona, Kozlov. _Why notable:_ 106 real attack procedures × 86 MITRE ATT&CK sub-techniques; Claude Opus 4.6 flags only 3.8% of malicious events on average — sharp SecOps recall reality check. [arXiv:2604.19533](https://arxiv.org/abs/2604.19533)
- **A Survey on the Security of Long-Term Memory in LLM Agents: Toward Mnemonic Sovereignty** — Lin, Li. _Why notable:_ Surveys persistent-memory threats; "mnemonic sovereignty" as a verifiable governance frame across write/storage/retrieval/execution/sharing/deletion. [arXiv:2604.16548](https://arxiv.org/abs/2604.16548)
- **SafeDream: Safety World Model for Proactive Early Jailbreak Detection** — Yan, Lin. _Why notable:_ Flags multi-turn jailbreak ~1.2 turns before compliance — proactive defense complement. [arXiv:2604.16824](https://arxiv.org/abs/2604.16824)
- **Don't Retrieve, Navigate: Distilling Enterprise Knowledge into Navigable Agent Skills** — Sun, Wei. _Why notable:_ Replaces RAG with skill-navigation; direct challenge to vanilla retrieval for enterprise KB. [arXiv:2604.14572](https://arxiv.org/abs/2604.14572)
- **UniDoc-RL: Coarse-to-Fine Visual RAG with Hierarchical Actions and Dense Rewards** — Wang, Tan. _Why notable:_ 17.7% gains over prior RL-based visual RAG. [arXiv:2604.14967](https://arxiv.org/abs/2604.14967)
- **Cybersecurity as Proof of Work** — Breunig essay + AISI Mythos eval. _Why notable:_ The defensive economic frame for the Mythos era — more tokens spent = more exploits found.
- **MCPThreatHive: Automated Threat Intelligence for MCP Ecosystems** — Shen, Toyoda. _Why notable:_ Open-source automation of the MCP threat-intel lifecycle; operationalises MCP-38 taxonomy. [arXiv:2604.13849](https://arxiv.org/abs/2604.13849)
- **KnowRL: Boosting LLM Reasoning via RL with Minimal-Sufficient Knowledge** — anon. _Why notable:_ Grounds reward at minimal-sufficient knowledge unit; counterpoint to "longer CoT = better." [arXiv:2604.12627](https://arxiv.org/abs/2604.12627)
