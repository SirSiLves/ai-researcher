## Top papers

**MCP-DPT: A Defense-Placement Taxonomy and Coverage Analysis for Model Context Protocol Security** — Rostamzadeh, Narula. Layer-aligned taxonomy organizing MCP attacks by enforcing architectural component; finds defenses unevenly distributed across MCP's six layers. Defense-placement view rather than the more common attack-catalog framing. [arxiv 2604.07551](https://arxiv.org/abs/2604.07551)

**Securing Retrieval-Augmented Generation: A Taxonomy of Attacks, Defenses, and Future Directions** — Xu, Zhang. Separates inherent LLM vulnerabilities from those introduced by the RAG layer; six-stage workflow surfaces, four primary attack surfaces, pivot from reactive patching to layered, boundary-aware governance. [arxiv 2604.08304](https://arxiv.org/abs/2604.08304)

**Externalization in LLM Agents: A Unified Review of Memory, Skills, Protocols and Harness Engineering** — Zhou, Chai. Frames the agent stack as moving from parametric capability to externalized cognitive artifacts (memory, skills, MCP/A2A protocols, harness code) — cleanest taxonomy yet for "what's outside the weights." [arxiv 2604.08224](https://arxiv.org/abs/2604.08224)

**Graph of Skills: Dependency-Aware Structural Retrieval for Massive Agent Skills** — Liu, Li. Executable skill graph + reverse-weighted Personalized PageRank with context-budgeted hydration; reward and token-efficiency wins across SkillsBench + ALFWorld. Concrete answer to "how do you retrieve over a skill library at scale." [arxiv 2604.05333](https://arxiv.org/abs/2604.05333)

**SkillClaw: Let Skills Evolve Collectively with an Agentic Evolver** — Ma, Yang. Multi-user ecosystem where an autonomous evolver aggregates per-user interactions to refine a shared skill repository — cross-user knowledge transfer with cumulative capability improvement. Third corner of the skill-library design space alongside Graph of Skills (retrieval) and SKILL0 (in-weight). [arxiv 2604.08377](https://arxiv.org/abs/2604.08377)

**MolmoWeb: Open Visual Web Agent and Open Data for the Open Web** — Gupta, Wolters. Open-weight web agent navigating from screenshots (no HTML or accessibility tree) with synthetic trajectories + human demos + atomic web-skill data; state-of-the-art among open-weight web agents, releases data alongside models. [arxiv 2604.08516](https://arxiv.org/abs/2604.08516)

**RAGEN-2: Reasoning Collapse in Agentic RL** — Identifies "template collapse" in multi-turn LLM agents (outputs structurally similar across inputs while entropy looks healthy); proposes mutual-information proxies and SNR-aware filtering. Sharp diagnostic for why agent RL plateaus when standard metrics say it shouldn't. [arxiv 2604.06268](https://arxiv.org/abs/2604.06268)

**Unifying Group-Relative and Self-Distillation Policy Optimization via Sample Routing (SRPO)** — Routes correct samples to GRPO-style RL and failed samples to logit-level self-distillation with entropy-aware dynamic weighting; argues neither GRPO nor SDPO alone is optimal. Concrete unification of the RLVR + distillation literature. [arxiv 2604.02288](https://arxiv.org/abs/2604.02288)

**Self-Distilled RLVR (RLSD)** — Combines RL with verifiable rewards and on-policy self-distillation; decomposes the RLVR update into magnitude and direction, with self-distillation supplying the missing fine-grained policy direction. Direct contribution to the unstable-RLVR thread. [arxiv 2604.03128](https://arxiv.org/abs/2604.03128)

**Test-Time Scaling Makes Overtraining Compute-Optimal** — Joint pass@k modeling shifts optimal pretraining decisions into the overtraining regime once inference cost is part of the optimization. Direct correction to Chinchilla-era recipes for any deployment running inference-time sampling at scale. [arxiv 2604.01411](https://arxiv.org/abs/2604.01411)

**Beyond Accuracy: Unveiling Inefficiency Patterns in Tool-Integrated Reasoning** — Introduces PTE (Prefill Token Equivalents), a hardware-aware metric that accounts for KV-cache eviction and long tool responses; correlates with actual wall-clock latency far better than raw token counts. Concrete instrumentation for agent-observability stacks. [arxiv 2604.05404](https://arxiv.org/abs/2604.05404)

**Rethinking Generalization in Reasoning SFT** — AI45Research. Systematic conditional analysis showing SFT and RL exhibit asymmetric cross-domain generalization on reasoning, and that reasoning gains and safety degradation track each other; documents a "dip-and-recovery" pattern in long-CoT training. [arxiv 2604.06628](https://arxiv.org/abs/2604.06628)
