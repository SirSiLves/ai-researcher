## Top papers
- **Coordination as an Architectural Layer for LLM-Based Multi-Agent Systems** — Nechepurenko, Shuvalov. _Why notable:_ 41-87% production multi-agent failure rate is coordination, not model — coordination as configurable layer. [arXiv:2605.03310](https://arxiv.org/abs/2605.03310)
- **Tool Calling is Linearly Readable and Steerable in Language Models** — Wu, Wang, Cho et al. (UCL / Holistic AI). _Why notable:_ Tool a model is about to call is encoded in a single linear direction in hidden state across 12 instruction-tuned models — cheap pre-execution probe. [arXiv:2605.07990](https://arxiv.org/abs/2605.07990)
- **ComplexMCP: Evaluation of LLM Agents in Dynamic, Interdependent, and Large-Scale Tool Sandbox** — anon. _Why notable:_ First MCP-native eval that models tool interdependence + dynamic state. [arXiv:2605.10787](https://arxiv.org/abs/2605.10787)
- **MCP-Cosmos: World Model-Augmented Agents for Complex Task Execution in MCP Environments** — anon. _Why notable:_ "Bring Your Own World Model" — MCP client simulates state transitions before executing tool calls. [arXiv:2605.09131](https://arxiv.org/abs/2605.09131)
- **Authorization Propagation in Multi-Agent AI Systems: Identity Governance as Infrastructure** — anon. _Why notable:_ Authorization as first-class infra concern across A2A and MCP handoffs. [arXiv:2605.05440](https://arxiv.org/abs/2605.05440)
- **STALE: Can LLM Agents Know When Their Memories Are No Longer Valid?** — anon. _Why notable:_ Current memory architectures (Mem0, etc.) largely fail to invalidate beliefs when new evidence arrives — sharp eval gap. [arXiv:2605.06527](https://arxiv.org/abs/2605.06527)
- **KV-Fold: One-Step KV-Cache Recurrence for Long-Context Inference** — anon. _Why notable:_ Training-free fold protocol; Llama-3.1-8B 100% needle-in-haystack 16K-128K on a single 40GB GPU. [arXiv:2605.12471](https://arxiv.org/abs/2605.12471)
- **Single-Agent LLMs Outperform Multi-Agent Systems on Multi-Hop Reasoning Under Equal Thinking Token Budgets** — Tran, Kiela. _Why notable:_ Normalises for compute and multi-agent edge largely vanishes — most reported MAS gains were extra test-time tokens. [arXiv:2604.02460](https://arxiv.org/abs/2604.02460)
- **MEME: Multi-entity & Evolving Memory Evaluation** — anon. _Why notable:_ All tested agent-memory systems collapse on dependency reasoning under defaults (3% Cascade / 1% Absence accuracy). [arXiv:2605.12477](https://arxiv.org/abs/2605.12477)
- **Self-Aware Vector Embeddings for RAG (SmartVector)** — anon. _Why notable:_ Augments dense embeddings with temporal validity + confidence decay + graph-relational signals; ~doubles top-1 accuracy. [arXiv:2604.20598](https://arxiv.org/abs/2604.20598)
