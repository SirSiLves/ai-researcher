## Top papers

**ComplexMCP: Evaluation of LLM Agents in Dynamic, Interdependent, and Large-Scale Tool Sandbox** — First MCP-native eval with interdependent dynamic tools; fills the gap between toy MCP demos and production servers where calls mutate state. [arxiv 2605.10787](https://arxiv.org/abs/2605.10787)

**MCP-Cosmos: World Model-Augmented Agents for Complex Task Execution in MCP Environments** — Bolts a learned world model onto an MCP client so the agent simulates likely outcomes of tool calls before invoking. Cited in two dailies this week. [arxiv 2605.09131](https://arxiv.org/abs/2605.09131)

**Bridging Protocol and Production: Design Patterns for Deploying AI Agents with Model Context Protocol** — Three production patterns (identity-scoped broker, adaptive timeout budget, structured error recovery); addresses the gap between spec and ~10k active servers. [arxiv 2603.13417](https://arxiv.org/abs/2603.13417)

**MCP Tool Descriptions Are Smelly!** — First large empirical study (856 tools across 103 MCP servers); description-quality "smells" measurably degrade agent performance. Operational input for anyone shipping MCP servers. [arxiv 2602.14878](https://arxiv.org/abs/2602.14878)

**Coordination as an Architectural Layer for LLM-Based Multi-Agent Systems** — 41–87% of multi-agent prod failures are coordination defects, not model capability. Picked up in Thursday's daily as the cite-able backdrop to the agentic-governance-gap thread. [arxiv 2605.03310](https://arxiv.org/abs/2605.03310)

**Single-Agent LLMs Outperform Multi-Agent Systems on Multi-Hop Reasoning Under Equal Thinking Token Budgets** — Normalises for compute and finds the multi-agent edge largely vanishes — most reported MAS gains were just extra test-time tokens. Important sobering counterweight to multi-agent hype. [arxiv 2604.02460](https://arxiv.org/abs/2604.02460)

**Tool Calling is Linearly Readable and Steerable in Language Models** — The tool a model is about to call is encoded in a single linear direction in hidden state across 12 instruction-tuned models (Gemma 3, Qwen 3, Llama 3.1) — cheap pre-execution probe for wrong-tool failures. [arxiv 2605.07990](https://arxiv.org/abs/2605.07990)

**Three RL-for-LLM-reasoning papers, opposing conclusions** — "Beyond Reasoning" (RL unlocks parametric knowledge, ~27% gains) vs. "Sparse Policy Selection, Not Capability Learning" vs. "Expressiveness Is Key (RL gains scale with logic expressiveness)." Three landed in one day on May 13 — defines a concrete debate axis for the discipline. [Parametric](https://arxiv.org/abs/2605.07153) · [Sparse](https://arxiv.org/abs/2605.06241) · [Expressiveness](https://arxiv.org/abs/2605.06638)

**A Single Neuron Is Sufficient to Bypass Safety Alignment in Large Language Models** — One neuron whose suppression removes refusal across multiple aligned models — striking interpretability + governance finding. [arxiv 2605.08513](https://arxiv.org/abs/2605.08513)

**Rethinking Agentic Search with Pi-Serini: Is Lexical Retrieval Sufficient?** — Stress-tests whether embedding retrieval beats BM25 once an agent is in the loop; finds lexical retrieval competitive or better. Counters the vector-DB-everywhere reflex. [arxiv 2605.10848](https://arxiv.org/abs/2605.10848)

**MEME: Multi-entity & Evolving Memory Evaluation** — All tested agent-memory systems collapse on dependency reasoning under defaults (3% Cascade / 1% Absence accuracy) despite passable static retrieval. Sharpens what "agent memory" actually means. [arxiv 2605.12477](https://arxiv.org/abs/2605.12477)

**Frontier Lag — Bibliometric Audit of Capability Misrepresentation in Academic AI Eval** — Pre-registered audit of 112k LLM papers (2022-01 to 2026-04). Median paper evaluates a model ~10.85 ECI behind the contemporaneous frontier (≈1.4× the gap between Sonnet 3.7 and Opus 4.5). Quantifies how stale academic LLM eval has become. [arxiv 2605.04135](https://arxiv.org/abs/2605.04135)
