## Top papers

**FIPO: Eliciting Deep Reasoning with Future-KL Influenced Policy Optimization** — anonymous (cs.LG). RL post-training method using discounted future-KL divergence to fix credit-assignment over long reasoning chains; argues vanilla PG dilutes reward signal across chain length and proposes a dense advantage that pulls signal closer to the steps it actually grades. Concrete entry in the "RL for reasoning vs. policy selection" debate. [arxiv 2603.19835](https://arxiv.org/abs/2603.19835)

**MonitorBench: A Comprehensive Benchmark for Chain-of-Thought Monitorability** — anonymous (cs.CL). Measures whether CoTs faithfully reveal decision-critical factors; monitorability drops sharply when structural reasoning isn't required and degrades further under stress-test conditions; both open- and closed-weight models fail. Pairs with "Therefore I am. I Think" (interpretability finding that action/tool-call decisions show up in pre-generation activations) to sharpen the CoT-faithfulness debate. [arxiv 2603.28590](https://arxiv.org/abs/2603.28590)

**Meta-Harness: End-to-End Optimization of Model Harnesses** — anonymous (cs.CL/cs.AI). Treats the agent harness (context manager, retriever, proposer, scheduler) as a searchable object; an outer-loop optimizer rewrites harness code from execution traces. Wins on TerminalBench-2 and retrieval-augmented math; the citable companion to "harness is the product" arguments and to Cursor 3 / Microsoft Agent Framework's first-class-harness framing. [arxiv 2603.28052](https://arxiv.org/abs/2603.28052)

**Terminal Agents Suffice for Enterprise Automation** — anonymous (cs.AI). Argues a plain terminal-based coding agent driving programmatic interfaces matches or beats heavily MCP/tool-augmented agents on enterprise tasks — direct counter-argument to the "more tools = better" framing of MCP-first stacks. [arxiv 2604.00073](https://arxiv.org/abs/2604.00073)

**Single-Agent LLMs Outperform Multi-Agent Systems on Multi-Hop Reasoning Under Equal Thinking Token Budgets** — Dat Tran, Douwe Kiela. Information-theoretic argument + empirical results across multiple model families: when reasoning-token budgets are held equal, single-agent setups consistently match or beat multi-agent systems on multi-hop reasoning. Important corrective to the "more agents = better" narrative. [arxiv 2604.02460](https://arxiv.org/abs/2604.02460)

**ASI-Evolve: AI Accelerates AI** — Weixian Xu, Tiantian Mi (GAIR/SII). Agentic learn–design–experiment–analyze loop across neural architectures, data curation and RL algorithms; reports 105 novel linear-attention architectures and gains over human-designed baselines in math + biomedicine. Concrete instantiation of the "AI-as-AI-researcher" thread. [arxiv 2603.29640](https://arxiv.org/abs/2603.29640)

**Apriel-1.5-OpenReasoner: RL Post-Training for General-Purpose and Efficient Reasoning** — Rafael Pardinas, Ehsan Kamalloo (ServiceNow). 15B reasoning model RL-trained across five domains with a difficulty-aware length penalty; 30–50% shorter reasoning traces at competitive accuracy. Pareto-frontier data point for the "concise reasoning vs. longer chains" debate. [arxiv 2604.02007](https://arxiv.org/abs/2604.02007)

**Do Phone-Use Agents Respect Your Privacy?** — anonymous (cs.AI). Introduces MyPhoneBench with an "iMy" minimal privacy contract; across 5 frontier models / 10 apps / 300 tasks, joint success-and-privacy evaluation reshuffles model rankings versus accuracy alone — persistent failure is data over-disclosure on benign tasks. Direct evidence for the governance/agent-privacy thread. [arxiv 2604.00986](https://arxiv.org/abs/2604.00986)

**CORAL: Towards Autonomous Multi-Agent Evolution for Open-Ended Discovery** — Ao Qu, Han Zheng (MIT). Multi-agent framework with shared persistent memory, asynchronous execution and heartbeat-based interventions; concrete co-evolution wins (e.g. kernel engineering 1363→1103 cycles with four agents). [arxiv 2604.01658](https://arxiv.org/abs/2604.01658)

**ClawKeeper: Comprehensive Safety Protection for Open Agents via Skills, Plugins, and Watchers** — anonymous (cs.AI). Defense framework for open-source agent runtimes (local file access, shell exec) that layers instruction-level policies, plugin sandboxing, and a watcher paradigm that intercepts high-risk actions for human confirmation. Citable control-plane reference design pairing with Microsoft's Agent Governance Toolkit. [arxiv 2603.24414](https://arxiv.org/abs/2603.24414)

**Investigating Autonomous Agent Contributions in the Wild** — Razvan Mihai Popescu, David Gros (TU Delft). 110K open-source PRs across Codex / Claude Code / Copilot / Jules / Devin: agent participation rising, but agent-written code shows higher churn and lower survival than human-authored code. Empirical input to the "agents-in-prod" governance debate. [arxiv 2604.00917](https://arxiv.org/abs/2604.00917)

**Omni-SimpleMem: Autoresearch-Guided Discovery of Lifelong Multimodal Agent Memory** — Jiaqi Liu, Zipeng Ling (UNC). Autonomous pipeline that discovers improved memory architectures (architectural fixes, not hyperparameter tuning): +411% F1 on LoCoMo, +214% on Mem-Gallery. Direct relevance to the agent-memory cluster where Mem0/STALE are converging. [arxiv 2604.01007](https://arxiv.org/abs/2604.01007)
