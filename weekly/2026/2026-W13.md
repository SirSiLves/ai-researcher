## Top stories

**Mythos / Capybara leak — Anthropic's step-change model revealed by misconfigured CMS** — Fortune broke on Thursday 26 March that a draft Anthropic blog post plus nearly 3,000 unpublished assets, describing an internal Capybara model branded externally as Claude Mythos, were left publicly accessible in a misconfigured CMS. The draft positioned Mythos as a new tier above Opus, with materially higher scores than Claude Opus 4.6 on software coding, academic reasoning and cybersecurity, and warned of "unprecedented cybersecurity risks." LayerX Security's Roy Paz and Cambridge's Alexandre Pauwels surfaced the exposed datastore; Anthropic confirmed the leak, blamed "human error" and acknowledged Mythos was already in early-access customer testing. By Friday Fortune's day-two coverage triggered cybersecurity-stock repricing on the leaked capability claims, and Saturday brought international coverage from NewsGhana, Techzine and a wave of EU/Commonwealth outlets framing it as an AI Act trilogue-adjacent policy story. _Why it matters:_ Easily the disclosure of the quarter — a frontier-lab packaging mistake that pre-stages the Claude Code source leak via missing `.npmignore` five days later (31 Mar) and forces the Mythos roll-out roadmap into the public eye before Anthropic had planned. Sets up the explicit "the model that crashed cybersecurity stocks before it was even announced" framing analysts will use through April.

**Harness engineering becomes the agent-platform reference architecture** — Anthropic's Labs engineer Prithvi Rajasekaran published "Harness design for long-running application development" on Mon 23 Mar, extending the November 2025 "Effective harnesses" piece with a three-agent planner / generator / evaluator decomposition: separate planning from generation, calibrate a dedicated evaluator with few-shot examples and scoring criteria to fight self-overrating, and use a distinct "initializer" prompt for the very first context window (the pass that builds `feature-list.json` and `init.sh`). Within hours Rick Hightower's "two agents, one feature list, zero context overflow" Medium piece, the `anthropics/cwc-long-running-agents` GitHub repo, a ZenML LLMOps DB entry, Just Understanding Data's generator-evaluator deep-dive, AddyOsmani.com's "agent harness engineering" essay, Anup's "the harness is the product" essay and a top-tier Hacker News thread all amplified. The harness-vs-model distinction also becomes very public very fast as Claude Code regressions (26 Mar caching-optimisation bug; peak-hours session limits) accumulate.

**Supply-chain compromise lands on the Python AI stack** — LiteLLM 1.82.7 and 1.82.8 shipped a malicious `litellm_init.pth` containing a base64 credential stealer; because Python loads `.pth` files at interpreter startup, *installing* the package was enough to execute the payload — no import required. It exfiltrated `~/.ssh/`, `~/.aws/`, crypto wallet directories, shell history. Daniel Hnyk (futuresearch.ai) used BigQuery PyPI download data to put the blast radius at 46,996 downloads in the ~46-minute live window; 88% of 2,337 dependents did not pin in a way that would have avoided the bad release. Callum McMahon's follow-up walked through using Claude inside a Docker container to confirm the malicious `.pth` and surface `security@pypi.org` as the report-to address — a concrete example of agentic incident response. Andrew Nesbitt's "Package Managers Need to Cool Down" survey, published in the same window, catalogued cooldown features that landed across pnpm 10.16, Yarn 4.10, Bun 1.3, Deno 2.6, uv 0.9.17, pip 26.0/26.1 and npm 11.10.0. Simon Willison's same-day take on Anthropic's new Auto mode for Claude Code (Sonnet 4.6 classifier gating tool calls against a default allow/soft-deny list) noted `pip install -r` is in the allow list — which wouldn't have stopped the LiteLLM attack. _Why it matters:_ The first AI-supply-chain incident with concrete blast-radius numbers, against a package that sits underneath a large slice of the open Python LLM tooling stack. Resets the dependency-management baseline for AI teams and gives the cooldown discussion its motivating event.

## Top papers

**FinMCP-Bench: Benchmarking LLM Agents for Real-World Financial Tool Use under the Model Context Protocol** — Zhu, Tian, Li, Wu. 613 samples across 33 financial scenarios and 65 real MCP servers; first MCP-native benchmark testing multi-turn, multi-tool reasoning where actual money would move. [arxiv 2603.24943](https://arxiv.org/abs/2603.24943)

**AgentRFC: Security Design Principles and Conformance Testing for Agent Protocols** — Zheng & Zhang. First systematic security framework for MCP/A2A/ANP/ACP with a formal architectural model and a cross-protocol gap detector — the protocol-conformance counterpart to AIP's identity layer. [arxiv 2603.23801](https://arxiv.org/abs/2603.23801)

**AIP: Agent Identity Protocol for Verifiable Delegation Across MCP and A2A** — Prakash. Introduces Invocation-Bound Capability Tokens (JWT + chained Biscuit forms) after a scan of ~2,000 MCP servers found *all* of them lacked authentication; direct input to the agent-identity radar thread. [arxiv 2603.24775](https://arxiv.org/abs/2603.24775)

**SlopCodeBench: Benchmarking How Coding Agents Degrade Over Long-Horizon Iterative Tasks** — Orlanski, Roy, Yun, Shin. First benchmark to directly measure code-quality drift across sequential agent-driven extensions; agent-authored code grows verbose and structurally erodes against human repos — useful counterweight to SWE-bench-style single-shot leaderboards. [arxiv 2603.24755](https://arxiv.org/abs/2603.24755)

**AVO: Agentic Variation Operators for Autonomous Evolutionary Search** — Chen, Ye, Xu. LLM agents as the variation operators in an evolutionary search loop; discovered attention kernels that outperform cuDNN and FlashAttention. Real-world demonstration that agentic search beats expert-engineered systems code. [arxiv 2603.24517](https://arxiv.org/abs/2603.24517)

**MSA: Memory Sparse Attention for Efficient End-to-End Memory Model Scaling to 100M Tokens** — Yu Chen, Runkai Chen. Sparse attention scheme pushing end-to-end memory models to 100 M-token contexts at linear complexity; decouples memory capacity from reasoning capacity and shifts the long-context-vs-RAG cost curve if it generalises. [arxiv 2603.23516](https://arxiv.org/abs/2603.23516)

**MemMA: Coordinating the Memory Cycle through Multi-Agent Reasoning and In-Situ Self-Evolution** — Lin, Zhang, Lu, Liu. End-to-end multi-agent memory cycle: a Meta-Thinker plans the forward path while in-situ probe-QA verifies and repairs memory on the backward path; pairs cleanly with the STALE / Mem0 memory-validity thread. [arxiv 2603.18718](https://arxiv.org/abs/2603.18718)

**OpenResearcher: A Fully Open Pipeline for Long-Horizon Deep Research Trajectory Synthesis** — Z. Li, Jiang, Ma, Zhang. Open pipeline for generating the long-horizon research trajectories used to train deep-research agents — concrete answer to the trajectory-data bottleneck keeping strong research agents inside industrial labs. [arxiv 2603.20278](https://arxiv.org/abs/2603.20278)

**Cryptographic Runtime Governance for Autonomous AI Systems: The Aegis Architecture** — Mazzocchetti. Treats policy/legal constraints as cryptographically sealed *execution* conditions with autonomous shutdown on violation; one of the first concrete hardware-rooted compliance boundary designs for autonomous agents. [arxiv 2603.16938](https://arxiv.org/abs/2603.16938)

**Mind the Gap: How the Technical Mechanisms of Agentic AI Outpace Global Legal Frameworks** — Osmond & Jego. Comparative legal analysis showing current statutes conflate model capability with system architecture and miss the actual control points (system prompts, API permissions, sandboxing) where agentic behaviour is governed. [arxiv 2603.27075](https://arxiv.org/abs/2603.27075)
