## Top papers

**Hierarchical Long-Term Semantic Memory for LinkedIn's Hiring Agent** — Zhentao Xu, Shangjing Zhang. _Why notable:_ Production memory architecture deployed in LinkedIn's Hiring Assistant; schema-aligned memory tree across multiple granularities reports >10% lifts on answer correctness and retrieval F1 with improved latency Pareto — industrial counterweight to bolt-on Mem0 patterns. [arxiv 2604.26197](https://arxiv.org/abs/2604.26197)

**Safe Bilevel Delegation (SBD): A Formal Framework for Runtime Delegation Safety in Multi-Agent Systems** — Yuan Sun. _Why notable:_ Bilevel optimization for hierarchical delegation with proven Safety Monotonicity, Inner Policy Convergence, and an Accountability Propagation bound across multi-hop chains — governance-grade formalism arriving exactly when Agent 365 and friends need it. [arxiv 2604.27358](https://arxiv.org/abs/2604.27358)

**NuggetIndex: Governed Atomic Retrieval for Maintainable RAG** — Saber Zerhoudi, Michael Granitzer (SIGIR '26). _Why notable:_ Atomic "nugget" records with temporal validity intervals and lifecycle states; +42% nugget recall, +9pp temporal correctness, −55% conflict rate, −64% generator input length vs passage/proposition baselines. Concrete maintainable-RAG plumbing for evolving corpora. [arxiv 2604.27306](https://arxiv.org/abs/2604.27306)

**ObjectGraph: From Document Injection to Knowledge Traversal — A Native File Format for the Agentic Era** — Mohit Dubey. _Why notable:_ Argues sequentially-readable documents are wasteful for retrieval-driven agents; proposes typed directed knowledge-graph format (.og) reporting up to 95.3% token reduction at parity task accuracy. Provocative reframing of "documents as agent inputs." [arxiv 2604.27820](https://arxiv.org/abs/2604.27820)

**Claw-Eval-Live: A Live Agent Benchmark for Evolving Real-World Workflows** — Chenxin Li, Zhengyang Tang. _Why notable:_ Dynamic benchmark refreshed against real demand signals with verifiable agent actions through execution traces and audit logs; even leading models reach only 66.7% completion, persistent failure on business workflows and multi-system operations. Audit-grade complement to OSWorld/WebArena. [arxiv 2604.28139](https://arxiv.org/abs/2604.28139)

**SAGA: Workflow-Atomic Scheduling for AI Agent Inference on GPU Clusters** — Dongxin Guo, Jikun Wu. _Why notable:_ Schedules entire agent workflows as atomic units rather than per-step inference calls; 1.64× faster task completion on a 64-GPU cluster serving SWE-bench coding agents and WebArena browser tasks. Platform-level pattern for production agent serving. [arxiv 2605.00528](https://arxiv.org/abs/2605.00528)

**Position: Safety and Fairness in Agentic AI Depend on Interaction Topology, Not on Model Scale or Alignment** — Tanav Singh Bajaj, Nikhil Singh. _Why notable:_ Argues three failure modes (ordering instability, information cascades, functional collapse) in deliberative MAS emerge from information-flow structure, not from per-model alignment — reframes the safety conversation toward topology-level properties. [arxiv 2605.01147](https://arxiv.org/abs/2605.01147)

**Tool Attention Is All You Need: Dynamic Tool Gating and Lazy Schema Loading for Eliminating the MCP/Tools Tax** — anonymous. _Why notable:_ Quantifies the hidden MCP "tax" as 10k–60k tokens per turn in typical multi-server setups from stateless eager schema injection; proposes dynamic tool gating + lazy schema loading. The first paper to put a concrete number on the MCP overhead problem. [arxiv 2604.21816](https://arxiv.org/abs/2604.21816)

**Latent Agents: A Post-Training Procedure for Internalized Multi-Agent Debate** — anonymous. _Why notable:_ Distills multi-agent debate into a single LLM via two-stage fine-tuning; matches or exceeds explicit debate while using up to 93% fewer tokens — direct cost/perf payoff for the "is multi-agent worth it?" debate. [arxiv 2604.24881](https://arxiv.org/abs/2604.24881)

**End-to-End Evaluation and Governance of an EHR-Embedded AI Agent for Clinicians** — Aaryan Shah, Andrew Hines. _Why notable:_ Field report on Hyperscribe with rubric validation (20 clinicians, 1,646 rubrics, 823 cases), live feedback, controlled experimentation across seven versions; median quality 84%→95%, live error reports 79%→30% over three months. Real-world template for "governance-as-product" in deployed clinical agents. [arxiv 2604.27309](https://arxiv.org/abs/2604.27309)

**A Language for Describing Agentic LLM Contexts (ACDL)** — Noga Peleg Pelc, Gal A. Kaminka, Yoav Goldberg (CAIS '26). _Why notable:_ Formal language for specifying LLM context structure and dynamics — role-message sequences, dynamic content, time-indexed references, conditional/iterative structure. Gives agent platforms a way to communicate and diff prompt architectures across implementations. [arxiv 2605.01920](https://arxiv.org/abs/2605.01920)
