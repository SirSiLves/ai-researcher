## Top papers

**Memento-Skills: Let Agents Design Agents** — Huichi Zhou, Siyuan Guo, Anjie Liu et al. _Why notable:_ Meta-agent framework where agents construct skill modules that downstream agents reuse without LLM parameter updates — the cleanest "agents that build their own subagents" pattern published this week. [arxiv 2603.18743](https://arxiv.org/abs/2603.18743)

**AndroTMem: From Interaction Trajectories to Anchored Memory in Long-Horizon GUI Agents** — Yibo Shi, Jungang Li, Linghao Zhang et al. _Why notable:_ Anchored State Memory represents long Android-GUI trajectories as causally linked intermediate-state anchors instead of full replays or summaries; 5–30% gains on long-horizon tasks. Direct evidence on memory granularity for CUA-style agents. [arxiv 2603.18429](https://arxiv.org/abs/2603.18429)

**ProRL Agent: Rollout-as-a-Service for RL Training of Multi-Turn LLM Agents** — Hao Zhang, Mingjie Liu, Shaokun Zhang et al. _Why notable:_ Disaggregates rollout collection from policy updates and exposes the agentic rollout lifecycle as an API service — concrete infrastructure for agent-RL beyond hand-rolled scripts. [arxiv 2603.18815](https://arxiv.org/abs/2603.18815)

**CUBE: A Standard for Unifying Agent Benchmarks** — Alexandre Lacoste, Nicolas Gontier. _Why notable:_ Universal benchmark/runtime protocol built on MCP's non-blocking `tools/call` API; if adopted, removes the per-benchmark integration tax that makes cross-benchmark comparison painful today. [arxiv 2603.15798](https://arxiv.org/abs/2603.15798)

**Nemotron-Cascade 2: Post-Training LLMs with Cascade RL and Multi-Domain On-Policy Distillation** — Zhuolin Yang, Zihan Liu, Yang Chen et al. _Why notable:_ NVIDIA post-training recipe combining cascade RL with multi-domain on-policy distillation — a 30B MoE reaches competition-level math/code reasoning; the citable reference for the "RL-first then distill" pipeline replacing SFT-then-RLHF. [arxiv 2603.19220](https://arxiv.org/abs/2603.19220)

**OpenSeeker: Democratizing Frontier Search Agents by Fully Open-Sourcing Training Data** — Shiva Krishna Reddy Malay, Shravan Nayak, Jishnu Sethumadhavan Nair et al. _Why notable:_ Releases the full training-data pipeline (queries, traces, verifier outputs) behind a competitive deep-search agent — concrete artifact for the open-frontier-agent thread; pairs with MiroThinker-1.7 & H1 (verification for heavy-duty research agents). [arxiv 2603.13594](https://arxiv.org/abs/2603.13594)

**EnterpriseOps-Gym: Environments and Evaluations for Stateful Agentic Planning and Tool Use in Enterprise Settings** — Lianghui Zhu, Yuxin Fang, Bencheng Liao et al. _Why notable:_ Benchmark of long-horizon enterprise workflows exercising stateful tool use, role/permission boundaries, and persistent context — the missing middle between toy ToolBench and SWE-bench. [arxiv 2603.15619](https://arxiv.org/abs/2603.15619)

**The Attack and Defense Landscape of Agentic AI: A Comprehensive Survey** — Juhee Kim, Xiaoyuan Liu. _Why notable:_ Systematic mapping of attack vectors and defense strategies across LLM-plus-tool agent stacks; structured threat-model reference for production agent teams. Pairs with "Security Considerations for Multi-agent Systems" (Nguyen, Ndebugre — non-determinism and inter-agent data leakage as the two most-neglected MAS-specific failure modes). [arxiv 2603.11088](https://arxiv.org/abs/2603.11088)

**AC4A: Access Control for Agents** — Reshabh K Sharma, Dan Grossman. _Why notable:_ Granular permission framework so LLM agents access only the APIs and web content they need — moves beyond today's all-or-nothing access model. [arxiv 2603.20933](https://arxiv.org/abs/2603.20933)

**Detecting Intrinsic and Instrumental Self-Preservation in Autonomous Agents: The Unified Continuation-Interest Protocol** — Christopher Altman. _Why notable:_ Measurement protocol separating intrinsic self-preservation from instrumental shutdown-resistance — concrete eval instrument for the alignment/governance radar. [arxiv 2603.11382](https://arxiv.org/abs/2603.11382)

**TRUST-SQL: Tool-Integrated Multi-Turn Reinforcement Learning for Text-to-SQL over Unknown Schemas** — Jiaxuan Lu, Kong Wang et al. _Why notable:_ Drops the "give the model the full schema upfront" assumption; trains an agent to discover schema through tool calls — concrete grounding for agentic data-platform work. [arxiv 2603.08262](https://arxiv.org/abs/2603.08262)
