## Top papers

**AI Identity: Standards, Gaps, and Research Directions for AI Agents** — Takumi Otsuka, Kentaroh Toyoda. _Why notable:_ Defines AI Identity as the continuous relationship between what an agent is declared to be and what it is observed to do; identifies five structural gaps (semantic intent verification, recursive delegation accountability, etc.) that current tech and regulation cannot resolve. [arxiv 2604.23280](https://arxiv.org/abs/2604.23280)

**MCP Pitfall Lab: Exposing Developer Pitfalls in MCP Tool Server Security under Multi-Vector Attacks** — Run Hao, Zhuoran Tan. _Why notable:_ Protocol-aware security testing framework operationalising developer pitfalls as reproducible scenarios; recommended hardening eliminates findings with minimal code changes — companion practitioner-paper for the same week's Mythos-driven MCP-security conversation. [arxiv 2604.21477](https://arxiv.org/abs/2604.21477)

**Co-Evolving LLM Decision and Skill Bank Agents for Long-Horizon Tasks (COSPLAY)** — Xiyang Wu, Zongxia Li. _Why notable:_ Agent retrieves skills from a learnable skill bank with skills discovered + refined across episodes; >25% average reward improvement on long-horizon game benchmarks vs baseline LLMs. Anchors the week's skill-bank cluster alongside EvoAgent / SkillFlow / SkillLearnBench. [arxiv 2604.20987](https://arxiv.org/abs/2604.20987)

**VLAA-GUI: Knowing When to Stop, Recover, and Search — A Modular Framework for GUI Automation** — Qijun Han, Haoqin Tu. _Why notable:_ Modular CUA design — Completeness Verifier (no premature success claims), Loop Breaker (escape repetitive cycles), Search Agent (handle unfamiliar workflows); state-of-the-art on multiple GUI benchmarks with several models surpassing human performance on OSWorld. [arxiv 2604.21375](https://arxiv.org/abs/2604.21375)

**Reward Hacking in the Era of Large Models: Mechanisms, Emergent Misalignment, Challenges** — anonymous (cs.LG). _Why notable:_ Survey-plus-analysis of reward hacking in the LLM-RL era and its link to emergent misalignment; pairs with the same-week Terminal Wrench dataset of 331 reward-hackable environments + 3,632 exploit trajectories. [arxiv 2604.13602](https://arxiv.org/abs/2604.13602)

**Trust but Verify — DAVinCI: A Framework for Dual Attribution and Verification** — Vipula Rawte, Ryan Rossi. _Why notable:_ Two-stage approach to LLM factuality — attribute claims to model components and external sources, then verify via entailment; 5–20% improvements on fact-checking datasets and a modular implementation that pushes accountability into the inference loop. [arxiv 2604.21193](https://arxiv.org/abs/2604.21193)

**Evaluating Multi-Hop Reasoning in RAG Systems (CARE)** — Lorenz Brehme, Thomas Ströhle. _Why notable:_ Context-Aware Retriever Evaluation strategy consistently beats prior LLM-as-judge retriever evals across HotPotQA / MuSiQue / SQuAD with OpenAI/Meta/Google models; accepted at SynIRgy/ECIR 2026. [arxiv 2604.18234](https://arxiv.org/abs/2604.18234)

**Qwen3.5-Omni Technical Report** — Qwen team. _Why notable:_ Next-iteration unified omni-modal (audio/image/text/video) extension of Qwen3 — concrete frontier-multimodal contribution from the open-weights side and a companion to the Qwen 3.6-27B dense coding model the same week. [arxiv 2604.15804](https://arxiv.org/abs/2604.15804)

**On the Reliability of Computer Use Agents** — anonymous (cs.AI). _Why notable:_ Moves CUA evaluation from peak capability to failure-mode characterisation; pairs with VLAA-GUI as the diagnostic side of the week's GUI-agent / computer-use cluster. [arxiv 2604.17849](https://arxiv.org/abs/2604.17849)

**TEMPO: Scaling Test-time Training for Large Reasoning Models** — anonymous (cs.LG). _Why notable:_ Test-time training (not just test-time search) scaled for reasoning models — concrete instantiation of the "post-training never ends" inference paradigm. [arxiv 2604.19295](https://arxiv.org/abs/2604.19295)

**Symbolic Guardrails for Domain-Specific Agents: Stronger Safety and Security Guarantees** — anonymous (cs.AI). _Why notable:_ Symbolic (rather than learned) guardrails for domain agents to obtain provable safety/security properties — complements DAVinCI on the verification side. [arxiv 2604.15579](https://arxiv.org/abs/2604.15579)
