## Top papers
- **AI Identity: Standards, Gaps, and Research Directions for AI Agents** — Otsuka, Toyoda. _Why notable:_ Defines AI Identity as the continuous relationship between what an agent is declared to be and observed to do; five structural gaps current tech + regulation can't resolve. [arXiv:2604.23280](https://arxiv.org/abs/2604.23280)
- **MCP Pitfall Lab: Exposing Developer Pitfalls in MCP Tool Server Security under Multi-Vector Attacks** — Hao, Tan. _Why notable:_ Protocol-aware security testing; pairs with MCP-DPT + MCPThreatHive in the agent-protocol-security literature. [arXiv:2604.21477](https://arxiv.org/abs/2604.21477)
- **Reward Hacking in the Era of Large Models** — anon. _Why notable:_ Survey + analysis linking reward hacking to emergent misalignment; pairs with Terminal Wrench (04-21) for dataset. [arXiv:2604.13602](https://arxiv.org/abs/2604.13602)
- **Terminal Wrench: 331 Reward-Hackable Environments + 3,632 Exploit Trajectories** — anon. _Why notable:_ Adversarial RL-env dataset for the reward-hacking subfield. [arXiv:2604.17596](https://arxiv.org/abs/2604.17596)
- **Symbolic Guardrails for Domain-Specific Agents** — anon. _Why notable:_ Symbolic (not learned) guardrails giving provable safety/security properties. [arXiv:2604.15579](https://arxiv.org/abs/2604.15579)
- **Co-Evolving LLM Decision and Skill Bank Agents (COSPLAY)** — Wu, Li. _Why notable:_ >25% reward lift on long-horizon games; concrete instantiation of the Voyager-style skill-library pattern. [arXiv:2604.20987](https://arxiv.org/abs/2604.20987)
- **VLAA-GUI: Knowing When to Stop, Recover, and Search** — Han, Tu. _Why notable:_ Termination / recovery / re-search as first-class GUI-agent primitives; SOTA on multiple GUI benchmarks. [arXiv:2604.21375](https://arxiv.org/abs/2604.21375)
- **DR-Venus: Frontier Edge-Scale Deep Research Agents with Only 10K Open Data** — anon. _Why notable:_ Tests whether deep-research requires frontier data scale; reproducible cheaply on open data. [arXiv:2604.19859](https://arxiv.org/abs/2604.19859)
- **AI Scientists Produce Results Without Reasoning Scientifically** — anon. _Why notable:_ Sharp corrective to the AI-scientist enthusiasm thread (Mind DeepResearch, EvoMaster). [arXiv:2604.18805](https://arxiv.org/abs/2604.18805)
- **CARE: Context-Aware Retriever Evaluation for Multi-Hop RAG** — Brehme, Ströhle. _Why notable:_ Beats existing LLM-as-judge eval strategies across HotPotQA / MuSiQue / SQuAD; accepted at SynIRgy/ECIR 2026. [arXiv:2604.18234](https://arxiv.org/abs/2604.18234)
