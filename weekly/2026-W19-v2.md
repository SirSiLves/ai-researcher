## Top papers

**Storage Is Not Memory: A Retrieval-Centered Architecture for Agent Recall** — Adler & Zehavi. Six-layer SQLite-based agent memory preserving verbatim events and resolving at query time; 93% on LoCoMo vs Mem0's 61.4%. [arxiv 2605.04897](https://arxiv.org/abs/2605.04897)

**Coordination as an Architectural Layer for LLM-Based Multi-Agent Systems** — Nechepurenko, Shuvalov. Production multi-agent failure rates are 41–87% from coordination defects, not model defects; coordination as a configurable layer separable from agent logic. [arxiv 2605.03310](https://arxiv.org/abs/2605.03310)

**RAG over Thinking Traces Can Improve Reasoning Tasks** — Arabzadeh, Ma, Min, Zaharia. Retrieving solution traces (not documents) lifts AIME by +56% on Gemini-2.5-Flash and GPQA-Diamond by +7.6% on GPT-5. [arxiv 2605.03344](https://arxiv.org/abs/2605.03344)

**Securing the Model Context Protocol (MCP): Risks, Controls, and Governance** — Threat model + control set for MCP server ecosystems (tool-name spoofing, prompt injection at the tool boundary, schema leakage); most concrete MCP-security paper to date. [arxiv 2511.20920](https://arxiv.org/abs/2511.20920)

**Beyond Semantic Similarity: Rethinking Retrieval for Agentic Search via Direct Corpus Interaction** — Lets agents interact with corpora directly instead of one-shot embedding lookup; breaks the semantic-similarity ceiling that has plagued production RAG. [arxiv 2605.05242](https://arxiv.org/abs/2605.05242)

**FinRAG-12B: A Production-Validated Recipe for Grounded Question Answering in Banking** — Katerenchuk, Duboue, et al. Calibrated refusal + citation-grounded RAG deployed at 40+ banks; +7.1pp query resolution at 3–5× speed and 20–50× cost efficiency of GPT-4. [arxiv 2605.05482](https://arxiv.org/abs/2605.05482)

**STALE: Can LLM Agents Know When Their Memories Are No Longer Valid?** — Benchmark for memory revision in long-running agents; current systems fail to invalidate beliefs when new evidence arrives — critical gap for production agent platforms. [arxiv 2605.06527](https://arxiv.org/abs/2605.06527)

**Frontier Lag: A Bibliometric Audit of Capability Misrepresentation in Academic AI Evaluation** — Median academic eval paper trails the deployed frontier by ~10.85 ECI (≈1.4× the Sonnet 3.7 → Opus 4.5 gap). [arxiv 2605.04135](https://arxiv.org/abs/2605.04135)

**Cited but Not Verified: Parsing and Evaluating Source Attribution in LLM Deep Research Agents** — First systematic eval showing deep-research-agent citations (OpenAI/Perplexity-style) often fail to verify against underlying sources; ships a parser+verifier pipeline. [arxiv 2605.06635](https://arxiv.org/abs/2605.06635)

**Auto Research with Specialist Agents Develops Effective and Non-Trivial Training Recipes** — Ning, Li, et al. Closed-loop multi-agent system writes/tests/optimizes training recipes; 0.81–38.7% gains across three headline tasks — the citable companion to Hugging Face's ml-intern. [arxiv 2605.05724](https://arxiv.org/abs/2605.05724)
