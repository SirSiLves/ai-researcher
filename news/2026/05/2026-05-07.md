**Google Gemini Workspace Intelligence & Embedding 2** — Google rolled out Workspace Intelligence for Gemini, integrating real-time context from Gmail, Chat, Calendar, and Drive with admin data-source controls. Gemini Embedding 2 now generally available via API and Vertex AI for stable multimodal (text, image, video, audio) search. Google AI Pro/Ultra got increased usage limits and launched an AI Agents Vibe Coding Course (June 2026). _Why it matters:_ Enterprise integration reaches native Google Workspace; multimodal embeddings move from research to production. [https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)

**Meta LlamaCon & Llama API Launch** — Meta held its inaugural LlamaCon developer event and launched Llama API, a limited free preview platform with one-click API key creation and model playgrounds for Llama 4 Scout and Maverick. Partnerships with Cerebras and Groq offer faster inference. Llama Protection Tools and a $1.5M second-year Impact Grants program announced. _Why it matters:_ Unified API moves Llama from open weights to managed platform; experimental inference partnerships signal performance roadmap. [https://ai.meta.com/blog/llamacon-llama-news/](https://ai.meta.com/blog/llamacon-llama-news/)

**Mistral Voxtral TTS & Medium 3.5** — Mistral released Voxtral TTS (open weights on Hugging Face + API at $0.016/1k chars) with 20 preset multilingual voices. Mistral Medium 3.5 (128B) launched as default in Vibe and Le Chat with remote agents support, async cloud-based coding, and agentic Work mode. _Why it matters:_ TTS closes the voice I/O gap for agentic workflows; 128B dense model competitive with frontier labs at lower cost.
