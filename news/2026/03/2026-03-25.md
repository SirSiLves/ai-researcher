## Major announcements & releases

**MCP crosses 97 M monthly SDK installs — Anthropic publishes the milestone figure** — Anthropic disclosed that the official Model Context Protocol SDKs (`@modelcontextprotocol/sdk` on npm and `mcp` on PyPI) crossed 97 M monthly installs in March 2026 — the headline metric that anchors the protocol's transition from experimental standard to foundational agentic infrastructure. The MCP team's 9 March roadmap shift to priority-area planning (rather than release-milestone planning) framed the moment. _Why it matters:_ The install-count signal underwrites every enterprise MCP-server pitch landing in April and May (AWS MCP Server GA on 6 May, Slack MCP server on 31 March, Jama Connect on 4 May, ServiceNow Action Fabric on 2 April). MCP is now decisively the dominant agent-tool protocol — Google's A2A and OpenAI's Responses-API tool layer compete inside its gravity well. [MCP blog — 2026 MCP roadmap](https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/) · [Digital Applied — MCP hits 97 M downloads](https://www.digitalapplied.com/blog/mcp-97-million-downloads-model-context-protocol-mainstream) · [MCP Roadmap on modelcontextprotocol.io](https://modelcontextprotocol.io/development/roadmap)

**Anthropic ships Claude Code Channels — Telegram and Discord adapters for the Claude Code agent** — Anthropic introduced Claude Code Channels, letting users interact with the Claude Code agent through messaging platforms Telegram and Discord. The launch slots the coding agent into the same ambient-surface pattern as the Slack/Cursor agent integrations. _Why it matters:_ Continues the shift from "agent runs in an IDE" to "agent reachable across all team surfaces" — and competes head-on with GitHub Copilot's chat-platform reach via Microsoft Teams. The Channels framing is the lightweight precursor to the Claude Managed Agents push that lands later in spring. [TLDR Dev — Anthropic harness design, Channels coverage](https://tldr.tech/dev/2026-03-27)

**OpenAI design playbook for GPT-5.4-driven UI/frontend generation** — OpenAI published a structured playbook on using GPT-5.4 to generate more effective UX and frontend designs — guidance on structured prompts, defined design systems, evaluation criteria. The post arrives alongside the parallel harness-engineering content from Anthropic and gives front-end-leaning engineers a paved path for design-agent integrations. _Why it matters:_ Cursor 3's "Design Mode" (launching 2 April) and Lovable's design-agent surface both lean on the same playbook framing; OpenAI is shaping the practitioner conversation ahead of the wave of design-agent launches in April. [OpenAI — design playbook surfaced in roundup](https://www.crescendo.ai/news/latest-ai-news-and-updates)

**OpenAI's "Spud" model finishes pretraining (March 25 background)** — Background reporting circulated on Wednesday that OpenAI's next model, codenamed "Spud," reportedly finished pretraining on March 25. The work feeds into the GPT-5.5 release that lands on 23 April. Reporting also noted OpenAI indefinitely shelved its "adult mode" ChatGPT project alongside the Sora retirement decision. _Why it matters:_ The pretraining-complete signal is the empirical anchor for the GPT-5.5 release timeline that drives OpenAI's enterprise-platform answer to Anthropic's Mythos. Combined with the Sora retirement and "adult mode" shelving, paints an unusually focused product portfolio: enterprise-and-coding workloads, not consumer-multimodal expansion. [The Neuron — March 28-29 weekend digest](https://www.theneuron.ai/ai-news-digests/-around-the-horn-digest-everything-that-happened-in-ai-this-weekend-march-28-29-2026/)

**Accenture launches Cyber.AI at RSA Conference, powered by Anthropic's Claude** — Accenture unveiled Cyber.AI, a new agentic-AI cybersecurity platform combining its proprietary security-agent library with Claude as the reasoning engine, plus Anthropic Agent Shield enterprise-governance controls. Already deployed inside Accenture: secures 1,600 apps and 500K+ APIs; scan turnaround dropped from 3-5 days to under 1 hour; coverage expanded from ~10% to 80%+. _Why it matters:_ The first material consultancy-grade Claude-fronted SOC platform — sets the template for Accenture's broader Anthropic JV announced later in spring and validates the lab+services GTM that Anthropic, OpenAI, and Palantir are all converging on. [Accenture Newsroom — Accenture and Anthropic team to secure cybersecurity ops](https://newsroom.accenture.com/news/2026/accenture-and-anthropic-team-to-help-organizations-secure-scale-ai-driven-cybersecurity-operations) · [Anthropic — Accenture and Anthropic multi-year partnership](https://www.anthropic.com/news/anthropic-accenture-partnership)

**McKinsey publishes 2026 AI Trust Maturity Survey: average score 2.3/4, agentic-governance gap widening** — McKinsey's State of AI Trust 2026 report (drawing on ~500 enterprise responses Dec 2025–Jan 2026) lands on Mar 25. Average Responsible-AI maturity climbs to 2.3 (from 2.0 in 2025) but only ~one-third of orgs hit level-3 in strategy, governance, or agentic-AI controls. TMT and financial services lead; Asia–Pacific tops regional maturity; orgs with named RAI ownership average 2.6. _Why it matters:_ The headline data point every CISO/Chief AI Officer will quote in board decks through Q2 — concretely names the agentic-AI governance gap that EU AI Act Annex III (Aug 2026) and California SB-53 obligations are about to land into. [McKinsey — State of AI trust in 2026: shifting to the agentic era](https://www.mckinsey.com/capabilities/tech-and-ai/our-insights/tech-forward/state-of-ai-trust-in-2026-shifting-to-the-agentic-era)

**Anthropic adjusts Claude Code session limits during peak hours; "What We Shipped" monthly livestream announced** — Anthropic confirmed adjustments to Claude Code session limits during peak hours and announced a new monthly "What We Shipped" livestream starting 7 April. The session-limit move ties to the Claude Code v2.1.116 stability work and the broader regression conversation kicked off by the 26 March caching bug. _Why it matters:_ Throttling at peak hours is a tacit acknowledgement that Claude Code demand is outrunning capacity even with the SpaceX compute deal in the works. The "What We Shipped" cadence borrows from Vercel/Cloudflare/Linear playbooks — a sign the lab is moving toward routinised product comms after the Mythos and source-leak incidents. [The Neuron — March 28-29 weekend digest](https://www.theneuron.ai/ai-news-digests/-around-the-horn-digest-everything-that-happened-in-ai-this-weekend-march-28-29-2026/)
