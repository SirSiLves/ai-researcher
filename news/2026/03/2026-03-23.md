## Major announcements & releases

**Anthropic publishes "Harness design for long-running application development" — three-agent planner / generator / evaluator architecture** — Anthropic's engineering team posted the formal harness-design write-up by Labs engineer Prithvi Rajasekaran. The post extends the November 2025 "Effective harnesses for long-running agents" piece with a three-agent harness — planner, generator, evaluator — pushing Claude further in frontend design and long-running autonomous software engineering. Core moves: separate planning from generation; calibrate a dedicated evaluator agent with few-shot examples and scoring criteria to fight the self-overrating problem; use a different prompt for the very first context window (the "initializer" pass that builds the feature-list.json and init.sh). _Why it matters:_ This is the reference architecture every coding-agent vendor is now reading against — and a meaningful signal of how Anthropic is thinking about the next generation of Claude Code (the harness that will eventually leak on 31 March via a missing `.npmignore`). It's also the most detailed first-party documentation on the harness/host vs. model decomposition that underlies Claude Managed Agents. [Anthropic — harness design for long-running application development](https://www.anthropic.com/engineering/harness-design-long-running-apps) · [Anthropic on X — multi-agent harness](https://x.com/AnthropicAI/status/2036481033621623056) · [InfoQ — Anthropic three-agent harness for full-stack AI development](https://www.infoq.com/news/2026/04/anthropic-three-agent-harness-ai/)

**Anthropic harness post triggers immediate community uptake — practitioner blogs, GitHub samples, reference forks** — Within hours, the post drew detailed practitioner walk-throughs and reference implementations: Rick Hightower's "two agents, one feature list, zero context overflow" Medium piece walks the architecture; a GitHub repo and ZenML LLMOps DB entry document the multi-context window pattern. AddyOsmani.com and a Hacker News thread amplified the architectural framing. _Why it matters:_ Sets the agent-platform conversation for the rest of the quarter — planner/generator/evaluator becomes shorthand in vendor pitches (Anysphere, Cognition, Magic, Replit). Cursor 3's "Agents Window" launch on 2 April is the most visible product expression of the pattern. [Rick Hightower — harness engineering: two agents, one feature list, zero context overflow](https://medium.com/@richardhightower/anthropics-harness-engineering-two-agents-one-feature-list-zero-context-overflow-7c26eb02c807) · [GitHub — anthropics/cwc-long-running-agents](https://github.com/anthropics/cwc-long-running-agents) · [ZenML LLMOps DB — Anthropic long-running agent harness](https://www.zenml.io/llmops-database/long-running-agent-harness-for-multi-context-software-development) · [Just Understanding Data — generator-evaluator harness design](https://understandingdata.com/posts/generator-evaluator-harness-design/)

**Mistral Voxtral TTS open-weights signal — open speech generation challenger** — Mistral's pre-announcement positioning of Voxtral TTS — its open-weights text-to-speech model targeting nine languages and edge-deployable inference — circulated heavily on Monday in advance of the formal release later in the week (23-26 March window).
