**Anthropic Haiku 3 retirement — last day for the $0.25 / $1.25 budget model** — Sunday 19 April was the last day for Claude Haiku 3, Anthropic's lowest-priced model ever ($0.25 / $1.25 per 1M tokens). The retirement was scheduled around the Opus 4.7 GA + Haiku 4.5 roll-forward; Haiku 4.5 ($1 / $5) becomes the cheapest model in the lineup, and developers had been receiving migration notices through API deprecation banners. _Why it matters:_ Haiku 3 was the workhorse for high-volume, low-margin RAG/agent workflows where unit economics mattered most. Its retirement is the clearest signal that Anthropic's API roadmap is concentrating on Sonnet/Opus tier capability rather than continuing the ultra-low-cost segment — a deliberate ceding of that segment to Mistral Small, Llama, and DeepSeek-side options. [Anthropic API pricing 2026 — Haiku 3 retirement note](https://www.finout.io/blog/anthropic-api-pricing) · [Claude API pricing 2026: latest Anthropic costs](https://evolink.ai/blog/claude-api-pricing-guide-2026)

**Claude Design / Figma weekend follow-on: practitioner deep-dives multiply, Pro/Max bundling cited as the real moat** — Sunday's design-community deep-dives on Claude Design moved past the launch-week novelty: MindStudio's Claude Design vs Figma piece, Get AI Perks' "AI tool that wants to replace Figma" review, and BuildFast With AI's non-designers guide all converged on the Pro/Max bundling as Claude Design's structural moat. The instant 50M+ user surface vs Figma's ~13M paid seats is now the consensus framing. _Why it matters:_ The bundling argument matters more than the feature comparison for the next two quarters' design-tooling procurement decisions — Claude Design becomes the default option for any team already on Claude Pro/Max, while Figma has to find a counter that doesn't undercut its own pricing. Sets up the design-tooling category re-pricing as one of Q2's defining "AI disintermediation" stories. [MindStudio — Claude Design vs Figma](https://www.mindstudio.ai/blog/claude-design-vs-figma) · [Get AI Perks — Claude Design 2026 review](https://www.getaiperks.com/en/blogs/42-claude-design-review-2026) · [BuildFast With AI — Claude Design complete guide for non-designers](https://www.buildfastwithai.com/blogs/claude-design-anthropic-guide-2026)
