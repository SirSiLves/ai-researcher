## Major announcements & releases

**Anthropic ships Claude Opus 4.7 — first model with high-res vision, task budgets, new tokenizer** — Anthropic announced Claude Opus 4.7 on 16 April as its most capable generally available model to date. Key upgrades vs Opus 4.6: 3× higher vision resolution (now up to 2576px / 3.75MP), a new "xhigh" effort tier, **task budgets** (Claude estimates how many tokens to spend across thinking, tool calls, tool results, and output), and a new tokenizer that improves performance across a wide range of tasks. Available day-one in Claude Pro/Max/Team/Enterprise, the API, Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry, Claude Code, Cursor, and GitHub Copilot. Pricing unchanged at $5 / $25 per 1M tokens. _Why it matters:_ Opus 4.7 closes the multimodal gap with GPT-5 and Gemini 3.1 while keeping pricing flat — but the new tokenizer can use up to ~35% more tokens for the same text, so effective unit economics shift even though the rate card doesn't. Task budgets are the agent-control primitive Anthropic had been missing for long-horizon Claude Code / Claude Cowork runs. **OpenAI launches GPT-Rosalind — life-sciences frontier reasoning model for drug discovery & genomics** — OpenAI announced GPT-Rosalind on 16 April: a frontier reasoning model built for biology, drug discovery, and translational medicine. Optimised for chemistry, protein engineering, and genomics; supports evidence synthesis, hypothesis generation, experimental planning, and multi-step research workflows. Available as a research preview in ChatGPT, Codex, and the API through a trusted-access program. Launch partners: Amgen, Moderna, the Allen Institute, Thermo Fisher Scientific (and Novo Nordisk via the 14 April deal). _Why it matters:_ This is OpenAI's first vertical model — taking a direct line at Google's Isomorphic Labs / AlphaFold positioning. The Rosalind Franklin naming and the trusted-access gating mirror the Mythos pattern: capability-restricted release while OpenAI maps misuse vectors with partner labs. The Novo Nordisk deal two days prior is the GTM dress rehearsal. **Cloudflare Agents Week day-4: Agent Memory (private beta), Project Think, Artifacts, Browser Run** — Cloudflare on 16 April shipped four marquee Agents Week launches: **Agent Memory** (managed persistent memory; five-channel parallel retrieval with Reciprocal Rank Fusion; four memory types — facts/events/instructions/tasks; Llama 4 Scout for extraction, Nemotron 3 for synthesis); **Project Think** (next-gen Agents SDK for agent loops); **Artifacts** (Git-compatible versioned storage for agents); and **Browser Run** (the rebrand of Browser Rendering, now with Live View, Human-in-the-Loop, CDP access, session recordings, 4× concurrency). _Why it matters:_ Agent Memory addresses "context rot" — the load-bearing failure mode for long-running agents — with a managed service rather than a vector-DB-shaped library. Exportability of memories is the deliberate counter to vendor-lock-in concerns and the closest analogue Cloudflare has to Snowflake's MCP-connector play. [Cloudflare — agents that remember (Agent Memory)](https://blog.cloudflare.com/introducing-agent-memory/) · [Cloudflare — Project Think (next-gen agents SDK)](https://blog.cloudflare.com/project-think/) · [InfoQ — Agent Memory beta](https://www.infoq.com/news/2026/04/cloudflare-agent-memory-beta/) · [Cloudflare AI Platform reframing](https://blog.cloudflare.com/ai-platform/)

**SAP Business AI Q1 2026 release highlights — 30+ specialised Joule agents, 2,500+ Joule Skills** — SAP News Center published the Q1 2026 SAP Business AI release highlights on 16 April. Headline numbers: 30+ specialised Joule agents shipped, 2,500+ Joule Skills in the catalog, Joule Tender Analysis Agent boosting customer revenue growth via critical-requirements extraction and risk flagging in complex tender documents. _Why it matters:_ This is the count-of-agents-shipped baseline going into SAP Sapphire (May 12–13), where SAP recasts Joule as the front door to the autonomous enterprise. The 30+ agents number is the answer SAP wants enterprises to compare against ServiceNow Otto and Salesforce Agentforce. [SAP Business AI Release Highlights Q1 2026](https://news.sap.com/2026/04/sap-business-ai-release-highlights-q1-2026/)

**ServiceNow + Anthropic deepen partnership — Claude as default model in ServiceNow Build Agent** — Cloud Wars and CIO reported on 16 April on the deepening ServiceNow + Anthropic integration as part of the run-up to Knowledge 2026 (4–7 May): ServiceNow has embedded Anthropic's Claude as the default model powering ServiceNow Build Agent — its enterprise coding solution for professional and citizen developers. The partnership traces back to the 28 January joint announcement. _Why it matters:_ ServiceNow standardising on Claude — not OpenAI or Gemini — for its default Build Agent is a meaningful signal of Anthropic's enterprise pull. The framing positions Build Agent as the developer-facing companion to Now Assist for end-users and pre-stages the Otto rebrand at Knowledge.
