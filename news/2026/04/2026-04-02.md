## Major announcements & releases

**Cursor 3 ships an agent-first interface — Agents Window, Design Mode, parallel cloud agents** — Anysphere released Cursor 3 on 2 April, its biggest interface overhaul since the product launched in 2023. The new Agents Window is a full-screen workspace for running and managing many AI agents in parallel — locally, in worktrees, in the cloud, or over remote SSH — with kick-offs accepted from mobile, Slack, GitHub and Linear. Design Mode (Cmd+Shift+D) lets developers annotate UI elements directly in a built-in browser to hand the agent precise visual targets. Agent Tabs display multiple chats side-by-side; a new `/worktree` command isolates changes per agent. The IDE remains; the Agents Window is a separate surface. Built under the codename "Glass." _Why it matters:_ Cursor 3 is the clearest statement yet that "you orchestrate, the agents code" is now the IDE's default mental model. It puts Cursor in direct head-to-head with Claude Code and Codex CLI on parallel-agent UX — the dimension that decides whose harness wins the next 12 months. [Cursor 3.0 changelog](https://cursor.com/changelog/3-0) · [Gizmodo — delegate to a team of coding agents](https://gizmodo.com/cursors-new-tool-lets-users-delegate-to-a-team-of-coding-agents-2000741761) · [AIToolly — unified workspace](https://aitoolly.com/ai-news/article/2026-04-03-cursor-3-launch-introducing-a-unified-workspace-for-autonomous-ai-agent-software-development) · [DevToolPicks review](https://devtoolpicks.com/blog/cursor-3-agents-window-review-2026)

**Amazon OpenSearch ships agentic AI for log analytics — chatbot, Investigation Agent, agent memory** — AWS announced on 2 April that Amazon OpenSearch Service has added agentic AI to the OpenSearch UI for observability. The release ships three primitives: an agentic chatbot for natural-language queries that generates/iterates PPL queries and analyses visualisations; an Investigation Agent that builds a plan, runs queries, evaluates results and returns ranked hypotheses with full transparency for root-cause analysis; and persistent agent memory across sessions and features. Powered by Claude Sonnet 4.6 via Amazon Bedrock. Available in nine regions (US East N. Va./Ohio, US West Oregon, EU Frankfurt/Stockholm/Spain/Ireland, AP Tokyo/Sydney) at no additional cost with token-based limits. _Why it matters:_ This is the first big-three hyperscaler to ship a default-on agentic UI for observability — the workflow Splunk/Datadog/New Relic have been racing to ship. Plan-execute-reflect is now first-party in OpenSearch with Bedrock pricing economics behind it. **Mistral launches Le Chat Enterprise — Microsoft SharePoint / Google Drive / Gmail integrations, on-prem deployment, agent builder** — Mistral introduced Le Chat Enterprise, an enterprise-tier AI assistant powered by Mistral Medium 3 with deep connectors into SharePoint, Google Drive and Gmail. Flexible deployment includes private cloud or on-premises hosting for GDPR / data-sovereignty compliance. The platform ships a built-in agent builder for invoice processing, meeting summarisation and expense reporting. _Why it matters:_ This is Mistral's clearest enterprise-distribution play — pitched explicitly as the European-sovereign alternative to OpenAI/Anthropic for regulated sectors, and the first product to cleanly sit alongside the Mistral 3 roadmap announced for mid-May. [Mistral — introducing Le Chat Enterprise](https://mistral.ai/news/le-chat-enterprise) · [Reworked — Mistral launches Le Chat Enterprise, privacy-first AI alternative](https://www.reworked.co/digital-workplace/mistral-ai-launches-a-european-focused-ai-alternative-for-the-enterprise/) · [Corti — Mistral Le Chat Enterprise](https://corti.com/mistrals-le-chat-enterprise/)

**ServiceNow opens AI Platform Australia release — AI Control Tower covers AWS, GCP, Azure, SAP, Oracle, Workday on 30 integrations** — ServiceNow began rolling out its AI Platform Australia release on 2 April, with new AI Control Tower capabilities to discover, observe, govern, secure and measure AI deployed across any enterprise system. AI Control Tower now ships 30 net-new enterprise integrations covering AWS, Google Cloud, Azure, and enterprise apps including SAP, Oracle and Workday. Companion launch: **Action Fabric**, a new integration layer that external AI agents must traverse to access ServiceNow data and execute workflows. _Why it matters:_ Action Fabric is the gating piece — every third-party agent (OpenAI, Anthropic, Cohere, etc.) now passes through ServiceNow's governance plane before touching enterprise data. AI Control Tower becomes the consolidated audit-and-attestation surface ahead of the EU AI Act's 2 August GP-AI obligations kicking in. [ServiceNow — AI Control Tower expansion](https://newsroom.servicenow.com/press-releases/details/2026/ServiceNow-expands-AI-Control-Tower-to-discover-observe-govern-secure-and-measure-AI-deployed-across-any-system-in-the-enterprise/default.aspx) · [ServiceNow — opens full system of action to every AI agent](https://newsroom.servicenow.com/press-releases/details/2026/ServiceNow-opens-its-full-system-of-action-to-every-AI-Agent-in-the-enterprise/default.aspx)

**Google releases Gemma 4 — open-weight 2B / 4B / 26B-MoE / 31B with 256K context, multimodal, Apache 2.0** — Google DeepMind ships Gemma 4 in four sizes: E2B (2.3B effective), E4B (4.5B effective), 26B Mixture-of-Experts (4B active), and 31B dense. Built from the same research line as Gemini 3, models go to 256K context with native vision, audio, and 140+ languages. Benchmark jumps over Gemma 3 are dramatic: AIME 2026 20.8 → 89.2, LiveCodeBench 29.1 → 80.0, GPQA 42.4 → 84.3. The 31B Dense reaches Arena 3rd; 26B variant 6th — all under Apache 2.0. _Why it matters:_ The strongest open-weight Gemini-class drop yet; on-device E2B/E4B push agentic capability to phones via the Android AICore preview. Resets the open-weight bar that Llama 4 / DeepSeek V4 will be measured against this month.
