## Major announcements & releases

**OpenAI closes $122 B mega-round at $852 B valuation — largest private fundraising in history** — OpenAI announced on 31 March / 1 April that it had closed its February-launched funding round at $122 B committed capital, at an $852 B post-money valuation. SoftBank co-led with Andreessen Horowitz, D.E. Shaw Ventures, MGX, TPG and T. Rowe Price; Amazon, Nvidia and Microsoft participated. ~$3 B came from individual investors via banks. OpenAI also expanded its revolving credit facility to ~$4.7 B with JPMorgan Chase, Citi, Goldman Sachs, Morgan Stanley, Wells Fargo, Mizuho, RBC, SMBC, UBS, HSBC and Santander. _Why it matters:_ Sets the funding ceiling for the rest of the frontier-lab race and turns the IPO timeline ("as soon as late 2026") into the explicit base case. OpenAI says it now does $2 B/month in revenue with 900 M weekly ChatGPT users, with enterprise above 40% of revenue. **Anthropic accidentally publishes the full Claude Code source — 512 K lines, fastest-growing GitHub repo ever** — A missing `.npmignore` line in `@anthropic-ai/claude-code` v2.1.88 shipped a 59.8 MB JavaScript source map containing ~513,000 lines of unobfuscated TypeScript across roughly 1,900 files — effectively the complete client-side agent harness. Researchers discovered hidden subsystems (a Tamagotchi-style "BUDDY" companion, a user-frustration-detection layer) and mirrored the leak. A clean-room rewrite hit 50,000 GitHub stars in two hours. _Why it matters:_ This is the second Anthropic packaging incident in a week (after the Mythos blog draft leak on 26 March) and the most detailed public look ever at how a frontier lab actually builds an agentic coding tool — every prompt, harness pattern, and hidden system message is in the wild. [Bloomberg — Anthropic scrambles to address Claude Code leak](https://www.bloomberg.com/news/articles/2026-04-01/anthropic-scrambles-to-address-leak-of-claude-code-source-code) · [CNBC — Anthropic leaks Claude Code internal source](https://www.cnbc.com/2026/03/31/anthropic-leak-claude-code-internal-source.html) · [Axios — 500,000 lines of own source code](https://www.axios.com/2026/03/31/anthropic-leaked-source-code-ai) · [Fortune — second security lapse](https://fortune.com/2026/03/31/anthropic-source-code-claude-code-data-leak-second-security-lapse-days-after-accidentally-revealing-mythos/)

**Anthropic DMCA-bombs ~8,100 GitHub repos, retracts after backlash** — Following the leak, Anthropic filed a DMCA takedown that GitHub executed against approximately 8,100 repositories — including legitimate forks of Anthropic's own public `claude-code` repo. Anthropic's head of Claude Code, Boris Cherny, publicly apologized and retracted the bulk of the takedowns, narrowing the action to one repo and 96 forks containing the inadvertently exposed sources. _Why it matters:_ The episode crystallises the DMCA-as-blunt-instrument problem for AI source leaks, and is now case study #1 for the Open Source Initiative's pending "agent SDK takedown" policy work. [TechCrunch — thousands of repos yanked, accident](https://techcrunch.com/2026/04/01/anthropic-took-down-thousands-of-github-repos-trying-to-yank-its-leaked-source-code-a-move-the-company-says-was-an-accident/) · [Bloomberg — accidental release of Claude AI agent code](https://www.bloomberg.com/news/articles/2026-04-01/anthropic-accidentally-releases-source-code-for-claude-ai-agent)

**Salesforce reframes Slack as the "agentic OS" with 30+ AI features (Fortune Tech follow-up)** — Fortune Tech published its 1 April deep-dive on Salesforce's Slack overhaul announced 31 March: Slackbot now transcribes meetings across any video platform, monitors desktop activity, executes tasks through MCP-connected third-party tools, and ships a lightweight CRM. The features are on Anthropic's Claude (Business+/Enterprise+ live now; rolling out to Pro/free in April) with Slack auto-provisioned for every new Salesforce customer this summer. _Why it matters:_ Salesforce stock is down ~30% YTD on AI-disintermediation fears ("Saaspocalypse"); the Slack refresh is Benioff's signature counter-pitch — turning the most-used enterprise chat surface into the agent control plane, with MCP as the lever to keep Workday/Notion/ServiceNow inside Salesforce's orbit. [Fortune Tech — Salesforce reinvents Slack, takes aim at Microsoft Copilot](https://fortune.com/2026/04/01/salesforce-reinvents-slack-ai-age-takes-aim-at-microsoft-copilot/) · [TechCrunch — 30 new features](https://techcrunch.com/2026/03/31/salesforce-announces-an-ai-heavy-makeover-for-slack-with-30-new-features/) · [eWeek — Slack AI update](https://www.eweek.com/news/slack-ai-update-salesforce-slackbot-2026/) · [SiliconANGLE — ultimate work assistant](https://siliconangle.com/2026/03/31/salesforce-transforms-slackbot-ultimate-work-assistant-30-new-ai-features/)

**Claude autonomously writes a full FreeBSD remote kernel RCE in four hours (CVE-2026-4747)** — A technical write-up published 1 April from researcher Nicholas Carlini documents how Claude — given only the FreeBSD kgssapi.ko code and a single prompt — autonomously developed two working remote root exploits for CVE-2026-4747, a stack buffer overflow in FreeBSD's RPCSEC_GSS authentication module. Each exploit succeeded on the first attempt after ~4 hours of compute. The work is part of "MAD Bugs" (Month of AI-Discovered Bugs) running through April; the same pipeline has since produced 500+ validated high-severity vulnerabilities. _Why it matters:_ This is the empirical evidence cited later in the Mythos disclosure. The capability is real — a single agent, no human in the loop, found and weaponised a freshly patched kernel bug while engineering teams were still rolling the update. [Calif blog — MAD Bugs: Claude wrote FreeBSD kernel RCE](https://blog.calif.io/p/mad-bugs-claude-wrote-a-full-freebsd) · [WinBuzzer — full kernel exploit in four hours](https://winbuzzer.com/2026/04/01/claude-ai-freebsd-remote-kernel-exploit-root-shell-xcxwbn/) · [OpenClawAI — autonomous FreeBSD exploit](https://openclawai.io/blog/claude-autonomous-freebsd-kernel-exploit-cve-2026-4747)

**Anthropic crosses $30 B annualized revenue run-rate, leapfrogging OpenAI's $25 B (early reporting)** — Reporting in the early-April window confirmed Anthropic's run-rate had reached ~$30 B, up from $14 B in February and $19 B in March, with enterprise customers spending $1 M+ annually doubling from ~500 to over 1,000 in under two months. OpenAI disputes the figure (arguing gross-revenue accounting overstates by ~$8 B) but the dispute remains unresolved. _Why it matters:_ For the first time, a frontier lab competitor has visibly overtaken OpenAI on the headline ARR number — the metric that underwrites the entire $852 B OpenAI valuation framing. The growth-curve gap (Anthropic doubling enterprise $1 M+ accounts in two months) is the more durable signal. [SaaStr — Anthropic just passed OpenAI in revenue](https://www.saastr.com/anthropic-just-passed-openai-in-revenue-while-spending-4x-less-to-train-their-models/) · [Trending Topics — $30 B run rate](https://www.trendingtopics.eu/anthropic-overtakes-openai-in-revenue-hitting-30-billion-run-rate/) · [Epoch AI — revenue tracker](https://epoch.ai/data-insights/anthropic-openai-revenue)

**MCP Dev Summit North America opens in New York (Apr 2-3 prep)** — The Model Context Protocol's first major North American summit kicks off this week with 1,200 attendees and 95+ sessions led by MCP co-founders, maintainers, and production deployers. Programming covers the AAIF (Agentic AI Foundation) governance handover, OAuth/identity, MCP-server registries, and reference implementations from Anthropic, AWS, GitHub, and Cloudflare. _Why it matters:_ MCP graduated from "Anthropic protocol" to neutral Linux Foundation standard in December 2025; this is the first developer summit under the new governance — sets the de-facto reference patterns enterprises will copy through 2026. [Search aggregator — MCP Dev Summit Apr 2-3 NYC](https://dev.to/pockit_tools/mcp-vs-a2a-the-complete-guide-to-ai-agent-protocols-in-2026-30li)

**SAP quietly publishes API Policy v4/2026 banning external AI agents** — Section 2.2.2 of the new SAP API Policy — published in the April 2026 window — explicitly prohibits AI systems that "independently schedule or execute calls" against SAP APIs without human-in-the-loop, effectively forcing external agents to route through SAP's own Joule assistant. The change lands as Salesforce and ServiceNow are publicly opening their MCP surfaces. _Why it matters:_ The first major enterprise vendor to formally close its API surface to autonomous agents — a direct counterweight to the MCP-everywhere trend, and the cleanest live test of the "agent-walled-garden vs. open MCP" platform fight. [Techzine — SAP blocks external AI agents while Salesforce and ServiceNow don't](https://www.techzine.eu/blogs/applications/141323/sap-blocks-external-ai-agents-salesforce-and-servicenow-dont/)
