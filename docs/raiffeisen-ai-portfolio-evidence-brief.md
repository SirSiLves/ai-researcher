## B. Evidence for shared org memory — *what the market is paying to solve*

The handoff / status-chasing / cross-actor memory pain is no longer a hypothesis in the market: it has been **codified into protocols, productised, and certified for regulated buyers.** That makes shared org memory a grounded bet, not a speculative one.

- **A2A handoff is now a procurement-grade wire protocol.** `a2a-protocol` is a topic in **633/1496** dossiers; the `a2a` dossier logs **235 mentions across 19 distinct days**; A2A appears in **10/15** weeklies with clear acceleration (W19=8 → W20=21 mentions/file). "A2A v1.0 stable; 150+ orgs in production; signed agent cards; Linux Foundation governance; native in ADK/LangGraph/CrewAI/LlamaIndex/Semantic Kernel/AutoGen" (`weekly/2026/2026-W20.md`, `trends.md`). **The market built a standard specifically for "who does the handoff" — an architecture decision upstream of model selection.**
- **Agent memory became a standalone 2026 procurement category** with its own benchmarks and shipped managed primitives — `agent-memory` in **659/1496**, recurring in **7/15** weeklies. "Memory moved from developer-experience toggle to runtime substrate with its own benchmarks (STALE, LoCoMo, MEME)… production agent memory is now a 2026 procurement category" (`trends.md`). This directly validates the shared-memory hypothesis: the market pays for governed memory so work/status/decisions persist across sessions and agents rather than being re-chased manually.
- **The clearest market statement of the thesis (this week, W25):** Snowflake Cortex Sense and Microsoft Work IQ **both independently bet the semantic context layer — not tool sprawl — is the real bottleneck**, collapsing M365 to ~10 generic MCP tools behind progressive disclosure (`weekly/2026/2026-W25.md`). Two Tier-1 vendors asserting the exact hypothesis behind a shared-memory/status initiative.
- **Pinecone publicly "buried the RAG era"** with Nexus, a context compiler producing persistent, citable knowledge artifacts — **financial-services early adopters reported up to 90% token reduction and 30× faster completion** (`weekly/2026/2026-W21.md`). "Better models won't fix agent reliability — better knowledge representation will." Frankfurt region available → directly transferable.
- **Multi-agent orchestration shipped GA across vendors:** Salesforce Agentforce Multi-Agent Orchestration GA ("agents as a unified team with shared context"), IBM watsonx Orchestrate as the governance plane for "fleets of agents from any source", Microsoft Azure Agent Mesh (`weekly/2026/2026-W25.md`, `-W20.md`). The "one agent hands work to another and someone chases status" pattern is now a **named GA product category**.
- **It is already a buyable, compliance-certified category:** Credal.ai sells an agent registry with "A2A with shared memory partitions" plus SOC2/HIPAA/GDPR + PII redaction (named customers MongoDB, Wise, Comcast, HHS); OpenAI Agents SDK ships **"handoffs" as a first-class primitive** (`linkedin/2026/05/2026-05-28.md`).

**Therefore:** shared org memory is a real, money-backed bet. For Raiffeisen the differentiators that matter are the bank-specific ones — Swiss data residency, FINMA/EU-AI-Act audit, partition-level PII governance, memory invalidation/revision (the research thread itself flags poisoning, drift and STALE-belief failure). Build those; don't re-invent the registry/memory/handoff plumbing the market has commoditised.

## C. Constraints & non-negotiables

- **EU AI Act Aug 2, 2026 cliff is the live forcing function** — Article 50 transparency + GPAI duties bind that date even after the Digital Omnibus deferral; fines **up to €35M / 7% of turnover**. Recurs in **7/15** weeklies; `eu-ai-act.json` carries **309 mentions across 22 distinct days** (`weekly/2026/2026-W24.md`, `eu-ai-act.json`). A transparency/labelling + GPAI-disclosure programme must be production-ready by **2026-08-02** regardless of any high-risk deferral.
- **High-risk obligations deferred — defined multi-year runway.** Annex III high-risk → **2 Dec 2027** (16-month delay), Annex I → **2 Aug 2028**, watermark grace → 2 Dec 2026, sandbox obligation Aug 2026 → Aug 2027 (`weekly/2026/2026-W21.md`, `annex-iii.json`: 25 mentions/11 days). Credit-scoring/fraud conformity spend can be **sequenced after** the Aug-2026 transparency tranche — but the deferral is not relief on Article 50/GPAI.
- **FINMA classified Mythos-class frontier capability "immediate systemic risk" (Thu 21 May 2026)** — the highest-jurisdiction formal AI-capability designation in the global stack; Fed/OCC paused US bank cyber exams over the same model. `finma.json`: **25 mentions/10 distinct days**; `mythos-cyber-governance-cascade` in **672/1496** (`weekly/2026/2026-W21.md`, `finma.json`, `trends.md`). The home regulator is principles-based and already has a hard "systemic risk" label on frontier AI cyber capability — design to FINMA's bar, not just EU rules.
- **Frontier-API availability is a sovereign-policy risk.** On **Fri 13 June 2026** a US Commerce export-control directive forced worldwide disablement of two flagship models inside a **~90-minute** window (incl. asking AWS to revoke Bedrock access) — the **first state-compelled takedown of a deployed frontier model** (`weekly/2026/2026-W25.md`, `-W24.md`). Treat single-frontier-vendor dependence as a critical-supplier-outage-equivalent continuity risk; mandate a documented fallback + sovereign/open-weight cold-standby before go-live.
- **Mandatory prompt-logging is a hard data gate.** AWS Bedrock reportedly required sharing prompt data with the model provider to use Mythos-class models — "a non-starter for regulated and government clients" (`daily/2026/06/2026-06-10.md`). A "zero-prompt-retention / no-training-on-our-data" clause is non-negotiable; any logging-mandate SKU is **disqualified** for use-cases touching client banking data under FADP.
- **MCP production security baseline is below banking bar** — **53%** of production MCP servers use long-lived static secrets, only **8.5%** OAuth; `mcp-security` in **607/1496** (`weekly/2026/2026-W21.md`). Set OAuth/OIDC as the non-negotiable MCP-server auth baseline; target the MCP 2026-07-28 stateless+OAuth spec; require a signed-manifest registry before any agent connects to a system of record.
- **Agent-to-agent identity/authz is an unsolved prerequisite.** Market consensus: OAuth/OIDC/SAML **structurally fail for recursive agent delegation** (`weekly/2026/2026-W25.md`, `-W20.md`). If Raiffeisen replaces manual handoffs with agent handoffs, the unsolved problem moves to authz propagation between non-human principals — pair any handoff/memory initiative with signed agent cards / token-exchange / SPIFFE-style identity.
- **OSS/agent supply chain is a primary attack surface.** The LiteLLM base64 credential-stealer (24 Mar 2026) ran on install with no import, **46,996 downloads in 46 min, 88% of dependents un-pinned** — and **LiteLLM is named in peer Swiss-bank (Bank J. Safra Sarasin) AI-CoE production stacks** (`weekly/2026/2026-W13.md`, `-W24.md`). Pin dependencies, internal mirror/cooldown, install-time-execution controls.
- **Enterprise stack is being walled at the gateway.** SAP API Policy v4/2026 (effective **9 June 2026**) bars external agents from autonomously calling SAP APIs except through a metered Joule layer (SAP also absorbed n8n, $5.2B); ServiceNow/Salesforce stay open via MCP (`daily/2026/06/2026-06-13.md`, `n8n.json`: 197 mentions/22 days). Any agent reaching SAP-class systems of record must budget for **per-operation tolls** and design around the gateway.
- **Cost-vs-sovereignty is an explicit, quantified trade-off.** Claude priced at **~9×** the cheapest Chinese alternative ($4,811 vs $544 standard workload); Chinese-model OpenRouter share rose **~1% (2024) → >60% (May 2026)**; GLM-5.2 reached "near-Opus-4.7 quality at stupid prices" (`weekly/2026/2026-W21.md`, `-W25.md`, `openrouter.json`). The cheapest open-weights are Chinese/off-path for a regulated Swiss bank — the in-corpus sovereign-deployable options are **Mistral (SBB-validated)** and **Apertus (ETH/EPFL 70B on Alps/CSCS)**.
- **[uncertain] Cooperative org structure (~200 independent banks / multi-controller consent)** — the user's named internal constraint is **NOT corroborated anywhere in this external corpus**; the Raiffeisen dossier holds only **4 incidental mentions across 2 days** (`raiffeisen.json`). Must be confirmed from internal sources. Architecturally it reinforces the same conclusion: a model-agnostic, per-entity-governed, on-/EU-region platform with strict data-egress controls.

## F. One-paragraph synthesis

The market evidence converges hard on one conclusion: for a regulated Swiss bank, **the binding constraints are governance, model-portability and shared knowledge — not raw model capability.** Agent capability is outrunning deployability (eval gap in 551 dossiers, agents passing ~33% of real tasks), the failures that matter are coordination/handoff and retrieval-quality failures (721 and 691 dossiers respectively), and a single frontier model can be silently degraded or pulled worldwide by a foreign government in ~90 minutes — while FINMA already classifies frontier capability as systemic risk and EU AI Act Article 50/GPAI duties bind Aug 2 2026. So the portfolio should prioritise, in order: (1) a **model-agnostic harness/gateway** with a tested open-weight/Mistral-Apertus sovereign fallback as a BCM control on *every* initiative; (2) a **governed semantic context/knowledge layer** with citations, retriever-enforced access control and stale-fact invalidation — the substrate two Tier-1 vendors and a financial-services context-compiler are independently betting on, and the thing that removes manual status-chasing far better than wiring up more MCP connectors; (3) **agent-identity + authz-propagation** as a hard prerequisite before any agent handoff replaces a human one; and (4) a **compliance-evidence agent** that drafts and refreshes the ISO 42001 / Article 50 / FINMA dossier with mandatory human attestation. Crucially, **build on what peers and vendors already ship** (Safra-Sarasin's LiteLLM+n8n+RAG reference stack, Anthropic Managed Agents' self-hosted sandboxes, SAP-Mistral's SBB-proven multilingual RAG, Big-Four attestation services) and reserve genuinely novel build budget for the cooperative-bank-specific layer the market is silent on — *but treat all of this as a proxy until the internal Slack/Confluence/email/ticket evidence is retrieved, because this corpus contains no Raiffeisen pain data at all.* That path delivers a governed, sovereign AI capability that gets safe initiatives to production fast, frees capacity through assistive back-office automation, and cuts manual handoffs — without betting the bank on a single model, a single vendor gateway, or an unverified market analogy.
