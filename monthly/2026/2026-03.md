## Defining themes

**Agent control plane as Q2 procurement category.** What started as GTC's "Agent Toolkit + 17 partners" substrate (Mar 16) hardened across four lanes inside two weeks: data platform (Snowflake Project SnowWork + Cortex Code GA, Mar 18), workflow SaaS (ServiceNow AI Gateway + Action Fabric, Mar 19 → Apr 2), developer surface (Slack as agentic OS with 30+ Salesforce features and Slack MCP GA, Mar 31; OpenAI Workspace Agents same day; Cursor 3 "Glass" Apr 2), and runtime/governance (Microsoft Agent Framework 1.0 + Agent Governance Toolkit + Copilot Studio A2A, Apr 3). SAP's API Policy v4/2026 §2.2.2 — banning external agents from autonomous API calls — became the cleanest live test of walled-garden vs. MCP-everywhere. _Why it matters:_ Every multi-vendor enterprise now has to pick a governance lane for agents before model selection.

**Harness-as-product.** Anthropic's Mar 23 engineering post formalised the planner / generator / evaluator three-agent decomposition for long-running coding work; within a week the framing was load-bearing for Cursor 3's Agents Window, Microsoft Agent Framework 1.0's Sequential/Group-Chat/Magentic-One patterns, and the Meta-Harness paper that treats the harness itself as a searchable artifact. The Claude Code source-map leak (Mar 31) then exposed the full reference implementation. Counterweight: the "Terminal Agents Suffice" and "Single-Agent vs Multi-Agent under equal token budgets" papers (early Apr) argue MCP-heavy and multi-agent setups under-perform plain terminal agents on enterprise tasks. _Why it matters:_ The product wedge for coding-agent vendors moved from "best model" to "best harness around a model"; Cursor 3 is the first IDE to demote the editor.

**MCP scale meets MCP security.** 97M monthly SDK installs (Anthropic disclosure Mar 25) and >10K public servers (ByteBridge, Mar 18) — but the production-security stack was being written the same month: FinMCP-Bench (613 samples × 33 financial scenarios × 65 MCP servers), AgentRFC (cross-protocol conformance), AIP Agent Identity Protocol (Invocation-Bound Capability Tokens after a scan of ~2,000 MCP servers found *all* lacked authentication), the PromptArmor / Snowflake Cortex sandbox-escape walkthrough (process-substitution defeated the allow-list), and the production-pattern paper "Bridging Protocol and Production." Linux Foundation AAIF then consolidated governance by hosting MCP Dev Summit NYC (Apr 2–3) and accepting Goose from Block alongside MCP and AGENTS.md as anchor projects. _Why it matters:_ MCP is now the dominant agent-tool protocol with a Linux-Foundation-blessed identity/auth profile — the platform-control fight is now over which products gate the registry, not over the protocol itself.

## Research highlights

- **FinMCP-Bench (Zhu et al., arXiv 2603.24943)** — 613 samples × 33 financial scenarios × 65 real MCP servers; first MCP-native benchmark testing multi-turn multi-tool reasoning where money would move.
- **AgentRFC (Zheng & Zhang, 2603.23801)** — First systematic security framework and conformance tester across MCP/A2A/ANP/ACP with cross-protocol gap detection.
- **AIP: Agent Identity Protocol (Prakash, 2603.24775)** — Invocation-Bound Capability Tokens (JWT + chained Biscuit) motivated by a ~2,000-server scan finding zero authenticated MCP endpoints.
- **AC4A: Access Control for Agents (Sharma & Grossman, 2603.20933)** — Granular per-API/per-content permission framework replacing all-or-nothing agent access.
- **Memento-Skills (Zhou, Guo, Liu et al., 2603.18743)** — Cleanest "agents that design subagents" pattern of the month; skill-module construction without LLM parameter updates.
- **Nemotron-Cascade 2 (Yang, Liu, Chen et al., 2603.19220)** — NVIDIA cascade-RL + multi-domain on-policy distillation; 30B MoE reaches competition-level math/code reasoning.
- **MSA: Memory Sparse Attention to 100M tokens (Chen & Chen, 2603.23516)** — End-to-end memory-model scaling at linear complexity; potentially shifts the long-context-vs-RAG cost curve.
- **Aegis cryptographic runtime governance (Mazzocchetti, 2603.16938)** + **Runtime Governance for AI Agents (Kaptein & Khan, 2603.16586)** + **Mind the Gap (Osmond & Jego, 2603.27075)** — month-end governance triad making policy a cryptographically sealed execution condition and surfacing the capability-vs-architecture conflation in current law.
- **SlopCodeBench (Orlanski et al., 2603.24755)** — First benchmark measuring agent-driven code-quality drift over sequential extensions; useful counterweight to single-shot SWE-bench framing.
- **AVO: Agentic Variation Operators (Chen, Ye, Xu, 2603.24517)** — LLM agents as variation operators in evolutionary search; discovered attention kernels outperforming cuDNN and FlashAttention. Concrete proof that agentic search can beat expert-engineered systems code.
