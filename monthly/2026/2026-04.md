## Research highlights

- **Dive into Claude Code: The Design Space of Today's and Future AI Agent Systems** (Liu, Zhao, [arXiv:2604.14228](https://arxiv.org/abs/2604.14228)) — Reverse-engineered architectural anatomy of Claude Code with OpenClaw comparison; closest "how this is actually built" reference for frontier coding agents.
- **Externalization in LLM Agents: A Unified Review** (Zhou, Chai, [arXiv:2604.08224](https://arxiv.org/abs/2604.08224)) — Cleanest taxonomy of the agent stack as memory + skills + protocols + harness — "what's outside the weights."
- **MCP-DPT + MCP Pitfall Lab + MCPThreatHive + Tool Attention** (W15–W18) — Defense-placement taxonomy across MCP's six layers (Rostamzadeh & Narula, [2604.07551](https://arxiv.org/abs/2604.07551)); developer-pitfall multi-vector attack lab (Hao & Tan, [2604.21477](https://arxiv.org/abs/2604.21477)); automated MCP threat-intel platform (Shen & Toyoda, [2604.13849](https://arxiv.org/abs/2604.13849)); first quantification of the "MCP tax" at 10–60k tokens per turn ([2604.21816](https://arxiv.org/abs/2604.21816)).
- **AI Identity: Standards, Gaps, and Research Directions for AI Agents** (Otsuka & Toyoda, [arXiv:2604.23280](https://arxiv.org/abs/2604.23280)) — Defines AI Identity as the continuous relationship between what an agent is declared to be and observed to do; five structural gaps current tech + regulation can't resolve.
- **Position: Safety and Fairness in Agentic AI Depend on Interaction Topology, Not on Model Scale or Alignment** ([arXiv:2605.01147](https://arxiv.org/abs/2605.01147)) — Three failure modes (ordering instability, information cascades, functional collapse) emerge from information-flow structure, not per-model alignment; reframes multi-agent safety.
- **Latent Agents + Safe Bilevel Delegation** ([2604.24881](https://arxiv.org/abs/2604.24881), [2604.27358](https://arxiv.org/abs/2604.27358)) — Latent Agents distills multi-agent debate into a single LLM with 93% fewer tokens; SBD formalises hierarchical delegation as bilevel optimisation with proved Safety Monotonicity / Inner Policy Convergence / Accountability Propagation.
- **Skill-bank cluster: Don't Retrieve Navigate (Corpus2Skill), COSPLAY, SkillFlow, Memento-Skills, ObjectGraph** (W15–W18) — Replaces flat RAG with skill-navigation across enterprise KB ([2604.14572](https://arxiv.org/abs/2604.14572)); >25% reward lift on long-horizon games via co-evolving decision + skill-bank agents ([2604.20987](https://arxiv.org/abs/2604.20987)); typed directed knowledge graph as native file format with up to 95.3% token reduction ([2604.27820](https://arxiv.org/abs/2604.27820)).
- **Memory cluster: Mnemonic Sovereignty survey + LinkedIn Hierarchical LTSM + NuggetIndex + MemRouter + Omni-SimpleMem + KV Packet** (W14–W18) — Persistent-memory threats and "mnemonic sovereignty" governance frame ([2604.16548](https://arxiv.org/abs/2604.16548)); agent memory hardens from research toy to production architecture with audit-grade taxonomies.
- **RAGEN-2 + SafeDream + RefusalGuard + Reward Hacking survey + Terminal Wrench** (W15–W18) — RAGEN-2 identifies "template collapse" in agentic RL ([2604.06268](https://arxiv.org/abs/2604.06268)); SafeDream flags multi-turn jailbreak ~1.2 turns before compliance ([2604.16824](https://arxiv.org/abs/2604.16824)); RefusalGuard preserves refusal subspace in fine-tuning ([2605.01913](https://arxiv.org/abs/2605.01913)); Reward Hacking + Terminal Wrench's 331-environment / 3,632-trajectory adversarial dataset ([2604.13602](https://arxiv.org/abs/2604.13602), [2604.17596](https://arxiv.org/abs/2604.17596)).
- **Cyber Defense Benchmark + CARE + Don't Retrieve Navigate** (W16–W17) — Opus 4.6 catches only 3.8% of malicious events on average across 106 attack procedures × 86 MITRE ATT&CK sub-techniques ([2604.19533](https://arxiv.org/abs/2604.19533)); CARE Context-Aware Retriever Evaluation beats LLM-as-judge across HotPotQA / MuSiQue / SQuAD ([2604.18234](https://arxiv.org/abs/2604.18234)).
