## Major announcements & releases

**Microsoft open-sources Agent Framework at Open Source Summit North America 2026** — At Open Source Summit NA (May 18), Microsoft positioned the Microsoft Agent Framework — its open-source SDK and runtime for building, deploying and managing multi-agent systems — at the center of an "open source to agentic systems" narrative, alongside the Agent Governance Toolkit (OS-level security/trust/compliance for autonomous agents) and the Agentic AI Foundation (AAIF) which Microsoft says is already the fastest-growing project in Linux Foundation history. _Why it matters:_ Microsoft is making an explicit play to own the **open** layer of the multi-agent stack — the same place it lost to AWS in IaaS a decade ago — and is using Linux Foundation governance to do it. [Microsoft Open Source Blog](https://opensource.microsoft.com/blog/2026/05/18/from-open-source-to-agentic-systems-microsoft-at-open-source-summit-north-america-2026/) ([Agent Governance Toolkit](https://opensource.microsoft.com/blog/2026/04/02/introducing-the-agent-governance-toolkit-open-source-runtime-security-for-ai-agents/))

**Anthropic acquires Stainless — gets the SDK + MCP server-generation stack used by OpenAI, Google, Cloudflare and Meta** — On May 18, Anthropic announced the acquisition of Stainless (founded 2022), the company that has powered the generation of every official Anthropic SDK since the earliest days and which also generates SDKs / CLIs / MCP servers for OpenAI, Google, Cloudflare and Meta in TypeScript, Python, Go, Java and Kotlin. The Information had reported the deal value at ~$300M+. Anthropic's stated rationale: "agents are only as useful as what they can connect to" — bringing Stainless in-house gives Anthropic ownership of the SDK/MCP generation pipeline at the same time it is metering third-party Agent SDK usage on subscriptions. _Why it matters:_ this is a structural move on the agent-connectivity layer — Anthropic now controls the codegen pipeline that ships SDKs **for its direct competitors**, and pairs with the May 14 Agent SDK billing split to consolidate the agent-interop surface around Claude. [Anthropic — Anthropic acquires Stainless](https://www.anthropic.com/news/anthropic-acquires-stainless) ([The Information](https://www.theinformation.com/articles/anthropic-talks-buy-developer-tools-startup-used-openai-google), [Investing.com summary](https://www.investing.com/news/stock-market-news/anthropic-acquires-stainless-to-boost-agent-connectivity-tools-93CH-4696558))

Supporting the number: Q1 2026 ARR above $44B (up roughly 80x year-over-year), more than 1,000 customers spending $1M+/yr, and named enterprise contracts with PwC, Blackstone, Goldman Sachs and the Gates Foundation. _Why it matters:_ valuation parity-plus with OpenAI is more than vanity — it shifts the gravity of the talent market, partnership negotiations and any future regulatory carve-outs. **Anthropic splits Claude subscription billing — Agent SDK gets its own credit pool (effective June 15)** — On May 14, Anthropic announced a major restructuring of Claude subscription billing: starting June 15, usage will split into two pools — one for first-party Anthropic tools (chat, official Claude Code CLI) and one for third-party Agent SDK / ACP / `claude -p` consumption — with Agent SDK monthly credit caps of $20 (Pro) / $100 (Max 5x) / $200 (Max 20x). Anthropic simultaneously reinstated OpenClaw and third-party agent harnesses on Claude subscriptions under the new metering. Sub-agent progress summaries now hit the prompt cache, cutting cache_creation token cost ~3x. _Why it matters:_ Anthropic is the first frontier lab to formally meter third-party agent harnesses — a structural shift that will force every downstream vendor (Zed, OpenClaw, Aider, etc.) to either pass the cost through, build their own billing, or move to API-only customers. The 12x–175x effective-price-increase modeling is already circulating in dev communities. [VentureBeat](https://venturebeat.com/technology/anthropic-reinstates-openclaw-and-third-party-agent-usage-on-claude-subscriptions-with-a-catch) ([Detailed policy analysis](https://gist.github.com/MagnaCapax/d9177e35b355853f03c730dfcaa693ef), [GIGAZINE coverage](https://gigazine.net/gsc_news/en/20260514-anthropic-claude-agent-sdk-credits/))

**Cursor releases Composer 2.5 — Kimi K2.5-based agentic coding model, claims Opus 4.7 / GPT-5.5 parity at ~1/5 the cost** — On May 18 Cursor shipped Composer 2.5, an in-house agentic coding model trained on 25x more synthetic tasks than Composer 2 and using a new training stack (targeted RL with textual feedback at trajectory choice points, sharded Muon and dual-mesh HSDP). Third-party benchmark coverage (the-decoder.com) reports Composer 2.5 matches Opus 4.7 and GPT-5.5 on benchmarks at a fraction of the price. _Why it matters:_ Cursor is the most-watched test of whether a frontier-lab application company can train its own model and undercut OpenAI/Anthropic on price for the specific workload it controls (coding). If the parity claim holds in independent evals, this is a real signal that the post-frontier app layer can defend margins. [Cursor — Introducing Composer 2.5](https://www.cursor.com/blog/composer-2-5) ([the-decoder benchmark coverage](https://the-decoder.com/cursors-composer-2-5-matches-opus-4-7-and-gpt-5-5-benchmarks-at-a-fraction-of-the-cost/))
