# AI News — 2026-05-31

_Collector: ai-news. Slice: vendor blogs, tech news, web search._

## Major announcements & releases

**ChatGPT adds personal-finance accounts via Plaid (12,000+ institutions)** — OpenAI rolled out the ability for U.S. ChatGPT Pro users on web and iOS to securely link financial accounts through Plaid, spanning more than 12,000 institutions, with Intuit support coming soon. ChatGPT can now answer questions grounded in a user's spending, bills, subscriptions, net worth, and investments via a personal finance dashboard. _Why it matters:_ Moves ChatGPT from advice-giver to a connected financial agent over real account data — a meaningful consumer-fintech distribution play. [https://openai.com/index/personal-finance-chatgpt/]

**Anthropic raises $65B Series H at $965B post-money** — Anthropic closed a $65B round (co-led by Altimeter, Dragoneer, Greenoaks, Sequoia, with Capital Group, Coatue, D1) valuing it at $965B post-money, likely its last private raise before a public listing. The company reported a ~$47B revenue run-rate, driven heavily by Claude Code, and overtook OpenAI as the most valuable AI startup. _Why it matters:_ Sets a new private-market high-water mark and signals an imminent frontier-lab IPO wave. [https://www.anthropic.com/news/series-h]

**Anthropic ships Claude Opus 4.8** — An upgrade to the Opus class with stronger coding, agentic, and professional-work performance plus consistency for long-running tasks. Claude.ai now exposes an effort control, Claude Code gains "dynamic workflows" for very large-scale problems, and fast mode runs at 2.5x speed and roughly 3x cheaper than prior models. _Why it matters:_ Keeps Anthropic at the coding/agentic frontier and adds user-facing cost/latency levers enterprises have been asking for. [https://www.anthropic.com/news/claude-opus-4-8]

**Project Glasswing update: 10,000+ vulnerabilities found in ~30 days** — Anthropic's defensive-security initiative, using the unreleased Claude Mythos Preview model with ~50 partners, surfaced 10,000+ high/critical-severity flags across 1,000+ open-source projects (1,094 confirmed high/critical true positives), including a 27-year-old OpenBSD remote-crash bug, a 16-year FFmpeg flaw, and CVE-2026-5194 in WolfSSL (CVSS 9.1). Cloudflare found 2,000 bugs; Mozilla fixed 271 Firefox vulns (10x its prior AI-assisted rate). _Why it matters:_ Demonstrates frontier models can now out-discover human remediation capacity — the cybersecurity bottleneck has shifted from finding bugs to fixing them. [https://www.anthropic.com/research/glasswing-initial-update]

**IBM + Red Hat commit $5B to "Project Lightwell" for open-source AI security** — A $5B program backed by 20,000+ engineers and frontier AI to run a trusted enterprise clearinghouse that finds and fixes vulnerabilities across open-source libraries, toolchains, and AI frameworks at scale. Early adopters include Bank of America, BNY, Citi, Goldman Sachs, JPMorganChase, Mastercard, Morgan Stanley, RBC, State Street, Visa, and Wells Fargo; it explicitly builds on learnings from Anthropic's Glasswing and OpenAI's cyber programs. _Why it matters:_ The enterprise platform layer is now spending at frontier-lab scale on AI-driven software-supply-chain security. [https://newsroom.ibm.com/2026-05-28-ibm-and-red-hat-commit-5-billion-to-redefine-the-future-of-open-source-in-the-ai-era]

**Mistral launches physics-AI models and unified "Vibe" agent** — Mistral introduced Physics AI (May 27), a new model class predicting the behavior of physical systems for engineering/hardware acceleration, alongside published research. On May 28 it shipped "Vibe gets to work," a single long-horizon agent unifying Work and Code modes (inbox/calendar triage, deep research, deliverable drafting, request-to-merged-change coding) plus a new VS Code extension and a Search Toolkit for production search pipelines. _Why it matters:_ A European frontier lab pushing past chat into simulation/engineering verticals and an integrated agentic work surface. [https://mistral.ai/news/introducing-physics-ai-at-mistral/]

**Google ships Gemini 3.5 Flash and previews Gemini Omni** — Following Google I/O, Gemini 3.5 Flash is GA with frontier agentic/coding performance (76.2% Terminal-Bench 2.1, 83.6% MCP Atlas, 4x faster output than other frontier models) at roughly 1/2–1/3 the cost of comparable models, available across the Gemini app, AI Mode, Antigravity, and Gemini Enterprise. Google also previewed Gemini Omni (any-input-to-any-output, starting with video). _Why it matters:_ Google is betting the agent era on cheap, fast models as the default interface rather than chasing flagship benchmarks alone. [https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5/]

**Anthropic opens Milan and Seoul offices in one week** — Anthropic announced a Milan office (May 27) serving Italian enterprise/research/developer communities — its second European hub — and named KiYoung Choi (ex-Snowflake Korea) Representative Director of Anthropic Korea (May 26) ahead of a Seoul opening, citing Korean Claude usage running ~3.5x population-predicted levels. _Why it matters:_ Frontier-lab go-to-market is going global fast, with the enterprise-deployment geography now spanning six international offices. [https://www.anthropic.com/news/milan-office-opening]

**Salesforce launches Agentforce Operations for the back office** — Agentforce Operations turns manual back-office processes into work that specialized agents complete (and coordinate with people only when needed), now generally available, with Flow auto-sync/trigger integration entering beta. Built on Salesforce's Regrello acquisition. _Why it matters:_ Pushes Agentforce from front-office assistants toward autonomous operations execution — the enterprise-platform agent battleground. [https://www.salesforce.com/news/stories/agentforce-operations-announcement/]
