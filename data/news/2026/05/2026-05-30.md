## Major announcements & releases

**OpenAI ships Codex v2.5 for Windows with autonomous "Computer Use"** — Released May 29, Codex on Windows 11 now gains the Computer Use mode previously limited to Mac: the agent can see the screen, click, type, and operate local apps, terminals and dev tools to test apps and hunt bugs under user supervision, plus remote control from the ChatGPT mobile app. It runs on the active desktop (foreground only) and requires a Copilot+ class NPU (40+ TOPS). _Why it matters:_ Agentic coding moves off the cloud and onto the developer's own machine — a concrete step toward agents that drive a full desktop, not just a repo. [https://openai.com/index/codex-for-almost-everything/] (The Decoder, Neowin)

**Salesforce reports its engineering org has gone "agentic" on Claude Code** — Salesforce moved its entire dev org to Anthropic's Claude Code with unlimited tokens and published April-2026 results: 79% more pull requests per developer, ~5% fewer incidents, and a 50.8% YoY rise in work items completed per developer. The flagship anecdote — a 33-endpoint API migration estimated at 231 person-days finished in 13 days (≈18x faster). _Why it matters:_ One of the largest first-party data points yet on agentic-coding ROI inside a major enterprise software vendor, and a notable Claude Code deployment proof point. [https://www.salesforce.com/news/stories/how-engineering-became-agentic/] (The Decoder)

**Attackers weaponize ChatGPT and Claude shared-chat links to spread malware ("LLMShare")** — Push Security documented a maturing attack pattern: adversaries craft public shared conversations that mimic outage notices or install guides, surface them via paid search ads, and abuse ChatGPT's code-rendering to build fake error pages or laced Claude "Apple support" walkthroughs with malicious Terminal commands. Because links sit on trusted openai.com/claude.ai domains, security tools don't flag them. Now seen across ChatGPT, Claude and Grok. _Why it matters:_ Public chat-sharing has become live malware-delivery infrastructure on trusted AI domains — a new abuse surface vendors and security teams now have to defend. [https://the-decoder.com/attackers-abuse-shared-chatgpt-and-claude-chats-to-spread-malware/] (BleepingComputer, Push Security)

**FERC heads toward a June deadline to rewrite large-load grid rules for AI data centers** — Per Politico, FERC is preparing a June proposal to govern how large loads (>20 MW), including AI data centers, connect to the interstate transmission system, built on a 14-principle directive from the Energy Secretary. A core feature is a 100% participant-funding model requiring data-center customers to pay the full cost of network upgrades they trigger — a sharp break from the socialized-cost norm. OpenAI, Microsoft and Google have all filed. _Why it matters:_ Power interconnection is the binding constraint on AI buildout; who pays for grid upgrades will shape data-center economics for years. [https://www.powermag.com/ferc-sets-june-deadline-to-rewrite-large-load-grid-rules-for-ai-era-power-demand/] (Politico, E&E News)

**Genesis AI releases Genesis World 1.0, a physics platform for robotics-model evaluation** — Announced May 27, the four-part stack (Genesis World physics engine, Nyx real-time path-traced renderer, Quadrants Python-to-GPU compiler, simulation interface) targets the model-development bottleneck: evaluations that took ~a week of real-robot testing now run in ~30 minutes in sim. Genesis claims 89% correlation with on-hardware rollouts and a reality gap 45% smaller than alternatives, with zero sim training data. _Why it matters:_ Reframes the robotics "sim-to-real" gap as a compute/eval problem — useful infra for the wave of robotics foundation models. [https://www.genesis.ai/blog/the-role-of-simulation-in-scalable-robotics-genesis-world-10-and-the-path-forward] (MarkTechPost, Humanoids Daily)

**Aleph Alpha and Cohere in merger talks for a "sovereign AI" alliance with Canada** — Handelsblatt reports Germany's Aleph Alpha (Heidelberg) and Canada's Cohere are discussing a tie-up, framed around joint Germany–Canada sovereign-AI ambitions. _Why it matters:_ Consolidation among the Western non-US-frontier labs — a signal that the "sovereign AI" push is moving from policy rhetoric toward corporate combination. [https://www.handelsblatt.com/politik/deutschland/kuenstliche-intelligenz-allianz-mit-kanada-aleph-alpha-und-cohere-sprechen-ueber-fusion/100211624.html] (Aleph Alpha + Cohere Fusionsgespräche)

**Qdrant 1.18 ships TurboQuant, Google Research's training-free vector quantization** — Qdrant's release brings TurboQuant (ICLR 2026), which applies a fast Hadamard rotation before compression and needs no per-dataset training, calibration set, or codebooks. It claims SQ-level recall at 2x less memory; the 2-bit/1-bit variants match binary-quant storage budgets at higher recall. Resurfaced today via a Towards Data Science analysis. _Why it matters:_ A practical retrieval-infra win — cheaper, calibration-free quantization makes large vector indexes meaningfully more memory-efficient for RAG at scale. [https://qdrant.tech/articles/turboquant-quantization/] (Google Research, Towards Data Science)
