**MarkTechPost recap — Mistral Medium 3.5 + Vibe Remote Agents lock in 77.6% SWE-Bench Verified, $1.50/$7.50 pricing** — Saturday recaps and follow-on coverage of Mistral's 29 April release land on 2 May. Mistral Medium 3.5 is a 128 B dense model with a 256 k context window, unifying instruction-following, reasoning and coding in one set of weights; SWE-Bench Verified score of 77.6% places it in the Claude Opus / GPT-5.5 frontier band. Vibe Remote Agents — cloud-resident parallel coding sessions invokable from CLI or Le Chat — and Le Chat Work mode (parallel multi-step agentic tasks across email/calendar/docs/Jira/Slack) ship on Pro, Team and Enterprise. Open weights on Hugging Face under modified MIT; pricing $1.50 in / $7.50 out per M tokens. _Why it matters:_ At weekend, Medium 3.5 is the cleanest open-weight coding-agent option on the market — direct pressure on Codex on Bedrock, Claude Code and Devstral 2. The pricing/perf curve makes Vibe Remote Agents the default sovereign-Europe agentic-coding stack heading into Sapphire 2026. **Pentagon AI awards reverberate: industry frames Anthropic exclusion as the moment usage policy met federal procurement** — Coverage on 2 May (Saturday) consolidates around how the 1 May DoD awards reshape the frontier-lab landscape. Pentagon officials reiterate "we will never again rely on a single AI provider"; commentary points out that Anthropic's exclusion is the first time a frontier lab has held a public usage policy against direct federal pressure and accepted being designated a supply-chain risk for it. The eight contracted vendors (OpenAI, Google, Microsoft, AWS, NVIDIA, SpaceX, Oracle, Reflection AI) now share an Impact-Level-6/7 footprint that no single competitor controls. _Why it matters:_ This is the cleanest test of the "values-aligned commercial lab vs federally-aligned compute" thesis. The weekend frame reads it as a long-term-positive for Anthropic's enterprise-services pitch — Goldman, Blackstone and Hellman & Friedman want a lab that can publicly refuse the Pentagon — and short-term-painful for federal revenue. **Microsoft 365 E7 + Agent 365 land in customer tenants: local AI agent controls live across enterprise estates** — Saturday rollout coverage confirms Microsoft 365 E7 ("Frontier Suite") and Agent 365 are now visible to admins worldwide following the 1 May GA. Agent 365 ships with local AI agent controls — observe, govern, manage and secure agents inside the tenant — and registry sync with AWS Bedrock and Google Cloud in public preview lets IT discover agents running outside Microsoft's stack. WinBuzzer's deep-dive on 2 May highlights that local agent controls plus runtime alerting via Intune/Defender (June preview) make this the first hyperscaler control-plane that treats agents like managed identities. _Why it matters:_ The first weekend with Agent 365 in tenants is when IT teams discover what agentic-AI inventory they actually have. The Intune/Defender path means existing endpoint-management workflows absorb the agent fleet without a separate AI-governance toolchain. [WinBuzzer — Agent 365 GA with local AI agent controls](https://winbuzzer.com/2026/05/02/microsoft-agent-365-general-availability-local-ai-agents-xcxwbn/) · [M365 Admin — Agent 365 GA recap](https://m365admin.handsontek.net/microsoft-agent-365-becomes-generally-available-ga/)

**Hugging Face open-weights weekend: GPT-OSS-120B-driven Zero-To-CAD pipeline lands** — Researcher Mehdi Ataei released Zero-To-CAD on Hugging Face: an agentic synthetic-data pipeline that uses GPT-OSS-120B inside a CAD generation loop to produce readable CadQuery programs from natural-language prompts. The pipeline is open and reproducible — a meaningful signal because it's the first weekend Hugging Face post to fully orchestrate OpenAI's GPT-OSS model in an end-to-end agentic synthesis workflow. _Why it matters:_ GPT-OSS-120B has been mostly evaluated head-to-head against Llama 4 and Qwen 3; this is the first non-trivial production-style agentic deployment of it. Synthetic-CAD generation is a high-value workflow for industrial customers; a public reproducible recipe accelerates the manufacturing-AI vertical that NVIDIA and Siemens have been seeding.
