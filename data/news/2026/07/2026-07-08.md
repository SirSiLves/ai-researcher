## Major announcements & releases

**European Commission unveils Action Plan on Cybersecurity and AI** — On July 7 the Commission presented a plan to address the risks and harness the opportunities of advanced AI in cybersecurity, tying directly into the AI Act's pre-market model-evaluation requirement. Key actions include building an EU third-party evaluation capacity to support the AI Office, an ENISA-defined "European blueprint for structured access" to frontier models for cyber defenders, a JRC/ENISA secure testing platform (with simulated environments), and an "EU Grand Challenge on AI for cybersecurity." _Why it matters:_ This is the first concrete operational scaffolding around the AI Act's frontier-model provisions, landing weeks before high-risk obligations become enforceable on Aug 2, 2026. [https://commission.europa.eu/news-and-media/news/new-eu-plan-address-risks-and-opportunities-advanced-ai-cybersecurity-2026-07-07_en] (press release: https://ec.europa.eu/commission/presscorner/detail/en/ip_26_1544)

**OpenAI previews GPT-5.6 (Sol / Terra / Luna); broad launch imminent** — OpenAI opened a limited preview of its GPT-5.6 series — Sol (flagship), Terra (balanced, ~2x cheaper than GPT-5.5), and Luna (fast/low-cost) — introducing a new `max` reasoning effort and an `ultra` mode that spawns subagents. Sol sets a new SOTA on Terminal-Bench 2.1 and is OpenAI's most capable cyber model yet, shipped with its most robust safety stack and a phased release coordinated with the U.S. government. Pricing (per 1M tokens): Sol $5/$30, Terra $2.50/$15, Luna $1/$6; general availability is expected within weeks (reporting points to a public launch around July 9). _Why it matters:_ A frontier-tier release whose limited, government-coordinated rollout is itself a governance precedent, and whose `ultra`/subagent mode pushes the single-model-vs-agent-swarm boundary. [https://openai.com/index/previewing-gpt-5-6-sol/]

**OpenAI to serve GPT-5.6 Sol on Cerebras at up to 750 tokens/sec** — Alongside the preview, OpenAI said it will run flagship Sol on Cerebras wafer-scale hardware at up to ~750 tok/s in July (initially select customers), roughly an order of magnitude faster than typical GPU streaming of a frontier-class model. _Why it matters:_ For agentic workflows that chain many generations across tool calls, wafer-scale throughput collapses end-to-end latency — a 30-second GPU agent loop finishes in under 3 seconds — reframing the inference-hardware competition. [https://openai.com/index/previewing-gpt-5-6-sol/] (context: https://www.kucoin.com/news/flash/openai-to-launch-gpt-5-6-sol-on-cerebras-hardware-in-july)

**MCP specification 2026-07-28 release candidate published** — The Model Context Protocol project shipped a release candidate for its largest revision since launch, with the final spec due July 28. Headline changes: a stateless core that scales on ordinary HTTP (no sticky sessions/shared session store required), server-rendered UIs via "MCP Apps," long-running work via a "Tasks" extension, and authorization aligned more closely with OAuth / OpenID Connect. _Why it matters:_ Removing the stateful-gateway requirement makes remote MCP servers deployable behind a plain load balancer — a major step toward enterprise-grade, standards-based agent tooling now stewarded by the Linux Foundation's Agentic AI Foundation. [https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/]

**DeepSeek V4 official release lands mid-July with peak-hour API pricing** — After the April 24 V4 Preview (V4-Pro, V4-Flash), DeepSeek is graduating V4 out of preview in mid-July, and — for the first time — introducing time-of-day API pricing, charging 2x the off-peak rate during peak windows (roughly 09:00–12:00 and 14:00–18:00). The legacy `deepseek-chat` / `deepseek-reasoner` model aliases are slated for deprecation on 2026-07-24. _Why it matters:_ A frontier open-weights family reaching GA, plus a novel congestion-pricing model for inference that other providers may copy as demand outstrips capacity. [https://api-docs.deepseek.com/news/news260424] (context: https://technode.com/2026/06/30/deepseek-to-launch-v4-in-mid-july-with-new-peak-time-api-pricing/)

**Google delays Gemini 3.5 Pro to July 17 for an architectural rebuild** — Multiple reports say Google DeepMind pushed Gemini 3.5 Pro's launch to July 17, scrapping the prior 2.5-Pro base architecture for a full rebuild after early enterprise testing flagged token-efficiency, coding, and long-horizon reasoning gaps. The model is expected to carry a 2M-token context window and a "Deep Think" reasoning layer. _Why it matters:_ Signals how high the frontier bar now sits — Google is willing to slip a flagship and absorb market pressure rather than ship below GPT-5.6 / Fable-class quality. Note: not officially confirmed by Google with a model card as of publication. [https://finance.biggo.com/news/6f0c6bb2-795f-4c57-9d09-6db691d7638a]

**Government of Alberta uses Claude Code to scan 466M lines of code in 20 hours** — Anthropic published a case study (July 6) on Alberta's Ministry of Technology and Innovation, which ran ~50 Claude Code agents (Opus + Sonnet) in parallel to scan every provincial repository — 466M lines across ~3,400 repos — for security vulnerabilities in about 20 hours, work the team estimates would otherwise have taken ~6.5 years, then fixed and even rebuilt legacy systems (a 25-year-old Java portal rebuilt in days). Continuous red-team/blue-team review agents are built on the Claude Agent SDK. _Why it matters:_ A concrete, at-scale public-sector agentic deployment — remediating security debt across 27 ministries — and a template Alberta is publishing for other governments. [https://www.anthropic.com/news/alberta-government-claude-cybersecurity]

**Claude Code makes "Manual" the default permission mode** — In v2.1.200 (rolled out July 3) Anthropic changed the default permission mode from Auto to Manual across the CLI, VS Code, and JetBrains, requiring human authorization before each file write, shell command, or network call. Anthropic's telemetry showed users rubber-stamping ~93% of prompts under Auto ("approval fatigue"); teams wanting the prior behavior must now opt in with `--permission-mode auto`. _Why it matters:_ A safe-by-default shift in the most widely used agentic coding tool, shrinking the blast radius for fresh installs — an agent-safety design signal the ecosystem is watching. [https://code.claude.com/docs/en/changelog] (analysis: https://www.techtimes.com/articles/319874/20260707/claude-code-defaults-human-approval-auto-mode-requires-explicit-opt.htm)

**Snowflake's managed MCP Server connects Cortex Agents to the agent ecosystem** — Snowflake's managed Model Context Protocol server (serving Cortex Analyst, Cortex Search, and Cortex Agents as tools) lets enterprises expose governed Snowflake data to external agent platforms — Anthropic, Salesforce Agentforce, Cursor, CrewAI, Devin, UiPath, Windsurf — without standing up separate infrastructure, with per-tool permissions. _Why it matters:_ A marquee example of the two-layer agent stack (MCP for tool access) reaching the enterprise data plane, letting the data warehouse become a first-class, permissioned tool surface for agents. [https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp] (context: https://www.constellationr.com/blog-news/insights/snowflake-launches-cortex-ai-financial-services-mcp-server)
