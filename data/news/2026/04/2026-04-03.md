## Major announcements & releases

**Microsoft ships Agent Governance Toolkit — open-source runtime security for autonomous agents, p99 below 0.1 ms** — Microsoft open-sourced the Agent Governance Toolkit on 2/3 April, the first toolkit to address all 10 OWASP agentic-AI risks with deterministic, sub-millisecond policy enforcement (reported p99 latency below 0.1 ms). The seven-package system is available in Python, TypeScript, Rust, Go and .NET; the Agent OS package is a stateless policy engine that intercepts every agent action before execution. Integrations are live with LangChain, CrewAI, Google ADK, Microsoft Agent Framework, plus Dify, LlamaIndex, OpenAI Agents SDK, Haystack, LangGraph and PydanticAI. Compliance tooling maps to EU AI Act, HIPAA and SOC 2. 9,500+ tests, continuous fuzzing via ClusterFuzzLite, SLSA-compatible build provenance, OpenSSF Scorecard, CodeQL and Dependabot. Microsoft has signalled it wants the project to move into a foundation home for community governance. _Why it matters:_ This is the most credible attempt yet at a vendor-neutral agent governance runtime, explicitly framed for the EU AI Act's 2 August GP-AI deadline. Sub-millisecond enforcement is the latency budget that lets governance run in-line on every tool call without breaking the agent loop. [Microsoft Open Source Blog — introducing the Agent Governance Toolkit](https://opensource.microsoft.com/blog/2026/04/02/introducing-the-agent-governance-toolkit-open-source-runtime-security-for-ai-agents/) · [Microsoft community — architecture deep dive](https://techcommunity.microsoft.com/blog/linuxandopensourceblog/agent-governance-toolkit-architecture-deep-dive-policy-engines-trust-and-sre-for/4510105) · [Help Net Security — open-source toolkit to govern autonomous agents](https://www.helpnetsecurity.com/2026/04/03/microsoft-ai-agent-governance-toolkit/) · [Phoronix — runtime security for AI agents](https://www.phoronix.com/news/Microsoft-AI-Agent-Governance)

**CNN Business — "Anthropic Mythos could be a watershed moment for cybersecurity" (first major outlet to surface Mythos)** — CNN Business ran the first major-outlet long-form on the Mythos model on 3 April, drawing on the leaked unpublished blog post that Fortune first surfaced 26 March. The piece quotes Anthropic's framing that Mythos is "far ahead of any other AI model in cyber capabilities" and "presages an upcoming wave of models that can exploit vulnerabilities in ways that far outpace the efforts of defenders." Anthropic is privately briefing government officials and letting a small set of organisations test the model ahead of any release. _Why it matters:_ This is the day Mythos crosses from "AI insiders know about it" to "general policy-class awareness." It's also the framing that triggers next week's Treasury/Fed/Bank of England banks briefings. [CNN Business — watershed moment for cybersecurity](https://edition.cnn.com/2026/04/03/tech/anthropic-mythos-ai-cybersecurity) · [KEYT — CNN piece syndicated](https://keyt.com/news/money-and-business/cnn-business-consumer/2026/04/03/anthropics-next-model-could-be-a-watershed-moment-for-cybersecurity-experts-say-that-could-also-be-a-concern/)

**Microsoft Copilot Studio — multi-agent systems GA, A2A protocol support, MCP connector for admins** — Microsoft moved multi-agent systems in Copilot Studio to general availability for all eligible customers on 3 April. New GA capabilities include multi-agent coordination across Microsoft Fabric, the Microsoft 365 Agents SDK, and the open Agent-to-Agent (A2A) protocol — letting agents from Copilot Studio collaborate with agents built on LangGraph, CrewAI and Google ADK. Agent Builder added admin review/approval before publishing to the Agent Store catalog. _Why it matters:_ A2A interoperability moves from spec to default-on in Copilot Studio — the largest enterprise agent footprint in the world is now natively multi-vendor. The April Copilot Studio release also adds the MCP-connector admin gate that closes the loop with the Agent Governance Toolkit's policy layer. [Microsoft Copilot Blog — new and improved agent governance, intelligent workflows](https://www.microsoft.com/en-us/microsoft-copilot/blog/copilot-studio/new-and-improved-agent-governance-intelligent-workflows-and-connected-app-experiences/) · [Microsoft Copilot Blog — multi-agent orchestration, connected experiences](https://www.microsoft.com/en-us/microsoft-copilot/blog/copilot-studio/new-and-improved-multi-agent-orchestration-connected-experiences-and-faster-prompt-iteration/)

**Microsoft 365 Copilot — 41 April updates including PowerPoint Agent, Excel Agent, hands-free wake word** — Microsoft's April Microsoft 365 Copilot release includes three new productivity agents (PowerPoint Agent for storytelling/layout, Excel Agent for charts/summaries, plus a Word agent variant), a wake word for hands-free Copilot access, MCP connector support for admins, and a wave of new third-party Copilot Connectors. _Why it matters:_ The big agentic stack is now distributed at the Office app surface, where the actual enterprise hours are spent. M365 Copilot's PPT/Excel/Word agents are the direct competitive stake against Anthropic's GA Claude add-ins for the same Office apps (announced 5 May). [Microsoft Community Hub — what's new in M365 Copilot April 2026](https://techcommunity.microsoft.com/blog/microsoft365copilotblog/what%e2%80%99s-new-in-microsoft-365-copilot--april-2026/4510935) · [A Guide to Cloud — 41 updates](https://www.aguidetocloud.com/blog/microsoft-365-copilot-april-2026-updates/)

**Anthropic Mythos disclosure prep — White House and federal-agency briefings underway** — Reporting on 3 April confirmed Anthropic was privately warning U.S. government officials about Mythos-class cyberattack potential ahead of the formal 7 April announcement. The framing emphasises preserving defensive head-start time for critical-software vendors before model release. _Why it matters:_ This is the pre-disclosure choreography that becomes the template for the next decade of frontier-model release governance. Project Glasswing's gated-consortium model is being workshopped against actual White House feedback rather than being unveiled cold. [CETaS — Claude Mythos future of cybersecurity](https://cetas.turing.ac.uk/publications/claude-mythos-future-cybersecurity) · [Medium — Anthropic Mythos is a monster](https://medium.com/@mahendraa1188/anthropic-mythos-is-a-monster-fe751f1beb19)

**Microsoft Agent Framework 1.0 hits GA — MCP-native, .NET + Python, Sequential / Group Chat / Magentic-One patterns** — Microsoft shipped Agent Framework 1.0 GA on April 3 — the production-ready open-source successor to Semantic Kernel + AutoGen for building single- and multi-agent workflows. Native MCP integration lets agents auto-discover tools without integration code; stable orchestration patterns (Sequential, Group Chat, Magentic-One); browser-based local debugger visualizes message flow, tool calls, and state in real time. _Why it matters:_ With Copilot Studio multi-agent GA shipping the same day, Microsoft now has the most complete MCP+A2A native stack — the framework is the developer-side piece of the same governance/orchestration story. [Microsoft Community — Future of Agentic AI: Inside Agent Framework 1.0](https://techcommunity.microsoft.com/blog/azuredevcommunityblog/the-future-of-agentic-ai-inside-microsoft-agent-framework-1-0/4510698)

**MCP Dev Summit NYC closes Day 2 — AAIF governance handover, OAuth/identity, registry roadmap** — Day 2 of the inaugural MCP Dev Summit wrapped in NYC with sessions from the Linux Foundation Agentic AI Foundation (AAIF), MCP maintainers, and registry/identity working groups. AAIF formed in late 2025 to anchor MCP, goose, and AGENTS.md as neutral standards; the summit is the first developer-facing post-handover event. _Why it matters:_ The community now has a published reference implementation set + OAuth profile — the unblocker for enterprise IT to ship MCP servers that pass internal SSO/identity reviews. [Linux Foundation — formation of the Agentic AI Foundation](https://www.linuxfoundation.org/press/linux-foundation-announces-the-formation-of-the-agentic-ai-foundation)
