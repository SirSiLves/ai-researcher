# AI News — 2026-06-02

_Collector: ai-news. Slice: vendor blogs, tech news, web search._

## Major announcements & releases

**Microsoft Build 2026 ships the full agent stack and cuts the OpenAI cord with Project Polaris** — At Build 2026 (June 2–3, Fort Mason, San Francisco), Satya Nadella framed the keynote around AI moving from synchronous assistants to "async coworkers that execute long-running tasks," and backed it with Project Polaris — Microsoft's own coding model, running on its custom Maia 200 accelerators, set to replace GPT-4 Turbo as the default GitHub Copilot engine for all subscribers by August 2026 (automatic migration, optional 3-month GPT-4 fallback). Polaris is purpose-built for code generation, multi-file refactoring, test writing, review and dependency analysis. _Why it matters:_ The most strategically loaded Build in years — Microsoft now owns the model, the inference silicon (Maia 200), and the developer surface end-to-end, resolving the awkward OpenAI-Copilot codependency just as OpenAI ships its own Codex competitor. [https://chatforest.com/builders-log/microsoft-build-2026-recap-windows-agent-platform-project-polaris-copilot-workspace/]

**Microsoft open-sources Windows Agent Framework 1.0 under MIT and turns Windows into an agent platform** — WAF 1.0 (shipped April 2, MIT-licensed at Build) gives agents a consistent programming model across local Windows, Windows 365 Cloud PCs, and Azure Arc edge, with access to four OS capability classes (file system, network, UI automation, process management), session-persistent state, and a built-in human-approval queue for privileged actions. It is model-agnostic — agents built on WAF can run Claude, Gemini, or any model. Visual Studio 2026 ships WAF project templates today. _Why it matters:_ The classic Microsoft platform play — give away the framework, own the platform. If WAF becomes the default way third-party agents integrate with Windows, Microsoft controls the agent layer regardless of which model wins. [https://windowsnews.ai/article/build-2026-microsoft-makes-windows-an-agent-platform-for-ai-developers.420496]

**Azure Agent Mesh: federated multi-agent execution across clouds, on-prem, and edge** — Microsoft announced Azure Agent Mesh, a control plane that federates agent execution across Azure, AWS Bedrock, Google Cloud AI Platform, on-prem systems (via Azure Arc), and Windows 365 Cloud PCs under one governance/observability layer, with full audit trails from Entra ID and Purview. The Build demo ran a financial-compliance agent spanning an on-prem DB, an Azure knowledge base, and a Cloud PC risk model as a single coordinated workflow. GA targeted Q4 2026. _Why it matters:_ Microsoft's strongest answer yet to the governance problem that has stalled enterprise agent adoption in regulated industries — and notably its first product positioned as explicitly multi-cloud rather than Azure-only. [https://aitoolsrecap.com/Blog/microsoft-build-2026-windows-agent-framework-wsl3-azure-mesh]

**Azure AI Foundry makes Claude, DeepSeek, Llama and Mistral first-party models; Microsoft ships its own MAI models commercially** — Foundry now offers Anthropic's Claude (Opus 4.8, Sonnet 4.6) as a first-class option alongside OpenAI, DeepSeek, Llama 4, and Mistral — same enterprise SLAs, Entra ID identity, Purview governance, and billing. Separately, Microsoft made its in-house MAI models broadly available for commercial use for the first time: MAI-Transcribe-1 (STT), MAI-Voice-1 (TTS, one minute of audio in under a second on one GPU), and MAI-Image-2-Efficient. Foundry Local also hit GA for on-device inference on Windows/macOS/Linux. _Why it matters:_ Microsoft is simultaneously becoming a model-agnostic platform (build once, swap backends) and a first-party model provider via Suleyman's MAI team — hedging its OpenAI dependency from both directions. [https://www.epcgroup.net/blog/microsoft-build-2026-enterprise-recap-key-announcements]

**OpenAI ships GPT-5.3-Codex — most capable agentic coding model to date** — OpenAI's new GPT-5.3-Codex unifies the Codex and GPT-5 training stacks into a single model that is ~25% faster and can take on long-running tasks involving research, tool use, and complex multi-step execution, with the ability to steer it mid-run without losing context. It sets new industry highs on SWE-Bench Pro and Terminal-Bench, with strong OSWorld and GDPval results. _Why it matters:_ Lands right as Microsoft announces Polaris to replace GPT-4 in Copilot — OpenAI is doubling down on Codex as its own agentic-coding product, sharpening the frontier-lab-vs-platform competition in developer tooling. [https://openai.com/index/introducing-gpt-5-3-codex/]

**Snowflake Summit 2026 centers the "agentic enterprise": Cortex Sense, Cortex Training, Horizon Catalog, and Snowflake CoWork** — At its Summit (announcements dated June 2), Snowflake pushed up the stack from data warehouse to AI platform: Cortex Sense (a shared context layer giving agents business definitions and operational knowledge), Cortex Training (managed GPU infra to fine-tune open models like Qwen and Mistral on proprietary data), Horizon Catalog (centralized cross-system governance via Apache Polaris, with Iceberg v3 and zero-copy integrations to SAP/Salesforce), and a rebrand of Snowflake Intelligence to "Snowflake CoWork" as a personal AI work agent. _Why it matters:_ Snowflake is staking out the governed-data-and-context plane that enterprise agents run on top of — positioning itself as the orchestration/governance layer rather than a foundation-model builder, the inverse of Microsoft's full-stack bet. [https://www.businesswire.com/news/home/20260602477507/en/Snowflake-Pioneers-New-Open-Framework-for-Interoperable-Enterprise-Data-and-AI]

**Google DeepMind, Anthropic and Meta expand machine-consciousness and AI-welfare research** — The Financial Times reported that the three labs are hiring psychologists, ethicists and philosophers and formally scaling up research into AI "consciousness" and model welfare — assessing systems for evidence of consciousness/robust agency and drafting policies for treating models with a measure of moral concern — even as Anthropic stresses there is no scientific consensus that current or near-future systems are conscious. _Why it matters:_ Model welfare is moving from fringe philosophy to a staffed corporate research function at the frontier labs, a governance/safety frontier that will shape future safety frameworks and public debate. [https://www.tradingview.com/news/reuters.com,2026:newsml_L4N42A0BV:0-google-deepmind-anthropic-and-meta-expand-research-into-machine-consciousness-and-ai-welfare-ft/]
