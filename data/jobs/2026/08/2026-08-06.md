## Notes

- **The methodological result of this run outweighs any single listing: this collector has been under-reading employers' own boards by roughly 4×, and ETH Zürich is the proof.** Since 08-01 this file has carried ETH as "×6", sourced through swissaijob's aggregation, with exactly **one** Apertus role on record (Evaluations). ETH's own portal was read in full today — **136 open positions** — and it shows **four** Apertus Engineer roles posted the same day (Infrastructure, Post-training, Deployment, Evaluations), plus a **Head of Geospatial AI**, a **Research Engineer for an Interactive AI Characters Platform**, and a **Platform Engineer (HPC & AI Infrastructure) posted today**. That is **five roles new to this file from a single employer that this file believed it was already tracking**. The aggregator did not mislabel anything; it simply sampled one req out of a four-req set and this file inherited the sample as the population. **Standing correction: for any employer that publishes its own board, the aggregate count is a lower bound and should never be treated as the employer's actual AI headcount demand.** The obvious next targets under the same logic are EPFL, CERN, IBM Research Zürich and the large banks.
