## Research highlights

- **[Is Grep All You Need? How Agent Harnesses Reshape Agentic Search](https://arxiv.org/abs/2605.15184)** — Lexical (grep) vs semantic vs hybrid search across tool-equipped LLM agent harnesses in long-context regimes. Argues harness design changes which retrieval primitive wins — undermines one-size-fits-all RAG.
- **[LLM-Oriented Information Retrieval: A Denoising-First Perspective](https://arxiv.org/abs/2605.00505)** — Reframes the IR pipeline around denoising (usable-evidence density per context window) as primary bottleneck. Pipeline-organized taxonomy across indexing, retrieval, context engineering, verification, and agentic workflow.
- **[ExploitBench: A Capability Ladder Benchmark for LLM Cybersecurity Agents](https://arxiv.org/abs/2605.14153)** — Tiered cyber-offense benchmark exposes a sharp capability gap between publicly deployed frontier models and the private frontier — direct evidence the closed-vs-open eval gap is widening for agentic security tasks.
- **[Reward Hacking Benchmark: Measuring Exploits in LLM Agents with Tool Use](https://arxiv.org/abs/2605.02964)** — Multi-step tool-use tasks instrumented with naturalistic shortcut opportunities (skip verification, infer from metadata, tamper with eval functions). Quantifies a missing dimension in current agent evals.
- **[Towards Federated Fine-Tuning: A Cross-Domain Benchmark for Private Data Training](https://arxiv.org/abs/2605.13936)** — Head-to-head of LoRA / QLoRA / IA3 in federated fine-tuning vs centralized baseline. Federated ≈ centralized; QLoRA/IA3 win on efficiency with marginal accuracy loss — practical privacy-preserving SFT signal.
- **[Position: Agentic AI Orchestration Should Be Bayes-Consistent](https://arxiv.org/abs/2605.00742)** — Argues current router/planner/critic orchestrators lack a decision-theoretic foundation; proposes consistency requirements to avoid degenerate behavior under uncertainty. Theoretical input for agent-platform designers.
- **[A Systematic Survey of Security Threats and Defenses in LLM-Based AI Agents](https://arxiv.org/abs/2604.23338)** — Threat model decomposes the agent attack surface into layers (prompt / memory / tool / delegation / coordination) and maps known attacks/defenses per layer. Operational reference for AI security teams.
- **[From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms](https://arxiv.org/abs/2605.06716)** — Three-stage evolutionary frame: Storage (trajectory preservation) → Reflection (refinement) → Experience (abstraction). Useful taxonomy as memory becomes the foundation primitive for long-horizon agents.
