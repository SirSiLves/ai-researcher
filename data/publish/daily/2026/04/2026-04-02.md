## Major news & releases

### Frontier model releases & open-weight wave

**Google releases Gemma 4 — open-weight 2B / 4B / 26B-MoE / 31B, 256K context, multimodal, Apache 2.0.** Four sizes: E2B (2.3B effective), E4B (4.5B effective), 26B Mixture-of-Experts (4B active), 31B dense. Resets the open-weight bar that Llama 4 / DeepSeek V4 will be measured against this month. ### Agent infrastructure & developer tools — Cursor 3 / Glass

**Cursor 3 ships an agent-first interface — Agents Window, Design Mode, parallel cloud agents.** Anysphere released Cursor 3 on 2 April — biggest interface overhaul since the product launched in 2023. New Agents Window is a full-screen workspace for running and managing many AI agents in parallel — locally, in worktrees, in the cloud, or over remote SSH — with kick-offs from mobile, Slack, GitHub and Linear. Design Mode (Cmd+Shift+D) lets developers annotate UI elements directly in a built-in browser to hand the agent precise visual targets. Agent Tabs display multiple chats side-by-side; `/worktree` command isolates changes per agent. The IDE remains; the Agents Window is a separate surface. Built under the codename "Glass." Composer 2 (Cursor's first continued-pretraining model on top of a base) ships in the same release. _Why it matters:_ Clearest statement yet that "you orchestrate, the agents code" is the IDE's default mental model. Puts Cursor in direct head-to-head with Claude Code and Codex CLI on parallel-agent UX — the dimension that decides whose harness wins the next 12 months. The Cursor 3 launch lands two days after Anthropic's Claude Code source-map leak and uses much of the same harness vocabulary. ## Research highlights

- **Terminal Agents Suffice for Enterprise Automation** — anonymous (cs.AI). Plain terminal-based coding agent driving programmatic interfaces matches or beats heavily MCP/tool-augmented agents on enterprise tasks. Direct counter to the "more tools = better" framing of MCP-first stacks. _Category:_ arXiv:2604.00073 — cs.AI. [arXiv](https://arxiv.org/abs/2604.00073)
- **ClawKeeper: Comprehensive Safety Protection for Open Agents via Skills, Plugins, and Watchers** — anonymous (cs.AI). Defense framework for open-source agent runtimes layering instruction-level policies, plugin sandboxing, and a watcher paradigm intercepting high-risk actions for human confirmation. _Category:_ arXiv:2603.24414 — cs.AI. [arXiv](https://arxiv.org/abs/2603.24414)
- **Do Phone-Use Agents Respect Your Privacy?** — anonymous (cs.AI). Introduces MyPhoneBench with an "iMy" minimal privacy contract operationalising permissioned access, minimal disclosure, and user-controlled memory. Across 5 frontier models / 10 apps / 300 tasks, joint success-and-privacy evaluation reshuffles model rankings vs. accuracy alone; persistent failure is data over-disclosure on benign tasks. _Category:_ arXiv:2604.00986 — cs.AI. [arXiv](https://arxiv.org/abs/2604.00986)
- **MiroEval: Benchmarking Multimodal Deep Research Agents in Process and Outcome** — anonymous (cs.IR/cs.AI). Scores adaptive synthesis, agentic factuality verification, and process auditing — not just final-answer correctness. Real-user task pipeline with a "live evolving setting." _Category:_ arXiv:2603.28407 — cs.IR. [arXiv](https://arxiv.org/abs/2603.28407)
- **Reasoning Shift: How Context Silently Shortens LLM Reasoning** — anonymous (cs.CL). Context length and structure systematically compress reasoning traces — models maintain accuracy on simple items while invisibly truncating verification and uncertainty management on harder ones. _Category:_ arXiv:2604.01161 — cs.CL. [arXiv](https://arxiv.org/abs/2604.01161)
- **HippoCamp: Benchmarking Contextual Agents on Personal Computers** — anonymous (cs.AI). Multimodal file-management benchmark probing long-horizon retrieval and cross-modal reasoning over dense personal file systems; concretely measures the "personal data" gap blocking serious consumer-agent deployment. _Category:_ arXiv:2604.01221 — cs.AI. [arXiv](https://arxiv.org/abs/2604.01221)
- **Brevity Constraints Reverse Performance Hierarchies in Language Models** — anonymous (cs.CL). Causal intervention showing that constraining output length flips the "bigger models are better" hierarchy on multiple benchmarks: verbose responses inject errors that mask capability. Practical implication for evals that ignore length budget. _Category:_ arXiv:2604.00025 — cs.CL. [arXiv](https://arxiv.org/abs/2604.00025)
- **A Survey of On-Policy Distillation for Large Language Models** — anonymous (cs.LG). Unifying f-divergence framework organising approaches by feedback signal (logit / outcome / uncertainty-aware), teacher access (white/black-box/teacher-free), and granularity (token/sequence/hybrid). Pulls in distillation scaling laws and agent-level distillation under one taxonomy. _Category:_ arXiv:2604.00626 — cs.LG. [arXiv](https://arxiv.org/abs/2604.00626)
