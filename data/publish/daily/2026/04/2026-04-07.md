## Major news & releases

### Frontier capability — Mythos / Glasswing

**Anthropic introduces Claude Mythos Preview and Project Glasswing — the first capability-gated frontier model.** Anthropic announced Project Glasswing on 7 April, an initiative to secure the world's most critical software for the AI era, powered by **Claude Mythos Preview** — the company's most capable model to date and the first model Anthropic has publicly deemed too high-risk for public release. Mythos Preview scored 31 percentage points higher than Opus 4.6 on USAMO 2026, and in pre-release testing autonomously identified and exploited thousands of previously unknown vulnerabilities across every major OS and browser — including a 27-year-old OpenBSD bug and a 16-year-old FFmpeg flaw. Internal tests showed it could successfully reproduce and exploit vulnerabilities in over 80% of cases. **Launch partners (11):** AWS, Anthropic, Apple, Broadcom, Cisco, CrowdStrike, Google, JPMorganChase, the Linux Foundation, Microsoft, NVIDIA, Palo Alto Networks. Extended access to over 40 additional organisations maintaining critical software infrastructure. **Commitments:** $100M in Mythos usage credits to Glasswing partners; $4M in direct donations to open-source security organisations. _Why it matters:_ The first concrete "we built it but we're not shipping it" call from a frontier lab on offensive-cyber risk. The 11-partner consortium becomes the template for future capability-gated frontier-model rollouts. Mythos is also the empirical anchor that Anthropic's $30B ARR isn't just enterprise demand but capability differentiation. ## Research highlights

- **Adam's Law: Textual Frequency Law on Large Language Models** — anonymous. Identifies a power-law relationship between sentence-level frequency in training data and downstream performance, operationalized as Textual Frequency Distillation + a Curriculum Textual Frequency Training schedule. Tested across math, MT, commonsense, and agentic tool calling. Concrete bridge from scaling-laws-of-data to recipe design. _Category:_ arXiv:2604.02176 — cs.CL. [arXiv](https://arxiv.org/abs/2604.02176)
- **TriAttention: Efficient Long Reasoning with Trigonometric KV Compression** — anonymous. Attacks the KV-cache bottleneck by working in the pre-RoPE space where Q/K vectors concentrate; trigonometric series for cheaper, more accurate key importance estimation. Throughput/memory win for long-context, complementary to KV-Fold / LaProx. _Category:_ arXiv:2604.04921 — cs.CL. [arXiv](https://arxiv.org/abs/2604.04921)
- **Memory Intelligence Agent** — anonymous. Manager-Planner-Executor architecture combining a non-parametric memory store with a parametric memory agent + alternating RL between them, plus test-time learning via reflection. Fresh design for the agent-memory-as-system problem around Mem0/STALE. _Category:_ arXiv:2604.04503 — cs.MA. [arXiv](https://arxiv.org/abs/2604.04503)
- **Can LLMs Learn to Reason Robustly under Noisy Supervision?** — anonymous. Online Label Refinement for RLVR: progressively corrects labels using majority-voted answers + consistency checks instead of trusting verifier output. Direct response to RLVR's verifier-bottleneck failure mode. _Category:_ arXiv:2604.03993 — cs.LG. [arXiv](https://arxiv.org/abs/2604.03993)
- **LightThinker++: From Reasoning Compression to Memory Management** — anonymous. Reframes "reasoning compression" as adaptive memory management with explicit memory primitives and a trajectory-synthesis pipeline for memory scheduling. Cuts tokens + inference time on long-horizon agentic tasks. _Category:_ arXiv:2604.03679 — cs.CL. [arXiv](https://arxiv.org/abs/2604.03679)
- **ClawArena: Benchmarking AI Agents in Evolving Information Environments** — anonymous. Eval for dynamic belief revision: multi-source conflicts, evolving facts, implicit personalization; shell-based executable checks rather than freeform grading. _Category:_ arXiv:2604.04202 — cs.AI. [arXiv](https://arxiv.org/abs/2604.04202)
- **SkillX: Automatically Constructing Skill Knowledge Bases for Agents** — anonymous. Self-evolving paradigm building reusable hierarchical skill libraries via iterative refinement and exploratory expansion; tested on long-horizon and user-interactive benchmarks with GLM-4.6. _Category:_ arXiv:2604.04804 — cs.MA. [arXiv](https://arxiv.org/abs/2604.04804)
- **Your Agent, Their Asset: A Real-World Safety Analysis of Open Personal Agents** — anonymous. Empirical safety analysis of an open personal-AI-agent platform using a CIK (Capability / Identity / Knowledge) attack taxonomy. Existing defenses insufficient against malicious injections; "legitimate updates" become attack vectors. _Category:_ arXiv:2604.04759 — cs.AI. [arXiv](https://arxiv.org/abs/2604.04759)
