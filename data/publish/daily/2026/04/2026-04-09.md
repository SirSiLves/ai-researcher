## Research highlights

- **RAGEN-2: Reasoning Collapse in Agentic RL** — anonymous. Identifies "template collapse" in multi-turn LLM agents: outputs become structurally similar across inputs while entropy looks healthy. Mutual-information proxies + SNR-aware filtering. Explains why agent RL plateaus when standard metrics don't predict it. _Category:_ arXiv:2604.06268 — cs.LG. [arXiv](https://arxiv.org/abs/2604.06268)
- **MARS: Enabling Autoregressive Models Multi-Token Generation** — anonymous. Fine-tunes off-the-shelf AR LLMs to predict multiple tokens per forward pass without architectural changes; dynamic speed via confidence thresholding. Practical inference-throughput win for production stacks. _Category:_ arXiv:2604.07023 — cs.CL. [arXiv](https://arxiv.org/abs/2604.07023)
- **Neural Computers** — anonymous. Position-and-prototype paper proposing models as runtime systems learning from I/O traces of screen frames and interface primitives (not from explicit programming). Collapses the boundary between video/world models and computer-use agents. _Category:_ arXiv:2604.06425 — cs.AI. [arXiv](https://arxiv.org/abs/2604.06425)
- **Combee: Scaling Prompt Learning for Self-Improving Language Model Agents** — anonymous. Parallel prompt-learning framework using parallel scans, augmented shuffle, dynamic batch-size control. Cleanly parallelizes the "agent rewrites its own system prompt from traces" loop. _Category:_ arXiv:2604.04247 — cs.MA. [arXiv](https://arxiv.org/abs/2604.04247)
- **SEVerA: Verified Synthesis of Self-Evolving Agents** — anonymous. Formally Guarded Generative Models combining planner-LLM proposals with first-order-logic specifications + rejection sampler + verified fallback; integrated GRPO-style fine-tuning on Dafny verification, symbolic math, policy-compliant tool use. _Category:_ arXiv:2603.25111 — cs.AI. [arXiv](https://arxiv.org/abs/2603.25111)
- **Personalized RewardBench: Evaluating Reward Models with Human-Aligned Personalization** — anonymous. Benchmark scoring ability to capture individual user preferences (not population averages); correlates with downstream PPO performance better than existing RM benchmarks. _Category:_ arXiv:2604.07343 — cs.LG. [arXiv](https://arxiv.org/abs/2604.07343)
- **Qualixar OS: A Universal Operating System for AI Agent Orchestration** — anonymous. Production-oriented agent runtime bridging MCP, A2A, and a "Universal Command Protocol," with multi-agent topologies (grid/forest/mesh/maker), Q-learning + Bayesian POMDP routing, JSD drift monitoring, HMAC-signed content attribution, skill marketplace. _Category:_ arXiv:2604.06392 — cs.MA. [arXiv](https://arxiv.org/abs/2604.06392)
- **The Depth Ceiling: On the Limits of LLMs in Discovering Latent Planning Strategies** — anonymous. On graph path-finding, LLMs execute latent reasoning at varying depths but consistently fail to discover the right multi-step planning strategies — discovery and execution dissociate. Direct evidence that CoT-monitoring captures execution but not strategy selection. _Category:_ arXiv:2604.06427 — cs.CL. [arXiv](https://arxiv.org/abs/2604.06427)
