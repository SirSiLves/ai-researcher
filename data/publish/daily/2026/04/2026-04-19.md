## Research highlights

_Sunday — HF Papers `/date/2026-04-19` redirects to the prior Friday; arXiv has no weekend submission slot. Picks below are the Friday cohort surfaced as Sunday backfill, deduped against the canonical 04-17 and the Saturday 04-18 slices._

- **A Survey on the Security of Long-Term Memory in LLM Agents: Toward Mnemonic Sovereignty** — Zehao Lin, Chunyu Li. Surveys persistent-memory threats — poisoning, unauthorized access, cross-session corruption — and proposes "mnemonic sovereignty" as a verifiable governance frame across write/storage/retrieval/execution/sharing/deletion. Pairs with STALE and the SSGM line — structural input for any team thinking about agent-memory governance. _Category:_ arXiv:2604.16548 — cs.CR. [arXiv](https://arxiv.org/abs/2604.16548)
- **SafeDream: Safety World Model for Proactive Early Jailbreak Detection** — Bo Yan, Weikai Lin. Lightweight external safety world model combining statistical detection and contrastive analysis to flag multi-turn jailbreaks ~1.0–1.2 conversation turns before compliance. Moves jailbreak defense from per-turn refusal to trajectory-level prediction. _Category:_ arXiv:2604.16824 — cs.CR. [arXiv](https://arxiv.org/abs/2604.16824)
- **SuperLocalMemory V3.3: The Living Brain — Biologically-Inspired Forgetting, Cognitive Quantization, and Multi-Channel Retrieval for Zero-LLM Agent Memory Systems** — Varun Pratap Bhardwaj. Local-first agent memory with adaptive forgetting, quantization-aware distance metrics, and multi-channel retrieval — explicitly avoids cloud LLM dependence. Niche but interesting position paper for the on-device-agent thread. _Category:_ arXiv:2604.04514 — cs.AI. [arXiv](https://arxiv.org/abs/2604.04514)
- **How to Fine-Tune a Reasoning Model? A Teacher-Student Cooperation Framework to Synthesize Student-Consistent SFT Data (TESSY)** — Zixian Huang, Kaichen Yang. Teacher and student cooperate to synthesize SFT data preserving the student's writing style while inheriting the teacher's reasoning — fixes the "stylistic mismatch" failure mode of distillation. _Category:_ arXiv:2604.14164 — cs.CL. [arXiv](https://arxiv.org/abs/2604.14164)
- **Cyber Defense Benchmark: Agentic Threat Hunting Evaluation for LLMs in SecOps** — Alankrit Chona, Igor Kozlov. 106 real attack procedures from OTRF Security-Datasets, 86 MITRE ATT&CK sub-techniques, wrapped as a Gymnasium RL environment. Even Claude Opus 4.6 only flags 3.8% of malicious events on average — sharp reality check. _Category:_ arXiv:2604.19533 — cs.CR. [arXiv](https://arxiv.org/abs/2604.19533)
- **MASS-RAG: Multi-Agent Synthesis Retrieval-Augmented Generation** — Xingchen Xiao, Heyan Huang. Multi-agent RAG with role-specialized agents for evidence summarization, extraction, and reasoning — pre-synthesizes complementary information across retrieved contexts before final answer. _Category:_ arXiv:2604.18509 — cs.IR. [arXiv](https://arxiv.org/abs/2604.18509)
- **MCPThreatHive: Automated Threat Intelligence for Model Context Protocol Ecosystems** — Yi Ting Shen, Kentaroh Toyoda. Open-source platform automating the MCP threat-intelligence lifecycle (collection → AI-driven extraction/classification → knowledge graph); operationalises the MCP-38 threat taxonomy. _Category:_ arXiv:2604.13849 — cs.CR. [arXiv](https://arxiv.org/abs/2604.13849)
- **Single-Agent LLMs Outperform Multi-Agent Systems on Multi-Hop Reasoning Under Equal Thinking Token Budgets** — Dat Tran, Douwe Kiela. Information-theoretic argument plus empirical results: when reasoning-token budgets are held equal, single-agent setups consistently match or beat multi-agent on multi-hop reasoning. _Category:_ arXiv:2604.02460 — cs.AI. [arXiv](https://arxiv.org/abs/2604.02460)
