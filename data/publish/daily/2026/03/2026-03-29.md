## 🎯 Top-5 reading priorities

1. **[AIP: Agent Identity Protocol for Verifiable Delegation Across MCP and A2A](https://arxiv.org/abs/2603.24775)** — Sunil Prakash. Invocation-Bound Capability Tokens (IBCTs) — issued in JWT + chained Biscuit forms — carry verifiable identity and attenuated delegation across MCP and A2A boundaries. **Scanned ~2,000 MCP servers and found ALL of them lacked authentication.** The single most consequential agent-protocol security paper of the quarter and direct input for the AWS MCP Server GA (6 May) auth story.
2. **[AgentRFC: Security Design Principles and Conformance Testing for Agent Protocols](https://arxiv.org/abs/2603.23801)** — Shenghan Zheng, Qifan Zhang. First systematic security framework for MCP / A2A / ANP / ACP with formal architectural model and a tool that detects gaps both within and across protocol compositions. The protocol-conformance counterpart to AIP's identity layer.
3. **[Pretext](https://simonwillison.net/2026/Mar/29/pretext/)** — Cheng Lou (via Simon Willison). New tiny browser library from a React core alum that calculates wrapped-text height without touching the DOM, with `prepare()` / `layout()` decomposition. Tested against the full Gatsby plus Thai/Chinese/Korean/Japanese/Arabic public-domain corpora. Standout example of agent-assisted hardcore engineering.
4. **[Mind the Gap: How the Technical Mechanisms of Agentic AI Outpace Global Legal Frameworks](https://arxiv.org/abs/2603.27075)** — Marcel Osmond, Thomas Jego. Comparative legal analysis showing current statutes conflate model capability with system architecture and miss the actual control points (system prompts, API permissions, sandboxing) where agentic behavior is governed. Direct ammunition for the EU-AI-Act-readiness debate.
5. **[March 2026 AI Roundup: the month that changed AI forever](https://www.digitalapplied.com/blog/march-2026-ai-roundup-month-that-changed-everything)** — Digital Applied. The framing that settles for the rest of the spring: (1) inference economics drive procurement; (2) agentic-AI is production-default; (3) the harness, not the model, is the product. Sets up Monday's OpenAI $122B fund close and Tuesday's Salesforce/Slack overhaul as culminations.

### Research wave

**Weekend research wave: DyMoE for continual learning (CVPR 2026), MIT Han Lab FourOverSix for NVFP4 quantisation.** (1) DyMoE (CVPR 2026, from zhaoc5) — a Dynamic Mixture of Experts with drift-aware token assignment for continual learning of large vision-language models. (2) MIT Han Lab released FourOverSix — adaptive block-scaled data types for more accurate NVFP4 quantisation. Both target the engineering layer underneath frontier model deployment. _Why it matters:_ DyMoE is the most promising of the spring's continual-learning approaches for VLMs without catastrophic forgetting; FourOverSix is a practical step toward making NVFP4 (the Blackwell / Vera Rubin native low-precision format) deliver better accuracy at production scale. - **Cryptographic Runtime Governance for Autonomous AI Systems: The Aegis Architecture** — Adam Massimo Mazzocchetti. Policy/legal constraints as cryptographically sealed execution conditions with autonomous shutdown on violation. One of the first hardware-rooted compliance-boundary designs. _Category:_ arXiv:2603.16938 — runtime governance / cs.AI. [arXiv](https://arxiv.org/abs/2603.16938)
- **Runtime Governance for AI Agents: Policies on Paths** — Maurits Kaptein, Vassilis-Javed Khan. Compliance policies as deterministic functions over (identity, partial path, proposed next action, org state) → violation probability — real-time path eval rather than design-time constraints. Aegis's policy-language sibling. _Category:_ arXiv:2603.16586 — runtime governance / cs.AI. [arXiv](https://arxiv.org/abs/2603.16586)
- **Risk-Adjusted Harm Scoring for Automated Red Teaming for LLMs in Financial Services** — Fabrizio Dimino, Bhaskarjit Sarmah. Domain-aware harm-scoring weighting red-team findings by financial-regulatory risk rather than treating every jailbreak as equivalent. _Category:_ arXiv:2603.10807 — eval / red teaming. [arXiv](https://arxiv.org/abs/2603.10807)
- **Contrastive Reasoning Alignment: Reinforcement Learning from Hidden Representations (CRAFT)** — Luo, Wang. Aligns reasoning models against jailbreaks at the hidden-representation level; ~4.7% accuracy improvement on R1-Distill / Qwen3-Thinking with smaller safety-reasoning trade-off than output-level defenses. _Category:_ arXiv:2603.17305 — alignment / safety. [arXiv](https://arxiv.org/abs/2603.17305)
- **AgenticCyOps: Securing Multi-Agentic AI Integration in Enterprise Cyber Operations** — Mitra, Patel. Tool orchestration and memory management as the two dominant MAS attack surfaces; 72% reduction in exploitable trust boundaries. _Category:_ arXiv:2603.09134 — agent security. [arXiv](https://arxiv.org/abs/2603.09134)
