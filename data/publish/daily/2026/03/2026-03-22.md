## Research highlights

_Sunday — arXiv/HF Papers don't publish a Sunday daily; HF Papers `/date/2026-03-22` redirects to Friday 2026-03-20. Picks below are the strongest Friday-cohort items leaning toward MCP/agent-protocol and agent-evaluation, deduped against Saturday's backfill._

- **CUBE: A Standard for Unifying Agent Benchmarks** — Lacoste, Gontier. Universal protocol so any compliant agent benchmark plugs into any compliant runtime — built on MCP's non-blocking `tools/call` API. Removes the per-benchmark integration tax. _Category:_ arXiv:2603.15798 — agent benchmarks / MCP. [arXiv](https://arxiv.org/abs/2603.15798)
- **Memento-Skills: Let Agents Design Agents** — Zhou, Guo. Agent-design-by-agent loop where a meta-agent grows a skill library and stateful prompt scaffold without any LLM parameter updates. Concrete instantiation of "agents that build their own subagents." _Category:_ arXiv:2603.18743 — meta-agents. [arXiv](https://arxiv.org/abs/2603.18743)
- **AndroTMem: From Interaction Trajectories to Anchored Memory in Long-Horizon GUI Agents** — Shi, Li. Anchored State Memory represents long Android-GUI trajectories as causally linked intermediate-state anchors; 5–30% gains on long-horizon tasks. _Category:_ arXiv:2603.18429 — GUI agents / memory. [arXiv](https://arxiv.org/abs/2603.18429)
- **VTC-Bench: Evaluating Agentic Multimodal Models via Compositional Visual Tool Chaining** — Zhu, Dong. 32 OpenCV-based visual tools and 680 problems engineered to make multimodal agents _compose_ multiple tools rather than answer with a single call. Reveals even leading multimodal models fail at multi-step planning across tool boundaries. _Category:_ arXiv:2603.15030 — multimodal agents. [arXiv](https://arxiv.org/abs/2603.15030)
- **ProRL Agent: Rollout-as-a-Service for RL Training of Multi-Turn LLM Agents** — Zhang, Liu. Decouples rollout generation from RL training via API service, so trainers and environments scale and migrate independently. _Category:_ arXiv:2603.18815 — agent training infra. [arXiv](https://arxiv.org/abs/2603.18815)
- **Nemotron-Cascade 2: Post-Training LLMs with Cascade RL and Multi-Domain On-Policy Distillation** — Yang, Liu. Extends cascade RL across broader domains with multi-domain on-policy distillation; a 30B MoE reaches competition-level math/code reasoning. _Category:_ arXiv:2603.19220 — post-training. [arXiv](https://arxiv.org/abs/2603.19220)
- **Reasoning over mathematical objects: on-policy reward modeling and test time aggregation** — Aggarwal, Ghazvininejad. On-policy judge training plus test-time aggregation pushes models past numeric answers toward formal mathematical expressions. _Category:_ arXiv:2603.18886 — reasoning / reward modeling. [arXiv](https://arxiv.org/abs/2603.18886)
- **What Really Controls Temporal Reasoning in LLMs: Tokenisation or Representation of Time?** — Bhatia, Isa. Tokenisation fragmentation dominates temporal-reasoning failures in low-resource languages; representation effects matter more in high-resource ones. _Category:_ arXiv:2603.19017 — reasoning diagnostics. [arXiv](https://arxiv.org/abs/2603.19017)
