## Top papers
- **Beyond Semantic Similarity: Rethinking Retrieval for Agentic Search via Direct Corpus Interaction** — Li, Zhang, Wei, Lu. _Why notable:_ Argues vector-similarity retrieval is wrong primitive for agentic search; DCI pushes BrowseComp-Plus 69%→80% on Sonnet 4.6. [arXiv:2605.05242](https://arxiv.org/abs/2605.05242)
- **Storage Is Not Memory: A Retrieval-Centered Architecture for Agent Recall** — Adler, Zehavi. _Why notable:_ Six-layer SQLite-based agent memory; 93% on LoCoMo vs Mem0 61.4%. [arXiv:2605.04897](https://arxiv.org/abs/2605.04897)
- **STALE: Can LLM Agents Know When Their Memories Are No Longer Valid?** — anon. _Why notable:_ First benchmark for memory revision in long-running agents — exposes critical gap for production agent platforms. [arXiv:2605.06527](https://arxiv.org/abs/2605.06527)
- **Cited but Not Verified: Parsing and Evaluating Source Attribution in LLM Deep Research Agents** — anon. _Why notable:_ First systematic eval showing deep-research citations often cannot be verified; ships parser + verifier pipeline. [arXiv:2605.06635](https://arxiv.org/abs/2605.06635)
- **Securing the Model Context Protocol (MCP): Risks, Controls, and Governance** — anon. _Why notable:_ Most concrete MCP-security paper to date — threat model + control set for MCP server ecosystems. [arXiv:2511.20920](https://arxiv.org/abs/2511.20920)
- **Coordination as an Architectural Layer for LLM-Based Multi-Agent Systems** — Nechepurenko, Shuvalov. _Why notable:_ 41-87% production failure rate in multi-agent LLM systems is coordination, not model. [arXiv:2605.03310](https://arxiv.org/abs/2605.03310)
- **Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces** — anon. _Why notable:_ Formalizes "orchestration traces" as the unit RL should optimize for multi-agent LLMs. [arXiv:2605.02801](https://arxiv.org/abs/2605.02801)
- **Governed Collaborative Memory as Artificial Selection in Multi-Agent Systems** — Cuadros et al. _Why notable:_ Treats persistent multi-agent memory as a selection problem with constitutional / metric / human-ratified regimes. [arXiv:2605.04264](https://arxiv.org/abs/2605.04264)
- **RAG over Thinking Traces Can Improve Reasoning Tasks** — Arabzadeh, Ma, Min, Zaharia. _Why notable:_ Retrieving solution traces (not documents) lifts AIME +56% on Gemini-2.5-Flash; GPQA-Diamond +7.6% on GPT-5. [arXiv:2605.03344](https://arxiv.org/abs/2605.03344)
- **MASPO: Joint Prompt Optimization for LLM-based Multi-Agent Systems** — anon. _Why notable:_ Optimizes role prompts across entire MAS jointly rather than per-role; notable gains over per-agent tuning. [arXiv:2605.06623](https://arxiv.org/abs/2605.06623)
