## The week in 90 seconds

**Anthropic starts the IPO clock as Microsoft and OpenAI reduce the whole race to one fight: the coding agent**

The week opened with the frontier labs walking toward the public markets and the platform giants drawing battle lines under them. Two days in, the story isn't a single launch — it's money and control hardening into structure: who lists first, who owns the agent layer, and how much it now costs to run one.

The lead story is financial. Anthropic confidentially filed a draft S-1 with the SEC on June 1, becoming the first frontier lab to formally start the IPO clock — just days after closing a $65B Series H at a $965B post-money valuation, up from $380B in February. The confidential filing keeps the prospectus private for roughly 60 to 90 days, pointing to a public document in late summer, with OpenAI reported only weeks behind and eyeing a September listing above $1T. This is the first genuine public-market test of whether frontier-lab revenue and margins can justify near-trillion-dollar valuations, and Hacker News read it that way: sentiment hardened from last week's AI-fatigue into outright bubble skepticism, with the Economist's "can the stockmarket swallow Anthropic, SpaceX and OpenAI?" drawing 618 points and 1,070 comments, running alongside the S-1 thread and Michael Burry's trillion-dollar pushback.

Underneath the listings, the platform fight narrowed to a single battlefield. At Build 2026 Microsoft cut its OpenAI cord — Project Polaris, Microsoft's own coding model on its Maia 200 silicon, replaces GPT-4 Turbo as the default GitHub Copilot engine for every subscriber by August. Around it Microsoft open-sourced the Windows Agent Framework 1.0 under MIT, previewed Azure Agent Mesh to federate agents across clouds under one Entra and Purview governance layer, and made Agent Mode the Office 365 Copilot default. OpenAI answered the same afternoon with GPT-5.3-Codex, folding the Codex and GPT-5 stacks into one model about 25% faster that sustains long multi-step tool use and posts new highs on SWE-Bench Pro and Terminal-Bench. The frontier-lab-versus-platform contest is now a coding-agent contest, and both sides escalated within hours.

The third thread is the bill. The all-you-can-eat AI-coding subscription died on June 1 as GitHub Copilot moved every plan to metered "AI Credits" — completions stay unlimited, but agentic sessions now bill by consumption, the clearest sign yet that inference cost is forcing the category onto usage-based pricing. In parallel the enterprise turned agent access into a tollbooth: SAP blocks external agents and routes them through Joule, Salesforce goes MCP-first open, ServiceNow, SAP and Workday meter agent operations, and Snowflake Summit staked out the governed-data plane with Cortex Sense, Cortex Training and Horizon Catalog. Two governance frontiers also surfaced inside 48 hours — PromptArmor's working ChatGPT-for-Sheets exfiltration exploit topped HN on Monday, while the FT reported DeepMind, Anthropic and Meta are now formally staffing machine-consciousness and AI-welfare research. With only two of seven daily files in, net-new model releases beyond Polaris and Codex have been quiet; watch whether the rest of the week brings capability news or stays a story about capital and control.

**Read this first:** [The frontier labs go public — Anthropic files first](../../daily/2026/06/2026-06-01.md) — the one item that reframes the whole week, turning the financing race into an IPO race.

## Top papers
- **Detecting Is Not Resolving: The Monitoring–Control Gap in Retrieval-Augmented LLMs** (arXiv:2605.27157) — _why notable:_ argues RAG monitoring detects errors but rarely resolves them, quantifying the control gap in retrieval pipelines; the most directly useful production-RAG read of the week so far. [arxiv.org/abs/2605.27157](https://arxiv.org/abs/2605.27157)
- **The Attribution Blind Spot: Detecting When LLMs Rely on Memory Rather Than Retrieved Context** (arXiv:2605.26778) — _why notable:_ a faithfulness diagnostic for whether a RAG model actually used retrieved context vs. parametric memory. [arxiv.org/abs/2605.26778](https://arxiv.org/abs/2605.26778)
- **CAR: Query-Guided Confidence-Aware Reranking for RAG** (arXiv:2605.04495) — _why notable:_ reranks retrieved passages by query-conditioned confidence rather than raw similarity, tightening the context window fed to the generator. [arxiv.org/abs/2605.04495](https://arxiv.org/abs/2605.04495)
- **MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation** (arXiv:2605.27366) — _why notable:_ an agent framework that autonomously creates, stores, manages and evaluates its own reusable skills — a concrete take on self-improving agent memory. [arxiv.org/abs/2605.27366](https://arxiv.org/abs/2605.27366)
- **MemFail: Stress-Testing Failure Modes of LLM Memory Systems** (arXiv:2605.26667) — _why notable:_ a stress-test benchmark exposing how and when LLM memory subsystems break — useful for agent eval/observability. [arxiv.org/abs/2605.26667](https://arxiv.org/abs/2605.26667)
- **From Parameter Dynamics to Risk Scoring: Quantifying Sample-Level Safety Degradation in LLM Fine-tuning** (arXiv:2605.04572) — _why notable:_ traces how individual fine-tuning samples erode safety alignment and proposes a per-sample risk score to flag offenders before they degrade the model (ICML 2026). [arxiv.org/abs/2605.04572](https://arxiv.org/abs/2605.04572)
- **A Queueing-Theoretic Framework for Stability Analysis of LLM Inference with KV Cache Memory Constraints** (arXiv:2605.04595) — _why notable:_ models LLM serving as a queueing system to derive stability conditions under KV-cache limits — practical inference-platform capacity planning. [arxiv.org/abs/2605.04595](https://arxiv.org/abs/2605.04595)
- **How Many Tools Should an LLM Agent See? A Chance-Corrected Answer** (arXiv:2605.24660) — _why notable:_ empirical study on tool-registry size vs. agent performance, with a chance-corrected metric. [arxiv.org/abs/2605.24660](https://arxiv.org/abs/2605.24660)
- **Position: AI Safety Requires Effective Controllability** (arXiv:2605.27117) — _why notable:_ argues controllability, not just alignment, is the core safety requirement for capable agents. [arxiv.org/abs/2605.27117](https://arxiv.org/abs/2605.27117)
- **ARIS: Autonomous Research via Adversarial Multi-Agent Collaboration** (arXiv:2605.03042) — _why notable:_ a multi-agent autonomous-research system using structured adversarial debate, self-healing execution and verifiable reporting (SJTU). [arxiv.org/abs/2605.03042](https://arxiv.org/abs/2605.03042)
