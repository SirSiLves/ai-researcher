## The week in 90 seconds

**Anthropic files the first frontier-lab S-1 as the bubble debate roars and Microsoft cuts the OpenAI cord**

The week the AI industry started talking about going public is also the week it started arguing, loudly, about whether anyone should buy in. Anthropic filed first; Microsoft declared model independence; and the whole AI-coding business quietly switched from a subscription to a taxi meter. Three days in, the story of W23 is the collision between trillion-dollar ambition and trillion-dollar doubt.

The defining move came Monday, when Anthropic confidentially filed a draft S-1 with the SEC — the first frontier lab to start the IPO clock. It landed days after the company closed a $65B Series H near a $965B valuation, roughly tripling February's $380B mark on a reported $47B revenue run-rate, and reordering the lab hierarchy above OpenAI, which is said to be weeks behind with a September listing targeted over $1T. By Wednesday Anthropic had bolted revenue scaffolding onto the prospectus with a three-tier Claude Partner Network: 40,000-plus firms applied and 10,000-plus consultants certified since March. But the filing also became a lightning rod. The Economist's "Can the stockmarket swallow Anthropic, SpaceX and OpenAI?" climbed from 618 to 700 points on Hacker News across the week, and Michael Burry's trillion-dollar doubts ran right alongside it — making bubble skepticism the dominant developer-and-investor conversation every single day so far.

Underneath the capital drama, the platform map redrew itself. At Build 2026 on Tuesday, Microsoft cut its OpenAI dependence from both ends at once: Project Polaris, its own coding model running on in-house Maia 200 silicon, will replace GPT-4 Turbo as the default GitHub Copilot engine for all subscribers by August, wrapped in a full agent stack — Windows Agent Framework 1.0 open-sourced under MIT, the multi-cloud Azure Agent Mesh, Office Copilot Agent Mode on by default, and a roughly $9.69B Pentagon deal. OpenAI answered within hours with GPT-5.3-Codex, then by Wednesday took its frontier models and Codex GA onto AWS Bedrock. The frontier-lab-versus-platform fight has narrowed to a single battlefield — the coding agent — and both sides escalated in real time.

The third thread is structural and arrives as a bill. The enterprise-agent layer split into open versus toll: ServiceNow opened its full system of action to any agent through a GA MCP server (Action Fabric), while SAP blocked external agents and routed everything through its own Joule layer; Snowflake Summit staked the governed-data plane with Claude as its foundational model. ServiceNow, SAP and Workday are now metering agent access outright — and on the developer side, GitHub Copilot moved every plan to usage-based "AI Credits" (1¢ each) on June 1, ending the flat-rate AI-coding subscription. Whoever owns your system-of-record data now decides which agent stack you may use, and charges you for it. Two more shifts frame the quarter: NVIDIA posted a record $81.6B quarter (+85% YoY) with a Vera Rubin platform promising up to 10× cheaper inference — the supply-side argument that makes these valuations conceivable — while the EU's Digital Omnibus deferred high-risk AI Act obligations 16 months to December 2027, resetting the compliance clock just as deployment accelerates.

## Top papers
- **[Capability Advertisement as a Market for Lemons: A Trust Layer for Heterogeneous Agent Networks](https://arxiv.org/abs/2606.03034)** — Gaurav Naresh Mittal. _why notable:_ argues MCP/A2A registries naively treat advertised agent capabilities as static and truthful, creating adverse selection — the sharpest theoretical counterpoint to this week's "just open the MCP server" enterprise enthusiasm.
- **[OpenAgenet/OAN: Open Infrastructure for Trusted Agent Interconnection](https://arxiv.org/abs/2606.03161)** — Jinliang Xu. _why notable:_ a protocol-neutral trust layer (identity provenance, governance state, discovery authorization, freshness checks) for open multi-operator agent networks; companion architecture paper [2606.03163](https://arxiv.org/abs/2606.03163).
- **[Economy of Minds: Emerging Multi-Agent Intelligence with Economic Interactions](https://arxiv.org/abs/2606.02859)** — Zhenting Qi et al. _why notable:_ a Hayek-inspired agent economy where agents bid in auctions for the right to act, inducing decentralized credit assignment without global orchestration.
- **[What Benchmarks Don't Measure: Evaluating Abstention Competence in Autonomous Agents](https://arxiv.org/abs/2606.02965)** — Victor Ojewale, Suresh Venkatasubramanian. _why notable:_ names "compliance bias" — RLHF-trained agents structurally proceed even without sufficient authorization; argues evals must measure whether an agent *should* have acted at all.
- **[When Helping Hurts: Multi-Agent Debate for Data Cleaning](https://arxiv.org/abs/2606.02866)** — Chirag Parmar et al. _why notable:_ across 6,000+ conditions, debate's sign reverses — degrading generation (−1.6 to −15.5pp) via "critique-induced confusion" while improving error detection; a useful corrective to multi-agent-debate hype.
- **[Detecting Is Not Resolving: The Monitoring–Control Gap in Retrieval-Augmented LLMs](https://arxiv.org/abs/2605.27157)** — _why notable:_ RAG monitoring detects errors but rarely resolves them, quantifying the control gap in retrieval pipelines — the week's most directly useful RAG-in-production read.
- **[The Attribution Blind Spot: Detecting When LLMs Rely on Memory Rather Than Retrieved Context](https://arxiv.org/abs/2605.26778)** — _why notable:_ a faithfulness diagnostic for whether a RAG model actually used retrieved context vs. parametric memory.
- **[Adaptive Latent Agentic Reasoning (ALAR)](https://arxiv.org/abs/2606.02871)** — Dongwon Jung et al. _why notable:_ compact latent reasoning for routine agent turns, escalating to explicit chain-of-thought only when needed, cutting multi-turn reasoning overhead.
- **[Thinking Past the Answer: Harmful Overthinking in Large Reasoning Models](https://arxiv.org/abs/2606.02835)** — Simone Caldarella et al. _why notable:_ challenges "longer reasoning is always better" — once an LRM reaches the right answer, extra reasoning can degrade it.
- **[MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation](https://arxiv.org/abs/2605.27366)** — _why notable:_ an agent framework that autonomously creates, stores, manages and evaluates its own reusable skills; a concrete take on self-improving agent memory.
