## Top papers
- **FORGE: Self-Evolving Agent Memory With No Weight Updates via Population Broadcast** — Bogdanov, Lung, Kunz, Gao, Taylor, Zaman. _Why notable:_ Population-based protocol that evolves prompt-injected natural-language memory for hierarchical ReAct agents — failed trajectories become reusable rules, best-performing instance's memory is broadcast, converged instances freeze. Concrete blueprint for self-improving agents without touching weights. [arXiv:2605.16233](https://arxiv.org/abs/2605.16233)
- **Differentiable Mixture-of-Agents Incentivizes Swarm Intelligence of LLMs** — Wu, Lu, Yan et al. _Why notable:_ Replaces hand-wired multi-agent topologies with a differentiable, context-aware router that dynamically activates agents at each reasoning step — implicitly simulating diverse communication graphs without static workflows. Directly relevant to agent orchestration design. [arXiv:2605.15706](https://arxiv.org/abs/2605.15706)
- **Agentic Discovery of Neural Architectures: AIRA-Compose and AIRA-Design** — Pepe, Lin, Magka et al. _Why notable:_ LLM agents autonomously design foundation-model architectures beyond Transformers — produces 14 AIRAformer/AIRAhybrid (Transformer-Mamba) variants that beat Llama 3.2 at 1B/3B and find more compute-efficient frontiers. Tangible recursive self-improvement evidence. [arXiv:2605.15871](https://arxiv.org/abs/2605.15871)
- **Argus: Evidence Assembly for Scalable Deep Research Agents** — Zhang, Su, Chen et al. _Why notable:_ Treats deep research as jigsaw assembly: Searcher gathers evidence per sub-query, Navigator maintains a shared evidence graph and identifies missing pieces. Avoids parallel-ReAct duplication; useful pattern for production research agents. [arXiv:2605.16217](https://arxiv.org/abs/2605.16217)
- **ICRL: Learning to Internalize Self-Critique with Reinforcement Learning** — Lin, Yu, Xin et al. _Why notable:_ Jointly trains solver + critic from a shared backbone; critic is rewarded by the solver's subsequent improvement. Practical recipe for closing the guided-vs-unguided LLM performance gap. [arXiv:2605.15224](https://arxiv.org/abs/2605.15224)
- **STS: Efficient Sparse Attention with Speculative Token Sparsity** — _Why notable:_ Reuses the draft model's attention scores from speculative decoding to build a sparsity mask for the target LLM — 2.67× speedup at ~90% sparsity, no retraining. Particularly relevant for multi-million-token agentic inference. [arXiv:2605.15508](https://arxiv.org/abs/2605.15508)
- **Towards Generalization of Block Attention via Automatic Segmentation and Block Distillation** — _Why notable:_ Learned semantic segmenter (30k-instance SemanticSeg dataset, 2k–32k texts across 16 categories) plus block distillation, making block attention practical for KV-cache reuse in long-context retrieval pipelines. [arXiv:2605.15913](https://arxiv.org/abs/2605.15913)
- **Judge Circuits** — Feldhus, Baeumel, Golimblevskaia et al. _Why notable:_ Mechanistically locates a shared "Latent Evaluator" sub-graph in mid-to-late MLPs of Gemma-3 / Qwen2.5 / Llama-3 that drives LLM-as-judge scores; zero-ablating it collapses judgment while preserving world knowledge. First mechanistic-interpretability paper to surface in the daily — explains format-induced inconsistency in LLM eval at the circuit level. [arXiv:2605.16023](https://arxiv.org/abs/2605.16023)
