## The week in 90 seconds

**The week the harness became the product, MCP got its number, and Anthropic leaked the next model.**

W13 is the week the agent stack stopped being a loose collection of vendor demos and started behaving like infrastructure. Three threads ran in parallel from Monday to Sunday: Anthropic published the canonical architecture for long-running coding agents on the same morning the LiteLLM supply chain was compromised; MCP got the install figure that anchors every enterprise pitch behind it; and a CMS misconfiguration on Thursday let Fortune name a draft Anthropic model called Mythos described as a step change above Opus, with explicit "unprecedented cybersecurity risks" framing that repriced listed cybersecurity stocks intraday on Friday.

The lead story is Mythos. On Thursday 2026-03-26 Fortune broke that researchers Roy Paz at LayerX and Alexandre Pauwels at Cambridge had found roughly 3,000 unpublished assets sitting in an unsecured Anthropic CMS, including a draft blog naming a tier above Opus on coding, academic reasoning, and cybersecurity. Anthropic confirmed "human error." By Friday the market had absorbed enough of the cybersecurity-capability gap implied by the draft to move stocks before any official announcement, and Anthropic's reported October-2026 IPO listing window surfaced in the same news cycle. The story carried into Saturday's international pickup wave on NewsGhana and Techzine, and it pre-stages two further Anthropic packaging mistakes that follow inside two weeks: the Claude FreeBSD kernel-RCE story on 1 April and the Claude Code source-code leak via a missing .npmignore on 31 March. It is the first model in 2026 to move listed-company equity values before announcement.

The counterweight underneath the headline is the harness story. Monday 2026-03-23 Anthropic Labs engineer Prithvi Rajasekaran published "Harness design for long-running application development," a three-agent planner/generator/evaluator architecture with a separate initializer prompt and a companion GitHub repo at anthropics/cwc-long-running-agents. Rick Hightower's runnable practitioner walk-through, Addy Osmani and Anup's essays, and the Hacker News thread landed within hours; by Friday TLDR Dev was using planner/generator/evaluator as week-defining vocabulary attributed to Cursor, Cognition, and Replit. Sunday's "March changed AI" framing on Digital Applied and Peterson Tech named "the harness, not the model, is the product" as the durable theme. The first product expression follows in W14 as Cursor 3's Agents Window. For the rest of the year, every coding-agent vendor gets read against this reference architecture, and the harness-versus-model decomposition that underpins Claude Managed Agents now has its first-party public documentation.

The third thread is agent-stack security crossing from theoretical to acute. Tuesday 2026-03-24, LiteLLM 1.82.7 and 1.82.8 shipped a base64 credential stealer hidden in a litellm_init.pth file that runs on install with no import required, exfiltrating SSH and AWS keys, crypto wallet directories, and shell history. Anthropic shipped Auto mode for Claude Code the same day, a Sonnet 4.6 classifier-based tool-call gating layer that, as Simon Willison noted in the same-day juxtaposition, would not have stopped the LiteLLM attack. Wednesday brought the FutureSearch BigQuery PyPI blast-radius data: 46,996 downloads in 46 minutes, with 88% of 2,337 dependents un-pinned. That same Wednesday Anthropic published the MCP install figure, 97 million monthly SDK installs against roughly two million at the November 2024 launch, anchoring every enterprise MCP pitch through Q2 including AWS GA, Slack, Jama Connect, and ServiceNow Action Fabric. Sunday's paper cohort closed the loop with hard data: the AIP paper scanned roughly 2,000 MCP servers and found zero with authentication, alongside AgentRFC's first systematic security framework for MCP, A2A, ANP and ACP, Aegis on cryptographic runtime governance, and the Mind-the-Gap legal-framework critique. MCP is now decisively the dominant agent-tool protocol — and the protocol everyone is going to have to retrofit auth onto.

The body adds a few facts the lead does not pad. Mistral shipped Voxtral TTS open-weights on Thursday at 4B parameters, nine languages, three-second voice cloning, roughly 0.016 dollars per thousand characters and CC-BY-NC-4.0 on Hugging Face — about an order of magnitude under ElevenLabs at parity quality, and the most consequential European-sovereign voice stack of the year so far. Liquid AI LFM2.5-350M on Saturday made the sub-1B agent specialist a category. Atlassian's 1,600-headcount cut (10% of staff, explicitly tied to AI development and enterprise sales) became the template Cloudflare copied six weeks later. OpenAI retired Sora on cost grounds, the first explicit consumer-AI product retirement against a falling base.

**Read this first:** [Harness design for long-running application development](https://www.anthropic.com/engineering/harness-design-long-running-apps) by Prithvi Rajasekaran — the week's reference architecture and the one read that explains why every coding-agent product from April onwards looks the way it does.

## Top papers
- **AIP: Agent Identity Protocol for Verifiable Delegation Across MCP and A2A** — Sunil Prakash. _Why notable:_ Invocation-Bound Capability Tokens (JWT + chained Biscuit); scanned ~2,000 MCP servers and found zero with authentication. [arXiv:2603.24775](https://arxiv.org/abs/2603.24775)
- **AgentRFC: Security Design Principles and Conformance Testing for Agent Protocols** — Shenghan Zheng, Qifan Zhang. _Why notable:_ First systematic security framework for MCP/A2A/ANP/ACP with formal architectural model. [arXiv:2603.23801](https://arxiv.org/abs/2603.23801)
- **Hyperagents** — Jenny Zhang, Bingchen Zhao, Wannan Yang, Jakob Foerster. _Why notable:_ Agents as compositional functions over other agents; meta-agent architecture beyond ReAct loops. [arXiv:2603.19461](https://arxiv.org/abs/2603.19461)
- **The Y-Combinator for LLMs: Solving Long-Context Rot with λ-Calculus** — Amartya Roy et al. _Why notable:_ Long-context degradation as a fixed-point problem; recursion-based mitigation. [arXiv:2603.20105](https://arxiv.org/abs/2603.20105)
- **OpenResearcher: A Fully Open Pipeline for Long-Horizon Deep Research Trajectory Synthesis** — Zhuofeng Li et al. _Why notable:_ Open trajectory pipeline behind a competitive deep-research agent. [arXiv:2603.20278](https://arxiv.org/abs/2603.20278)
- **SlopCodeBench: How Coding Agents Degrade Over Long-Horizon Iterative Tasks** — Gabriel Orlanski, Devjeet Roy. _Why notable:_ First benchmark explicitly measuring agent-driven code-quality erosion across sequential extensions. [arXiv:2603.24755](https://arxiv.org/abs/2603.24755)
- **AVO: Agentic Variation Operators for Autonomous Evolutionary Search** — Terry Chen et al. _Why notable:_ Discovered attention kernels outperforming cuDNN and FlashAttention — agentic search beats expert systems code. [arXiv:2603.24517](https://arxiv.org/abs/2603.24517)
- **FinMCP-Bench: Benchmarking LLM Agents for Real-World Financial Tool Use under MCP** — Jie Zhu, Yimin Tian. _Why notable:_ 613 samples × 33 scenarios × 65 real MCP servers; first finance-vertical eval explicitly built around MCP. [arXiv:2603.24943](https://arxiv.org/abs/2603.24943)
- **Mind the Gap: How the Technical Mechanisms of Agentic AI Outpace Global Legal Frameworks** — Marcel Osmond, Thomas Jego. _Why notable:_ Statutes conflate model capability with system architecture and miss the actual control points. [arXiv:2603.27075](https://arxiv.org/abs/2603.27075)
- **CUA-Suite: Massive Human-annotated Video Demonstrations for Computer-Use Agents** — Xiangru Jian et al. _Why notable:_ Largest open trajectory corpus for CUAs; addresses the data bottleneck. [arXiv:2603.24440](https://arxiv.org/abs/2603.24440)
