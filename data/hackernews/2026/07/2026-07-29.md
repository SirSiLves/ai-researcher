**[Kimi K3 Architecture Overview and Notes](https://sebastianraschka.com/blog/2026/kimi-k3-architecture-notes.html)** — 489 pts · 104 comments · 26 hours ago · `sebastianraschka.com` · [HN discussion](https://news.ycombinator.com/item?id=49085698)

_What this is:_ Sebastian Raschka's architecture teardown. K3 is essentially Kimi Linear scaled 48B → 2.8T, plus LatentMoE (as in Nemotron 3 Ultra). Everything else is inference-efficiency substitution: MoE → LatentMoE, attention → MLA + Kimi Delta Attention. The one non-efficiency change is attention residuals (+4% training, +2% inference cost). All RoPE layers dropped for NoPE everywhere — the first frontier-scale model to do so.

_Comment signal:_
- @Ilaurens: baffled that NoPE-everywhere works at all — "doesn't it just become a token soup?"
- @Giho: KDA's state update `St = St−1 + βt(vt − St−1 kt)ktᵀ` is literally a single-sample MSE gradient step, which puts it close to a model that learns at inference time.
- @augment_me: reads the Kimi team as the best curators in the industry — skipping the expensive, empirically-uncertain mHC in favour of simpler residuals — but doubts Linear Attention over DSA as inherently lossy.
- _Notable critique:_ @mickael-kerjean asks the reproducibility question nobody answered: are these papers implementable, or PDF/PSD-style "open specs" with the crucial details omitted?
