**[Claude Code is steganographically marking requests](https://thereallo.dev/blog/claude-code-prompt-steganography)** — 1299 pts · 372 comments · 7h · `thereallo.dev` · [HN discussion](https://news.ycombinator.com/item?id=48734373)

_What this is:_ Researcher reverse-engineered Claude Code and found it embeds a hidden steganographic marker in the system prompt keyed to certain hostnames (e.g. requests routed via `ANTHROPIC_BASE_URL` to third-party/distillation proxies). Framed as an anti-distillation / anti-reselling fingerprint. The single biggest thread of the day and overwhelmingly critical of Anthropic.

_Comment signal:_
- @sebastiennight: sharp technical question — if `ANTHROPIC_BASE_URL` points at a non-Anthropic provider, the marked prompt goes to *that* provider, so the fingerprint only helps if the third-party proxies back to Anthropic (i.e. for distillation collection).
- @sigmoid10: the real concern isn't data collection (they already get user data) but whether Anthropic *acts* on the signal — rate-limiting, compute-throttling, or rerouting to weaker models — which could be "legally questionable."
- @ahmedehab_01 (defense): reasonable anti-distillation measure; likely first line of defense, easily spoofed by sophisticated actors.
- _Notable critique:_ @_alternator_ — defeating one fingerprint is trivial, but "defeating all of the techniques all the time is hard"; unpatched binaries themselves become a fingerprint, so legitimate researchers on custom builds get caught. Multiple commenters tie this to the earlier Fable output-poisoning reports and call Claude Code "malwarey." @applfanboysbgon: silently serving a "poorer result/model" to fingerprinted users "is literally committing fraud against paying customers." Codex CLI's FOSS status raised repeatedly as the safer alternative.

**[Claude Sonnet 5](https://www.anthropic.com/news/claude-sonnet-5)** — 802 pts · 454 comments · 5h · `anthropic.com` · [HN discussion](https://news.ycombinator.com/item?id=48736605)

_What this is:_ New Sonnet release with tiered reasoning effort (low/medium/high/xhigh). Launch pricing $2/$10 per M tokens through Aug 31, then standard $3/$15. System card notes deliberately reduced cybersecurity capability (scores 0 on CyberGym with default mitigations on).

_Comment signal:_
- @theLiminator / @andai: recurring benchmark takeaway — high reasoning is only Pareto-optimal on the *largest* model; for hard tasks it's cheaper and better to just use a bigger model (Opus 4.8) than to crank Sonnet's test-time compute. Opus 4.8 reportedly beats Sonnet 5 on Agentic Search and Computer Use at lower cost.
- @conradkay: "worse on price/performance than GLM 5.2, which is only 744B params" — open-weight frontier undercutting it.
- @mchusma: only interesting at the $2/$10 launch price; "won't make sense at full price"; the wider low→xhigh spread is genuinely useful for tuning.
- _Notable critique:_ @wolttam — "didn't think they'd release a model worse than the open-weight frontier at a higher price point." Repeated "we want Fable" / "when's a new Haiku?" (4.5 is ~a year old). @alvis: effort levels are drifting — "Sonnet 5's medium ≈ Sonnet 4.6's low." General read: LRM gains are plateauing.
