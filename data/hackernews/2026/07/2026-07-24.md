**[Show HN: Needle: We Distilled Gemini Tool Calling into a 26M Model](https://github.com/cactus-compute/needle)** — 667 pts · 188 comments · 1d · `github.com/cactus-compute` · [HN discussion](https://news.ycombinator.com/item?id=48111896)

_What this is:_ Cactus open-sourced Needle, a 26M-parameter function-calling (tool-use) model that runs ~6000 tok/s prefill / 1200 tok/s decode on consumer devices (phones, watches, glasses). Architecture is "Simple Attention Networks" — attention + gating, no MLP/FFN layers — on the thesis that tool calling is retrieval-and-assembly, not reasoning. MIT-licensed; pretrained on 200B tokens (16 TPU v6e, 27h); claims wins over FunctionGemma-270M, Qwen-0.6B, Granite-350M, LFM2.5-350M on single-shot function calling.

_Comment signal:_
- @simonw (top): "publish a live demo of the needle playground... small enough it should be pretty cheap to run this on a little VPS."
- _Notable:_ author argues the "no-FFN" finding generalizes to any task with external structured knowledge (RAG / tool use) — "the model doesn't need to memorize facts in FFN weights if the facts are provided in the input."
