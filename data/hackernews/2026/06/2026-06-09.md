_What this is:_ Cactus open-sourced a 26M-parameter function-calling model that runs at ~6000 tok/s prefill / 1200 tok/s decode on consumer devices (phones, watches, glasses). Architecture is pure attention + gating with no MLP/FFN layers — the claim is that tool calling is retrieval-and-assembly, not reasoning, so FFN params are wasted. MIT-licensed weights on Hugging Face.

_Comment signal:_

- _Notable claim from author:_ the "no FFN" finding generalizes beyond function calling to any task where structured knowledge is supplied in-context (RAG, tool use), since the model needn't memorize facts in weights.
