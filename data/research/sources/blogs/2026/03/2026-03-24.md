## Long-form picks

- **Malicious litellm_init.pth in litellm 1.82.8 — credential stealer** — BerriAI / via Simon Willison. _Takeaway:_ A supply-chain compromise of LiteLLM (1.82.7 and 1.82.8 on PyPI) shipped a base64 credential stealer in a `.pth` file — so even installing without importing was enough to run it. Stole everything from `~/.ssh/` and `~/.aws/` to crypto wallet directories and shell history. Likely chained off a recent Trivy CI compromise. [https://simonwillison.net/2026/Mar/24/malicious-litellm/](https://simonwillison.net/2026/Mar/24/malicious-litellm/)
- **Package Managers Need to Cool Down** — Andrew Nesbitt, via Simon Willison. _Takeaway:_ Tour of dependency-cooldown features that landed across pnpm 10.16, Yarn 4.10, Bun 1.3, Deno 2.6, uv 0.9.17, pip 26.0/26.1 and npm 11.10.0 — a six-month industry shift toward delaying new releases before installation. Companion piece to the LiteLLM news. [https://nesbitt.io/2026/03/04/package-managers-need-to-cool-down.html](https://nesbitt.io/2026/03/04/package-managers-need-to-cool-down.html)
- **Auto mode for Claude Code** — Anthropic, via Simon Willison. _Takeaway:_ New permissions mode where a Sonnet 4.6 classifier model gates each tool call against an extensive default allow/soft-deny ruleset (test artifacts, local ops, read-only ops, declared deps; force-push, default-branch push, curl|bash, cloud mass-delete). Simon: still prefers deterministic sandboxes — AI-based prompt-injection defenses are non-deterministic by nature, and `pip install -r` in the allow list wouldn't have stopped today's LiteLLM attack. [https://simonwillison.net/2026/Mar/24/auto-mode-for-claude-code/](https://simonwillison.net/2026/Mar/24/auto-mode-for-claude-code/)
- **Streaming experts: Qwen3.5-397B and Kimi K2.5 running locally** — Simon Willison. _Takeaway:_ Follow-up to Mar 18: in five days Dan Woods went from 397B-MoE-in-48GB to @seikixtc running 1T-parameter Kimi K2.5 in 96GB on an M2 Max, plus an iOS port at 0.6 tok/s. Autoresearch loops are still finding optimizations. [https://simonwillison.net/2026/Mar/24/streaming-experts/](https://simonwillison.net/2026/Mar/24/streaming-experts/)

- **Materials science as the unsung hero of the science world** — Latent Space podcast (ep. 186). _Takeaway:_ Episode argues materials science — decades-long iteration cycles, painstaking property tuning — is the chokepoint that AI for science most needs to compress. Sets up why agentic-research benchmarks like PostTrainBench matter. [https://www.latent.space/podcast](https://www.latent.space/podcast)
