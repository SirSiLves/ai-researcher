# AI Papers — 2026-05-01

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Position: Safety and Fairness in Agentic AI Depend on Interaction Topology, Not on Model Scale or Alignment** — Tanav Singh Bajaj, Nikhil Singh. _Takeaway:_ Position paper arguing that in deliberative or vote-aggregating multi-agent setups, three failure modes — ordering instability, information cascades, and functional collapse — emerge from the structure of information flow rather than from individual model alignment or scale. Reframes the agentic-safety conversation away from per-model evals toward topology-level properties; pairs naturally with the `agent-governance` and `multi-agent-safety` radar threads. _Category:_ arXiv:2605.01147 (cs.MA/cs.AI). [https://arxiv.org/abs/2605.01147](https://arxiv.org/abs/2605.01147)

- **"I Don't Know" — Towards Appropriate Trust with Certainty-Aware Retrieval Augmented Generation** — Daan Di Scala, Maaike de Boer. _Takeaway:_ CERTA wires uncertainty signals from question-context-answer relevance into a RAG pipeline so the system can refuse rather than over-agree. Reduces over-confident answers and produces cautious behavior on moral or ambiguous prompts — concrete primitive for the `appropriate-trust` and `RAG-safety` lines. _Category:_ arXiv:2605.00957 (cs.CL). [https://arxiv.org/abs/2605.00957](https://arxiv.org/abs/2605.00957)

- **MemRouter: Memory-as-Embedding Routing for Long-Term Conversational Agents** — Tianyu Hu, Weikai Lin. _Takeaway:_ Encodes each turn with recent context, projects through a frozen LLM backbone, and uses lightweight 12M-parameter classification heads to decide what to commit to long-term memory — sidestepping the prompted-LLM "should I remember this?" pattern that dominates current memory layers. Concrete plumbing-level move for the agent-memory subfield. _Category:_ arXiv:2605.00356 (cs.CL). [https://arxiv.org/abs/2605.00356](https://arxiv.org/abs/2605.00356)

- **Effect-Transparent Governance for AI Workflow Architectures: Semantic Preservation, Expressive Minimality, and Decidability Boundaries** — Alan L. McCann (sole author). _Takeaway:_ Formalizes governance over AI workflow architectures as a semantics-preserving operator that mediates memory access, external calls, and oracle queries. Proves effect-level governance can be enforced without reducing computational expressivity, and maps decidability boundaries — useful theoretical scaffold for governance-graph work and the AI-platform compliance stack. _Category:_ arXiv:2605.01030 (cs.AI). [https://arxiv.org/abs/2605.01030](https://arxiv.org/abs/2605.01030)

- **Governing What the EU AI Act Excludes: Accountability for Autonomous AI Agents in Smart City Critical Infrastructure** — Talal Ashraf Butt, Muhammad Iqbal. _Takeaway:_ Introduces AgentGov-SC, a three-layer governance architecture with 25 measures traceable to the EU AI Act, ISO/IEC 42001, and the NIST AI RMF, targeted at autonomous-agent deployments in smart-city critical infrastructure that fall outside the AI Act's scope. Useful concrete bridge from policy text to enforceable controls — direct input to the governance/policy thread. _Category:_ arXiv:2605.01091 (cs.AI). [https://arxiv.org/abs/2605.01091](https://arxiv.org/abs/2605.01091)

- **FinSafetyBench: Evaluating LLM Safety in Real-World Financial Scenarios** — Yutao Hou, Yihan Jiang. _Takeaway:_ Bilingual (English-Chinese) red-teaming benchmark of LLM refusal behavior under financial-compliance-violating requests. Vertical-grounded safety eval that goes past generic harm taxonomies to map concrete regulatory failure modes — relevant to both the `agent-safety` and `compliance` radar lines. _Category:_ arXiv:2605.00706 (cs.CL). [https://arxiv.org/abs/2605.00706](https://arxiv.org/abs/2605.00706)

- **SAGA: Workflow-Atomic Scheduling for AI Agent Inference on GPU Clusters** — Dongxin Guo, Jikun Wu. _Takeaway:_ Schedules entire agent workflows as atomic units rather than independent per-step inference calls. Reports 1.64x faster task completion on a 64-GPU cluster serving SWE-bench coding agents and WebArena browser tasks, with better memory efficiency. Concrete platform-level pattern for serving multi-turn tool-using agents at production scale. _Category:_ arXiv:2605.00528 (cs.AI). [https://arxiv.org/abs/2605.00528](https://arxiv.org/abs/2605.00528)

- **Towards Multi-Agent Autonomous Reasoning in Hydrodynamics** — Jinpai Zhao, Albert Cerrone. _Takeaway:_ Multi-agent prototype that uses a planner agent to construct query-specific Layer Execution Graphs (LEGs) from natural-language routing heuristics; specialist agents under strict tool allowlists, consolidator agents fusing parallel outputs, reporter agent synthesizing, runtime logs every tool invocation for auditability. 93.6% factual precision / 100% pass on 37 queries with Claude Sonnet 4.6 as backbone; degrades gracefully under simulated data-source loss. Concrete instantiation of planner-led graph-orchestrated MAS against the single-context-window bottleneck. _Category:_ arXiv:2605.01102 (cs.AI). [https://arxiv.org/abs/2605.01102](https://arxiv.org/abs/2605.01102)

## Other interesting items

- **[H-RAG at SemEval-2026 Task 8: Hierarchical Parent–Child Retrieval for Multi-Turn RAG Conversations](https://arxiv.org/abs/2605.00631)** — Passant Elchafei, Hossam Emam. Separates fine-grained child-chunk retrieval from parent-document context reconstruction during generation in a Weaviate hybrid store; concrete pattern for multi-turn RAG faithfulness.
- **[Structure-Aware Chunking for Tabular Data in Retrieval-Augmented Generation](https://arxiv.org/abs/2605.00318)** — Pooja Guttal, Varun Magotra. Targets the pervasive failure mode of naïve text chunking on tables — useful for any RAG stack ingesting financial/scientific PDFs.
- **[When More Reformulations Hurt: Avoiding Drift Using Ranker Feedback](https://arxiv.org/abs/2605.00560)** — V Venktesh, Mandeep Rathee. ReformIR treats query reformulations as first-class features and learns a lightweight surrogate to estimate document utility — a budget-aware retrieval framework that pushes back on "more reformulations always help" RAG folklore.
- **[A Replicability Study of XTR](https://arxiv.org/abs/2605.00646)** — Rohan Jha, Reno Kriz. Independent replication of XTR's contextual-token retrieval shortcut for ColBERT; useful sanity check for anyone deploying token-level retrievers in production.
