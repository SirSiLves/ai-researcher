# AI Papers — 2026-04-03

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **The Latent Space: Foundation, Evolution, Mechanism, Ability, and Outlook** — anonymous (cs.CL/cs.LG submission). _Takeaway:_ Position paper arguing latent-space computation (continuous representations, no discretization bottleneck) is becoming a substrate for both language and multimodal models. Synthesizes the latent-reasoning literature into one frame — useful as a reference for the "verbal CoT vs. latent reasoning" thread. _Category:_ arXiv:2604.02029 (cs.CL). [https://arxiv.org/abs/2604.02029](https://arxiv.org/abs/2604.02029)

- **SKILL0: In-Context Agentic Reinforcement Learning for Skill Internalization** — anonymous (cs.AI/cs.LG submission). _Takeaway:_ In-context RL with a dynamic curriculum that lets agents internalize tool-use skills during training, then operate zero-shot at inference without the heavy context overhead of skill libraries. Tested on ALFWorld and Search-QA — concrete attempt to escape the "growing skill bag in context" pattern. _Category:_ arXiv:2604.02268 (cs.AI). [https://arxiv.org/abs/2604.02268](https://arxiv.org/abs/2604.02268)

- **CORAL: Towards Autonomous Multi-Agent Evolution for Open-Ended Discovery** — anonymous (cs.MA submission). _Takeaway:_ Multi-agent framework with persistent memory and asynchronous execution targeting open-ended math/optimization discovery; explicit knowledge reuse channel between agents. Adds to the small but growing set of multi-agent designs that go beyond debate-style aggregators. _Category:_ arXiv:2604.01658 (cs.MA). [https://arxiv.org/abs/2604.01658](https://arxiv.org/abs/2604.01658)

- **Therefore I am. I Think** — anonymous (cs.CL/cs.AI submission). _Takeaway:_ Interpretability result: reasoning models appear to encode action/tool-call decisions in pre-generation activations before the textual deliberation begins. Linear probes + activation steering confirm. Adds nuance to the CoT-faithfulness debate — the chain may be partly post-hoc rationalization. _Category:_ arXiv:2604.01202 (cs.CL). [https://arxiv.org/abs/2604.01202](https://arxiv.org/abs/2604.01202)

- **Omni-SimpleMem: Autoresearch-Guided Discovery of Lifelong Multimodal Agent Memory** — anonymous (cs.MA submission). _Takeaway:_ Uses an autonomous research pipeline (automated architecture mods, bug fixes, prompt engineering — not hyperparameter tuning) to discover a unified multimodal memory framework. Concrete instance of AI-for-AI design loops applied to the agent-memory subfield. _Category:_ arXiv:2604.01007 (cs.MA). [https://arxiv.org/abs/2604.01007](https://arxiv.org/abs/2604.01007)

- **Apriel-Reasoner: RL Post-Training for General-Purpose and Efficient Reasoning** — anonymous (cs.CL/cs.LG submission). _Takeaway:_ 15B reproducible RL recipe with multi-domain training, domain sampling, and an explicit length penalty pushing the Pareto frontier of accuracy-vs-tokens. Useful concrete recipe for the "efficient reasoning" thread that's mostly been about decoding tricks. _Category:_ arXiv:2604.02007 (cs.CL). [https://arxiv.org/abs/2604.02007](https://arxiv.org/abs/2604.02007)

- **Investigating Autonomous Agent Contributions in the Wild** — anonymous (cs.SE/cs.AI submission). _Takeaway:_ Empirical analysis of AI coding agents on open-source projects: higher PR activity, but elevated code-churn and lower survival rates versus human-authored code. Concrete data point for the agent-productivity vs. agent-debt argument. _Category:_ arXiv:2604.00917 (cs.AI). [https://arxiv.org/abs/2604.00917](https://arxiv.org/abs/2604.00917)

- **Ask or Assume? Uncertainty-Aware Clarification-Seeking in Coding Agents** — anonymous (cs.SE/cs.AI submission). _Takeaway:_ Multi-agent scaffold that detects underspecified SWE-bench tasks and proactively asks clarifying questions instead of guessing. Reports well-calibrated uncertainty improves task resolve rate on OpenHands + Claude Sonnet 4.5. Concrete pattern for the agent-interaction-design thread. _Category:_ arXiv:2603.26233 (cs.AI). [https://arxiv.org/abs/2603.26233](https://arxiv.org/abs/2603.26233)

- **Signals: Trajectory Sampling and Triage for Agentic Interactions** — anonymous (cs.AI submission). _Takeaway:_ Computes low-cost signals over agent trajectories to triage which interactions are worth labeling for preference-data construction — addresses the cost wall on post-deployment optimization. Concrete operational tooling for agent-observability stacks. _Category:_ arXiv:2604.00356 (cs.AI). [https://arxiv.org/abs/2604.00356](https://arxiv.org/abs/2604.00356)

- **AutoMIA: Improved Baselines for Membership Inference Attack via Agentic Self-Exploration** — anonymous (cs.LG/cs.CR submission). _Takeaway:_ Agentic framework that automatically searches the MIA attack space (logit-level strategies, autoencoder probes) with closed-loop self-evaluation; model-agnostic stronger baselines. Useful security-side data point for the privacy/leakage radar. _Category:_ arXiv:2604.01014 (cs.LG). [https://arxiv.org/abs/2604.01014](https://arxiv.org/abs/2604.01014)

## Other interesting items

- **[GPA: Learning GUI Process Automation from Demonstrations](https://arxiv.org/abs/2604.01676)** — cs.AI. Vision-based RPA via Sequential Monte Carlo localization; deterministic, fully local execution beats VLM-based CUA on long-horizon tasks.
- **[ASI-Evolve: AI Accelerates AI](https://arxiv.org/abs/2603.29640)** — cs.AI. Agentic framework for AI-for-AI research: architecture design, pretraining-data curation, RL algorithm design. Concrete instance of the "evolutionary agents" pattern.
- **[LatentUM: Interleaved Cross-Modal Reasoning via a Latent-Space Unified Model](https://arxiv.org/abs/2604.02097)** — cs.CL. Represents every modality in a shared semantic latent space; argues codec bias from pixel-space mediation hurts cross-modal reasoning.
