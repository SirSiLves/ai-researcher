## Top picks

- **Hierarchical Long-Term Semantic Memory for LinkedIn's Hiring Agent** — Zhentao Xu, Shangjing Zhang. _Takeaway:_ Production memory architecture deployed in LinkedIn's Hiring Assistant. Organizes textual data into a schema-aligned memory tree spanning multiple granularities; reports >10% lifts on answer correctness and retrieval F1 while improving the latency Pareto frontier. Concrete industrial counterweight to the "just bolt on Mem0" pattern and directly relevant to the agent-memory subfield. _Category:_ arXiv:2604.26197 (cs.IR). [https://arxiv.org/abs/2604.26197](https://arxiv.org/abs/2604.26197)

- **AgentSim: A Platform for Verifiable Agent-Trace Simulation** — Saber Zerhoudi, Michael Granitzer. _Takeaway:_ Open-source platform that generates verifiable, stepwise reasoning traces for RAG agents over arbitrary document collections, plus the released Agent-Trace Corpus (ATC) — 103K verifiable steps across three IR benchmarks with 100% grounding on substantive answers. Fills a real gap between outcome-only QA data and process-level training/eval for agentic RAG. SIGIR '26. _Category:_ arXiv:2604.26653 (cs.IR). [https://arxiv.org/abs/2604.26653](https://arxiv.org/abs/2604.26653)

- **TDD Governance for Multi-Agent Code Generation via Prompt Engineering** — Tarlan Hasanli, Shahbaz Siddeeq. _Takeaway:_ Operationalizes classical TDD principles as prompt- and workflow-level governance for multi-agent code generation — phase ordering, bounded repair loops, validation gates, atomic mutation control — separating model proposal from a deterministic engine authority. Concrete instantiation of the "compile-once, govern-the-workflow" pattern the radar has been tracking for coding agents. PROMPT-SE 2026. _Category:_ arXiv:2604.26615 (cs.SE). [https://arxiv.org/abs/2604.26615](https://arxiv.org/abs/2604.26615)

- **AGEL-Comp: A Neuro-Symbolic Framework for Compositional Generalization in Interactive Agents** — Mahnoor Shahid, Hannes Rothe. _Takeaway:_ Combines a dynamic Causal Program Graph (CPG) world model, an Inductive Logic Programming engine, and a hybrid reasoning core where the LLM proposes sub-goals verified by a Neural Theorem Prover. Sample-efficient symbolic learning under sparse feedback in Retro Quest — direct contribution to the neuro-symbolic-agent thread. _Category:_ arXiv:2604.26522 (cs.AI). [https://arxiv.org/abs/2604.26522](https://arxiv.org/abs/2604.26522)

- **SafeAgent: A Runtime Protection Architecture for Agentic Systems** — Hailin Liu, Eugene Ilyushin. _Takeaway:_ Treats safety as a stateful decision problem with a runtime controller and context-aware decision core that evaluates risk and governs agent actions across multi-step workflows. Lowest attack success rates across multiple attack categories while keeping benign-task performance — fits the same control-plane pattern as ARGUS/AgentTrust on the May 13 list. _Category:_ arXiv:2604.17562 (cs.AI). [https://arxiv.org/abs/2604.17562](https://arxiv.org/abs/2604.17562)

- **UniToolCall: Unifying Tool-Use Representation, Data, and Evaluation for LLM Agents** — Yijuan Liang, Xinghao Chen. _Takeaway:_ Unified framework for tool learning with 22K+ tools and 390K+ training instances across multiple datasets, plus a converter that brings existing benchmarks into a unified evaluation format. Concrete plumbing for the agent-eval and tool-use-standardization threads — this is what reproducible tool-use evaluation actually requires. _Category:_ arXiv:2604.11557 (cs.CL). [https://arxiv.org/abs/2604.11557](https://arxiv.org/abs/2604.11557)

## Other interesting items

- **[CORAL: Adaptive Retrieval Loop for Culturally-Aligned Multilingual RAG](https://arxiv.org/abs/2604.25676)** — Nayeon Lee, Jiwoo Song (ACL 2026 Findings). Iterative critique-and-rewrite loop over both corpora and queries for mRAG; up to 3.58pp accuracy gain on low-resource languages relative to strong baselines.
- **[Agentic Tool Use in Large Language Models](https://arxiv.org/abs/2604.00835)** — Jinchao Hu, Meizhi Zhong. Survey organizing tool-use literature into prompting / supervised tool learning / reward-driven tool policy learning paradigms; useful vocabulary check.
- **[Adaptive Prompt Embedding Optimization for LLM Jailbreaking](https://arxiv.org/abs/2604.24983)** — Miles Q. Li, Benjamin C. M. Fung. White-box attack that optimizes embeddings of original prompt tokens (no appended adversarial suffixes); extends the jailbreak threat model into embedding space.
