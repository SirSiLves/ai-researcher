## Top picks

- **Safe Bilevel Delegation (SBD): A Formal Framework for Runtime Delegation Safety in Multi-Agent Systems** — Yuan Sun. _Takeaway:_ Formalizes hierarchical agent delegation as a bilevel optimization: an outer meta-weight network learns context-dependent safety-efficiency weights; an inner loop optimizes the delegation policy subject to a probabilistic safety constraint. Proves Safety Monotonicity, Inner Policy Convergence, and an Accountability Propagation bound across multi-hop delegation chains. Important governance-grade framework as agents are deployed in high-stakes domains. _Category:_ arXiv:2604.27358 (cs.AI). [https://arxiv.org/abs/2604.27358](https://arxiv.org/abs/2604.27358)

- **Security Attack and Defense Strategies for Autonomous Agent Frameworks: A Layered Review with OpenClaw as a Case Study** — Luyao Xu, Xiang Chen. _Takeaway:_ Layered review of agent-framework security organized into four layers — context/instruction, tool/action, state/persistence, and ecosystem/automation — and shows how threats propagate across them (manipulated inputs → unsafe actions → state contamination → ecosystem impact). Useful frame for the "agent supply chain" governance discussion. _Category:_ arXiv:2604.27464 (cs.CR). [https://arxiv.org/abs/2604.27464](https://arxiv.org/abs/2604.27464)

- **End-to-End Evaluation and Governance of an EHR-Embedded AI Agent for Clinicians** — Aaryan Shah, Andrew Hines. _Takeaway:_ Field report on continuous governance for Hyperscribe, an EHR-embedded agent: rubric validation (20 clinicians, 1,646 rubrics, 823 cases), live feedback, perf monitoring, and controlled experimentation. Seven versions evaluated, median quality 84%→95%; live error reports dropped from 79% to 30% over three months. Real-world template for "governance-as-product" in deployed clinical agents. _Category:_ arXiv:2604.27309 (cs.AI). [https://arxiv.org/abs/2604.27309](https://arxiv.org/abs/2604.27309)

- **NuggetIndex: Governed Atomic Retrieval for Maintainable RAG** — Saber Zerhoudi, Michael Granitzer. _Takeaway:_ Stores atomic information units ("nuggets") as managed records with temporal validity intervals and lifecycle states, filtering deprecated facts before ranking. +42% nugget recall, +9pp temporal correctness, −55% conflict rate, −64% generator input length vs. passage/proposition retrieval baselines. A maintainable-RAG plumbing pattern as corpora evolve. SIGIR '26. _Category:_ arXiv:2604.27306 (cs.IR). [https://arxiv.org/abs/2604.27306](https://arxiv.org/abs/2604.27306)

- **ObjectGraph: From Document Injection to Knowledge Traversal — A Native File Format for the Agentic Era** — Mohit Dubey. _Takeaway:_ Argues traditional document formats designed for sequential human reading create inefficiencies when used by retrieval-driven agents; proposes OBJECTGRAPH (.og), a typed, directed knowledge graph traversed rather than injected as a string. Reports up to 95.3% token reduction at parity task accuracy — provocative reframing of "documents as agent inputs." _Category:_ arXiv:2604.27820 (cs.AI). [https://arxiv.org/abs/2604.27820](https://arxiv.org/abs/2604.27820)

- **Claw-Eval-Live: A Live Agent Benchmark for Evolving Real-World Workflows** — Chenxin Li, Zhengyang Tang. _Takeaway:_ Dynamic agent benchmark that refreshes against real-world demand signals rather than staying static; emphasizes verifiable agent action through execution traces and audit logs. Even leading models reach only 66.7% completion, with persistent failure on business workflows and multi-system operations. Live, audit-grade complement to OSWorld/WebArena. _Category:_ arXiv:2604.28139 (cs.AI). [https://arxiv.org/abs/2604.28139](https://arxiv.org/abs/2604.28139)

## Other interesting items

- **[A Brief Overview: Agentic Reinforcement Learning In Large Language Models](https://arxiv.org/abs/2604.27859)** — Fangming Cui, Ruixiao Zhu. Position-style overview of LLM-based Agentic RL — meta-reasoning, self-reflection, multi-step decision-making integrated into the learning loop; useful as a vocabulary check on the "agent RL" cluster.
- **[LLM-as-a-Judge for Human-AI Co-Creation: A Reliability-Aware Evaluation Framework for Coding](https://arxiv.org/abs/2604.27727)** — Md Faizul Ibne Amin, Yutaka Watanobe. Reliability-aware LLM-as-judge framework for human-AI coding sessions; reports modest inter-judge agreement, useful caveat for the "scale up LLM-judge" reflex.
- **[Iterative Multimodal Retrieval-Augmented Generation for Medical Question Answering](https://arxiv.org/abs/2604.27724)** — MedVRAG, an iterative multimodal RAG framework that retrieves and reasons over PMC document page images instead of OCR'd text — vertical-RAG signal for medical agents.
