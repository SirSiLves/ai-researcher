# AI Papers — 2026-04-02

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Terminal Agents Suffice for Enterprise Automation** — anonymous (cs.AI submission). _Takeaway:_ Argues that a plain terminal-based coding agent driving programmatic interfaces matches or beats heavily MCP/tool-augmented agents on enterprise tasks. Direct counter-argument to the "more tools = better" framing of the MCP-first agent stacks — relevant for the agent-platform consolidation thread. _Category:_ arXiv:2604.00073 (cs.AI). [https://arxiv.org/abs/2604.00073](https://arxiv.org/abs/2604.00073)

- **ClawKeeper: Comprehensive Safety Protection for Open Agents via Skills, Plugins, and Watchers** — anonymous (cs.AI submission). _Takeaway:_ Defense framework for open-source agent runtimes (local file access, shell exec) that layers instruction-level policies, plugin sandboxing, and a watcher paradigm that intercepts high-risk actions for human confirmation. Concrete control-plane reference design for the governance/agent-safety thread. _Category:_ arXiv:2603.24414 (cs.AI). [https://arxiv.org/abs/2603.24414](https://arxiv.org/abs/2603.24414)

- **MiroEval: Benchmarking Multimodal Deep Research Agents in Process and Outcome** — anonymous (cs.IR/cs.AI submission). _Takeaway:_ Eval framework for deep-research agents that scores adaptive synthesis, agentic factuality verification, and process auditing — not just final answer correctness. Real-user task pipeline with a "live evolving setting." Concrete eval artifact for the deep-research-agent comparison radar. _Category:_ arXiv:2603.28407 (cs.IR). [https://arxiv.org/abs/2603.28407](https://arxiv.org/abs/2603.28407)

- **Reasoning Shift: How Context Silently Shortens LLM Reasoning** — anonymous (cs.CL submission). _Takeaway:_ Documents that context length and structure systematically compress reasoning traces — models maintain accuracy on simple items while invisibly truncating verification and uncertainty management on harder ones. Sharp empirical claim for the test-time-scaling and long-context-vs-RAG threads. _Category:_ arXiv:2604.01161 (cs.CL). [https://arxiv.org/abs/2604.01161](https://arxiv.org/abs/2604.01161)

- **HippoCamp: Benchmarking Contextual Agents on Personal Computers** — anonymous (cs.AI submission). _Takeaway:_ Multimodal file-management benchmark probing long-horizon retrieval and cross-modal reasoning over dense personal file systems. Concretely measures the "personal data" gap that's blocking serious deployment of consumer agents. _Category:_ arXiv:2604.01221 (cs.AI). [https://arxiv.org/abs/2604.01221](https://arxiv.org/abs/2604.01221)

- **Do Phone-Use Agents Respect Your Privacy?** — anonymous (cs.AI submission). _Takeaway:_ Introduces MyPhoneBench with an "iMy" minimal privacy contract operationalizing permissioned access, minimal disclosure, and user-controlled memory. Across 5 frontier models / 10 apps / 300 tasks, joint success-and-privacy evaluation reshuffles model rankings versus accuracy alone; persistent failure is data over-disclosure on benign tasks. Direct evidence for the governance/agent-privacy thread. _Category:_ arXiv:2604.00986 (cs.AI). [https://arxiv.org/abs/2604.00986](https://arxiv.org/abs/2604.00986)

- **Proactive Agent Research Environment: Simulating Active Users** — anonymous (cs.MA submission). _Takeaway:_ Models applications as finite state machines to drive realistic active-user simulation across multi-app orchestration — a clean eval substrate for proactive assistants where the agent must observe context and infer intervention timing rather than wait for prompts. _Category:_ arXiv:2604.00842 (cs.MA). [https://arxiv.org/abs/2604.00842](https://arxiv.org/abs/2604.00842)

- **Brevity Constraints Reverse Performance Hierarchies in Language Models** — anonymous (cs.CL submission). _Takeaway:_ Causal intervention showing that constraining output length flips the "bigger models are better" hierarchy on multiple benchmarks: verbose responses inject errors that mask capability. Practical implication for evals that ignore length budget. _Category:_ arXiv:2604.00025 (cs.CL). [https://arxiv.org/abs/2604.00025](https://arxiv.org/abs/2604.00025)

- **A Survey of On-Policy Distillation for Large Language Models** — anonymous (cs.LG submission). _Takeaway:_ Survey but with a unifying f-divergence framework organizing approaches by feedback signal (logit / outcome / uncertainty-aware), teacher access (white/black-box/teacher-free), and granularity (token/sequence/hybrid). Pulls in distillation scaling laws and agent-level distillation under one taxonomy — useful reference scaffold. _Category:_ arXiv:2604.00626 (cs.LG). [https://arxiv.org/abs/2604.00626](https://arxiv.org/abs/2604.00626)

- **Revision or Re-Solving? Decomposing Second-Pass Gains in Multi-LLM Pipelines** — anonymous (cs.CL submission). _Takeaway:_ Decomposes the "second-pass improves over first" effect into re-solving, scaffold, and content components — finds gains depend on task structure and draft quality, not uniform error correction. Useful counter-evidence to naive "always add a verifier" practice in multi-LLM pipelines. _Category:_ arXiv:2604.01029 (cs.CL). [https://arxiv.org/abs/2604.01029](https://arxiv.org/abs/2604.01029)

## Other interesting items

- **[Universal YOCO for Efficient Depth Scaling](https://arxiv.org/abs/2604.01220)** — cs.LG. Combines YOCO decoder-decoder architecture with recursive computation for KV-cache-efficient long-context inference.
- **[Embarrassingly Simple Self-Distillation Improves Code Generation](https://arxiv.org/abs/2604.01193)** — cs.CL. SFT on model-generated samples improves pass@1 on LiveCodeBench by addressing the precision-vs-exploration trade-off in decoding.
- **[S0 Tuning: Zero-Overhead Adaptation of Hybrid Recurrent-Attention Models](https://arxiv.org/abs/2604.01168)** — cs.LG. Parameter-efficient fine-tuning that targets the recurrent state matrix in Mamba-2 / GatedDeltaNet hybrids; beats LoRA with zero inference overhead.
