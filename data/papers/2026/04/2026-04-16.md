# AI Papers — 2026-04-16

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **OccuBench: Evaluating AI Agents on Real-World Professional Tasks via Language World Models** — anonymous (cs.AI submission). _Takeaway:_ Real-world professional-task benchmark for agents that uses language world models for evaluation rather than scripted oracles. Important for the "agents in actual jobs" eval thread. _Category:_ arXiv:2604.10866 (cs.AI). [https://arxiv.org/abs/2604.10866](https://arxiv.org/abs/2604.10866)

- **Sema Code: Decoupling AI Coding Agents into Programmable, Embeddable Infrastructure** — anonymous (cs.AI submission). _Takeaway:_ Treats coding agents as embeddable infrastructure with explicit programmable surfaces — directly relevant to the "agents as infrastructure" platform thread (MCP, A2A, harness frameworks). _Category:_ arXiv:2604.11045 (cs.AI). [https://arxiv.org/abs/2604.11045](https://arxiv.org/abs/2604.11045)

- **SemaClaw: A Step Towards General-Purpose Personal AI Agents through Harness Engineering** — anonymous (cs.AI submission). _Takeaway:_ Centers harness engineering as the lever for general-purpose personal agents — pairs naturally with HARBOR (automated harness optimization) and the broader "scaffolding is the model" line. _Category:_ arXiv:2604.11548 (cs.AI). [https://arxiv.org/abs/2604.11548](https://arxiv.org/abs/2604.11548)

- **TREX: Automating LLM Fine-tuning via Agent-Driven Tree-based Exploration** — anonymous (cs.LG submission). _Takeaway:_ Agent-driven tree search over fine-tuning configurations and data slices — automates a workflow that's still mostly hand-tuned. Direct competitor to AutoML-for-LLM tooling threads. _Category:_ arXiv:2604.14116 (cs.LG). [https://arxiv.org/abs/2604.14116](https://arxiv.org/abs/2604.14116)

- **Exploration and Exploitation Errors Are Measurable for Language Model Agents** — anonymous (cs.AI submission). _Takeaway:_ Decomposes agent failures into exploration vs. exploitation errors and shows both are individually measurable. Practical diagnostic primitive for agent observability stacks. _Category:_ arXiv:2604.13151 (cs.AI). [https://arxiv.org/abs/2604.13151](https://arxiv.org/abs/2604.13151)

- **Memory Transfer Learning: How Memories are Transferred Across Domains in Coding Agents** — anonymous (cs.AI submission). _Takeaway:_ Empirical study of cross-domain memory transfer in coding agents — a probe of whether Mem0/agent-memory-style systems are actually generalizing or overfitting to source distribution. _Category:_ arXiv:2604.14004 (cs.AI). [https://arxiv.org/abs/2604.14004](https://arxiv.org/abs/2604.14004)

- **UI-Copilot: Advancing Long-Horizon GUI Automation via Tool-Integrated Policy Optimization** — anonymous (cs.AI submission). _Takeaway:_ Long-horizon GUI automation with explicit tool-integration in the policy-optimization loop — moves the GUI-agent SOTA from prompt-engineered orchestration to end-to-end optimized tool use. _Category:_ arXiv:2604.13822 (cs.AI). [https://arxiv.org/abs/2604.13822](https://arxiv.org/abs/2604.13822)

- **MERRIN: A Benchmark for Multimodal Evidence Retrieval and Reasoning in Noisy Web Environments** — anonymous (cs.IR submission). _Takeaway:_ Multimodal RAG benchmark explicitly designed around *noisy* web environments rather than clean curated corpora — closer to deep-research production reality. _Category:_ arXiv:2604.13418 (cs.IR). [https://arxiv.org/abs/2604.13418](https://arxiv.org/abs/2604.13418)

- **From P(y|x) to P(y): Investigating Reinforcement Learning in Pre-train Space** — anonymous (cs.LG submission). _Takeaway:_ Reframes RL for LLMs as optimizing the marginal P(y) rather than conditional P(y|x) — a theoretical lens with practical implications for unconditional generation and bias inheritance during RL. _Category:_ arXiv:2604.14142 (cs.LG). [https://arxiv.org/abs/2604.14142](https://arxiv.org/abs/2604.14142)

- **TIP: Token Importance in On-Policy Distillation** — anonymous (cs.LG submission). _Takeaway:_ Weights distillation loss by per-token importance rather than treating every token equally — a precise lever for the on-policy distillation pipeline that the Apr 15 KnowRL/Lightning-OPD/Rethinking-OPD papers are also targeting. _Category:_ arXiv:2604.14084 (cs.LG). [https://arxiv.org/abs/2604.14084](https://arxiv.org/abs/2604.14084)

## Other interesting items

- **[RationalRewards: Reasoning Rewards Scale Visual Generation Both Training and Test Time](https://arxiv.org/abs/2604.11626)** — cs.CV/cs.LG. Reasoning-style rewards transfer to visual generation at both train and test time — bridges reasoning-RL and image-generation worlds.
- **[Self-Distillation Zero: Self-Revision Turns Binary Rewards into Dense Supervision](https://arxiv.org/abs/2604.12002)** — cs.LG. Converts binary outcome rewards to dense supervision via self-revision passes — directly relevant to the "outcome rewards aren't enough" thread from Apr 27 reference (2604.22074).
- **[ROSE: An Intent-Centered Evaluation Metric for NL2SQL](https://arxiv.org/abs/2604.12988)** — cs.IR/cs.CL. Replaces execution-match metrics with intent-centered evaluation for NL2SQL — captures the right thing for production text-to-SQL.
- **[Self-Sovereign Agent](https://arxiv.org/abs/2604.08551)** — cs.AI. Architecture for agents that own their own identity, keys, and policy — the AI-identity governance thread continues to thicken.
