## Top picks

- **SkillClaw: Let Skills Evolve Collectively with Agentic Evolver** — Ziyu Ma, Shidong Yang. _Takeaway:_ Aggregates experience from many users so an autonomous evolver can identify behavioral patterns and refine/extend a shared skill repository. Sits between SKILL0 (in-weight skill internalization) and Graph-of-Skills (inference-time retrieval) — useful as the third corner of the agent-skills design space. _Category:_ arXiv:2604.08377. [https://arxiv.org/abs/2604.08377](https://arxiv.org/abs/2604.08377)
- **MolmoWeb: Open Visual Web Agent and Open Data for the Open Web** — Tanmay Gupta, Piper Wolters. _Takeaway:_ Open-weight family of multimodal web agents trained on diverse browser-task data, navigating from screenshots without HTML. State-of-the-art on web benchmarks among open-weight models; releases data alongside models — direct counter-pressure to closed CUA stacks. _Category:_ arXiv:2604.08516. [https://arxiv.org/abs/2604.08516](https://arxiv.org/abs/2604.08516)
- **KnowU-Bench: Towards Interactive, Proactive, and Personalized Mobile Agent Evaluation** — Tongbo Chen, Zhengxi Lu. _Takeaway:_ Mobile-agent benchmark that tests preference inference and proactive assistance, not just task execution. Finds agents that excel at explicit task execution drop below 50% on vague instructions requiring user-preference inference — sharp eval gap for personalized agent platforms. _Category:_ arXiv:2604.08455. [https://arxiv.org/abs/2604.08455](https://arxiv.org/abs/2604.08455)
- **Beyond Stochastic Exploration: What Makes Training Data Valuable for Agentic Search** — Chuzhan Hao, Wenfeng Feng. _Takeaway:_ Hierarchical Experience (HiExp) transforms raw reasoning trajectories into clustered, contrastive experience knowledge so RL-trained search agents explore by experience rather than by random sampling. Direct contribution to the "what does an agent learn" subfield Meta-RL Self-Reflection raised in March. _Category:_ arXiv:2604.08124. [https://arxiv.org/abs/2604.08124](https://arxiv.org/abs/2604.08124)
- **Rethinking Generalization in Reasoning SFT: A Conditional Analysis on Optimization, Data, and Model Capability** — AI45Research. _Takeaway:_ Conditional analysis of why reasoning SFT generalizes (or doesn't): isolates contributions from optimization, data composition, and base-model capability. Useful empirical complement to the "RL teaches knowledge vs RL teaches selection" debate that dominated 2026-05-13's picks. _Category:_ arXiv:2604.06628. [https://arxiv.org/abs/2604.06628](https://arxiv.org/abs/2604.06628)
- **Investigating Autonomous Agent Contributions in the Wild — Saturday companion** — see `2026-04-11.md` for MCP-DPT and the agent-platform externalization picks; this Sunday file leans into the "skills + web-agent + RL training" cluster from the same Friday cohort.

## Other interesting items

- **[AIBench: Evaluating Visual-Logical Consistency in Academic Illustration Generation](https://arxiv.org/abs/2603.28068)** — Wan-AI. Domain-specific eval for visual-logical consistency in scientific illustration generation; long-tail multimodal eval signal.
- **[MDPBench: A Benchmark for Multilingual Document Parsing in Real-World Scenarios](https://arxiv.org/abs/2603.28130)** — multilingual document parsing benchmark; relevant to multilingual RAG/document-AI agent evals.
- **[A Survey on the Security of Long-Term Memory in LLM Agents: Toward Mnemonic Sovereignty](https://arxiv.org/abs/2604.16548)** — Zehao Lin, Chunyu Li. Surveys persistent-memory threats (poisoning, unauthorized access, cross-session corruption) and proposes "mnemonic sovereignty" as a verifiable governance frame — surfaces this week and pairs with STALE on the agent-memory governance line.
