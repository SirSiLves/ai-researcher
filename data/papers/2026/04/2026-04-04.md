## Top picks

- **SKILL0: In-Context Agentic Reinforcement Learning for Skill Internalization** — Zhengxi Lu, Zhiyuan Yao. _Takeaway:_ Trains agents on a curriculum that begins with full skill context and progressively withdraws it, so skills end up baked into model weights rather than retrieved at runtime. Practical alternative to skill-bank retrieval and a useful counterpoint to the "graph-of-skills at inference" line. _Category:_ arXiv:2604.02268. [https://arxiv.org/abs/2604.02268](https://arxiv.org/abs/2604.02268)
- **CORAL: Towards Autonomous Multi-Agent Evolution for Open-Ended Discovery** — Ao Qu, Han Zheng. _Takeaway:_ MIT framework with shared persistent memory, asynchronous multi-agent execution, and heartbeat-based interventions for open-ended discovery. Reports concrete co-evolution wins (e.g. kernel engineering 1363→1103 cycles with four agents) — directly relevant to the agent-evolution thread the radar has been tracking. _Category:_ arXiv:2604.01658. [https://arxiv.org/abs/2604.01658](https://arxiv.org/abs/2604.01658)
- **Apriel-1.5-OpenReasoner: RL Post-Training for General-Purpose and Efficient Reasoning** — Rafael Pardinas, Ehsan Kamalloo. _Takeaway:_ ServiceNow ships a 15B reasoning model RL-trained across five domains with a difficulty-aware length penalty; produces 30-50% shorter reasoning traces at competitive accuracy. Important data point for the "concise-reasoning vs longer-chains" debate that 2026-05-13's ScaleLogic also touches. _Category:_ arXiv:2604.02007. [https://arxiv.org/abs/2604.02007](https://arxiv.org/abs/2604.02007)
- **The Latent Space: Foundation, Evolution, Mechanism, Ability, and Outlook** — Xinlei Yu, Zhangquan Chen. _Takeaway:_ 37-author position survey arguing latent space is becoming a native substrate for language models — alternative to explicit token-level generation. Read as a vocabulary check for the latent-reasoning / continuous-thought cluster (CoCoMix, COCONUT etc.) rather than as a method paper. _Category:_ arXiv:2604.02029. [https://arxiv.org/abs/2604.02029](https://arxiv.org/abs/2604.02029)
- **Signals: Trajectory Sampling and Triage for Agentic Interactions** — Shuguang Chen, Adil Hafeez. _Takeaway:_ DigitalOcean's lightweight, signal-based framework for picking valuable agent trajectories without LLM-as-judge or human review. Computes structured interaction/execution/environment signals and beats random sampling and heuristic filters on informativeness — concrete plumbing for agent-eval observability stacks. _Category:_ arXiv:2604.00356. [https://arxiv.org/abs/2604.00356](https://arxiv.org/abs/2604.00356)
- **GPA: Learning GUI Process Automation from Demonstrations** — Zirui Zhao, Jun Hao Liew. _Takeaway:_ Salesforce single-demo GUI agent: vision-only replay with Monte Carlo localization, deterministic readiness calibration, and local execution for privacy. Reports superior stability vs Gemini 3 Pro on process replay — a "boring but reliable" counter-example to the LLM-driven CUA approach. _Category:_ arXiv:2604.01676. [https://arxiv.org/abs/2604.01676](https://arxiv.org/abs/2604.01676)

## Other interesting items

- **[Investigating Autonomous Agent Contributions in the Wild: Activity Patterns and Code Change over Time](https://arxiv.org/abs/2604.00917)** — Razvan Mihai Popescu, David Gros (TU Delft). 110K open-source PRs across Codex, Claude Code, Copilot, Jules, Devin: agent participation is rising, but agent-written code shows higher churn than human-written. Empirical input to the "agents-in-prod" governance debate.
- **[Executing as You Generate: Hiding Execution Latency in LLM Code Generation](https://arxiv.org/abs/2604.00491)** — Zhensu Sun, Zhihao Lin. Eager runs code in parallel with token generation via AST-based chunking; up to 55% end-to-end latency reduction for coding agents. Concrete inference-loop optimization for tool-using agents.
- **[Ask or Assume? Uncertainty-Aware Clarification-Seeking in Coding Agents](https://arxiv.org/abs/2603.26233)** — Nicholas Edwards, Sebastian Schuster. Multi-agent setup that detects ambiguity and asks for clarification with calibrated uncertainty — relevant to the "agent communication" subfield.
- **[AutoMIA: Improved Baselines for Membership Inference Attack via Agentic Self-Exploration](https://arxiv.org/abs/2604.01014)** — Ruhao Liu, Weiqi Huang. Reframes MIA as an agentic search problem; matches/beats hand-crafted heuristic baselines without manual feature engineering. Notable as MIA tooling moves into the agent paradigm.
