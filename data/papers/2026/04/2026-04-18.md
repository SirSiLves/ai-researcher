## Top picks

- **Dive into Claude Code: The Design Space of Today's and Future AI Agent Systems** — Jiacheng Liu, Xiaohan Zhao. _Takeaway:_ Architectural anatomy of Claude Code as an agentic system — five core values driving the design, with comparison to OpenClaw to show how deployment context shapes agent architecture. Closest thing yet to a "how this is actually built" reference for frontier coding agents; baseline reading for any agent-platform team. _Category:_ arXiv:2604.14228. [https://arxiv.org/abs/2604.14228](https://arxiv.org/abs/2604.14228)
- **Don't Retrieve, Navigate: Distilling Enterprise Knowledge into Navigable Agent Skills for QA and RAG** — Yiqun Sun, Pengfei Wei. _Takeaway:_ Corpus2Skill turns document collections into hierarchical skill directories that LLM agents navigate, instead of consuming flat retrieval results. Beats traditional RAG on enterprise QA in scenarios where structure matters — important reframing of the "retrieval vs navigation" axis for the agentic-RAG cluster. _Category:_ arXiv:2604.14572. [https://arxiv.org/abs/2604.14572](https://arxiv.org/abs/2604.14572)
- **UniDoc-RL: Coarse-to-Fine Visual RAG with Hierarchical Actions and Dense Rewards** — Jun Wang, Shuo Tan. _Takeaway:_ DeepGlint RL framework that progressively refines visual evidence from document retrieval through image selection to active region cropping, with a dense reward shaping the trajectory. Up to 17.7% gains over prior RL-based methods — concrete advance for visual/multimodal RAG. _Category:_ arXiv:2604.14967. [https://arxiv.org/abs/2604.14967](https://arxiv.org/abs/2604.14967)
- **Modality-Native Routing in Agent-to-Agent Networks: A Multimodal A2A Protocol Extension** — Vasundra Srinivasan. _Takeaway:_ MMA2A inspects A2A Agent Card capability declarations to route voice, image, and text in their native modality; reports 52% task completion vs 32% for text-only systems with strong gains on vision-dependent tasks. Concrete A2A protocol evolution and the same author behind the MCP production-patterns work — direct A2A-radar input. _Category:_ arXiv:2604.12213. [https://arxiv.org/abs/2604.12213](https://arxiv.org/abs/2604.12213)
- **DR³-Eval: Towards Realistic and Reproducible Deep Research Evaluation** — Qianqian Xie, Qingheng Xiong. _Takeaway:_ NJU-LINK Lab benchmark for deep-research agents that uses authentic user-provided materials paired with a static research corpus and a multi-dimensional eval rubric. Surfaces real retrieval-robustness and hallucination gaps in current "deep research" agents — useful third-party stress test as the category proliferates. _Category:_ arXiv:2604.14683. [https://arxiv.org/abs/2604.14683](https://arxiv.org/abs/2604.14683)
- **KV Packet: Recomputation-Free Context-Independent KV Caching for LLMs** — Chuangtao Chen, Grace Li Zhang. _Takeaway:_ Reusable cached documents via trainable soft-token adapters instead of recomputation; near-zero FLOPs and lower TTFT than recomputation baselines. Pairs with KV-Fold (2605.12471) on the long-context-economics line — both push the inference cost curve down without architectural changes. _Category:_ arXiv:2604.13226. [https://arxiv.org/abs/2604.13226](https://arxiv.org/abs/2604.13226)

## Other interesting items

- **[MM-WebAgent: A Hierarchical Multimodal Web Agent for Webpage Generation](https://arxiv.org/abs/2604.15309)** — Yan Li, Zezi Zeng (Microsoft Research). Hierarchical planning + iterative self-reflection coordinating AIGC element generation; jointly optimizes layout, content, and integration with a new benchmark.
- **[TRACER: Trace-Based Adaptive Cost-Efficient Routing for LLM Classification](https://arxiv.org/abs/2604.14531)** — Adam Rida. Trains lightweight surrogates on production LLM logs and routes to them via a parity gate when agreement exceeds a reliability threshold — practical observability-driven cost optimization for LLM platforms.
- **[LongAct: Harnessing Intrinsic Activation Patterns for Long-Context Reinforcement Learning](https://arxiv.org/abs/2604.14922)** — Bowen Ping, Zijun Chen. Saliency-guided sparse update strategy that exploits high-magnitude QK activations during long-context RL; ~8% benchmark gain.
- **[SafeDream: Safety World Model for Proactive Early Jailbreak Detection](https://arxiv.org/abs/2604.16824)** — Bo Yan, Weikai Lin (surfaces this week). Safety state world model + statistical detection + contrastive analysis to flag multi-turn jailbreak ~1.2 turns before compliance — proactive defense complement to ICD/CRA attack work.
