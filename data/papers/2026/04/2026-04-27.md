# AI Papers — 2026-04-27

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Latent Agents: A Post-Training Procedure for Internalized Multi-Agent Debate** — anonymous (cs.CL submission). _Takeaway:_ Distills multi-agent debate into a single LLM via a two-stage fine-tuning pipeline; internalized models match or exceed explicit multi-agent debate while using up to 93% fewer tokens. Direct cost/perf payoff for the "is multi-agent worth it?" debate. _Category:_ arXiv:2604.24881 (cs.CL). [https://arxiv.org/abs/2604.24881](https://arxiv.org/abs/2604.24881)

- **Thinking Without Words: Efficient Latent Reasoning with Abstract Chain-of-Thought** — anonymous (cs.LG submission, v2 on Apr 27). _Takeaway:_ Post-training mechanism that produces a short sequence of tokens from a reserved discrete latent vocabulary in lieu of natural-language CoT before the response — a concrete "latent reasoning" alternative to explicit chains. _Category:_ arXiv:2604.22709 (cs.LG). [https://arxiv.org/abs/2604.22709](https://arxiv.org/abs/2604.22709)

- **Self-Aware Vector Embeddings for RAG: A Neuroscience-Inspired Framework for Temporal, Confidence-Weighted, and Relational Knowledge** — anonymous (cs.IR submission). _Takeaway:_ SmartVector augments dense embeddings with temporal awareness, confidence decay, and relational awareness, plus a five-stage lifecycle modeled on hippocampal–neocortical consolidation. Pushes back on the "static, context-free embedding" assumption in production RAG. _Category:_ arXiv:2604.20598 (cs.IR). [https://arxiv.org/abs/2604.20598](https://arxiv.org/abs/2604.20598)

- **Breaking MCP with Function Hijacking Attacks: Novel Threats for Function Calling and Agentic Models** — cs.CR/cs.AI submission. _Takeaway:_ Defines a function-hijacking attack that manipulates the tool-selection process of agentic models to force the invocation of a specific attacker-chosen function. Important data point for the MCP threat-model thread. _Category:_ arXiv:2604.20994 (cs.AI). [https://arxiv.org/abs/2604.20994](https://arxiv.org/abs/2604.20994)

- **Tool Attention Is All You Need: Dynamic Tool Gating and Lazy Schema Loading for Eliminating the MCP/Tools Tax in Scalable Agentic Workflows** — cs.AI submission. _Takeaway:_ Quantifies the "MCP tax": stateless eager schema injection imposes a hidden 10k–60k-token per-turn overhead in typical multi-server deployments. Proposes dynamic tool gating + lazy schema loading. Practical infra fix for MCP-heavy agent stacks. _Category:_ arXiv:2604.21816 (cs.AI). [https://arxiv.org/abs/2604.21816](https://arxiv.org/abs/2604.21816)

- **HARBOR: Automated Harness Optimization** — anonymous (cs.LG submission). _Takeaway:_ Automated optimization of agent harnesses — the layer between the model and the tools. A move toward learning the scaffolding rather than hand-tuning it. _Category:_ arXiv:2604.20938 (cs.LG). [https://arxiv.org/abs/2604.20938](https://arxiv.org/abs/2604.20938)

- **Outcome Rewards Do Not Guarantee Verifiable or Causally Important Reasoning** — anonymous (cs.LG submission). _Takeaway:_ Argues outcome-only RL rewards optimize for getting answers right without ensuring the underlying chain is verifiable or causally responsible — a structural critique of current RLHF/RLVR practice for reasoning. _Category:_ arXiv:2604.22074 (cs.LG). [https://arxiv.org/abs/2604.22074](https://arxiv.org/abs/2604.22074)

- **Structure Guided Retrieval-Augmented Generation for Factual Queries** — cs.IR submission. _Takeaway:_ Existing RAG predominantly relies on vector similarity, which is prone to semantic noise and fails to guarantee responses satisfying complex conditions of factual queries; this work injects structural constraints into the retrieval step. _Category:_ arXiv:2604.22843 (cs.IR). [https://arxiv.org/abs/2604.22843](https://arxiv.org/abs/2604.22843)

- **AgentSearchBench: A Benchmark for AI Agent Search in the Wild** — cs.IR submission. _Takeaway:_ Wild-distribution benchmark for agent search behavior rather than synthetic IR queries. Useful eval surface for the "agentic retrieval" thread. _Category:_ arXiv:2604.22436 (cs.IR). [https://arxiv.org/abs/2604.22436](https://arxiv.org/abs/2604.22436)

- **IntrAgent: An LLM Agent for Content-Grounded Information Retrieval through Literature Review** — cs.IR submission. _Takeaway:_ Content-grounded retrieval agent specialized for literature review — explicit decomposition of "search, read, ground" rather than treating it as a single retrieval call. _Category:_ arXiv:2604.22861 (cs.IR). [https://arxiv.org/abs/2604.22861](https://arxiv.org/abs/2604.22861)

## Other interesting items

- **[Read the Paper, Write the Code: Agentic Reproduction of Social-Science Results](https://arxiv.org/abs/2604.21965)** — cs.AI. Closed-loop agent that reads a social-science paper and reproduces its results in code — eval for end-to-end scientific reproduction agents.
- **[Spatial Metaphors for LLM Memory: A Critical Analysis of the MemPalace Architecture](https://arxiv.org/abs/2604.21284)** — cs.AI. Critical lens on memory-palace–style agent memory architectures; tests whether the spatial metaphor is doing real work or just framing.
- **[Provable Coordination for LLM Agents via Message Sequence Charts](https://arxiv.org/abs/2604.17612)** — cs.MA. Uses message-sequence-chart formalism to give provable coordination guarantees across LLM agents — formal-methods-meets-MAS direction.
