# AI Papers — 2026-04-17

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Dive into Claude Code: The Design Space of Today's and Future AI Agent Systems** — anonymous (cs.AI submission). _Takeaway:_ Reverse-engineering analysis of Claude Code as a representative production agent system, used to map the design space of next-gen agent stacks. Useful synthesis paper for the "what makes a good agent harness" thread. _Category:_ arXiv:2604.14228 (cs.AI). [https://arxiv.org/abs/2604.14228](https://arxiv.org/abs/2604.14228)

- **UniDoc-RL: Coarse-to-Fine Visual RAG with Hierarchical Actions and Dense Rewards** — anonymous (cs.IR submission). _Takeaway:_ Visual RAG over documents trained with hierarchical actions (page → region → token) and dense rewards instead of end-of-trajectory only. Directly addresses the "agentic visual retrieval" gap for document AI. _Category:_ arXiv:2604.14967 (cs.IR). [https://arxiv.org/abs/2604.14967](https://arxiv.org/abs/2604.14967)

- **Don't Retrieve, Navigate: Distilling Enterprise Knowledge into Navigable Agent Skills** — anonymous (cs.IR submission). _Takeaway:_ Replaces retrieve-then-read with distill-into-navigable-agent-skills. A direct challenge to vanilla RAG for enterprise knowledge — relevant to the long-context-vs-RAG and skill-based-memory threads. _Category:_ arXiv:2604.14572 (cs.IR). [https://arxiv.org/abs/2604.14572](https://arxiv.org/abs/2604.14572)

- **DR^3-Eval: Towards Realistic and Reproducible Deep Research Evaluation** — anonymous (cs.IR submission). _Takeaway:_ Evaluation framework for deep-research agents emphasizing realism + reproducibility — needed as ad-hoc deep-research benchmarks proliferate. _Category:_ arXiv:2604.14683 (cs.IR). [https://arxiv.org/abs/2604.14683](https://arxiv.org/abs/2604.14683)

- **RAD-2: Scaling Reinforcement Learning in a Generator-Discriminator Framework** — anonymous (cs.LG submission). _Takeaway:_ Scales generator-discriminator RL for LLMs — a structured alternative to RLHF/RLVR that puts a learned discriminator (not a verifier) in the reward seat. Relevant to the "what should provide the RL signal" debate. _Category:_ arXiv:2604.15308 (cs.LG). [https://arxiv.org/abs/2604.15308](https://arxiv.org/abs/2604.15308)

- **LongAct: Harnessing Intrinsic Activation Patterns for Long-Context Reinforcement Learning** — anonymous (cs.LG submission). _Takeaway:_ Long-context RL post-training that conditions on intrinsic activation patterns rather than synthetic-needle objectives. Useful data for the long-context-post-training thread. _Category:_ arXiv:2604.14922 (cs.LG). [https://arxiv.org/abs/2604.14922](https://arxiv.org/abs/2604.14922)

- **TRACER: Trace-Based Adaptive Cost-Efficient Routing for LLM Classification** — anonymous (cs.LG submission). _Takeaway:_ Cost-aware routing across model tiers based on per-trace features — concrete production primitive for the LLM-router subfield as multi-model deployments scale. _Category:_ arXiv:2604.14531 (cs.LG). [https://arxiv.org/abs/2604.14531](https://arxiv.org/abs/2604.14531)

- **MM-WebAgent: A Hierarchical Multimodal Web Agent for Webpage Generation** — anonymous (cs.AI submission). _Takeaway:_ Web agent that generates rather than just navigates — hierarchical multimodal policy outputting full pages. Companion to UI-Copilot from yesterday: GUI-agent capability is generalizing from interaction to authoring. _Category:_ arXiv:2604.15309 (cs.AI). [https://arxiv.org/abs/2604.15309](https://arxiv.org/abs/2604.15309)

- **KV Packet: Recomputation-Free Context-Independent KV Caching for LLMs** — anonymous (cs.LG submission). _Takeaway:_ Context-independent KV blocks ("packets") that can be reused without recomputation across prompts. A concrete answer to KV-cache reuse / dedup at the serving layer. Pairs with byte-exact dedup (Apr 27 ref) and IceCache (Apr 14). _Category:_ arXiv:2604.13226 (cs.LG). [https://arxiv.org/abs/2604.13226](https://arxiv.org/abs/2604.13226)

- **Cross-Tokenizer LLM Distillation through a Byte-Level Interface** — anonymous (cs.CL submission). _Takeaway:_ Distillation across mismatched tokenizers via a byte-level interface — eliminates the "must share vocab" constraint that currently blocks cross-family distillation. Practical infra for mixing Qwen → Llama, etc. _Category:_ arXiv:2604.07466 (cs.CL). [https://arxiv.org/abs/2604.07466](https://arxiv.org/abs/2604.07466)

## Other interesting items

- **[C2: Scalable Rubric-Augmented Reward Modeling from Binary Preferences](https://arxiv.org/abs/2604.13618)** — cs.LG. Rubric-augmented RMs trained from binary preferences — denser signal without requiring rubric-annotated data.
- **[RadAgent: A Tool-Using AI Agent for Stepwise Interpretation of Chest CT](https://arxiv.org/abs/2604.15231)** — cs.AI. Vertical agent benchmark for radiology — concrete domain-specific instance of agentic tool use.
- **[Reinforcement Learning via Value Gradient Flow](https://arxiv.org/abs/2604.14265)** — cs.LG. Value-gradient flow as an RL update — alternative to PPO/GRPO in the post-training algorithm space.
- **[Towards Autonomous Mechanistic Reasoning in Virtual Cells](https://arxiv.org/abs/2604.11661)** — cs.AI. Mechanistic-reasoning agent over virtual-cell simulators — concrete instance of agentic scientific reasoning.
