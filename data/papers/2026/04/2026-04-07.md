# AI Papers — 2026-04-07

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Adam's Law: Textual Frequency Law on Large Language Models** — anonymous (cs.CL submission). _Takeaway:_ Identifies a power-law relationship between sentence-level frequency in training data and downstream performance, then operationalizes it as Textual Frequency Distillation and a Curriculum Textual Frequency Training schedule. Tested on prompting + fine-tuning across math, MT, commonsense, and agentic tool calling — concrete bridge from scaling-laws-of-data to recipe design. _Category:_ arXiv:2604.02176 (cs.CL). [https://arxiv.org/abs/2604.02176](https://arxiv.org/abs/2604.02176)

- **TriAttention: Efficient Long Reasoning with Trigonometric KV Compression** — anonymous (cs.CL/cs.LG submission). _Takeaway:_ Attacks the KV-cache bottleneck by working in the pre-RoPE space where Q/K vectors concentrate — uses a trigonometric series for cheaper, more accurate key importance estimation. Concrete throughput/memory win for long-context generation, complementary to KV-Fold / LaProx. _Category:_ arXiv:2604.04921 (cs.CL). [https://arxiv.org/abs/2604.04921](https://arxiv.org/abs/2604.04921)

- **Memory Intelligence Agent** — anonymous (cs.MA submission). _Takeaway:_ Manager-Planner-Executor architecture that combines a non-parametric memory store with a parametric memory agent and runs alternating RL between them, plus test-time learning via a reflection loop. Fresh design for the agent-memory-as-system problem the radar has been tracking around Mem0/STALE. _Category:_ arXiv:2604.04503 (cs.MA). [https://arxiv.org/abs/2604.04503](https://arxiv.org/abs/2604.04503)

- **Can LLMs Learn to Reason Robustly under Noisy Supervision?** — anonymous (cs.LG submission). _Takeaway:_ Online Label Refinement for RLVR: progressively corrects labels using majority-voted answers + consistency checks instead of trusting verifier output. Cleanly separates "active" vs "inactive" noisy labels and shows robustness gains across math reasoning benchmarks — direct response to RLVR's verifier-bottleneck failure mode. _Category:_ arXiv:2604.03993 (cs.LG). [https://arxiv.org/abs/2604.03993](https://arxiv.org/abs/2604.03993)

- **LightThinker++: From Reasoning Compression to Memory Management** — anonymous (cs.CL submission). _Takeaway:_ Reframes "reasoning compression" as adaptive memory management with explicit memory primitives and a trajectory-synthesis pipeline for memory scheduling. Reduces tokens and inference time on long-horizon agentic tasks. Practical complement to TriAttention on the inference-cost front. _Category:_ arXiv:2604.03679 (cs.CL). [https://arxiv.org/abs/2604.03679](https://arxiv.org/abs/2604.03679)

- **ClawArena: Benchmarking AI Agents in Evolving Information Environments** — anonymous (cs.AI submission). _Takeaway:_ Eval for dynamic belief revision: multi-source conflicts, evolving facts, and implicit personalization. Uses shell-based executable checks rather than freeform grading. Sharp counterpart to the STALE-style "do agents know when their memory is stale?" question. _Category:_ arXiv:2604.04202 (cs.AI). [https://arxiv.org/abs/2604.04202](https://arxiv.org/abs/2604.04202)

- **SkillX: Automatically Constructing Skill Knowledge Bases for Agents** — anonymous (cs.MA submission). _Takeaway:_ Self-evolving paradigm that builds reusable hierarchical skill libraries via iterative refinement and exploratory expansion. Tested on long-horizon and user-interactive benchmarks with GLM-4.6 — concrete pattern for the skill-library-vs-context-window debate. _Category:_ arXiv:2604.04804 (cs.MA). [https://arxiv.org/abs/2604.04804](https://arxiv.org/abs/2604.04804)

- **Your Agent, Their Asset: A Real-World Safety Analysis of Open Personal Agents** — anonymous (cs.AI/cs.CR submission). _Takeaway:_ Empirical safety analysis of an open personal-AI-agent platform using a CIK (Capability / Identity / Knowledge) attack taxonomy in sandboxed eval. Existing defenses prove insufficient against malicious injections and even "legitimate updates" become attack vectors. Concrete threat-model artifact for the agent-platform governance line. _Category:_ arXiv:2604.04759 (cs.AI). [https://arxiv.org/abs/2604.04759](https://arxiv.org/abs/2604.04759)

- **Unifying Group-Relative and Self-Distillation Policy Optimization via Sample Routing (SRPO)** — anonymous (cs.LG submission). _Takeaway:_ Routes correct samples to GRPO-style reward-aligned RL and failed samples to logit-level self-distillation correction, with entropy-aware dynamic weighting. Argues neither GRPO nor SDPO alone is optimal — concrete unification of the RLVR + distillation literature. _Category:_ arXiv:2604.02288 (cs.LG). [https://arxiv.org/abs/2604.02288](https://arxiv.org/abs/2604.02288)

- **Learning to Learn-at-Test-Time: Language Agents with Learnable Adaptation Policies** — anonymous (cs.AI submission). _Takeaway:_ Bi-level optimization with evolutionary search over a meta-agent's adaptation policy across sequential episodes. Pulls test-time adaptation out of hand-crafted heuristics into a discoverable transferable strategy — relevant to the in-place test-time training thread. _Category:_ arXiv:2604.00830 (cs.AI). [https://arxiv.org/abs/2604.00830](https://arxiv.org/abs/2604.00830)

## Other interesting items

- **[FileGram: Grounding Agent Personalization in File-System Behavioral Traces](https://arxiv.org/abs/2604.04901)** — cs.MA. Bottom-up memory architecture built from atomic file-system actions and content deltas; concrete pattern for personalization without intrusive user models.
- **[PLUME: Latent Reasoning Based Universal Multimodal Embedding](https://arxiv.org/abs/2604.02073)** — cs.IR. Replaces explicit CoT in embedding rollouts with continuous-latent rollouts via a semantic-anchor-guided transition adapter — fast retrieval-grade reasoning.
- **[Synthetic Sandbox for Training ML-Engineering Agents](https://arxiv.org/abs/2604.04872)** — cs.MA. SandMLE multi-agent framework generates synthetic MLE environments from seed tasks for on-policy RL; cuts dataset size while preserving problem complexity.
- **[Paper Espresso: From Paper Overload to Research Insight](https://arxiv.org/abs/2604.04562)** — cs.IR. Open-source platform for automated arXiv discovery + multi-granularity trend analysis. Adjacent to Paper Circle / FlowPIE.
