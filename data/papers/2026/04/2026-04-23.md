# AI Papers — 2026-04-23

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **DR-Venus: Towards Frontier Edge-Scale Deep Research Agents with Only 10K Open Data** — anonymous (cs.AI submission). _Takeaway:_ Deep-research agent built with only 10K open training examples — directly tests whether the deep-research capability requires frontier data scale or can be reproduced cheaply on open data. _Category:_ arXiv:2604.19859 (cs.AI). [https://arxiv.org/abs/2604.19859](https://arxiv.org/abs/2604.19859)

- **Reward Hacking in the Era of Large Models: Mechanisms, Emergent Misalignment, Challenges** — anonymous (cs.LG submission). _Takeaway:_ Survey-plus-analysis of reward hacking in the LLM RL era, including the link to emergent misalignment. Pairs naturally with Terminal Wrench (Apr 21) which provides the dataset. _Category:_ arXiv:2604.13602 (cs.LG). [https://arxiv.org/abs/2604.13602](https://arxiv.org/abs/2604.13602)

- **Near-Future Policy Optimization** — anonymous (cs.LG submission). _Takeaway:_ Policy-optimization variant that explicitly optimizes near-future rather than full-horizon return — a principled middle ground between greedy and full-trajectory RL post-training. _Category:_ arXiv:2604.20733 (cs.LG). [https://arxiv.org/abs/2604.20733](https://arxiv.org/abs/2604.20733)

- **A Self-Evolving Framework for Efficient Terminal Agents via Observational Context Compression** — anonymous (cs.AI submission). _Takeaway:_ Self-evolving terminal-agent framework whose key trick is observational context compression — direct attack on the "agent loops blow up the context window" failure mode. _Category:_ arXiv:2604.19572 (cs.AI). [https://arxiv.org/abs/2604.19572](https://arxiv.org/abs/2604.19572)

- **Scaling Test-Time Compute for Agentic Coding** — anonymous (cs.AI submission). _Takeaway:_ How test-time compute scaling behaves specifically for agentic coding (multi-step, tool-using) rather than single-turn code generation — useful data point for the inference-cost-vs-quality frontier on coding agents. _Category:_ arXiv:2604.16529 (cs.AI). [https://arxiv.org/abs/2604.16529](https://arxiv.org/abs/2604.16529)

- **Abstain-R1: Calibrated Abstention and Post-Refusal Clarification via Verifiable RL** — anonymous (cs.CL submission). _Takeaway:_ RL-trained calibrated abstention plus post-refusal clarification — direct mechanism for the "I don't know" failure mode that current frontier models still get wrong under epistemic uncertainty. _Category:_ arXiv:2604.17073 (cs.CL). [https://arxiv.org/abs/2604.17073](https://arxiv.org/abs/2604.17073)

- **OpenMobile: Building Open Mobile Agents with Task and Trajectory Synthesis** — anonymous (cs.AI submission). _Takeaway:_ Open mobile-agent stack with synthetic task and trajectory generation as the data engine. Companion to ClawGUI / UI-Copilot in the open GUI-agent ecosystem. _Category:_ arXiv:2604.15093 (cs.AI). [https://arxiv.org/abs/2604.15093](https://arxiv.org/abs/2604.15093)

- **Self-Evolving LLM Memory Extraction Across Heterogeneous Tasks** — anonymous (cs.CL submission). _Takeaway:_ Memory-extraction mechanism that evolves itself across heterogeneous tasks — agent-memory thread getting more aggressive about self-improvement of the memory layer itself. _Category:_ arXiv:2604.11610 (cs.CL). [https://arxiv.org/abs/2604.11610](https://arxiv.org/abs/2604.11610)

- **Benign Fine-Tuning Breaks Safety Alignment in Audio LLMs** — anonymous (cs.SD/cs.AI submission). _Takeaway:_ Demonstrates that even benign downstream fine-tuning collapses safety alignment in audio LLMs — extends the "alignment is brittle" thread (cf. Apr 13's 2604.09544) into the audio-LLM modality. _Category:_ arXiv:2604.16659 (cs.AI). [https://arxiv.org/abs/2604.16659](https://arxiv.org/abs/2604.16659)

- **AI Scientists Produce Results Without Reasoning Scientifically** — anonymous (cs.AI submission). _Takeaway:_ Empirical critique: AI-scientist systems produce surface-correct results without engaging genuine scientific reasoning patterns. Sharp corrective to the AI-scientist enthusiasm thread (Mind DeepResearch, EvoMaster, etc.). _Category:_ arXiv:2604.18805 (cs.AI). [https://arxiv.org/abs/2604.18805](https://arxiv.org/abs/2604.18805)
