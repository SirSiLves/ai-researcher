## Top picks

- **AI Identity: Standards, Gaps, and Research Directions for AI Agents** — Takumi Otsuka, Kentaroh Toyoda. _Takeaway:_ Defines AI Identity as the continuous relationship between what an agent is declared to be and what it is observed to do, and identifies five structural gaps (semantic intent verification, recursive delegation accountability, etc.) that current tech and regulation cannot resolve. Concludes foundational research is needed — important framing for the AI-identity radar thread. _Category:_ arXiv:2604.23280. [https://arxiv.org/abs/2604.23280](https://arxiv.org/abs/2604.23280)
- **MCP Pitfall Lab: Exposing Developer Pitfalls in MCP Tool Server Security under Multi-Vector Attacks** — Run Hao, Zhuoran Tan. _Takeaway:_ Protocol-aware security testing framework that operationalizes developer pitfalls as reproducible scenarios and validates outcomes with MCP traces and objective validators. Shows recommended hardening eliminates findings with minimal code changes — companion to MCP-DPT and MCPThreatHive on the MCP-security trio. _Category:_ arXiv:2604.21477. [https://arxiv.org/abs/2604.21477](https://arxiv.org/abs/2604.21477)
- **Co-Evolving LLM Decision and Skill Bank Agents for Long-Horizon Tasks** — Xiyang Wu, Zongxia Li. _Takeaway:_ COSPLAY: agent retrieves skills from a learnable skill bank to make decisions, with skills discovered and refined across episodes. Reports >25% average reward improvement on long-horizon game benchmarks vs baseline LLMs — sits in the same skill-bank cluster as SKILL0/SkillClaw/Graph-of-Skills. _Category:_ arXiv:2604.20987. [https://arxiv.org/abs/2604.20987](https://arxiv.org/abs/2604.20987)
- **EvoAgent: An Evolvable Agent Framework with Skill Learning and Multi-Agent Delegation** — Aimin Zhang, Jiajing Guo. _Takeaway:_ Models skills as multi-file structured capability units with triggering mechanisms and evolutionary metadata; user-feedback closed loop drives continuous skill generation. ~28% lift with GPT-5.2 on foreign-trade application tasks — concrete instantiation of the closed-loop skill evolution pattern. _Category:_ arXiv:2604.20133. [https://arxiv.org/abs/2604.20133](https://arxiv.org/abs/2604.20133)
- **VLAA-GUI: Knowing When to Stop, Recover, and Search — A Modular Framework for GUI Automation** — Qijun Han, Haoqin Tu. _Takeaway:_ Three modular components for GUI agents: Completeness Verifier (no premature success claims), Loop Breaker (escape repetitive cycles), Search Agent (handle unfamiliar workflows). State-of-the-art on multiple GUI benchmarks with several models surpassing human performance on OSWorld — concrete failure-mode-targeted CUA design. _Category:_ arXiv:2604.21375. [https://arxiv.org/abs/2604.21375](https://arxiv.org/abs/2604.21375)
- **Trust but Verify: Introducing DAVinCI — A Framework for Dual Attribution and Verification in Claim Inference for Language Models** — Vipula Rawte, Ryan Rossi. _Takeaway:_ Two-stage approach to LLM factuality: attribute claims to model components and external sources, then verify via entailment. 5-20% improvements on fact-checking datasets and a modular implementation that pushes accountability into the inference loop. _Category:_ arXiv:2604.21193. [https://arxiv.org/abs/2604.21193](https://arxiv.org/abs/2604.21193)

## Other interesting items

- **[LanG — A Governance-Aware Agentic AI Platform for Unified Security Operations](https://arxiv.org/abs/2604.05440)** — Anes Abdennebi, Nadjia Kara. Open-source agentic AI platform with a layered governance-MCP-agentic-AI-security architecture for SecOps; ties governance directly to MCP plumbing.
- **[Hybrid Policy Distillation for LLMs](https://arxiv.org/abs/2604.20244)** — Wenhong Zhu, Ruobing Xie. Unified KD framework that integrates forward and reverse KL to balance mode coverage vs mode-seeking; gains across math, dialogue, and code generation.
- **[Memory-Augmented LLM-based Multi-Agent System for Automated Feature Generation on Tabular Data](https://arxiv.org/abs/2604.20261)** — Fengxian Dong, Zhi Zheng. MALMAS: Router Agent + procedural/feedback/conceptual memory for iterative tabular feature generation — multi-agent system applied to a structured-data vertical.
