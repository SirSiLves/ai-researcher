# AI Papers — 2026-05-16

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **GraphBit: A Graph-based Agentic Framework for Non-Linear Agent Orchestration** — Yeahia Sarker, Md Rahmat Ullah, Musa Molla, Shafiq Joty. _Takeaway:_ Engine-orchestrated DAG-based agentic framework (Rust core) that replaces prompted routing with typed function-style agents — fixes hallucinated routing, infinite loops, reproducibility. _Category:_ 2605.13848. [https://arxiv.org/abs/2605.13848](https://arxiv.org/abs/2605.13848)

- **A Two-Dimensional Framework for AI Agent Design Patterns: Cognitive Function and Execution Topology** — Jia Huang, Joey Tianyi Zhou. _Takeaway:_ Unifies industry agent guides (Anthropic, Google, LangChain — execution topology) with cognitive-science frameworks (cognitive function) into a two-axis taxonomy useful for choosing/comparing architectures. _Category:_ 2605.13850. [https://arxiv.org/abs/2605.13850](https://arxiv.org/abs/2605.13850)

- **Invisible Orchestrators Suppress Protective Behavior and Dissociate Power-Holders: Safety Risks in Multi-Agent LLM Systems** — Hiroki Fukui. _Takeaway:_ Empirical evidence that hidden coordinator agents in enterprise multi-agent deployments measurably suppress worker agents' safety behaviors — a concrete failure mode for orchestrator transparency requirements. _Category:_ 2605.13851. [https://arxiv.org/abs/2605.13851](https://arxiv.org/abs/2605.13851)

- **PREPING: Building Agent Memory without Tasks** — Yumin Choi, Sangwoo Park, Minki Kang, Jinheon Baek, Sung Ju Hwang. _Takeaway:_ Pre-deployment, task-free agent memory construction that closes the cold-start gap when agents are first dropped into a new environment. _Category:_ 2605.13880. [https://arxiv.org/abs/2605.13880](https://arxiv.org/abs/2605.13880)

- **Deepchecks: Evaluating Retrieval-Augmented Generation (RAG)** — Assaf Gerner, Netta Madvil, Nadav Barak, Alex Zaikman, Jonatan Liberman, Liron Hayman. _Takeaway:_ A practical evaluation framework for RAG systems from the Deepchecks team — relevant for anyone building production RAG with retrieval, grounding, and answer-quality metrics that go beyond exact-match. _Category:_ 2605.14488. [https://arxiv.org/abs/2605.14488](https://arxiv.org/abs/2605.14488)

- **Why Neighborhoods Matter: Traversal Context and Provenance in Agentic GraphRAG** — Riccardo Terrenzi, Maximilian von Zastrow, Serkan Ayvaz. _Takeaway:_ Reframes citation faithfulness for agentic GraphRAG: when an agent walks a knowledge graph, which neighborhood and traversal history must be cited to be truly grounded? _Category:_ 2605.15109. [https://arxiv.org/abs/2605.15109](https://arxiv.org/abs/2605.15109)

- **Model-Adaptive Tool Necessity Reveals the Knowing-Doing Gap in LLM Tool Use** — Yize Cheng, Chenrui Fan, Mahdi JafariRaviz, Keivan Rezaei, Soheil Feizi. _Takeaway:_ Tool necessity is model-dependent, not task-dependent — exposes a knowing-doing gap where models know they should use a tool but don't, with implications for function-calling benchmarks. _Category:_ 2605.14038. [https://arxiv.org/abs/2605.14038](https://arxiv.org/abs/2605.14038)

- **Orchard: An Open-Source Agentic Modeling Framework** — Baolin Peng, Wenlin Yao, Qianhui Wu, Hao Cheng, Xiao Yu, Rui Yang, Tao Ge et al. _Takeaway:_ Open-source framework for turning LLMs into autonomous agents (planning, reasoning, tool use, multi-turn) — useful counterweight to closed agent stacks. _Category:_ 2605.15040. [https://arxiv.org/abs/2605.15040](https://arxiv.org/abs/2605.15040)

- **Concurrency without Model Changes: Future-based Asynchronous Function Calling for LLMs** — papers.cool / arxiv. _Takeaway:_ Adds future-based async semantics to function calling without retraining models — addresses real bottleneck in production agent latency. _Category:_ 2605.15077. [https://arxiv.org/abs/2605.15077](https://arxiv.org/abs/2605.15077)

- **Holistic Evaluation and Failure Diagnosis of AI Agents** — Netta Madvil, Gilad Dym, Alon Mecilati, Edo Dekel, Jonatan Liberman, Rotem Brazilay. _Takeaway:_ Moves beyond outcome metrics to connect specific failure types to where they occurred in the agent's process — closer to actionable observability. _Category:_ 2605.14865. [https://arxiv.org/abs/2605.14865](https://arxiv.org/abs/2605.14865)

- **From Sycophantic Consensus to Pluralistic Repair: Why AI Alignment Must Surface Disagreement** — Varad Vishwarupe, Nigel Shadbolt, Marina Jirotka. _Takeaway:_ Argues pluralistic alignment shouldn't aggregate preferences into consensus; it should surface and repair disagreement — direct critique of Overton/Steerable/Distributional approaches. _Category:_ 2605.14912. [https://arxiv.org/abs/2605.14912](https://arxiv.org/abs/2605.14912)

- **Beyond Individual Intelligence: Surveying Collaboration, Failure Attribution, and Self-Evolution in LLM-based Multi-Agent Systems** — Shihao Qi, Jie Ma, Rui Xing et al. _Takeaway:_ Survey synthesizing what's actually known about multi-agent coordination, failure attribution and self-evolution — featured on HF Papers daily. _Category:_ 2605.14892. [https://arxiv.org/abs/2605.14892](https://arxiv.org/abs/2605.14892)

- **Mechanical Enforcement for LLM Governance: Evidence of Governance-Task Decoupling in Financial Decision Systems** — papers.cool / arxiv. _Takeaway:_ Shows that prompt-level governance instructions get decoupled from actual task execution in financial LLM systems; argues for mechanical (out-of-band) enforcement — relevant to AI policy and regulated-industry deployment. _Category:_ 2605.14744. [https://arxiv.org/abs/2605.14744](https://arxiv.org/abs/2605.14744)

- **Is Grep All You Need? How Agent Harnesses Reshape Agentic Search** — papers.cool top pick. _Takeaway:_ Empirical look at how the surrounding agent harness (not just the search tool) determines retrieval quality — provocative for RAG / search-tool design. _Category:_ 2605.15184. [https://arxiv.org/abs/2605.15184](https://arxiv.org/abs/2605.15184)

- **LiSA: Lifelong Safety Adaptation via Conservative Policy Induction** — HF Papers daily. _Takeaway:_ Conservative policy-induction approach for keeping safety constraints intact as models continue learning post-deployment — relevant to alignment durability. _Category:_ 2605.14454. [https://arxiv.org/abs/2605.14454](https://arxiv.org/abs/2605.14454)
