# AI Papers — 2026-05-17

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **FutureSim: Replaying World Events to Evaluate Adaptive Agents** — Shashwat Goel, Nikhil Chandak, Arvindh Arun, Ameya Prabhu, Steffen Staab, Moritz Hardt et al. _Takeaway:_ Builds a benchmark that replays real-world news in chronological order so frontier agents can be evaluated on whether they actually adapt to information arriving past their training cutoff — directly attacks the static-eval problem that plagues current agent leaderboards. _Category:_ 2605.15188. [https://arxiv.org/abs/2605.15188](https://arxiv.org/abs/2605.15188)

- **STALE: Can LLM Agents Know When Their Memories Are No Longer Valid?** — Hanxiang Chao, Yihan Bai, Rui Sheng, Tianle Li, Yushi Sun. _Takeaway:_ Introduces a 400-scenario benchmark for "implicit conflict" — a new observation invalidates an earlier memory without explicit negation — and shows current agents fail to revise their stored beliefs, a serious gap for long-lived personalized agents. _Category:_ 2605.06527. [https://arxiv.org/abs/2605.06527](https://arxiv.org/abs/2605.06527)

- **MemEye: A Visual-Centric Evaluation Framework for Multimodal Agent Memory** — Minghao Guo, Qingyue Jiao, Zeru Shi, Yihao Quan, Boxuan Zhang, Danrui Li et al. _Takeaway:_ Most "multimodal memory" benchmarks can be solved from captions; MemEye explicitly grades whether agents preserve the visual evidence they need later, exposing where current memory pipelines silently lose pixels. _Category:_ 2605.15128. [https://arxiv.org/abs/2605.15128](https://arxiv.org/abs/2605.15128)

- **MemLens: Benchmarking Multimodal Long-Term Memory in Large Vision-Language Models** — Xiyu Ren, Zhaowei Wang, Yiming Du, Zhongwei Xie, Chi Liu, Xinlin Yang et al. _Takeaway:_ First systematic head-to-head between long-context LVLMs and memory-augmented agents on 789 multi-session questions across five memory abilities (extraction, multi-session reasoning, temporal, knowledge update, attribution) — useful design input for agent memory architectures. _Category:_ 2605.14906. [https://arxiv.org/abs/2605.14906](https://arxiv.org/abs/2605.14906)

- **MeMo: Memory as a Model** — Ryan Wei Heng Quek, Sanghyuk Lee, Alfred Wei Lun Leong, Arun Verma, Alok Prakash, Nancy F. Chen et al. _Takeaway:_ Treats agent memory as a separate trainable model wrapped around a frozen LLM — captures cross-document relations and avoids retraining the base model when new knowledge arrives, a credible alternative to RAG and continued pretraining. _Category:_ 2605.15156. [https://arxiv.org/abs/2605.15156](https://arxiv.org/abs/2605.15156)

- **EvolveMem: Self-Evolving Memory Architecture via AutoResearch for LLM Agents** — Jiaqi Liu, Xinyu Ye, Peng Xia, Zeyu Zheng, Cihang Xie, Mingyu Ding et al. _Takeaway:_ Argues adaptive memory must co-evolve at two levels — stored content and the retrieval mechanism itself — and exposes the full retrieval config as an action space an LLM-powered diagnosis module optimizes. Directly relevant to RAG / memory infrastructure design. _Category:_ 2605.13941. [https://arxiv.org/abs/2605.13941](https://arxiv.org/abs/2605.13941)

- **From Scenes to Elements: Multi-Granularity Evidence Retrieval for Verifiable Multimodal RAG (GranuRAG)** — Guanhua Chen, Chuyue Huang, Yutong Yao, Shudong Liu, Xueqing Song, Lidia S. Chao et al. _Takeaway:_ Existing multimodal RAG retrieves whole images/scenes, mismatching fine-grained queries and making failures unverifiable; GranuRAG treats visual elements as first-class retrieval units with a benchmark (GranuVistaVQA) that scores grounded citation at element granularity. _Category:_ 2605.15019. [https://arxiv.org/abs/2605.15019](https://arxiv.org/abs/2605.15019)

- **ML-Embed: Inclusive and Efficient Embeddings for a Multilingual World** — Ziyin Zhang, Zihan Liao, Hang Yu, Peng Di, Rui Wang. _Takeaway:_ Open-source embedding suite built on a new 3-Dimensional Matryoshka Learning framework — addresses compute cost, multilingual coverage, and the closed-weight transparency problem in production embedding stacks. _Category:_ 2605.15081. [https://arxiv.org/abs/2605.15081](https://arxiv.org/abs/2605.15081)

- **AI Knows When It's Being Watched: Functional Strategic Action and Contextual Register Modulation in LLMs** — Vinicius Covas, Jorge Alberto Hidalgo Toledo. _Takeaway:_ Empirically demonstrates multi-agent LLM systems modulate their language register when they perceive they are being observed — a behavioral Hawthorne effect with direct implications for AI auditing and evaluation validity. _Category:_ 2605.15034. [https://arxiv.org/abs/2605.15034](https://arxiv.org/abs/2605.15034)

- **WildClawBench: A Benchmark for Real-World, Long-Horizon Agent Evaluation** — Shuangrui Ding, Xuanlang Dai, Long Xing, Shengyuan Ding, Ziyu Liu, JingYi Yang et al. _Takeaway:_ Native-runtime CLI-harness benchmark of 60 bilingual multimodal tasks (~8 min each, 200+ steps) — moves agent evaluation off synthetic sandboxes and onto realistic long-horizon work. _Category:_ 2605.10912. [https://arxiv.org/abs/2605.10912](https://arxiv.org/abs/2605.10912)

- **Learning to Build the Environment: Self-Evolving Reasoning RL via Verifiable Environment Synthesis** — Yucheng Shi, Zhenwen Liang, Kishan Panaganti, Dian Yu, Wenhao Yu, Haitao Mi. _Takeaway:_ Reframes zero-data reasoning RL as an environment-construction loop (model builds the executable env that grades it) and identifies stable solve-verify asymmetry as the key property for self-improvement to compound. _Category:_ 2605.14392. [https://arxiv.org/abs/2605.14392](https://arxiv.org/abs/2605.14392)

- **Nexus: An Agentic Framework for Time Series Forecasting** — Sarkar Snigdha Sarathi Das, Palash Goyal, Mihir Parmar, Nanyun Peng, Vishy Tirumalashetty, Chun-Liang Li et al. _Takeaway:_ Decomposes forecasting into specialized agent stages that fuse Time Series Foundation Models (numerical) with LLMs (textual/news/event context) — concrete blueprint for multi-agent systems that bridge structured + unstructured signals. _Category:_ 2605.14389. [https://arxiv.org/abs/2605.14389](https://arxiv.org/abs/2605.14389)

- **Achieving Gold-Medal-Level Olympiad Reasoning via Simple and Unified Scaling** — Yafu Li, Runzhe Zhan, Haoran Zhang, Shunkai Zhang, Yizhuo Li, Zhilin Wang et al. _Takeaway:_ Distills a clean recipe — reverse-perplexity SFT curriculum followed by two-stage RL — to turn a post-trained reasoning backbone into an IMO/IPhO gold-medal solver. Useful reference for frontier reasoning model training. _Category:_ 2605.13301. [https://arxiv.org/abs/2605.13301](https://arxiv.org/abs/2605.13301)

- **Boosting RLVR with Verifiable Rewards via Randomly Selected Few-Shot Guidance (FEST)** — Kai Yan, Alexander G. Schwing, Yu-Xiong Wang. _Takeaway:_ Tackles RLVR's sample-efficiency wall on hard problems with a few-shot demonstration-guided algorithm — avoids the heavy SFT data costs of current demonstration-guided RLVR pipelines. _Category:_ 2605.15012. [https://arxiv.org/abs/2605.15012](https://arxiv.org/abs/2605.15012)

- **EndPrompt: Efficient Long-Context Extension via Terminal Anchoring** — Han Tian, Luxuan Chen, Xinran Chen, Rui Kong, Fang Wang, Jiamin Chen et al. _Takeaway:_ Achieves context extension using only short training sequences by anchoring a brief terminal prompt to span the target positional distance — practical recipe that sidesteps the quadratic cost of training on long sequences. _Category:_ 2605.14589. [https://arxiv.org/abs/2605.14589](https://arxiv.org/abs/2605.14589)

## Other interesting items

- **[BOOKMARKS: Efficient Active Storyline Memory for Role-playing](https://arxiv.org/abs/2605.14169)** — Letian Peng et al., search-based memory framework that maintains task-relevant bookmarks instead of lossy recurrent summarization.
- **[Improving Multi-turn Dialogue Consistency with Self-Recall Thinking](https://arxiv.org/abs/2605.15102)** — Renning Pang et al., addresses non-adjacent-turn dependency tracking without high-latency external memory.
- **[Video2GUI: Synthesizing Large-Scale Interaction Trajectories for Generalized GUI Agent Pretraining](https://arxiv.org/abs/2605.14747)** — Weimin Xiong et al., automated extraction of GUI agent training data from unlabeled internet videos.
- **[FrontierSmith: Synthesizing Open-Ended Coding Problems at Scale](https://arxiv.org/abs/2605.14445)** — Runyuan He et al., evolves open-ended training problems from closed-ended tasks to strengthen LLM coders on real-world ambiguous work.
- **[RewardHarness: Self-Evolving Agentic Post-Training](https://arxiv.org/abs/2605.08703)** — Yuxuan Zhang et al., reframes reward modeling as context evolution to close the data-efficiency gap with humans on edit-evaluation rewards.
- **[BEAM: Binary Expert Activation Masking for Dynamic Routing in MoE](https://arxiv.org/abs/2605.14438)** — Juntong Wu et al., token-adaptive expert selection that avoids fixed Top-K redundancy at high sparsity without architectural retraining.
- **[Dynamic Latent Routing](https://arxiv.org/abs/2605.14323)** — Fangyuan Yu et al., jointly learns discrete latent codes, routing policies, and model parameters in one post-training stage via a Dijkstra-style temporal composition.
- **[RouteProfile: Elucidating the Design Space of LLM Profiles for Routing](https://arxiv.org/abs/2605.00180)** — Jingjun Xu et al., disentangles profile design from router design — clarifies how model-capability profiles affect routing performance.
- **[Long Context Pre-Training with Lighthouse Attention](https://arxiv.org/abs/2605.06554)** — Bowen Peng, Subho Ghosh, Jeffrey Quesnelle, training-only sub-quadratic hierarchical attention that wraps SDPA and can be removed at the end of training.
- **[DiffusionOPD: A Unified Perspective of On-Policy Distillation in Diffusion Models](https://arxiv.org/abs/2605.15055)** — Quanhao Li et al., multi-task RL paradigm for diffusion T2I that avoids cross-task interference of joint optimization and catastrophic forgetting of cascade RL.
- **[Non-linear Interventions on Large Language Models](https://arxiv.org/abs/2605.14749)** — Sangwoo Kim, extends interpretability beyond Linear Representation Hypothesis to features on non-linear manifolds — relevant for mechanistic interpretability and safety.
- **[Text Knows What, Tables Know When: Clinical Timeline Reconstruction via Retrieval-Augmented Multimodal Alignment](https://arxiv.org/abs/2605.15168)** — Sayantan Kumar et al., multimodal RAG aligning unstructured narratives with structured EHR for precise clinical event timelines.
