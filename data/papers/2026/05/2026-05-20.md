## Top picks

- **Goal-Oriented Reasoning for RAG-based Memory in Conversational Agentic LLM Systems** — authors n/a. _Takeaway:_ Long-horizon conversational agents fail not on retrieval but on reasoning over retrieved memory; introduces a goal-conditioned reasoning layer over RAG-based memory modules. _Category:_ arXiv 2605.12213. [link](https://arxiv.org/abs/2605.12213)

- **Rethinking RL for LLM Reasoning: It's Sparse Policy Selection, Not Capability Learning** — authors n/a. _Takeaway:_ Token-level analysis across model families shows RL's benefit is a sparse correction at high-entropy decision points — RL chooses among capabilities the base model already has rather than teaching new ones. _Category:_ arXiv 2605.06241. [link](https://arxiv.org/abs/2605.06241)

- **EnergyAgentBench: Benchmarking LLM Agents on Live Energy Infrastructure Data** — authors n/a. _Takeaway:_ First agentic benchmark grounded in live electricity-market data — 70 task variants across datacenter siting, portfolio optimization, and causal grid diagnosis. _Category:_ arXiv 2605.15230. [link](https://arxiv.org/abs/2605.15230)

- **Cattle Trade: A Multi-Agent Benchmark for LLM Bluffing, Bidding, and Bargaining** — authors n/a. _Takeaway:_ Negotiation/bluffing benchmark across 7 cost-efficient LLMs plus 3 deterministic code agents — separates strategic reasoning from raw capability. _Category:_ arXiv 2605.14537. [link](https://arxiv.org/abs/2605.14537)

- **From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms** — authors n/a. _Takeaway:_ Synthesis of how agent memory has moved from KV-store-style retrieval toward experiential, episodic, and self-reflective structures — useful map for memory architecture decisions. _Category:_ arXiv 2605.06716. [link](https://arxiv.org/abs/2605.06716)

- **Code as Agent Harness** — authors n/a. _Takeaway:_ Treats generated code as the orchestration substrate for LLM agents, replacing JSON tool-call plumbing with executable programs that drive tool use. _Category:_ arXiv 2605.18747. [link](https://arxiv.org/abs/2605.18747)

- **ContextualJailbreak: Evolutionary Red-Teaming via Simulated Conversational Priming** — Mario Rodriguez Bejar et al. _Takeaway:_ Black-box red-team that runs evolutionary search over simulated multi-turn primed dialogue — pushes jailbreak research beyond single-shot prompt attacks. _Category:_ arXiv 2605.02647. [link](https://arxiv.org/abs/2605.02647)

- **Redefining AI Red Teaming in the Agentic Era: From Weeks to Hours** — authors n/a. _Takeaway:_ Frames red-teaming itself as an agent task: operator sets strategy, an agent orchestrates probes and attacks, collapsing engagements from weeks to hours. _Category:_ arXiv 2605.04019. [link](https://arxiv.org/abs/2605.04019)

- **Can You Trust the Vectors in Your Vector Database? Black-Hole Attack from Embedding Space Defects** — authors n/a. _Takeaway:_ Geometric defects in high-dim embeddings create "black holes" that capture up to 99.85% of top-10 retrievals — concrete attack surface for RAG/vector-DB stacks. _Category:_ arXiv 2604.05480. [link](https://arxiv.org/abs/2604.05480)

- **Benchmarking Retrieval Strategies for Biomedical Retrieval-Augmented Generation: A Controlled Empirical Study** — authors n/a. _Takeaway:_ Controlled comparison across retrieval strategies; cross-encoder reranking lands at composite 0.827 / contextual precision 0.852 — empirical case for query–document interaction in domain RAG. _Category:_ arXiv 2605.02520. [link](https://arxiv.org/abs/2605.02520)

## Other interesting items

- **[Rethinking Hybrid Retrieval: When Small Embeddings and LLM Re-ranking Beat Bigger Models](https://arxiv.org/pdf/2506.00049)** — Tri-modal hybrid retrieval (dense + sparse + graph) where MiniLM-v6 plus LLM reranking outperforms the much larger BGE-Large.
- **[Self-Aware Vector Embeddings for Retrieval-Augmented Generation](https://arxiv.org/abs/2604.20598)** — SmartVector augments dense embeddings with temporal decay, confidence weighting, and relational awareness for RAG.
- **[On the Theoretical Limitations of Embedding-Based Retrieval](https://arxiv.org/abs/2508.21038)** — Introduces LIMIT, a stress-test dataset on which even SOTA embedders fail; argues for techniques beyond single-vector retrieval.
- **[AstraFlow: Dataflow-oriented RL for Multi-Policy LLM Agent Training](https://huggingface.co/papers/trending)** — Multi-policy collaborative RL training with elastic scaling across heterogeneous compute (HF trending, posted 2026-05-15).
- **[Model Context Protocol (MCP) Tool Descriptions Are Smelly! Towards Improving AI Agent Efficiency with Augmented MCP Tool Descriptions](https://arxiv.org/html/2602.14878v2)** — Code-smell-style analysis of MCP tool descriptions; proposes augmented descriptions to cut agent failures.
- **[Breaking the Protocol: Security Analysis of the Model Context Protocol Specification and Prompt Injection Vulnerabilities in Tool-Integrated LLM Agents](https://arxiv.org/pdf/2601.17549)** — Spec-level security review of MCP and prompt-injection paths in tool-integrated agents.
