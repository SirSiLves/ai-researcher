## Top picks

- **Boiling the Frog: A Multi-Turn Benchmark for Agentic Safety** — Piercosma Bisconti, Matteo Prandi, Federico Pierucci, Federico Sartore. _Takeaway:_ Argues that single-turn safety evals miss the actual deployed-agent risk surface; benchmarks whether tool-using agents can be steered into harmful actions through gradual multi-turn escalation rather than direct asks. Concrete agentic-safety primitive worth tracking. _Category:_ arXiv:2605.22643. [link](https://arxiv.org/abs/2605.22643)

- **Advancing Mathematics Research with AI-Driven Formal Proof Search** — George Tsoukalas, Anton Kovsharov, Sergey Shirobokov, Anja Surina. _Takeaway:_ First large-scale evaluation of LLM-driven Lean proof search on *open* problems — autonomously resolves 9/353 Erdős problems at a few hundred dollars each and 44/492 OEIS conjectures, and is already being used in working math research groups. Real benchmark of LLM-as-research-assistant. _Category:_ arXiv:2605.22763. [link](https://arxiv.org/abs/2605.22763)

- **AMEL: Accumulated Message Effects on LLM Judgments** — Sid-ali Temkit. _Takeaway:_ 75,898 API calls across 11 models (OpenAI, Anthropic, Google, open-source) showing that LLM judges drift toward the prevailing polarity of prior items in the same conversation (d = -0.17, p < 10^-46). Directly relevant to anyone running LLM-as-judge eval pipelines in batches. _Category:_ arXiv:2605.22714. [link](https://arxiv.org/abs/2605.22714)

- **Memory-R2: Fair Credit Assignment for Long-Horizon Memory-Augmented LLM Agents** — Sikuan Yan, Ahmed Bahloul, Ercong Nie, Susanna Schwarzmann. _Takeaway:_ Notes that GRPO-style group-relative RL breaks for memory-augmented agents because rollouts no longer share the same intermediate environment state once they write/update/delete memory differently. Proposes a fair credit-assignment scheme — a real training-loop fix, not just a benchmark. _Category:_ arXiv:2605.21768. [link](https://arxiv.org/abs/2605.21768)

- **Trace2Skill: Verifier-Guided Skill Evolution for Long-Context EDA Agents** — Zijian Du, Nathaniel Pinckney. _Takeaway:_ Test-time scaling for a hardware-design agent that treats the agent's natural-language skill as an evolvable policy — mines repeated rollout traces, distills dense diagnostics, and updates the skill without RTL-specialized fine-tuning. Pattern generalizes well beyond Verilog. _Category:_ arXiv:2605.21810. [link](https://arxiv.org/abs/2605.21810)

- **Self-Policy Distillation via Capability-Selective Subspace Projection** — Guangya Hao, Yitong Shang, Yunbo Long, Zhuokai Zhao. _Takeaway:_ Self-distillation methods either need expensive external curation or train indiscriminately on raw self-outputs; this work projects out task-irrelevant stylistic/formatting subspaces so the distillation signal targets a specific capability. Cleaner alternative to filter-based pipelines. _Category:_ arXiv:2605.22675. [link](https://arxiv.org/abs/2605.22675)

- **Cross-domain benchmarks reveal when coordinated AI agents improve scientific inference from partial evidence** — Fiona Y. Wong, Markus J. Buehler. _Takeaway:_ Four scientific tasks (molecular-to-musical mapping, paradigm-shift detection, disease-emergence, exoplanet vetting) with frozen panels and explicit nulls, used to define *three operating regimes* under which coordinated agents beat simpler workflows. A rare empirical answer to "do we actually need a multi-agent system here?". _Category:_ arXiv:2605.22300. [link](https://arxiv.org/abs/2605.22300)

- **GraphRAG on Consumer Hardware: Benchmarking Local LLMs for Healthcare EHR Schema Retrieval** — Peter Fernandes, Ria Kanjilal. _Takeaway:_ Implements Microsoft's GraphRAG pipeline against real EHR schema docs with Llama 3.1 and other locally-deployed open models. Useful data point for anyone weighing local GraphRAG vs hosted LLMs in regulated/privacy-sensitive domains. _Category:_ arXiv:2605.20815. [link](https://arxiv.org/abs/2605.20815)

- **Bridging the Cold-Start Gap: LLM-Powered Synthetic Data Generation for Natural Language Search at Airbnb** — Wendy Ran Wei, Hao Li, Weiwei Guo, Xiaowei Liu. _Takeaway:_ Production case study from Airbnb on bootstrapping an NL search system with LLM-generated queries and labels — contrastive listing pairs from real booking sessions seed both diversity and realism, with a cold-to-warm transition as real traffic arrives. Useful template for shipping retrieval at scale before you have data. _Category:_ arXiv:2605.21812. [link](https://arxiv.org/abs/2605.21812)

- **Reinforced Preference Optimization for Reasoning-Augmented Recommendations** — Jingtong Gao, Zeyu Song, Chi Lu, Xiaopeng Li. _Takeaway:_ Most "LLM-with-reasoning for recsys" work bolts free-form CoT onto a downstream ranker and loses alignment; this paper formulates the reasoning step itself as a preference-optimization target tied to recommendation objectives. Concrete bridge from CoT to ranking metrics. _Category:_ arXiv:2605.21967. [link](https://arxiv.org/abs/2605.21967)

- **Moral Semantics Survive Machine Translation: Cross-Lingual Evidence from Moral Foundations Corpora** — Maciej Skorski. _Takeaway:_ Tests whether LLM-based translation preserves moral-foundation signal well enough to recycle English moral-values corpora across languages. Four-way validation (LaBSE, CKA, LLM-as-judge, downstream classifiers) on ~50k Polish posts. Relevant to anyone building multilingual content-moderation or value-alignment evals. _Category:_ arXiv:2605.22660. [link](https://arxiv.org/abs/2605.22660)

- **Tokenisation via Convex Relaxations (ConvexTok)** — Jan Tempus, Philip Whittington, Craig W. Schmidt, Dennis Komm. _Takeaway:_ Reformulates tokeniser construction as a linear program (vs the greedy BPE/Unigram default) and shows consistent BpB gains plus a certificate of how far the tokeniser is from optimal. Combine with the same authors' ToaST (2605.22705) for a refreshed tokenization stack. _Category:_ arXiv:2605.22821. [link](https://arxiv.org/abs/2605.22821)

## Other interesting items

- **[Tokenization with Split Trees (ToaST)](https://arxiv.org/abs/2605.22705)** — Schmidt, Krumdick, Wiemerslage, Ebner. Vocabulary selection as an Integer Program over recursive split-trees; near-integral LP relaxation gives provably near-optimal vocabularies.
- **[BeLink: Biomedical Entity Linking Meets Generative Re-Ranking](https://arxiv.org/abs/2605.22501)** — Shlyk, Montanelli, Hunter. Instruction-tuned generative re-ranker for BEL; 3-24% accuracy lift over SOTA with reduced inference cost — clean RAG-adjacent recipe for vertical domains.
- **[Generative Conversational Recommender System](https://arxiv.org/abs/2605.21987)** — Zhang, Liu, Long. Unified autoregressive model that emits both responses and recommended items (as discrete semantic IDs) in one stream, replacing decoupled rec+dialog pipelines.
- **[A Generalized Nash Equilibrium-Seeking Scheme for Trauma Resuscitation](https://arxiv.org/abs/2605.22661)** — Ekpo, Taylor, Molu. Multi-agent control in safety-critical clinical decisions — interesting outside-the-tech-bubble application of multi-agent formalisms.
- **[Diversed Model Discovery via Structured Table Discovery](https://arxiv.org/abs/2605.22766)** — Dong, Miller. Model-card search that combines text + structured-table similarity to surface diverse model candidates instead of near-duplicates — a "model registry as RAG" primitive.
- **[Remember to be Curious: Episodic Context and Persistent Worlds for 3D Exploration](https://arxiv.org/abs/2605.22814)** — Goli, Kerr, Reda. Curiosity-driven RL for long-horizon 3D exploration with persistent world models — embodied-agent memory architecture worth tracking alongside Memory-R2.
