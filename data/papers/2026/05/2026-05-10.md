## Top picks

- **Beyond Semantic Similarity: Rethinking Retrieval for Agentic Search via Direct Corpus Interaction** — _Takeaway:_ Argues retrieval for agents should not be a one-shot embedding lookup; lets the agent interact with the corpus directly, breaking the semantic-similarity ceiling that has plagued RAG. _Category:_ cs.IR / cs.CL. [link](https://arxiv.org/abs/2605.05242)

- **Cited but Not Verified: Parsing and Evaluating Source Attribution in LLM Deep Research Agents** — _Takeaway:_ First systematic eval showing citations produced by deep-research agents (OpenAI/Perplexity-style) often cannot be verified against the underlying sources; introduces a parser+verifier pipeline that flags fabricated/misattributed claims. _Category:_ cs.CL. [link](https://arxiv.org/abs/2605.06635)

- **Superintelligent Retrieval Agent: The Next Frontier of Information Retrieval** — _Takeaway:_ Frames retrieval as an active reasoning loop rather than a black-box lookup; agent issues exploratory queries, inspects snippets, and adapts strategy — practical blueprint for next-gen enterprise RAG. _Category:_ cs.IR. [link](https://arxiv.org/abs/2605.06647)

- **STALE: Can LLM Agents Know When Their Memories Are No Longer Valid?** — _Takeaway:_ New benchmark for memory revision in long-running agents — most current memory systems fail to invalidate beliefs when new evidence arrives. Critical gap for production agent platforms. _Category:_ cs.CL. [link](https://arxiv.org/abs/2605.06527)

- **EnterpriseRAG-Bench: A RAG Benchmark for Company Internal Knowledge** — _Takeaway:_ Purpose-built benchmark for RAG over messy internal corpora (tickets, wikis, code) where existing public RAG benchmarks systematically over-estimate quality. Useful for procurement/eval of enterprise RAG platforms. _Category:_ cs.IR. [link](https://arxiv.org/abs/2605.05253)

- **StraTA: Incentivizing Agentic Reinforcement Learning with Strategic Trajectory Abstraction** — _Takeaway:_ Tackles long-horizon credit assignment in agentic RL by abstracting trajectories into strategy-level units; shows meaningful gains over reactive RLHF/GRPO baselines on multi-step agent tasks. _Category:_ cs.CL / cs.LG. [link](https://arxiv.org/abs/2605.06642)

- **Can RL Teach Long-Horizon Reasoning to LLMs? Expressiveness Is Key** — _Takeaway:_ Systematic study of how RL scaling interacts with task difficulty; finds expressiveness of the reward/representation — not compute alone — gates whether RL transfers reasoning to longer horizons. _Category:_ cs.AI. [link](https://arxiv.org/abs/2605.06638)

- **MASPO: Joint Prompt Optimization for LLM-based Multi-Agent Systems** — _Takeaway:_ Optimizes role prompts across an entire multi-agent system jointly rather than per-role; reports notable gains over per-agent prompt tuning, relevant for agent-orchestration platforms. _Category:_ cs.AI / cs.MA. [link](https://arxiv.org/abs/2605.06623)

## Other interesting items

- **[SkillOS: Learning Skill Curation for Self-Evolving Agents](https://arxiv.org/abs/2605.06614)** — Framework for distilling reusable skills from agent experience streams; addresses the "one-shot agent" problem where deployed agents never accumulate know-how.
- **[Skill1: Unified Evolution of Skill-Augmented Agents via Reinforcement Learning](https://arxiv.org/abs/2605.06130)** — Couples skill discovery and policy learning under one RL objective so skills co-evolve with the agent's policy.
- **[Recursive Agent Optimization](https://arxiv.org/abs/2605.06639)** — RL training for agents that spawn and supervise sub-instances of themselves; relevant to hierarchical/MCP-style decomposition.
- **[Improving the Efficiency of Language Agent Teams with Adaptive Task Graphs](https://arxiv.org/abs/2605.06320)** — Replaces fixed pipelines with dynamically rewired task graphs; targets the cost-vs-flexibility tradeoff in multi-agent orchestration.
- **[Active Learning for Communication Structure Optimization in LLM-Based Multi-Agent Systems](https://arxiv.org/abs/2605.05703)** — Learns who-talks-to-whom topology in MAS, cutting tokens while preserving quality.
- **[Auto Research with Specialist Agents Develops Effective and Non-Trivial Training Recipes](https://arxiv.org/abs/2605.05724)** — Closed-loop auto-research agents that propose, run, and learn from training experiments.
- **[A^2TGPO: Agentic Turn-Group Policy Optimization with Adaptive Turn-level Clipping](https://arxiv.org/abs/2605.06200)** — GRPO-style agentic RL with per-turn adaptive clipping for multi-turn tool use.
- **[Beyond Negative Rollouts: Positive-Only Policy Optimization with Implicit Negative Gradients](https://arxiv.org/abs/2605.06650)** — Verifiable-reward RL variant that learns from positive trajectories only, simplifying the post-PPO/GRPO stack.
- **[OBLIQ-Bench: Exposing Overlooked Bottlenecks in Modern Retrievers with Latent and Implicit Queries](https://arxiv.org/abs/2605.06235)** — New retrieval benchmark for "oblique" queries that current dense retrievers handle poorly; useful diagnostic for embedding-pipeline owners.
- **[When No Benchmark Exists: Validating Comparative LLM Safety Scoring Without Ground-Truth Labels](https://arxiv.org/abs/2605.06652)** — Statistical method for safety-comparing models when no labeled benchmark is available; directly relevant to AI governance / pre-deployment screening.
- **[Why Global LLM Leaderboards Are Misleading: Small Portfolios for Heterogeneous Supervised ML](https://arxiv.org/abs/2605.06656)** — Analyzes ~89K pairwise comparisons across 116 languages and 52 LLMs; shows global leaderboards mask large heterogeneity.
- **[Sustaining Cooperation in Populations Guided by AI: A Folk Theorem for LLMs](https://arxiv.org/abs/2605.06525)** — Theory paper on emergent (mis)coordination when many agents take instructions from the same LLM — governance-relevant.
