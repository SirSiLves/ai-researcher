# AI Papers — 2026-05-15

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Is Grep All You Need? How Agent Harnesses Reshape Agentic Search** — anon. _Takeaway:_ Empirical study of retrieval strategies inside tool-equipped LLM agents — compares lexical (grep), semantic, and hybrid search across harnesses, including long-context regimes. Argues that harness design changes which retrieval primitive wins, undermining one-size-fits-all RAG. _Category:_ arXiv:2605.15184 [cs.IR]. [link](https://arxiv.org/abs/2605.15184)
- **LLM-Oriented Information Retrieval: A Denoising-First Perspective** — anon. _Takeaway:_ Reframes the IR pipeline for LLMs around denoising — maximizing usable evidence density per context window — as the primary bottleneck, with a pipeline-organized taxonomy across indexing, retrieval, context engineering, verification, and agentic workflow. _Category:_ arXiv:2605.00505 [cs.IR]. [link](https://arxiv.org/abs/2605.00505)
- **ExploitBench: A Capability Ladder Benchmark for LLM Cybersecurity Agents** — anon. _Takeaway:_ Tiered cyber-offense benchmark that reveals a sharp capability split between publicly deployed frontier models and the private frontier — direct evidence the closed-vs-open evaluation gap is widening for agentic security tasks. _Category:_ arXiv:2605.14153 [cs.CR]. [link](https://arxiv.org/abs/2605.14153)
- **Reward Hacking Benchmark: Measuring Exploits in LLM Agents with Tool Use** — anon. _Takeaway:_ Multi-step tool-use tasks instrumented with naturalistic shortcut opportunities (skip verification, infer from metadata, tamper with evaluation functions). Quantifies reward hacking in agentic tool use — a missing dimension in current agent evals. _Category:_ arXiv:2605.02964 [cs.AI]. [link](https://arxiv.org/abs/2605.02964)
- **Towards the Next Frontier of LLMs, Training on Private Data: A Cross-Domain Benchmark for Federated Fine-Tuning** — anon. _Takeaway:_ Head-to-head of LoRA / QLoRA / IA3 in federated fine-tuning vs. centralized baseline across domains. Federated performance lands close to centralized; QLoRA/IA3 win on efficiency with marginal accuracy loss. Practical input for enterprise privacy-preserving SFT. _Category:_ arXiv:2605.13936 [cs.LG]. [link](https://arxiv.org/abs/2605.13936)
- **EngiAgent: Fully Connected Coordination of LLM Agents for Open-ended Engineering Problems** — anon. _Takeaway:_ Specialized roles (analysis, modeling, verification, solving, evaluation) coordinated through a fully connected coordinator with flexible feedback routing — outperforms rigid pipeline reflection on feasibility-constrained engineering tasks. _Category:_ arXiv:2605.02289 [cs.MA]. [link](https://arxiv.org/abs/2605.02289)
- **Improving the Efficiency of Language Agent Teams with Adaptive Task Graphs (LATTE)** — anon. _Takeaway:_ Agents collaboratively build and maintain a shared, evolving coordination graph encoding sub-task dependencies, assignments, and progress. Measures finer-grained team metrics (overwrites, concurrent writes, communication overhead, wasted outputs) that flat coordination misses. _Category:_ arXiv:2605.06320 [cs.MA]. [link](https://arxiv.org/abs/2605.06320)
- **From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms** — anon. _Takeaway:_ Evolutionary framework for agent memory in three stages — Storage (trajectory preservation), Reflection (trajectory refinement), Experience (trajectory abstraction). Useful taxonomy as memory becomes the foundation primitive for long-horizon agents. _Category:_ arXiv:2605.06716 [cs.CL]. [link](https://arxiv.org/abs/2605.06716)
- **Position: Agentic AI Orchestration Should Be Bayes-Consistent** — anon. _Takeaway:_ Argues current LLM orchestrators (router/planner/critic stacks) lack a Bayes-consistent decision-theoretic foundation — proposes consistency requirements that orchestration policies must satisfy to avoid degenerate behavior under uncertainty. Theoretical input for agent-platform designers. _Category:_ arXiv:2605.00742 [cs.AI]. [link](https://arxiv.org/abs/2605.00742)
- **Towards Dependable Retrieval-Augmented Generation Using Factual Confidence Prediction** — anon. _Takeaway:_ Adds a calibrated factual-confidence predictor on top of RAG outputs to gate when answers should be surfaced vs. abstained — addresses the silent-hallucination failure mode that's blocking enterprise RAG. _Category:_ arXiv:2605.05244 [cs.CL]. [link](https://arxiv.org/abs/2605.05244)
- **Externalization in LLM Agents: A Unified Review of Memory, Skills, Protocols and Harness Engineering** — anon. _Takeaway:_ Unifies four parallel research lines (memory systems, skill libraries, agent protocols, harness engineering) under "externalization" — the practice of moving state and capability out of the model into structured external components. _Category:_ arXiv:2604.08224 [cs.AI]. [link](https://arxiv.org/abs/2604.08224)
- **A Systematic Survey of Security Threats and Defenses in LLM-Based AI Agents: A Layered Attack Surface Framework** — anon. _Takeaway:_ Threat-modeling framework that decomposes the agent attack surface into layers — prompt, memory, tool, delegation, coordination — and maps known attacks/defenses per layer. Operational input for AI security teams. _Category:_ arXiv:2604.23338 [cs.CR]. [link](https://arxiv.org/abs/2604.23338)

## Other interesting items

- **[GraphInstruct: A Progressive Benchmark for Diagnosing Capability Gaps in LLM Graph Generation](https://arxiv.org/abs/2605.09997)** — anon., six-level progressive benchmark with 800 hand-authored instructions and 1,582 reference solutions evaluating 12 LLMs across 45 model/strategy configs.
- **[Coordination as an Architectural Layer for LLM-Based Multi-Agent Systems](https://arxiv.org/abs/2605.03310)** — anon., 41-87% of multi-agent prod failures are coordination defects, not capability — proposes coordination as a separable architectural layer (carry-over from 2026-05-14, still trending).
- **[Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces](https://arxiv.org/abs/2605.02801)** — anon., 8-family reward taxonomy and 5-decision orchestration decomposition; notes no public RL method yet for the stop-decision (carry-over, expanded coverage).
- **[Enhancing MCP with Context-Aware Server Collaboration](https://arxiv.org/abs/2601.11595)** — anon., extends MCP with cross-server context propagation so multi-MCP-server agent sessions share negotiated state instead of treating each server independently.
- **[Real Faults in Model Context Protocol (MCP) Software: a Comprehensive Taxonomy](https://arxiv.org/abs/2603.05637)** — anon., fault taxonomy mined from real MCP deployments — operational reference for anyone shipping MCP servers.
- **[Securing the Model Context Protocol (MCP): Risks, Controls, and Governance](https://arxiv.org/abs/2511.20920)** — anon., MCP-specific control framework (auth, scoping, audit) tied to standard governance taxonomies.
- **[A Survey on the Security of Long-Term Memory in LLM Agents: Toward Mnemonic Sovereignty](https://arxiv.org/abs/2604.16548)** — anon., introduces "mnemonic sovereignty" — verifiable, recoverable governance over agent memory; threat model for cross-session memory poisoning.
- **[Frontier Lag: Bibliometric Audit of Capability Misrepresentation in Academic AI Eval](https://arxiv.org/abs/2605.04135)** — anon., median academic LLM paper evaluates a model ~10.85 ECI behind frontier (carry-over from 2026-05-14, sustained signal).
- **[Redefining AI Red Teaming in the Agentic Era: From Weeks to Hours](https://arxiv.org/abs/2605.04019)** — anon., automated agentic red-teaming with compliance mapping to OWASP LLM Top 10 / MITRE ATLAS / NIST AI RMF / Google SAIF.
- **[MCP Tool Descriptions Are Smelly! Augmenting MCP Tool Descriptions for Agent Efficiency](https://arxiv.org/abs/2602.14878)** — anon., 856 tools across 103 MCP servers; description-quality smells measurably degrade agent performance — actionable for MCP authors.
