## Top picks

- **FORGE: Self-Evolving Agent Memory With No Weight Updates via Population Broadcast** — Igor Bogdanov, Chung-Horng Lung, Thomas Kunz, Jie Gao, Adrian Taylor, Marzia Zaman. _Takeaway:_ Population-based protocol that evolves prompt-injected natural-language memory for hierarchical ReAct agents — converts failed trajectories into reusable rules/examples, broadcasts the best-performing instance's memory to the population, and freezes converged instances. Concrete blueprint for self-improving agents that doesn't touch model weights. _Category:_ 2605.16233. [https://arxiv.org/abs/2605.16233](https://arxiv.org/abs/2605.16233)

- **Differentiable Mixture-of-Agents Incentivizes Swarm Intelligence of Large Language Models** — Xingjian Wu, Junkai Lu, Siyu Yan, Xiangfei Qiu, Jilin Hu, Chenjuan Guo, Bin Yang. _Takeaway:_ Replaces hand-wired multi-agent topologies with a differentiable, context-aware router that dynamically activates agents at each reasoning step — implicitly simulating diverse communication graphs without static workflows. Direct relevance to agent orchestration design. _Category:_ 2605.15706. [https://arxiv.org/abs/2605.15706](https://arxiv.org/abs/2605.15706)

- **Agentic Discovery of Neural Architectures: AIRA-Compose and AIRA-Design** — Alberto Pepe, Chien-Yu Lin, Despoina Magka, Bilge Acun, Yannan Nellie Wu, Anton Protopopov, Carole-Jean Wu, Yoram Bachrach. _Takeaway:_ LLM agents autonomously design foundation-model architectures beyond Transformers — produces 14 AIRAformer/AIRAhybrid (Transformer-Mamba) variants that beat Llama 3.2 at 1B/3B scales and find more compute-efficient scaling frontiers. Tangible recursive self-improvement evidence. _Category:_ 2605.15871. [https://arxiv.org/abs/2605.15871](https://arxiv.org/abs/2605.15871)

- **Argus: Evidence Assembly for Scalable Deep Research Agents** — Zhen Zhang, Liangcai Su, Zhuo Chen, Xiang Lin, Haotian Xu, Simon Shaolei Du, Kaiyu Yang, Bo An, Lidong Bing, Xinyu Wang. _Takeaway:_ Treats deep research as jigsaw assembly: a Searcher gathers evidence per sub-query while a Navigator maintains a shared evidence graph and identifies missing pieces — avoids the duplication problem of parallel ReAct rollouts. Useful pattern for production research agents (e.g., for this very pipeline). _Category:_ 2605.16217. [https://arxiv.org/abs/2605.16217](https://arxiv.org/abs/2605.16217)

- **ICRL: Learning to Internalize Self-Critique with Reinforcement Learning** — Jianbo Lin, Xiaomin Yu, Yi Xin, Yifu Guo, Zhuosong Jiang, Zhongqi Yue, Weishi Wang, Heqing Zou, Chengwei Qin, Hui Xiong. _Takeaway:_ Jointly trains solver + critic from a shared backbone so that critique-induced gains become unassisted solver ability — critic is rewarded by the solver's subsequent improvement. Practical recipe for closing the gap between guided and unguided LLM performance. _Category:_ 2605.15224. [https://arxiv.org/abs/2605.15224](https://arxiv.org/abs/2605.15224)

- **Nudging Beyond the Comfort Zone: Efficient Strategy-Guided Exploration for RLVR (NudgeRL)** — Chanuk Lee, Sangwoo Park, Minki Kang, Sung Ju Hwang. _Takeaway:_ Tackles RLVR's exploration ceiling without brute-force rollout scaling — conditions each rollout on lightweight strategy-level contexts to induce diverse reasoning trajectories. A simpler alternative to oracle-supervised exploration in reasoning RL. _Category:_ 2605.15726. [https://arxiv.org/abs/2605.15726](https://arxiv.org/abs/2605.15726)

- **STS: Efficient Sparse Attention with Speculative Token Sparsity** — Ceyu Xu, Jiangnan Yu, Yongji Wu, Yuan Xie. _Takeaway:_ Reuses the draft model's attention scores from speculative decoding to build a token-and-head-wise sparsity mask for the target LLM — 2.67x speedup at ~90% sparsity with no retraining. Particularly relevant for multi-million-token agentic inference. _Category:_ 2605.15508. [https://arxiv.org/abs/2605.15508](https://arxiv.org/abs/2605.15508)

- **Towards Generalization of Block Attention via Automatic Segmentation and Block Distillation** — Shuaiyi Li, Zhisong Zhang, Yan Wang, Lei Zhu, Dongyang Ma, Chenlong Deng, Yang Deng, Wai Lam. _Takeaway:_ Two key contributions for RAG: a learned semantic segmenter (30k-instance SemanticSeg dataset, 2k-32k texts across 16 categories) plus block distillation, making block attention practical for KV-cache reuse in long-context retrieval pipelines. _Category:_ 2605.15913. [https://arxiv.org/abs/2605.15913](https://arxiv.org/abs/2605.15913)

- **Reducing the Safety Tax in LLM Safety Alignment with On-Policy Self-Distillation (OPSA)** — Yu Fu, Longxuan Yu, Haz Sameen Shahgir, Zhipeng Wei, Hui Liu, N. Benjamin Erichson, Yue Dong. _Takeaway:_ Identifies off-policy training mismatch as a second source of the reasoning-vs-safety tradeoff and introduces "teacher flip rate" — a measurable criterion for when a privileged safety context converts unsafe responses into safe ones. Concrete alignment recipe with auditable signal. _Category:_ 2605.15239. [https://arxiv.org/abs/2605.15239](https://arxiv.org/abs/2605.15239)

- **SaaS-Bench: Can Computer-Use Agents Leverage Real-World SaaS to Solve Professional Workflows?** — Kean Shi, Zihang Li, Tianyi Ma, Zengji Tu, Jialong Wu, Xinbo Xu, Qingyao Yang, Ruoyu Wu, Weichu Xie, Ming Wu et al. _Takeaway:_ 23 deployable SaaS systems, 106 tasks across six professional domains — moves computer-use agent evaluation off toy GUIs onto realistic cross-application enterprise workflows with long-horizon dependencies. _Category:_ 2605.15777. [https://arxiv.org/abs/2605.15777](https://arxiv.org/abs/2605.15777)

- **SMMBench: A Benchmark for Source-Distributed Multimodal Agent Memory** — Huacan Chai, Yukai Wang, Yingxuan Yang, Dan Peng, Yuanyi Song, Zhihui Fu, Weiwen Liu, Jianghao Lin, Jun Wang, Weinan Zhang. _Takeaway:_ Evaluates whether agents can retrieve, align, and compose multimodal evidence fragmented across heterogeneous sources (conversations, profiles, screenshots, tables, images, docs) — a more realistic memory test than single curated contexts. _Category:_ 2605.15710. [https://arxiv.org/abs/2605.15710](https://arxiv.org/abs/2605.15710)

- **Judge Circuits** — Nils Feldhus, Tanja Baeumel, Elena Golimblevskaia, Qianli Wang, Van Bach Nguyen, Aaron Louis Eidt, Christopher Ebert, Wojciech Samek, Jing Yang, Vera Schmitt, Sebastian Möller, Simon Ostermann. _Takeaway:_ Mechanistically locates a shared "Latent Evaluator" sub-graph in mid-to-late MLPs of Gemma-3/Qwen2.5/Llama-3 that drives LLM-as-judge scores — zero-ablating it collapses judgment while preserving world knowledge. Explains format-induced inconsistency in LLM eval at the circuit level. _Category:_ 2605.16023. [https://arxiv.org/abs/2605.16023](https://arxiv.org/abs/2605.16023)

- **Formal Methods Meet LLMs: Auditing, Monitoring, and Intervention for Compliance of Advanced AI Systems** — Parand A. Alamdari, Toryn Q. Klassen, Sheila A. McIlraith. _Takeaway:_ Combines formal methods with ML to offer offline auditing and runtime monitoring (including predictive sampling-based and intervening monitors) of temporally extended behavioral constraints on black-box LLMs. Direct AI-governance tooling. _Category:_ 2605.16198. [https://arxiv.org/abs/2605.16198](https://arxiv.org/abs/2605.16198)

- **Quantization Undoes Alignment: Bias Emergence in Compressed LLMs Across Models and Precision Levels** — Plawan Kumar Rath, Rahul Maliakkal. _Takeaway:_ 911,100-record controlled study across Qwen2.5-7B, Mistral-7B, Phi-3.5-mini at five precision levels shows 3-bit quantization causes 6-21% of previously unbiased BBQ items to develop new stereotypes. Treats safety failure as threshold-dependent, not gradual — relevant for edge deployment. _Category:_ 2605.15208. [https://arxiv.org/abs/2605.15208](https://arxiv.org/abs/2605.15208)

- **AgentStop: Terminating Local AI Agents Early to Save Energy in Consumer Devices** — Dzung Pham, Kleomenis Katevas, Ali Shahin Shamsabadi, Hamed Haddadi. _Takeaway:_ Quantifies the time/token/energy blowup of local agentic execution on consumer hardware and proposes early termination — a rare empirical look at agent deployment costs outside the cloud, with implications for on-device assistants. _Category:_ 2605.15206. [https://arxiv.org/abs/2605.15206](https://arxiv.org/abs/2605.15206)

- **RecMem: Recurrence-based Memory Consolidation for Efficient and Effective Long-Running LLM Agents** — Zijie Dai, Shiyuan Deng, Sheng Guan, Yizhou Tian, Xin Yao, Xiao Yan, James Cheng. _Takeaway:_ Replaces eager per-step memory writes with recurrence-triggered consolidation — cuts memory-construction token cost by up to 87% while preserving recall quality for long-running agents. A practical fix for the memory-write bottleneck in deployed agentic systems. _Category:_ 2605.16045. [https://arxiv.org/abs/2605.16045](https://arxiv.org/abs/2605.16045)

[https://arxiv.org/abs/2605.13521](https://arxiv.org/abs/2605.13521)

- **SkillSmith: Compiling Agent Skills into Boundary-Guided Runtime Interfaces** — Duling Xu, Zheng Chen, Zaifeng Pan, Jiawei Guan, Dong Dong, Jialin Li, Bangzheng Pu. _Takeaway:_ Compiler-runtime that compiles skill packages offline into minimal executable interfaces — 57.44% token reduction versus exposing raw skill definitions at runtime. Concrete pattern for MCP/tool-use systems trying to keep agent prompts bounded as skill libraries grow. _Category:_ 2605.15215. [https://arxiv.org/abs/2605.15215](https://arxiv.org/abs/2605.15215)

## Other interesting items

- **[DimMem: Dimensional Structuring for Efficient Long-Term Agent Memory](https://arxiv.org/abs/2605.15759)** — Wentao Qiu et al., typed atomic memory units with explicit time/location/reason/purpose fields hit 81.43% on LoCoMo-10 and 78.20% on LongMemEval-S while cutting context cost.
- **[TeamTR: Trust-Region Fine-Tuning for Multi-Agent LLM Coordination](https://arxiv.org/abs/2605.15207)** — Yi Xie et al., formalizes "compounding occupancy shift" in sequential multi-agent finetuning and shows trust-region resampling reduces the penalty from quadratic to linear in agent count.
- **[SDOF: Taming the Alignment Tax in Multi-Agent Orchestration with State-Constrained Dispatch](https://arxiv.org/abs/2605.15204)** — Zhantao Wang, treats LangChain/LangGraph/CrewAI execution as a constrained state machine — 7B GRPO-tuned intent router beats zero-shot GPT-4o on FSM-constrained routing.
- **[VSPO: Vector-Steered Policy Optimization for Behavioral Control](https://arxiv.org/abs/2605.15604)** — Xuechen Zhang et al., uses steering vectors inside GRPO rollouts to up-sample rare target behaviors — solves the sparse-behavioral-reward bottleneck without separate preference data.
- **[Calibrating LLMs with Semantic-level Reward (CSR)](https://arxiv.org/abs/2605.15588)** — Fengfei Yu et al., addresses RLVR's confidence-blind binary reward by training models with semantic-level confidence calibration — important for high-stakes deployments.
- **[Look Before You Leap: Autonomous Exploration for LLM Agents](https://arxiv.org/abs/2605.16143)** — Ziang Ye et al., introduces Exploration Checkpoint Coverage as a verifiable metric and interleaves task-execution and exploration rollouts to fix premature exploitation.
- **[Solvita: Enhancing Large Language Models for Competitive Programming via Agentic Evolution](https://arxiv.org/abs/2605.15301)** — Han Li et al., four-role agentic system (Planner/Solver/Oracle/Hacker) with trainable graph-structured knowledge networks — continuous learning for coding agents without weight updates.
- **[Context Pruning for Coding Agents via Multi-Rubric Latent Reasoning (LaMR)](https://arxiv.org/abs/2605.15315)** — Jingjing Wang et al., decomposes code-relevance pruning into semantic-evidence and dependency-support CRFs with MoE gating — reduces wasted context in repo-scale coding agents.
- **[X-SYNTH: Beyond Retrieval — Enterprise Context Synthesis from Observed Human Attention](https://arxiv.org/abs/2605.15505)** — Guruprasad Raghavan et al., argues retrieval breaks down in enterprise contexts; synthesizes from behavioral attention signatures rather than stored system state.
- **[GRLO: Towards Generalizable Reinforcement Learning in Open-Ended Environments from Zero](https://arxiv.org/abs/2605.15464)** — Shangjian Yin et al., studies whether RLHF-from-scratch on small data generalizes — relevant for the cost-vs-RLVR design choice in post-training.
- **[AstraFlow: Dataflow-Oriented Reinforcement Learning for Agentic LLMs](https://arxiv.org/abs/2605.15565)** — Haizhong Zheng et al., decouples rollout services, dataflow, and training into auto-scaling components — scalable infrastructure for agentic RL workloads.
- **[CAPS: Cascaded Adaptive Pairwise Selection for Efficient Parallel Reasoning](https://arxiv.org/abs/2605.15513)** — Fangzhou Lin et al., adapts how much of each candidate the LLM-judge sees and how comparisons spread across the pool — cuts the cost of pairwise self-verification at test time.
- **[DeltaPrompts: Escaping the Zero-Delta Trap in Multimodal Distillation](https://arxiv.org/abs/2605.15532)** — Jaehun Jung et al., shows 69% of standard distillation prompts are zero-delta (no teacher-student divergence); selecting on answer divergence dramatically improves VLM distillation efficiency.
- **[ASRU: Activation Steering Meets Reinforcement Unlearning for Multimodal LLMs](https://arxiv.org/abs/2605.15687)** — Jiahui Guang et al., adds generation-quality as a core objective for MLLM unlearning — avoids the hallucination/rigidity failure of output-deviation-only methods.
- **[Capability Conditioned Scaffolding for Professional Human-LLM Collaboration](https://arxiv.org/abs/2605.15404)** — Sen Yang, Yinglei Ma, types user expertise into strong/mixed/weak domains to combat "Professional Domain Drift" — over-reliance on AI in areas users cannot verify.
- **[Nexa: Response-Conditioned Parallel-to-Sequential Orchestration for Multi-Agent Systems](https://arxiv.org/abs/2605.15573)** — Nurbek Tastan et al., trainable router that switches between parallel and sequential agent execution per query based on response embeddings — hybrid orchestration beyond static topologies.
