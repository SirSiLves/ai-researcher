# AI Papers — 2026-05-13

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **KV-Fold: One-Step KV-Cache Recurrence for Long-Context Inference** — anonymous (cs.CL/cs.LG submission). _Takeaway:_ Training-free fold over sequence chunks where the KV cache is the accumulator; hits 100% needle-in-a-haystack across 16K–128K tokens on Llama-3.1-8B inside a single 40GB GPU. A practical route to long-context inference without architectural changes — directly relevant to the `kv-cache-handoff` and `long-context-vs-rag` radar threads. _Category:_ arXiv:2605.12471 (cs.CL). [https://arxiv.org/abs/2605.12471](https://arxiv.org/abs/2605.12471)

- **MCP-Cosmos: World Model-Augmented Agents for Complex Task Execution in MCP Environments** — cs.MA submission. _Takeaway:_ "Bring Your Own World Model" strategy that augments an MCP client with a generative world model so the agent can simulate state transitions and refine plans in latent space before executing tool calls. Central to the `mcp-adoption` thread. _Category:_ arXiv:2605.09131 (cs.MA). [https://arxiv.org/abs/2605.09131](https://arxiv.org/abs/2605.09131)

- **ARGUS: Defending LLM Agents Against Context-Aware Prompt Injection** — anonymous (cs.AI submission). _Takeaway:_ Provenance-aware decision auditing for tool-using agents: builds an influence-provenance graph that tracks how untrusted context propagates into agent decisions, then enforces policy at the decision boundary. Important for governance-grade agent deployments. _Category:_ arXiv:2605.03378 (cs.AI). [https://arxiv.org/abs/2605.03378](https://arxiv.org/abs/2605.03378)

- **AgentTrust: Runtime Safety Evaluation and Interception for AI Agent Tool Use** — cs.AI submission. _Takeaway:_ A runtime safety layer that intercepts agent tool calls before execution and returns a structured verdict (allow / warn / block / review). Complements ARGUS — together they sketch a control-plane pattern for enterprise agent platforms. _Category:_ arXiv:2605.04785 (cs.AI). [https://arxiv.org/abs/2605.04785](https://arxiv.org/abs/2605.04785)

- **Authorization Propagation in Multi-Agent AI Systems: Identity Governance as Infrastructure** — cs.MA submission. _Takeaway:_ Treats authorization as a first-class infra concern across A2A and MCP handoffs: how to maintain authz invariants as non-human principals retrieve, delegate, and synthesize across changing trust boundaries. Pairs naturally with the AI-identity thread the radar has been tracking. _Category:_ arXiv:2605.05440 (cs.MA). [https://arxiv.org/abs/2605.05440](https://arxiv.org/abs/2605.05440)

- **Beyond Reasoning: Reinforcement Learning Unlocks Parametric Knowledge in LLMs** — anonymous (cs.LG submission). _Takeaway:_ RL post-training doesn't just sharpen reasoning chains — it also unlocks recall of parametric knowledge in closed-book QA, yielding ~27% average relative gains across three model families. Argues RL post-training reshapes the model's accessible knowledge, not only its reasoning policy. _Category:_ arXiv:2605.07153 (cs.LG). [https://arxiv.org/abs/2605.07153](https://arxiv.org/abs/2605.07153)

- **Rethinking RL for LLM Reasoning: It's Sparse Policy Selection, Not Capability Learning** — cs.LG submission. _Takeaway:_ Companion claim to the above with the opposite conclusion: argues observed RL gains on reasoning come from sparse selection over an existing policy distribution, not from learning new capability. Read as a pair — defines the open question. _Category:_ arXiv:2605.06241 (cs.LG). [https://arxiv.org/abs/2605.06241](https://arxiv.org/abs/2605.06241)

- **Can RL Teach Long-Horizon Reasoning to LLMs? Expressiveness Is Key** — cs.LG submission. _Takeaway:_ Introduces ScaleLogic, a synthetic logical-reasoning framework with independent control over proof-planning depth and logic expressiveness. Finds RL gains scale with expressiveness, not raw chain length — a useful corrective to "longer chains = better reasoning" assumptions. _Category:_ arXiv:2605.06638 (cs.LG). [https://arxiv.org/abs/2605.06638](https://arxiv.org/abs/2605.06638)

- **Byte-Exact Deduplication in Retrieval-Augmented Generation: A Three-Regime Empirical Analysis** — cs.IR submission. _Takeaway:_ Three-regime empirical study of chunk-level dedup across BeIR (0.16% reduction), constructed enterprise patterns (24%), and multi-turn conversational AI (80%). Deterministic inference compute savings at no model-quality cost — concrete plumbing win for production RAG. _Category:_ arXiv:2605.09611 (cs.IR). [https://arxiv.org/abs/2605.09611](https://arxiv.org/abs/2605.09611)

- **FinAgent-RAG: Agentic Retrieval-Augmented Generation for Financial Document Question Answering** — cs.IR submission. _Takeaway:_ Iterative retrieve-reason-verify loops engineered for financial numerical reasoning. Concrete instantiation of `agentic-retrieval` in a vertical (finance) where numeric precision is the long-tail RAG failure mode. _Category:_ arXiv:2605.05409 (cs.IR). [https://arxiv.org/abs/2605.05409](https://arxiv.org/abs/2605.05409)

- **Separating Intelligence from Execution: A Workflow Engine for the Model Context Protocol** — cs.AI submission. _Takeaway:_ Decouples agent reasoning from execution by having an LLM emit a declarative workflow blueprint that an MCP-native engine then executes with a single tool call. Pushes the "compile-once, execute-many" pattern into MCP infrastructure. _Category:_ arXiv:2605.00827 (cs.AI). [https://arxiv.org/abs/2605.00827](https://arxiv.org/abs/2605.00827)

- **STALE: Can LLM Agents Know When Their Memories Are No Longer Valid?** — cs.CL submission. _Takeaway:_ Probes whether agents can detect that stored beliefs have been invalidated by new evidence — a memory-revision benchmark that current memory architectures (Mem0, etc.) largely fail. Sharp eval gap for the agent-memory subfield. _Category:_ arXiv:2605.06527 (cs.CL). [https://arxiv.org/abs/2605.06527](https://arxiv.org/abs/2605.06527)

## Other interesting items

- **[Reformulating KV Cache Eviction Problem for Long-Context LLM Inference](https://arxiv.org/abs/2605.07234)** — cs.LG. Introduces LaProx — first eviction strategy with globally comparable per-token importance scores, modeling the multiplicative attention/value interaction explicitly.
- **[Novelty-based Tree-of-Thought Search for LLM Reasoning and Planning](https://arxiv.org/abs/2605.06040)** — cs.LG. Augments ToT with a novelty signal to avoid the dominant failure mode of over-exploiting one branch.
- **[Multi-User Large Language Model Agents](https://arxiv.org/abs/2604.08567)** — cs.AI. Most agent stacks assume single-principal interaction; this one designs for multiple users with distinct roles, preferences, authority. Highly relevant to enterprise agent platforms.
- **[ProgramBench: Can Language Models Rebuild Programs From Scratch?](https://arxiv.org/abs/2605.03546)** — cs.AI. Coding-agent benchmark that goes harder than SWE-bench by asking for program reconstruction rather than issue resolution.
- **[Modality-Native Routing in Agent-to-Agent Networks: A Multimodal A2A Protocol Extension](https://arxiv.org/abs/2604.12213)** — cs.MA. Extends Google's A2A so Agent Cards can declare modality capabilities; +20pp accuracy over text-bottleneck baselines. Concrete A2A protocol evolution.
- **[Mem0: Memory-Centric Architecture with Graph-Based Memory](https://huggingface.co/papers)** — HF-trending. Graph memory layer that extracts, consolidates, and retrieves long-term conversational state; reported wins over prior memory systems on both accuracy and compute.
- **[GenericAgent: Self-Evolving LLM Agent with Hierarchical Memory and Reusable SOPs](https://huggingface.co/papers)** — HF-trending. Hierarchical memory + SOP reuse + compression to push past long-horizon context limits — the pattern several frontier labs are converging on.
- **[DFlash: Block-Diffusion Speculative Decoding](https://huggingface.co/papers)** — HF-trending. Block-diffusion drafter for speculative decoding; sizable speedup over AR drafters without quality loss.
- **[AI-Trader: Live Benchmark for LLMs in Financial Decision-Making](https://huggingface.co/papers)** — HF-trending. Fully automated live benchmark across multiple markets — agent eval with real-time financial ground truth.
