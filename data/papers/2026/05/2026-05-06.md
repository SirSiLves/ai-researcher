# AI Papers — 2026-05-06

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

**Coordination as an Architectural Layer for LLM-Based Multi-Agent Systems** — Maksym Nechepurenko, Pavel Shuvalov. _Takeaway:_ Multi-agent LLM systems fail at rates 41-87% due to coordination defects; proposes treating coordination as a configurable architecture layer separate from agent logic; demonstrates via prediction-market testbed that different coordination configurations produce distinct signatures and Pareto frontiers. _Category:_ cs.MA. [https://arxiv.org/abs/2605.03310](https://arxiv.org/abs/2605.03310)

**MemFlow: Intent-Driven Memory Orchestration for Small Language Model Agents** — Jiayi Chen, Yingcong Li, Guiling Wang. _Takeaway:_ SLMs struggle with long-horizon memory; proposes training-free framework that externalizes memory planning via intent routing and deterministic evidence preparation instead of open-ended reasoning; achieves 2x accuracy improvement on frozen Qwen3-1.7B backbone. _Category:_ cs.MA. [https://arxiv.org/abs/2605.03312](https://arxiv.org/abs/2605.03312)

**RAG over Thinking Traces Can Improve Reasoning Tasks** — Negar Arabzadeh, Wenjie Ma, Sewon Min, Matei Zaharia. _Takeaway:_ Challenges assumption that RAG doesn't help reasoning; shows that retrieving problem-solving thinking traces (not documents) improves reasoning benchmarks (AIME +56% for Gemini-2.5-Flash, GPQA-Diamond +7.6% for GPT-5) while reducing inference cost. _Category:_ cs.IR. [https://arxiv.org/abs/2605.03344](https://arxiv.org/abs/2605.03344)

**Beyond Similarity Search: A Unified Data Layer for Production RAG Systems** — Venkata Krishna Prasanth Budigi, Siri Chandana Sirigiri. _Takeaway:_ Production RAG systems fail due to data staleness, tenant leakage, and query composition explosion; proposes unified PostgreSQL+pgvector data layer eliminating split-system gaps; achieves 92% latency reduction for filtered queries and zero cross-tenant leakage. _Category:_ cs.IR. [https://arxiv.org/abs/2605.03275](https://arxiv.org/abs/2605.03275)

**When Safety Geometry Collapses: Fine-Tuning Vulnerabilities in Agentic Guard Models** — Authors listed in cs.LG. _Takeaway:_ Safety guard models used in agentic AI are vulnerable to fine-tuning attacks; demonstrates fine-tuning-based jailbreaks that compromise agent safety mechanisms. _Category:_ cs.LG. [https://arxiv.org/abs/2605.02914](https://arxiv.org/abs/2605.02914)

**SURE-RAG: Sufficiency and Uncertainty-Aware Evidence Verification for Selective RAG** — Jingxi Qiu, Zeyu Han, Cheng Huang. _Takeaway:_ Proposes multi-hop evidence sufficiency verification for RAG; treats sufficiency as set-level property rather than per-passage; calibrated SURE-RAG reaches 0.9075 Macro-F1 on HotpotQA-RAG with auditable decision-making; reduces unsafe answers by 37%. _Category:_ cs.IR. [https://arxiv.org/abs/2605.03534](https://arxiv.org/abs/2605.03534)

**Physics-Grounded Multi-Agent Architecture for Traceable, Risk-Aware Human-AI Decision Support in Manufacturing** — Danny Hoang, Ryan Matthiessen, Christopher Miller, et al. _Takeaway:_ Multi-agent LLM orchestration for high-stakes manufacturing (CNC machining); separates intent routing, quantitative analysis, knowledge-graph retrieval, and critic verification; improves tool execution by up to 87.5% over unstructured LLM interaction. _Category:_ cs.MA. [https://arxiv.org/abs/2605.04003](https://arxiv.org/abs/2605.04003)

**Enwar 3.0: An Agentic Multi-Modal LLM Orchestrator for Situation-Aware Beamforming** — Ahmad M. Nazar, Abdulkadir Celik, Asmaa Abdallah, et al. _Takeaway:_ Agentic LLM framework for mmWave vehicular networks; integrates multi-modal sensing, agent orchestration via chain-of-thought priming, and context-driven model selection; achieves 88% beam accuracy and 98% blockage F1. _Category:_ cs.MA. [https://arxiv.org/abs/2605.03215](https://arxiv.org/abs/2605.03215)

**Rethinking Reasoning-Intensive Retrieval: Evaluating and Advancing Retrievers in Agentic Search Systems** — Yilun Zhao, Jinbiao Wei, Tingyu Song, et al. _Takeaway:_ Proposes BRIGHT-Pro benchmark (multi-aspect gold evidence) and aspect-decomposed synthetic corpus for training reasoning-intensive retrievers; aspect-aware evaluation exposes retrieval behaviors hidden by standard metrics in agentic search. _Category:_ cs.IR. [https://arxiv.org/abs/2605.04018](https://arxiv.org/abs/2605.04018)

**QKVShare: Quantized KV-Cache Handoff for Multi-Agent On-Device LLMs** — Pratik Honavar, Tejpratap GVSL. _Takeaway:_ Framework for efficient KV-cache handoff between on-device agents via token-level mixed-precision quantization; reduces TTFT relative to re-prefill at 8K context from 1029.7ms to 397.1ms; enables context sharing in edge multi-agent systems. _Category:_ cs.AI. [https://arxiv.org/abs/2605.03884](https://arxiv.org/abs/2605.03884)

**Soft Tournament Equilibrium** — Saad Alqithami. _Takeaway:_ For non-transitive agent interactions (cyclic competition), proposes STE: differentiable framework computing set-valued tournament solutions (Top Cycle, Uncovered Set) with continuous membership scores; re-centers agent evaluation on stable, set-valued equilibria instead of unstable rankings. _Category:_ cs.MA. [https://arxiv.org/abs/2604.04328](https://arxiv.org/abs/2604.04328)

**FINER-SQL: Boosting Small Language Models for Text-to-SQL** — Thanh Dat Hoang, Thanh Trung Huynh, Matthias Weidlich, et al. _Takeaway:_ Reinforcement learning framework for SLM Text-to-SQL using dense, interpretable rewards (memory + atomic rewards); achieves 67.73% execution accuracy on BIRD with 3B model, matching much larger LLMs while reducing latency to 5.57s/sample. _Category:_ cs.MA. [https://arxiv.org/abs/2605.03465](https://arxiv.org/abs/2605.03465)

**COMPASS: Closed-Loop Vision-Language Planning for Multi-Agent Coordination** — Zhiyuan Li, Wenshuai Zhao, Joni Pajarinen. _Takeaway:_ Multi-agent framework integrating VLMs for decentralized, closed-loop planning; generates interpretable code-based strategies with multi-hop communication; achieves 57% win rate on SMACv2 Protoss 5v5 (30pp ahead of QMIX). _Category:_ cs.AI. [https://arxiv.org/abs/2502.10148](https://arxiv.org/abs/2502.10148)

**Descent-Guided Policy Gradient for Scalable Cooperative Multi-Agent Learning** — Shan Yang, Yang Liu. _Takeaway:_ MARL framework using noise-free descent signals from differentiable analytical models; reduces policy-gradient variance from O(N) to O(1); converges within 20 episodes on 1500-agent cloud scheduling vs. MAPPO/IPPO divergence. _Category:_ cs.MA. [https://arxiv.org/abs/2602.20078](https://arxiv.org/abs/2602.20078)

**Generate, Filter, Control, Replay: A Comprehensive Survey of Rollout Strategies for LLM Reinforcement Learning** — Authors in cs.LG. _Takeaway:_ Comprehensive survey of rollout strategies (generation, filtering, control, replay) for LLM reinforcement learning optimization. _Category:_ cs.LG. [https://arxiv.org/abs/2605.02913](https://arxiv.org/abs/2605.02913)
