# AI Papers — 2026-05-19

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **The Scaling Laws of Skills in LLM Agent Systems** — Charles Chen, Qiming Yu, Yuhang Gu, Zhuoye Huang, Hanjing Li, Hongyu Liu, Simin Liu, Jinhao Liu, Dengyun Peng, Jiangyi Wang, Zheng Yan, Fanqing Meng, Ethan Qin et al. _Takeaway:_ Across 15 frontier LLMs, 1,141 real-world skills, and over 3M routing/execution decisions, identifies two coupled laws: single-step routing accuracy decays logarithmically with library size (R^2 > 0.97), and correct execution can rescue routing errors by ~4x — coupled by a single decay-slope parameter. First quantitative scaling theory for agent skill libraries, directly relevant to anyone building skill marketplaces. _Category:_ 2605.16508. [https://arxiv.org/abs/2605.16508](https://arxiv.org/abs/2605.16508)

- **ADR: An Agentic Detection System for Enterprise Agentic AI Security** — Chenning Li, Pan Hu, Justin Xu, Baris Ozbas, Olivia Liu, Caroline Van, Manxue Li, Wei Zhou, Mohammad Alizadeh, Pengyu Zhang, KK Sriramadhesikan, Ming Zhang. _Takeaway:_ Claims to be the first production-proven enterprise framework for securing MCP-based AI agents — combines an ADR Sensor for agentic telemetry, an Expert reasoning layer, and cost-aware inference to address the three gaps EDR/static defenses leave open (observability, robustness, cost). Direct evidence MCP security tooling is moving from research to deployed product. _Category:_ 2605.17380. [https://arxiv.org/abs/2605.17380](https://arxiv.org/abs/2605.17380)

- **TOBench / MM-ToolBench: A Task-Oriented Omni-Modal Benchmark for Real-World Tool-Using Agents** — Zhiqiang Liu, Wenhui Dong, Yilang Tan, Yuwen Qu, Haochen Yin, Chenyang Si. _Takeaway:_ 100 executable tasks across Customer Service and Intelligent Creation domains, 20 subcategories, 27 MCP servers exposing 324 tools — finally evaluates tool use, computer use, and multimodal reasoning together rather than in isolation. Sets the bar for end-to-end omni-modal agent benchmarks. _Category:_ 2605.16909. [https://arxiv.org/abs/2605.16909](https://arxiv.org/abs/2605.16909)

- **Code as Agent Harness** — Xuying Ning, Katherine Tieu, Dongqi Fu, Tianxin Wei, Zihao Li, Yuanchen Bei, Jiaru Zou, Mengting Ai, Zhining Liu, Ting-Wei Li, Lingjie Chen et al. _Takeaway:_ Reframes code not as agent output but as the operational substrate for reasoning, acting, environment modeling, and verification — a "harness" view that unifies interface, mechanism, and infrastructure layers. Useful conceptual scaffolding for anyone designing tool/skill systems instead of yet another tool-calling schema. _Category:_ 2605.18747. [https://arxiv.org/abs/2605.18747](https://arxiv.org/abs/2605.18747)

- **ConflictRAG: Detecting and Resolving Knowledge Conflicts in Retrieval Augmented Generation** — Chenyu Wang, Yingmin Liu, Yang Shu. _Takeaway:_ Two-stage conflict detection (embedding MLP + selective LLM refinement) reduces API costs 62% while keeping 90.8% detection accuracy; adds an Entropy-TOPSIS source-credibility scorer (+7.1% selection accuracy over manual heuristics) and CARS, a diagnostic conflict-handling metric. Concrete recipe for fixing RAG's silent "all retrieved docs agree" assumption. _Category:_ 2605.17301. [https://arxiv.org/abs/2605.17301](https://arxiv.org/abs/2605.17301)

- **PropGuard: Safeguarding LLM-MAS via Propagation-Aware Exploration and Remediation** — Bingyu Yan, Xiaoming Zhang, Jinyu Hou, Chaozhuo Li, Ziyi Zhou, Xiaozhe Zhang, Litian Zhang. _Takeaway:_ Multi-agent prompt-injection defense that constructs a dual-view spatio-temporal graph (response-centric risk + full-state evidence) to trace fine-grained propagation paths and remediate contaminated state without disrupting benign collaboration. Moves beyond local filtering and anomaly detection that dominate current LLM-MAS defenses. _Category:_ 2605.16346. [https://arxiv.org/abs/2605.16346](https://arxiv.org/abs/2605.16346)

- **Agent Bazaar: Enabling Economic Alignment in Multi-Agent Marketplaces** — Seth Karten, Cameron Crow, Chi Jin. _Takeaway:_ Multi-agent marketplace simulation that surfaces two systemic failure modes when LLM agents become economic actors: algorithmic instability ("The Crash" in B2C) and sybil deception ("The Lemon Market" in C2C, where one agent floods with coordinated seller identities). Introduces "Economic Alignment" as a distinct safety axis from individual capability failure. _Category:_ 2605.17698. [https://arxiv.org/abs/2605.17698](https://arxiv.org/abs/2605.17698)

- **LongMINT: Evaluating Memory under Multi-Target Interference in Long-Horizon Agent Systems** — Hyunji Lee, Justin Chih-Yao Chen, Joykirat Singh, Zaid Khan, Elias Stengel-Eskin, Mohit Bansal. _Takeaway:_ Benchmark for memory-augmented agents under realistic interference — long, interconnected contexts with frequently updated information across state tracking, multi-turn dialogue, and Wikipedia retrieval. Targets the gap that LoCoMo/LongMemEval miss: dynamic interactions between evolving memories, not just static recall. _Category:_ 2605.18565. [https://arxiv.org/abs/2605.18565](https://arxiv.org/abs/2605.18565)

- **SkillsVote: Lifecycle Governance of Agent Skills from Collection, Recommendation to Evolution** — Hongyi Liu, Haoyan Yang, Tao Jiang, Bo Tang, Feiyu Xiong, Zhiyu Li. _Takeaway:_ Treats Agent Skills as a versioned, governed experience schema (executable scripts + non-executable guidance) rather than raw trajectories — profiles a million-scale corpus, synthesizes verifiable tasks, and provides an agentic library-search step before execution. Complementary to today's Scaling Laws paper: the governance side of the skill-library problem. _Category:_ 2605.18401. [https://arxiv.org/abs/2605.18401](https://arxiv.org/abs/2605.18401)

- **AgentWall: A Runtime Safety Layer for Local AI Agents** — Ashwin Aravind. _Takeaway:_ Runtime sandbox for local agents (shell, filesystem, API, browser actions) — intercepts the moment intent becomes action on a real machine. Targets the gap left by model alignment and input filtering: there's nothing standing between an injected agent and your dev box. Useful pattern as local coding agents proliferate. _Category:_ 2605.16265. [https://arxiv.org/abs/2605.16265](https://arxiv.org/abs/2605.16265)

- **EnvFactory: Scaling Tool-Use Agents via Executable Environments Synthesis and Robust RL** — Minrui Xu, Zilin Wang, Mengyi Deng, Zhiwei Li, Zhicheng Yang, Xiao Zhu, Yinhong Liu, Boyu Zhu, Baiyu Huang, Chao Chen, Heyuan Deng, Fei Mi, Lifeng Shang et al. _Takeaway:_ Fully automated pipeline that explores and verifies stateful executable tool environments from authentic sources — fixes the two bottlenecks in agentic RL (no scalable environments, no realistic data) without depending on costly APIs or hallucination-prone LLM simulators. Trajectories preserve implicit human reasoning rather than over-specified instruction sequences. _Category:_ 2605.18703. [https://arxiv.org/abs/2605.18703](https://arxiv.org/abs/2605.18703)

- **TriAxialKV: Toward Extreme Low-Precision KV-Cache Quantization for Agentic Inference Tasks** — Hanzhang Shen, Haoran Wu, Yiren Zhao, Robert Mullins. _Takeaway:_ Recognizes that agentic contexts have heterogeneity along three axes — temporal recency, modality (text/image), and semantic role (user query/tool call/observation/reasoning) — and quantizes the KV cache differently per axis. First KV-cache compression scheme designed specifically for the structured multi-turn tool-calling traces that dominate agent inference. _Category:_ 2605.17170. [https://arxiv.org/abs/2605.17170](https://arxiv.org/abs/2605.17170)

- **Monitoring the Internal Monologue: Probe Trajectories Reveal Reasoning Dynamics** — Maciej Chrabąszcz, Aleksander Szymczyk, Marcin Sendera, Tomasz Trzciński, Sebastian Cygert. _Takeaway:_ Replaces single-token concept probes with probe trajectories — the continuous evolution of a concept's probability across the entire CoT — extracts signal-processing features (volatility, drift) that predict future model behavior better than static probes or unfaithful CoT text. Concrete tool for white-box reasoning-model safety monitoring. _Category:_ 2605.18549. [https://arxiv.org/abs/2605.18549](https://arxiv.org/abs/2605.18549)

- **AI for Auto-Research: Roadmap & User Guide** — Lingdong Kong, Xian Sun, Wei Chow, Linfeng Li, Kevin Qinghong Lin, Xuan Billy Zhang, Song Wang, Rong Li, Qing Wu, Wei Gao, Yingshuo Wang, Shaoyuan Xie, Jiachen et al. _Takeaway:_ End-to-end map of automated research through April 2026 across four epistemological phases (Creation, Writing, Validation, Dissemination) — flags that $15 auto-papers are now real but frontier LLMs still fabricate results, miss hidden errors, and misjudge novelty. Useful framing for anyone building research-agent pipelines (including this one). _Category:_ 2605.18661. [https://arxiv.org/abs/2605.18661](https://arxiv.org/abs/2605.18661)

- **SE-GA: Memory-Augmented Self-Evolution for GUI Agents** — Shilong Jin, Lanjun Wang, Zhuosheng Zhang. _Takeaway:_ Combines hierarchical episodic/semantic/experiential memory (Test-Time Memory Extension) with a training pipeline (Memory-Augmented Self-Evolution) that promotes test-time-collected data back into the base model — closes the loop between inference-time retrieval and policy improvement for GUI agents. _Category:_ 2605.16883. [https://arxiv.org/abs/2605.16883](https://arxiv.org/abs/2605.16883)

## Other interesting items

- **[Stop When Reasoning Converges: Semantic-Preserving Early Exit for Reasoning Models](https://arxiv.org/abs/2605.17672)** — Dehai Min et al. Identifies reasoning-level semantic redundancy (not just answer-readiness) as the right early-exit signal for LRMs — preserves accuracy while cutting overthinking tokens.
- **[NGM: A Plug-and-Play Training-Free Memory Module for LLMs](https://arxiv.org/abs/2605.16893)** — Yuwen Qu et al. N-gram Memory module that averages pretrained token embeddings as N-gram representations — explicit lookup over a frozen backbone with zero new parameters or training.
- **[Post-Trained MoE Can Skip Half Experts via Self-Distillation (ZEDA)](https://arxiv.org/abs/2605.18643)** — Xingtai Lv et al. Converts a fully trained static MoE into a dynamic one by injecting parameter-free zero-output experts and self-distilling — easy tokens skip half the experts at serving time.
- **[AMR-SD: Asymmetric Meta-Reflective Self-Distillation for Token-Level Credit Assignment](https://arxiv.org/abs/2605.18529)** — Zhenlin Wei et al. Fixes GRPO's sequence-level reward problem by inserting a reflection bottleneck between the self-teacher and the oracle trace — avoids the answer-leakage that plagues raw-context self-distillation in RLVR.
- **[Internalizing Tool Knowledge in Small Language Models via QLoRA Fine-Tuning](https://arxiv.org/abs/2605.17774)** — Yuval Shemla et al. 8-bit QLoRA on ~1,700 tool-use examples lets Gemma 4 E4B and Qwen3-4B plan under description-free inference (no tool schemas in the prompt) — practical recipe for shrinking agent prompt token overhead.
- **[Skim: Speculative Execution for Fast and Efficient Web Agents](https://arxiv.org/abs/2605.16565)** — Mike Wong et al. Profiles purpose-built websites' stable URL/answer patterns offline so most queries skip frontier inference, browser rendering, and ReAct planning entirely — verified by a lightweight gate.
- **[OProver: A Unified Framework for Agentic Formal Theorem Proving](https://arxiv.org/abs/2605.17283)** — David Ma et al. Lean 4 prover that iteratively repairs failed proofs using retrieved verified proofs + compiler feedback — agentic loop is part of training, not just inference.
