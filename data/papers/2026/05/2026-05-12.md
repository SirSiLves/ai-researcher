# AI Papers — 2026-05-12

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **ComplexMCP: Evaluation of LLM Agents in Dynamic, Interdependent, and Large-Scale Tool Sandbox** — anonymous (cs.AI submission). _Takeaway:_ First MCP-native evaluation that models tool interdependence and dynamic state — fills the gap between toy MCP demos and the messy reality of production MCP servers where calls mutate the environment for later calls. _Category:_ arXiv:2605.10787 (cs.AI). [https://arxiv.org/abs/2605.10787](https://arxiv.org/abs/2605.10787)

- **MCP-Cosmos: World Model-Augmented Agents for Complex Task Execution in MCP Environments** — cs.MA submission. _Takeaway:_ Bolts a learned world model onto an MCP client so the agent simulates likely outcomes of tool calls before invoking them — directly relevant to anyone wiring Anthropic/OpenAI agents into multi-tool MCP stacks. _Category:_ arXiv:2605.09131 (cs.MA). [https://arxiv.org/abs/2605.09131](https://arxiv.org/abs/2605.09131)

- **Safe, or Simply Incapable? Rethinking Safety Evaluation for Phone-Use Agents** — HF-trending. _Takeaway:_ Argues current phone-use-agent safety benchmarks reward incapable agents (an agent that fails the task can't cause harm) — proposes capability-controlled evaluation. Important framing for governance teams scoring computer-use / mobile-agent vendors. _Category:_ arXiv:2605.07630 (HF Papers). [https://arxiv.org/abs/2605.07630](https://arxiv.org/abs/2605.07630)

- **Rethinking Agentic Search with Pi-Serini: Is Lexical Retrieval Sufficient?** — cs.IR submission. _Takeaway:_ Stress-tests whether expensive embedding-based retrieval actually beats BM25 once an agent is in the loop; finds lexical retrieval is competitive or better in agentic-search workloads. Counters the vector-DB-everywhere reflex. _Category:_ arXiv:2605.10848 (cs.IR). [https://arxiv.org/abs/2605.10848](https://arxiv.org/abs/2605.10848)

- **Route Before Retrieve: Activating Latent Routing Abilities of LLMs for RAG vs. Long-Context Selection** — cs.CL submission. _Takeaway:_ Treats the RAG-vs-long-context decision as a per-query routing problem and shows LLMs already encode the signal needed to pick — practical recipe for hybrid retrieval stacks. _Category:_ arXiv:2605.10235 (cs.CL). [https://arxiv.org/abs/2605.10235](https://arxiv.org/abs/2605.10235)

- **WildClawBench: A Benchmark for Real-World, Long-Horizon Agent Evaluation** — cs.CL submission. _Takeaway:_ Follow-up to ClawBench (referenced in the radar taxonomy) with longer-horizon, in-the-wild tasks; another datapoint that today's agent benchmarks are saturating and need harder cousins. _Category:_ arXiv:2605.10912 (cs.CL). [https://arxiv.org/abs/2605.10912](https://arxiv.org/abs/2605.10912)

- **Can Agent Benchmarks Support Their Scores? Evidence-Supported Bounds for Interactive-Agent Evaluation** — cs.AI submission. _Takeaway:_ Methodology paper that derives statistical confidence bounds for agent-benchmark scores — agent leaderboards typically report single point estimates from few runs, this gives the error bar. Should change how vendors publish eval numbers. _Category:_ arXiv:2605.10448 (cs.AI). [https://arxiv.org/abs/2605.10448](https://arxiv.org/abs/2605.10448)

- **A Single Neuron Is Sufficient to Bypass Safety Alignment in Large Language Models** — HF-trending. _Takeaway:_ Identifies one neuron whose suppression removes refusal behavior across multiple aligned models — striking interpretability/safety finding, with obvious red-team and governance implications. _Category:_ arXiv:2605.08513 (cs.LG / HF). [https://arxiv.org/abs/2605.08513](https://arxiv.org/abs/2605.08513)

- **Dynamic Skill Lifecycle Management for Agentic Reinforcement Learning** — cs.LG submission. _Takeaway:_ Treats agent skills as a managed lifecycle (acquisition, refinement, retirement) rather than a fixed library; meaningful pattern as agents accumulate persistent skills across sessions. _Category:_ arXiv:2605.10923 (cs.LG, also HF). [https://arxiv.org/abs/2605.10923](https://arxiv.org/abs/2605.10923)

- **Designing Intelligent Enterprise Agents: A Capability-Aligned Multi-Agent Architecture** — cs.MA submission. _Takeaway:_ Reference architecture for enterprise multi-agent deployments aligned to a capability taxonomy — useful skeleton for the SAP/Salesforce/ServiceNow-style enterprise agent stack the radar tracks under `agent-platforms-enterprise`. _Category:_ arXiv:2605.08258 (cs.MA). [https://arxiv.org/abs/2605.08258](https://arxiv.org/abs/2605.08258)

- **PRISM: Generation-Time Detection and Mitigation of Secret Leakage in Multi-Agent LLM Pipelines** — cs.AI submission. _Takeaway:_ Inline guardrail that detects and redacts secrets (API keys, PII, internal URLs) as agents stream — practical safety primitive for multi-agent MCP pipelines where one agent's context can leak through another's tool call. _Category:_ arXiv:2605.10614 (cs.AI). [https://arxiv.org/abs/2605.10614](https://arxiv.org/abs/2605.10614)

- **Shepherd: A Runtime Substrate Empowering Meta-Agents with a Formalized Execution Trace** — cs.AI / HF. _Takeaway:_ Proposes a formal trace format so meta-agents (agents that orchestrate other agents) can reason over what their workers did — close cousin to the OpenTelemetry-for-AI thread the radar is tracking. _Category:_ arXiv:2605.10913 (cs.AI). [https://arxiv.org/abs/2605.10913](https://arxiv.org/abs/2605.10913)

## Other interesting items

- **[Human-Inspired Memory Architecture for LLM Agents](https://arxiv.org/abs/2605.08538)** — cs.IR. Working/episodic/semantic memory split for agents; competing design against the "everything in context" school.
- **[MemReread: Enhancing Agentic Long-Context Reasoning via Memory-Guided Rereading](https://arxiv.org/abs/2605.10268)** — cs.CL. Lets the agent re-read prior context with memory-guided attention rather than relying on linear position decay.
- **[OrchJail: Jailbreaking Tool-Calling Text-to-Image Agents by Orchestration-Guided Fuzzing](https://arxiv.org/abs/2605.07414)** — cs.MA. Attacks the orchestration layer (not the model) — relevant for anyone building agentic image pipelines.
- **[RUBEN: Rule-Based Explanations for Retrieval-Augmented LLM Systems](https://arxiv.org/abs/2605.10862)** — cs.CL. Explainability layer for RAG that surfaces which rules / sources drove the answer; useful for governance-grade RAG.
- **[Collective Alignment in LLM Multi-Agent Systems: Disentangling Bias from Cooperation via Statistical Physics](https://arxiv.org/abs/2605.10528)** — cs.MA. Formal model of when multi-agent systems converge on a shared bias versus genuinely cooperate.
- **[The Bystander Effect in Multi-Agent Reasoning: Quantifying Cognitive Loafing in Collaborative Interactions](https://arxiv.org/abs/2605.10698)** — cs.MA. Multi-agent setups can produce diffusion-of-responsibility failures; quantifies the effect and shows it grows with team size.
- **[Safe Multi-Agent Behavior Must Be Maintained, Not Merely Asserted: Constraint Drift in LLM-Based Multi-Agent Systems](https://arxiv.org/abs/2605.10481)** — cs.MA. Documents how safety constraints quietly erode across multi-agent rounds even when each agent passes single-turn safety tests.
- **[Beyond the All-in-One Agent: Benchmarking Role-Specialized Multi-Agent Collaboration in Enterprise Workflows](https://arxiv.org/abs/2605.08761)** — cs.MA. Heads-up benchmark for the enterprise "one big agent vs many specialised agents" debate.
- **[Nautilus Compass: Black-box Persona Drift Detection for Production LLM Agents](https://arxiv.org/abs/2605.09863)** — cs.IR. Observability layer for detecting when a production agent's persona has silently drifted across deploys.
- **[jina-embeddings-v5-omni: Text-Geometry-Preserving Multimodal Embeddings via Frozen-Tower Composition](https://arxiv.org/abs/2605.08384)** — HF. New Jina multimodal-embeddings release — relevant for the vector-DB / multimodal-RAG track.
