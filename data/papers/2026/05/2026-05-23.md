# AI Papers — 2026-05-23

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

_Saturday run — ArXiv RSS is empty on weekends, so this digest is sourced from the most recent submitted batch (Thu 2026-05-21) via the ArXiv API plus the HF Papers / papers.cool trending lists._

## Top picks

- **Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention** — Ali Hatamizadeh, Yejin Choi, Jan Kautz. _Takeaway:_ Linear-attention variant that separately gates erase and write into a fixed-size recurrent state, editing the compressed cache without scrambling existing associations — a cleaner delta-rule than Gated DeltaNet. _Category:_ arXiv:2605.22791. [link](https://arxiv.org/abs/2605.22791)

- **Vector Policy Optimization: Training for Diversity Improves Test-Time Search** — Ryan Bahlous-Boldi, Isha Puri, Idan Shenfeld, Akarsh Kumar. _Takeaway:_ Post-training that optimizes a *vector* of rewards instead of a scalar, so the policy stays diverse and inference-time search procedures (à la AlphaEvolve) can actually find better rollouts. _Category:_ arXiv:2605.22817. [link](https://arxiv.org/abs/2605.22817)

- **Evaluating Commercial AI Chatbots as News Intermediaries** — Mirac Suzgun, Emily Shen, Federico Bianchi, Alexander Spangher. _Takeaway:_ 14-day evaluation of six chatbots (Gemini and peers) on how accurately their proprietary search + RAG pipelines surface emerging news facts across languages and regions — the first systematic look at retrieval-synthesis accuracy in shipped products. _Category:_ arXiv:2605.22785. [link](https://arxiv.org/abs/2605.22785)

- **Reducing Political Manipulation with Consistency Training** — Long Phan, Devin Kim, Alexander Pan, Alice Blair. _Takeaway:_ Identifies seven categories of "covert political bias" where LLMs handle opposing sides asymmetrically, then proposes a consistency-training objective that flattens the gap without hurting capability. Useful safety/alignment lever. _Category:_ arXiv:2605.22771. [link](https://arxiv.org/abs/2605.22771)

- **MOSS: Self-Evolution through Source-Level Rewriting in Autonomous Agent Systems** — Qianshu Cai, Yonggang Zhang, Xianzhang Jia, Wei Xue. _Takeaway:_ Goes beyond prompt/skill mutation: the agent rewrites its own source code as the evolution substrate, giving a strictly larger search space than text-mutable artifacts and reportedly fixing recurring failures without human patches. _Category:_ arXiv:2605.22794. [link](https://arxiv.org/abs/2605.22794)

- **LCGuard: Latent Communication Guard for Safe KV Sharing in Multi-Agent Systems** — Sadia Asif, Mohammad Mohammadi Amiri, Momin Abbas, Prasanna Sattigeri. _Takeaway:_ Multi-agent systems that share KV-caches (instead of text) get richer signal but also a new attack surface; LCGuard is a runtime check on those latent messages to block jailbreaks/poisoning while preserving the efficiency gains. _Category:_ arXiv:2605.22786. [link](https://arxiv.org/abs/2605.22786)

- **DeltaBox: Scaling Stateful AI Agents with Millisecond-Level Sandbox Checkpoint/Rollback** — Yunpeng Dong, Jingkai He, Yuze Hou, Dong Du. _Takeaway:_ A delta-encoded snapshot mechanism for full sandbox state (files + process memory) cuts C/R from hundreds of ms to single-digit ms, making high-frequency tree-search RL over real shells finally tractable. Agent-runtime primitive worth tracking. _Category:_ arXiv:2605.22781. [link](https://arxiv.org/abs/2605.22781)

- **Search-E1: Self-Distillation Drives Self-Evolution in Search-Augmented Reasoning** — Zihan Liang, Yufei Ma, Ben Chen, Zhipeng Qian. _Takeaway:_ Argues that recent search-augmented agents lean too hard on external supervision and auxiliary modules; pure self-distillation from a base post-training run matches or beats them, with a much simpler stack. RAG/agent training simplification. _Category:_ arXiv:2605.22511. [link](https://arxiv.org/abs/2605.22511)

- **Maestro: Reinforcement Learning to Orchestrate Hierarchical Model-Skill Ensembles** — Jinyang Wu, Guocheng Zhai, Ruihan Jin, Yuhao Shen. _Takeaway:_ RL-trained orchestrator that dynamically routes among a pool of LLMs and skills instead of pinning a single model behind fixed logic — moves agent frameworks past the "one LLM, hand-written graph" pattern. _Category:_ arXiv:2605.22177. [link](https://arxiv.org/abs/2605.22177)

- **Efficient Agentic Reasoning Through Self-Regulated Simulative Planning** — Mingkai Deng, Jinyu Hou, Lara Sá Neves, Varad Pimpalkhute. _Takeaway:_ Trains the agent to decide *when* to plan and how deeply, rather than letting CoT-style planning emerge implicitly. Cuts token usage substantially without losing accuracy — directly relevant to cost/observability budgets in agent platforms. _Category:_ arXiv:2605.22138. [link](https://arxiv.org/abs/2605.22138)

- **The Log is the Agent: Event-Sourced Reactive Graphs for Auditable, Forkable Agentic Systems** — Yohei Nakajima. _Takeaway:_ ActiveGraph inverts the usual agent stack — append-only event log is the source of truth, the working graph is derived. Gives time-travel, forking, and clean audit trails by construction, an interoperability-adjacent runtime pattern. _Category:_ arXiv:2605.21997. [link](https://arxiv.org/abs/2605.21997)

- **Forecasting Scientific Progress with Artificial Intelligence** — Sean Wu, Pan Lu, Yupeng Chen, Jonathan Bragg. _Takeaway:_ Introduces CUSP, a cutoff-conditioned multi-disciplinary benchmark for whether models can forecast the next *event* in a research area from pre-cutoff state of knowledge. A new kind of capability eval beyond static QA. _Category:_ arXiv:2605.22681. [link](https://arxiv.org/abs/2605.22681)

## Other interesting items

- **[Spreadsheet-RL: Advancing Large Language Model Agents on Realistic Spreadsheet Tasks via Reinforcement Learning](https://arxiv.org/abs/2605.22642)** — Banghao Chi et al., RL-trained agent that beats prompt-only baselines on real Excel/Sheets workflows; useful concrete vertical-agent benchmark.
- **[ACC: Compiling Agent Trajectories for Long-Context Training](https://arxiv.org/abs/2605.21850)** — Qisheng Su et al., uses real agent trajectories (tool calls + observations) as a free source of long-context training data instead of hand-curated long documents.
- **[Self-Evolving Multi-Agent Systems via Decentralized Memory](https://arxiv.org/abs/2605.22721)** — Guangya Hao et al., drops the central memory store; agents keep private memories and gossip, reducing comms cost and privacy exposure.
- **[π-Bench: Evaluating Proactive Personal Assistant Agents in Long-Horizon Workflows](https://arxiv.org/abs/2605.14678)** — Haoran Zhang et al., benchmark specifically targeting proactive behavior under under-specified requests — directly relevant to OpenClaw-style assistants.
- **[Forecasting Downstream Performance of LLMs With Proxy Metrics](https://arxiv.org/abs/2605.18607)** — Arkil Patel, Siva Reddy, Marius Mosbach, Dzmitry Bahdanau. Argues both loss and direct eval are unreliable signals during pretraining; proposes proxy metrics that predict downstream wins.
- **[Full Attention Strikes Back: Transferring Full Attention into Sparse within Hundred Training Steps](https://arxiv.org/abs/2605.16928)** — Yanke Zhou et al., converts a full-attention LLM into a sparse one in ~100 training steps with minimal accuracy loss.
- **[Unsupervised Process Reward Models](https://arxiv.org/abs/2605.10158)** — Artyom Gadetsky et al., trains step-level PRMs with no human annotations, removing the main bottleneck for process-reward RL.
- **[Integrating Chain-of-Thought into Generative Retrieval: A Preliminary Study](https://arxiv.org/abs/2605.22358)** — Wenhao Zhang et al., adds CoT deliberation between query and docid in generative retrieval; complex multi-step queries benefit most.
- **[One prompt is not enough: Instruction Sensitivity Undermines Embedding Model Evaluation](https://arxiv.org/abs/2605.22544)** — Yevhen Kostiuk, Kenneth Enevoldsen, shows MTEB-style single-prompt scores are not robust across phrasings — a methodological hit for embedding leaderboards.
- **[TerminalWorld: Benchmarking Agents on Real-World Terminal Tasks](https://arxiv.org/abs/2605.22535)** — Zhaoyang Chu et al., 1,530 tasks reverse-engineered from in-the-wild terminal recordings, covering long workflows (50+ steps) and 1,280 distinct commands.
