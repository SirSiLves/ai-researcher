## Top picks

- **How Well Do Models Follow Their Constitutions?** — Arya Jakkli, Senthooran Rajamanoharan, Neel Nanda. _Takeaway:_ Treats each frontier lab's published spec as an auditable target: decomposes Anthropic's constitution into 205 atomic tenets, OpenAI's Model Spec into 197, generates multi-turn adversarial scenarios with Petri + a modified SURF-style rubric search, then validates against each lab's own system card. Across seven models per spec, violation rates fall sharply with each generation (Sonnet 4: 15.0% → Sonnet 4.6: 2.0%; GPT-4o: 11.7% → newer GPT-5). Most concrete governance benchmark on alignment-with-public-spec we've seen — directly relevant to enterprise AI governance auditing. _Category:_ arXiv:2605.24229. [link](https://arxiv.org/abs/2605.24229)

- **Behind EvoMap: Characterizing a Self-Evolving Agent-to-Agent Collaboration Network** — Qiming Ye, Peixain Zhang, Yupeng He, Zifan Peng, Gareth Tyson. _Takeaway:_ First large-scale empirical study of an A2A collaboration network — 1.5M assets, 128K agents. Finds the credit-economy design rewards publication over adoption (98% of assets never reused; rewards concentrated in a few agents), and the GDI quality-scoring algorithm is trivially manipulable via unverified self-reported metadata. Concrete failure-mode catalogue for anyone building A2A interop protocols or agent marketplaces. _Category:_ arXiv:2605.25815. [link](https://arxiv.org/abs/2605.25815)

- **From Model Scaling to System Scaling: Scaling the Harness in Agentic AI** — Shangding Gu. _Takeaway:_ Argues the structured execution layer around a foundation model (memory substrate, context constructor, skill-routing layer, orchestration loop, verification-and-governance layer) is now a first-class object of design, evaluation, and optimization — not an implementation detail. Walks through three bottlenecks (context governance, trustworthy memory, dynamic skill routing) plus the orchestration/governance layer that coordinates them. Strong framing paper for anyone building enterprise agent platforms; aligns with the MCP/A2A/runtime-standards conversation. _Category:_ arXiv:2605.26112. [link](https://arxiv.org/abs/2605.26112)

- **Who Judges the Judges? Governance from Metrics: A Runtime Framework for Continuous LLM Compliance Monitoring** — Jehanne Dussert. _Takeaway:_ Argues static compliance assessments are structurally ill-suited to the EU AI Act's demand for ongoing oversight and detection of emergent behavioural drift. Introduces govllm, an open-source governance-driven routing architecture where model selection is determined by accumulated compliance scores rather than latency/cost. Panel of regulatory judges (EU AI Act, GDPR, ANSSI, accessibility) where inter-judge disagreement is the regulatory-uncertainty signal. Validated with 49 annotated prompt/response pairs and four SLMs (1.7B–7B) running fully on-prem. Concrete EU-AI-Act-aligned governance plumbing. _Category:_ arXiv:2605.24737. [link](https://arxiv.org/abs/2605.24737)

- **A Governance Horizon for Ethical-Use Constraints in Open-Weight AI Models** — Weiwei Xu, Hengzhi Ye, Haoran Ye, Kai Gao, Vladimir Filkov, Minghui Zhou. _Takeaway:_ Audits 2,142,823 model repos on Hugging Face Hub to test whether voluntary-metadata governance can sustain traceability through model lineages. Finds restriction evidence decays with a half-life of 1.31 derivation steps (R²=0.98); past seven generations, ≥80% of descendants lack public governance evidence. Formalizes this as the "governance horizon" and shows policy design (mandatory-declaration vs inheritance-only) — not enforcement — is the binding factor. Hard, quantified data point for policy debates on open-weight licensing. _Category:_ arXiv:2605.24383. [link](https://arxiv.org/abs/2605.24383)

- **Mitigating Provenance-Role Collapse in Long-Term Agents via Typed Memory Representation** — Zhengda Jin, Bingbing Wang, Jing Li, Ruifeng Xu, Min Zhang. _Takeaway:_ Names a failure mode for persistent-memory agents — "provenance-role collapse," a source-monitoring error where the agent confuses raw evidence with retrieval cues with truth-bearing claims. Proposes MemIR, a typed Memory Intermediate Representation that operationalizes source monitoring as a structural constraint with separate atom types and factual authorization restricted to supported claims. Best-in-class on LoCoMo and BEAM-100K for source-tracking, temporal grounding, and aggregation. Pairs naturally with the persistent-memory architectures shipping in Claude/ChatGPT today. _Category:_ arXiv:2605.25869. [link](https://arxiv.org/abs/2605.25869)

- **QUEST: Training Frontier Deep Research Agents with Fully Synthetic Tasks** — Jian Xie, Tianhe Lin, Zilu Wang, Yuting Ning et al. _Takeaway:_ Releases QUEST, an open 2B–35B family of deep-research agents that match or surpass frontier closed-source agents across eight deep-research benchmarks using only 8K fully-synthesized training tasks. Training recipe = mid-training + SFT + RL with verifiable rewards from a "unified rubric tree" pipeline (no human annotation). Most credible "open-source frontier deep-research agent" claim of the week and a useful template for anyone building deep-research-agent pipelines. _Category:_ arXiv:2605.24218. [link](https://arxiv.org/abs/2605.24218)

- **ECHO: Terminal Agents Learn World Models for Free** — Vaishnavi Shrivastava, Piero Kauffmann, Ahmed Awadallah, Dimitris Papailiopoulos. _Takeaway:_ Standard agent RL (GRPO-style) discards environment-response tokens already present in rollouts; ECHO adds an auxiliary loss that trains the policy to predict environment observation tokens from its own actions, reusing the same forward pass. Doubles GRPO pass@1 on TerminalBench-2.0 (Qwen3-8B 2.70 → 5.17; Qwen3-14B 5.17 → 10.79). Microsoft Research signal that "world-model-from-rollouts" is the next free lunch in agent RL. _Category:_ arXiv:2605.24517. [link](https://arxiv.org/abs/2605.24517)

- **Faithfulness Metrics Don't Measure Faithfulness: A Meta-Evaluation with Ground Truth** — Yoav Gur-Arieh, Ana Marasović, Mor Geva. _Takeaway:_ Existing CoT-faithfulness metrics have been validated only against proxies (plausibility, importance) that are orthogonal to faithfulness. The authors construct tasks whose outputs *reveal* which intermediate computations must have produced them, then build BonaFide (3,066 labeled CoTs, 13 tasks, 10 models) — the first ground-truth faithfulness benchmark. Direct hit on a common interpretability assumption; useful for anyone using CoT as a safety-monitoring signal. _Category:_ arXiv:2605.25052. [link](https://arxiv.org/abs/2605.25052)

- **Your Embedding Model Is SMARTer Than You Think** — Jianrui Zhang, Hyun Jung Lee, Sukanta Ganguly, Tae-Eui Kam, Donghyun Kim, Yong Jae Lee. _Takeaway:_ Shows that standard contrastive training on the pooled embedding implicitly shapes the retrieval geometry of preceding hidden states via gradient flow — meaning a single-vector embedding model already contains usable multi-vector structure. SMART applies direct late-interaction over those frozen hidden states at inference time as a plug-and-play upgrade, letting a single-vector model out-perform SoTA multi-vector models on MMEB-V2 and Visual Document retrieval. Free production-RAG win — no retraining. _Category:_ arXiv:2605.24938. [link](https://arxiv.org/abs/2605.24938)

- **Iterate Until Retrieved: Factual Nugget Optimization for Discoverable Continual Corrections in Agentic RAG** — Moshe Hazoom, Gal Patel, Alon Talmor, Tom Hope. _Takeaway:_ Focuses on actionable factual corrections in production agentic RAG — converting user feedback into "factual nuggets" (compact KB entries), then running an Iterative Nugget Optimization loop that probes each nugget with the triggering query + paraphrases, reflects on failed retrieval/answer traces, and revises until discoverable. Validated on two production B2B knowledge-assistance agents across multiple companies. Concrete, deployable continual-learning primitive for agentic RAG. _Category:_ arXiv:2605.25641. [link](https://arxiv.org/abs/2605.25641)

- **LLM-Wiki: Retrieval as Reasoning via Self-Evolving Agent-Native Retrieval** — Haoliang Ming, Feifei Li, Xiaoqing Wu, Wenhui Que. _Takeaway:_ Argues flat-chunks-by-embedding-similarity is poorly aligned with tool-using agents. LLM-Wiki compiles documents into structured Wiki pages with bidirectional links, exposes search/read/link-following operations through standard tool-calling interfaces, and adds an "Error Book" for persistent structural and semantic self-correction. Beats HippoRAG 2, LightRAG, and GraphRAG by 2.0–8.1 F1 on HotpotQA / MuSiQue / 2WikiMultiHopQA. Important data point for the "RAG-as-tool-use vs RAG-as-lookup" debate. _Category:_ arXiv:2605.25480. [link](https://arxiv.org/abs/2605.25480)

- **Language Models Need Sleep** — Sangyun Lee, Sean McLeish, Tom Goldstein, Giulia Fanti. _Takeaway:_ Sleep-like consolidation mechanism: model periodically converts recent context into persistent fast weights (via N offline recurrent passes that update SSM-block fast weights through a learned local rule), then clears its KV cache. Shifts extra compute to "sleep" while preserving wake-time latency. Tested on cellular automata, multi-hop graph retrieval, and math reasoning, with the largest gains on examples requiring deeper reasoning. Provocative framing that bridges long-context inference with persistent-memory architectures. _Category:_ arXiv:2605.26099. [link](https://arxiv.org/abs/2605.26099)

- **ContextEcho: A Benchmark for Persona Drift in Long Agentic-Coding Sessions** — Xianzhong Ding, Yangyang Yu, Changwei Liu, Bill Zhao. _Takeaway:_ Existing persona-stability studies focus on short dialogues; ContextEcho measures drift at deployment scale using three anonymized Claude Code sessions spanning 3,746–9,716 turns plus a 25-probe identity suite and a snapshot-then-probe protocol that forks state without perturbing the live session. Across 23 frontier models: drift is *general* (not family-specific), in-session compaction doesn't reliably reset it, and a single-shot anchor restores the trained register. Direct operational signal for anyone running long Claude Code / coding-agent deployments. _Category:_ arXiv:2605.24279. [link](https://arxiv.org/abs/2605.24279)

- **SkillEvolBench: Benchmarking the Evolution from Episodic Experience to Procedural Skills** — Yingtie Lei, Zhongwei Wan, Jiankun Zhang, et al. _Takeaway:_ Diagnostic benchmark for whether agents convert episodic experience into reusable procedural skills. 180 tasks across six real-world agent environments with role-conditioned task families. Across ten model configs and three agent harnesses, current agents adapt locally but rarely form robust reusable skills — and *raw-trajectory reuse frequently outperforms distilled skills*, a sharp finding for anyone building Anthropic-Skills-style libraries. _Category:_ arXiv:2605.24117. [link](https://arxiv.org/abs/2605.24117)

## Other interesting items

- **[CUA-Gym: Scaling Verifiable Training Environments and Tasks for Computer-Use Agents](https://arxiv.org/abs/2605.25624)** — Bowen Wang, Dunjie Lu et al. Generator+Discriminator+Orchestrator pipeline that co-generates task instructions, environment states, and reward functions for CUAs, plus CUA-Gym-Hub (broad mock-app suite). Order-of-magnitude scaling of CUA RLVR data.
- **[Anticipate and Learn: Unleashing Idle-Time Compute in Proactive Agents](https://arxiv.org/abs/2605.25971)** — ProAct architecture that uses idle time between user turns to predict upcoming needs and prefetch evidence. -14.8% turns, -28.1% hallucinations on the new ProActEval benchmark (200 scenarios / 40 domains).
- **[Claw-Anything: Benchmarking Always-On Personal Assistants with Broader Access to User's Digital World](https://arxiv.org/abs/2605.26086)** — Long-horizon activity histories + interdependent backend services + integrated GUI+CLI across devices, with months of simulated user activity. GPT-5.5 hits only 34.5% pass@1 — biggest gap I've seen in 2026 agent benchmarks.
- **[SEAL: Synergistic Co-Evolution of Agents and Learning Environments](https://arxiv.org/abs/2605.24426)** — Closed-loop co-evolution where the environment evolves its training-time learning interface (tool affordance cues, constraint info, recovery feedback) alongside the policy. +8.25 to +26.25 avg-point gains with only 400 training samples.
- **[ProofAgent Harness: Open Infrastructure for Adversarial Evaluation of AI Agents](https://arxiv.org/abs/2605.24134)** — Adversarial multi-juror scoring with turn-level audit for evaluating agents under pressure. Open-source; extensible domains/traps/jurors. Practical eval-infrastructure piece.
- **[Security of OpenClaw Agents: Fundamentals, Attacks, and Countermeasures](https://arxiv.org/abs/2605.25435)** — Survey-flavoured but worth noting: layered threat framework for "OpenClaw" agents (high-privilege + persistent-memory class), with skill poisoning, cognitive manipulation, multi-agent cascading failures, supply-chain vulnerabilities each mapped to defense primitives.
