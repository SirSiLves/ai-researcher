## Top picks

- **Toward Auditable AI Scientists: A Hypothesis Evolution Protocol for LLM Agents** — Izumi Takahara, Teruyasu Mizoguchi. _Takeaway:_ Proposes the Hypothesis Evolution Protocol (HEP), an agent harness that turns hypothesis generation, evaluation, and evolution into explicit, auditable operations instead of burying them in unstructured logs. On materials-science tasks a HEP agent runs the full hypothesis–test–evidence–belief loop that planning-style agents lack, generalizes across research questions, and exploits the protocol more as the base LLM gets stronger — a concrete step toward AI scientists whose reasoning can be inspected and verified. _Category:_ arXiv:2607.09195 (cs.AI). [https://arxiv.org/abs/2607.09195](https://arxiv.org/abs/2607.09195)

- **Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents** — Yifan Wu et al. (Meta AI). _Takeaway:_ Treats memory as an active intervention rather than passive retrieval: in long-horizon tasks, decision-relevant state (task requirements, environment facts, prior attempts, diagnoses, open subgoals) scatters across an expanding trajectory and gets buried in — or pushed past — the context window. A proactive memory agent surfaces the right state exactly when a decision needs it, attacking the failure mode where retrieval-only memory misses what matters. _Category:_ arXiv:2607.08716 (cs.AI). [https://arxiv.org/abs/2607.08716](https://arxiv.org/abs/2607.08716)

- **HaloGuard 1.0: An Open Weights Constitutional Classifier for Multilingual AI Safety** — Navaneeth Sangameswaran, Preetham S, Ashmiya Lenin. _Takeaway:_ Open-weights constitutional classifier for input safety: a natural-language constitution of 46 policies / 2,940 subcategories drives synthetic-data generation with one-to-one paired counterfactuals (topic and vocabulary held fixed, intent flipped) balanced across 46 languages. The 0.8B model tops seven prompt-safety benchmarks (avg F1 90.9) while beating open guards up to 27B — over 30x larger — holding FPR to 4.3, and an always-on adversarial red-team loop hardens it against content-level and agentic attacks. _Category:_ arXiv:2607.02079 (cs.CL). [https://arxiv.org/abs/2607.02079](https://arxiv.org/abs/2607.02079)

- **OpenSafeIntent: Evaluating Intent-Calibrated Safe Completion Across Dual-Use Prompt Sets** — Rheeya Uppaal, Seungwoo Lyu, Selina Sung, Junjie Hu. _Takeaway:_ Varies user intent while holding the task fixed — each item ships benign, dual-use, and malicious variants — to test whether models calibrate assistance across intent shifts instead of merely looking safe on average. Prompt-level safety hides failures: models often break across matched intent variants, dual-use behavior is brittle under paraphrase, and high-level answers on risky topics aren't reliably safe. Argues safe completion should be measured as intent-calibrated behavior, not a single helpfulness/safety tradeoff. _Category:_ arXiv:2607.02047 (cs.CL). [https://arxiv.org/abs/2607.02047](https://arxiv.org/abs/2607.02047)

- **CheckRLM: Effective Knowledge-Thought Coherence Checking in Retrieval-Augmented Reasoning** — Dingling Xu, Ruobing Wang, Qingfei Zhao et al. (incl. Xu Han, Maosong Sun). _Takeaway:_ Wires RAG into the chain of thought to keep reasoning models factual: it extracts factual claims from the reasoning chain, localizes subtle knowledge inconsistencies during inference, and applies minimal-cost, precise corrections from external knowledge. Cuts error accumulation in long-horizon, knowledge-intensive reasoning at lower cost than baselines — a clean retrieval-checks-reasoning pattern. _Category:_ arXiv:2607.02262 (cs.CL). [https://arxiv.org/abs/2607.02262](https://arxiv.org/abs/2607.02262)

- **Know Your Source: A Public Knowledge Store for Media Background Checks** — Benjamin Nichols, Michael Schlichtkrull, Nedjma Ousidhoum. _Takeaway:_ Targets a weak spot in RAG-based fact-checking — the assumption that retrieved evidence is reliable — by operationalizing source-critical reasoning through media background checks (MBCs). MEDIAREF is a public, web-sourced knowledge store enabling reproducible, low-cost MBC generation and evaluation across 200 media sources, replacing costly proprietary search APIs while improving MBC quality. _Category:_ arXiv:2607.02383 (cs.CL). [https://arxiv.org/abs/2607.02383](https://arxiv.org/abs/2607.02383)

- **Will Scaling Improve Social Simulation with LLMs?** — Caleb Ziems, William Held, Su Doga Karaca, David Grusky, Tatsunori Hashimoto, Diyi Yang. _Takeaway:_ Uses scaling laws to ask whether social-simulation fidelity rides general-capability scaling or is orthogonal to it. Across 85 Qwen3-architecture models (10^18–10^20 FLOPs) plus open-weight models up to 70B, opinion and behavioral simulation improve strongly with scale for well-represented populations, but longitudinal forecasting, underrepresented opinions, and calibration to human cognitive biases (e.g., risk aversion) scale slowly or not at all — even after fine-tuning. _Category:_ arXiv:2607.02464 (cs.CL). [https://arxiv.org/abs/2607.02464](https://arxiv.org/abs/2607.02464)

- **Object Aligner: A Configurable JSON Schema Similarity Score for Graphs, Applied to LLM Prompt Optimization** — Jan Drchal. _Takeaway:_ An open-source, deterministic scorer for JSON output — the format behind information extraction, tool calling, agentic planning, and knowledge-graph construction — that recursively aligns object trees (Hungarian algorithm / sequence alignment) and awards schema-declared partial credit, configured entirely via JSON-Schema annotations. Its "referential alignment" (Weisfeiler-Leman color refinement) makes scores invariant to identifier relabeling for graph-shaped records, and as a reward inside the GEPA prompt optimizer it helps or stays neutral across datasets. _Category:_ arXiv:2607.01972 (cs.CL). [https://arxiv.org/abs/2607.01972](https://arxiv.org/abs/2607.01972)

## Other interesting items

- **[LACUNA: A Testbed for Evaluating Localization Precision for LLM Unlearning](https://arxiv.org/abs/2607.02513)** — Boglioni, Rousset, Reddy, Mosbach, Dankers. First unlearning testbed with ground-truth parameter-level localization (PII injected into predefined weights of 1B/7B OLMo models); finds SOTA unlearning is output-strong but imprecise and vulnerable to resurfacing attacks, while accurate localization makes even simple gradient unlearning robust.
- **[Compete then Collaborate: Frontier AI Teachers Build a Verifiable Curriculum to Improve a Coding Student Beyond Imitation](https://arxiv.org/abs/2607.08255)** — Multiple frontier "teacher" models construct a verifiable training curriculum that pushes a coding "student" model past pure imitation (training/RL-curriculum for code; July batch).
- **[From Passive Retrieval to Active Memory Navigation: Learning to Use Memory as a Structured Action Space](https://arxiv.org/abs/2607.05794)** — Reframes agent memory access as navigation over a structured action space rather than passive lookup, learning when and how to move through memory.
- **[Agent Reinforcement Learning via Pivotal-Aware Self-Feedback Retry](https://arxiv.org/abs/2607.03702)** — Agent RL that identifies pivotal steps and uses self-feedback retries, an approach to credit assignment and recovery over long agent trajectories.
- **[SPORK: Self-Speculative Forking to Accelerate Agentic LLM Inference](https://arxiv.org/abs/2607.03333)** — Self-speculative forking to accelerate agentic LLM inference — an inference-throughput play for multi-step agent loops.
- **[Challenges and Recommendations for LLMs-as-a-Judge in Multilingual Settings and Low-Resource Languages](https://arxiv.org/abs/2607.02235)** — Doğruöz et al. Of 650 ACL-Anthology papers using LLM-as-judge, only 33 target low-resource/multilingual; audit finds inconsistent outcomes, over-trust of judgments, and near-universal single-judge reliance, with concrete recommendations.
- **[Governance Gaps in Agent Interoperability Protocols: What MCP, A2A, and ACP Cannot Express](https://arxiv.org/abs/2606.31498)** — (Jun 2026) Evaluates whether MCP/A2A/ACP support governed agent communities across a six-dimension taxonomy (membership, deliberation, voting, dissent preservation, human escalation, audit/replay) and finds key expressiveness gaps. Included as the freshest reachable interop-protocol item; July MCP work was not surfaced through egress.
