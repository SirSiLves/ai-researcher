# AI Papers — 2026-07-15

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Cost-Governed RAG: Unified Per-Tenant Cost Attribution Across Retrieval and Generation in Multi-Tenant LLM Systems** — Navnit Shukla. _Takeaway:_ Enterprise RAG meters generation per token but leaves the retrieval layer (vector memory, similarity compute) unattributed; proposes unified per-tenant cost attribution spanning retrieval and generation — a governance/FinOps primitive for production multi-tenant RAG. _Category:_ arXiv:2607.12188 (cs.AI). [https://arxiv.org/abs/2607.12188](https://arxiv.org/abs/2607.12188)

- **Transforming LLMs into Efficient Cross-Encoders via Knowledge Distillation for RAG Reranking** — Shreeya Dasa Lakshminath, Shubhan S. _Takeaway:_ Distills LLM cross-encoder reranking quality into a cheaper student to escape the quadratic inference cost that keeps high-accuracy cross-encoders out of real-time RAG pipelines. _Category:_ arXiv:2607.11933 (cs.CL). [https://arxiv.org/abs/2607.11933](https://arxiv.org/abs/2607.11933)

- **Ring-Zero: Scaling Zero RL to a Trillion Parameters for Emergent Reasoning** — Xinyu Tang, Gangqiang Cao, Yurou Liu, et al. _Takeaway:_ Pushes "zero RL" (verifiable rewards, no human-annotated data) to trillion-parameter scale to elicit emergent chain-of-thought reasoning — a frontier-scale RL training result. _Category:_ arXiv:2607.12395 (cs.CL). [https://arxiv.org/abs/2607.12395](https://arxiv.org/abs/2607.12395)

- **A Threshold Exceedance Framework for CBRN Uplift Evaluation in Frontier Language Models** — Rahul Gupta, Abhinav Mohanty, Payal Motwani, et al. _Takeaway:_ A threshold-exceedance methodology for policymakers and developers to judge whether frontier-model access materially raises a non-expert's ability to plan CBRN (chemical/bio/radiological/nuclear) harms — a concrete dangerous-capability eval. _Category:_ arXiv:2607.12200 (cs.AI). [https://arxiv.org/abs/2607.12200](https://arxiv.org/abs/2607.12200)

- **Isolation as a First-Class Principle for LLM-Agent System Safety: Concepts, Taxonomy, Challenges and Future Directions** — Huihao Jing, Wenbin Hu, Shaojin Chen, et al. _Takeaway:_ Argues that once an LLM is the "brain" of a system, safety becomes a system-level property rather than just input/output filtering; offers a taxonomy and open challenges for treating isolation as the first-class containment principle for agents. _Category:_ arXiv:2607.12406 (cs.AI). [https://arxiv.org/abs/2607.12406](https://arxiv.org/abs/2607.12406)

- **Agentic Service-Oriented Computing: A Manifesto for the Next Frontier of Service-Oriented Computing** — Amin Beheshti, Rong N. Chang, Boualem Benatallah, Fabio Casati, Schahram Dustdar, et al. _Takeaway:_ Reframes service-oriented computing for LLM agents — from static request/response services to goal-directed, adaptive, tool-using components — and sketches the orchestration and interoperability research agenda for agentic systems. _Category:_ arXiv:2607.12619 (cs.AI). [https://arxiv.org/abs/2607.12619](https://arxiv.org/abs/2607.12619)

- **MemOps: Benchmarking Lifecycle Memory Operations in Long-Horizon Conversations** — Xixuan Hao, Zeyu Zhang, Zehao Lin, et al. _Takeaway:_ Existing agent-memory benchmarks test mostly recall; MemOps evaluates the full memory lifecycle (write / update / consolidate / retire) across extended multi-session conversations. _Category:_ arXiv:2607.12893 (cs.AI). [https://arxiv.org/abs/2607.12893](https://arxiv.org/abs/2607.12893)

- **Who Grades the Grader? Co-Evolving Evaluation Metrics and Skills for Self-Improving LLM Agents** — Xing Zhang, Guanghui Wang, Yanwei Cui, et al. _Takeaway:_ When no reliable verifier exists, "Double Ratchet" co-evolves an inspectable evaluation metric alongside the agent's skill loop, recovering 88–110% of the lift a ground-truth metric would have enabled across code (MBPP+), text-to-SQL (Spider 2.0-Snow), and report generation. _Category:_ arXiv:2607.12790 (cs.AI/cs.MA). [https://arxiv.org/abs/2607.12790](https://arxiv.org/abs/2607.12790)

- **Vertical Standardisation for High-Risk AI Systems under the EU AI Act: A Domain-Specific Framework for Algorithmic Hiring** — Anna Gatzioura, Vrettos Moulos, Nina Baranowska. _Takeaway:_ With no European standards yet covering algorithmic hiring, proposes domain-specific, standardisation-oriented recommendations mapping EU AI Act obligations (risk management, data governance, logging/traceability, human oversight, accuracy) onto that high-risk vertical. _Category:_ arXiv:2607.12588 (cs.AI). [https://arxiv.org/abs/2607.12588](https://arxiv.org/abs/2607.12588)

## Other interesting items

- **[A JoLT for the KV Cache: Near-Lossless KV Cache Compression via Joint Tucker and JL-Residual Allocation for LLMs](https://arxiv.org/abs/2607.12550)** — cs.LG, Rahul Krishnan & Volker Schulz. Targets the KV cache — the dominant memory cost of long-context transformer inference — with near-lossless joint Tucker + Johnson–Lindenstrauss residual compression.
- **[Function-Aware Fill-in-the-Middle as Mid-Training for Coding Agent Foundation Models](https://arxiv.org/abs/2607.12463)** — cs.AI, Yubo Wang et al. Mid-training recipe teaching coding agents to fold external tool returns back into ongoing reasoning, a capability left-to-right pretraining exposes only in the forward direction.
- **[Track, Rank, Crack: Epistemic Working Memory Scales Multi-Hop Reasoning in Language Agents](https://arxiv.org/abs/2607.12267)** — cs.LG, Ning Liu. Adds an epistemic working memory to counter the "context dilution" that makes tool-using agents degrade as reasoning chains lengthen, even when each individual step is easy.
- **[RCWT: Measuring Task-Budget Displacement from Coordination Content in LLM Calls](https://arxiv.org/abs/2607.12216)** — cs.CL/cs.MA, Brenda Lelis & Rodrigo Cabral-Carvalho. The Roundtable Context Window Test isolates how multi-agent coordination tokens crowd out task budget; GPT-4.1-mini, Claude Haiku 4.5, and Gemini 2.5 Flash degrade sharply once residual task evidence falls to a few hundred tokens.
- **[PM-Bench: Evaluating Prospective Memory in LLM Agents](https://arxiv.org/abs/2607.12385)** — cs.AI, Genglin Liu & Saadia Gabriel. Benchmarks "prospective memory" — an agent executing a deferred intention at a specific future cue or state while other activities are ongoing.
- **[Evidence-Grounded Verified Agentic Reasoning: Eliminating LLM Hallucination in Empirical Inference via Tool-Attested Kernel Proofs](https://arxiv.org/abs/2607.12650)** — cs.LG, Junyu Ren. Makes tool-using LLM reasoning governable by requiring accepted outputs to descend from attested evidence and survive formal (kernel-proof) scrutiny.
