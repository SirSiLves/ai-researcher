## Top picks

**What LLM Agents Say When No One Is Watching: Social Structure and Latent Objective Emergence in Multi-Agent Debates** — Arman Ghaffarizadeh, Danyal Mohaddes, Aliakbar Izadkhah, et al. _Takeaway:_ Dual-channel debate framework separates each agent's public utterance from an "off-the-record" channel under identical conditions, revealing that social structure alone (role, audience) shifts what agents say publicly even with no explicit objective in the prompt — a concrete probe for latent-objective / deceptive-alignment risk in multi-agent systems. _Category:_ cs.AI/cs.MA · 2607.02507. [link](https://arxiv.org/abs/2607.02507)

**Distributed Attacks in Persistent-State AI Control** — Josh Hills, Ida Caspary, Asa Cooper Stickland. _Takeaway:_ Introduces "Iterative VibeCoding," an AI-control setting where a misaligned or prompt-injected coding agent spreads a payload across multiple pull requests over time and times it for the PR with the best natural cover — a new persistent-state attack surface as coding agents ship iteratively across sessions. _Category:_ cs.AI · 2607.02514. [link](https://arxiv.org/abs/2607.02514)

**Steerability via constraints: a substrate for scalable oversight of coding agents** — Thomas Winninger. _Takeaway:_ Argues the decades-old toolkit for managing large human engineering teams — access control, network policies, tooling-enforced coding conventions — transfers directly to coding agents and is cheaper (in tokens) than recent agentic scaffolding; sketches an end-to-end constrained system and reports a controlled evaluation. _Category:_ cs.AI · 2607.02389. [link](https://arxiv.org/abs/2607.02389)

**ContextNest: Verifiable Context Governance for Autonomous AI Agent** — Misha Sulpovar, Benn R. Konsynski, Qaish Kanchwala, et al. _Takeaway:_ Formalizes "context governance" and proposes an open spec + reference implementation for governed, AI-consumable knowledge vaults — provenance, version identity, integrity, traceability, and point-in-time reconstruction as a governance layer *beneath* RAG rather than a replacement for it. _Category:_ cs.AI · 2607.02116. [link](https://arxiv.org/abs/2607.02116)

**HNSW with Accuracy Guarantees Using Graph Spanners** — Minghao Li, Raghav Mittal, et al. _Takeaway:_ A "Certify-then-Rectify" framework wraps industry-standard HNSW ANN search with a distribution-free statistical certificate, bridging heuristic greedy-traversal speed and exact-retrieval rigor — vector-store fundamentals with correctness guarantees rather than purely empirical recall. _Category:_ cs.IR · 2607.02338. [link](https://arxiv.org/abs/2607.02338)

**A Hippocampus for Linear Attention: An Exact Memory for What the Recurrent State Forgets** — Wanyun Cui. _Takeaway:_ HOLA gives linear-attention / state-space models a "hippocampal" complement — keeping the compressive delta-rule state and adding a bounded exact KV cache — to recover needle-recall that fixed-size recurrent states lose when many key–value associations compete. _Category:_ cs.AI · 2607.02303. [link](https://arxiv.org/abs/2607.02303)

**Evaluating Chunking Strategies for Retrieval-Augmented Generation on Academic Texts** — Valentin J. J. Kreileder, Johannes Reisinger, et al. _Takeaway:_ Compares cluster-based semantic chunking against fixed-size and recursive chunking on long, structured academic theses using the RAGAs framework; notably finds RAGAs-based faithfulness has limited reliability in this setup — a caution for RAG-eval practice, not just a chunking result. _Category:_ cs.IR · 2607.01852. [link](https://arxiv.org/abs/2607.01852)

**STRUCTSURVEY: Structured Agentic Retrieval for Automated Survey Paper Generation** — Paolo Pedinotti, Enrico Santus. _Takeaway:_ Shifts structural reasoning from generation-time to retrieval-time via a hierarchical multi-agent framework that dynamically builds graph-based representations, so the model no longer has to infer conceptual/methodological/taxonomic relations from raw text while writing — an agentic-retrieval architecture for long-form synthesis. _Category:_ cs.IR · 2607.01243. [link](https://arxiv.org/abs/2607.01243)

**Online Safety Monitoring for LLMs** — Mona Schirmer, Metod Jazbec, Alexander Timans, et al. _Takeaway:_ A deliberately simple real-time monitor turns an external verifier's signal into an alarm by thresholding, with the threshold calibrated via risk control; on math-reasoning and red-teaming datasets it is competitive with more elaborate monitors — a practical deployment-time safety baseline. _Category:_ cs.AI · 2607.02510. [link](https://arxiv.org/abs/2607.02510)

**Adoption and Ecosystem Health: A Longitudinal Analysis of Open-Source Multi-Agent Frameworks** — Xi Zhang, Papi Menon, et al. _Takeaway:_ Longitudinal, ecosystem-level study of how open-source multi-agent frameworks are adopted and how healthy their communities are over time — a rare evidence base for platform/framework selection rather than yet another new framework. _Category:_ cs.MA · 2607.02453. [link](https://arxiv.org/abs/2607.02453)

## Other interesting items

- **[ReContext: Recursive Evidence Replay as LLM Harness for Long-Context Reasoning](https://arxiv.org/abs/2607.02509)** — Yanjun Zhao, Ruizhong Qiu, Tianxin Wei, et al.; training-free inference-time harness that recursively replays evidence already present in the input to close the gap between context *access* and effective context *use*. (cs.AI · 2607.02509)
- **[UA-ChatDev: Uncertainty-Aware Multi-Agent Collaboration for Reliable Software Development](https://arxiv.org/abs/2607.02186)** — Temitayo Olamilekan Ogunsusi, Lijun Qian, Xishuang Dong; adds uncertainty estimates to role-based multi-agent software pipelines to curb hallucination propagation from early phases. (cs.AI · 2607.02186)
- **[Criticality-Based Guard Rail Validation for AI Agent Decisions in Autonomous Telecom Networks](https://arxiv.org/abs/2607.02210)** — Ravi Kant Sharma; standardizable runtime layer that intercepts and validates individual agent inference outputs before they trigger live network-state changes. (cs.AI · 2607.02210)
- **[A rubric-based controlled comparison of frontier language models on expert-authored clinical reasoning tasks](https://arxiv.org/abs/2607.02175)** — Samiha A. Ismail, Fan X. Chen, Ali Merali; small, deliberately hard clinician-authored rubric eval (25–62 MECE criteria/task) probing where saturated multiple-choice medical benchmarks hide open-ended weakness. (cs.AI · 2607.02175)
- **[Cache Merging as a Convergent Replicated State for Multi-Agent Latent Reasoning](https://arxiv.org/abs/2607.01308)** — Carlos Baquero, Luís Brito; treats KV-cache merging as a CRDT-style convergent replicated state, a distributed-systems primitive for coordinating multi-agent latent reasoning. (cs.MA · 2607.01308)
- **[Embedding Inference Attack](https://arxiv.org/abs/2607.01276)** — Cedric Fitiavana Raelijohn, Sébastien Gambs, et al.; privacy attack reconstructing information from text embeddings — relevant to vector-store / retrieval security. (cs.IR · 2607.01276)
- **[Bringing Agentic Search to Earth Observation Data Discovery](https://arxiv.org/abs/2607.02387)** — Minghan Yu, Youran Sun, et al.; applies an agentic-search pattern to structured scientific data-catalog discovery. (cs.IR · 2607.02387)
- **[Visually Grounded Self-Reflection for Vision-Language Models via Reinforcement Learning](https://arxiv.org/abs/2607.02490)** — Liyan Tang, Fangcong Yin, Greg Durrett; RL to make VLM self-reflection actually attend to the image, so feedback yields grounded corrections rather than ungrounded text edits. (cs.CL · 2607.02490)
