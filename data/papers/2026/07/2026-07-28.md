## Top picks

**Kimi K3: Open Frontier Intelligence** — Kimi Team. _Takeaway:_ A 2.8T-parameter MoE with 104B activated parameters, native vision and a 1M-token context, built on Kimi Delta Attention plus Attention Residuals and a Stable LatentMoE router that activates 16 of 896 experts per token — together worth roughly a 2.5x gain in scaling efficiency over K2; post-training is RL across general, agentic and coding domains at multiple reasoning-effort levels, supported by million-token agentic RL with persistent rollout and sandbox state. The team reports frontier-level results on long-horizon coding, agentic, knowledge, reasoning and vision tasks while candidly placing it behind Claude Fable 5 and GPT-5.6 Sol, and ahead of every other open or proprietary model in their suite; **full weights released**. Today's #1 HF paper by a wide margin (241 upvotes). _Category:_ cs.CL / cs.LG — 2607.24653. [link](https://arxiv.org/abs/2607.24653)

**A Comparative Study of MCP and A2A for Inter-Agent Coordination in LLM-Based Systems** — Ionut Predoaia, Tuong Manh Vu, Konstantinos Barmpis, Dimitris Kolovos, Antonio García-Domínguez. _Takeaway:_ The first implementation-grounded head-to-head of the two dominant interop protocols: the same software-engineering coordination task is built twice, once on MCP and once on A2A, and scored against requirements drawn from the literature and industry partners — agent discoverability, multi-part messaging, multi-turn conversations, async communication, observability, interoperability and access control. MCP wins on economy (a lighter implementation model, lower coordination complexity) but pushes conversational state management and task-lifecycle handling up into the application layer; A2A carries those natively as protocol-level task and lifecycle abstractions at a substantially higher implementation cost — the clearest statement yet that the choice is an architectural trade, not a ranking. _Category:_ cs.MA — 2607.23884. [link](https://arxiv.org/abs/2607.23884)

**Keep It InMind: Benchmarking the Implicit-Association Blind Spot in Agent Memory** — Ruizhe Li, Mingxuan Du, Benfeng Xu, Zhendong Mao. _Takeaway:_ Names the unstated assumption under every long-term memory system — that a memory which is needed will *resemble* the query that needs it — and shows world knowledge breaks it: a stored tree-nut allergy should change the answer to a macaron request via almond flour, but the two texts share no retrievable cue. InMind (125 expert-verified tasks, ten life domains, 113 grounded in citable sources) uses paired controls to separate "never stored" from "lacks bridging knowledge" from "stored but never surfaced", and the verdict is stark: with the decisive memory placed in context the backbone answers 84.0% of indirect queries, but when it must be *retrieved*, six vector, graph and agentic memory systems reach at most 14.4% — despite recalling the same facts on demand at up to 100%. Eight-fold larger embeddings barely move it; the failure is in the query-conditioned interface itself. _Category:_ cs.CL — 2607.24368. [link](https://arxiv.org/abs/2607.24368)

**StateAct: Program State, before Pixels, for Long-Horizon Computer-Use Agents** — Yan Yang, Xiangru Jian, Ziyang Luo, Zirui Zhao, Yutong Dai, Ziji Shi, Hanshu Yan, Jun Hao Liew. _Takeaway:_ Argues the whole computer-use field is optimizing the wrong surface — a screenshot is a lossy rendering of the files, backends and DOM that actually hold the task data, and distinct states can render identical pixels — so the main agent works program state directly through code and a GUI subagent is called only where pixels are unavoidable (28 of 108 tasks, 1.1% of main-agent steps); direct state access also enables an independent finish gate that catches output that is missing, unsaved or written to the wrong path. On OSWorld 2.0 it lifts Claude Opus 4.8 from 20.6% to 26.9% binary success and 54.8% to 61.6% partial, at ~9x lower cost per task than the same model driven by screenshots. #6 HF paper (51 upvotes). _Category:_ cs.SE / cs.CV — 2607.22798. [link](https://arxiv.org/abs/2607.22798)

**ACM: Agentic Context Management for Long Horizon Tasks** — Xiaochuan Li, Ryan Ming, Meng Chu, Shuai Shao, Rong Jin, Chenyan Xiong. _Takeaway:_ Existing context compression is lossy and fires on rigid heuristics that are misaligned with where the agent's reasoning has actually moved; ACM instead hands the agent purpose-built context *editing tools* so it decides when to compress, offloads discarded content to an external store modeled on the short-term/long-term memory split, and queries it back on demand — making the management lossless rather than destructive. A post-training pipeline builds demonstrations of good context management and improves both agentic search and coding; the analysis is the useful part, showing lower peak token pressure, longer viable explorations, and more consistent solutions across independent trials. Code, data and checkpoints released. _Category:_ cs.AI — 2607.23809. [link](https://arxiv.org/abs/2607.23809)

**From Proprietary to Open-Source: Bridging the Distribution Gap via Multi-Agent Protocol Distillation in Agentic Search** — Junlin Liu, Jiangwang Chen, Zixin Song, et al. _Takeaway:_ Outcome-RL gives agentic search only sparse supervision and the obvious fix — distilling from a strong proprietary teacher — is blocked twice over: hidden logits and mismatched tokenizers rule out logit matching, while imitating raw natural-language trajectories transfers style rather than reasoning. MAPD inserts a structured, style-normalized JSON *protocol* as the intermediate representation: an offline multi-agent system decomposes the query, retrieves evidence, repairs failed searches, then emits task type, reasoning plan and extractive grounding facts; at training time that protocol is shown only to a privileged branch of the student, whose token distributions supply a dense distillation signal alongside the sparse RL objective. Consistent wins across seven QA benchmarks. #3 HF paper (63 upvotes). _Category:_ cs.AI — 2607.24280. [link](https://arxiv.org/abs/2607.24280)

**Agentic Permissions Policy Algebra for Taint Confinement in LLM Agents** — Arseny Kravchenko, Vadim Liventsev, Innokentii Konstantinov, Ildar Iskhakov, Matvey Kukuy. _Takeaway:_ Information Flow Control gives real structural guarantees against prompt injection but classical taint tracking is unusable in practice — one read of unvetted data permanently taints the context and kills everything downstream. APPA fixes the usability bottleneck with engine-managed context *branching*: unvetted data is inspected inside a label-seeded child trajectory that absorbs the label descent locally while a trusted sanitizer returns a bounded derivative to an unchanged parent, and acquisition is enforced prospectively — before the read happens — generating actionable Authorize/Accept remedy plans. Parent-label preservation and merge confinement are formally proved under a two-monoid model; on a multi-turn tool-chaining benchmark across four models exfiltration drops from 31–50% to 0–7% attack success, with branching recovering much of the utility plain tainting forfeits. _Category:_ cs.AI / cs.CR — 2607.24625. [link](https://arxiv.org/abs/2607.24625)

**MemTX: Transactional Belief Commit for Stateful Agent Memory** — Xiaoyang Li, Yiqi Wang, Haohui Lu, Zhi Chen, Mo Li, Pingan Song, Taotao Cai. _Takeaway:_ In shared-memory multi-agent systems one agent's write becomes another's premise and eventually a tool call with real side effects, yet current memory systems treat every accepted write as immediately actionable truth — so a polluted tool result or a teammate's half-finished note can silently drive an irreversible action. MemTX's thesis is that *a memory write is not a belief commit*: records carry evidence, permissions, provenance and validity, writes are staged in snapshot-isolated transactions behind a validate-and-commit pipeline, irreversible tool calls are gated on in-flight belief state, and retracting a belief triggers typed cascading repair of derived records *and* tool side effects. Action-safety gating and cascade-repair completeness are machine-checked over 5.5M enumerated protocol states with zero violations; across five backbones it is the only method with zero downstream harm everywhere — capability does not substitute for commit discipline. _Category:_ cs.AI — 2607.23929. [link](https://arxiv.org/abs/2607.23929)

**AIR-BENCH Live: An Evolving Safety Benchmark for Foundation Models** — Rohan Naphade, Minzhou Pan, Bo Li. _Takeaway:_ Safety benchmarks freeze the risk landscape of their publication date — taxonomies go incomplete as governments legislate and attack prompts go stale as models improve — so AIR-BENCH Live makes the benchmark itself a running process: an automated pipeline monitors government regulation, classifies new policy against the four-tier risk taxonomy and either maps it to an existing category or proposes a new granular one, then a multi-agent persona-driven generator writes realistic multilingual prompts with minimal human review. It has already grown 314 → 335 granular risks, the 21 new categories drawing on 31 genuinely novel policy clauses across seven jurisdictions; across 14 recent models safety spreads from 0.17 to 0.89, the modernized prompts are 0.06 harder on average with the largest drops among the *most* compliant models, and most models are modestly less safe in non-English. _Category:_ cs.AI — 2607.22671. [link](https://arxiv.org/abs/2607.22671)

## Other interesting items

- **[Where Is the Cost of Third-Party API Routers in Agentic Software Development?](https://arxiv.org/abs/2607.23624)** — Donghao Fu, Jingxin Li, Xue Jiang, Yihong Dong. Third-party routers unifying access across LLM providers sit squarely on the trusted path of high-autonomy coding agents, able to inspect and modify every request and response with nothing verifying that provider output matches the repo-level actions the agent then executes. An empirical study across four intervention levels (substitution → append → LLM-polished → distribution-aligned) with the SIDEL trace/replay/injection framework and 400 curated samples finds router-side intervention substantially alters repository actions and largely evades whitelist execution control and LLM review.
- **[False Prophets: On the Security of World Models in Agentic Systems](https://arxiv.org/abs/2607.23147)** — Erik Imgrund, Anna Wimbauer, Klim Kireev, Konrad Rieck. Trained environment simulators improve agent performance but are a new attack surface: world-model-specific vulnerabilities in terminal-based agents enable malicious code execution and sensitive-data extraction, with induced mispredictions succeeding up to 95% of the time. The authors argue some of the risk is *intrinsic* to approximate world modeling and release a security benchmark for text-based world models.
- **[Codifying the Judge: Scalable Evaluation via Program Distillation](https://arxiv.org/abs/2607.22561)** — Tzu-Heng Huang, Shengqi Qiu, Frederic Sala. Distills an LLM judge's decision logic into a committee of programs that score candidates directly — transparent, editable, zero per-sample API cost. PAJAMA aggregates their verdicts and escalates only low-confidence cases; programmatic judges match a 13B LLM judge across five datasets and four model families, and a reward model trained on their verdicts beats one trained on proprietary LLM labels at two orders of magnitude lower cost.
- **[SpecBox: Speculative Sandbox Scheduling for Efficient LLM Agent Serving](https://arxiv.org/abs/2607.23933)** — Yihui Zhang, Tianyu Wo, Jinghao Wang, et al. (Beihang). As agents lean on MCP to invoke isolated external sandboxes, disaggregated deployment forces a choice between persistent reservations (memory blowup) and lazy instantiation (cold starts). SpecBox prewarms sandboxes intent-driven — keyword matching plus streaming semantic embedding detect pending tool demands *mid-token-generation* so bootstrap overlaps inference — with stochastic prefetching over a sandbox dependency graph, a semantic result cache, and zero-copy shared-memory artifact transport.
- **[The Physics of Multi-Turn Long-Horizon Planning](https://arxiv.org/abs/2607.24720)** — Tianyi Men, Zhuoran Jin, Kang Liu, Jun Zhao. A controlled multi-turn environment isolates how planning ability is acquired and shaped: explicit world-model construction via CoT state-transition modeling generalizes best, atomic skills alone don't compose, a little long-horizon data goes far, and suboptimal trajectories are actively harmful because errors amplify over the horizon. Post-training splits into unnecessary / effective / unsupported regions, with on-policy distillation holding a broader effective region than GRPO under low-quality and long-horizon settings. #1 on papers.cool cs.CL.
- **[A corrective agentic hybrid RAG and an operations-grounded evaluation for a scientific facility](https://arxiv.org/abs/2607.24663)** — Rajat Sainju, Dariusz Jarosz, Hairong Shang, et al. (Argonne). A *deployed* platform over decades of logbooks, wikis, ops chat, maintenance records and live control-system data, fusing dense/sparse/knowledge-graph retrieval with query-type-adaptive reciprocal-rank fusion, a corrective agentic loop, and a native-tool ReAct executor over an MCP tooling layer. The honest ablation is the value: full Agentic GraphRAG reaches 70.3% strict vital-nugget recall vs 63.8% BM25, but the **cross-encoder reranker is what matters** — removing it costs 32.8 points — while the graph channel and corrective loop contribute only marginally.
