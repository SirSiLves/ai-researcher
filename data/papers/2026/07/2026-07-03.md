# AI Papers — 2026-07-03

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Behind the Refusal: Determining Guardrail Activation via Behavioral Monitoring** — William Hackett, Peter Garraghan. _Takeaway:_ Guardrail systems protecting LLMs/agents can be fingerprinted from observable refusal behavior alone — attackers can tell which guardrail fired, a blind spot for AI security stacks. _Category:_ cs.AI 2607.02121. [link](https://arxiv.org/abs/2607.02121)
- **Safeguarding LLM Agents from Misalignment through Provenance Analysis** — Yining She, Yiliang Liang, Eunsuk Kang. _Takeaway:_ Uses provenance analysis over an agent's tool invocations to detect actions that deviate from user intent before they cause harm — runtime alignment checking for tool-using agents. _Category:_ cs.CL 2607.01236. [link](https://arxiv.org/abs/2607.01236)
- **Cache Merging as a Convergent Replicated State for Multi-Agent Latent Reasoning** — Carlos Baquero, Luís Brito. _Takeaway:_ Makes multi-agent KV-cache composition order-independent (CRDT-style "CanonicalMerge", byte-identical under any agent ordering, verified on Qwen3 1.7B/4B) — a genuine agent-composition primitive. _Category:_ cs.MA 2607.01308. [link](https://arxiv.org/abs/2607.01308)
- **PACE: A Proxy for Agentic Capability Evaluation** — Yueqi Song, Lintang Sutawika, Jiarui Liu et al. _Takeaway:_ Predicts expensive agentic benchmark results (SWE-Bench, GAIA — thousands of dollars, days per run) from fast, cheap non-agentic capability tests. _Category:_ HF Papers, arXiv 2607.02032. [link](https://arxiv.org/abs/2607.02032)
- **AgenticDataBench: A Comprehensive Benchmark for Data Agents** — Zhaoyan Sun, Shan Zhong, Daizhou Wen et al. _Takeaway:_ End-to-end benchmark for data-science agents over heterogeneous raw data; also trending on HF Papers today. _Category:_ cs.CL 2607.01647. [link](https://arxiv.org/abs/2607.01647)
- **Evaluating Chunking Strategies for Retrieval-Augmented Generation on Academic Texts** — Valentin J. J. Kreileder, Johannes Reisinger, Andreas Fischer. _Takeaway:_ Cluster-based semantic chunking did NOT beat fixed-size/recursive chunking on long structured documents, and RAGAs faithfulness proved unreliable — useful negative result for RAG pipeline design. _Category:_ cs.IR 2607.01852. [link](https://arxiv.org/abs/2607.01852)
- **Lynx: Progressive Speculative Quantization for accelerating KV Transfer in Long-Context Inference** — Wenchen Han, Gingfung Matthew Yeung, Marco Barletta et al. _Takeaway:_ Speeds up KV-cache transfer in disaggregated serving — directly targets the long-context workloads RAG and agentic systems generate. _Category:_ cs.LG 2607.01831. [link](https://arxiv.org/abs/2607.01831)
- **Online Safety Monitoring for LLMs** — Mona Schirmer, Metod Jazbec, Alexander Timans et al. _Takeaway:_ Real-time sequential monitor over external verifier signals that raises an alarm when deployed-LLM safety can no longer be assumed — safety as an ops problem, not just training. _Category:_ stat.ML 2607.02510. [link](https://arxiv.org/abs/2607.02510)
- **Will Scaling Improve Social Simulation with LLMs?** — Caleb Ziems, William Held, Su Doga Karaca et al. _Takeaway:_ Investigates whether the current scaling paradigm closes the faithfulness gap in LLM social simulations, or whether simulation needs different ingredients than scale. _Category:_ cs.CL 2607.02464. [link](https://arxiv.org/abs/2607.02464)

## Other interesting items

- **[AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents](https://arxiv.org/abs/2607.02255)** — Xiangchen Cheng, Yunwei Jiang, Jianwen Sun et al. — treats agent memory as a contract about what future decisions may see; bounded-context alternative to append-everything (HF Papers).
- **[Adoption and Ecosystem Health: A Longitudinal Analysis of Open-Source Multi-Agent Frameworks](https://arxiv.org/abs/2607.02453)** — Xi Zhang, Papi Menon, Vivian Chu et al. (Cisco) — analyzes 15 major open-source agent frameworks beyond GitHub-star popularity; useful for platform selection.
- **[kNNGuard: Turning LLM Hidden Activations into a Training-Free Configurable Guardrail](https://arxiv.org/abs/2607.02072)** — Mahmoud Abdelfattah, Hamid Nasiri, Peter Garraghan — training-free guardrail built from hidden activations, avoiding fine-tuned classifiers' generalization/latency issues.
- **[Embedding Inference Attack](https://arxiv.org/abs/2607.01276)** — Cedric Fitiavana Raelijohn, Sébastien Gambs, Jean-Francois Rajotte — black-box attack identifying which embedding model a RAG/IR system uses from retrieved-document sets alone; rerankers don't fully defend.
- **[HNSW with Accuracy Guarantees Using Graph Spanners](https://arxiv.org/abs/2607.02338)** — Minghao Li, Raghav Mittal, Sanjivni Rana et al. — "certify-then-rectify" framework giving worst-case correctness guarantees to HNSW vector search at near-HNSW speed.
- **[When Search Agents Should Ask: DiscoBench for Clarification-Aware Deep Search](https://arxiv.org/abs/2606.27669)** — Yiling Tao, Shihan Deng, Meiling Tao et al. — benchmark for deep-search agents facing vague, underspecified, or factually wrong user queries (HF Papers).
