# AI Papers — 2026-07-09

## Top picks

**Operational Reframing and Approval-Framed Delegation in Multi-Agent LLM Safety** — Lifei Liu, Haoran Yu, Xiaochong Jiang, et al. _Takeaway:_ Argues the usual "pipeline effect" (direct prompt vs. planner-executor) conflates three distinct mechanisms — harmful intent reframed as plausible operational work, planner refusal/transformation, and executor acting under delegation prompts that imply prior approval — and introduces a five-condition controlled-contrast design (30 harmful scenarios + external validation) to separate them. _Category:_ 2607.07097. [link](https://arxiv.org/abs/2607.07097)

**Institutional Red-Teaming: Deployment Rules, Not Just Models, Causally Shape Multi-Agent AI Safety** — Yujiao Chen. _Takeaway:_ Evaluation methodology that holds agents/objectives/task-state fixed and varies exactly one *deployment rule*, attributing behavior change to that rule; instantiated in IABench-CA (228 consequence-allocation contexts, five canonical rules, seven model populations, 33,924 games) with a cooperative reference — showing the governance layer, not just the model, drives collective safety. _Category:_ 2607.07695. [link](https://arxiv.org/abs/2607.07695)

**Multi-Agent AI Control: Distributed Attacks Hamper Per-Instance Monitors** — Oliver Makins, Orazio Angelini, Zohreh Shams, Mary Phuong. _Takeaway:_ Opens the empirical study of *multi-agent* AI control: real deployments run many agents over shared infrastructure and the worst risks (weight exfiltration, training poisoning) plausibly need several agents in concert; formalizes distributed attacks that split malicious work across agents so any single per-instance monitor sees only innocuous behavior. _Category:_ 2607.07368. [link](https://arxiv.org/abs/2607.07368)

**AgentLens: Production-Assessed Trajectory Reviews for Coding Agent Evaluation** — Andrey Podivilov, Vadim Lomshakov, et al. _Takeaway:_ Most code-agent benchmarks reduce a run to a single pass/fail bit; AgentLens scores the whole trajectory (instruction-following, tool use, self-verification, recovery, communication) by pairing formal verification where an objective check exists with LLM-written trajectory reviews and side-by-side comparisons, yielding a readable explanation of each score. _Category:_ 2607.06624. [link](https://arxiv.org/abs/2607.06624)

**The Harness Effect: How Orchestration Design Sets the Token Economics of Enterprise Agentic AI** — Muayad Sayed Ali, Aliaksandra Novik, et al. _Takeaway:_ Names "token maxing" — buying capability with longer traces, more turns, wider tool payloads, replayed context, so tokens/task outgrow task value — and isolates the orchestration harness as the decisive lever via a controlled swap: 22 locked tasks across six foundation models (Claude Sonnet 4.6, Gemini 3.1, Qwen 3.6, and others), same tasks, different harness. _Category:_ 2607.06906. [link](https://arxiv.org/abs/2607.06906)

**Entropy Pacing Policy Optimization for Multi-Task Agentic Reinforcement Learning** — Zetian Hu, Shunyu Liu, et al. _Takeaway:_ Identifies an "exploration-exploitation pace mismatch" across tasks in multi-task agentic RL — a single generalist agent's tasks want to explore/exploit at different rates — and paces per-task entropy to keep a generalist LLM agent learning multiple tasks simultaneously rather than collapsing onto the easy ones. _Category:_ 2607.07178. [link](https://arxiv.org/abs/2607.07178)

**Single-Rollout Asynchronous Optimization for Agentic Reinforcement Learning** — Zhenyu Hou, Yujiang Li, Jie Tang, Yuxiao Dong. _Takeaway:_ Synchronous batch-interleaved RL is inefficient for long-horizon agentic tasks; async RL updates as rollouts arrive but usually chases throughput at the cost of stability. This work targets stability *and* task effectiveness in a single-rollout asynchronous scheme for post-training LLMs on agentic tasks. (HF Papers-curated today.) _Category:_ 2607.07508. [link](https://arxiv.org/abs/2607.07508)

**Reasoning Consistency Scanning: Auditing Chain-of-Thought Validity in AI Safety Evaluations** — Silvia Santano. _Takeaway:_ Detecting CoT unfaithfulness normally needs controlled interventions that can't be applied to eval transcripts after the fact; instead this asks the more tractable, post-hoc question of whether stated reasoning is *logically consistent* with the answer it accompanies — a lightweight scanner over existing safety-eval transcripts. _Category:_ 2607.07229. [link](https://arxiv.org/abs/2607.07229)

## Other interesting items
- **[From Noisy Traces to Root Causes: Structural Trajectory Analysis and Causal Extraction for Agent Optimization](https://arxiv.org/abs/2607.07702)** — Ying Chang, Jiahang Xu, et al. Reflection-based agent optimization overfits to redundant/low-value failures in huge trace collections; this structurally analyzes trajectories and extracts causal root causes so the LLM-as-optimizer improves policies on what actually mattered.
- **[MILES: Modular Instruction Memory with Learnable Selection for Self-Improving LLM Reasoning](https://arxiv.org/abs/2607.06974)** — Ruilin Tong, Dong Gong. When problems arrive sequentially, accumulating reusable experience beats treating each in isolation; MILES stores modular instruction memory with a learnable selector optimized for final-answer correctness, and grows the memory at test time without fixed action spaces.
- **[Think Big, Search Small: Where Capacity Matters in Hierarchical Search Agents?](https://arxiv.org/abs/2607.07548)** — Qinnan Cai, Yibo Zhao, Xiang Li. Multi-agent search systems usually instantiate every role from one model of identical scale; this factorizes hierarchical search into delegation / execution / (aggregation) roles and asks where model capacity should actually be spent.
- **[Online Data Selection Is Implicit Alignment](https://arxiv.org/abs/2607.07023)** — Aoxiong Zeng, Yuxin Yang, Xiangquan Yang. Challenges the SFT-adapts / RLHF-aligns split: scoring and keeping examples online during fine-tuning already shifts a model's behavioral preferences, making data selection itself an alignment mechanism under a fixed selected-token budget.
- **[Evaluating RAG Metrics in Applied Contexts: An Experiment, Its Findings and Its Limitations](https://arxiv.org/abs/2607.07302)** — Quentin Brabant. Empirically compares RAG evaluation metrics from four libraries (Ragas, DeepEval, RAGChecker, Opik) against human scores and classic recall on a human-annotated business QA set — a reality check on how well popular RAG metrics track human judgment.
- **[Interpretable Uncertainty for Adaptive Retrieval and Reasoning in Question Answering](https://arxiv.org/abs/2607.07380)** — Ritajit Dey, Iadh Ounis, Graham McDonald. Adaptive-RAG that decides *when/how* to retrieve from explicit signals in the LLM's internal representations, distinguishing knowledge insufficiency from knowledge ambiguity/conflict instead of relying on opaque policies or costly multi-step prompting.
- **[From Atomic Actions to Standard Operating Procedures: Iterative Tool Optimization for Self-Evolving LLM Agents](https://arxiv.org/abs/2607.07321)** — Haipeng Ding, Yuexiang Xie, et al. Agents forced to reinvent low-level logic from granular atomic tools every time; this synthesizes recurring workflows into reusable higher-order SOPs (callable multi-step tools), cutting reasoning overhead and failure rates via self-evolution.
- **[Sparse Delta Memory: Scaling the State of Linear RNNs through Sparsity](https://arxiv.org/abs/2607.07386)** — Loïc Cabannes, Pierre-Emmanuel Mazaré, Gergely Szilvasy, et al. (Meta FAIR). Linear-attention models have fixed state and compute but lag transformers on long-context recall; SDM scales the hidden state of gated linear RNNs via sparsity, improving recall without the FLOP blow-up of simply enlarging the state. (HF Papers-curated today.)
