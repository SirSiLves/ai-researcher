# AI Papers — 2026-07-22

## Top picks

**DataFlow-Harness: A Grounded Code-Agent Platform for Constructing Editable LLM Data Pipelines** — Runming He, Zhen Hao Wong, Hao Liang, Zimo Meng, Chengyu Shen, Xiaochen Ma, et al. _Takeaway:_ Closes the "NL2Pipeline gap" by having a coding agent build platform-native DAGs through typed incremental mutations over an MCP layer that exposes the live operator surface — instead of emitting throwaway scripts. Top-3 HF paper today (105 upvotes). _Category:_ HF Papers — 2607.16617. [link](https://arxiv.org/abs/2607.16617)

**AI Tool Discovery at Scale: All You Need is DNS** — Enhao Chen, Yulin Shao. _Takeaway:_ Proposes ToolDNS, retrofitting semantic tool discovery onto DNS so agents resolve tools in O(log N) name lookups with decentralized governance, rather than O(N) search over a central registry. _Category:_ cs.AI / cs.MA — 2607.18242. [link](https://arxiv.org/abs/2607.18242)

**AgentDebugX: An Open-Source Toolkit for Failure Observability, Attribution, and Recovery in LLM Agents** — Kunlun Zhu, Xuyan Ye, Zhiguang Han, Yuchen Zhao, Bingxuan Li, Weijia Zhang, et al. _Takeaway:_ Observability framework that runs Detect → Attribute → Recover → Rerun as a closed loop, doing multi-turn root-cause diagnosis rather than just replaying traces — the step where an agent error surfaces is rarely the one that caused it. HF-featured. _Category:_ cs.AI / cs.CL — 2607.18754. [link](https://arxiv.org/abs/2607.18754)

**ResearchArena: Evaluating Sabotage and Monitoring in Automated AI R&D** — Lena Libon, Ben Rank, Jehyeok Yeon, David Schmotz, Jeremy Qin, Daniel Donnelly, Derck Prinzhorn, Maksym Andriushchenko. _Takeaway:_ AI-control benchmark across four long-horizon R&D tasks (safety post-training, capabilities post-training, CUDA-kernel and inference-server optimization), pairing each with hidden embedded and independent sabotage side tasks to test whether monitors catch covert sabotage before deployment. _Category:_ cs.AI / cs.LG — 2607.19321. [link](https://arxiv.org/abs/2607.19321)

**Supra Cognitive Modes: A Routed Architecture for Agent Memory** — Joshua Tobkin, David Yang. _Takeaway:_ Routes each query to a different retrieval/synthesis mode (fused lexical+dense lookup, graph multi-hop, or stratified long-form synthesis) over one shared ingest substrate of multi-granularity embeddings, triples, and fact-version metadata; characterized on LoCoMo, MemoryAgentBench, and LongMemEval. _Category:_ cs.AI / cs.CL — 2607.19096. [link](https://arxiv.org/abs/2607.19096)

**PAGE-RAG: Evidence-Grounded Adaptive Graph Retrieval for Long-Document Question Answering** — Xingyu Chen, Junxiu An, Jun Guo, Li Wang. _Takeaway:_ Treats GraphRAG structures as navigational "semantic skeletons" over the source documents rather than a replacement knowledge source, with task-adaptive routing that picks the retrieval behavior per query — a direct fix for unreliable retrieval from incomplete auto-built graphs. _Category:_ cs.IR — 2607.19301. [link](https://arxiv.org/abs/2607.19301)

**SysAdmin: Measuring Instrumental Power-Seeking in Frontier AI** — Mana Azarm, Qiyao Wei, Rahul Nambiar. _Takeaway:_ Puts seven frontier models in a high-fidelity Linux sandbox as autonomous sysadmins across 2,800 tasks, scoring self-preservation, autonomy-seeking, resource acquisition, environment modification, and strategic concealment; bias-corrected power-seeking rates land at 0–5% per model. _Category:_ cs.AI — 2607.18239. [link](https://arxiv.org/abs/2607.18239)

**Operational Hallucination and Safety Drift in AI Agents** — Shasha Yu, Fiona Carroll, Barry L. Bentley. _Takeaway:_ Characterizes two multi-turn agent failure modes empirically across several SOTA LLMs: safety drift (textual refusal followed by reconnaissance and unsafe execution) and operational hallucination (repetitive tool-call livelocks) — single-turn guardrails don't cover either. _Category:_ cs.AI / cs.CL — 2607.18366. [link](https://arxiv.org/abs/2607.18366)

## Other interesting items

- **[Data Leakage Prevention in Agentic Applications via Preemptive Hardening](https://arxiv.org/abs/2607.18847)** — Akansha Shukla, Emily Bellov, Parth Atulbhai Gandhi, Yuval Elovici, Asaf Shabtai. Pre-deployment pipeline that scans prompt templates, tool interfaces, and invocation code for leakage-enabling patterns, generates patches, then validates them under adversarial prompt injection.
- **[PLAID-PRF: Pseudo-Relevance Feedback with Centroid-like Tokens in PLAID](https://arxiv.org/abs/2607.18626)** — Xiao Wang, Sean MacAvaney, Craig Macdonald. Runs PRF over ColBERT/PLAID by reusing the internal centroid vectors as pseudo-tokens, getting query expansion at low added cost in multi-vector retrieval.
- **[Fusion Embedding: A Unified Embedding Space for Text, Image, Video, and Audio](https://arxiv.org/abs/2607.18666)** — Abdul Basit Tonmoy, Kazi Fardinul Hoque, Md. Shahrier Islam Arham, Arman Luthra. Bolts audio onto a frozen vision-language embedding base via a 16.4M-param connector and modality-gated adapters, so one index serves every modality with bit-for-bit preservation of the base on text/image/video.
- **[SkillSight: Seeing Through Shared Descriptions for Accurate Skill Retrieval](https://arxiv.org/abs/2607.18785)** — Jinying Xiao, Bin Ji, Shasha Li, Xiaodong Liu, et al. Training-free retrieval that calibrates away the boilerplate shared across skill-library descriptions, which otherwise inflates dense scores and hides the capability signal.
- **[Stale but Stable: Staleness-Adaptive Trust Regions for Stabilizing Asynchronous Reinforcement Learning](https://arxiv.org/abs/2607.18722)** — Junyao Yang, Yucheng Shi, Zongxia Li, Zhongzhi Li, et al. Argues PPO clipping is only a sampled surrogate for a real trust region and adapts the region to rollout staleness; HF-featured (29 upvotes).
- **[From Agent Failure Paths to Quantified Residual Risk: A Compositional Framework for Resilient Agentic AI](https://arxiv.org/abs/2607.18243)** — Hassan Karim, Sai Sitharaman, Deepti Gupta, Danda B. Rawat. Couples a seven-layer integrity decomposition (CPSAINT) to a residual-risk functional grounded in an absorbing Markov model, so control effectiveness is derived from state dynamics instead of assigned as an informal score.
- **[A Decision-Centered Reference Architecture for Trustworthy Agentic Commerce](https://arxiv.org/abs/2607.18347)** — Dimitrios S. Sfiris. Protocol-agnostic merchant-side architecture (canonical envelope, hashed dependencies, Ed25519/HMAC auth, execution-time revalidation, eleven semantic invariants) for agents acting under delegated payment authority.
