## Top picks

**AREX: Towards a Recursively Self-Improving Agent for Deep Research** — Shuqi Lu, Chaofan Li, Kun Luo, et al. _Takeaway:_ Exploits the discovery-vs-verification asymmetry in deep research — an inner loop gathers evidence and drafts a provisional answer while an outer loop audits it constraint-by-constraint and launches targeted follow-up research, with a learned context-update policy to sustain recursive self-improvement over long horizons. #1 HF paper today (115 upvotes). _Category:_ cs.AI — 2607.21461. [link](https://arxiv.org/abs/2607.21461)

**DynamicMCPBench: A Trace-Grounded, Effect-Scored Benchmark for LLM Agents over Live MCP Servers** — Jerzy Kaminski, Ilya Galyukshev, Artem Kuznetsov, et al. _Takeaway:_ A reusable framework (not a fixed dataset) that scores agents over live, stateful MCP servers on whether they reproduce the path-agnostic _effects_ of a known-good trajectory, instead of matching a brittle final answer or a fixed ground-truth tool list; run at scale across 24 models and 121 servers. _Category:_ cs.AI — 2607.20531. [link](https://arxiv.org/abs/2607.20531)

**Euclid-MCP: A Model Context Protocol Server for Deterministic Logical Reasoning via Prolog** — Bartolomeo Bogliolo. _Takeaway:_ Packages SWI-Prolog behind a standard MCP tool interface so any MCP client can delegate multi-step logical inference to a deterministic engine; introduces Euclid-IR, an engine-agnostic Horn-clause intermediate representation that LLMs can generate and a translate-run-inspect-repair loop drives — a clean neuro-symbolic play on the interop layer. _Category:_ cs.AI / cs.CL — 2607.21412. [link](https://arxiv.org/abs/2607.21412)

**ChannelGuard: Safe Models Do Not Compose into Safe Multi-Agent Systems** — Elias Hossain, Md Mehedi Hasan Nipu, Fatema Tuj Johora Faria, et al. _Takeaway:_ Over a 2,100-trace evaluation, a planner→worker→verifier→synthesizer pipeline that looks perfectly safe (0.000 attack success on tool/memory poisoning) owes that safety almost entirely to the cloud provider's server-side filter (54 of 60 blocks on Azure GPT-5) — every inter-agent hop is an unmonitored channel, and outcome-only reporting hides the dependency. _Category:_ cs.MA — 2607.19430. [link](https://arxiv.org/abs/2607.19430)

**GRADRAG: Cross-Component Prompt Adaptation for Coordinated Multi-Agent RAG** — Paolo Pedinotti, Enrico Santus. _Takeaway:_ Models a multi-agent RAG pipeline as a computational graph and propagates structured evaluator feedback upstream, so retrievers, graph constructors, and answerers are co-optimized via prompt adaptation rather than tuned in isolation, with evaluator-triggered early stopping. _Category:_ cs.AI / cs.CL — 2607.21324. [link](https://arxiv.org/abs/2607.21324)

**Chronofy: A Temporal-Logical Decay Architecture for Information Validity in Time-Aware RAG** — Muntaser Syed, Marius Silaghi, Sheikh Abujar, et al. _Takeaway:_ Attacks "temporal hallucination" — obsolete-but-plausible facts corrupting output — by reserving a temporal subspace inside Matryoshka embeddings so fact age is structurally irremovable, and folding learnable exponential-decay functions into graph retrieval rather than filtering recency post-hoc. _Category:_ cs.LG — 2607.20560. [link](https://arxiv.org/abs/2607.20560)

**IssueTrojanBench: Benchmarking AI Coding Agents Against Malicious Issue Requests** — Ankur Singh, Jinqiu Yang, Tse-Hsun Chen. _Takeaway:_ A benchmark of malicious issue requests aimed at production coding agents (Cursor, Claude Code, Codex Desktop) on GPT-5.3/5.4 and Sonnet 4.6, probing induced API misuse, data exfiltration, and persistent dev-environment compromise that stem from agentic tool-use autonomy rather than the LLM backbone alone. _Category:_ cs.AI — 2607.20759. [link](https://arxiv.org/abs/2607.20759)

**LLMs Get Lost in Evolving User Intent** — Jihoon Tack, Philippe Laban, Jennifer Neville. _Takeaway:_ Turns static single-turn tasks into dynamic multi-turn conversations where intent is incrementally revealed, revised, and mid-stream redirected, exposing how poorly current LLM agents track evolving user goals — a failure mode left invisible by the fully-specified single-turn setups they're trained and evaluated on. HF-featured (14 upvotes). _Category:_ cs.LG — 2607.20734. [link](https://arxiv.org/abs/2607.20734)

## Other interesting items

- **[Agentic Context Management: Solving Agent Memory and Cost by Treating Them as Lifecycle and Architecture Problems](https://arxiv.org/abs/2607.21503)** — Gaurav Dadhich. Reframes agent memory from a store-and-retrieve problem into a full lifecycle — decide-what-to-remember, extract/structure, consolidate and forget with provenance, and compact-to-budget — to curb ballooning per-turn token cost and missing cross-conversation recalls.
- **[NVIDIA-labs OO Agents (NOOA): Native Python Object-Oriented Agents](https://arxiv.org/abs/2607.20709)** — Paul Furgale, Severin Klingler, James Nolan, et al. An agent _is_ a Python object: methods are actions, fields are state, docstrings are prompts, type annotations are contracts, and a `...` method body is completed at runtime by an LLM loop — so agent behavior is testable, traceable, and refactorable like ordinary software. HF-featured (18 upvotes).
- **[Verifier-First Evaluation of Agentic LLMs for Infrastructure-as-Code Generation](https://arxiv.org/abs/2607.20478)** — Mohamed Jouini. Rigorous (McNemar + Wilson CI) study of seven agentic Terraform strategies on IaC-Eval v2; MCP- or ChromaDB-backed ReAct retrieval lifts Qwen2.5-Coder-7B from 14.0% to 45.7% pass@1, with failures separated across validate / plan / opa-eval stages.
- **[MemTools: A Unified Research Framework for Interoperable Agent Memory](https://arxiv.org/abs/2607.21404)** — Chengfeng Zhao, Jinhui Chen, Sirui Liang, et al. Decouples the memory lifecycle from deployment via declarative data contracts and separates benchmark datasets from execution protocols, giving one interface to mix symbolic, neural, and multimodal memory across otherwise-fragmented agent stacks.
- **[Marking the Wrong Symptoms: Evaluating LLM Watermarks in Medical Texts](https://arxiv.org/abs/2607.20462)** — Melanie Rieff, Robin Staab, Thibaud Gloaguen, et al. First rigorous audit (5 watermarking schemes across 11 LLMs and 7 VLMs) of how output watermarking degrades clinical reasoning, terminological precision, and induced hallucinations — a traceability-vs-safety tradeoff in a high-stakes domain.
- **[Tencent WorkBuddy Bench: A Multi-Domain Coding-Agent Benchmark with Contamination-Resistant Task Construction](https://arxiv.org/abs/2607.20911)** — Tencent WorkBuddy Bench Team, Siqi Cai, Shaopeng Chen, et al. Reverse-engineers every task from a real commit/PR/business scenario rewritten as a colloquial role-played request across Code/Web/Office/Security, so a prompt isn't web-searchable back to its source issue. HF-featured (17 upvotes).
