# AI Papers — 2026-07-10

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

**WebSwarm: Recursive Multi-Agent Orchestration for Deep-and-Wide Web Search** — Xiaoshuai Song, Liancheng Zhang, Guanting Dong, … Ji-Rong Wen, Zhicheng Dou. _Takeaway:_ Progressive recursive-delegation framework where each agentic search node couples a local objective with a search mode and can either solve it itself or spawn child nodes, returning evidence upward so parents can expand, revise, or aggregate; consistently beats single- and multi-agent baselines on BrowseComp-Plus, WideSearch, DeepWideSearch, and GISA. _Category:_ 2607.08662. [link](https://arxiv.org/abs/2607.08662)

**Who Broke the System? Failure Localization in LLM-Based Multi-Agent Systems** — Yufei Xia, Anjun Gao, Yueyang Quan, Zhuqing Liu, Minghong Fang. _Takeaway:_ AgentLocate attributes a multi-agent failure to both the responsible agent *and* the earliest decisive step, combining an LLM judge with multi-perspective verification by independent evaluators, confidence-aware aggregation, and lightweight fine-tuning of the judge; outperforms prior localization methods on two benchmarks while staying cheap on tokens and runtime. _Category:_ 2607.07989. [link](https://arxiv.org/abs/2607.07989)

**UniClawBench: A Universal Benchmark for Proactive Agents on Real-World Tasks** — Zhekai Chen, Chengqi Duan, Kaiyue Sun, … Xihui Liu. _Takeaway:_ Existing proactive-agent evals lean on sandboxed, single-turn setups that mix multiple capabilities inside one task category; UniClawBench targets multi-turn, real-world tool operation with a capability-disentangled task taxonomy so failures can be pinned to a specific skill. (HF Papers-trending today, 21 upvotes.) _Category:_ 2607.08768. [link](https://arxiv.org/abs/2607.08768)

**Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents** — Yifan Wu, Lizhu Zhang, Yuhang Zhou, … Zhuokai Zhao. _Takeaway:_ Names "behavioral state decay" — task requirements, prior attempts, diagnoses, and open subgoals get buried in or pushed past the context window as trajectories grow — and runs a separate memory agent alongside the actor that treats memory as an active intervention rather than passive retrieval. _Category:_ 2607.08716. [link](https://arxiv.org/abs/2607.08716)

**Context Graphs for Proactive Enterprise Agents** — Avinash Kumar. _Takeaway:_ Argues RAG and agentic stacks stay fundamentally reactive (they wait for a human query); proposes the Context Graph, a live relational data structure modeling enterprise entities, their relationships, and state transitions over time so agents can surface relevant, actionable information to workers *before* they ask. _Category:_ 2607.07721. [link](https://arxiv.org/abs/2607.07721)

**Token-Flow Firewall: Semantic Runtime Auditing for Persistent AI Agents** — Puji Wang, Yingchen Zhang, Ruqing Zhang, Jiafeng Guo, Xueqi Cheng. _Takeaway:_ Persistent agents let unsafe content propagate through persistent state, reusable skills, and tool-mediated calls, creating a far larger semantic attack surface than chat; since most security-critical interactions travel as natural-language token flows (memory updates, tool arguments, retrieved files), they add a runtime firewall that semantically audits those flows. _Category:_ 2607.08395. [link](https://arxiv.org/abs/2607.08395)

**Persuasion Attacks Can Decrease Effectiveness of CoT Monitoring** — Jennifer Za, Julija Bainiaksina, Nikita Ostrovsky, Tanush Chopra, Victoria Krakovna. _Takeaway:_ Chain-of-thought monitoring assumes visible reasoning traces surface misaligned or deceptive behavior; this shows persuasion-style attacks can measurably degrade a CoT monitor's ability to catch that behavior, poking a hole in a safety mechanism many labs are counting on. _Category:_ 2607.08066. [link](https://arxiv.org/abs/2607.08066)

**When the Judge Changes, So Does the Measurement: Auditing LLM-as-Judge Reliability** — Zongyou Yang, Yinghan Hou, Xiaokun Yang. _Takeaway:_ Frames evaluator-replacement ambiguity — an LLM-as-judge score can move even with candidate responses held fixed, simply because the evaluator changed — as a measurement-validity problem, and audits how much of a reported score is judge artifact versus signal. _Category:_ 2607.08535. [link](https://arxiv.org/abs/2607.08535)

**Jet-Long: Efficient Long-Context Extension with Dynamic Bifocal RoPE** — Haozhan Tang, Zerui Wang, Yuxian Gu, Song Han, Han Cai. _Takeaway:_ Targets long-context deployment (RAG, repository-level coding, and agentic workflows whose accumulated reasoning/tool traces push inputs an order of magnitude past pretraining length) with a Dynamic Bifocal RoPE scheme for cheaper, more stable context extension. (HF Papers-trending today.) _Category:_ 2607.07740. [link](https://arxiv.org/abs/2607.07740)

**The Illusion of Equivalency: Statistical Characterization of Quantization Effects in LLMs** — Baha Rababah, Cuneyt Gurcan Akcora, Carson K. Leung. _Takeaway:_ Post-training quantization is judged almost entirely by accuracy and perplexity; this shows those metrics fail to capture behavioral changes quantization induces and offers a statistical characterization of what actually shifts — a caution for anyone shipping quantized models to production. _Category:_ 2607.08734. [link](https://arxiv.org/abs/2607.08734)

## Other interesting items
- **[From Prompts to Contracts: Harness Engineering for Auditable Enterprise LLM Agents](https://arxiv.org/abs/2607.08028)** — Joongho Ahn, Moonsoo Kim. Productizing prototype LLM apps adds requirements for source boundaries, entity routing, answer contracts, and reproducible traces; reframes prompt-and-context-carried behavior as engineered "harness contracts" so enterprise agents become auditable rather than opaque.
- **[PolyUQuest: Verifiable Structure-Aware Web RAG over Heterogeneous Graphs](https://arxiv.org/abs/2607.08269)** — Ying Liu, Yi Ye, Quanyu Feng, et al. Existing web-RAG flattens pages to text and discards the structural/semantic signal encoded in HTML; PolyUQuest builds a heterogeneous graph unifying hyperlinks and page structure for verifiable, structure-aware retrieval.
- **[Tool-Making and Self-Evolving LLM Agents in Low-Latency Systems](https://arxiv.org/abs/2607.08010)** — Kalle Kujanpää, Ning Liu, … Shervin Malmasi. Production agents waste latency and reliability regenerating code for the same procedural steps on every request; an agentic tool-making pipeline compiles repeated SOP steps into validated, versioned tools before deployment.
- **[Efficient Safety Alignment of Language Models via Latent Personality Traits](https://arxiv.org/abs/2607.07918)** — Mohamed Amine Merzouk, Nolan Smyth, … Adam Oberman. Latent Adversarial Training is among the strongest defenses but degrades utility and needs large harmful-prompt datasets; this steers safety via latent personality traits as a cheaper, less destructive alternative.
- **[PLURAL: A Global Dataset for Value Alignment](https://arxiv.org/abs/2607.08034)** — Dhruv Agarwal, Anya Shukla, Tanya Goyal, Aditya Vashistha. LLMs disproportionately reflect Western values; PLURAL is a large, value-focused preference dataset grounded in the Integrated Values Survey to broaden alignment beyond Western defaults.
