# AI Papers — 2026-06-05

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

**The Evaluation Blind Spot: A Stereological Theory of Benchmark Coverage for Large Language Models** — Jason Z Wang. _Takeaway:_ Proves LLM leaderboards have low effective dimensionality (2.9–4.8), so a structural "blind spot" two orders of magnitude larger than the runner-up gap means 92% of random visible/held-out splits flip the top-1 ranking; a 4-benchmark stable core is identified via submodular greedy. _Category:_ 2606.05169. [link](https://arxiv.org/abs/2606.05169)

**ERRORQUAKE: Heavy-Tailed Error Severity Distributions in Open-Weight Large Language Models** — Jason Z Wang. _Takeaway:_ Introduces a 10k-query benchmark scoring errors on a continuous 0–4 severity scale; at matched accuracy, 85 of 210 open-weight model pairs have disjoint severity profiles, proving severity is informationally non-redundant with scalar error rate and should be reported alongside accuracy. _Category:_ 2606.05170. [link](https://arxiv.org/abs/2606.05170)

**Cascading Hallucination in Agentic RAG: The CHARM Framework for Detection and Mitigation** — Saroj Mishra et al. _Takeaway:_ Characterizes how a single retrieval hallucination propagates and amplifies across multi-step agentic RAG pipelines, and proposes a detection-plus-mitigation framework to break the cascade. _Category:_ 2606.04435. [link](https://arxiv.org/abs/2606.04435)

**Agent-Orchestrated Adaptive RAG: A Comparative Study on Structured and Multi-Hop Retrieval** — Anuj Maharjan, Devinder Kaur, Richard Molyet. _Takeaway:_ Systematically compares agent-driven adaptive RAG strategies across structured and multi-hop retrieval settings, mapping where orchestration helps versus adds latency without accuracy gains. _Category:_ 2606.05658. [link](https://arxiv.org/abs/2606.05658)

**Memory is Reconstructed, Not Retrieved: Graph Memory for LLM Agents** — Shuo Ji, Yibo Li, Bryan Hooi et al. _Takeaway:_ Argues agent memory should be reconstructed from a graph rather than retrieved verbatim, yielding a graph-memory architecture that improves long-horizon agent recall and coherence. _Category:_ 2606.06036. [link](https://arxiv.org/abs/2606.06036)

**Toward Pre-Deployment Assurance for Enterprise AI Agents: Ontology-Grounded Simulation and Trust Certification** — Thanh Luong Tuan, Abhijit Sanyal. _Takeaway:_ Proposes an ontology-grounded verification framework with an Agent Operational Envelope and machine-verifiable Trust Certificate; ontology-driven scenario generation beats persona-based baselines on regulatory coverage (48.3% vs 33.1%) across four regulated industries. _Category:_ 2606.04037. [link](https://arxiv.org/abs/2606.04037)

**Ahoy: LLMs Enacting Multiagent Interaction Protocols** — Omkar Joshi, Munindar P. Singh, Amit K. Chopra. _Takeaway:_ Programming-free LLM agents that dynamically select and enact declarative multiagent interaction protocols — even concurrently — bringing protocol-based interoperability to agent design without specialized training. _Category:_ 2606.05390. [link](https://arxiv.org/abs/2606.05390)

**ColBERTSaR: Sparsified ColBERT Index via Product Quantization** — Eugene Yang, Andrew Yates, Dawn Lawrie, James Mayfield et al. _Takeaway:_ Turns a ColBERT index into a true inverted index via embedding quantization, proving equivalence to learned-sparse retrieval and shrinking the index 50–70% below one-bit PLAID while retaining effectiveness. _Category:_ 2606.05568. [link](https://arxiv.org/abs/2606.05568)

**Exploring Cross-Scenario Generality of Agentic Memory Systems: Diagnostics and a Strong Baseline** — Zhikai Chen, Jialiang Gu, Junyu Yin et al. _Takeaway:_ Diagnoses why agentic memory systems fail to generalize across task scenarios and offers a strong, simple baseline that current bespoke memory architectures often fail to beat. _Category:_ 2606.04315. [link](https://arxiv.org/abs/2606.04315)

**The Granularity Gap: A Multi-Dimensional Longitudinal Audit of Sycophancy in Gemini Models** — (cs.CL). _Takeaway:_ Longitudinal, multi-dimensional audit of sycophancy across Gemini model versions, quantifying how flattery/agreement bias shifts over releases — a frontier-model safety-evaluation signal. _Category:_ 2606.05183. [link](https://arxiv.org/abs/2606.05183)
