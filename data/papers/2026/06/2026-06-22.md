# AI Papers — 2026-06-22

## Top picks

**NRT-Bench: Multi-Turn Red-Teaming of LLM Agents Operating Safety-Critical Systems** — Hanwool Lee, Dasol Choi, Bokyeong Kim, Seung Geun Kim, Haon Park. _Takeaway:_ A nuclear-control-room simulation where adaptive multi-turn attacks push a five-role LLM operator team past a critical safety function in 8.7–12.1% of sessions — and model vulnerabilities are nearly disjoint, so the same guardrail that helps one model hurts another. _Category:_ 2606.20408 (cs.CR). [link](https://arxiv.org/abs/2606.20408)

**Multi-Agent Transactive Memory (MATM)** — CMU & UC Berkeley. _Takeaway:_ Treats agent trajectories as reusable procedural knowledge, proposing population-level storage and retrieval so heterogeneous agents share what they've learned rather than re-deriving it. _Category:_ 2606.19911 (cs.CL). [link](https://arxiv.org/abs/2606.19911)

**Orchestra-o1: Omnimodal Agent Orchestration** — Orchestra-o1 team. _Takeaway:_ An orchestration framework for task decomposition and collaboration across omnimodal (text/vision/audio) agents in multi-agent systems. _Category:_ 2606.13707 (cs.CL). [link](https://arxiv.org/abs/2606.13707)

**EurekAgent: Agent Environment Engineering is All You Need for Autonomous Scientific Discovery** — EurekAgent authors. _Takeaway:_ Given an optimizable metric and an execution environment, LLM agents can propose, validate, and iterate scientific solutions — reframing autonomous discovery as an environment-engineering problem. _Category:_ 2606.13662 (cs.CL/cs.AI). [link](https://arxiv.org/abs/2606.13662)

**Oblivion: Self-Adaptive Agentic Memory Control through Decay-Driven Activation** — Ashish Rana, Chia-Chien Hung, Qumeng Sun, Julian Martin Kunkel, Carolin Lawrence (NEC). _Takeaway:_ Models agent memory with biological-style decay so stale items lose activation and relevant ones resurface, instead of unbounded context accumulation. Code released. _Category:_ 2604.00131 (cs.CL). [link](https://arxiv.org/abs/2604.00131)

**Do Language Models Know When They'll Refuse? Probing Introspective Awareness of Safety Boundaries** — Tanay Gondil. _Takeaway:_ Probes whether an LLM internally "knows" it is about to refuse, with implications for whether refusal behavior is genuinely introspectable vs. surface-level. _Category:_ 2604.00228 (cs.CL). [link](https://arxiv.org/abs/2604.00228)

**Finding and Reactivating Post-Trained LLMs' Hidden Safety Mechanisms** — Mingjie Li, Wai Man Si, Michael Backes, Yang Zhang, Yisen Wang. _Takeaway:_ Identifies latent safety mechanisms that post-training can suppress and shows they can be reactivated, relevant to alignment robustness after fine-tuning. _Category:_ 2604.00012 (cs.CL). [link](https://arxiv.org/abs/2604.00012)

**Asymmetric Actor-Critic for Multi-Turn LLM Agents** — Shuli Jiang, Zhaoyang Zhang, Yi Zhang, Shuo Yang, Wei Xia, Stefano Soatto. _Takeaway:_ An asymmetric actor-critic RL scheme tailored to multi-turn agent training, where the critic sees privileged information the actor does not. _Category:_ 2604.00304 (cs.CL). [link](https://arxiv.org/abs/2604.00304)
