# AI Papers — 2026-06-01

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

**MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation** — Huawei Lin, Peng Li, Jie Song, Fuxin Jiang, Tieying Zhang. _Takeaway:_ Agent framework that autonomously creates, stores, manages, and evaluates its own reusable skills — a concrete take on self-improving agent memory. _Category:_ 2605.27366. [link](https://arxiv.org/abs/2605.27366)

**Alignment Tampering: How RLHF Is Exploited to Optimize Misaligned Biases** — Dongyoon Hahm, Dylan Hadfield-Menell, Kimin Lee. _Takeaway:_ Shows RLHF pipelines can be exploited to bake in misaligned biases; accepted at ICML 2026 — relevant to alignment/red-team risk. _Category:_ 2605.27355. [link](https://arxiv.org/abs/2605.27355)

**SIA: Self Improving AI with Harness & Weight Updates** — Prannay Hebbar et al. _Takeaway:_ Self-improving system that updates both its scaffolding harness and model weights, probing the limits of autonomous capability gain. _Category:_ 2605.27276. [link](https://arxiv.org/abs/2605.27276)

**Position: AI Safety Requires Effective Controllability** — Yige Li, Yunhao Feng, Jun Sun. _Takeaway:_ Position paper arguing controllability, not just alignment, is the core safety requirement for capable agents — a governance/safety framing piece. _Category:_ 2605.27117. [link](https://arxiv.org/abs/2605.27117)

**MemFail: Stress-Testing Failure Modes of LLM Memory Systems** — Ishir Garg, Neel Kolhe, Dawn Song, Xuandong Zhao. _Takeaway:_ A stress-test benchmark exposing how and when LLM memory subsystems break — directly useful for agent eval/observability. _Category:_ 2605.26667. [link](https://arxiv.org/abs/2605.26667)

**Detecting Is Not Resolving: The Monitoring Control Gap in Retrieval Augmented LLMs** — Zhe Yu et al. _Takeaway:_ Argues RAG monitoring detects errors but rarely resolves them, quantifying the control gap in retrieval-augmented pipelines. _Category:_ 2605.27157. [link](https://arxiv.org/abs/2605.27157)

**The Attribution Blind Spot: Detecting When LLMs Rely on Memory Rather Than Retrieved Context** — Zhe Yu et al. _Takeaway:_ Method to tell whether a RAG model actually used retrieved context vs. parametric memory — a faithfulness diagnostic for retrieval grounding. _Category:_ 2605.26778. [link](https://arxiv.org/abs/2605.26778)

**Your Embedding Model is SMARTer Than You Think** — Jianrui Zhang et al. _Takeaway:_ Shows standard embedding models carry more latent capability than benchmarks credit, with implications for retrieval/vector-store design. _Category:_ 2605.24938. [link](https://arxiv.org/abs/2605.24938)

**How Many Tools Should an LLM Agent See? A Chance-Corrected Answer** — Vyzantinos Repantis et al. _Takeaway:_ Empirical study on tool-registry size vs. agent performance, with a chance-corrected metric — practical for tool-use/function-calling design. _Category:_ 2605.24660. [link](https://arxiv.org/abs/2605.24660)

**LDP: An Identity-Aware Protocol for Multi-Agent LLM Systems** — Sunil Prakash. _Takeaway:_ Proposes an identity-aware interoperability protocol for multi-agent systems — relevant to A2A / agent runtime standards. _Category:_ 2603.08852. [link](https://arxiv.org/abs/2603.08852)

**ToolRosetta: Bridging Open-Source Repositories and LLM Agents through Automated Tool Standardization** — Shimin Di et al. _Takeaway:_ Automates conversion of arbitrary repos into standardized agent tools — a tool-use/MCP-adjacent standardization effort. _Category:_ 2603.09290. [link](https://arxiv.org/abs/2603.09290)
