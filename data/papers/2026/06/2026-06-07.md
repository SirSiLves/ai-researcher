# AI Papers — 2026-06-07

## Top picks

**Self-Healing Agentic Orchestrators for Reliable Tool-Augmented LLM Systems** — (arXiv). _Takeaway:_ Treats orchestration reliability as a bounded runtime control problem, adding self-healing recovery across planning, retrieval, tool invocation, validation and memory. _Category:_ 2606.01416. [link](https://arxiv.org/abs/2606.01416)

**Channel Fracture: Architectural Blind Spots in Scheduled Cross-Agent Memory Injection** — (arXiv). _Takeaway:_ Surfaces failure modes in cross-agent memory injection for multi-agent orchestration systems — a concrete interop/runtime hazard as agent memory gets shared. _Category:_ 2606.04896. [link](https://arxiv.org/abs/2606.04896)

**RCEM: Embedder Equipped with Query Rewriting Skill for Robust Conversational Search** — Microsoft. _Takeaway:_ Distills LLM query-reformulation into the embedding model, aligning conversational-query embeddings with rewritten-query embeddings to hold up under distributional shift. _Category:_ 2606.01697. [link](https://arxiv.org/abs/2606.01697)

**Test-Time Training for Zero-Resource Dense Retrieval Reranking (DART)** — Huazhong Univ. of Science & Tech / ByteDance. _Takeaway:_ Adapts the scoring function at inference time, +2.1% mean per-dataset NDCG@10 over a dense baseline at under 10ms added latency per query. _Category:_ 2606.01070. [link](https://arxiv.org/abs/2606.01070)

**Attested Tool-Server Admission: A Security Extension to the Model Context Protocol** — (arXiv). _Takeaway:_ Adds an attestation-based admission control layer so MCP hosts can verify tool servers before granting access — directly relevant to MCP supply-chain risk. _Category:_ 2605.24248. [link](https://arxiv.org/abs/2605.24248)

**MCP Tool Descriptions Are Smelly! Improving Agent Efficiency with Augmented Tool Descriptions** — (arXiv). _Takeaway:_ Catalogs "smells" in MCP tool descriptions and shows augmented descriptions measurably improve agent tool-selection efficiency. _Category:_ 2602.14878. [link](https://arxiv.org/abs/2602.14878)

**Agent Skills for Large Language Models: Architecture, Acquisition, Security, and the Path Forward** — (arXiv). _Takeaway:_ Synthesizes the emerging "agent skills" stack (SKILL specs, autonomous skill discovery, skill-level security) into a coherent architecture and research agenda. _Category:_ 2602.12430. [link](https://arxiv.org/abs/2602.12430)

**Be Your Own Red Teamer: Safety Alignment via Self-Play and Reflective Reasoning** — (arXiv). _Takeaway:_ A Safety Self-Play pipeline where one LLM is both attacker and defender, generating jailbreak prompts then hardening against them — red-teaming without external adversaries. _Category:_ 2601.10589. [link](https://arxiv.org/abs/2601.10589)
