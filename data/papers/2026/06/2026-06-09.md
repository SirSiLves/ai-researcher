## Top picks

**A Unified Framework for the Evaluation of LLM Agentic Capabilities** — authors not fully listed in feed. _Takeaway:_ Configuration-driven harness where benchmark selection, environment instantiation, tool loading, model serving, and eval settings are all specified via config files — aims to standardize fragmented agent evals. _Category:_ 2605.27898. [link](https://arxiv.org/abs/2605.27898)

**Self-Aware Vector Embeddings for Retrieval-Augmented Generation: A Neuroscience-Inspired Framework** — authors not fully listed in feed. _Takeaway:_ "SmartVector" augments dense embeddings with temporal awareness, confidence decay, and relational awareness via a hippocampal-neocortical-style lifecycle; roughly doubles top-1 accuracy over plain cosine RAG (62.0% vs 31.0%) and cuts stale-answer rate from 35.0% to 13.3%. _Category:_ 2604.20598. [link](https://arxiv.org/abs/2604.20598)

**Structure Guided Retrieval-Augmented Generation for Factual Queries** — authors not fully listed in feed. _Takeaway:_ SG-RAG reframes retrieval as embedding-based subgraph matching and uses retrieved topological structure to guide generation, reducing semantic-noise failures on complex factual queries. _Category:_ 2604.22843. [link](https://arxiv.org/abs/2604.22843)

**Rethinking Reinforcement Fine-tuning of LLMs: A Multi-armed Bandit Learning Perspective** — authors not fully listed in feed. _Takeaway:_ Recasts RL fine-tuning of LLMs through a multi-armed-bandit lens to better balance exploration/exploitation during reasoning-oriented training. _Category:_ 2601.14599. [link](https://arxiv.org/pdf/2601.14599)

**Defending LLMs Against Jailbreak Attacks via In-Decoding Safety-Awareness Probing** — authors not fully listed in feed. _Takeaway:_ "SafeProbing" probes latent safety signals during decoding (rather than at input filtering) to detect and block jailbreak trajectories mid-generation. _Category:_ 2601.10543. [link](https://arxiv.org/html/2601.10543v1)

**The Hierarchy of Agentic Capabilities: Evaluating Frontier Models on Realistic RL Environments** — authors not fully listed in feed. _Takeaway:_ Empirical study scoring frontier models across 150 workplace tasks in a realistic e-commerce RL environment, proposing a tiered capability hierarchy rather than a single score. _Category:_ 2601.09032. [link](https://arxiv.org/abs/2601.09032)

**MCP Tool Descriptions Are Smelly! Towards Improving AI Agent Efficiency with Augmented MCP Tool Descriptions** — authors not fully listed in feed. _Takeaway:_ Audits Model Context Protocol tool descriptions for "smells," then shows augmenting/standardizing them improves agent tool-selection efficiency — practical signal for MCP server authors. _Category:_ 2602.14878. [link](https://arxiv.org/html/2602.14878v2)

**Alignment in Time: Peak-Aware Orchestration for Long-Horizon Agentic Systems** — authors not fully listed in feed. _Takeaway:_ Peak-aware scheduling/orchestration to keep long-horizon multi-agent runs aligned and resource-efficient over extended task arcs. _Category:_ 2602.17910. [link](https://arxiv.org/pdf/2602.17910)
