## Top picks

**Memory is Reconstructed, Not Retrieved: Graph Memory for LLM Agents** — Shuo Ji, Yibo Li, Bryan Hooi. _Takeaway:_ Replaces the static retrieve-then-reason memory pipeline with a graph memory that adapts access to intermediate evidence as reasoning unfolds, improving long-horizon agent recall. _Category:_ 2606.06036. [link](https://arxiv.org/abs/2606.06036)

**Beyond Similarity: Trustworthy Memory Search for Personal AI Agents** — Jiawen Zhang, Kejia Chen, Jiachen Ma, et al. _Takeaway:_ Argues semantic-similarity memory retrieval is unsafe for personal agents and proposes a trustworthiness-aware memory search to avoid injecting misleading or conflicting context. _Category:_ 2606.06054. [link](https://arxiv.org/abs/2606.06054)

**QCFuse: Query-Aware Cache Fusion via Compressed View for Efficient RAG Serving** — Jianxin Yan, Wangze Ni, Zhenxin Li, et al. _Takeaway:_ Cuts RAG prefill serving cost by reusing precomputed KV caches through a query-aware, compressed-view cache fusion, targeting the dominant cost of grounding on retrieved context. _Category:_ 2606.05875. [link](https://arxiv.org/abs/2606.05875)

**Beyond Vector Similarity: A Structural Analysis of Graph-Augmented Retrieval for Industrial Knowledge Graphs** — Grama Chethan. _Takeaway:_ Compares eight retrieval architectures (text → graph traversal → graph computation) on aerospace supply-chain queries, showing where pure vector RAG fails on structural multi-hop reasoning. _Category:_ 2606.06003. [link](https://arxiv.org/abs/2606.06003)

**Do More Agents Help? Controlled and Protocol-Aligned Evaluation of LLM Agent Workflows** — Yuhang Fu, Ruishan Fang, Jiaqi Shao, et al. _Takeaway:_ BenchAgent pins down tool access, answer contract, and usage accounting across single-agent, fixed multi-agent, and evolving MAS workflows to give an apples-to-apples answer on when multi-agent actually pays off. _Category:_ 2606.05670. [link](https://arxiv.org/abs/2606.05670)

**When Tools Fail: Benchmarking Dynamic Replanning and Anomaly Recovery in LLM Agents** — Dongsheng Zhu, Xuchen Ma, Yucheng Shen, et al. _Takeaway:_ ToolMaze moves tool-integrated-reasoning evaluation off "happy paths" to measure how agents replan and recover when tools genuinely fail. _Category:_ 2606.05806. [link](https://arxiv.org/abs/2606.05806)

**From Risk Classification to Action Plan Remediation: A Guardrail Feedback Driven Framework for LLM Agents** — Yuhao Sun, Jiacheng Zhang, Shaanan Cohney, et al. _Takeaway:_ Goes beyond allow/deny guardrails: turns risk signals into corrective remediation plans so agents can fix unsafe action sequences rather than just being blocked. _Category:_ 2606.05805. [link](https://arxiv.org/abs/2606.05805)

**Safety Paradox: How Enhanced Safety Awareness Leaves LLMs Vulnerable to Posterior Attack** — Long P. Hoang, Hai V. Le, Shaoyang Xu, Wei Lu, Wenxuan Zhang. _Takeaway:_ Shows that the very safety-awareness instilled by alignment creates an exploitable latent channel ("Posterior Attack") to elicit harmful content — a cautionary result for red-teaming aligned models. _Category:_ 2606.05614. [link](https://arxiv.org/abs/2606.05614)

**ToolChoiceConfusion: Causal Minimal Tool Filtering for Reliable LLM Agents** — Rahul Suresh Babu, Laxmipriya Ganesh Iyer. _Takeaway:_ Larger tool menus hurt reliability; a causal minimal-filtering step prunes the visible toolset to reduce wrong-tool calls and token cost in tool-using agents. _Category:_ 2606.06284. [link](https://arxiv.org/abs/2606.06284)

**MLEvolve: A Self-Evolving Framework for Automated Machine Learning Algorithm Discovery** — Shangheng Du, Xiangchao Yan, Jinxin Shi, et al. _Takeaway:_ Tackles inter-branch information isolation and memoryless search in MLE agents to sustain self-evolution over long-horizon scientific/ML-engineering tasks. _Category:_ 2606.06473. [link](https://arxiv.org/abs/2606.06473)

## Other interesting items
- **[Insurance of Agentic AI](https://arxiv.org/abs/2606.05449)** — Quanyan Zhu. Frames the novel risk exposures of autonomous tool-invoking agents and how they map onto insurability — a governance/risk-quantification angle.
- **[Evaluating Agentic Configuration Repair for Computer Networks](https://arxiv.org/abs/2606.06212)** — Rufat Asadli, Benjamin Hoffman, Ioannis Protogeros, Laurent Vanbever. Benchmarks LLM agents on real network misconfiguration repair, where even SOTA models still fall short at scale.
- **[When Should Memory Stay Silent: Measuring Memory-Use Boundaries in Memory-Augmented Conversational Agents](https://arxiv.org/abs/2606.06055)** — Lingxiang Xu, Jiaoyun Yang, Min Hu, et al. Studies when retrieved long-term memories should and should not be injected into agent responses.
- **[GuardNet: Ensemble Strategies of Shallow Neural Networks for Robust Prompt Injection and Jailbreak Detection](https://arxiv.org/abs/2606.05566)** — Paulo Ricardo Ferreira Neves, et al. Lightweight ensemble detector for prompt-injection and jailbreak attacks, with attention to benchmark contamination.
- **[Benchmark Everything Everywhere All at Once](https://arxiv.org/abs/2606.06462)** — Shiyun Xiong, Dongming Wu, Peiwen Sun, et al. Proposes a more sustainable, reusable approach to LLM/MLLM benchmark construction.
