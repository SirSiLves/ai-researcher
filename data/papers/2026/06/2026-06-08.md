# AI Papers — 2026-06-08

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

**Think Fast: Estimating No-CoT Task-Completion Time Horizons of Frontier AI Models** — Gould, Ward, Woodruff, Arike, et al. _Takeaway:_ Measures how far frontier models can reason internally without explicit chain-of-thought across 30,000+ questions / 43 benchmarks — directly bears on whether CoT monitoring remains a viable safety oversight mechanism. _Category:_ 2606.07157 (cs.AI). [link](https://arxiv.org/abs/2606.07157)

**Attack Selection in Agentic AI Control Evaluations Meaningfully Decreases Safety** — Ge-Wang, Crosse, Hadad, Schaeffer, Potham, Tracy. _Takeaway:_ Shows that red-team attackers who strategically choose *when* to attack defeat trusted-monitor AI-control protocols far more than indiscriminate attackers — current control evals overstate safety. _Category:_ 2606.06529 (cs.AI). [link](https://arxiv.org/abs/2606.06529)

**OpenSkill: Open-World Self-Evolution for LLM Agents** — Yan, Song, Zhang, Liang, et al. _Takeaway:_ Agent framework that builds both its skills *and* its own verification signals from scratch given only a task prompt — no curated skills, trajectories, or verifier signals required. _Category:_ 2606.06741 (cs.AI). [link](https://arxiv.org/abs/2606.06741)

**Declarative Skills for AI Agents in Knowledge-Grounded Tool-Use Workflows** — Lim, Sharudin, Chen, Lim, Wynter. _Takeaway:_ Argues natural-language "skill files" appended to the system prompt beat imperative state machines for orchestrating tool-using agents over unstructured KBs — a direct empirical case for the skills/declarative-agent paradigm. _Category:_ 2606.06923 (cs.AI). [link](https://arxiv.org/abs/2606.06923)

**Exploring Agentic Tool-Calling Decisions via Uncertainty-Aligned Reinforcement Learning** — Zhou, Zeng, Lu, Xie, Liu, Yan, Shao. _Takeaway:_ Reduces unsupported tool invocations and hallucinated direct answers by aligning RL reward to the model's decision uncertainty rather than coarse outcome signals. _Category:_ 2606.06976 (cs.AI). [link](https://arxiv.org/abs/2606.06976)

**Towards Retrieving Interaction Spaces for Agentic Search** — Zhuang, Ni, Fun, Lin, Ma. _Takeaway:_ Direct-corpus-interaction search agents (grep/file-read over raw corpora) don't scale; proposes retrieving bounded "interaction spaces" so agentic search keeps latency manageable as corpora grow. _Category:_ 2606.06880 (cs.IR). [link](https://arxiv.org/abs/2606.06880)

**HKVM-RAG: Key-Value-Separated Hypergraph Evidence Organization for Multi-Hop RAG** — Zhang, Ma. _Takeaway:_ Organizes retrieved text into answer-path hyperedges rather than independently-scored passages, exposing multi-hop evidence chains under fixed retrieval budgets. _Category:_ 2606.07218 (cs.IR). [link](https://arxiv.org/abs/2606.07218)

**AdMem: Advanced Memory for Task-solving Agents** — Wang, Lu, Liu, Dong, Zhu. _Takeaway:_ Unified, automatic memory framework integrating semantic + procedural memory that handles failure cases and online scalability — addresses the "replay past successes only" limit of prior agent memory. _Category:_ 2606.06787 (cs.AI). [link](https://arxiv.org/abs/2606.06787)

**Hierarchical Certified Semantic Commitment for Byzantine-Resilient LLM-Agent Collaboration** — Xu, Zhang, Ounis, Wang. _Takeaway:_ A finality-control primitive (H-CSC) for multi-agent LLM systems: decides commit / typed-commit / safe-abort over stochastic natural-language proposals where classical byte-identity BFT fails. _Category:_ 2606.07316 (cs.MA). [link](https://arxiv.org/abs/2606.07316)

**SafeGene: Reusable Adapters for Transferable Safety Alignment** — Wang, Kou, Feng, Wang, Geng. _Takeaway:_ A reusable safety-adapter module that re-applies alignment after downstream fine-tuning weakens it — tackles the recurring "safety recovery" problem for repeatedly-updated open-weight models. _Category:_ 2606.06519 (cs.AI). [link](https://arxiv.org/abs/2606.06519)

**Act As a Real Researcher: Benchmarks Evaluating Frontier LLMs and Agentic Harnesses in the Research Lifecycle** — Wang, Lv, Fu, Fu, Song, et al. _Takeaway:_ A benchmark suite probing where autonomous research agents still fail — field sensitivity, research ethics, nuanced scientific judgment — beyond the coding tasks they already do well. _Category:_ 2606.07462 (cs.AI). [link](https://arxiv.org/abs/2606.07462)

**MacArena: Benchmarking Computer Use Agents on an Online macOS Environment** — Muryn, Shamrai, Mazepa, Khodysko. _Takeaway:_ A live online macOS benchmark/training environment for computer-use agents, filling the macOS gap left by OSWorld and the narrow macOSWorld. _Category:_ 2606.06560 (cs.LG). [link](https://arxiv.org/abs/2606.06560)

## Other interesting items
- **[When Tools Fail: Benchmarking Dynamic Replanning and Anomaly Recovery in LLM Agents](https://arxiv.org/abs/2606.05806)** — HF-curated; stress-tests how agents recover when tool calls fail mid-task.
- **[Socratic-SWE: Self-Evolving Coding Agents via Trace-Derived Agent Skills](https://arxiv.org/abs/2606.07412)** — coding agents that mine reusable skills from their own execution traces.
- **[Workflow-to-Skill: Skill Creation via Routing-Workflow-Semantics-Attachments Decomposition](https://arxiv.org/abs/2606.06893)** — automatic skill construction from demonstrations, trajectories, and tool/execution logs.
- **[DuMate-DeepResearch: An Auditable Multi-Agent System with Recursive Search and Rubric-Grounded Reasoning](https://arxiv.org/abs/2606.07299)** — Yan et al.; addresses long-horizon planning and hallucination in deep-research agents.
- **[Signal-Driven Observation for Long-Horizon Web Agents](https://arxiv.org/abs/2606.06708)** — Gaur, Lane; decouples observation frequency from action frequency to curb context degradation in web agents.
- **[A Four-Condition Diagnostic Protocol for Evidence Utilization in Long-Context and Retrieval-Augmented LMs](https://arxiv.org/abs/2606.06758)** — Xia; matched no-/full-/retrieved-/oracle-evidence protocol to test whether a RAG model actually *used* its evidence.
- **[Evidence Graph Consistency in RAG: A Model-Dependent Analysis of Hallucination Detection](https://arxiv.org/abs/2606.06748)** — Shen; structural consistency measures over a per-response evidence graph as hallucination indicators.
- **[ThinkBooster: A Unified Framework for Seamless Test-Time Scaling of LLM Reasoning](https://arxiv.org/abs/2606.06915)** — Smirnov et al.; unifies fragmented test-time-compute scaling strategies under a quality-cost lens.
- **[Lean4Agent: Formal Modeling and Verification for Agent Workflow and Trajectory](https://arxiv.org/abs/2606.06523)** — Wang et al.; brings formal-methods specification/verification to agent execution trajectories.
- **[Online Pandora's Box for Contextual LLM Cascading](https://arxiv.org/abs/2606.07392)** — Belloni, Chen, Wei; online algorithm for adaptively querying/selecting LLM APIs under per-query cost.
