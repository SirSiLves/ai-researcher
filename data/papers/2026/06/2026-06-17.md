# AI Papers — 2026-06-17

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

**ProvenanceGuard: Source-Aware Factuality Verification for MCP-Based LLM Agents** — Ander Alvarez, Santhiya Rajan, Samuel Mugel, Román Orús. _Takeaway:_ Introduces a provenance-sensitive factuality metric for tool-using agents on the Model Context Protocol, catching the failure mode where a claim is "supported somewhere" but not by the right source. _Category:_ 2606.18037 (cs.AI). [https://arxiv.org/abs/2606.18037](https://arxiv.org/abs/2606.18037)

**SEAGym: An Evaluation Environment for Self-Evolving LLM Agents** — Congjie Zheng, Chuanyi Xue, Bin Liang, Jun Yang, Changshui Zhang. _Takeaway:_ Benchmarks self-evolving agents at the harness level (prompts, memory, tools, middleware, runtime state) rather than via isolated task scores, revealing whether a harness update actually improves the agent. _Category:_ 2606.17546 (cs.AI). [https://arxiv.org/abs/2606.17546](https://arxiv.org/abs/2606.17546)

**How Inference Compute Shapes Frontier LLM Evaluation** — Jessica McFadyen, Ole Jorgensen, Harry Coppock, Kevin Wei, Cozmin Ududec. _Takeaway:_ Shows frontier-model eval rankings are highly sensitive to test-time compute budget; reporting at a single restrictive budget can misrank models on hard agentic tasks. _Category:_ 2606.17930 (cs.AI). [https://arxiv.org/abs/2606.17930](https://arxiv.org/abs/2606.17930)

**Compositional Skill Routing for LLM Agents: Decompose, Retrieve, and Compose** — Xueping Gao. _Takeaway:_ Formalizes composing multiple reusable tool specifications (not just selecting one) — decompose a query into atomic sub-tasks, retrieve the right skills, and compose them — a concrete primitive for tool/skill libraries. _Category:_ 2606.18051 (cs.CL). [https://arxiv.org/abs/2606.18051](https://arxiv.org/abs/2606.18051)

**The Benchmark Illusion: Pruned LLMs Can Pass Multiple Choice but Fail to Answer** — Rui Wen, Lu Sun, Jiayang Liu, Zesheng Xu, Tianshuo Cong, Zheng Li. _Takeaway:_ Compression can leave multiple-choice scores intact while gutting open-generation ability, exposing a blind spot in how pruned/quantized models are evaluated. _Category:_ 2606.17609 (cs.CL). [https://arxiv.org/abs/2606.17609](https://arxiv.org/abs/2606.17609)

**Decoding Hidden Deception in Reasoning LLMs: Activation Explainers for Deception Auditing** — Kexin Chen, Yi Liu, Haonan Zhang, Yanhui Li, Xinyu Deng, Dongxia Wang. _Takeaway:_ STATEWITNESS is an activation-level explainer that surfaces inspectable evidence for why a reasoning model's response is deceptive, going beyond scalar probe scores. _Category:_ 2606.17478 (cs.CL). [https://arxiv.org/abs/2606.17478](https://arxiv.org/abs/2606.17478)

**RepSelect: Robust LLM Unlearning via Representation Selectivity** — Filip Sondej, Yushi Yang, Adam Mahdi. _Takeaway:_ Diagnoses why current unlearning is "shallow" (easily reversed by fine-tuning or few-shot prompting) and targets representation selectivity for deeper, more robust forgetting. _Category:_ 2606.17168 (cs.CL). [https://arxiv.org/abs/2606.17168](https://arxiv.org/abs/2606.17168)

**MemTrace: Probing What Final Accuracy Misses in Long-Term Memory** — Xianxuan Long, Zhikai Chen, Shenglai Zeng, Shouren Wang, Kai Guo, Jiliang Tang. _Takeaway:_ Aggregate accuracy hides how a single user fact behaves across changing conditions in long-term agent memory; MemTrace tracks per-fact dynamics instead. _Category:_ 2606.17328 (cs.AI). [https://arxiv.org/abs/2606.17328](https://arxiv.org/abs/2606.17328)

**A Unified Framework for Context-Aware and Relation-Aware Graph Retrieval-Augmented Generation** — Haoyang Zhong, Yifei Sun, Antong Zhang, Chunping Wang, Lei Chen, Yang Yang. _Takeaway:_ Tackles the core limit of graph-RAG — entity/chunk representations anchored to raw text without true knowledge fusion — with a unified context- and relation-aware retrieval design. _Category:_ 2606.18075 (cs.AI). [https://arxiv.org/abs/2606.18075](https://arxiv.org/abs/2606.18075)

**PseudoBench: Measuring How Agentic Auto-Research Fuels Pseudoscience** — Xinyang Liao, Lingyu Li, Huacan Liu, Tianle Gu, Yang Yao, Tong Zhu, Yan Teng, Yingchun Wang. _Takeaway:_ Adversarial benchmark testing whether autonomous research agents resist generating plausible-but-misleading studies that could contaminate the literature — a timely AI-safety/governance probe. _Category:_ 2606.18060 (cs.AI). [https://arxiv.org/abs/2606.18060](https://arxiv.org/abs/2606.18060)

## Other interesting items

- **[EnvRL: Learn from Environment Dynamics in Agentic Reinforcement Learning](https://arxiv.org/abs/2606.17680)** — Zhitong Wang et al., uses rich rollout-trajectory dynamics to densify sparse outcome rewards in long-horizon agentic RL.
- **[AnchorKV: Safety-Aware KV Cache Compression via Soft Penalty with a Refusal Anchor](https://arxiv.org/abs/2606.17872)** — Ning Ni, Yingjie Lao, compresses the KV cache while preserving refusal/safety behavior for on-device long-context inference.
- **[HarnessBridge: Learnable Bidirectional Controller for LLM Agent Harness](https://arxiv.org/abs/2606.12882)** — HF-trending; a learnable controller mediating the agent harness loop.
- **[EvoBrowseComp: Benchmarking Search Agents on Evolving Knowledge](https://arxiv.org/abs/2606.13120)** — HF-trending; evaluates web-search agents against knowledge that changes over time.
- **[Zone of Proximal Policy Optimization: Teacher in Prompts, Not Gradients](https://arxiv.org/abs/2606.18216)** — Byung-Kwan Lee et al., distillation that places the teacher in prompts rather than logits, easing small-student brittleness.
- **[Beyond Parallel Sampling: Diverse Query Initialization for Agentic Search](https://arxiv.org/abs/2606.17209)** — Sidhaarth Murali et al., breadth-scaling for agentic search by diversifying first-turn queries to fix redundancy.
- **[PreAct: Computer-Using Agents that Get Faster on Repeated Tasks](https://arxiv.org/abs/2606.17929)** — Bojie Li, compiles successful runs so computer-use agents avoid re-reasoning every repeated task.
- **[Risk Under Pressure: Compute-Aware Evaluation of Adversarial Robustness in Language Models](https://arxiv.org/abs/2606.11409)** — HF-trending; measures adversarial robustness as a function of attacker compute.
