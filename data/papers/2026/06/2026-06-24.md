# AI Papers — 2026-06-24

## Top picks

**Externalization in LLM Agents: A Unified Review of Memory, Skills, Protocols and Harness Engineering** — multiple authors. _Takeaway:_ Unifying review framing agent capability gains as externalization across memory, skills, interop protocols (MCP/A2A), and harness engineering rather than model weights. _Category:_ arXiv 2604.08224. [link](https://arxiv.org/pdf/2604.08224)

**Self-Aware Vector Embeddings for Retrieval-Augmented Generation (SmartVector)** — multiple authors. _Takeaway:_ Augments dense RAG embeddings with temporal awareness, confidence decay, and relational signals so retrieval reasons about when/how trustworthy a source is, not just static similarity. _Category:_ arXiv 2604.20598. [link](https://arxiv.org/abs/2604.20598)

**TRACE: Capability-Targeted Agentic Training** — Liu et al. _Takeaway:_ An agent data protocol that unifies heterogeneous datasets for targeted fine-tuning of LLM agents toward specific capabilities (ICLR 2026). _Category:_ arXiv 2604.05336. [link](https://arxiv.org/pdf/2604.05336)

**From Recall to Forgetting: Benchmarking Long-Term Memory for Personalized Agents** — multiple authors. _Takeaway:_ Long-term memory benchmark spanning weeks-to-months of user conversations, testing remembering, reasoning, and recommending — a recurring weak spot for frontier models. _Category:_ arXiv 2604.20006. [link](https://arxiv.org/html/2604.20006v1)

**Separating Intelligence from Execution: A Workflow Engine for the Model Context Protocol** — multiple authors. _Takeaway:_ Proposes decoupling agent reasoning from execution via an MCP-native workflow engine, so multi-step tool orchestration across heterogeneous systems is deterministic and auditable. _Category:_ arXiv 2605.00827. [link](https://arxiv.org/html/2605.00827)

**Retrieval-Augmented LLM Agents: Learning to Learn from Experience** — multiple authors. _Takeaway:_ Treats accumulated agent experience as a retrievable corpus, letting agents bootstrap from prior trajectories rather than relearning each task. _Category:_ arXiv 2603.18272. [link](https://arxiv.org/pdf/2603.18272)

**Tool-R0: Self-Evolving LLM Agents for Tool-Learning from Zero Data** — multiple authors. _Takeaway:_ RL-based self-evolution that teaches agents tool use without curated tool-call data, generating its own training signal from interaction. _Category:_ arXiv 2602.21320. [link](https://arxiv.org/pdf/2602.21320)

**Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Emerging Frontiers** — multiple authors. _Takeaway:_ Synthesizes agent-memory mechanisms and evaluation into a frontier roadmap (store/retrieve/update/summarize/discard as first-class operations). _Category:_ arXiv 2603.07670. [link](https://arxiv.org/html/2603.07670v1)

## Other interesting items

- **[ARLArena: A Unified Framework for Stable Agentic Reinforcement Learning](https://arxiv.org/pdf/2602.21534)** — addresses unstable multi-turn credit assignment in agentic RL with a unified, stabilized training framework.
- **[AMA-Bench: Evaluating Long-Horizon Memory for Agentic Applications](https://arxiv.org/html/2602.22769v1)** — long-horizon memory benchmark where even GPT-5.2 reaches only ~72% accuracy.
- **[Benchmarking Agent Memory in Interdependent Multi-Session Agentic Tasks](https://arxiv.org/html/2602.16313v1)** — tests whether agents carry state correctly across dependent multi-session workflows.
- **[D-MEM: Dopamine-Gated Agentic Memory via Reward Prediction Error Routing](https://arxiv.org/pdf/2603.14597)** — neuroscience-inspired gating to decide what an agent commits to long-term memory.
- **[Deactivating Refusal Triggers: Understanding and Mitigating Overrefusal in Safety Alignment](https://arxiv.org/pdf/2603.11388)** — analyzes and reduces over-refusal without weakening genuine safety guardrails.
- **[Efficient Privacy-Preserving RAG with Distance-Preserving Encryption](https://arxiv.org/abs/2601.12331)** — defends RAG embedding stores against vector-to-text reconstruction attacks.
