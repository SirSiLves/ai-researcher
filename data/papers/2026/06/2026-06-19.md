## Top picks

**Agentic Environment Engineering for Large Language Models: A Survey of Environment Modeling, Synthesis, Evaluation, and Application** — arXiv. _Takeaway:_ Frames the environment (not just the model) as the core artifact for agent evolution — characterizes memory-centric, orchestration-centric, trajectory-centric, and exploration-centric evolution across neural-, difficulty-, and scaling-driven paradigms. _Category:_ 2606.12191. [link](https://arxiv.org/abs/2606.12191)

**State-Grounded Multi-Agent Synthetic Data Generation for Tool-Augmented LLMs** — arXiv. _Takeaway:_ StateGen orchestrates a four-role LLM loop to synthesize grounded training conversations for tool-augmented agents, targeting the data bottleneck in function-calling agents. _Category:_ 2606.16307. [link](https://arxiv.org/html/2606.16307v1)

**Agents-K1: Towards Agent-native Knowledge Orchestration** — arXiv. _Takeaway:_ Proposes agent-native knowledge orchestration for research agents that plan experiments, retrieve literature, write code, and draft papers in a single loop — pushing beyond bolt-on RAG. _Category:_ 2606.13669. [link](https://arxiv.org/html/2606.13669v1)

**Decentralized Multi-Agent Systems with Shared Context (DeLM)** — arXiv. _Takeaway:_ Replaces the centralized-orchestrator bottleneck with parallel agents coordinating through shared verified context and a task queue, improving multi-agent scalability. _Category:_ 2606.10662. [link](https://arxiv.org/abs/2606.10662)

**NRT-Bench: Multi-Turn Red-Teaming of LLM Agents in Safety-Critical Systems** — arXiv. _Takeaway:_ Benchmarks LLM agents acting as operators of a simulated nuclear power plant control room under sustained, adaptive adversarial pressure — a sharper test of agent robustness than single-turn jailbreaks. _Category:_ 2606.20408. [link](https://arxiv.org/abs/2606.20408)

## Other interesting items
- **[Self-Aware Vector Embeddings for Retrieval-Augmented Generation](https://arxiv.org/abs/2604.20598)** — SmartVector augments dense embeddings with temporal awareness, confidence decay, and relational signals, treating embeddings as non-static artifacts in RAG.
- **[Don't believe everything you read: Measuring MCP Behavior under Misleading Tool Descriptions](https://arxiv.org/html/2602.03580v1)** — Formalizes MCP attack surfaces and measures how agents behave when tool descriptions are adversarially misleading; an interoperability-protocol security study.
- **[Beyond Context Sharing: A Unified Agent Communication Protocol (ACP) for Secure, Federated, Autonomous A2A Orchestration](https://arxiv.org/html/2602.15055v1)** — Argues for a unified ACP layer beyond raw context sharing for secure agent-to-agent orchestration.
- **[Reward Modeling for Reinforcement Learning-Based LLM Reasoning: Design, Challenges, and Evaluation](https://arxiv.org/html/2602.09305v1)** — Surveys reward design (model-based, rule-based, self-rewarding) for RL fine-tuning of LLM reasoning.
- **[VectorSmuggle: Steganographic Exfiltration in Embedding Stores](https://arxiv.org/html/2605.13764)** — Shows attackers with write access can hide payloads inside RAG embeddings while preserving retrieval behavior, plus a cryptographic provenance defense.
