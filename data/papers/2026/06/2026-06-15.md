# AI Papers — 2026-06-15

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

**WorkBench Revisited: Workplace Agents Two Years On** — Olly Styles. _Takeaway:_ Re-runs the 2024 WorkBench office-agent benchmark: best agent jumps from GPT-4's 43% task completion (26% harmful actions) to Claude Opus 4.8's 89% completion with harmful actions down to 2.5% — a concrete two-year capability-and-safety progress snapshot. _Category:_ 2606.13715. [link](https://arxiv.org/abs/2606.13715)

**APPO: Agentic Procedural Policy Optimization** — HF Papers trending. _Takeaway:_ Agentic-RL credit-assignment method that moves beyond coarse tool-call-boundary credit to finer-grained per-decision attribution, improving multi-turn tool-use training. _Category:_ 2606.12384. [link](https://arxiv.org/abs/2606.12384)

**Memory is Reconstructed, Not Retrieved: Graph Memory for LLM Agents (MRAgent)** — HF Papers trending. _Takeaway:_ Replaces the static retrieve-then-reason memory pipeline with a graph memory that dynamically adapts memory access to evidence found mid-inference — directly relevant to agent memory architectures. _Category:_ 2606.06036. [link](https://arxiv.org/abs/2606.06036)

**HarnessX: A Composable, Adaptive, and Evolvable Agent Harness Foundry** — HF Papers trending. _Takeaway:_ Treats the agent runtime harness (prompts, tools, memory, control flow) as a first-class, composable artifact and distills execution traces back into reusable scaffolding instead of bespoke hand-crafting — an agent-runtime / composition primitive. _Category:_ 2606.14249. [link](https://arxiv.org/abs/2606.14249)

**Orchestra-o1: Omnimodal Agent Orchestration** — Fan Zhang et al. _Takeaway:_ Multi-agent orchestration framework that generalizes task decomposition and collaboration across modalities, addressing the narrow-modality limits of existing orchestration stacks. _Category:_ 2606.13707. [link](https://arxiv.org/abs/2606.13707)

**Rethinking RAG in Long Videos: What to Retrieve and How to Use It?** — HF Papers trending. _Takeaway:_ Pushes RAG beyond text into long egocentric video, introducing a benchmark where queries genuinely require the video (exposing retrieval errors) and multi-modal/multi-granularity retrieval — a concrete advance in multimodal RAG evaluation. _Category:_ 2606.13141. [link](https://arxiv.org/abs/2606.13141)

**The Arbiter Agent: Continually Monitoring Multi-Agent Conversations to Detect Emergent Misalignment** — HF Papers trending. _Takeaway:_ A monitor agent that watches multi-agent dialogues to catch misalignment that emerges from interaction even when each agent looks well-aligned in isolation — an agent-safety / observability primitive for multi-agent systems. _Category:_ 2606.10747. [link](https://arxiv.org/abs/2606.10747)

**The Coin Flip Judge? Reliability and Bias in LLM-as-a-Judge Evaluation** — Abel Yagubyan. _Takeaway:_ Quantifies run-to-run instability of LLM-as-a-Judge across 29 tasks and two OpenAI judges with 50 pairwise/pointwise repeats, characterizing how unreliable judge-based leaderboards and reward signals can be. _Category:_ 2606.13685. [link](https://arxiv.org/abs/2606.13685)

**TASR: Training-Free Adaptive Stopping for Iterative Retrieval** — Adrian Kieback et al. _Takeaway:_ Training-free stopping policy for iterative RAG agents that halts once retrieval stops changing the answer/evidence, cutting wasted retrieval calls without a learned stopper. _Category:_ 2606.13814. [link](https://arxiv.org/abs/2606.13814)

**ADORE: Iterative Query Expansion with Retrieval-Grounded Relevance Feedback** — Amin Bigdeli et al. _Takeaway:_ Grounds LLM query expansion in how the target corpus actually responds, curbing the "retrieval drift" of generation-only pseudo-document expansion. _Category:_ 2606.13905. [link](https://arxiv.org/abs/2606.13905)

**Benchmarking Web Agent Safety under E-commerce Deceptive Interfaces (WebDecept)** — Zijing Shi, Meng Fang, Ling Chen. _Takeaway:_ Introduces a configurable framework injecting realistic deceptive UI patterns into e-commerce sites to stress-test autonomous web agents' safety under adversarial interfaces. _Category:_ 2606.13686. [link](https://arxiv.org/abs/2606.13686)
