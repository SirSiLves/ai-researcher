## Top picks

**Agent Planning Benchmark (APB)** — diagnostic framework for planning capabilities in LLM agents. _Takeaway:_ 4,209 multimodal cases across 22 domains covering holistic planning, feedback-conditioned step-wise planning, and robustness under extraneous/broken tools and unsolvable tasks — a fine-grained planning diagnostic distinct from end-to-end agent benchmarks. _Category:_ 2606.04874. [link](https://arxiv.org/abs/2606.04874)

**Proof-Carrying Agent Actions (PCAA)** — model-agnostic runtime governance for heterogeneous agent systems. _Takeaway:_ attaches verifiable proofs to agent actions so policies can be enforced at runtime across mixed agent stacks regardless of underlying model — a concrete agent-governance/runtime-standards primitive. _Category:_ 2606.04104. [link](https://arxiv.org/abs/2606.04104)

**CodegenBench: Can LLMs Write Efficient Code Across Architectures?** _Takeaway:_ benchmarks generation of efficient parallel code across x86_64, Sunway, and Kunpeng, probing the underexplored question of CPU-oriented high-performance code generation beyond single-architecture correctness. _Category:_ 2606.04023. [link](https://arxiv.org/abs/2606.04023)

**Multi-User Large Language Model Agents** _Takeaway:_ formalizes multi-user interaction as a multi-principal decision problem and introduces a unified protocol with stress-test scenarios for instruction following, privacy preservation, and coordination across competing principals. _Category:_ 2604.08567. [link](https://arxiv.org/abs/2604.08567)

**Self-Aware Vector Embeddings for RAG (SmartVector)** — neuroscience-inspired temporal, confidence-weighted, relational embeddings. _Takeaway:_ augments dense embeddings with temporal awareness and confidence decay to fix the case where conventional RAG returns semantically similar but temporally invalid content (58% accuracy on versioned technical queries). _Category:_ 2604.20598. [link](https://arxiv.org/abs/2604.20598)

**Information Fidelity in Tool-Using LLM Agents: A Martingale Analysis of MCP** — AAMAS 2026. _Takeaway:_ formal martingale analysis of how information degrades across MCP tool-call chains, framing MCP's M×N→M+N integration model and bounding fidelity loss in multi-hop tool use. _Category:_ 2602.13320. [link](https://arxiv.org/pdf/2602.13320)

**MCP Tool Descriptions Are Smelly! Augmented MCP Tool Descriptions** _Takeaway:_ shows that low-quality MCP tool descriptions degrade agent efficiency and proposes augmented descriptions that improve tool selection/invocation — a practical interoperability-layer finding for MCP deployments. _Category:_ 2602.14878. [link](https://arxiv.org/html/2602.14878v2)

**Agent Skills for Large Language Models: Architecture, Acquisition, Security, and the Path Forward** — revised 2026-06-02. _Takeaway:_ frames the shift from monolithic models to modular skill-equipped agents, where skills are composable packages of instructions, code, and resources enabling dynamic capability extension without retraining. _Category:_ 2602.12430. [link](https://arxiv.org/abs/2602.12430)

**From the AI Act to a European AI Agency: Completing the Union's Regulatory Architecture** _Takeaway:_ argues the EU AI Act's institutional design is incomplete and proposes a centralized European AI Agency to close enforcement gaps — timely as the Act becomes fully applicable 2 August 2026. _Category:_ 2603.22912. [link](https://arxiv.org/abs/2603.22912v1)
