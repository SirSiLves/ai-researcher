## Top picks
For each: **Title** — authors. _Takeaway:_ 1 line. _Category:_ {arxiv id}. [link]

- **MiniMax Sparse Attention** — Xunhao Lai, Weiqi Xu, Yufeng Yang, Qiaorui Chen. _Takeaway:_ A blockwise sparse-attention scheme on top of GQA, with a lightweight index branch that scores and selects KV blocks, targets the quadratic-cost wall for ultra-long-context agentic/repo-scale/persistent-memory workloads. _Category:_ 2606.13392. [link](https://arxiv.org/abs/2606.13392)

- **The Cold-Start Safety Gap in LLM Agents** — Chung-En Sun, Linbo Liu, Tsui-Wei Weng. _Takeaway:_ Tool-calling agents are most vulnerable to safety threats at the very start of a session and get markedly safer after a few benign tasks; the SODA benchmark quantifies this across up to 20 preceding tasks and 7 models. _Category:_ 2606.07867. [link](https://arxiv.org/abs/2606.07867)

- **Risk Under Pressure: Compute-Aware Evaluation of Adversarial Robustness in Language Models** — Malikeh Ehghaghi, Boglárka Ecsedi, Marsha Chechik, Colin Raffel. _Takeaway:_ Argues fixed-budget attack-success-rate hides the true cost of jailbreaks (attack compute varies by orders of magnitude) and proposes a compute-aware robustness evaluation. _Category:_ 2606.11409. [link](https://arxiv.org/abs/2606.11409)

- **EvoBrowseComp: Benchmarking Search Agents on Evolving Knowledge** — Yunhan Wang, Jiaan Wang, Lianzhe Huang, Xianfeng Zeng. _Takeaway:_ A 400-question evolving benchmark for search agents that resists test-set contamination and parametric memorization, separating genuine retrieval from fact recall. _Category:_ 2606.13120. [link](https://arxiv.org/abs/2606.13120)

- **Evoflux: Inference-Time Evolution of Executable Tool Workflows for Compact Agents** — Kushal Raj Bhandari, Ling Yue, Ching-Yun Ko, Dhaval Patel. _Takeaway:_ Tackles the gap in MCP-style tool use for small models — discovering tools from live catalogs, satisfying schemas, tracking dependencies, grounding in executed evidence — by evolving executable workflows at inference time. _Category:_ 2606.12674. [link](https://arxiv.org/abs/2606.12674)

- **ToolSense: A Diagnostic Framework for Auditing Parametric Tool Knowledge in LLMs** — Ashutosh Hathidara, Sai Shruthi Sistla, Sebastian Schreiber, Sahil Bansal. _Takeaway:_ Audits parametric tool-retrieval (tools encoded as virtual vocabulary tokens) and probes whether ToolBench-style gains reflect real tool semantics or benchmark artifacts — relevant to retrieval over large tool catalogs. _Category:_ 2606.12451. [link](https://arxiv.org/abs/2606.12451)

- **EvoArena: Tracking Memory Evolution for Robust LLM Agents in Dynamic Environments** — Jundong Xu, Qingchuan Li, Jiaying Wu, Yihuai Lan. _Takeaway:_ A benchmark suite that models environments as sequences of progressive updates (terminal, software, social domains) to test whether agents keep knowledge and behavior aligned as conditions change. _Category:_ 2606.13681. [link](https://arxiv.org/abs/2606.13681)

- **Getting Better at Working With You: Compiling User Corrections into Runtime Enforcement for Coding Agents** — Yujun Zhou, Kehan Guo, Haomin Zhuang, Xiangqi Wang. _Takeaway:_ Shows memory layers (e.g. Mem0) still violate 57.5% of applicable preference checks; TRACE compiles user corrections into runtime rule enforcement so a fix in one session persists into the next. _Category:_ 2606.13174. [link](https://arxiv.org/abs/2606.13174)

- **See What I See, Know What I Think: Dense Latent Communication Across Heterogeneous Agents** — Siyi Chen, Xiaoyan Zhang, Meng Wu, Jonathan Tremblay. _Takeaway:_ Replaces lossy text passing between multi-agent systems with KV-cache communication across *heterogeneous* models, addressing cross-model latent alignment rather than assuming duplicate models. _Category:_ 2606.13594. [link](https://arxiv.org/abs/2606.13594)

- **WeaveBench: A Long-Horizon, Real-World Benchmark for Computer-Use Agents with Hybrid Interfaces** — Wanli Li, Bowen Zhou, Yunyao Yu, Zhou Xu. _Takeaway:_ 114 long-horizon tasks across 8 work domains that force computer-use agents to orchestrate across visual desktop, CLI, code editing, browsers, and external tools — interfaces prior benchmarks test in isolation. _Category:_ 2606.09426. [link](https://arxiv.org/abs/2606.09426)

## Other interesting items
- **[FORT-Searcher: Synthesizing Shortcut-Resistant Search Tasks for Training Deep Search Agents](https://arxiv.org/abs/2606.12087)** — Jia Deng, Yimeng Chen, Xiaoqing Xiang, Ziyang Zeng. Formalizes "shortcut-aware difficulty" for synthesizing search-training questions whose answers can't be reached by a cheaper identifying route.
- **[HarnessBridge: Learnable Bidirectional Controller for LLM Agent Harness](https://arxiv.org/abs/2606.12882)** — Xiaoxuan Wang, Haixin Wang, Alexander Taylor, Jason Cong. Replaces hand-engineered agent harnesses with an end-to-end-trainable plug-in module that mediates agent–environment interaction.
- **[Demystifying Hidden-State Recurrence: Switchable Latent Reasoning with On-Policy RL](https://arxiv.org/abs/2606.13106)** — Jiayu Yang, Chao Chen, Shengen Wu, Yinhong Liu. Explicit boundary tokens make latent chain-of-thought compatible with standard on-policy RL and give a foothold for mechanistic interpretation.
- **[EurekAgent: Agent Environment Engineering is All You Need For Autonomous Scientific Discovery](https://arxiv.org/abs/2606.13662)** — Amy Xin, Jiening Siow, Junjie Wang, Zijun Yao. Argues the bottleneck for autonomous scientific discovery is shifting from agent workflows to engineering the environments (resources, constraints, interfaces) agents act in.
- **[Rethinking Psychometric Evaluation of LLMs: When and Why Self-Reports Predict Behavior](https://arxiv.org/abs/2606.12730)** — Rafal Kocielnik, Pengrui Han, Peiyang Song, Myrl G. Marmarelis. Revisits self-report-vs-behavior dissociation, showing context matching and trait specificity determine whether low-cost psychometric probes predict deployment behavior.
- **[On the Limits of LLM Adaptability: Impact of Model-Internalized Priors on Annotation Task Performance](https://arxiv.org/abs/2606.00467)** — Etienne Casanova, Rafal Kocielnik, R. Michael Alvarez. Probes "decision stickiness" — how internalized priors limit prompt-based correction in zero-shot annotation and LLM-as-a-judge use.
