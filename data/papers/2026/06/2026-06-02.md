# AI Papers — 2026-06-02

## Top picks

**From Parameter Dynamics to Risk Scoring: Quantifying Sample-Level Safety Degradation in LLM Fine-tuning** — Xiao Wang, Yifei Zhang, YongKang Liu, et al. (ICML 2026). _Takeaway:_ Traces how individual fine-tuning samples erode a model's safety alignment and proposes a per-sample risk score to flag the offenders before they degrade the model. _Category:_ 2605.04572 (cs.AI). [link](https://arxiv.org/abs/2605.04572)

**CAR: Query-Guided Confidence-Aware Reranking for Retrieval-Augmented Generation** — Zhipeng Song, Yizhi Zhou, Xiangyu Kong, et al. _Takeaway:_ Reranks retrieved passages using query-conditioned confidence rather than raw similarity, tightening the context window fed to the generator in RAG pipelines. _Category:_ 2605.04495 (cs.CL). [link](https://arxiv.org/abs/2605.04495)

**Beyond Static Best-of-N: Bayesian List-wise Alignment for LLM-based Recommendation** — (cs.CL). _Takeaway:_ Replaces fixed best-of-N sampling with a Bayesian list-wise alignment objective, improving how LLM recommenders rank candidate items. _Category:_ 2605.04559 (cs.CL). [link](https://arxiv.org/abs/2605.04559)

**A Queueing-Theoretic Framework for Stability Analysis of LLM Inference with KV Cache Memory Constraints** — (cs.LG). _Takeaway:_ Models LLM serving as a queueing system to derive stability conditions under KV-cache memory limits — practical guidance for inference-platform capacity planning. _Category:_ 2605.04595 (cs.LG). [link](https://arxiv.org/abs/2605.04595)

**SensingAgents: A Multi-Agent Collaborative Framework for Robust IMU Activity Recognition** — (cs.AI). _Takeaway:_ Coordinates specialized LLM agents over noisy sensor streams, a concrete multi-agent-orchestration pattern applied to IMU human-activity recognition. _Category:_ 2605.04608 (cs.AI). [link](https://arxiv.org/abs/2605.04608)

**Towards General Preference Alignment: Diffusion Models at Nash Equilibrium** — Jiaming Hu, Jiamu Bai, Haoyu Wang, et al. _Takeaway:_ Frames preference alignment for diffusion models as finding a Nash equilibrium, generalizing RLHF-style alignment beyond autoregressive LLMs. _Category:_ 2605.04494 (cs.CL/cs.AI). [link](https://arxiv.org/abs/2605.04494)

**GenericAgent: A Token-Efficient Self-Evolving LLM Agent via Contextual Information Density Maximization** — Fudan University. _Takeaway:_ A self-evolving agent that maximizes contextual information density to cut token usage while improving task performance — agent-architecture + cost angle. _Category:_ 2604.17091 (cs.AI). [link](https://arxiv.org/abs/2604.17091)

**ARIS: Autonomous Research via Adversarial Multi-Agent Collaboration** — Shanghai Jiao Tong University. _Takeaway:_ Multi-agent autonomous-research system that improves scientific discovery through structured adversarial debate, self-healing execution, and verifiable reporting. _Category:_ 2605.03042 (cs.AI/cs.MA). [link](https://arxiv.org/abs/2605.03042)

**NanoResearch: Co-Evolving Skills, Memory, and Policy for Personalized Research Automation** — OpenMOSS. _Takeaway:_ Jointly evolves an agent's skill library, long-term memory, and policy for personalized research automation — agent memory/continual-learning primitives. _Category:_ 2605.10813 (cs.AI). [link](https://arxiv.org/abs/2605.10813)
