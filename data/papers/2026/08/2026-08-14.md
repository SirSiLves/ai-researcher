# AI Papers — 2026-08-14

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

**InterSAGE: The Secure and Verifiable Interoperability Protocol for An Internet of Agents** — Zhenhua Zou, Sheng Guo, Qiuyang Zhan, Lepeng Zhao, Shuo Li, Zhuotao Liu. _Takeaway:_ Positioning paper proposing a security- and verifiability-first interoperability protocol for cross-vendor agent communication — the "Internet of Agents" framing sits directly alongside MCP/A2A as a standards-layer proposal. _Category:_ arXiv:2608.13030 (cs.CR; cs.MA, cs.NI). [link](https://arxiv.org/abs/2608.13030)

**The Embedder's Dilemma: LLMs Are Better, but at What Cost?** — Adnan El Assadi, Niklas Muennighoff, Jinhyuk Lee. _Takeaway:_ From the MTEB/Gemini-embedding lineage: LLM-based embedders do beat smaller encoders on quality, but the paper prices the accuracy gain against inference cost — the decision every RAG/vector-store build actually faces. Accepted at COLM 2026. _Category:_ arXiv:2608.12875 (cs.CL). [link](https://arxiv.org/abs/2608.12875)

**Practice Makes Unsafe: Skill Misevolution in Self-Improving LLM Agents** — Xutao Mao, Liangjie Zhao, Xiang Zheng, Cong Wang. _Takeaway:_ Agents that accumulate skills from their own experience drift into unsafe behaviour — a safety failure mode created by the self-improvement loop itself, not by the base model. _Category:_ arXiv:2608.12851 (cs.AI). [link](https://arxiv.org/abs/2608.12851)

**Beyond Final Scores: A Systematic Evaluation of Agents for Long-Horizon AI Research and Development** — Yiwei Li, Wanli Yang, Hexiang Tan, Xiangzhou Huang, Zhengyu Chen et al. (Meituan). _Takeaway:_ Argues end-score benchmarks hide how long-horizon R&D agents actually behave, and builds a process-level evaluation instead. _Category:_ arXiv:2608.13417 (cs.AI). [link](https://arxiv.org/abs/2608.13417)

**RAGSieve: Self-Referenced Local Contrast for Knowledge-Poison Detection in Retrieval-Augmented Generation** — Xinlong Xu, Yoshua Y. Li. _Takeaway:_ Detects poisoned passages in a RAG corpus by contrasting each retrieved chunk against its local neighbourhood, with no clean reference set required — a defence that fits an existing pipeline. _Category:_ arXiv:2608.13010 (cs.CL; cs.CR, cs.IR). [link](https://arxiv.org/abs/2608.13010)

**StateBridge: Training-free Hidden-state Alignment for Latent Communication in LLM Multi-Agent Systems** — Yanwen Peng, Delvin Ce Zhang, Xi Wang, Nikolaos Aletras. _Takeaway:_ Agents exchange aligned hidden states instead of natural-language messages, with no training required — a cheaper interop primitive for multi-agent orchestration. Accepted at COLM 2026. _Category:_ arXiv:2608.13317 (cs.AI). [link](https://arxiv.org/abs/2608.13317)

**Rules or Character? Scaling Laws for AI Safety Design** — Satoshi Takahashi, Nobuji Kouno, Masaaki Komatsu, Ryuji Hamamoto. _Takeaway:_ Compares rule-based guardrails against character/persona-level safety conditioning and finds which wins flips with model scale — a direct input to how a safety layer should be designed. Accepted at AIES 2026. _Category:_ arXiv:2608.13345 (cs.AI). [link](https://arxiv.org/abs/2608.13345)

**GEM: A Generative Embedding Model Bridging Reasoning and Retrieval** — Zhili Shen, Craig Macdonald (Glasgow). _Takeaway:_ A single generative model that produces embeddings while retaining reasoning ability, aiming to close the gap between "retrieve then reason" and "reason to retrieve". _Category:_ arXiv:2608.13200 (cs.CL; cs.AI, cs.IR). [link](https://arxiv.org/abs/2608.13200)

**Sovereign by necessity? Frontier AI export controls, cyber security, and the limits of national AI capability** — Alan Woodward, Andrew Rogoyski (Surrey). _Takeaway:_ 42-page policy analysis of whether export controls actually produce sovereign AI capability or merely relocate the dependency — relevant to the European/Swiss sovereignty debate. _Category:_ arXiv:2608.13272 (cs.AI; cs.CR). [link](https://arxiv.org/abs/2608.13272)

**Agent Behavioral Contracts II: Certifying Compositional Reliability Without Assuming Independence** — Varun Pratap Bhardwaj, Garima Singh, Arun Pratap Bhardwaj. _Takeaway:_ Formal reliability certification for composed agent systems that drops the (false) assumption that component failures are independent — 18 theorems, six experiments, preregistered. _Category:_ arXiv:2608.12895 (cs.AI; cs.MA). [link](https://arxiv.org/abs/2608.12895)

## Other interesting items

- **[When Your Agent Opens the Chat App: Agent-Controlled Search over Raw Chat Logs Rivals Structured Memory](https://arxiv.org/abs/2608.12888)** — Ruizhe Li, Licheng Zhang, Benfeng Xu, Mingxuan Du, Zheren Fu, Weidong Chen. Letting the agent search raw logs matches purpose-built memory structures — an argument against premature memory engineering.
- **[RippleMem: From Isolated Retrieval to Associative Recollection for Long-Term Agent Memory](https://arxiv.org/abs/2608.13334)** — Jingbo Ji et al. Associative recall over agent memory rather than independent top-k retrieval.
- **[Who Speaks Matters: Authority-Aware Multi-View RAG over Italian Parliamentary Proceedings](https://arxiv.org/abs/2608.13410)** — Mirko Tritella, Riccardo Pozzi, Matteo Palmonari. RAG that weights passages by speaker authority instead of treating the corpus as flat; ISWC 2026 In-Use track.
- **[Discovering Efficient and Explainable Communication Topologies for LLM-based Multi-Agent Systems via Causal Inference](https://arxiv.org/abs/2608.12921)** — Junzhi Li et al. Causal inference to find which agent-to-agent edges actually carry signal, cutting communication cost.
- **[Rethinking Agent Security as a Networking Problem](https://arxiv.org/abs/2608.12172)** — Van Tran, Taveesh Sharma, Tajveer Singh Dhesi, Nick Feamster (Chicago). Reframes agent security around network-style controls rather than prompt-level defences.
- **[DFM Mimir v1: An Open HRM Delivering Frontier Performance at 1B Parameters Using Only Permissible Post-Training Data](https://arxiv.org/abs/2608.13517)** — Peter Schneider-Kamp et al. Open 1B hierarchical reasoning model trained only on licence-clean post-training data — the data-provenance angle matters as much as the benchmark.
- **[Beyond Retrieval: Query-Conditioned Reuse of Long-Horizon Agent Trajectories](https://arxiv.org/abs/2608.12847)** — Yifei Li et al. Conditions trajectory reuse on the current query rather than retrieving past runs verbatim.
- **[QuoteBench: How Matched Scores Can Hide Command-Path Failures](https://arxiv.org/abs/2608.13547)** — Shangao Li, Yao Zhang, Volker Tresp, Yuanyuan Yang. Two models with identical benchmark scores can fail very differently on the command path.
