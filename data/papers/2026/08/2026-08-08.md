## Top picks

**The Bitter Lesson of Tool Calling** — Ishan Patel, Sahil Sen, Elias Lumer, Vamse Kumar Subbiah.
_Takeaway:_ A Sutton-style argument applied to tool use — hand-engineered tool schemas, routers and selection heuristics lose to scale and general learning, which cuts directly against the elaborate tool-registry and description-engineering layers most MCP-era agent stacks are building. _Category:_ 2608.06370 (cs.CL). https://arxiv.org/abs/2608.06370

**Beyond Top-K: Replacing Black-Box Retrieval with Interpretable Agentic Operations** — Sagar Tamang, Ayush Vyas, Tabarakul Hazarika.
_Takeaway:_ Swaps the opaque top-K dense-retrieval call for a set of explicit, inspectable retrieval operations the agent composes itself — the clearest statement yet of the "retrieval as tool-use, not as a black box" turn in agentic RAG. _Category:_ 2608.06305 (cs.AI; cs.CL; cs.IR). https://arxiv.org/abs/2608.06305

**Benchmarking the Benchmarks: Evaluating Benchmarks for Conversational Agents** — Noam Koren, Roy Bar-Haim, Abigail Goldsteen (IBM Research).
_Takeaway:_ Meta-evaluation of the conversational-agent benchmark landscape itself — useful ammunition when a vendor cites a benchmark number, since it grades which benchmarks actually discriminate. _Category:_ 2608.06329 (cs.CL; cs.AI). https://arxiv.org/abs/2608.06329

**Learning When to Trust via Selective Context Preference Optimization** — Xian Sun, Wei Chow, Yingshuo Wang, Junhao Liu, Wei Gao, Qing Wu, Lingdong Kong.
_Takeaway:_ Trains the model to decide when retrieved/injected context deserves trust versus when to fall back on parametric knowledge — the core failure mode of production RAG, with code and the MIST-Bench dataset released. _Category:_ 2608.06377 (cs.CL; cs.AI; cs.LG). https://arxiv.org/abs/2608.06377

**NeSy-RAG: Neuro-Symbolic RAG for Explainable Question Answering** — Jonas Gann, Michael Gertz.
_Takeaway:_ Puts a symbolic layer over retrieval so the answer carries a checkable derivation rather than a vibe-based citation — the explainability angle regulated industries keep asking RAG vendors for. _Category:_ 2608.06292 (cs.CL; cs.SC). https://arxiv.org/abs/2608.06292

**Filtered Vector Search in a Disaggregated Lakehouse: Composing Table-Format Pruning with Per-File ANN** — Rakesh Jain, Thomas Griffin, Syed Zawad (IBM Research).
_Takeaway:_ Builds filtered ANN out of Iceberg-style table pruning plus per-file indexes instead of a dedicated vector database — the architectural case for "your lakehouse is the vector store", which is exactly the build-vs-buy question enterprises are hitting. _Category:_ 2608.05441 (cs.DB; cs.DC; cs.ET; cs.IR). https://arxiv.org/abs/2608.05441

**From Trajectories to Evidence: Auditable Experimental Records for Industrial Research Agents** — Zijie Zhuang, Changxin Lao, Pengbo Xu, Hanwen Xu, Ruochen Yang, Yingzhi He, Peng Zhang, Jiangxia Cao, Yusheng Huang, Guohong Mu, Jian Liang, Ruiming Tang, Shuang Yang, Zhaojie Liu, Wenwu Ou, Kun Gai.
_Takeaway:_ Turns raw agent trajectories into auditable experimental records — an observability/provenance primitive from a large industrial deployment, and the practical bridge between "the agent did something" and "we can defend what it did". _Category:_ 2608.05235 (cs.IR). https://arxiv.org/abs/2608.05235

**SkillZip: Contract-Preserving Graph Compression for Scalable Agent Skill Libraries** — Xingyu Tan, Xiaoyang Wang, Qing Liu, Xiwei Xu, Xin Yuan, Liming Zhu, Wenjie Zhang (CSIRO Data61).
_Takeaway:_ Compresses a growing skill library while preserving each skill's interface contract, addressing the context-window blowup that hits every agent once the skill/tool catalogue passes a few dozen entries. _Category:_ 2608.05604 (cs.CL; cs.AI). https://arxiv.org/abs/2608.05604

**Where Privacy Risk Lives in English-Source Multilingual RAG: A Stage-Decomposed Audit Across Five Query Languages** — Yanhang Li, Zhichao Fan, Zexin Zhuang.
_Takeaway:_ Decomposes a multilingual RAG pipeline stage by stage to locate where PII actually leaks — directly relevant to any European deployment where the corpus is English but the queries are not. _Category:_ 2608.05163 (cs.CL; cs.LG). https://arxiv.org/abs/2608.05163

**Mood Matters: How Syntactic Sensitivity Undermines Safety Alignment** — Alina Klerings, Jannik Brinkmann, Heiner Stuckenschmidt, Simone Paolo Ponzetto (Mannheim).
_Takeaway:_ Grammatical mood alone (imperative vs. interrogative phrasing) moves safety-refusal behaviour, showing alignment is keyed to surface syntax rather than intent — a cheap, reproducible jailbreak surface. _Category:_ 2608.05409 (cs.CL). https://arxiv.org/abs/2608.05409

**When Does LLM Orchestration Pay Off? A Controlled Evaluation of Accuracy, Cost, and Task Difficulty** — Nicolas Leins, Nico Pelleriti, Jana Gonnermann-Müller, Sebastian Pokutta (ZIB / TU Berlin).
_Takeaway:_ Holds task difficulty fixed and measures when multi-model orchestration actually beats a single call on the accuracy/cost frontier — the missing controlled answer to the question every platform team is guessing at, and the natural companion to the routing-bounds paper below. _Category:_ 2608.00685 (cs.AI primary). https://arxiv.org/abs/2608.00685

**Agentic Coding in the Wild: Characterizing GitHub Copilot Traces at Production Scale** — Banruo Liu, Haoran Qiu, Íñigo Goiri, Rodrigo Fonseca, Ricardo Bianchini, Esha Choukse (Microsoft Azure Research).
_Takeaway:_ Production telemetry from Copilot rather than a benchmark — what agentic coding sessions actually look like at scale, which is the empirical ground truth most agent-platform capacity and cost planning currently lacks. _Category:_ 2608.00101 (cs.AI primary; cs.LG). https://arxiv.org/abs/2608.00101

**SIRIN: A Unified Toolkit for Detecting Contextual Hallucinations in Retrieval-Augmented and Memory-Grounded LLM Systems** — Julia Belikova, Rauf Parchiev, Mikhail Filimonov, Konstantin Polev, Andrey Savchenko, Maksim Makarenko.
_Takeaway:_ One toolkit spanning both RAG-grounded and memory-grounded hallucination detection, which matters because agent memory is now a second ungrounded surface that existing RAG-only faithfulness checks silently miss. _Category:_ 2608.00033 (cs.AI primary). https://arxiv.org/abs/2608.00033

**Shared Organizational Memory for Enterprise Coding Agents: System Design and Deployment Snapshot** — Harsh Rao Dhanyamraju, Leonidas Raghav.
_Takeaway:_ A deployed design for memory shared *across* an organization's coding agents rather than per-session — the architectural step from "each agent relearns the codebase" to an institutional knowledge layer, with a real deployment snapshot rather than a proposal. _Category:_ 2608.00122 (cs.AI primary). https://arxiv.org/abs/2608.00122

**Crushing the Evidence: A Dual-Penalty Evasion Framework for Fooling White-Box Explainable AI Auditors** — Niraj Kumar, Harsh Kasyap.
_Takeaway:_ Shows a model can be trained to satisfy a white-box explainability audit while retaining the behaviour the audit is meant to catch — a direct attack on the assurance model that XAI-based AI-governance regimes are being built on. _Category:_ 2608.00566 (cs.LG primary; cs.AI). https://arxiv.org/abs/2608.00566

## Other interesting items

- **[Routing Is Least Learnable Where It Is Most Valuable: Bounds on Representation Routing for Web Agents](https://arxiv.org/abs/2608.06171)** — Jiaming Wei, Zekun Wu, Adriano Koshiyama, Maria Perez-Ortiz (REALM @ EMNLP 2026) — theoretical bounds showing model/tool routing is hardest to learn exactly in the regimes where routing would pay off most.
- **[Causal Episodic Memory for Feedback-Driven Agent Repair](https://arxiv.org/abs/2608.05906)** — Khang Nhat Hoang Vo, Tam Minh Chu, Anh Trac Duc Dinh, Thuyen Vinh Ha Bui, Tho Quan — stores episodes with causal structure so an agent can trace a failure back to the decision that caused it and repair rather than retry.
- **[Mapping Similarity Spaces across Embedding Models with Synthetic Query Probing](https://arxiv.org/abs/2608.05857)** — Marcin Rozmus, Peter van der Putten (Discovery Science 2026) — probes how two embedding models' similarity geometries differ, which is the missing diagnostic before any embedding-model migration.
- **[EXCISE: Query-Side Exclusion for Late-Interaction Retrieval](https://arxiv.org/abs/2608.05497)** — Mohammed Ali, Abdelrahman Abdallah, Adam Jatowt — adds negation/exclusion semantics to ColBERT-style late interaction, a long-standing gap in dense retrieval.
- **[From Siloed Algorithms to Compliance-First Agentic Platforms: A Multi-Layered Architecture for Hospital AI Systems](https://arxiv.org/abs/2608.06112)** — Manideep Dhar, Ritwik Singh, Sharat Chandra Kumar Manikonda — a reference architecture that makes compliance a platform layer rather than a per-model afterthought; a transferable pattern for any regulated agentic rollout.
- **[AgentStream: How Well Do Self-Evolving LLM Agents Perform Under Streaming Tasks?](https://arxiv.org/abs/2608.00155)** — Dong Yan, Jian Liang, Dapeng Hu, Ran He, Nicholas Jing Yuan, Qi Zhang, Tieniu Tan (cs.AI primary) — drops self-evolving agents into a continuous task stream instead of an episodic benchmark; code released.
- **[Memory Reward Inflation in Self-Improving LLM Agents](https://arxiv.org/abs/2608.00017)** — Mohammad Asadolahi, Amir Amini, Samira Talebi, Amirfarhad Farhadi, Azadeh Zamanifar (cs.AI primary) — names the failure where an agent's own memory inflates its reward signal, i.e. self-improvement loops that drift into self-congratulation.
- **[More Debate, Same Evidence: Structural Limits of Homogeneous Multi-Agent Groundedness](https://arxiv.org/abs/2608.00243)** — Yuelyu Ji (cs.AI primary) — argues debate among copies of the same model cannot add grounding, only confidence; a cheap sanity check on multi-agent-debate architectures.
- **[RAG-TESTER: Automated End-to-End Testing of Retrieval-Augmented Large Language Models](https://arxiv.org/abs/2608.00054)** — Ange Maiztegi, Jon Ayerdi, Miren Illarramendi, Aitor Arrieta (cs.AI primary; cs.SE) — treats a RAG pipeline as a system under test rather than a model to be scored, which is the software-engineering framing enterprise QA teams need.
- **[H+ Embedding: Harmonizing Global and Token-Level Retrieval with Context-Dependent Phrases](https://arxiv.org/abs/2608.00065)** — Shusen Zhang, Junyi Hu, Ye Feng et al. (cs.AI primary; cs.LG) — one embedding serving both dense whole-document and token-level late-interaction retrieval, collapsing a stack most teams currently run twice.
- **[AOSpec: Action and Observation Co-Speculation for Low-Latency Agent Serving](https://arxiv.org/abs/2608.00881)** — Hao Mark Chen, Jinnan Guo, Wayne Luk, Hongxiang Fan (cs.LG primary) — extends speculative decoding past tokens to whole agent actions and their observations, attacking the tool-call round-trip that dominates agent latency.
- **[MetaRoute-Bench: Evaluating Meta-Decision Policies for Agentic Workflow Routing](https://arxiv.org/abs/2608.00107)** — Natan Vidra, Alina Kapanova, Arun Kanhai, Spurthi Setty (cs.LG primary; cs.AI) — an executable benchmark for the routing decision itself; pairs with their compositional meta-routing paper ([2608.00106](https://arxiv.org/abs/2608.00106)).
- **[Leak It: A Probabilistic Approach to Training-Data Extraction from Black-Box Language Models](https://arxiv.org/abs/2608.00144)** — Victor Maricato (cs.LG primary; cs.CR) — black-box training-data extraction with released code, which moves this from a research curiosity to a due-diligence item for anyone fine-tuning on proprietary corpora.
