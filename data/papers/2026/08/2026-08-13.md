# AI Papers — 2026-08-13

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

**BDH-CQ: In-Context Learning with Recurrent Latent Reasoning** — Pathway (submitted by Jan Chorowski).
_Takeaway:_ A 150M-parameter model using recurrent latent reasoning plus in-context learning sets a new cost-accuracy frontier on ARC-AGI-1 — the strongest small-model reasoning result on HF Papers this week (559 upvotes, #1 trending).
_Category:_ arXiv:2608.09888. [link](https://arxiv.org/abs/2608.09888)

**SciRet: A Compute-Aware Empirical Study of Retrieval and Reranking for Scientific RAG** — (arXiv 2608.03860).
_Takeaway:_ Across 1K/5K/15K-paper corpora, hybrid BM25 + BGE-M3 + RRF retrieval is more robust than sparse- or dense-only, and an MS MARCO-trained cross-encoder reranker actually *reduces* precision on scientific text — domain mismatch outweighs stronger query-passage interaction.
_Category:_ cs.IR — arXiv:2608.03860. [link](https://arxiv.org/abs/2608.03860)

**Rethinking Agent Security as a Networking Problem** — Van Tran, Taveesh Sharma, Tajveer Singh Dhesi, Nick Feamster.
_Takeaway:_ Argues agent-to-agent security should be framed with networking primitives (identity, isolation, policy at the "wire") rather than as a prompt-level problem — directly relevant to MCP/A2A trust boundaries.
_Category:_ cs.MA — arXiv:2608.12172. [link](https://arxiv.org/abs/2608.12172)

**Beyond Memory: A Transactional Continuity Kernel for Long-Lived AI Agents** — Jun He, Deying Yu.
_Takeaway:_ Proposes a transactional kernel (rather than a memory store) as the durability primitive for agents that must survive across sessions and failures.
_Category:_ cs.MA / cs.AI — arXiv:2608.11632. [link](https://arxiv.org/abs/2608.11632)

**MasDrift: Benchmarking Authorization Preservation Across Multi-Agent Architectures** — Zhuoning Xu, Xiucheng Zhang, Hanjun Luo, Yingbin Jin, Yinpeng Dong, Hanan Salam.
_Takeaway:_ A benchmark for whether permissions survive delegation hops between agents — the governance question that agent interop standards keep deferring.
_Category:_ cs.MA — arXiv:2608.07556. [link](https://arxiv.org/abs/2608.07556)

**Mitigating Context Interference for Reliable and Efficient Search Agents** — Boyang Xue, Bin Wu, Shuofei Qiao, Sheng Wang, Rui Wang, Yiming Du, Hongru Wang, Jeff Z. Pan, Emine Yilmaz, Kam-Fai Wong, Aldo Lipani.
_Takeaway:_ Retrieved context accumulated over multi-hop search turns actively degrades the agent; the paper targets that interference rather than retrieval quality.
_Category:_ cs.CL — arXiv:2608.10743. [link](https://arxiv.org/abs/2608.10743)

**Cracks in the Foundation: Seemingly Minor Architectural Choices Impact Long Context Extension** — Amanda Bertsch, Luca Soldaini, Matthew R. Gormley, Graham Neubig, Hannaneh Hajishirzi, Kyle Lo, Dirk Groeneveld.
_Takeaway:_ AI2/CMU show small pretraining architecture decisions determine how far a model can later be context-extended — a pretraining-time constraint on long-context roadmaps. Accepted to COLM 2026.
_Category:_ cs.CL — arXiv:2608.10296. [link](https://arxiv.org/abs/2608.10296)

**MAP-Graph: Provenance-Aware Shared Memory for Multi-Agent Workflows** — Yiqi Wang, Zihao Yan, Jiaqi Zhang, Zhangkai Wu, Mingkai Zheng, Zequn Sun, Yanming Zhu, Taotao Cai.
_Takeaway:_ Shared agent memory with provenance tracking, so a multi-agent workflow can attribute where a belief entered the graph.
_Category:_ cs.AI / cs.MA — arXiv:2608.10509. [link](https://arxiv.org/abs/2608.10509)

**EvoGraph-Mem: Failure-Aware Editable Graph Memory for Long-Term Language Agents** — Yuxi Qian, Yuxiang Ren.
_Takeaway:_ Graph memory that can be edited when downstream failures reveal a bad stored fact — memory as a maintained artifact, not an append-only log.
_Category:_ cs.AI / cs.MA — arXiv:2608.11248. [link](https://arxiv.org/abs/2608.11248)

**Actions Speak Louder than Words: Measuring Cross-Lingual Policy Retention in Tool-Using Agents** — Sourabrata Mukherjee, Kalika Bali, Sunayana Sitaram.
_Takeaway:_ Tests whether a tool-using agent still obeys its policy when the interaction switches language — safety evaluated on actions taken, not text produced. Accepted at COLM 2026.
_Category:_ cs.CL — arXiv:2608.11110. [link](https://arxiv.org/abs/2608.11110)

**Similarity Gates Approve Reversals: A Validity Audit of Embedding-Cosine Thresholds in Agent Systems** — Scott E. Frias.
_Takeaway:_ Cosine-similarity gates used across RAG and agent pipelines will wave through semantically reversed content; a direct validity warning for threshold-based retrieval filters.
_Category:_ cs.CL / cs.AI — arXiv:2608.10216. [link](https://arxiv.org/abs/2608.10216)

**Multi-Agent AI Safety as an Institutional Design Problem** — Abdullah X.
_Takeaway:_ Frames multi-agent safety as institution/mechanism design rather than per-agent alignment — a governance framing with public reproducibility artifacts.
_Category:_ cs.LG / cs.MA — arXiv:2608.09828. [link](https://arxiv.org/abs/2608.09828)

**Co-Evolution in Agentic Systems: Toward Self-Directed Evolution Beyond Human Design** — Qing Zong, Jiayu Liu, Junhao Shen, Zecong Tang, Linsi Wu, Yuxuan Liu, Rui Wang, Zhaowei Wang, Weiqi Wang, Cheng Qian, Xiusi Chen, Yangqiu Song.
_Takeaway:_ Position/framework paper on agent systems that co-evolve their own components rather than being re-architected by hand.
_Category:_ cs.CL — arXiv:2608.10299. [link](https://arxiv.org/abs/2608.10299)

**Data Attribution of Emergent Misalignment with Persona Features** — Clemens Vetter, David Kaczér, Lucie Flek, Florian Mai.
_Takeaway:_ Traces emergent misalignment back to specific training data via persona features — attribution rather than post-hoc behavioral patching.
_Category:_ cs.CL — arXiv:2608.11025. [link](https://arxiv.org/abs/2608.11025)
