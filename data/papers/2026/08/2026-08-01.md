## Top picks

**A Comparative Study of MCP and A2A for Inter-Agent Coordination in LLM-Based Systems** — Ionut Predoaia, Tuong Manh Vu, Konstantinos Barmpis, Dimitris Kolovos, Antonio García-Domínguez.
_Takeaway:_ First implementation-grounded head-to-head of MCP vs A2A — same software-engineering task built twice, scored against industry-derived requirements (agent discoverability, multi-part messaging, multi-turn conversation), rather than the usual spec-level comparison.
_Category:_ cs.MA — arXiv:2607.23884. [link](https://arxiv.org/abs/2607.23884)

**Stop Shipping AI Agents on Faith: Capability Is Not Production Readiness** — Fouad Bousetouane.
_Takeaway:_ Proposes the ProofAgent Index (PAI), a four-dimension deployment-evidence score — Evaluation, Context, Compliance, Governance — arguing demos and behavioral tests say nothing about whether an agent survives production constraints.
_Category:_ cs.MA — arXiv:2607.27677. [link](https://arxiv.org/abs/2607.27677)

**Separating Capability from Permission: A Governance Framework for Agentic AI Autonomy Levels** — Haining Zheng, Qian Dong, Rodolfo K. Depena, Jonathan D. Bhatia, Feng Xiao, Peng Xu.
_Takeaway:_ Splits Allowed Autonomy Levels (what an agent is authorized to do, given risk and oversight) from Autonomous Capability Levels (what it technically can do), with five rungs from reactive execution to delegated operational authority — a clean vocabulary for agent deployment policy.
_Category:_ cs.MA / cs.AI — arXiv:2607.23438. [link](https://arxiv.org/abs/2607.23438)

**Can Agents Deceive? Evaluating Reasoning and Deception in ParliamentBench using a Social Deduction Game** — Niklas Bauer, Lars Benedikt Kaesberg, Akiko Aizawa, Jan Philip Wahle, Bela Gipp, Terry Ruas.
_Takeaway:_ Open-source benchmark built on Secret Hitler; 16 LLMs across 1,600 simulated matches (model-vs-model, model-vs-human, plus a corpus of real online games) with metrics that separate social deduction from reasoning from deliberate deception.
_Category:_ cs.CL — arXiv:2607.28146. [link](https://arxiv.org/abs/2607.28146)

**How Benchmarks Mis-Score Computer-Use Agents** — Zihan Dong, Zhiyuan Ma, Zekun Wang, Yunqing Li, Zirou Liu, Ruixuan Deng.
_Takeaway:_ Audit of 150 failure-scored trajectories across five web/enterprise/desktop CUA benchmarks finds 15.3% of FAIL verdicts are wrong — 10.7% evaluator false negatives, 4.7% broken tasks. Scripted oracles are quietly deflating reported agent capability.
_Category:_ cs.AI — arXiv:2607.28367. [link](https://arxiv.org/abs/2607.28367)

**PAIChecker: Uncovering and Checking PR-Issue Misalignment in SWE-Bench-Like Benchmarks** — Manyi Wang, Junjielong Xu, Pinjia He.
_Takeaway:_ 13.6% of SWE-bench Verified instances have PR-issue pairings that don't actually match, across five misalignment patterns — the problem statement and the test oracle describe different work. Companion piece to the CUA audit above; both say benchmark plumbing is now the measurement bottleneck.
_Category:_ cs.AI / cs.SE — arXiv:2607.28587. [link](https://arxiv.org/abs/2607.28587)

**Sample More, Reflect Less: Self-Refine and Reflexion Lose to Repeated Sampling at Equal Token Cost, from 1.5B to 7B** — Iliya Mirzaei.
_Takeaway:_ Properly powered replication (seven methods, three model sizes, two math benchmarks, with confidence intervals) confirms that plain repeated sampling plus majority vote beats self-critique and reflection loops once token budgets are matched. Most "reasoning scaffold" gains are just more tokens.
_Category:_ cs.CL / cs.AI / cs.LG — arXiv:2607.28576. [link](https://arxiv.org/abs/2607.28576)

**GLM-RAG: Graph Language Models for Graph-Based Retrieval-Augmented Generation** — Maya Arseven, Anette Frank, Beni Egressy, Johann Higl, Moritz Plenz.
_Takeaway:_ Benchmarks graph-language-model retrievers against GNN and plain vector search on single- and multi-hop RAG, with an explicit focus on transfer to unseen domains — the axis most KG-RAG papers skip.
_Category:_ cs.AI / cs.CL / cs.IR — arXiv:2607.28397. [link](https://arxiv.org/abs/2607.28397)

**ChronoMem: Version Control and Semantic Rollback for Large Language Model Agent Memory** — Yongye Su, Wujiang Xu, Chaoji Zuo, Elisa Bertino.
_Takeaway:_ Agent memory today is forward-only — no way to inspect, version, or revert. ChronoMem adds whole-memory snapshots, version history, and semantic rollback as a layer inside Google's open-source Agent Development Kit.
_Category:_ cs.CL / cs.AI — arXiv:2607.27773. [link](https://arxiv.org/abs/2607.27773)

## Other interesting items

- **[RAGuard: A Layered Defense Framework for Retrieval-Augmented Generation Systems Against Data Poisoning](https://arxiv.org/abs/2607.26339)** — Pushkal Kumar, Tucker Nielson, Tanish Kolhe, Shubham Zala et al. — Adversarially fine-tuned retriever downranks poisoned passages, then a label-free black-box filter (Zero-Knowledge Inference Patch) scores each retrieved doc by leave-one-out semantic shift.
- **[SafeFlow: Semantic Information-Flow Control for Blocking Malicious Propagation in Multi-Agent Systems](https://arxiv.org/abs/2607.25255)** — Haowen Dai, Zonghao Ying, Wenfeng Li, Xiangfan Wu et al. — Treats "harmful goal split into individually innocuous subtasks" as an information-flow problem rather than per-turn prompt classification.
- **[AgentRadio: Passive Awareness for Long-Horizon Multi-Agent Collaboration](https://arxiv.org/abs/2607.28430)** — Xinxing Ren, Qianbo Zang, Ziyan Wang, Caelum Forder et al. — On SWE-Atlas QnA a single Claude Code agent (Opus 4.6) resolves 32.3%; the paper argues sub-agents must exchange findings mid-execution, not only at staged handoffs.
- **[ORCA-bench: How Ready Are Language Model Agents for Oncall?](https://arxiv.org/abs/2607.28545)** — Albert Gong, Kyuseong Choi, Abhineet Agarwal, Jason Schechner et al. — 1,079 root-cause-analysis tasks against a live OpenTelemetry microservice stack (Prometheus, Jaeger, OpenSearch via Grafana) with six days of real telemetry.
- **[InfoOps Bench: A live information operations safety benchmark](https://arxiv.org/abs/2607.28503)** — Dorian Quelle, Lisa-Maria Neudert, Jonathan Bright, John Gallacher — Continuously updated benchmark measuring whether frontier models can be co-opted for state-backed influence ops, drawn from 2,100+ tracked Russian, Chinese and Iranian operations.
