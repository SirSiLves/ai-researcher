**Today's through-line:** measurement and permissions. Four separate groups independently argue that the thing being measured (agent-safety benchmarks, sample-level benchmark composition, failure attribution, financial system validation) is mis-specified — and two more argue that the tool layer, not the model, is where agent safety actually leaks.

## Top picks

**Safety, or Just Capability? A Validity Audit of Agent-Safety Benchmarks** — Youting Wang, Xiao Han, Dingyan Shang, Yuan Tang, Bowen Liu.
_Takeaway:_ Runs R-Judge, InjecAgent, AgentHarm and AgentDojo as measurements to be validated across up to 22 models. On any binary trace-judgment benchmark scored by F1, an "always positive" policy scores 0.690 on R-Judge — above five models that actually discriminate. The three broad benchmarks rank the same 18 models differently, and the apparent capability/safety trade-off is largely a small-panel artifact (ρ = −0.64 at n=7 collapses to +0.02 at n=18).
_Category:_ cs.AI / cs.IR — arXiv:2607.28685. [link](https://arxiv.org/abs/2607.28685)

**Tool Specifications Matter: Uncovering and Mitigating Safety Risks in AI Agents** — Minghui Pan, Jiayuxuan Yang, Yuanyuan Yuan, Yu Jiang, Zhenpeng Chen.
_Takeaway:_ Identifies schema-formatted tool specifications themselves as a primary cause of agent safety degradation — white-box representation analysis shows they weaken the model's internal refusal signals. SafeKeep decouples the two: judge the request against *flattened textual* specs, execute against the original schema. Refusal rate on harmful requests 23.8% → 70.6%; prompt-injection attack success 25.6% → 2.5%, with task capability preserved.
_Category:_ cs.AI — arXiv:2607.29254. [link](https://arxiv.org/abs/2607.29254)

**Data Turnstile: A Scalable Open Framework for Function-Calling Data Generation** — Goutham Ramakrishnan, Megha Sharma.
_Takeaway:_ Open framework that turns user-defined API specs into validated synthetic function-calling data via constrained stepwise generation with error-feedback loops. A Turnstile-tuned Qwen3-0.6B hits 75.9% on BFCL single-turn without chain-of-thought (base with thinking: 67.4%), and on τ²-bench Telecom a 1.7B beats Qwen2.5-32B-Instruct (31.1% vs 27.4% pass^1). Released with 1,000+ APIs and 100K+ multi-turn interactions.
_Category:_ cs.CL — arXiv:2607.29250. [link](https://arxiv.org/abs/2607.29250)

**Model or Harness? An Interaction-Centric Taxonomy for Localizing Agent Failures** — Harsh Raj, Vipul Gupta, Anas Mahmoud, Razvan-Gabriel Dumitru, Darvin Yi, Aakash Sabharwal, Yunzhong He.
_Takeaway:_ Reframes agent failure analysis as a repair-assignment problem: the same visible failure may need post-training, harness engineering, environment redesign, or benchmark repair. 41 failure modes, each assigned to an *edge* between two components plus a fault side. Reproducibility tested with frontier models as judges — best judge reaches Cohen's κ = 0.76 against human labels.
_Category:_ cs.AI — arXiv:2607.28802. [link](https://arxiv.org/abs/2607.28802)

**Zero-Mem: Zero-Token Memory Operations for LLM Agents** — Yilin Xiao, Zhehan Zhu, Yujing Zhang, Jin Chen, Zijin Hong et al.
_Takeaway:_ Asks whether structured agent memory needs generation at all. No step outside final QA invokes an LLM: raw interaction traces are indexed by an entity–context graph plus a temporal hierarchy, weighted per query. Competitive on long-memory and long-context QA while cutting memory-operation time 57.6% versus the fastest baseline.
_Category:_ cs.CL — arXiv:2607.29377. [link](https://arxiv.org/abs/2607.29377)

**Reproducing LightMem: Naive RAG Is Just as Good for Memory Management** — Yongjie Zhou, Shuai Wang, Bevan Koopman, Guido Zuccon (UQ / CSIRO / Google).
_Takeaway:_ Reproduction study with a sharp negative result. Swapping only the retriever over a fixed LightMem store moves answer accuracy from 58.1% to 75.5% — retriever choice dominates the memory architecture. Naive RAG over raw turns generally wins at matched retrieval depth; LightMem only leads under tight token budgets, and oracle evaluation shows memory construction discards answer-relevant information. Read alongside Zero-Mem.
_Category:_ cs.IR — arXiv:2607.29104. [link](https://arxiv.org/abs/2607.29104)

**CAGE: Certified Authorization under Typed-Return Uncertainty for Tool-Using Agents** — Blaise Delattre, Cong Wang, Yang Cao.
_Takeaway:_ Runtime permission gates authorize the observed tool return, leaving the decision unprotected against small errors in how that return was bound to its source. CAGE certifies authorization over a declared neighborhood — one admissible binding fault plus bounded numerical drift — and proves that certifying the categorical and numerical channels *separately does not compose*: perturbations safe on each channel alone can jointly turn an action unsafe.
_Category:_ cs.AI — arXiv:2607.29190. [link](https://arxiv.org/abs/2607.29190)

**MerchantBench: Benchmarking LLM Agents for Long-Term Coherence in E-Commerce Operations** — Qiming Shi, Yulong Tao, Linbo Jin, Zhaolu Kang, Yibo Dou et al.
_Takeaway:_ A 365-day order-level simulation grounded in 98,843 real product records with 26 tools, coupling promptly observable supplier events to delayed order outcomes so agents must revisit earlier decisions. Eight LLMs across two agent frameworks, 48 full-year runs: the best configuration reaches only 27.3% of the mean final net assets achieved by human participants.
_Category:_ cs.AI — arXiv:2607.28956. [link](https://arxiv.org/abs/2607.28956)

**TokTier: Exact Stateful Tokenization for Agentic LLM Serving** — Zhenyu Zhang, Zhichao Cao.
_Takeaway:_ Rare hard data on agent serving economics: across 153,951 calls from two agent ecosystems the median call appends ~1.4K characters, and at a 94.1% prompt-cache hit rate *tokenization* reaches up to 64% of time-to-first-token. TokTier re-tokenizes a window around the append and splices only after a stable-boundary check, guaranteeing byte-identical token IDs — incremental repair in 0.5–1.1 ms from 100K to 3M characters, up to 437× faster than HF tokenization, zero divergence over 1.5×10^10 split checks.
_Category:_ cs.CL — arXiv:2607.29678. [link](https://arxiv.org/abs/2607.29678)

**AISPA: User-Centric System Prompt Auditing for Large Language Model Applications** — Xiangning Lin, Shenzhe Zhu, Shu Yang, Zhenyu Zhang et al. (26 authors, incl. Robert Mahari, Tobin South, Dazza Greenwood).
_Takeaway:_ Audits 3,249 instructions from system prompts across 88 commercial AI products along eight user-facing dimensions, classifying each instruction as protective or problematic. Findings: enormous spread (some orgs average 60+ protective instructions per product, others fewer than 5), and protection is broad but shallow — 98.9% of products have at least one protective instruction, only 24% cover all eight dimensions. Concrete substrate for disclosure-style AI governance.
_Category:_ cs.AI / cs.CY / cs.HC — arXiv:2607.28617. [link](https://arxiv.org/abs/2607.28617)

## Other interesting items

- **[Know It, Act on It: Investigating Memory Utilization in LLM Personalization](https://arxiv.org/abs/2607.29433)** — Zhaoxin Feng, Jianfei Ma, Emmanuele Chersoni — Paired Know/Act tests over 1,000 preferences, 16 systems, five memory architectures: agents routinely recall a stated user preference yet fail to act on it, with the gap worst for health and therapy preferences.
- **[Benchmarks Are Not Validation: A System-Level View of Financial LLM Applications](https://arxiv.org/abs/2607.28840)** — Burak Payzun, İrem Demirtaş, Simona Scala, Elena Ferretti, Seçil Arslan — Position paper from practitioners validating GenAI in financial institutions: benchmark scores are not approval evidence; validation must span data, retrieval, agent behavior, governance and implementation, and produce decision-ready evidence rather than scores.
- **[ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction](https://arxiv.org/abs/2607.29677)** — Boyang Zhang, Adrian Lyjak, Eli Stewart, Zhaoqi Li, Simon Suo — 4,869 pages, 370 enterprise documents, 67 document types; first to score value accuracy, record completeness, grounding *and* measured cost together. Commercial VLMs truncate record lists on long documents; coding agents stay accurate at much higher cost.
- **[Safeguards Based on Copyable Context Cannot Provide Reliable Safety for LLMs](https://arxiv.org/abs/2607.27951)** — Pingyu Wu, Lingyao Zhu, Weiming Zhang, Nenghai Yu — Derives a worst-case floor on attacker assistance whenever the evidence a safeguard relies on is copyable, yielding a safety trilemma: Useful Capability, Reliable Safety and Open Access cannot coexist. Argues for hard-to-copy trusted credentials as a complement.
- **[An Ontology-Guided, Deduplication-Aware Extraction Layer for Knowledge Graph Construction from Heterogeneous Documents](https://arxiv.org/abs/2607.28662)** — Vaibhav Dangaich, Kevin Lewis, Kundeshwar Pundalik — Production KG-build report: the relevant ontology slice is retrieved live by embedding similarity and injected into the extraction prompt (~94% less catalog overhead than static slices); search recall improved from ~70% to 95% with no false merges.
