## Top picks

**Toward Skill-Native LLMs: Skill Entropy for Benchmarking and Training Long-Horizon Reasoning** — Yinghui He, Ling Yang, Jiarui Liu, Yongjin Yang, Lechen Zhang, Yingcheng Wu, Zhenfei Yin, Mengdi Wang, Sanjeev Arora.
_Takeaway:_ Proposes skill entropy as both a benchmark axis and an RL training signal for long-horizon reasoning, i.e. measuring whether a model actually spreads across distinct skills rather than re-running one. Code released. _Category:_ 2608.05139 (cs.CL; cs.LG). https://arxiv.org/abs/2608.05139

**OneDayAgent: Towards a Long-Horizon Harness for Autonomous Agents** — Jingsheng Zheng, Xinyuan Fang, Jintian Zhang, Zhengke Gui, Huajun Chen, Ningyu Zhang.
_Takeaway:_ A harness aimed at a full day of autonomous operation rather than a single task episode — the harness layer, not the model, is where long-horizon agent reliability is being contested right now. _Category:_ 2608.05013 (cs.CL; cs.AI; cs.HC; cs.LG; cs.MA). https://arxiv.org/abs/2608.05013

**Skill-Use: Can LLMs Actually Use Skills in Agentic Harnesses?** — Jinyi Han, Yuanjian Xu, Ying Liao, Xinyi Wang, Zishang Jiang, Zixiang Di, Fanyang Lu, Zhichao Hu, Yanghua Xiao.
_Takeaway:_ Tests whether models can genuinely invoke and compose packaged "skills" inside an agent harness, which is the empirical question sitting underneath every skills/tool-registry product decision. _Category:_ 2608.04828 (cs.CL). https://arxiv.org/abs/2608.04828

**InsightEmb: Learning Action-Intent Embeddings for Agentic Insight Retrieval** — Tsz Ting Chung, Jiangnan Li, Jie Zhou, Mo Yu.
_Takeaway:_ Trains embeddings on action intent rather than surface text so an agent retrieves what it needs to *do* next, not merely what is lexically similar — a concrete retrieval-side answer to agentic RAG drift. _Category:_ 2608.04761 (cs.CL; cs.AI). https://arxiv.org/abs/2608.04761

**DelusionEval: Measuring Delusion-Linked Behaviors in AI Chatbots** — Jared Moore, Andrea Mock, Yifan Mai, Jacy Reese Anthis, Ryan Louie, William Agnew, Ashish Mehta, Kevin Klyman, Percy Liang, Nick Haber, Eric Lin, Desmond C. Ong.
_Takeaway:_ A HELM-adjacent Stanford eval for whether chatbots reinforce delusional user beliefs — the first properly instrumented benchmark for a failure mode that has been driving product-safety headlines all year. _Category:_ 2608.05004 (cs.CL). https://arxiv.org/abs/2608.05004

**Does Out-of-Sight Equal Out-of-Mind in CoT Monitorability?** — Pedro Ferreira, Wilker Aziz, Ivan Titov.
_Takeaway:_ Probes whether reasoning that disappears from the visible chain-of-thought is actually absent from the computation, which is the load-bearing assumption behind every CoT-monitoring safety proposal. _Category:_ 2608.04928 (cs.CL). https://arxiv.org/abs/2608.04928

**Resourced Authority: A Mechanism-Design Model for Participatory Governance of Deployed AI Agents** — Praphul Chandra, Sujit Gujar, Ganesh Ghalme.
_Takeaway:_ Treats governance of deployed agents as a mechanism-design problem where authority comes with resources, rather than as a policy document — a rare formal treatment of who can actually constrain a running agent. _Category:_ 2608.06353 (cs.GT; cs.AI; cs.MA). https://arxiv.org/abs/2608.06353

**ASGE-RR: Agentic Service Graph Embedding with Revisable Reservations for Dynamic AI-Agent Calls** — Trond Vatten, Yuming Jiang.
_Takeaway:_ Models inter-agent service calls as a graph with revisable capacity reservations — an interoperability/runtime primitive that MCP- and A2A-style protocols specify the wire format for but leave scheduling undefined. _Category:_ 2608.06033 (cs.MA; cs.PF). https://arxiv.org/abs/2608.06033

**EuroExec: Frontier Language Models Fall Short of Expert Judgment on European Executive Decision Tasks** — Pau Arnal, Khaled Denfir, Danylo Smahliuk, Amrut Avhad, Marcus A. Castro.
_Takeaway:_ Frontier models underperform human experts on European executive decision tasks, a non-US-centric capability eval worth having on hand before quoting generic "expert-level" claims in a European enterprise context. _Category:_ 2608.04549 (cs.CL; cs.AI; cs.LG). https://arxiv.org/abs/2608.04549

## Other interesting items

- **[A Two-Tier Perspective on Inference-Time Parallelism in Multi-Agent LLM Systems](https://arxiv.org/abs/2608.05791)** — Zihan Xu, Haolin Tian, Hai Jiang (ICML 2026) — separates intra-agent from inter-agent parallelism, giving a cleaner cost model for orchestration design.
- **[AV-AIVAT: 74x Cheaper Agent Evaluation with Certified Anytime-Valid Stopping in Imperfect-Information Games](https://arxiv.org/abs/2608.06362)** — Boning Li, Yu Chen, Longbo Huang — anytime-valid stopping cuts agent-eval cost by ~74x while keeping statistical guarantees.
- **[Caching for the Future: Scrub Jay Episodic Memory Principles for Agent Memory Systems](https://arxiv.org/abs/2608.04746)** — Kartikey Singh Bhandari, Aarya Wadhwani, Dhruv Kumar, Pratik Narang — borrows food-caching bird cognition to decide what an agent should store and when to expire it.
- **[State2State: Environment-Derived Mid-Training for LLM Agents](https://arxiv.org/abs/2608.04934)** — Xuanyu Lei, Yiqi Zhu, Chenliang Li, Kaiming Liu, Peng Li, Ming Yan, Jieping Ye, Ya-Qin Zhang, Yang Liu — mid-training on environment-derived state transitions instead of scraped trajectories.
- **[Spoken Function Calling: A New Perspective on Spoken Language Understanding for Large Audio Language Models](https://arxiv.org/abs/2608.05126)** — Yuezhang Peng, Yuxin Liu, Changfeng Gao, Zhifu Gao, Xiangang Li, Xie Chen (ACM MM 2026) — reframes spoken-language understanding as function calling, pushing tool-use schemas into the audio stack.
- **[Responsibility in Multi-Agent Sequential Decision-Making: Comparing Human Judgments to Formal Models of Causal Attribution](https://arxiv.org/abs/2608.04318)** — Nripsuta Ani Saxena, Stelios Triantafyllou, Goran Radanović — where formal causal-attribution models diverge from human blame judgments in multi-agent settings; directly relevant to agent accountability regimes.
