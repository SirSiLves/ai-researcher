## Top picks

**An Actionable Diagnosis of Multilingual, Multi-Agent Planning Failures** — Vikas Pahuja, Jonathan Brokman, Omer Hofman, Tamir Nizri, Daniel Vishna, Seraphina Goldfarb-Tarrant, Kelly Marchisio, Hisashi Kojima, Roman Vainshtein.
_Takeaway:_ Breaks multi-agent planning failures down by language, showing that non-English orchestration degrades in ways the usual English-only agent benchmarks never surface — a concrete blind spot for anyone deploying agents outside en-US. _Category:_ 2608.03735 (cs.MA; cs.CL). https://arxiv.org/abs/2608.03735

**Stateful Governance for Concurrent Agentic Systems** — Yuxiang Peng, Xiaodi Wu.
_Takeaway:_ Treats governance of concurrently running agents as a stateful, database-flavoured problem rather than a per-call policy check — the runtime/composition primitive that MCP- and A2A-style protocols currently leave undefined. _Category:_ 2608.02764 (cs.MA; cs.DB). https://arxiv.org/abs/2608.02764

**Emergence of Biased Consensus in Multi-Agent LLM Debates** — Maya Okawa (ICML 2026).
_Takeaway:_ Multi-agent debate, widely sold as a self-correction mechanism, is shown to converge on systematically biased consensus — directly relevant if you use debate or majority-vote ensembles as an eval or safety layer. _Category:_ 2608.02827 (cs.MA). https://arxiv.org/abs/2608.02827

**MemArena: An Ego-Centric Benchmark for On-Device Agentic Personal Memory Assistants at Scale** — Jiadong Zhang, Xiaosong Ma.
_Takeaway:_ A large ego-centric benchmark for personal-memory agents running on-device, filling the gap between toy long-context tests and what a real assistant has to remember across months. _Category:_ 2608.02613 (cs.CL; cs.AI; cs.LG; cs.MA). https://arxiv.org/abs/2608.02613

**Magnet: Detecting Cross-Session AI Misuse Through Capability Accumulation** — Natalie Isak, Matthew Dressman.
_Takeaway:_ Misuse detection that reasons over capability accumulated across sessions rather than per-prompt — the right threat model for persistent-memory assistants, and a governance control that per-request filters structurally cannot provide. _Category:_ 2608.02518 (cs.AI; cs.CY). https://arxiv.org/abs/2608.02518

**Right Answer, Wrong Method: Shortcut Hacking Misleads the Evaluation of LLM Reasoning on Frontier Science Benchmarks** — Xuan Ren, Weiqi Zhai, Tianle Pu, Yihua Zhu, Hu Wei, Bing Zhao.
_Takeaway:_ Frontier science benchmarks are being passed via shortcuts rather than reasoning, so headline scores overstate capability — read this before quoting any frontier-science eval number. _Category:_ 2608.02442 (cs.AI; cs.CL). https://arxiv.org/abs/2608.02442

**HALT: Verification-Aware Stopping for Retrieval-Augmented Search Agents** — Daeyoung Roh, Donghee Han.
_Takeaway:_ Makes the stopping decision in agentic RAG verification-aware instead of budget- or confidence-based, cutting both premature answers and runaway retrieval loops. Code released. _Category:_ 2608.02009 (cs.AI). https://arxiv.org/abs/2608.02009

**Adversarial Fast-Moving Real-World Domains as Test Beds for Benchmarking AI Scientist Capabilities** — William Bolton, Philip Torr (AI for Science workshop, ICML 2026).
_Takeaway:_ Proposes benchmarking "AI scientist" agents on adversarial, fast-moving real domains where the answer key keeps changing — a contamination-resistant alternative to static research benchmarks. _Category:_ 2608.03569 (cs.AI; cs.CY; cs.LG; cs.MA). https://arxiv.org/abs/2608.03569

## Other interesting items

- **[When Truth Is Distributed: Misinformation Derails Collective Fact Recovery in LLM-Based Multi-Agent Systems](https://arxiv.org/abs/2608.03421)** — Chenfei Yan, Zeyang Yue, Feifei Zhao, Erliang Lin, Lu Jia, Haibo Tong, Mingyang Lyu, Chengyi Sun, Yi Zeng — when evidence is split across agents, a small amount of injected misinformation collapses collective fact recovery.
- **[Before Reasoning Fails: Pre-Evidence Procedural Failures in Agentic RAG](https://arxiv.org/abs/2608.02011)** — Daeyoung Roh, Donghee Han — most agentic-RAG errors happen before any evidence is even retrieved, which reframes where to spend debugging effort.
- **[MemArbiter: Decision-Time Memory Arbitration for Long-Horizon LLM Agents](https://arxiv.org/abs/2608.02113)** — Jiajun Dong, Yutao Hu, Fengrui Fan, Shihan Dou, Yueming Wu, Deqing Zou — arbitrates which memories to admit at decision time rather than at write time.
- **[SkillTrace: Traversing a Query-Skill Graph for Composable LLM Agents](https://arxiv.org/abs/2608.02356)** — Yue Yao, Shengyuan Wang, Xin Chen, Minke Zhang, Jia He, Bingjun Luo, Tom Gedeon — routes queries over an explicit skill graph, an interoperability-flavoured take on agent composition.
- **[Structured Memory for Edge Language Models: Persistent Context and Corpus Retrieval via O(1) SSM State Injection](https://arxiv.org/abs/2608.02560)** — Anusha Madan Gopal, Aras Pirbadian, Kristofor D. Carlson, M Anthony Lewis, Jonathan Tapson — constant-time state injection as an alternative to context stuffing for edge retrieval.
- **[Internalising the Identity Primitive: Cryptographic Individuality for an Autonomous Agent on a Public Blockchain](https://arxiv.org/abs/2608.02986)** — Keisuke Suzuki — binds agent identity to model weights cryptographically; an unusual but concrete answer to "who is this agent" in open agent networks.
