## Top picks

**Co-Evolution in Agentic Systems: Toward Self-Directed Evolution Beyond Human Design** — Qing Zong, Jiayu Liu, Junhao Shen, Zecong Tang, Linsi Wu, Yuxuan Liu, Rui Wang, Zhaowei Wang, Weiqi Wang, Cheng Qian, Xiusi Chen, Yangqiu Song (HKUST et al.). _Takeaway:_ **#1 HF paper of the day.** Survey — but earns its place: argues single-agent self-evolution is capped by a static learning context, and proposes a three-stage taxonomy (Agent–Agent → Agent–Environment → Meta Co-Evolution) tracing how a system progressively sheds human-engineered constraints, ending with the evolution mechanism itself becoming evolvable. Explicitly flags evaluation, multi-component scaling, and keeping autonomous evolution controllable as open problems. _Category:_ arXiv 2608.10299. [link](https://huggingface.co/papers/2608.10299) · [repo](https://github.com/zongqing0068/awesome-co-evolution)

**ComBodied Agents: a New Paradigm of Human-Centric Agentic AI** — Qianggang Ding, Xingyao Wang, Rui Feng, Zhibin Wang, Kelong Mao, Hao Sun, Lei Li, Minheng Ni, Zhenghua Chen, Min Wu, Jun Cheng, Huazhu Fu, Dacheng Tao, Bang Liu + 8 more (22 authors). _Takeaway:_ Argues digital agents transform software state and embodied agents transform physical state, but neither models *the person's* evolving state — proposes a closed loop of event-based multimodal perception, longitudinal correctable memory, "Personal World Models" that forecast user state under alternative interventions, and an admissible-intervention policy gated on consent, uncertainty, reversibility and user control. Notably rejects the exhaustive "Human Digital Twin" in favour of purpose-bounded, user-correctable representations, and proposes agency-preservation metrics — a genuinely governance-aware agent architecture. _Category:_ arXiv 2608.10915. [link](https://huggingface.co/papers/2608.10915)

**MAP-Graph: Provenance-Aware Shared Memory for Multi-Agent Workflows** — Yiqi Wang, Zihao Yan, Jiaqi Zhang, Zhangkai Wu, Mingkai Zheng, Zequn Sun, Yanming Zhu, Taotao Cai. _Takeaway:_ **Pick of the day for enterprise agent platforms.** Core insight: in shared agent memory, access restrictions propagate through derivations — a summary can silently launder a private, poisoned, untrusted or revoked source into an agent that was never allowed to read it. MAP-Graph is a typed execution graph over agents/sources/memories/claims/actions that (1) hard-excludes permission-ineligible records, (2) reranks the rest by semantic similarity × multiplicative path trust, and (3) applies a risk-sensitive gate before action execution while retaining lineage for audit. 94.96% task success and 72.70% exact decision accuracy over 2,700 synthetic tasks across three domains; advantages hold across two other backbones. The argument that matters: **provenance as an operational control signal, not just post-hoc audit metadata.** _Category:_ arXiv 2608.10509 (cs.AI, cross-list cs.MA). [link](https://arxiv.org/abs/2608.10509)

**SkillZip: Evaluation-Free Skill Compression for Self-Evolving Agents by Discovering Reusable Structure** — Xiaofan Bai, Hongqiang Lin, Chao Liu, Yantao Zhang, Xuan Jin, Xipeng Cao, Yuhong Li. _Takeaway:_ Self-evolving agents bloat their skill files by appending fixes until the same rule is restated across branches, examples and warnings. Generic prompt compression fails here because a skill is not flat prose — name/description gate *when* it applies, workflow controls execution, tool and output contracts constrain validity, and rare exceptions stay essential even if no sampled task triggers them. SkillZip instead solves a typed minimum-description-length objective ("explain once, reference many") under a hard coverage constraint on every trigger, workflow edge, tool requirement and output field — so rare rules survive by construction and no evaluation rollouts are needed. Ships a continual **Zip-on-Write** mode that folds each self-evolution patch in without replaying tasks or reparsing history. _Category:_ arXiv 2608.11079. [link](https://huggingface.co/papers/2608.11079)

**ASCon: A Direction-Aware Reciprocal Agent–Step Contextualization Model for Failure Attribution in Multi-Agent Systems** — Shuyu Jiang, Yue Ran, Kaiyu Xu, Xingshu Chen, Yi Zhang, Hao Ren, Rui Tang, Tianwei Zhang. _Takeaway:_ Attributes multi-agent run failures to the specific agent and step responsible — the eval/observability primitive most agent stacks still lack. _Category:_ arXiv 2608.10646 (cs.MA). [link](https://arxiv.org/abs/2608.10646)

**Mendel Gödel Machine: Recursive Self-Improving Coding Agents via Comparative Evolution** — Ludwig Maximilian University of Munich (HF submitter: RealLiu). _Takeaway:_ Self-improving coding agent that uses comparative evolution between candidate agent variants rather than a single self-modification chain. _Category:_ arXiv 2608.07645. [link](https://huggingface.co/papers/2608.07645)

**DSAgentBench: Can Agents Automate End-to-End Data-Science Workflows in Real Computer Environments?** — 6 authors (HF submitter: taesiri). _Takeaway:_ Benchmark for full data-science workflows executed in real computer environments, not sandboxed notebook snippets — a harder bar for enterprise agent claims. _Category:_ arXiv 2608.10366. [link](https://huggingface.co/papers/2608.10366)

**DistilVDR: A Compact End-to-End Visual Document Retriever via Dual-Student Distillation** — NanoVDR (HF submitter: Ryenhails). _Takeaway:_ Distills visual-document retrieval into a compact end-to-end model via two student networks — relevant to anyone running ColPali-style retrieval at cost. _Category:_ arXiv 2608.10636. [link](https://huggingface.co/papers/2608.10636)

**Not a Monolith: Lab-Level Divergence in the Cooperative Equilibria of Chinese Frontier LLM Agents** — Francisco León Zúñiga Bolívar (Institución Universitaria Colegio Mayor del Cauca). _Takeaway:_ Compares cooperative-game equilibria across Chinese frontier labs' models and finds lab-level divergence rather than a uniform national behaviour profile — useful counter-evidence for model-provenance risk arguments. _Category:_ arXiv 2608.10262 (cs.MA). [link](https://arxiv.org/abs/2608.10262)

**The Deliberative Deficit: An Empirical Critique of LLMs in Democratic Discourse** — Maurice Flechtner. _Takeaway:_ AIES 2026 archival paper arguing empirically that LLMs underperform as deliberative participants in democratic discourse; a governance-side counterweight to "AI for civic engagement" pitches. _Category:_ arXiv 2608.10186 (cs.MA, cs.AI, cs.CY). [link](https://arxiv.org/abs/2608.10186)
