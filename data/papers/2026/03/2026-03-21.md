## Top picks

- **Retrieval-Augmented LLM Agents: Learning to Learn from Experience** — Thomas Palmeira Ferraz, Romain Deffayet. _Takeaway:_ Combines fine-tuning with episodic experience retrieval so LLM agents generalize to unfamiliar tasks by reusing past trajectories. Concrete pattern for the `agent-memory` and `experience-retrieval` directions. _Category:_ arXiv:2603.18272. [https://arxiv.org/abs/2603.18272](https://arxiv.org/abs/2603.18272)
- **Toward Reliable, Safe, and Secure LLMs for Scientific Applications** — Saket Sanjeev Chaturvedi, Joshua Bergerson. _Takeaway:_ Multilayered defense framework for autonomous LLM agents in scientific research — threat taxonomy, adversarial benchmarks, and proactive internal safeguards. Direct input to the agent-safety governance debate. _Category:_ arXiv:2603.18235. [https://arxiv.org/abs/2603.18235](https://arxiv.org/abs/2603.18235)
- **AC4A: Access Control for Agents** — Reshabh K Sharma, Dan Grossman. _Takeaway:_ Granular permission framework so LLM agents access only the APIs and web content they need — moves beyond today's all-or-nothing access model and gives an enforceable surface for agent governance. _Category:_ arXiv:2603.20933. [https://arxiv.org/abs/2603.20933](https://arxiv.org/abs/2603.20933)
- **Governing Evolving Memory in LLM Agents (SSGM)** — Chingkwun Lam, Jiaxin Li. _Takeaway:_ SSGM combines consistency verification, temporal decay modeling, and dynamic access control to prevent memory corruption in long-running LLM agent systems. Pairs naturally with the "agents that forget on purpose" line. _Category:_ arXiv:2603.11768. [https://arxiv.org/abs/2603.11768](https://arxiv.org/abs/2603.11768)
- **The Attack and Defense Landscape of Agentic AI: A Comprehensive Survey** — Juhee Kim, Xiaoyuan Liu. _Takeaway:_ Systematically maps attack vectors and defense strategies across LLM-plus-tool agent stacks. Useful as a structured threat-model reference for any team productionizing agents. _Category:_ arXiv:2603.11088. [https://arxiv.org/abs/2603.11088](https://arxiv.org/abs/2603.11088)
- **Security Considerations for Multi-agent Systems** — Tam Nguyen, Moses Ndebugre. _Takeaway:_ Existing AI security frameworks critically miss multi-agent failure modes — non-determinism (mean score 1.231) and inter-agent data leakage are the two most-neglected domains. Argues for MAS-specific controls before A2A scales. _Category:_ arXiv:2603.09002. [https://arxiv.org/abs/2603.09002](https://arxiv.org/abs/2603.09002)

## Other interesting items

- **[Sell Me This Stock: Unsafe Recommendation Drift in LLM Agents](https://arxiv.org/abs/2603.12564)** — Wu, Koshiyama. Stronger models exhibit *worse* tool-data manipulation susceptibility — counter-intuitive safety result that complicates "bigger = safer."
- **[Bridging Protocol and Production: Design Patterns for Deploying AI Agents with MCP](https://arxiv.org/abs/2603.13417)** — Srinivasan. MCP production gaps (identity, tool budgeting, error handling) and infra-level fixes; baseline reading for any team building MCP-grade agent platforms.
