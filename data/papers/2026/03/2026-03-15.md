## Top picks

- **Bridging Protocol and Production: Design Patterns for Deploying AI Agents with Model Context Protocol** — Vasundra Srinivasan. _Takeaway:_ Names three production-deployment gaps in MCP (identity propagation, tool budgeting, error handling) and proposes infrastructure-level patterns to close each. One of the first peer-style papers to treat MCP as a real production protocol rather than a demo surface — pairs with the `mcp-adoption` and `agent-identity` radar threads. _Category:_ arXiv:2603.13417. [https://arxiv.org/abs/2603.13417](https://arxiv.org/abs/2603.13417)
- **Sell Me This Stock: Unsafe Recommendation Drift in LLM Agents** — Zekun Wu, Adriano Koshiyama. _Takeaway:_ LLM recommendation agents faithfully execute manipulated tool data without questioning it; counter-intuitively, stronger models show worse safety violations despite higher quality scores. _Category:_ arXiv:2603.12564. [https://arxiv.org/abs/2603.12564](https://arxiv.org/abs/2603.12564)
- **Strategic Navigation or Stochastic Search? How Agents and Humans Reason Over Document Collections** — Łukasz Borchmann, Jordy Van Landeghem. _Takeaway:_ Multimodal agents match human accuracy on document search but rely on brute-force compensation for weak strategic planning — direct relevance to RAG vs agentic-retrieval debate. _Category:_ arXiv:2603.12180. [https://arxiv.org/abs/2603.12180](https://arxiv.org/abs/2603.12180)
- **Meta-Reinforcement Learning with Self-Reflection for Agentic Search** — Teng Xiao, Yige Yuan. _Takeaway:_ MR-Search lets a search agent learn from cross-episode self-reflection rather than within-episode optimization; concrete agent-memory pattern. _Category:_ arXiv:2603.11327. [https://arxiv.org/abs/2603.11327](https://arxiv.org/abs/2603.11327)
- **DIVE: Scaling Diversity in Agentic Task Synthesis for Generalizable Tool Use** — Aili Chen, Chi Zhang. _Takeaway:_ Training-data diversity beats raw quantity for OOD generalization in tool-using LLMs — argument-grade evidence for the "synth-data quality, not size" thesis. _Category:_ arXiv:2603.11076. [https://arxiv.org/abs/2603.11076](https://arxiv.org/abs/2603.11076)
- **IndexCache: Accelerating Sparse Attention via Cross-Layer Index Reuse** — Yushi Bai, Qian Dong. _Takeaway:_ Reuses top-k token selections across transformer layers to cut sparse-attention indexer compute by ~75%; relevant to long-context inference economics. _Category:_ arXiv:2603.12201. [https://arxiv.org/abs/2603.12201](https://arxiv.org/abs/2603.12201)
