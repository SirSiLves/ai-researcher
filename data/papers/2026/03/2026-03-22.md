## Top picks

- **Memento-Skills: Let Agents Design Agents** — Huichi Zhou, Siyuan Guo. _Takeaway:_ Agent-design-by-agent loop in which a meta-agent grows a skill library and stateful prompt scaffold without any LLM parameter updates. A concrete instantiation of the "agents that build their own subagents" pattern; pairs with the `agent-self-improvement` and `agent-memory` radar threads. _Category:_ arXiv:2603.18743. [https://arxiv.org/abs/2603.18743](https://arxiv.org/abs/2603.18743)
- **AndroTMem: From Interaction Trajectories to Anchored Memory in Long-Horizon GUI Agents** — Yibo Shi, Jungang Li. _Takeaway:_ Anchored State Memory represents long Android-GUI trajectories as causally linked intermediate-state anchors instead of full replays or summaries, yielding 5–30% gains on long-horizon tasks. Direct evidence on what memory granularity actually helps CUA-style agents. _Category:_ arXiv:2603.18429. [https://arxiv.org/abs/2603.18429](https://arxiv.org/abs/2603.18429)
- **VTC-Bench: Evaluating Agentic Multimodal Models via Compositional Visual Tool Chaining** — Xuanyu Zhu, Yuhao Dong. _Takeaway:_ 32 OpenCV-based visual tools and 680 problems engineered to make multimodal agents *compose* multiple tools rather than answer with a single call. Reveals that even leading multimodal models still fail at multi-step planning across tool boundaries — sharp eval signal for the agentic-multimodal track. _Category:_ arXiv:2603.15030. [https://arxiv.org/abs/2603.15030](https://arxiv.org/abs/2603.15030)
- **ProRL Agent: Rollout-as-a-Service for RL Training of Multi-Turn LLM Agents** — Hao Zhang, Mingjie Liu. _Takeaway:_ Decouples rollout generation from RL training by exposing the agentic rollout lifecycle through an API service, so trainers and environments can scale and migrate independently. Concrete infrastructure pattern for shops trying to operationalize multi-turn agent RL beyond hand-rolled scripts. _Category:_ arXiv:2603.18815. [https://arxiv.org/abs/2603.18815](https://arxiv.org/abs/2603.18815)
- **CUBE: A Standard for Unifying Agent Benchmarks** — Alexandre Lacoste, Nicolas Gontier. _Takeaway:_ Proposes a universal protocol so any compliant agent benchmark plugs into any compliant runtime — built on MCP's non-blocking `tools/call` API. If adopted, it removes the per-benchmark integration tax that currently makes cross-benchmark comparison so painful. _Category:_ arXiv:2603.15798. [https://arxiv.org/abs/2603.15798](https://arxiv.org/abs/2603.15798)
- **Nemotron-Cascade 2: Post-Training LLMs with Cascade RL and Multi-Domain On-Policy Distillation** — Zhuolin Yang, Zihan Liu. _Takeaway:_ Extends cascade RL across broader domains and adds multi-domain on-policy distillation to recover the cross-domain regressions cascade RL usually causes; a 30B MoE reaches competition-level math/code reasoning. Useful concrete recipe for the post-training stack. _Category:_ arXiv:2603.19220. [https://arxiv.org/abs/2603.19220](https://arxiv.org/abs/2603.19220)

## Other interesting items

- **[Reasoning over mathematical objects: on-policy reward modeling and test time aggregation](https://arxiv.org/abs/2603.18886)** — Aggarwal, Ghazvininejad. On-policy judge training plus test-time aggregation pushes models past numeric answers toward formal mathematical expressions; a tighter reward-modeling loop for symbolic reasoning.
- **[What Really Controls Temporal Reasoning in LLMs: Tokenisation or Representation of Time?](https://arxiv.org/abs/2603.19017)** — Bhatia, Isa. Tokenisation fragmentation dominates temporal-reasoning failures in low-resource languages; representation effects matter more in high-resource ones — useful diagnostic before blaming "the reasoning chain."
- **[Tinted Frames: Question Framing Blinds Vision-Language Models](https://arxiv.org/abs/2603.19203)** — Fan, Luo. VLMs selectively reduce visual attention based on question format (MCQ vs open-ended); proposes a learnable-token prompt-tuning fix. Direct robustness signal for any VLM-grounded agent stack.
- **[LVOmniBench: Pioneering Long Audio-Video Understanding Evaluation for Omnimodal LLMs](https://arxiv.org/abs/2603.19217)** — Tao, Zheng. First long-form (10–90 min) omnimodal benchmark; current models struggle hard, providing a clear gap for the long-context multimodal track.
