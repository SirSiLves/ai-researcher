**Deploy Your First MCP Server This Week: A Practical Guide for Technology Leaders** — Venkat Y. (CTO, Monotype), 2026-08-02.
The MCP spec revision dated 2026-07-28 makes the protocol stateless at the transport layer — no handshake, no session header. Author's argument: this demotes an MCP server from special infrastructure needing sticky sessions to an ordinary HTTP workload behind a standard load balancer, gateway and WAF.
_Why interesting:_ Concrete, dated protocol change with a direct operational consequence for enterprise rollout — the single most actionable MCP item this week.
