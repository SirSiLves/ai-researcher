## The month in 90 seconds

**March was the month the harness became the product — and then the reference harness leaked.**

The field's centre of gravity moved twice in March. GTC reset the unit-economics conversation away from frontier benchmarks; Anthropic's harness post a week later named the architecture the rest of the industry now competes on; and five days after that, Anthropic's own coding-agent harness shipped to npm with a missing `.npmignore` and a 59.8MB source map containing it. The month that opened on inference-cost compression closed on a public reference implementation of how a frontier lab builds an agent.

GTC 2026 (Mar 16) was the structural anchor. Vera Rubin's Rubin R100 and 88-core Vera CPU claim roughly five times Blackwell inference at about ten times lower cost per token; Groq 3 LPU shipped as the first chip from the late-2025 acquisition; the Agent Toolkit launched with seventeen enterprise anchors (Adobe, Salesforce, SAP, ServiceNow, Siemens, CrowdStrike, Atlassian, Cadence, Synopsys, IQVIA, Palantir, Box, Cohesity, Dassault, Red Hat, Cisco, Amdocs) and a roughly $1T Blackwell-plus-Rubin order book through 2027. Inside the next two weeks twelve frontier-model launches landed against that economic floor: GPT-5.4 mini and nano (nano at $0.20 / $1.25 per million tokens, Willison's "76,000 photos for $52" benchmark went everywhere), Mistral Small 4 and Leanstral, Grok 4.20 with real-time web access, Mistral Voxtral TTS at roughly ten times under ElevenLabs, Liquid LFM2.5-350M as a sub-1B agent specialist, and on March 30 Qwen3.5-Omni's pivot to closed weights breaking Alibaba's open-source streak. Capacity, not capability, became the binding constraint visible to users.

The harness story is the month's defining inflection. Anthropic engineer Prithvi Rajasekaran's March 23 "Harness design for long-running application development" post formalised the planner / generator / evaluator decomposition. Within 96 hours the vocabulary was running through Cursor, Cognition, Replit and Friday's TLDR Dev roundup. Cursor 3 "Glass" (Apr 2) shipped the leaked vocabulary as a product launch. The Meta-Harness paper, which treats the harness itself as a searchable object rewritten from execution traces, landed the same day the Claude Code v2.1.88 source map leaked — exposing the "BUDDY" Tamagotchi-companion and user-frustration-detection layers across roughly 513,000 lines of TypeScript. A clean-room fork hit 50,000 GitHub stars in two hours; Anthropic's DMCA wave hit roughly 8,100 repos before Boris Cherny narrowed it. It was the second Anthropic packaging incident in five days — Fortune's March 26 disclosure of the Mythos / Capybara CMS leak (about 3,000 unpublished assets, a draft blog naming a "step change" model "above Opus" with "unprecedented cybersecurity risks" framing) had already moved listed cybersecurity stocks intraday.

The infrastructure layer caught up at scale, then revealed its security floor. Anthropic disclosed MCP at 97M monthly SDK installs on March 25, against roughly two million at the November 2024 launch — the order-of-magnitude shift that anchors every enterprise MCP-server pitch landing through Q2. The same week Sunil Prakash's AIP paper scanned roughly 2,000 MCP servers and found zero with authentication; LiteLLM 1.82.7 / 1.82.8 shipped a base64 credential stealer in a `.pth` file with 46,996 downloads in 46 minutes; ServiceNow AI Gateway shipped MCP-registry imports with per-server PII detection. By April 1, Nicholas Carlini's MAD Bugs campaign had produced a working FreeBSD remote kernel RCE (CVE-2026-4747) in roughly four hours on the publicly available Claude harness, then 500-plus validated high-severity CVEs by April 4 and around 1,000 by April 5. Greg Kroah-Hartman, Daniel Stenberg and Willy Tarreau independently confirmed the Linux kernel security list had flipped from two or three slop reports a week to five or ten real AI-assisted reports a day inside a month.

Capital and workforce reallocation became co-equal storylines. OpenAI closed the largest private round in history at $852B post-money on March 31 with revolver expanding to roughly $4.7B across eleven banks; Anthropic crossed $30B ARR run-rate on April 1, up from $14B in February and $19B in March; Atlassian cut 1,600 staff (10%) on March 24 with explicit AI-development-plus-enterprise-sales framing — the template Cloudflare copied six weeks later. OpenAI retired Sora on cost grounds (about $1M/day compute against fewer than 500K actives) as the first frontier-lab consumer-product retirement on unit economics. Heading into April, the agent control plane became a procurement category with four lanes already named: data platform (Snowflake), workflow SaaS (ServiceNow), developer surface (Slack-as-agent-OS, shipped March 31), and runtime governance (Microsoft Agent Framework, GA April 3). Every multi-vendor enterprise now picks a governance lane before model selection.

**Read this first:** [Meta-Harness: End-to-End Optimization of Model Harnesses](https://arxiv.org/abs/2603.28052) — the paper that treats the harness as a searchable object, landing the same day the Claude Code harness leaked. If you only open one item from March, the through-line of the month sits at this intersection.

**The agent control plane becomes a Q2 procurement category** — What started as GTC's "Agent Toolkit + 17 partners" substrate (Mar 16) hardened across four lanes inside two weeks: data platform (Snowflake Project SnowWork preview + Cortex Code GA + AWS Glue/Databricks/Postgres connectors, Mar 18), workflow SaaS (ServiceNow AI Gateway MCP-registry + CIMD + per-server PII detection, Mar 19 → Action Fabric, Apr 2), developer surface (Slack as agentic OS with 30+ Salesforce Slackbot AI features + Slack MCP GA, Mar 31; OpenAI Workspace Agents same day; Cursor 3 "Glass" Agents Window Apr 2), and runtime/governance (Microsoft Agent Framework 1.0 + Agent Governance Toolkit at p99<0.1ms + Copilot Studio multi-agent A2A GA, Apr 3). SAP API Policy v4/2026 §2.2.2 banning external agents from autonomous API calls became the cleanest live test of walled-garden vs. MCP-everywhere. _Why it matters:_ Every multi-vendor enterprise now has to pick a governance lane for agents before model selection.

## Research highlights

- **Bridging Protocol and Production: Design Patterns for Deploying AI Agents with MCP** (Srinivasan, [arXiv:2603.13417](https://arxiv.org/abs/2603.13417)) — First peer-style paper treating MCP as a real production protocol; identity propagation, tool budgeting, error handling as the three deployment gaps.
- **CUBE: A Standard for Unifying Agent Benchmarks** (Lacoste, Gontier, [arXiv:2603.15798](https://arxiv.org/abs/2603.15798)) — Universal benchmark protocol built on MCP `tools/call`; removes the per-benchmark integration tax.
- **AIP: Agent Identity Protocol for Verifiable Delegation Across MCP and A2A** (Prakash, [arXiv:2603.24775](https://arxiv.org/abs/2603.24775)) — Invocation-Bound Capability Tokens (JWT + chained Biscuit); ~2,000-server scan finds zero authenticated MCP endpoints.
- **AgentRFC: Security Design Principles and Conformance Testing for Agent Protocols** (Zheng, Zhang, [arXiv:2603.23801](https://arxiv.org/abs/2603.23801)) — First systematic security framework for MCP/A2A/ANP/ACP with formal architectural model.
- **AC4A: Access Control for Agents** (Sharma, Grossman, [arXiv:2603.20933](https://arxiv.org/abs/2603.20933)) — Granular per-API/per-content permission framework replacing all-or-nothing access.
- **FinMCP-Bench: Benchmarking LLM Agents for Real-World Financial Tool Use under MCP** (Zhu, Tian, [arXiv:2603.24943](https://arxiv.org/abs/2603.24943)) — 613 samples × 33 financial scenarios × 65 real MCP servers; first finance-vertical eval built around MCP.
- **SlopCodeBench: How Coding Agents Degrade Over Long-Horizon Iterative Tasks** (Orlanski, Roy, [arXiv:2603.24755](https://arxiv.org/abs/2603.24755)) — First benchmark explicitly measuring agent-driven code-quality erosion across sequential extensions; pairs with the same-week Claude Code caching regression.
- **AVO: Agentic Variation Operators for Autonomous Evolutionary Search** (Chen et al., [arXiv:2603.24517](https://arxiv.org/abs/2603.24517)) — Discovered attention kernels outperforming cuDNN and FlashAttention; agentic search beats expert-engineered systems code.
- **Meta-Harness: End-to-End Optimization of Model Harnesses** (anon, [arXiv:2603.28052](https://arxiv.org/abs/2603.28052)) — Treats the harness (context manager / retriever / proposer / scheduler) as a searchable object rewritten from execution traces; ships the day Claude Code's harness leaks.
- **Mind the Gap: How the Technical Mechanisms of Agentic AI Outpace Global Legal Frameworks** (Osmond, Jego, [arXiv:2603.27075](https://arxiv.org/abs/2603.27075)) — Statutes conflate model capability with system architecture and miss the actual control points.
