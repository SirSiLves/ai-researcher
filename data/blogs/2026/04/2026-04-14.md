## Long-form picks

- **Cybersecurity Looks Like Proof of Work Now** — Drew Breunig, via Simon Willison. _Takeaway:_ UK AISI's evaluation of Claude Mythos Preview shows more tokens spent = more exploits found, which Breunig argues collapses security into a brutally simple equation: harden a system by spending more tokens than your attackers will. Strong corollary: open-source libraries get _more_ valuable because review tokens amortize across all users. [https://simonwillison.net/2026/Apr/14/cybersecurity-proof-of-work/](https://simonwillison.net/2026/Apr/14/cybersecurity-proof-of-work/)

- **Trusted access for the next era of cyber defense (GPT-5.4-Cyber)** — OpenAI, annotated by Simon Willison. _Takeaway:_ OpenAI's counter-move to Anthropic's Claude Mythos/Project Glasswing: a cyber-permissive variant of GPT-5.4 and an extended Trusted Access program with Persona-based ID verification; Willison notes the announcement is hard to follow and the "best tools" path still requires a Google Form, much like Glasswing. [https://simonwillison.net/2026/Apr/14/trusted-access-openai/](https://simonwillison.net/2026/Apr/14/trusted-access-openai/)

- **Replace token-based CSRF with Sec-Fetch-Site header protection (Datasette PR #2689)** — Simon Willison. _Takeaway:_ Lands Filippo Valsorda's Go-1.25-style header-based CSRF in Datasette, ripping out hidden form tokens. Notable as a worked example of writing PR descriptions by hand after a Claude Code / GPT-5.4 cross-review loop — a small but well-articulated point on agentic engineering hygiene. [https://simonwillison.net/2026/Apr/14/replace-token-based-csrf/](https://simonwillison.net/2026/Apr/14/replace-token-based-csrf/)

- **The impact of AI on software engineers in 2026: key trends** — Gergely Orosz (Pragmatic Engineer). _Takeaway:_ Survey of 900+ readers on AI tool usage — concerns about rising AI costs, ~30% of respondents already hitting usage limits. Pairs cleanly with the Claude Code / GitHub Copilot pricing kerfuffle later in the same week. [https://newsletter.pragmaticengineer.com/p/the-impact-of-ai-on-software-engineers-2026](https://newsletter.pragmaticengineer.com/p/the-impact-of-ai-on-software-engineers-2026)
