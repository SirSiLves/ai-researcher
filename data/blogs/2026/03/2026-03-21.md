## Long-form picks

- **Profiling Hacker News users based on their comments** — Simon Willison. _Takeaway:_ A "mildly dystopian" experiment: feeding a user's last 1,000 HN comments to an LLM with the prompt "Profile this user". An honest look at how cheap surveillance-at-scale becomes once long context + cheap inference are commoditized. [https://simonwillison.net/2026/Mar/21/profiling-hacker-news-users/](https://simonwillison.net/2026/Mar/21/profiling-hacker-news-users/)
- **Using Git with coding agents** — Simon Willison (Agentic Engineering Patterns chapter). _Takeaway:_ Argues that because coding agents are fluent in Git, humans can be more ambitious — leaning on rebase/bisect/worktree workflows without memorizing the commands. [https://simonwillison.net/guides/agentic-engineering-patterns/using-git-with-coding-agents/](https://simonwillison.net/guides/agentic-engineering-patterns/using-git-with-coding-agents/)

- **8 plots that explain the state of open models** — Nathan Lambert, Interconnects. _Takeaway:_ Companion data drop to "What comes next with open models": Qwen still dominates Western adoption metrics for new entrants (Z.ai, MiniMax, Kimi, Ant Ling), and DeepSeek's V3/R1 outperform every Qwen large MoE/dense model on download share. From the ATOM Project's expanded ecosystem measurement. [https://www.interconnects.ai/p/8-plots-that-explain-the-state-of](https://www.interconnects.ai/p/8-plots-that-explain-the-state-of)
