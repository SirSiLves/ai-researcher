## Long-form picks

- **Mr. Chatterbox is a (weak) Victorian-era ethically trained model you can run on your own computer** — Simon Willison. _Takeaway:_ Notes on Trip Venturella's Mr. Chatterbox — a small LLM trained entirely on >28,000 out-of-copyright British Library texts (1837–1899). Weak by frontier standards but a clean reference point for the ethical-training-data conversation; Simon ships an `llm-mrchatterbox` plugin to run it locally. [https://simonwillison.net/2026/Mar/30/mr-chatterbox/](https://simonwillison.net/2026/Mar/30/mr-chatterbox/)
- **Mr. Chatterbox, or, the Modern Prometheus** — Trip Venturella (Estragon). _Takeaway:_ Author's own write-up of the project — methodology, training corpus, model card. Foundational reference for anyone interested in copyright-clean LLM training. [https://www.estragon.news/mr-chatterbox-or-the-modern-prometheus/](https://www.estragon.news/mr-chatterbox-or-the-modern-prometheus/)
- **Why it's hard to find local models that work well with coding agents** — Georgi Gerganov (llama.cpp), via Simon Willison. _Takeaway:_ Gerganov on the long fragile chain from prompt to result for local-model + coding-agent setups: harness bugs, chat-template intricacies, prompt construction issues, plus the occasional pure inference bug. The components are built by different parties, so what you observe is "with very high probability still broken in some subtle way along that chain". [https://twitter.com/ggerganov/status/2038674698809102599](https://twitter.com/ggerganov/status/2038674698809102599)

- **Import AI 451: Political superintelligence; Google's society of minds, and a robot drummer** — Jack Clark. _Takeaway:_ Lead essay frames AI as a path to "political superintelligence" — automated delegates that monitor politicians and surface accountability. Plus Google's hierarchical multi-agent "society of minds" architecture, and DexDrummer as a robot-control benchmark. [https://jack-clark.net/2026/03/30/import-ai-451-political-superintelligence-googles-society-of-minds-and-a-robot-drummer/](https://jack-clark.net/2026/03/30/import-ai-451-political-superintelligence-googles-society-of-minds-and-a-robot-drummer/)

- **Latest open artifacts (Artifacts Log #20)** — Nathan Lambert, Interconnects. _Takeaway:_ End-of-month artifacts roundup. Highlights `cohere-transcribe-03-2026` (conformer-based STT, 14 languages including AIPAC + Arabic) and Sarvam's `sarvam-105b` (12-16T tokens, 30B-A2B and 105B-10A) — Indian frontier-scale open models entering the conversation. [https://www.interconnects.ai/p/latest-open-artifacts-20-new-orgs](https://www.interconnects.ai/p/latest-open-artifacts-20-new-orgs)
