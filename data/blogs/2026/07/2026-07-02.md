# AI Blogs — 2026-07-02

## Long-form picks

- **What's new in Claude Sonnet 5** — Simon Willison. _Takeaway:_ Sonnet 5 nears Opus 4.8 quality at Sonnet pricing but drops temperature/top_p sampling params and ships a new tokenizer emitting ~30% more tokens per text — an effective ~1.3–1.4x price hike for English/code despite unchanged headline rates. [link](https://simonwillison.net/2026/Jun/30/claude-sonnet-5/)
- **TokenBudgeting: Our Conversations with Enterprises on Token Spend** — Crystal Huang, Joey Brookhart, Dylan Patel / SemiAnalysis. _Takeaway:_ From 50+ enterprise conversations: "tokenmaxxing blowout" headlines reflect poor incentives, not collapsing demand — per-employee budgets ($250–$2,000+/month) are the new norm, ~70%+ of OpenAI/Anthropic ARR is coding, and 2H26 AI budgets look safe. [link](https://newsletter.semianalysis.com/p/tokenbudgeting-our-conversations)
- **Impressions from visiting OpenAI, Anthropic, & Cursor** — Gergely Orosz / The Pragmatic Engineer. _Takeaway:_ Cloud-running agents are the next mega-trend (Claude Managed Agents, OpenAI's Cloud Agents team, Cursor cloud agents + iOS), enabled by good-enough models, mature MCP/skills infra, and 1M-token contexts; engineers' work is shifting to building efficient agent environments. [link](https://newsletter.pragmaticengineer.com/p/impressions-from-visiting-openai)
- **Scaling Laws, Carefully** — Lilian Weng. _Takeaway:_ Traces scaling laws from Kaplan to Chinchilla to new data-constrained variants with explicit overfitting penalties for repeated data. Core warning: fitting is fragile — loss rounding, Huber-loss bugs, and fit-region choice can wildly change extrapolated predictions. [link](https://lilianweng.github.io/posts/2026-06-24-scaling-laws/)
- **GLM-5.2 is the step change for open agents** — Nathan Lambert / Interconnects. _Takeaway:_ Z.ai's GLM-5.2 is the first open-weight model that "feels right" as a general agent in coding harnesses, ~6.8 months behind the closed frontier — a bigger moment than DeepSeek R1, landing while US-government restrictions squeeze frontier-lab access and pricing. [link](https://www.interconnects.ai/p/glm-52-is-the-step-change-for-open)
- **Why the Frontier Ecosystem must be Open — Matei Zaharia & Reynold Xin (Databricks)** — swyx / Latent.Space. _Takeaway:_ As frontier models commoditize, durable advantage shifts to company-specific context (proprietary data, governed access, state); Databricks open-sourced Omnigent, a meta-harness above Claude Code/Codex to compose multi-agent workflows — production agent quality is a systems problem. [link](https://www.latent.space/p/databricks)
- **Red-Teaming after Mythos — Zico Kolter & Matt Fredrikson (Gray Swan)** — swyx / Latent.Space. _Takeaway:_ AI security is not "cybersecurity with AI": agents create a new vulnerability class (prompt injection, agent identity), models don't get safer as they scale, and specialized red-teaming models now beat humans at breaking AI systems. [link](https://www.latent.space/p/gray-swan)
- **Import AI 463: Self-improving robots; a 10k Chinese GPU cluster** — Jack Clark. _Takeaway:_ NVIDIA's ENPIRE puts coding-agent-style self-improvement loops on physical robots (auto-eval + auto-reset, 99% on dexterous tasks); Tencent's ARGUS tracing across a 10,000+ GPU cluster signals frontier-grade Chinese training maturity. [link](https://jack-clark.net/2026/06/29/import-ai-463-self-improving-robots-a-10k-chinese-gpu-cluster-and-an-elegiac-essay-for-the-human-era/)
- **My Vibe Coding Adventure, The App and the Experience, Ten Takeaways** — Ben Thompson / Stratechery. _Takeaway:_ Thompson vibe-codes an app he actually uses daily and distills ten takeaways on what agentic coding means for non-developers — first-hand evidence for how far "English as programming language" has come. [link](https://stratechery.com/2026/my-vibe-coding-adventure-the-app-and-the-experience-ten-takeaways/)
- **Using Local Coding Agents** — Sebastian Raschka / Ahead of AI. _Takeaway:_ Hands-on guide to running open-weight models (Qwen3.6 35B-A3B et al. via Ollama/vLLM/MLX) as an alternative to Claude Code/Codex subscriptions. Key caveat: model–harness coupling — vendors optimize models for their own harness first, so pairing matters. [link](https://magazine.sebastianraschka.com/p/using-local-coding-agents)
- **"It's Hard to Eval" Is a Product Smell** — Hamel Husain. _Takeaway:_ If builders can't verify an AI product's output, neither can users — "with AI, verification is the bottleneck." Redesigns three real products around provenance, diffs against trusted anchors, and progressive disclosure, which makes annotation cheap and evals tractable. [link](https://hamel.dev/blog/posts/eval-smell/)
- **How to Use RLMs in Deep Agents** — Sydney Runkle / LangChain. _Takeaway:_ Implements MIT's Recursive Language Models idea via dynamic subagents plus a code interpreter: the agent writes map/reduce-style orchestration code that fans subagents over context chunks. On OOLONG at 128k tokens: 0.79 vs 0.44 for a plain agent. [link](https://www.langchain.com/blog/how-to-use-rlms-in-deep-agents)
- **Announcing Retrieval Harness** — LlamaIndex. _Takeaway:_ Argues one-shot semantic RAG has been outgrown by autonomous agents: exposes filesystem-style primitives (hybrid retrieve, list-files, server-side grep, direct file read) so agents deterministically traverse and verify documents instead of hoping top-k chunks suffice. [link](https://www.llamaindex.ai/blog/announcing-retrieval-harness)
- **Devin Fusion: Frontier Performance at 35% Lower Cost** — Cognition. _Takeaway:_ Hybrid-model harness: a frontier "main" agent plans/reviews and delegates execution to a cheap parallel "sidekick," each keeping its own persistent cached context; model switching is timed to context compaction so it's cache-free. Matches frontier FrontierCode scores at 35% lower cost. [link](https://cognition.com/blog/devin-fusion)
- **Can Frontier AI Labs Lawfully Agree to Pause?** — Nicholas Felstead / Lawfare. _Takeaway:_ Anthropic has floated a coordinated, verified pause in frontier AI development; Felstead argues antitrust law might actually prohibit such an inter-lab agreement — safety coordination among competitors sits in unresolved tension with competition law. [link](https://www.lawfaremedia.org/article/can-frontier-ai-labs-lawfully-agree-to-pause)
