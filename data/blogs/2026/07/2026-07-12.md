## Medium roundup

### model-context-protocol / mcp
- **[MCP's Upcoming 2026 Release Is a Big Deal](https://medium.com/@balajibal/mcps-upcoming-2026-release-is-a-big-deal-1d15990f121f)** — balaji bal (Jun 2026): the coming MCP spec revision (stateless HTTP core, MCP Apps server-rendered UI, long-running Tasks extension, OAuth/OIDC-aligned auth) is a maturity milestone, not a routine version bump.

### rag / retrieval-augmented-generation
- **[Modern RAG in 2026: The Components That Actually Matter](https://medium.com/data-science-collective/modern-rag-in-2026-the-components-that-actually-matter-3f6a138ef117)** — Anubhav: naive chunk-and-embed RAG is dead; production RAG now hinges on adaptive routing, context caching, reranking and agentic retrieval — most failures are retrieval failures, not model failures.
- **[Beyond Naive RAG: A Step-by-Step Guide to Building Agentic RAG in 2026](https://medium.com/@vkrishnan9074/beyond-naive-rag-a-step-by-step-guide-to-building-agentic-rag-in-2026-fceddd989c74)** — V S Krishnan: hands-on walkthrough for letting the LLM decide what, when and how many times to retrieve rather than a fixed single-shot pipeline.

### ai-agents / agentic-ai
- **[The Architecture of Agency: A Deep Technical Guide to Agentic AI Systems in 2026](https://medium.com/@nraman.n6/the-architecture-of-agency-a-deep-technical-guide-to-agentic-ai-systems-in-2026-9df63b37f6df)** — NJ Raman: dissects reasoning loops, memory architectures, tool-calling, orchestration patterns and failure modes after two years of production agent investment.
- **[Antigravity Managed Agents Tutorial: Ship Production AI Agents](https://medium.com/google-cloud/antigravity-managed-agents-tutorial-ship-production-ai-agents-b5917844932b)** — Romin Irani (Jun 2026): practical guide to Google's Antigravity "managed agents" — give the agent a goal and a sandbox instead of hand-building the surrounding infrastructure.

### agent-protocols (A2A)
- **[Unlocking Agent Communication: The A2A Protocol Explained](https://medium.com/wpp-ai-research-labs/unlocking-agent-communication-the-a2a-protocol-explained-4a63ceea1de3)** — Anastasios Stamoulakatos (Satalia AI Research Lab): how A2A Agent Cards (served at /.well-known/agent.json) enable cross-vendor task discovery and handoff under Linux Foundation governance.

### vector-database
- **[Do You Still Need a Vector Database in 2026?](https://medium.com/data-science-collective/vector-databases-are-dying-heres-the-production-evidence-8c17b54687e2)** — Data Science Collective: production-evidence argument that dedicated vector DBs are being displaced by pgvector-style extensions and long-context / agentic retrieval for many workloads.
