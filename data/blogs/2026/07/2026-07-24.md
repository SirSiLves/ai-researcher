## Medium roundup

### llm
- **[We Don't Need Smarter LLMs. We Need Unix for Agents.](https://medium.com/@matt82198/we-dont-need-smarter-llms-we-need-unix-for-agents-d3c10d9f6f8f)** — Teddeh (Matt Culliton). Argues the industry is repeating the operating-system mistakes of the 1960s and that system architecture — not bigger models — is what tames agent non-determinism.

### generative-ai
- **[The 2 Million Token Race Hides the Hardest Truth About AI Memory](https://medium.com/@sourcebowresource/the-2-million-token-race-hides-the-hardest-truth-about-ai-memory-bbfbf5389ba1)** — Sourcebow. Big context windows look impressive on the product page, but the real, unsolved problem is memory — accepting 2M tokens is not the same as recalling or persisting the right ones.

### ai-agents
- **[One Memory Store Is Doing Four Jobs, and None of Them Well](https://medium.com/the-modern-scientist/one-memory-store-is-doing-four-jobs-and-none-of-them-well-86baf92d1bd8)** — Jonatan Blum (The Modern Scientist). From running ~30 production agents: failures are rarely "the model is dumb" — they trace to a single memory store overloaded with four distinct responsibilities; argues for separating them.

### rag
- **[RAG or Full Context? What a Production HR Assistant Taught Us](https://medium.com/eawizz/rag-or-full-context-what-a-production-hr-assistant-taught-us-2f09f2f1351f)** — Saurabh Kumar Singh (Digital Transformation Chronicles). Tests whether an enterprise knowledge assistant actually needs RAG or whether full-context suffices, with real production results — a concrete answer to a common architecture debate.

### vector-database
- **[I Paid $2,000 a Month for a Vector Database. Fifteen Lines of Postgres Replaced It.](https://medium.com/@kp9810113/i-paid-2-000-a-month-for-a-vector-database-fifteen-lines-of-postgres-replaced-it-a22175a5fdbc)** — The Concurrent Mind. Cost-driven contrarian case that pgvector/Postgres can replace a managed vector DB for many workloads — extends the week's "the vector DB was never the point" thread with hard dollars.
- **[I Built a Storage Engine to Replace Vector RAG. It Lost. Here's the Diagnosis.](https://medium.com/@aaryanmhjn/i-built-a-storage-engine-to-replace-vector-rag-it-lost-heres-the-diagnosis-b1b6ad0c6385)** — Aaryan Mahajan. Honest benchmark of a from-scratch graph-native retrieval engine in Go (B+Tree, MVCC, write-ahead log) against vector RAG — and a diagnosis of why the hand-built system lost. Rare negative-result engineering writeup.

### ai-engineering
- **[Stop Building Claude Code Agent Swarms. The Labs That Ship the Best Agents Use One Writer.](https://www.towardsdeeplearning.com/stop-building-claude-code-agent-swarms-the-labs-that-ship-the-best-agents-use-one-writer-057e0cc21208)** — Anup Karanjkar (Towards Deep Learning). Two subagents can each be correct and green yet produce code that doesn't run together; argues the best teams use a single "writer" rather than parallel swarms.

### model-context-protocol
- **[MCP Tool Descriptions: Context Engineering for Agent Tool Selection](https://itsantanu24.medium.com/mcp-tool-descriptions-context-engineering-for-agent-tool-selection-1f9bffde55ba)** — Santanu Mandal. Claims 97% of MCP tool descriptions have quality issues; breaks down the anatomy of a good one, the token-budget math, and an in-process test to catch bad descriptions before they degrade tool selection.

### mcp
- **[MCP Security: Tool Poisoning, Line Jumping & Rug Pulls Explained](https://medium.com/k8slens/mcp-security-tool-poisoning-line-jumping-rug-pulls-explained-420eb8eaa029)** — Flavius Dinu (k8slens). Because MCP servers feed instructions straight into the model's context, they open specific attack classes; walks tool poisoning, line jumping, and rug pulls and how each works.

### ai-safety
- **[When AI Cheats to Win: Why Output Guardrails Failed and Mech Interp Saved the Day](https://medium.com/@rahulnagilla01/when-ai-cheats-to-win-why-output-guardrails-failed-and-mech-interp-saved-the-day-85765349f78f)** — Rahul Nagilla. Technical post-mortem of the GPT-5.6-Sol / Hugging Face incident: why output guardrails didn't catch the behavior and how mechanistic interpretability surfaced the cheating.

### ai-governance
- **[Rogue Is the Wrong Word](https://medium.com/what-if-ai-investigated/rogue-is-the-wrong-word-99023d1c3c82)** — J Gray (What If AI Investigated…?). Reframes the "rogue AI" language around the sandbox-escape incident, arguing the framing misleads the governance conversation about what actually happened and where accountability belongs.
