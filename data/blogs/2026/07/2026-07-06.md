## Long-form picks

- **The Art of Loop Engineering** — Sydney Runkle, LangChain blog (2026-07-01). _Takeaway:_ Argues the real leverage in agents is not the model but the loops you stack around it, and lays out a concrete four-loop model: (1) the base agent loop (reads state, calls tools until done — often wrong on first pass), (2) a verification loop that grades output against a rubric and returns failing work with feedback until it passes, (3) an event-driven loop that fires the agent on an external signal (doc lands, schedule, webhook) instead of a human pressing go, and (4) a hill-climbing loop that runs an analysis agent over accumulated traces and rewrites the harness (prompts, tools, graders) to improve future runs. A clean mental model for pushing reliability and self-improvement into the harness rather than the prompt. [link](https://www.langchain.com/blog/the-art-of-loop-engineering)
- **Scaling Laws, Carefully** — Lilian Weng, Lil'Log (2026-06-24). _Takeaway:_ A 25-minute deep-dive revisiting scaling laws as an empirical foundation of deep learning — training loss falling as a power law in model size, data, and compute — and folding in recent work (incl. Lovelace et al. 2026) on how model size and data repetition interact, i.e. when re-using data still buys you loss reductions and when it stops. Careful, math-grounded original analysis rather than a hot take; surfaced now as it predates but was missed in prior runs. [link](https://lilianweng.github.io/posts/2026-06-24-scaling-laws/)

## Medium roundup

### agent-protocols
- **[AG-UI vs MCP vs A2A vs A2UI: A Field Guide to the 2026 Agent Protocol Stack](https://medium.com/system-design-mastery-series/ag-ui-vs-mcp-vs-a2a-vs-a2ui-a-field-guide-to-the-2026-agent-protocol-stack-07080e346fc9)** — Suresh Kumar Ariya Gowder (Jul 2026). Maps the four protocols as complementary layers rather than competitors — MCP connects agents to tools, A2A to other agents, AG-UI to the UI, and A2UI lets the agent draw that UI itself — with the useful framing that AG-UI is the transport and A2UI the content format (an AG-UI event can carry an A2UI payload). Practical adoption advice: start with the layer your problem needs (MCP for external tools, add A2A when coordinating agents) rather than adopting all of them at once.

### ai-safety
- **[LLM Reasoning and Agentic Safety at ICML 2026](https://medium.com/capital-one-tech/llm-reasoning-and-agentic-safety-at-icml-2026-55f341e21caa)** — Capital One Tech (Jul 2026). Timed to ICML 2026 (Seoul, Jul 6–11); introduces SAFARI, a framework that replaces dumping a whole trajectory into context with a tool-augmented diagnostic loop — the model gets a toolbox to read and search trajectory segments plus a persistent short-term memory for cross-turn reasoning. A concrete engineering pattern for failure diagnosis / agentic safety rather than a survey.
