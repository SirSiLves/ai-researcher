## Long-form picks

- **Open Source AI Gap Map** — Simon Willison (2026-07-03). _Takeaway:_ Willison walks the Gap Map v0.1, which catalogs 421 open-source AI artifacts (266 tools/libraries, 85 models, 50 datasets, 20 hardware projects) across 228 orgs to show where the open ecosystem has real depth versus where it still trails closed frontier labs. A useful map for anyone deciding what to build on vs. buy. [link](https://simonwillison.net/2026/Jul/3/open-source-ai-gap-map/)
- **Release: llm-coding-agent 0.1a0** — Simon Willison (2026-07-02). _Takeaway:_ A Fable-5 experiment in which Willison builds a small but working coding agent on top of his `llm` library, which has quietly grown into an agent framework (tool loops, not just completions). A concrete, readable reference for the minimal moving parts of a coding agent. [link](https://simonwillison.net/2026/Jul/2/llm-coding-agent/)
- **How to Use RLMs in Deep Agents** — LangChain blog (2026-07-01). _Takeaway:_ Introduces Recursive Language Models as an answer to "context rot": instead of stuffing everything into one window, the model runs code in a REPL that dispatches sub-agents and recurses over slices of the input context. A substantive architectural pattern for long-context agent work rather than another prompt trick. [link](https://www.langchain.com/blog/how-to-use-rlms-in-deep-agents)
- **Introducing Rubrics: Build Agents that Evaluate and Correct Their Work** — Hunter Lovell, LangChain blog (2026-07-01). _Takeaway:_ Rubrics let Deep Agents score and revise their own outputs against explicit criteria, pushing eval/self-correction into the agent loop itself rather than a separate offline harness — part of the broader shift toward agents that critique before they ship. [link](https://www.langchain.com/blog/introducing-rubrics-for-deepagents)
- **Will the New Export Controls Shake the Foundations of the U.S. AI Industry?** — Lawfare (2026-07-01). _Takeaway:_ Unpacks Dario Amodei's June essay in which he reversed Anthropic's long-standing stance and endorsed binding, FDA-style pre-release testing with government power to block unsafe model releases — and what that reversal, alongside new export controls, means for frontier-lab governance. A sharp read on a genuinely shifting policy debate. [link](https://www.lawfaremedia.org/article/will-the-new-export-controls-shake-the-foundations-of-the-u.s.-ai-industry)

### mcp
- **[MCP Killed the Session. Here's Why That's a Big Deal.](https://medium.com/@sathishkraju/mcp-killed-the-session-heres-why-that-s-a-big-deal-4e484b331c27)** — Sathish Raju (Jun 2026), on the stateless-core change in the 2026-07-28 MCP spec: dropping `Mcp-Session-Id` and protocol-level sessions means any request can hit any server instance — plain round-robin load balancing, no sticky routing or shared session store. A clear operational read on why the revision matters for anyone running MCP servers in production.
