## Long-form picks

- **Using Claude Code: The Unreasonable Effectiveness of HTML** — Thariq Shihipar (Anthropic / Claude Code team), via Simon Willison. _Takeaway:_ Argues HTML — not Markdown — is the right default output format to ask Claude for. With HTML, Claude can drop in SVG diagrams, interactive widgets, in-page nav, color-coded annotations. Example prompt: have Claude render a PR review as an HTML artifact with inline diff annotations and severity-colored findings. Simon takes the bait and runs it against the `copy.fail` Linux LPE PoC to generate a rich exploit explainer. Companion gallery of examples at thariqs.github.io/html-effectiveness/. [https://simonwillison.net/2026/May/8/unreasonable-effectiveness-of-html/](https://simonwillison.net/2026/May/8/unreasonable-effectiveness-of-html/)
