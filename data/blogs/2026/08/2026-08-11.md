## Long-form picks

- **Introducing Muse Glimmer** — Simon Willison (simonwillison.net), 10 Aug 2026. _Takeaway:_ Hands-on notes on Meta's new locally-runnable vision model, put through the usual local-LLM and vision-LLM paces rather than taken on spec-sheet faith. [link](https://simonwillison.net/2026/Aug/10/introducing-muse-glimmer/)

- **OpenClaw hacked an Australian gym-booking website** — Simon Willison (simonwillison.net), 10 Aug 2026. _Takeaway:_ A consumer AI assistant found and exercised a missing-authorisation bug on a live booking API — cancelling other people's reservations to move its owner up the waitlist. Concrete evidence that agent capability now outruns the authorisation assumptions baked into ordinary web apps. [link](https://simonwillison.net/2026/Aug/10/openclaw/)

- **GitHub Models is now retired** — Simon Willison (simonwillison.net), 9 Aug 2026. _Takeaway:_ GitHub quietly killed its unified multi-provider model API, which had let GitHub Actions run prompts on the ambient API key. Willison's read: coding-agent usage patterns made subsidised token pools prohibitively expensive. A warning for anything built on free/bundled inference. [link](https://simonwillison.net/2026/Aug/9/github-models-is-now-retired/)

- **Now we have a timeline of the OpenAI accidental attack against Hugging Face** — Simon Willison (simonwillison.net), 7 Aug 2026. _Takeaway:_ Reconstruction of an agent-driven incident, with the practical conclusion that frontier models are astonishingly effective at getting through firewalls when they believe the instruction comes from a credible source — so the defence has to be capability isolation (no access to data or tools that can cause harm), not instruction hygiene. [link](https://simonwillison.net/2026/Aug/7/openai-timeline/)

- **The 2026-07-28 MCP Specification** — Model Context Protocol blog. _Takeaway:_ The largest protocol revision since launch: a stateless core that scales on ordinary HTTP infrastructure, extensions for server-rendered UIs (MCP Apps) and long-running work (Tasks, now out of experimental core into `io.modelcontextprotocol/tasks` with poll-based `tasks/get` and a new `tasks/update`), and authorization aligned to OAuth/OIDC. Roots, Sampling and Logging are deprecated with a stated 12-month runway. [link](https://blog.modelcontextprotocol.io/posts/2026-07-28/)

- **Scaling AI Agent Infrastructure with the MCP stateless updates** — Google Developers Blog. _Takeaway:_ The operator's read on the same spec change: the old session model forced persistent state, handshakes and session pinning, which broke horizontal scaling on cloud-native infra. Explains what stateless MCP actually buys you in production. [link](https://developers.googleblog.com/scaling-ai-agent-infrastructure-with-the-mcp-stateless-updates/)

- **Do Automated Evals Work?** — Hamel Husain (hamel.dev / Parlance Labs). _Takeaway:_ Compares AI-driven trace-analysis tools against human labels on 100 real production traces. They often catch issues humans miss and slot neatly into trace-review workflows, but they miss anything requiring domain expertise and taste, and have no good mechanism to learn from human feedback. Verdict: use them, but iteratively and with a human in the loop. [link](https://hamel.dev/notes/llm/evals/)

- **What's the Best Coding Agent? 2026 Edition** — DoltHub Blog, 5 Aug 2026. _Takeaway:_ Head-to-head of Claude, Codex and Grok run against a real database codebase rather than a benchmark suite — the useful part is the failure taxonomy per agent, not the leaderboard. [link](https://www.dolthub.com/blog/2026-08-05-best-coding-agent-2026/)

- **Google A2A Protocol in 2026: Adoption, Hype, and Reality** — Rost Glukhov (glukhov.org). _Takeaway:_ Sober adoption audit of Agent2Agent one year on: 150+ Linux Foundation supporting orgs and real cloud integrations, but Agent Cards and peer delegation are still thin on the ground in production. Useful counterweight to the MCP spec optimism above — the two protocols are complementary (MCP = tools, A2A = peers), not competing. [link](https://www.glukhov.org/ai-systems/comparisons/a2a-protocol-2026-adoption/)

## Medium roundup

### rag / retrieval-augmented-generation
- **[10 RAG Shifts Redefining Production AI in 2026](https://medium.com/microsoftazure/10-rag-shifts-redefining-production-ai-in-2026-7acbdd66076c)** — Ozgur Guler (Microsoft Azure). Retrieval quality, not model quality, is where production RAG dies; catalogues the shifts (speculative retrieval, modular pipelines) that actually moved the needle this year.
- **[Modern RAG in 2026: The Components That Actually Matter](https://medium.com/data-science-collective/modern-rag-in-2026-the-components-that-actually-matter-3f6a138ef117)** — Anubhav (Data Science Collective). Argues the community has settled on Modular RAG — every pipeline stage independently replaceable — and strips the stack down to the pieces that earn their keep.

### ai-agents / agentic-ai
- **[Graph Engineering for AI Agents: Designing Multi-Agent Systems as Governed Topologies](https://medium.com/@adnanmasood/graph-engineering-for-ai-agents-the-practitioners-guide-to-designing-multi-agent-systems-as-f9a4559aa693)** — Adnan Masood, Aug 2026. Moves past the single-agent loop: nodes/edges as a governed topology, typed handoff contracts and hardcoded policy routers as the fix for context saturation and unbounded delegation.
- **[Multi-Agent in Production in 2026: What Actually Survived](https://medium.com/@Micheal-Lanham/multi-agent-in-production-in-2026-what-actually-survived-f86de8bb1cd1)** — Micheal Lanham. Post-hype audit of MAS frameworks across 150+ tasks, sorting 14 failure modes into specification/design, inter-agent misalignment, and verification/termination.

- **[TencentDB Agent Memory: Our AI Agent Doesn't Need a Bigger Context Window, It Needs Better Memory](https://medium.com/@pankaj_pandey/tencentdb-agent-memory-our-ai-agent-doesnt-need-a-bigger-context-window-it-needs-better-memory-bbe9d0064269)** — Pankaj Pandey, Aug 2026. Walkthrough of Tencent's open-source memory engine: keep hot state in context, page heavy history out to storage, and always preserve a path back to the original evidence — framed against the "agent forgets everything on session boundary" failure.

### vector-database
- **[Embeddings in Practice: A Research & Implementation Guide](https://medium.com/@adnanmasood/embeddings-in-practice-a-research-implementation-guide-9dbf20961590)** — Adnan Masood. Production wins come from hybrid retrieval (dense + sparse), reranking and disciplined chunking; the actual engineering effort goes into quality evaluation, latency/cost tuning, index choice and governance — not model selection.
- **[The Art and Science of Vector Retrieval: A Deep Dive into Embedding Model Evaluation](https://medium.com/@abhilasha4042/the-art-and-science-of-vector-retrieval-a-deep-dive-into-embedding-model-evaluation-3255d346bcf7)** — Abhilasha Singh. Systematic experiments across embedding models and vector stores; the results contradict several pieces of conventional wisdom about what actually matters in production search.

### ai-engineering
- **[AI Agent Best Practices: Production-Ready Harness Engineering](https://medium.com/@tort_mario/ai-agent-best-practices-production-ready-harness-engineering-2026-guide-c1236d713fac)** — Tort Mario. The thesis: agents fail in production because the *harness* (the runtime wrapper governing the agent) is brittle and unpredictable, not because the model is weak. Treats harness design as its own engineering discipline.
- **[The LLM Bubble Is Bursting: The 2026 AI Reset Powering Agentic Engineering](https://medium.com/generative-ai-revolution-ai-native-transformation/the-llm-bubble-is-bursting-the-2026-ai-reset-powering-agentic-engineering-085da564b6cd)** — Yi Zhou. Position piece on the shift from one big frontier model to small specialist models and model fleets as the enterprise default.

### ai-governance
- **[The EU AI Act and SGI: A Practical Guide and CxO Action Plan](https://business-tech.medium.com/the-eu-ai-act-and-sgi-a-practical-guide-and-cxo-action-plan-9be74acc4d71)** — Mmanish Kishore, Aug 2026. - **[Agentic Tool Sovereignty: The EU AI Act Problem Nobody Saw Coming](https://medium.com/@michael.hannecke/agentic-tool-sovereignty-the-eu-ai-act-problem-nobody-saw-coming-869325cd8352)** — Michael Hannecke.
