### Structural cause

The fetch layer enforces a per-URL provenance rule - it refuses any URL that has not already appeared in a WebSearch result. Tonight it took out arxiv cs.CL, papers.cool, the GitHub REST API, and the direct index fetches for openai.com, claude.com, deepmind.google, mistral.ai and ai.meta.com. Search-first-then-fetch is the only working pattern.

The blogs collector had **no fetch path at all** this run and went search-only end to end, leaving **ten** configured long-form sources completely unread (`ai.engineer`, `jack-clark.net`, `stratechery.com`, `every.to`, `lilianweng.github.io`, `karpathy.github.io`, `cognition.ai/blog`, `news.smol.ai`, `lastweekin.ai`, plus the Karpathy YouTube channel).
