## Major news & releases

### GPT-5.5 ships

**OpenAI launches GPT-5.5 — first new base model in a year, doubled per-token prices, agent-first positioning.** OpenAI announced GPT-5.5: "a new class of intelligence for real work and powering agents, built to understand complex goals, use tools, check its work, and carry more tasks through to completion." Gains concentrated in **agentic coding, computer use, knowledge work, and early scientific research**. Rolling out to Plus, Pro, Business, and Enterprise users in ChatGPT and Codex; **GPT-5.5 Pro** for Pro/Business/Enterprise. API GA tomorrow. **Pricing**: input doubled from $2.50 to **$5.00**/1M tokens; output doubled from $15.00 to **$30.00**/1M tokens. GPT-5.5 Pro stays at $30 / $180. OpenAI says effective cost increase is ~20% once token efficiency is factored in. Released with the **strongest safeguards to date**: internal/external redteam, targeted cyber + biology testing, GPT-5.5 system card updated 24 April. _Why it matters:_ OpenAI's most aggressive pricing move in two years — the doubled rate card recoups inference economics for agent-heavy use, betting customers will pay for capability. Agentic-coding and computer-use positioning is the explicit answer to Anthropic's Claude Code lead; the "AI super-app" framing previews the OpenAI Deployment Company narrative on 11 May. ### Anthropic admits the Claude Code regression

**Anthropic publishes "Claude Code regression" investigation — admits dumbed-down behaviour March 4 → April 7.** Anthropic published the results of an investigation into customer complaints about lower-quality Claude responses, finding three distinct changes between March and early April that degraded Claude Code, Claude Agent SDK, and Claude Cowork. Most notable: Anthropic **adjusted Claude Code's default reasoning effort from high to medium on 4 March** to reduce latency; "this was the wrong tradeoff" — reverted **7 April**. Also a caching bug and a system-prompt change that compounded the regression. The API was not affected. **Memory in Managed Agents** also moved to public beta the same day. _Why it matters:_ Most explicit "we got it wrong" public from a frontier lab in 2026 and a deliberate trust rebuild. The regression narrative had been simmering for six weeks; the disclosure vindicates power-users and signals Anthropic will publish reasoning-effort changes going forward. [The Register — Anthropic admits dumbed-down](https://www.theregister.com/2026/04/23/anthropic_says_it_has_fixed/) · [Anthropic news hub](https://www.anthropic.com/news) · [Anthropic developer tracking](https://tjrobertson.com/anthropic-2026-claude-updates/)

**Anthropic Memory in Managed Agents — public beta.** Durable per-agent memory across sessions with policy + observability hooks, available across Claude Agent SDK and Claude Cowork. _Why it matters:_ On the same day as the regression apology, Memory in Managed Agents is the forward-looking primitive that competes head-on with Cloudflare Agent Memory (16 April private beta). Anthropic offering this as a managed feature on its own SDK rather than via a partner is the explicit "we own the agent runtime" play. [Code with Claude — doubled limits, infinite context, memory](https://www.dotzlaw.com/insights/anthropic-2026-code-with-claude/)

### Software stocks reprice on AI-substitution

**Software stocks plunge — ServiceNow –18%, IBM and Salesforce / Workday / Oracle drag down on AI fear.** Software stocks plunged after ServiceNow and IBM Q1 results disappointed. **ServiceNow shares fell ~18%** (its worst day on record), citing Middle East conflict "headwind" on subscription revenue; IBM also dragged. **Salesforce, Workday and Oracle followed lower**. The selloff broadened into a re-rating of application SaaS as "AI-vulnerable" — agents seen as the disintermediation risk that earnings can't yet refute. _Why it matters:_ The market is now pricing application SaaS on agent-substitution risk, even when the headline Q1 number is fine. ServiceNow's "Middle East headwind" excuse was widely disbelieved; the read-across to Workday and Oracle compounded. The selloff hardens the narrative for Knowledge 2026 and Sapphire — vendors arrive needing to prove agent-defensibility. - **A Self-Evolving Framework for Efficient Terminal Agents via Observational Context Compression** — anonymous (cs.AI). Self-evolving terminal-agent framework whose key trick is observational context compression — direct attack on the "agent loops blow up the context window" failure mode. _Category:_ arXiv:2604.19572 — cs.AI. [arXiv](https://arxiv.org/abs/2604.19572)
- **Scaling Test-Time Compute for Agentic Coding** — anonymous (cs.AI). - **OpenMobile: Building Open Mobile Agents with Task and Trajectory Synthesis** — anonymous (cs.AI). Open mobile-agent stack with synthetic task and trajectory generation as the data engine. _Category:_ arXiv:2604.15093 — cs.AI. [arXiv](https://arxiv.org/abs/2604.15093)
