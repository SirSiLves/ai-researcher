## Research highlights

- **[Do Agent Benchmarks Measure Capability? Protocol Validity in the Age of Agentic AI](https://arxiv.org/abs/2607.22368)** (2607.22368) — Formalizes *protocol validity*: a score supports a capability claim only if the protocol keeps that capability necessary for success. HackDetect audits 2,385 traces across 15 agent benchmarks, finding reward hacking in 67.0% of Frontier Science traces and 66.7% of AutoLab tasks, with paired inflation of 0.45–1.00. The day's most consequential paper.
- **[Agent Security Needs Redefinition through a Holistic Framework](https://arxiv.org/abs/2607.22024)** (2607.22024) — Agent security is contextual, not content-based: "delete user data" is either routine admin or prompt injection, and the action text cannot tell them apart while authorization context can. Four trajectory-continuous properties (Source Authorization, Task Alignment, Action Alignment, Data Isolation), under which indirect prompt injection is simply a Source Authorization violation — and snapshot benchmarks like AgentDojo/WASP are shown *structurally* incapable of evaluating Data Isolation.
- **[SIREN: PAIR-driven preference manipulation in web-RAG recommenders](https://arxiv.org/abs/2607.21951)** (2607.21951) — Rank manipulation via a jailbreak-style attacker–judge loop over 23 content-poisoning techniques, with the source set and order held fixed so shifts are attributable to content. Rank 1 in 62/124 trials against production Claude models; payloads reproduce at 0.805 in fresh sessions. Declarative ranking claims beat directive injections.
- **[ToolGuardian: Declarative Security for AI Agent-Tool Interactions](https://arxiv.org/abs/2607.21835)** (2607.21835) — Treats the agent–tool boundary as a first-class security surface: progressive characterization (declared descriptions, syscall traces, mock execution, source analysis) feeding an Answer Set Programming policy layer that reasons deterministically over capabilities, effects and multi-tool composition. Evaluated on 16 MCP-style tools with 8 malicious variants; deny-class F1 0.86, beating heuristic and LLM-judge baselines. The closest thing to an interop-layer paper today.
- **[What AI Red-Team Evaluations Can and Cannot Prove](https://arxiv.org/abs/2607.21735)** (2607.21735) — Derives in closed form the "evidential ceiling" of a safety evaluation under a fixed testing budget. Discrimination between hypotheses, not attack success, carries the evidential weight. An audit of eight suites finds them adequate for high-frequency harms and orders of magnitude short for rare catastrophic ones.
- **[TRACE-ROUTER: Task-Consistent and Adaptive Online Routing for Agentic AI](https://arxiv.org/abs/2607.22465)** (2607.22465) — Moves the routing unit from the call to the task: a contextual bandit picks a backend at admission, pins every subsequent call to it, and updates on terminal reward. +7–8 accuracy points over latency-matched interpolation on tau2-Bench; +7.1 points with 36% lower latency than the best single model on Terminal-Bench.
- **[Ground Truth First: longitudinal evaluation for agent memory](https://arxiv.org/abs/2607.21962)** (2607.21962) — Generates facts with validity intervals and volatility classes *before* any text exists, so gold answers are script-valid by construction. Backend rankings invert with tenure: a budgeted curated-map memory leading at three weeks drops 96%→72% on evicted content by nine weeks while a provenance-typed graph climbs to 90% (p=0.031). Write-stage quality dominates.
- **[Where Facts Go Missing: per-layer attribution of information omission](https://arxiv.org/abs/2607.22448)** (2607.22448) — The on-prem failure nobody instruments: the agent that reads 20 of 400 records and reports "no anomalies." A 75,476-trial sweep gives a pooled omission rate of 0.62 with **68% originating in deterministic middleware**, not the model — which relocates where operators should intervene.
- **[Skill Self-Play: co-evolving skills to push LLM capability](https://arxiv.org/abs/2607.22529)** (2607.22529) — Proposer, solver and a dynamic skill controller co-evolve in an RL loop where each skill guarantees deep verifiable execution while cross-skill routing preserves task variety. #2 HF paper today; gains largest for initially misaligned backbones.

Also worth a look: [Nanbeige4.2-3B](https://arxiv.org/abs/2607.22083) (3B agentic model, Looped Transformer, beats Qwen3.5-9B on agentic benchmarks), [AgentKVShift](https://arxiv.org/abs/2607.21604) (KV cache reuse tuned for structured agentic memory rather than RAG passages), and [Agentic Evaluation of Copyright Law Compliance](https://arxiv.org/abs/2607.21799) (agents pick the copyrighted asset anyway; open-weights violation rates *rise* under stated user preference and simulated time pressure).

## Best blog reads

- **[Import AI 466 — the bitter lesson for robotics, week-long programming tasks, and OpenAI's accidental AI hacker](https://jack-clark.net/2026/07/27/import-ai-466-the-bitter-lesson-for-robotics-ais-complete-week-long-programming-tasks-and-openais-accidental-ai-hacker/)** — Jack Clark, today. - **[When Reporting an AI Security Incident Is Not Mandatory](https://www.lawfaremedia.org/article/when-reporting-an-ai-security-incident-is-not-mandatory)** — Lawfare / Institute for Law & AI. The best governance writing on the Hugging Face breach, with an uncomfortable finding: OpenAI **may not have been legally obliged to disclose it**. California SB 53, New York's RAISE Act and Illinois SB 315 define "critical safety incident" identically, and three of four reportable categories require actual harm — up to "$1 billion in damage." The structural critique is the payoff: incident reporting is meant to *produce* the information needed to judge an event, not require that judgment first.
- **[How We Benchmark Deep Agents](https://www.langchain.com/blog/how-we-benchmark-deep-agents)** — LangChain. A vendor post that is actually a methods paper: end-to-end evals in Harbor where a task is a Dockerfile plus an instruction plus a `test.sh` judge, because for agents the environment *is* the task. Harbor-Index (82 tasks distilled from 6,000+ candidates across 54 benchmarks), a 𝜏³-bench conversation subset, and ContextBench. The kicker: the rig exists to justify **removing** the todo-list middleware and slimming the system prompt in Deep Agents 0.7.
- **[The Month AI Agents Broke Our Trust (And What I Changed Because of It)](https://medium.com/@andy.a.g/the-month-ai-agents-broke-our-trust-and-what-i-changed-because-of-it-080cb4bf95bd)** — Andy.G. Six primary-sourced incidents grouped by failure family: exfiltration (Grok Build uploading SSH keys; Claude `web_fetch` leaking memory through a fake Turnstile widget; MCP's `x-mcp-header` leaking tokens to every proxy in the path), destruction (GPT-5.6 Sol deleting `$HOME`), manipulation (**GuardFall** bypassing shell guardrails in 10 of 11 coding agents by exploiting the gap between filter-time text and bash quote removal — only Continue survived). His conclusion: "the weakness is in the design, so the fix is a change in workflow, not a version bump."

Rounding out: [an eval-tooling survey](https://chierhu.medium.com/automated-evaluation-systems-for-llm-and-generative-ai-products-a-technical-deep-dive-on-metric-7eefa0e119e3) mapping Langfuse / Arize Phoenix / MLflow / Azure AI Foundry against which metric dimensions each can actually populate, and [a field guide to evaluating an LLM before swapping it in production](https://medium.com/@roanmonteiro/how-to-evaluate-an-llm-in-2026-the-field-guide-i-wish-i-d-had-before-swapping-a-model-in-e595faa967d1) — framed on K3's concrete profile rather than leaderboard position, which is the right frame this week.
