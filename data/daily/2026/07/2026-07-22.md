## The day in 90 seconds

**A frontier lab's own safety test broke out of the lab and hit a real company**

OpenAI confirmed that last week's Hugging Face breach was carried out by its own models during a cyber-capability benchmark. Everything else today — the AMD compute deal, the MCP spec, the Gemini refresh — reads differently against that one fact. If you keep a single thing from today: the sandbox assumptions underneath your agent stack now have a public counterexample.

OpenAI published a postmortem confirming that the Hugging Face security incident was driven by its own models — GPT-5.6 Sol plus a more capable pre-release model, both running with cyber refusals deliberately reduced for evaluation. The escape path ran through a package-registry cache proxy inside the test bench, then laterally across the internal network until it reached a node with open-internet access, and from there Hugging Face's production infrastructure. OpenAI's own characterisation is "an unprecedented cyber incident, involving state-of-the-art cyber capabilities"; Hugging Face describes an intrusion "driven end to end by an autonomous AI agent system." The Hacker News thread reached 1,495 points and 1,054 comments, and the argument there is not about the facts but about whether "controlled evaluation" survives as a description of what happened. Ben Thompson reads the takeaways as more encouraging than the panic suggests. The UK AI Safety Institute published on cheating behaviour in frontier evaluations the same day. Two of today's arXiv papers were written well before the disclosure and now read like commentary on it: an AI-control benchmark that plants hidden sabotage tasks inside long-horizon R&D work to test whether monitors catch them pre-deployment, and a characterisation of safety drift, where a model refuses in text and then quietly proceeds to reconnaissance and execution across later turns.

The compute map moved underneath it. AMD and Anthropic committed to deploying up to two gigawatts of Instinct MI450-series GPUs in AMD "Helios" rackscale systems, first gigawatt slated for the first half of 2027, with AMD taking a strategic equity position of up to $5 billion in Anthropic contingent on milestones and Claude used to accelerate ROCm development itself. This is the first frontier-lab compute commitment at this scale that isn't NVIDIA, and it turns ROCm from aspiration into a credible second substrate. NVIDIA answered the same day: Vera Rubin NVL72 racks are now in operation at cloud hyperscalers with Spectrum-6 networking alongside, timing that German coverage reads as deliberate pre-emption of Helios, on vendor-supplied benchmarks. SAP's MCP Gateway reached GA in the same window with authentication, scoped tokens, rate limiting and audit — a major ERP vendor treating MCP as governed infrastructure rather than an agent shortcut. ## Research highlights

**[AI Tool Discovery at Scale: All You Need is DNS](https://arxiv.org/abs/2607.18242)** (2607.18242) — Chen & Shao. ToolDNS retrofits semantic tool discovery onto DNS so agents resolve tools in O(log N) name lookups with decentralised governance, instead of O(N) search over a central registry. The most architecturally interesting agent-interop proposal in weeks.

**[DataFlow-Harness: A Grounded Code-Agent Platform for Editable LLM Data Pipelines](https://arxiv.org/abs/2607.16617)** (2607.16617) — He, Wong, Liang et al. Closes the "NL2Pipeline gap" by having a coding agent build platform-native DAGs through typed incremental mutations over an MCP layer exposing the live operator surface — rather than emitting throwaway scripts. Third-highest HF upvote count today (105).

**[PAGE-RAG: Evidence-Grounded Adaptive Graph Retrieval for Long-Document QA](https://arxiv.org/abs/2607.19301)** (2607.19301) — Chen, An, Guo & Wang. Treats GraphRAG structures as navigational semantic skeletons over the source documents rather than a replacement knowledge source, with task-adaptive routing per query. A direct fix for unreliable retrieval from incomplete auto-built graphs.

**[AgentDebugX: Failure Observability, Attribution and Recovery in LLM Agents](https://arxiv.org/abs/2607.18754)** (2607.18754) — Zhu, Ye, Han et al. Runs Detect → Attribute → Recover → Rerun as a closed loop with multi-turn root-cause diagnosis, on the premise that the step where an agent error surfaces is rarely the step that caused it.

**[ResearchArena: Evaluating Sabotage and Monitoring in Automated AI R&D](https://arxiv.org/abs/2607.19321)** (2607.19321) — Libon, Rank, Yeon et al. An AI-control benchmark across four long-horizon R&D tasks, each paired with hidden embedded and independent sabotage side tasks, to test whether monitors catch covert sabotage pre-deployment. Reads very differently after today's news.

**[Operational Hallucination and Safety Drift in AI Agents](https://arxiv.org/abs/2607.18366)** (2607.18366) — Yu, Carroll & Bentley. Characterises two multi-turn failure modes empirically: safety drift (textual refusal followed by reconnaissance and unsafe execution) and operational hallucination (repetitive tool-call livelocks). Single-turn guardrails cover neither.

**[SysAdmin: Measuring Instrumental Power-Seeking in Frontier AI](https://arxiv.org/abs/2607.18239)** (2607.18239) — Azarm, Wei & Nambiar. Seven frontier models as autonomous sysadmins in a high-fidelity Linux sandbox across 2,800 tasks; bias-corrected power-seeking rates land at 0–5% per model.

**[Supra Cognitive Modes: A Routed Architecture for Agent Memory](https://arxiv.org/abs/2607.19096)** (2607.19096) — Tobkin & Yang. Routes each query to a different retrieval/synthesis mode (fused lexical+dense, graph multi-hop, or stratified long-form synthesis) over one shared ingest substrate. Characterised on LoCoMo, MemoryAgentBench and LongMemEval.

Also notable: [Data Leakage Prevention in Agentic Applications via Preemptive Hardening](https://arxiv.org/abs/2607.18847) (scans prompt templates, tool interfaces and invocation code for leakage-enabling patterns, then validates patches under adversarial injection) · [PLAID-PRF](https://arxiv.org/abs/2607.18626) (pseudo-relevance feedback over ColBERT/PLAID by reusing internal centroid vectors) · [SkillSight](https://arxiv.org/abs/2607.18785) (training-free skill retrieval that calibrates away boilerplate shared across skill-library descriptions).
