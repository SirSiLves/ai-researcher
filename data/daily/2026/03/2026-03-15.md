## Research highlights

_Note from collector:_ HF Papers `/date/2026-03-15` redirects to Friday 2026-03-13. Picks below are the strongest items from that Friday cohort surfaced as Sunday backfill.

- **Bridging Protocol and Production: Design Patterns for Deploying AI Agents with Model Context Protocol** — Vasundra Srinivasan. Names three production-deployment gaps in MCP (identity propagation, tool budgeting, error handling) and proposes infrastructure-level patterns to close each. One of the first peer-style papers to treat MCP as a real production protocol rather than a demo surface. _Category:_ arXiv:2603.13417 — agent infrastructure / MCP. [arXiv](https://arxiv.org/abs/2603.13417)
- **Sell Me This Stock: Unsafe Recommendation Drift in LLM Agents** — Zekun Wu, Adriano Koshiyama. LLM recommendation agents faithfully execute manipulated tool data without questioning it; counter-intuitively, stronger models show *worse* safety violations despite higher quality scores. _Category:_ arXiv:2603.12564 — agent safety / alignment. [arXiv](https://arxiv.org/abs/2603.12564)
- **Strategic Navigation or Stochastic Search? How Agents and Humans Reason Over Document Collections** — Łukasz Borchmann, Jordy Van Landeghem. Multimodal agents match human accuracy on document search but rely on brute-force compensation for weak strategic planning — direct relevance to the RAG vs agentic-retrieval debate. _Category:_ arXiv:2603.12180 — RAG / agentic retrieval. [arXiv](https://arxiv.org/abs/2603.12180)
- **Meta-Reinforcement Learning with Self-Reflection for Agentic Search** — Teng Xiao, Yige Yuan. MR-Search lets a search agent learn from cross-episode self-reflection rather than within-episode optimization; concrete agent-memory pattern. _Category:_ arXiv:2603.11327 — agent learning / memory. [arXiv](https://arxiv.org/abs/2603.11327)
- **DIVE: Scaling Diversity in Agentic Task Synthesis for Generalizable Tool Use** — Aili Chen, Chi Zhang. Training-data diversity beats raw quantity for OOD generalization in tool-using LLMs — argument-grade evidence for the "synth-data quality, not size" thesis. _Category:_ arXiv:2603.11076 — synthetic data / tool use. [arXiv](https://arxiv.org/abs/2603.11076)
- **IndexCache: Accelerating Sparse Attention via Cross-Layer Index Reuse** — Yushi Bai, Qian Dong. Reuses top-k token selections across transformer layers to cut sparse-attention indexer compute by ~75%; relevant to long-context inference economics. _Category:_ arXiv:2603.12201 — inference efficiency. [arXiv](https://arxiv.org/abs/2603.12201)
- **Examining Reasoning LLMs-as-Judges in Non-Verifiable LLM Post-Training** — Henry Liu et al. LLM-as-judge reliability for non-verifiable tasks; matters for eval/observability and alignment. _Category:_ arXiv:2603.12246 — evaluation. [arXiv](https://arxiv.org/abs/2603.12246)
- **Video-Based Reward Modeling for Computer-Use Agents** — Lin Xinso et al. Reward-spec for autonomous computer-using agents — direct input to the CUA / browser-agent line. _Category:_ arXiv:2603.10178 — CUA / reward modelling. [arXiv](https://arxiv.org/abs/2603.10178)
