## Research highlights

_Saturday — arXiv doesn't accept Saturday submissions. HF Papers `/date/2026-03-21` redirects to Friday 2026-03-20. Picks below are the strongest items from late-week safety/governance submissions, deduped against the 2026-03-20 daily._

- **Retrieval-Augmented LLM Agents: Learning to Learn from Experience** — Ferraz & Deffayet. Combines fine-tuning with episodic experience retrieval so LLM agents generalize to unfamiliar tasks by reusing past trajectories. _Category:_ arXiv:2603.18272 — agent memory / experience retrieval. [arXiv](https://arxiv.org/abs/2603.18272)
- **Toward Reliable, Safe, and Secure LLMs for Scientific Applications** — Chaturvedi & Bergerson. Multilayered defense framework for autonomous LLM agents in scientific research — threat taxonomy, adversarial benchmarks, proactive internal safeguards. _Category:_ arXiv:2603.18235 — agent safety. [arXiv](https://arxiv.org/abs/2603.18235)
- **AC4A: Access Control for Agents** — Sharma & Grossman. Granular permission framework so LLM agents access only the APIs and web content they need — beyond today's all-or-nothing access model; enforceable surface for agent governance. _Category:_ arXiv:2603.20933 — agent governance. [arXiv](https://arxiv.org/abs/2603.20933)
- **Governing Evolving Memory in LLM Agents (SSGM)** — Lam & Li. Consistency verification, temporal decay modeling, dynamic access control to prevent memory corruption in long-running LLM agent systems. _Category:_ arXiv:2603.11768 — agent memory governance. [arXiv](https://arxiv.org/abs/2603.11768)
- **The Attack and Defense Landscape of Agentic AI: A Comprehensive Survey** — Kim & Liu. Systematically maps attack vectors and defense strategies across LLM-plus-tool agent stacks. Structured threat-model reference for any team productionizing agents. _Category:_ arXiv:2603.11088 — agent security. [arXiv](https://arxiv.org/abs/2603.11088)
- **Security Considerations for Multi-agent Systems** — Nguyen & Ndebugre. Existing frameworks critically miss multi-agent failure modes — non-determinism (1.231 mean score) and inter-agent data leakage are the two most-neglected domains. Argues for MAS-specific controls before A2A scales. _Category:_ arXiv:2603.09002 — multi-agent security. [arXiv](https://arxiv.org/abs/2603.09002)
- **Sell Me This Stock: Unsafe Recommendation Drift in LLM Agents** — Wu, Koshiyama. Stronger models exhibit _worse_ tool-data manipulation susceptibility — counter-intuitive safety result complicating "bigger = safer." _Category:_ arXiv:2603.12564 — agent safety. [arXiv](https://arxiv.org/abs/2603.12564)
- **Bridging Protocol and Production: Design Patterns for Deploying AI Agents with MCP** — Srinivasan. MCP production gaps (identity, tool budgeting, error handling) and infra-level fixes. _Category:_ arXiv:2603.13417 — MCP / production agents. [arXiv](https://arxiv.org/abs/2603.13417)
