## Major news & releases

### Sub-1B agent tier expands

**Liquid AI ships LFM2.5-350M — 350M-parameter agentic-loop model trained on 28T tokens.** Liquid AI released LFM2.5-350M, a 350M-parameter model trained on 28T tokens with scaled RL — engineered specifically for reliable agentic loops, data extraction, and tool use on CPUs, GPUs and mobile (under 500MB quantised). Pitch is "frontier-grade tool-use behaviour in a model small enough for on-device deployment." _Why it matters:_ Joins the OpenAI mini/nano (17 Mar) and the upcoming PrismML "1-bit Bonsai" iPhone-resident model in the spring's sub-1B-parameter agent-tier surge. The 28T-token training pre-conditions LFM2.5 as a true agent specialist — not a chat model that happens to be small. [Build Fast with AI](https://www.buildfastwithai.com/blogs/ai-models-march-2026-releases)

### xAI: structural talent reset

**xAI loses last original co-founder — all 11 founders now gone, Musk in middle of "rebuild from foundations."** TechCrunch reported Saturday that Elon Musk's last remaining xAI co-founder has departed, completing the exodus of all 11 original founders. Comes two weeks after Musk publicly conceded "xAI was not built right first time around, so is being rebuilt from the foundations up." New hires include Andrew Milich, Jason Ginsberg (formerly Cursor) and Devendra Chaplot (Mistral co-founder); Musk and engineering-talent lead Baris Akis are reportedly working through past interview pipelines. _Why it matters:_ The structural-talent question for the third frontier-lab in the U.S. is now a 6-month overhang — directly relevant for procurement teams weighing Grok 4.20 against GPT-5.4 and Claude Opus 4.6 in agentic-deployment RFPs. Coincides with the SpaceX/xAI valuation-merger reframing. [TechCrunch](https://techcrunch.com/2026/03/28/elon-musks-last-co-founder-reportedly-leaves-xai/) · [TheNextWeb](https://thenextweb.com/news/xai-all-cofounders-departed-musk-spacex-rebuild)

## Research highlights

_Saturday — arXiv does not accept Saturday submissions; HF Papers `/date/2026-03-28` redirects to Friday 2026-03-27. Picks below are the strongest Friday-cohort items + late-week submissions surfaced as Saturday backfill, deduped against Friday's daily._

- **FinMCP-Bench: Benchmarking LLM Agents for Real-World Financial Tool Use under MCP** — Jie Zhu, Yimin Tian. 613 samples across 33 financial scenarios and 65 real MCP servers; multi-turn, multi-tool reasoning where actual money would move. Concrete vertical eval the `mcp-adoption` thread has been short on. _Category:_ arXiv:2603.24943 — MCP / finance. [arXiv](https://arxiv.org/abs/2603.24943)
- **MSA: Memory Sparse Attention for Efficient End-to-End Memory Model Scaling to 100M Tokens** — Yu Chen, Runkai Chen. Pushes end-to-end memory models to 100M-token contexts at linear complexity, decoupling memory capacity from reasoning capacity. If it generalizes, it shifts the long-context-vs-RAG cost curve materially. _Category:_ arXiv:2603.23516 — long-context / cs.LG. [arXiv](https://arxiv.org/abs/2603.23516)
- **AVO: Agentic Variation Operators for Autonomous Evolutionary Search** — Terry Chen et al. Autonomous LLM agents replace hand-designed evolutionary operators; **discovers attention kernels that outperform cuDNN and FlashAttention** — real-world demonstration that agentic search can beat expert systems code. _Category:_ arXiv:2603.24517 — agent search / cs.LG. [arXiv](https://arxiv.org/abs/2603.24517)
- **MemMA: Coordinating the Memory Cycle through Multi-Agent Reasoning and In-Situ Self-Evolution** — Minhua Lin, Zhiwei Zhang. Memory as an end-to-end multi-agent cycle: Meta-Thinker plans the forward path while in-situ probe-QA verifies and repairs memory on the backward path. Pairs with the STALE / Mem0 thread. _Category:_ arXiv:2603.18718 — agent memory / cs.AI. [arXiv](https://arxiv.org/abs/2603.18718)
- **SlopCodeBench: How Coding Agents Degrade Over Long-Horizon Iterative Tasks** — Gabriel Orlanski, Devjeet Roy. First benchmark directly measuring code-quality degradation across sequential agent-driven extensions; agent-authored code grows verbose and structurally erodes vs human repos. _Category:_ arXiv:2603.24755 — coding agents / cs.CL. [arXiv](https://arxiv.org/abs/2603.24755)
- **Reaching Beyond the Mode: RL for Distributional Reasoning in Language Models** — Isha Puri, Mehul Damani. Multi-answer RL trains models to emit several candidate answers in a single forward pass — distributional reasoning without expensive repeated sampling. _Category:_ arXiv:2603.24844 — RL / cs.LG. [arXiv](https://arxiv.org/abs/2603.24844)
- **Revisiting On-Policy Distillation: Empirical Failure Modes and Simple Fixes** — Fu, Huang. "Teacher top-K local support matching," a truncated reverse-KL fix that recovers ~20% on standard tasks. _Category:_ arXiv:2603.25562 — post-training / cs.LG. [arXiv](https://arxiv.org/abs/2603.25562)
- **A Coin Flip for Safety: LLM Judges Fail to Reliably Measure Adversarial Robustness** — Schwinn, Ladenburger. 6,642 human-verified labels; LLM-judge agreement on adversarial robustness collapses to near random. Direct hit on the LLM-as-judge eval-stack. _Category:_ arXiv:2603.06594 — eval / safety. [arXiv](https://arxiv.org/abs/2603.06594)
