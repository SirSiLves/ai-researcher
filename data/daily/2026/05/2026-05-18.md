## Research highlights

- **[FORGE: Self-Evolving Agent Memory With No Weight Updates via Population Broadcast](https://arxiv.org/abs/2605.16233)** — Bogdanov, Lung, Kunz, Gao, Taylor, Zaman. Population-based protocol that evolves prompt-injected natural-language memory for hierarchical ReAct agents — failed trajectories become reusable rules, best-performing instance's memory is broadcast, converged instances freeze. Concrete blueprint for self-improving agents without touching model weights.
- **[Differentiable Mixture-of-Agents Incentivizes Swarm Intelligence of LLMs](https://arxiv.org/abs/2605.15706)** — Wu, Lu, Yan et al. Replaces hand-wired multi-agent topologies with a differentiable, context-aware router that dynamically activates agents at each reasoning step — implicitly simulating diverse communication graphs without static workflows. Directly relevant to agent orchestration design.
- **[Agentic Discovery of Neural Architectures: AIRA-Compose and AIRA-Design](https://arxiv.org/abs/2605.15871)** — Pepe, Lin, Magka et al. LLM agents autonomously design foundation-model architectures beyond Transformers — produces 14 AIRAformer/AIRAhybrid (Transformer-Mamba) variants that beat Llama 3.2 at 1B/3B scales and find more compute-efficient frontiers. Tangible recursive self-improvement evidence.
- **[Argus: Evidence Assembly for Scalable Deep Research Agents](https://arxiv.org/abs/2605.16217)** — Zhang, Su, Chen et al. Treats deep research as jigsaw assembly: Searcher gathers evidence per sub-query, Navigator maintains a shared evidence graph and identifies missing pieces. Avoids parallel-ReAct duplication; useful pattern for production research agents (e.g., for this very pipeline).
- **[ICRL: Learning to Internalize Self-Critique with Reinforcement Learning](https://arxiv.org/abs/2605.15224)** — Lin, Yu, Xin et al. Jointly trains solver + critic from a shared backbone; critic is rewarded by the solver's subsequent improvement. Practical recipe for closing the guided-vs-unguided LLM performance gap.
- **[STS: Efficient Sparse Attention with Speculative Token Sparsity](https://arxiv.org/abs/2605.15508)** — Reuses the draft model's attention scores from speculative decoding to build a sparsity mask for the target LLM — 2.67× speedup at ~90% sparsity, no retraining. Particularly relevant for multi-million-token agentic inference.
- **[Towards Generalization of Block Attention via Automatic Segmentation and Block Distillation](https://arxiv.org/abs/2605.15913)** — Two contributions for RAG: a learned semantic segmenter (30k-instance SemanticSeg dataset, 2k–32k texts across 16 categories) plus block distillation, making block attention practical for KV-cache reuse in long-context retrieval pipelines.
- **[Judge Circuits](https://arxiv.org/abs/2605.16023)** — Feldhus, Baeumel, Golimblevskaia et al. Mechanistically locates a shared "Latent Evaluator" sub-graph in mid-to-late MLPs of Gemma-3 / Qwen2.5 / Llama-3 that drives LLM-as-judge scores; zero-ablating it collapses judgment while preserving world knowledge. Explains format-induced inconsistency in LLM eval at the circuit level.
