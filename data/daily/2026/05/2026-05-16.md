## Research highlights

- **[GraphBit: A Graph-based Agentic Framework for Non-Linear Agent Orchestration](https://arxiv.org/abs/2605.13848)** — Sarker, Ullah, Molla, Joty. Engine-orchestrated DAG-based agentic framework (Rust core) that replaces prompted routing with typed function-style agents — fixes hallucinated routing, infinite loops, reproducibility.
- **[Invisible Orchestrators Suppress Protective Behavior and Dissociate Power-Holders](https://arxiv.org/abs/2605.13851)** — Fukui. Empirical evidence that hidden coordinator agents in enterprise multi-agent deployments measurably suppress worker agents' safety behaviors — a concrete failure mode for orchestrator-transparency requirements.
- **[A Two-Dimensional Framework for AI Agent Design Patterns](https://arxiv.org/abs/2605.13850)** — Huang, Zhou. Unifies industry agent guides (Anthropic, Google, LangChain — execution topology) with cognitive-science frameworks (cognitive function) into a two-axis taxonomy useful for choosing/comparing architectures.
- **[PREPING: Building Agent Memory without Tasks](https://arxiv.org/abs/2605.13880)** — Choi et al. Pre-deployment, task-free agent memory construction that closes the cold-start gap when agents are dropped into a new environment.
- **[Deepchecks: Evaluating Retrieval-Augmented Generation (RAG)](https://arxiv.org/abs/2605.14488)** — Gerner et al. Practical evaluation framework for RAG systems — retrieval, grounding, and answer-quality metrics that go beyond exact match.
- **[Why Neighborhoods Matter: Traversal Context and Provenance in Agentic GraphRAG](https://arxiv.org/abs/2605.15109)** — Terrenzi, von Zastrow, Ayvaz. Reframes citation faithfulness for agentic GraphRAG: when an agent walks a knowledge graph, which neighborhood and traversal history must be cited to be truly grounded?
- **[Model-Adaptive Tool Necessity Reveals the Knowing-Doing Gap in LLM Tool Use](https://arxiv.org/abs/2605.14038)** — Cheng et al. Tool necessity is model-dependent, not task-dependent; exposes a knowing-doing gap where models know they should use a tool but don't.
- **[Is Grep All You Need? How Agent Harnesses Reshape Agentic Search](https://arxiv.org/abs/2605.15184)** — Empirical look at how the surrounding agent harness (not just the search tool) determines retrieval quality. Provocative for RAG / search-tool design — pairs directly with the Anthropic Claude Code "no-index" doctrinal post on HN today.
- **[Mechanical Enforcement for LLM Governance: Evidence of Governance-Task Decoupling in Financial Decision Systems](https://arxiv.org/abs/2605.14744)** — Shows prompt-level governance instructions get decoupled from actual task execution in financial LLM systems; argues for mechanical (out-of-band) enforcement.
