## Research highlights

- **[FutureSim: Replaying World Events to Evaluate Adaptive Agents](https://arxiv.org/abs/2605.15188)** — Goel, Chandak, Arun, Prabhu, Staab, Hardt et al. Replay real-world news chronologically so agents are tested on adaptation past training cutoff. Directly attacks the static-eval problem of current agent leaderboards.
- **[STALE: Can LLM Agents Know When Their Memories Are No Longer Valid?](https://arxiv.org/abs/2605.06527)** — Chao, Bai, Sheng, Li, Sun. 400-scenario benchmark for "implicit conflict" — new observations invalidating earlier memory without explicit negation. Current agents fail to revise stored beliefs, a serious gap for long-lived personalized agents.
- **[EvolveMem: Self-Evolving Memory Architecture via AutoResearch for LLM Agents](https://arxiv.org/abs/2605.13941)** — Liu, Ye, Xia, Zheng, Xie, Ding et al. Co-evolves stored content AND retrieval mechanism; exposes the full retrieval config as an action space optimized by an LLM diagnosis module. The strongest concrete RAG-architecture proposal of the week.
- **[MemLens: Benchmarking Multimodal Long-Term Memory in Large Vision-Language Models](https://arxiv.org/abs/2605.14906)** — First systematic head-to-head between long-context LVLMs and memory-augmented agents on 789 multi-session questions across five memory abilities (extraction, multi-session reasoning, temporal, knowledge update, attribution).
- **[From Scenes to Elements: Multi-Granularity Evidence Retrieval for Verifiable Multimodal RAG (GranuRAG)](https://arxiv.org/abs/2605.15019)** — Chen, Huang, Yao, Liu, Song, Chao et al. Treats visual elements as first-class retrieval units with element-level citation grounding (benchmark GranuVistaVQA).
- **[AI Knows When It's Being Watched: Functional Strategic Action and Contextual Register Modulation in LLMs](https://arxiv.org/abs/2605.15034)** — Covas, Hidalgo Toledo. Empirical demonstration that multi-agent LLM systems modulate their language register when they perceive observation — behavioral Hawthorne effect with direct implications for AI auditing validity.
- **[Learning to Build the Environment: Self-Evolving Reasoning RL via Verifiable Environment Synthesis](https://arxiv.org/abs/2605.14392)** — Shi, Liang, Panaganti, Yu, Yu, Mi. Reframes zero-data reasoning RL as an environment-construction loop where the model builds the executable env that grades it; identifies stable solve-verify asymmetry as the property that lets self-improvement compound.
- **[Nexus: An Agentic Framework for Time Series Forecasting](https://arxiv.org/abs/2605.14389)** — Decomposes forecasting into specialized agent stages that fuse Time Series Foundation Models with LLMs for textual/news/event context. Concrete multi-agent blueprint bridging structured + unstructured signals.
