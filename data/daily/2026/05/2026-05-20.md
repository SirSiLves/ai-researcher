## Research highlights

- **[Goal-Oriented Reasoning for RAG-based Memory in Conversational Agentic LLM Systems](https://arxiv.org/abs/2605.12213)** — Long-horizon conversational agents fail not on retrieval but on reasoning over retrieved memory; introduces a goal-conditioned reasoning layer over RAG-based memory modules.
- **[Rethinking RL for LLM Reasoning: It's Sparse Policy Selection, Not Capability Learning](https://arxiv.org/abs/2605.06241)** — Token-level analysis across model families shows RL's benefit is a sparse correction at high-entropy decision points — RL chooses among capabilities the base model already has rather than teaching new ones.
- **[EnergyAgentBench](https://arxiv.org/abs/2605.15230)** — First agentic benchmark grounded in live electricity-market data — 70 task variants across datacenter siting, portfolio optimization, and causal grid diagnosis.
- **[From Storage to Experience: A Survey on the Evolution of LLM Agent Memory Mechanisms](https://arxiv.org/abs/2605.06716)** — Map of how agent memory has moved from KV-store-style retrieval toward experiential, episodic, and self-reflective structures.
- **[Code as Agent Harness](https://arxiv.org/abs/2605.18747)** — Treats generated code as the orchestration substrate for LLM agents, replacing JSON tool-call plumbing with executable programs that drive tool use.
- **[ContextualJailbreak](https://arxiv.org/abs/2605.02647)** — Black-box red-team that runs evolutionary search over simulated multi-turn primed dialogue — pushes jailbreak research beyond single-shot prompt attacks.
- **[Can You Trust the Vectors in Your Vector Database? Black-Hole Attack from Embedding Space Defects](https://arxiv.org/abs/2604.05480)** — Geometric defects in high-dim embeddings create "black holes" that capture up to 99.85% of top-10 retrievals — concrete attack surface for RAG/vector-DB stacks.
- **[MCP Tool Descriptions Are Smelly!](https://arxiv.org/html/2602.14878v2)** — Code-smell-style analysis of MCP tool descriptions; proposes augmented descriptions to cut agent failures.
