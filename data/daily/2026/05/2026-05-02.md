## The day in 90 seconds

**Pentagon's snub of Anthropic becomes a feature, not a bug, as weekend tenants meet Agent 365.**

Saturday consolidated a week of structural moves rather than breaking new ground. Commentary settled on Anthropic's Pentagon exclusion as the cleanest test yet of the values-aligned-commercial-lab thesis, IT teams worldwide opened Microsoft 365 admin consoles to find Agent 365 already in their tenants, and a Hugging Face weekend post quietly turned GPT-OSS-120B into a credible substrate for vertical agentic pipelines.

The Pentagon thread is the one that sticks. Yesterday's news was the procurement event — eight vendors picked, Anthropic left out. Today's coverage on RoboRhythms, MS.Now and DDR Innova reads the split as long-term-positive for Anthropic and short-term-painful only for federal revenue. The commentary frame matters because it is the first time a frontier lab has held a public usage policy against direct federal pressure and accepted being designated a supply-chain risk for it. The cleanest version of the argument — that Goldman, Blackstone and Hellman & Friedman want exactly a lab that can publicly refuse the Pentagon — turns the snub into the reference case for the enterprise-services JV pitch sitting behind the lab's $900B-plus private mark. The eight contracted vendors now share an Impact-Level-6/7 footprint no single competitor controls, and Pentagon officials are repeating the line that they will never again rely on a single AI provider. The bifurcation between federally-aligned compute and commercially-distinct posture is now a market structure, not a one-off.

Underneath that, the operational story of the day was Microsoft Agent 365's first weekend in customer tenants. Friday's GA became Saturday's discovery exercise as admins worldwide started seeing local agent controls, registry sync into AWS Bedrock and Google Cloud, and an Intune/Defender path that absorbs the agent fleet without standing up a separate AI-governance toolchain. WinBuzzer's deep-dive on 2 May names this as the first hyperscaler control plane that treats agents like managed identities — observe, govern, manage and secure them inside the tenant, with runtime alerting via the existing endpoint stack coming in the June preview. The structural read is that enterprise IT now has a credible answer to the "what agentic-AI inventory do we actually have" question, and that answer arrived inside the tools they already pay Microsoft for.

The third thread is the weekend's open-weights motion. MarkTechPost's recap of Mistral Medium 3.5 plus Vibe Remote Agents locks in 77.6 percent on SWE-Bench Verified at $1.50 per million input and $7.50 per million output tokens, with open weights on Hugging Face under a modified MIT licence and a 128-billion-parameter dense backbone running at 256k context. That places it squarely in the Claude Opus / GPT-5.5 frontier band on benchmarks while keeping pricing and licensing on the right side of European procurement, and makes Vibe Remote Agents — cloud-resident parallel coding sessions invokable from CLI or Le Chat — the cleanest open-weight coding-agent option on the market heading into Sapphire 2026. Alongside it, researcher Mehdi Ataei posted Zero-To-CAD on Hugging Face, an agentic synthetic-data pipeline that uses GPT-OSS-120B to produce readable CadQuery programs from natural-language prompts. It is the first non-trivial production-style agentic deployment of OpenAI's open-weight 120B and a meaningful early proof point for the NVIDIA/Siemens manufacturing-AI vertical. Around the edges, Perplexity Computer's Mac-mini-first agent orchestrating Grok 4.1, GPT-5.5 and Claude became the first Mac-native agentic OS from a non-hyperscaler — and the first significant cross-platform integration of an xAI model into a competing agent shell. Indie MCP middleware filled in the consumer end of the same picture: PrePrompt's sub-millisecond prompt rewriting for Claude Code and Cursor, fewshell's mandatory-human-approval SSH copilot, and Verantyx's Privacy Shield obfuscating code before LLM calls all landed as the bottom-up reflection of the same control-plane thesis Agent 365 represents at the enterprise top.

## Research highlights

_Saturday — arXiv does not announce new papers on Saturdays. Picks below are (a) the small Saturday-stamped submissions and (b) Friday-cohort items not used in the 05-01 daily, deduped against it._

- **Feedback-Normalized Developer Memory for Reinforcement-Learning Coding Agents: A Safety-Gated MCP Architecture** — MCP-architected memory layer for RL coding agents that normalizes developer feedback signals through safety-gated controls before they enter the policy update loop. ~80% decision accuracy with robust hard-negative suppression. Sits at the intersection of MCP adoption and agent safety — concrete instantiation of "safety-gated memory." _Category:_ arXiv:2605.01567 — cs.AI. [arXiv](https://arxiv.org/abs/2605.01567)
- **Automated Interpretability and Feature Discovery in Language Models with Agents** — Autonomous multi-agent framework for mechanistic interpretability with two coupled loops — explanation refinement (one agent proposes competing hypotheses) and feature discovery (another generates prompt sets and constructs activation-space graphs). Important data point on whether research agents can do real internal-mechanism science. _Category:_ arXiv:2605.01555 — cs.AI/cs.LG. [arXiv](https://arxiv.org/abs/2605.01555)
- **ControBench: An Interaction-Aware Benchmark for Controversial Discourse Analysis on Social Networks** — Combines social interaction graphs with textual content for analyzing controversial discussions across ideological divides on Reddit. Useful for evaluating LLM-as-judge and content-moderation systems on content where reply context matters as much as text. _Category:_ arXiv:2605.00513 — cs.CL. [arXiv](https://arxiv.org/abs/2605.00513)
- **Rethinking LLM Ensembling from the Perspective of Mixture Models** — Recasts LLM ensembling as a mixture-of-experts inference problem rather than logit-/output-aggregation. Reports a faster, more principled ensembler that recovers what ad-hoc heuristics approximate — useful for inference platforms running multiple frontier models for routing or quality lifts. _Category:_ arXiv:2605.00419 — cs.CL/cs.LG. [arXiv](https://arxiv.org/abs/2605.00419)
- **Synthetic Computers at Scale for Long-Horizon Productivity Simulation** — Constructs 1,000 synthetic computer environments to train computer-use / productivity agents on realistic long-horizon tasks; reports significant in-domain and out-of-domain gains. Concrete throughput contribution to CUA/browser-agent line where data scarcity is the bottleneck. _Category:_ arXiv:2604.28181 — cs.AI. [arXiv](https://arxiv.org/abs/2604.28181)
- **Claw-Eval-Live: A Live Agent Benchmark for Evolving Real-World Workflows** — Live benchmark — even with deterministic grading and structured LLM-judge scoring, the strongest model only hits 66.7% task completion. Sharp eval gap that makes "agents are productionizable" claims testable. _Category:_ arXiv:2604.28139 — cs.AI. [arXiv](https://arxiv.org/abs/2604.28139)
- **FlashRT: Towards Computationally and Memory Efficient Red-Teaming for Prompt Injection and Knowledge Corruption** — 2-7× speedup and 2-4× memory reduction for prompt-injection / RAG-corruption red-teaming — concrete operational win for safety teams running these evals at scale. _Category:_ arXiv:2604.28157 — cs.AI. [arXiv](https://arxiv.org/abs/2604.28157)
- **Safety Drift After Fine-Tuning: Evidence from High-Stakes Domains** — Empirical evidence that domain fine-tuning measurably erodes safety properties even when base-model evals look clean. Direct input to the post-deployment safety-drift governance debate. _Category:_ arXiv:2604.24902 — cs.LG. [arXiv](https://arxiv.org/abs/2604.24902)
