## Research highlights

- **[The Scaling Laws of Skills in LLM Agent Systems](https://arxiv.org/abs/2605.16508)** — Two coupled laws across 15 LLMs, 1,141 skills, 3M+ routing/execution decisions: routing accuracy decays logarithmically with library size; correct execution rescues routing errors by ~4×.
- **[ADR: An Agentic Detection System for Enterprise Agentic AI Security](https://arxiv.org/abs/2605.17380)** — Claims first production-proven enterprise framework for securing MCP-based AI agents; ADR Sensor for agentic telemetry + Expert reasoning layer + cost-aware inference. Direct evidence MCP security tooling is moving from research to deployed product.
- **[TOBench / MM-ToolBench](https://arxiv.org/abs/2605.16909)** — 100 executable tasks, 20 subcategories, 27 MCP servers exposing 324 tools — evaluates tool use, computer use, and multimodal reasoning together rather than in isolation.
- **[Code as Agent Harness](https://arxiv.org/abs/2605.18747)** — Reframes code as the operational substrate for reasoning, acting, environment modeling, and verification — a "harness" view unifying interface, mechanism, and infrastructure layers.
- **[ConflictRAG](https://arxiv.org/abs/2605.17301)** — Two-stage knowledge-conflict detection (embedding MLP + selective LLM refinement) cuts API costs 62% while keeping 90.8% detection accuracy; adds Entropy-TOPSIS source-credibility scorer.
- **[PropGuard](https://arxiv.org/abs/2605.16346)** — Multi-agent prompt-injection defense via dual-view spatio-temporal graph (response-centric risk + full-state evidence) that traces propagation paths and remediates contaminated state without disrupting benign collaboration.
- **[SkillsVote — Lifecycle Governance of Agent Skills](https://arxiv.org/abs/2605.18401)** — Treats Agent Skills as a versioned governed experience schema; profiles a million-scale corpus, synthesizes verifiable tasks, agentic library-search step before execution. The governance complement to today's Scaling Laws paper.
- **[LongMINT](https://arxiv.org/abs/2605.18565)** — Memory-under-interference benchmark for long-horizon agents — closes the gap left by LoCoMo/LongMemEval (dynamic interactions, not just static recall).
