## 🎯 Top reading priorities

**Four, not five.** Only four items could be tied to a verifiable 2026-08-09 publication date. The
usual fifth slot would have to be filled from Friday or Monday material, which would misrepresent

1. **[GitHub Models is now retired](https://simonwillison.net/2026/Aug/9/github-models-is-now-retired/)** — Simon Willison, dated 9 Aug (the URL path carries the dateline). GitHub quietly killed its unified multi-provider model API, which had let GitHub Actions run prompts on the ambient API key. Willison's read: coding-agent usage patterns made subsidised token pools prohibitively expensive. The most consequential thing published on the day itself, and a standing warning for anything built on free or bundled inference.
2. **[One MCP Endpoint, Multiple Tool Servers, Multiple Agents — Who Gets Access to What?](https://www.linkedin.com/pulse/one-mcp-endpoint-multiple-tool-servers-agents-who-gets-tiwary-fkcff)** — Abhishek Tiwary (AWS), dated Aug 9. Proposes deterministic per-agent tool authorization via Amazon Bedrock AgentCore Gateway and Cedar policies, on the premise that MCP standardised how agents talk to tools but never who may call what. Cites >21,000 publicly reachable MCP servers. This is the design-side answer to the 380-of-414 unauthenticated-server audit that dominated 08-08, and it landed on the Sunday in between.
3. **[How I use LLMs to learn complex topics](https://news.ycombinator.com/item?id=49234675)** — submitted 2026-08-09 and the single largest Hacker News item with an 08-09 dateline by a wide margin. A personal-workflow post on using LLMs as a study aid that became a proxy thread for the whole "does AI help or erode learning" argument — the comment volume, not the post, is the artefact.
4. **[Israeli startup was linked to rogue AI hacks at OpenAI, Anthropic and Meta](https://www.cnbc.com/2026/08/09/israeli-startup-irregular-linked-to-ai-hacks-openai-anthropic-meta.html)** — CNBC, 9 Aug (dateline in the URL path). Ties the testing vendor **Irregular** to intrusions across three frontier labs. This closes the loop on the 08-06 Meta Muse Spark disclosure and the 08-07 OpenAI/Hugging Face timeline: the common factor across all three incidents is the evaluation harness, and now it has a named third party attached to it.
