## Research highlights

**[DCAS: Decoupling CLI Agent Scaffolding to Internalize Planning across Scaffolds](https://arxiv.org/abs/2608.06113)** (2608.06113, Waterloo) — The sharpest agent-interoperability result of the batch. CLI coding agents have converged on one training environment (OpenHands); models fine-tuned there score well under OpenHands but degrade substantially under any other scaffold, while untrained base models show no such divergence — so the gap is fine-tuning-induced, not capability. DCAS is an interception layer enabling honest cross-scaffold evaluation. The diagnosis: planning structure is currently a scaffold artifact and needs to become a learned model capability.

**[The Horizon Gap: Planning, Memory, Execution, Training, and Evaluation for Long-Horizon LLM Agents](https://arxiv.org/abs/2608.06663)** (2608.06663) — Surveys 1,547 papers (2024–2026) and does the disambiguation the field keeps fudging: long-horizon (task property) vs. long-context (model property) vs. long-term memory (system property). One pattern everywhere — outcome-only signals go uninformative as horizons lengthen, and every fix is really manufacturing denser step-level signal. Closes on the commercially decisive measurement problem: you cannot currently separate model capability from harness capability. Dovetails exactly with DCAS.

**[CoinRAG: Contextualized Information Nugget KV Cache Reuse for Long-Context RAG](https://arxiv.org/abs/2608.07458)** (2608.07458) — Goes finer-grained than chunk-level KV cache reuse: two-stage retrieval picks query-relevant semantic units *inside* each chunk and assembles their sliced KV representations, cutting prefill cost while gaining 5.3% relative F1 on LongBench multi-hop QA. The prefill-cost lever that decides whether long-context RAG is affordable in production.

**[LLMRouter: Unified Infrastructure for Developing, Evaluating, and Deploying LLM Routers](https://arxiv.org/abs/2608.06867)** (2608.06867) — A single framework covering the whole router lifecycle — train, benchmark, serve — rather than another one-off routing heuristic. The platform layer that last week's "when does orchestration pay off" result implies you need.

**[Zero Gap Is Not Restoration: Stratified Per-Question Probability Evaluation of Benchmark Contamination](https://arxiv.org/abs/2608.07341)** (2608.07341, Zhejiang) — Closing the contamination gap on aggregate is not the same as restoring an uncontaminated benchmark; gives a per-question stratified probability test instead. Directly useful ammunition when a vendor waves a benchmark score.

**[From Test-Time Scaling to Reusable Memory: Measuring Crystallization in Text-to-SQL](https://arxiv.org/abs/2608.07213)** (2608.07213) — Asks whether expensive test-time search can be "crystallized" into reusable memory so the second run is cheap. The economic question behind every agent-memory product, measured on a concrete task with reproduction artifacts released.

**[Exact Adaptive Hybrid Retrieval Without Fixed Top-L Cutoffs](https://arxiv.org/abs/2608.07152)** (2608.07152) — Drops the arbitrary top-L truncation in hybrid sparse+dense retrieval while keeping exactness, removing a tuning knob that quietly caps recall in most production RAG stacks.

**[Skaling: Chinchilla's Exponents Meet Kaplan's Coupling](https://arxiv.org/abs/2608.07222)** (2608.07222, AI at Meta) — Reconciles the two canonical scaling-law families that have disagreed for four years. The kind of result that changes how compute budgets get argued about internally.

_Added from the Tuesday 11 Aug arXiv batch, which landed after the morning pass:_

**[LLM within MCP Matters: Measuring Inefficient Resource Utilization Driven by LLMs](https://arxiv.org/abs/2608.08467)** (2608.08467) — 54,000 trials across 24 models (9 Claude, 6 Gemini, 9 GPT) against a production legal-information MCP server, testing whether clients actually use reference data embedded in *server instructions*. They largely don't — they re-discover the same facts through a search tool. The diagnostic condition is the punchline: remove the competing search tool and 23 of 24 models read the embedded data reliably. Behavioural preference, not missing capability, and it means most MCP server designs are paying for tool calls the instruction payload already answered.

**[MasDrift: Benchmarking Authorization Preservation Across Multi-Agent Architectures](https://arxiv.org/abs/2608.07556)** (2608.07556) — The governance question adversarial red-teaming misses: when a supervisor delegates a goal, does the authorization boundary travel with it? 600 benign productivity tasks across eight domains. Centralized hierarchies win on completion (93.9–98.6% vs 85.7–87.0% for peer networks) but lose badly on authorization — unauthorized actions in 2.7–19.8% of tasks versus 0.6–0.8% — and **the gap widens with hierarchy depth**. A concrete completion-vs-containment curve for anyone choosing a multi-agent topology.

**[Evo-Bench: Can Language Models Improve Agent Harness?](https://arxiv.org/abs/2608.09096)** (2608.09096) — The direct follow-on to DCAS above. Where DCAS showed the harness is a confound, Evo-Bench makes the harness the *measured object*, isolating harness improvement from base-model strength via auxiliary-task evolution — exactly the separation the Horizon Gap survey said the field cannot currently make.

**[Beyond Tier Labels: Role- and Deployment-Dependent Model Substitution in Multi-Call LLM Workflows](https://arxiv.org/abs/2608.09155)** (2608.09155) — Sharpens LLMRouter's problem statement: query-level routing is the wrong granularity, because a model's value depends on *where in a dependent computation it is called*. On solve-merge-verify workflows of 8–64 calls, ladder composition flips the answer — all-strong cuts RMSE 4.818 → 1.538 on a mixed Qwen/GPT ladder while the Qwen-only ordering reverses. Vendor-agnostic routing heuristics are unsafe.

**Also from the Tuesday batch:** [Muscle Memory for Agents: Compile not Merely Retrieve](https://arxiv.org/abs/2608.08995) (2608.08995 — argues agent memory has over-converged on store-and-retrieve, and that personalization wants recurring intent *compiled* into specialist agents; the companion to today's crystallization result); [SuperLocalMemory 4.0](https://arxiv.org/abs/2608.08253) (2608.08253 — the rare agent-memory paper written for a regulated buyer: bi-temporal recall, RBAC, GDPR export and verified erasure, an EU AI Act deployment checklist); [SkillSentry](https://arxiv.org/abs/2608.09253) and [KVDiagnosis](https://arxiv.org/abs/2608.09412); and the skill-supply-chain attack pair [ElasticBack](https://arxiv.org/abs/2608.09577) and [Query-Only Backdoor Attacks on Self-Evolving Skills](https://arxiv.org/abs/2608.08303), which SkillSentry is the enforcement-side answer to.
