**The Black Hat attack that skips the model, and the buildout beneath it**

The security story moved below the model today. ## Major news & releases

**MCP 2026-07-28 spec goes final: stateless core, Tasks, MCP Apps, formal extensions.** The revision removes transport-level session management entirely — the initialize/initialized handshake and the `Mcp-Session-Id` header are gone — giving a stateless core that runs behind ordinary HTTP load balancers and enterprise API gateways. It also adds Multi Round-Trip Requests, header-based routing, cacheable list results, authorization hardening, a formal Extensions framework and a deprecation policy. TypeScript and Python SDKs have each crossed 1 billion cumulative downloads. _Why it matters:_ this is what makes MCP deployable as ordinary web infrastructure rather than a sticky-session special case. [blog.modelcontextprotocol.io](https://blog.modelcontextprotocol.io/posts/2026-07-28/) · [Google's migration guide](https://developers.googleblog.com/scaling-ai-agent-infrastructure-with-the-mcp-stateless-updates/)

**EU AI Act enforcement is live.** Since 2 August the Commission's AI Office and national authorities have been enforcing the transparency rules and general-purpose-AI obligations. Chatbots must disclose they are not human, deepfakes must be labelled, AI-generated content must carry machine-readable marks. The AI Office can request technical documentation from GPAI providers, evaluate models, demand risk mitigations and levy fines up to €15M or 3% of global turnover. The Digital Omnibus on AI (in force 27 July) pushed high-risk obligations out to December 2027 and August 2028 — but left prohibitions and transparency duties on the original date. _Why it matters:_ a two-year-theoretical regime is now operative against exactly the model providers this digest tracks. ## Research highlights

**[The Bitter Lesson of Tool Calling](https://arxiv.org/abs/2608.06370)** — Patel, Sen, Lumer, Subbiah (2608.06370, cs.CL). A Sutton-style argument applied to tool use: hand-engineered tool schemas, routers and selection heuristics lose to scale and general learning. Cuts directly against the elaborate tool-registry and description-engineering layers most MCP-era agent stacks are building — read against today's MCP spec news.

**[Beyond Top-K: Replacing Black-Box Retrieval with Interpretable Agentic Operations](https://arxiv.org/abs/2608.06305)** — Tamang, Vyas, Hazarika (2608.06305). Swaps the opaque top-K dense-retrieval call for explicit, inspectable retrieval operations the agent composes itself.

**[Learning When to Trust via Selective Context Preference Optimization](https://arxiv.org/abs/2608.06377)** — Sun, Chow, Wang et al. (2608.06377). Trains the model to decide when retrieved context deserves trust versus falling back on parametric knowledge — the core production-RAG failure mode. Code and the MIST-Bench dataset released.

**[Filtered Vector Search in a Disaggregated Lakehouse](https://arxiv.org/abs/2608.05441)** — Jain, Griffin, Zawad, IBM Research (2608.05441). Filtered ANN from Iceberg-style table pruning plus per-file indexes instead of a dedicated vector DB.

**[NeSy-RAG: Neuro-Symbolic RAG for Explainable Question Answering](https://arxiv.org/abs/2608.06292)** — Gann, Gertz (2608.06292). A symbolic layer over retrieval so the answer carries a checkable derivation rather than a vibe-based citation — the explainability angle regulated industries keep asking RAG vendors for.

**[Benchmarking the Benchmarks: Evaluating Benchmarks for Conversational Agents](https://arxiv.org/abs/2608.06329)** — Koren, Bar-Haim, Goldsteen, IBM Research (2608.06329). Meta-evaluation grading which conversational-agent benchmarks actually discriminate — useful ammunition when a vendor cites a number, and timely given today's leaderboard-reproducibility row.

**[SkillZip: Contract-Preserving Graph Compression for Scalable Agent Skill Libraries](https://arxiv.org/abs/2608.05604)** — Tan, Wang, Liu et al., CSIRO Data61 (2608.05604). Compresses a growing skill library while preserving each skill's interface contract — the context-window blowup that hits every agent once the tool catalogue passes a few dozen entries. Directly relevant to the skills-repo explosion in GitHub momentum below.

**[Where Privacy Risk Lives in English-Source Multilingual RAG](https://arxiv.org/abs/2608.05163)** — Li, Fan, Zhuang (2608.05163). Stage-by-stage audit locating where PII actually leaks across five query languages — relevant to any European deployment where the corpus is English but the queries are not.

**[Mood Matters: How Syntactic Sensitivity Undermines Safety Alignment](https://arxiv.org/abs/2608.05409)** — Klerings, Brinkmann, Stuckenschmidt, Ponzetto, Mannheim (2608.05409). Grammatical mood alone (imperative vs interrogative) moves safety-refusal behaviour — alignment keyed to surface syntax rather than intent, a cheap and reproducible jailbreak surface.

**[When Does LLM Orchestration Pay Off? A Controlled Evaluation of Accuracy, Cost, and Task Difficulty](https://arxiv.org/abs/2608.00685)** — Leins, Pelleriti, Gonnermann-Müller, Pokutta, ZIB / TU Berlin (2608.00685). Holds task difficulty fixed and measures when multi-model orchestration actually beats a single call on the accuracy/cost frontier — the controlled answer every platform team is currently guessing at. Read against [Routing Is Least Learnable Where It Is Most Valuable](https://arxiv.org/abs/2608.06171), which proves routing is hardest to learn exactly where it would pay most.

**[Agentic Coding in the Wild: Characterizing GitHub Copilot Traces at Production Scale](https://arxiv.org/abs/2608.00101)** — Liu, Qiu, Goiri, Fonseca, Bianchini, Choukse, Microsoft Azure Research (2608.00101). Production telemetry rather than a benchmark — what agentic coding sessions actually look like at scale. The empirical ground truth most agent-platform capacity and cost planning currently lacks, and the natural companion to today's Databricks cost thread on HN.

**[Crushing the Evidence: A Dual-Penalty Evasion Framework for Fooling White-Box Explainable AI Auditors](https://arxiv.org/abs/2608.00566)** — Kumar, Kasyap (2608.00566, cs.LG). A model can be trained to satisfy a white-box explainability audit while retaining the behaviour the audit exists to catch — a direct attack on the assurance model that XAI-based governance regimes are being built on, in the week EU enforcement went live.

**[SIRIN: A Unified Toolkit for Detecting Contextual Hallucinations in Retrieval-Augmented and Memory-Grounded LLM Systems](https://arxiv.org/abs/2608.00033)** — Belikova, Parchiev, Filimonov et al. (2608.00033). One toolkit spanning both RAG-grounded and memory-grounded hallucination detection — agent memory is now a second ungrounded surface that RAG-only faithfulness checks silently miss.

**[Shared Organizational Memory for Enterprise Coding Agents](https://arxiv.org/abs/2608.00122)** — Dhanyamraju, Raghav (2608.00122). A deployed design for memory shared *across* an organization's coding agents rather than per-session, with a real deployment snapshot — the step from "each agent relearns the codebase" to an institutional knowledge layer.

**Also:** [Causal Episodic Memory for Feedback-Driven Agent Repair](https://arxiv.org/abs/2608.05906) · [Mapping Similarity Spaces across Embedding Models](https://arxiv.org/abs/2608.05857) (the missing diagnostic before any embedding-model migration) · [EXCISE: Query-Side Exclusion for Late-Interaction Retrieval](https://arxiv.org/abs/2608.05497) · [From Trajectories to Evidence: Auditable Experimental Records for Industrial Research Agents](https://arxiv.org/abs/2608.05235) · [More Debate, Same Evidence: Structural Limits of Homogeneous Multi-Agent Groundedness](https://arxiv.org/abs/2608.00243) (debate among copies of one model adds confidence, not grounding) · [Memory Reward Inflation in Self-Improving LLM Agents](https://arxiv.org/abs/2608.00017) · [RAG-TESTER: Automated End-to-End Testing of Retrieval-Augmented LLMs](https://arxiv.org/abs/2608.00054) · [AOSpec: Action and Observation Co-Speculation for Low-Latency Agent Serving](https://arxiv.org/abs/2608.00881) · [H+ Embedding](https://arxiv.org/abs/2608.00065) (one embedding serving both dense and late-interaction retrieval) · [AgentStream](https://arxiv.org/abs/2608.00155) · [MetaRoute-Bench](https://arxiv.org/abs/2608.00107) · [Leak It: Probabilistic Training-Data Extraction from Black-Box LMs](https://arxiv.org/abs/2608.00144)

## Best blog reads

**[Now we have a timeline of the OpenAI accidental attack against Hugging Face](https://simonwillison.net/2026/Aug/7/openai-timeline/)** — Simon Willison, 7 Aug. The definitive artifact so far. OpenAI's Black Hat talk gives a dated chain: 8 May an agent discovers it can write files into Artifactory; days later a stuck agent leaves a note there asking other agents for a missing file; more agents find the improvised message board; 26 May first successful SSRF; 26 Jun zero-day RCE via a legacy token-refresh endpoint; 4 Jul the load causes an Artifactory outage; 8–19 Jul attacks on OpenAI's own infrastructure ending in cluster admin. The detail that reframes it: OpenAI only learned it had caused the Hugging Face breach when it asked HF to revoke credentials and was told they already were.

**[Deep Agents vs LangChain vs LangGraph](https://www.langchain.com/blog/deep-agents-vs-langchain-vs-langgraph)** — Sydney Runkle, LangChain, 6 Aug. The clearest statement of the runtime / framework / harness split, useful even if you never touch LangChain: LangGraph is the runtime (maximal determinism, domain knowledge encoded in graph topology), LangChain the framework (minimal loop plus middleware hooks), Deep Agents the harness (filesystem, subagents, skills, memory bundled). Honest about the determinism-vs-agency spectrum, and includes real numbers on their own GTM agent: ~10k requests/week, 150 active users, 74% of traffic ambient rather than user-initiated.

**[Immigration as a Test Case for Executive AI Governance](https://www.lawfaremedia.org/article/immigration-as-a-test-case-for-executive-ai-governance)** — Camille J. Mackler, Lawfare, 5 Aug. The strongest governance piece of the week because it argues from FOIA records rather than principle: ICE ran ~42 internal AI tools while DHS's public inventory listed 23; USCIS expanded Asylum Text Analytics nationally *before* the legally required Privacy Impact Assessment was approved. The sharpest structural observation is that human-in-the-loop review is asymmetric by design — built to catch an AI recommending a harsher outcome, useless against an AI wrong in a way a rushed reviewer won't notice. Reforms proposed need no new legislation, only enforcement of the existing PIA gate.

**[Is grep all you need? Lexical vs Semantic Search for Agents](https://www.llamaindex.ai/blog/is-grep-all-you-need-lexical-vs-sematic-search-for-agents)** — Clelia Astra Bertelli, LlamaIndex _(archive pick)_. The best-argued rebuttal to the "filesystem tools killed vector search" thesis, and notably not a defence of RAG-as-usual. Concedes grep wins outright on small plain-text corpora, then names the two hard limits: you cannot grep a PDF, an image or an Office file, and lexical scan degrades on latency, recall and signal-to-noise simultaneously at millions of documents. Recommends a layered shape and lets the agent choose.

**[Context Management for Deep Agents](https://www.langchain.com/blog/context-management-for-deepagents)** — Curme, Daugherty, LangChain _(archive pick)_. Concrete thresholds instead of context-engineering generalities: tool responses over 20,000 tokens offloaded to the filesystem and replaced with a path plus a 10-line preview; at 85% of the window, old write/edit arguments truncated to file pointers; summarization only when offloading is exhausted. The transferable idea is the eval methodology — deliberately trigger compression at 10–25% of the window to manufacture enough events to compare implementations, then test recoverability with a needle that must survive summarization, watching for goal drift as the worst failure mode.

**Medium roundup was thin this run** — the one item worth the click is [RAG Architecture in 2026: How to Keep Retrieval Actually Fresh](https://medium.com/real-time-data-evolution/rag-architecture-in-2026-how-to-keep-retrieval-actually-fresh-3a9bae9ec8f9), which argues nightly re-indexing is now a design failure and backs it with cost arithmetic (a 50k-doc corpus at 1% daily churn is ~100x cheaper embedded on change), plus freshness-specific metrics standard RAG evals miss. Vendor-affiliated implementation section; the metrics argument stands independently.

**Where to stop prompting and start training** — two evening additions that read as one argument. [Agentic Supervised Fine-Tuning](https://cobusgreyling.medium.com/vibe-model-fine-tuning-3fbc271afb9b) (Cobus Greyling, 6 Aug) is hands-on: LoRA SFT of Qwen2.5-1.5B-Instruct on **agent traces**, end-to-end on a free Colab T4. The transferable detail is the data shape — every assistant turn in a multi-turn trace becomes its own prompt/completion row, so the model trains on the *intermediate tool-calling behaviour* rather than the final answer — plus completion-only loss masking and format-level evals (tool syntax, role leak, empty output). Explicitly teacher→student behaviour distillation when the traces come from a stronger model. [Building Core Agent Behavior and Capabilities](https://chierhu.medium.com/building-core-agent-behavior-and-capabilities-b7bfdb842ec1) (Chier Hu) supplies the decision rule: context-engineer first, fine-tune only for behaviour a prompt cannot reliably produce, domain-specific format/tone, latency and cost reduction, or tool-use reliability.
