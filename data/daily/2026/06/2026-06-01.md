## The day in 90 seconds

**Anthropic starts the IPO clock as the AI-coding business quietly goes metered**

The frontier-lab era took a decisive turn toward Wall Street today: Anthropic confidentially filed for a US IPO, the first lab to do so. Underneath that headline, two structural shifts landed at once — GitHub Copilot switched every plan to usage-based billing, and the enterprise platforms turned third-party agent access into a tollbooth. The throughline is money: AI is no longer priced as a flat subscription, and the companies that own your data have started charging the agents that touch it.

Anthropic said on June 1 it has confidentially filed a draft registration statement with the SEC, formally starting the IPO clock days after closing a $65B Series H at a $965B post-money valuation — up from $380B in February, a number that vaulted it past OpenAI as the most valuable AI startup. A confidential filing keeps the S-1 private for roughly 60 to 90 days, so the public prospectus would surface in late summer, and OpenAI is reported to be just weeks behind with a September target above $1T. This is the first genuine public-market test of frontier-lab economics — whether the revenue and margins justify valuations approaching a trillion dollars — and Hacker News treated the news as such, putting the SEC filing near the top of the board at 215 points and 145 comments.

The less glamorous but more immediately practical story is that the all-you-can-eat AI-coding subscription died today. GitHub Copilot moved every plan to metered "AI Credits" priced at one cent each, consumed against per-model token rates: Pro+ now bundles $39 a month in credits, Business stays $19 per user with $19 in credits, and Enterprise lands at $39 with a matching allowance. Code completions and next-edit suggestions stay unlimited and unmetered, but agentic sessions now bill by consumption. It is the clearest signal yet that escalating inference cost is forcing the entire category onto usage-based pricing, and anyone budgeting agentic-coding spend should read the terms before the promotional summer credits run out. The same logic is reshaping the enterprise: SAP's new API policy (§2.2.2) blocks external agents from independently scheduling or executing calls and forces them through its own Joule layer under A2A, while Salesforce goes the opposite direction — headless, MCP-first, welcoming third-party agents as first-class users — and ServiceNow, SAP, and Workday meter and charge for agent access outright. Whoever owns the system-of-record data is now deciding which agent stack you can use, and billing you for the privilege.

Worth a moment too: the day's single highest-engagement item on Hacker News was not the IPO but PromptArmor's working prompt-injection exploit, which exfiltrates entire workbooks through a ChatGPT-for-Sheets integration — 311 points and 116 comments, outpacing even the Anthropic filing. It is a reminder that agent security is still a live wound, not a solved problem, and that developer skepticism toward LLM tool-use safety is hardening even as the money pours in.

## Research highlights

- **[MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation (2605.27366)](https://arxiv.org/abs/2605.27366)** — Agent framework that autonomously creates, stores, manages and evaluates its own reusable skills; a concrete take on self-improving agent memory.
- **[Detecting Is Not Resolving: The Monitoring–Control Gap in Retrieval-Augmented LLMs (2605.27157)](https://arxiv.org/abs/2605.27157)** — RAG monitoring detects errors but rarely resolves them, quantifying the control gap in retrieval pipelines.
- **[The Attribution Blind Spot: Detecting When LLMs Rely on Memory Rather Than Retrieved Context (2605.26778)](https://arxiv.org/abs/2605.26778)** — A faithfulness diagnostic for whether a RAG model actually used retrieved context vs. parametric memory.
- **[Alignment Tampering: How RLHF Is Exploited to Optimize Misaligned Biases (2605.27355)](https://arxiv.org/abs/2605.27355)** — Shows RLHF pipelines can be exploited to bake in misaligned biases; accepted at ICML 2026.
- **[MemFail: Stress-Testing Failure Modes of LLM Memory Systems (2605.26667)](https://arxiv.org/abs/2605.26667)** — A stress-test benchmark exposing how and when LLM memory subsystems break — useful for agent eval/observability.
- **[How Many Tools Should an LLM Agent See? A Chance-Corrected Answer (2605.24660)](https://arxiv.org/abs/2605.24660)** — Empirical study on tool-registry size vs. agent performance, with a chance-corrected metric.
- **[LDP: An Identity-Aware Protocol for Multi-Agent LLM Systems (2603.08852)](https://arxiv.org/abs/2603.08852)** — An identity-aware interoperability protocol for multi-agent systems, relevant to A2A / agent runtime standards.
- **[Position: AI Safety Requires Effective Controllability (2605.27117)](https://arxiv.org/abs/2605.27117)** — Argues controllability, not just alignment, is the core safety requirement for capable agents.
