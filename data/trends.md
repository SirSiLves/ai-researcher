## Now — 2026-06

The state is now a release variable: in one month the US suspended Anthropic's Fable 5 / Mythos 5 (June 13 — the first state pull of a shipped frontier model), hardened that into a two-lab pre-clearance regime (GPT-5.6 live only to ~20 government-approved partners), then ran the first take-down-then-reinstate cycle June 29–30, lifting controls in exchange for cyber-blocking classifiers — while Brussels moved the opposite way (Annex III high-risk → Dec 2027, Annex I → Aug 2028, the Aug 2 GPAI date holding). Open weights crossed from cost story to capability story: Z.ai's MIT-licensed GLM-5.2 posts 62.1 on SWE-Bench Pro above GPT-5.5's 58.6 — the first open model past the closed flagship on the hardest coding benchmark, a measured ~6.8-month lag — and developers read the export gating as its tailwind. Capital went public and moved below the model: SpaceX's record SPCX IPO put a frontier lab on Nasdaq by proxy (briefly ~$2.25T) before it bought Cursor for $60B, OpenAI taped out its own inference ASIC with Broadcom, and Baseten / Groq / Qualcomm-Modular repriced serving and silicon as the next margin pool. Enterprise agents became a budget line — Gartner's $206.5B for 2026 (+139%) — with ServiceNow / SAP / Workday metering external-agent access, SAP embedding n8n ($5.2B) as the Joule Studio orchestration canvas, and managed agent runtimes (Google Managed Agents, Claude Tag) turning first-party. The new constraint is trust: June ended with the first HN cycle where "you can't trust the big labs" ran as an upvoted majority, aimed at the safety-forward lab on Sonnet 5's launch day — lab reputation now gets priced alongside capability, cost and state-controlled availability.
