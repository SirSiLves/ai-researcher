# AI Papers — 2026-05-07

_Collector: papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

**Governed Collaborative Memory as Artificial Selection in LLM-Based Multi-Agent Systems** — Cuadros et al. _Takeaway:_ Design framework for persistent, governed memory in multi-agent LLM systems with selection regimes (constitutional, metric-based, human-ratified) and layered architecture for provenance and version control. _Category:_ cs.MA. [https://arxiv.org/abs/2605.04264](https://arxiv.org/abs/2605.04264)

**Evolving Idea Graphs with Learnable Edits-and-Commits for Multi-Agent Scientific Ideation** — Dong et al. _Takeaway:_ Graph-based multi-agent ideation framework with learned edit-and-commit control, outperforming text-only coordination methods on novelty, feasibility, clarity across benchmarks. _Category:_ cs.MA. [https://arxiv.org/abs/2605.04922](https://arxiv.org/abs/2605.04922)

**Storage Is Not Memory: A Retrieval-Centered Architecture for Agent Recall** — Adler & Zehavi. _Takeaway:_ Six-layer SQLite-based memory system for agents that preserves verbatim events and retrieves at query-time, achieving 93% accuracy on LoCoMo vs. 61.4% for Mem0. _Category:_ cs.IR/cs.AI. [https://arxiv.org/abs/2605.04897](https://arxiv.org/abs/2605.04897)

**Tree-based Credit Assignment for Multi-Agent Memory System** — Mao et al. _Takeaway:_ RL-based credit assignment for multi-agent memory pipelines (builder–summarizer–retrieval) via tree-structured Monte Carlo averaging, enabling heterogeneous agent specialization without task-specific annotations. _Category:_ cs.MA. [https://arxiv.org/abs/2605.04811](https://arxiv.org/abs/2605.04811)

**GRAIL: Deep Agentic Web Exploration for Agent Discovery** — Xu et al. _Takeaway:_ Sub-400ms agent discovery framework using fine-tuned SLM for capability tagging and pseudo-document expansion; 79× faster than LLM-parsing baselines while outperforming vector search. _Category:_ cs.IR. [https://arxiv.org/abs/2605.02489](https://arxiv.org/abs/2605.02489)

## Other interesting items

- **SWE-WebDevBench: Evaluating Coding Agent Application Platforms as Virtual Software Agencies** (Saxena et al.) — 68-metric evaluation framework for agentic app builders revealing specification bottleneck, frontend-backend decoupling, and security failures across six platforms. [https://arxiv.org/abs/2605.04637](https://arxiv.org/abs/2605.04637)

- **ARMATA: Auto-Regressive Multi-Agent Task Assignment** (Youssef et al.) — End-to-end autoregressive framework unifying allocation and routing, achieving 20% improvement over Google OR-Tools and IBM CPLEX. [https://arxiv.org/abs/2605.04225](https://arxiv.org/abs/2605.04225)

- **Caesar: Deep Agentic Web Exploration for Creative Answer Synthesis** (Liang et al.) — Agentic web traversal with dynamic knowledge graphs for non-obvious retrieval, achieving 13–23% improvement on creative synthesis over prior deep research agents. [https://arxiv.org/abs/2604.20855](https://arxiv.org/abs/2604.20855)

- **Beyond Static Best-of-N: Bayesian List-wise Alignment for LLM-based Recommendation** (Chen et al.) — BLADE framework adapts ranking targets to evolving model capabilities, breaking static performance upper bounds on list-wise metrics (NDCG, fairness, diversity). [https://arxiv.org/abs/2605.04559](https://arxiv.org/abs/2605.04559)

- **Benchmarking Retrieval Strategies for Biomedical Retrieval-Augmented Generation** (2605.02520) — Cross-encoder reranking outperforms dense vector, hybrid, and expansion methods in biomedical RAG; contextual precision 0.852. [https://arxiv.org/abs/2605.02520](https://arxiv.org/abs/2605.02520)

- **TabEmbed: Benchmarking and Learning Generalist Embeddings for Tabular Understanding** (Qiang et al.) — First generalist embedding model for tabular data unifying classification and retrieval; outperforms text embeddings on TabBench. [https://arxiv.org/abs/2605.04962](https://arxiv.org/abs/2605.04962)

- **Terminus-4B: Can a Smaller Model Replace Frontier LLMs at Agentic Execution Tasks?** (2605.03195) — Investigates finetuned small LMs vs. frontier models on terminal execution; cost-efficiency analysis for agentic deployment. [https://arxiv.org/abs/2605.03195](https://arxiv.org/abs/2605.03195)

- **Single-Agent LLMs Outperform Multi-Agent Systems on Multi-Hop Reasoning Under Equal Thinking Token Budgets** (2604.02460) — Normalization of computation reveals single-agent systems can match or exceed multi-agent reasoning under fixed token budgets. [https://arxiv.org/abs/2604.02460](https://arxiv.org/abs/2604.02460)
