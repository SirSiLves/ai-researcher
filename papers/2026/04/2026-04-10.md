# AI Papers — 2026-04-10

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Rethinking Generalization in Reasoning SFT: A Conditional Analysis on Optimization, Data, and Model Capability** — anonymous (cs.CL/cs.LG submission). _Takeaway:_ Systematic conditional analysis showing SFT and RL exhibit asymmetric cross-domain generalization on reasoning — and that reasoning gains and safety degradation track each other. Documents a "dip-and-recovery" pattern in long-CoT training. Sharp empirical input to the RL-for-reasoning-vs-policy-selection debate and to the reasoning-vs-safety tradeoff. _Category:_ arXiv:2604.06628 (cs.CL). [https://arxiv.org/abs/2604.06628](https://arxiv.org/abs/2604.06628)

- **SkillClaw: Let Skills Evolve Collectively with an Agentic Evolver** — anonymous (cs.MA submission). _Takeaway:_ Multi-user agent ecosystem where an autonomous evolver aggregates per-user interactions to refine a shared skill repository — explicit cross-user knowledge transfer with cumulative capability improvement. Pairs naturally with the multi-user-agent thread (Multi-User LLM Agents from 04-13) and the broader skill-library debate. _Category:_ arXiv:2604.08377 (cs.MA). [https://arxiv.org/abs/2604.08377](https://arxiv.org/abs/2604.08377)

- **Externalization in LLM Agents: A Unified Review of Memory, Skills, Protocols and Harness Engineering** — anonymous (cs.MA submission). _Takeaway:_ Position/survey that frames the agent stack as moving from parametric capability to externalized cognitive artifacts (memory, skills, MCP/A2A protocols, harness code). Useful reference for arguing the shape of "what's outside the weights." _Category:_ arXiv:2604.08224 (cs.MA). [https://arxiv.org/abs/2604.08224](https://arxiv.org/abs/2604.08224)

- **MolmoWeb: Open Visual Web Agent and Open Data for the Open Web** — anonymous (cs.MA/cs.AI submission). _Takeaway:_ Open-weight web agent operating purely on screenshots (no HTML or accessibility tree). Mixes synthetic trajectories, human demos, and atomic web-skill trajectories; gains from test-time scaling with parallel rollouts + best-of-N. Direct competitor to closed-source web agents on a level evaluation playing field. _Category:_ arXiv:2604.08516 (cs.MA). [https://arxiv.org/abs/2604.08516](https://arxiv.org/abs/2604.08516)

- **Structured Distillation of Web Agent Capabilities Enables Generalization** — anonymous (cs.MA submission). _Takeaway:_ Uses Gemini 3 Pro as teacher in an agent-as-annotator pipeline (task designer / annotator / supervisor / judge filter) to produce structured synthetic trajectories; open-weight students transfer across WebArena and WorkArena L1. Concrete teacher-student recipe for the open-web-agent thread. _Category:_ arXiv:2604.07776 (cs.MA). [https://arxiv.org/abs/2604.07776](https://arxiv.org/abs/2604.07776)

- **KnowU-Bench: Towards Interactive, Proactive, and Personalized Mobile Agent Evaluation** — anonymous (cs.AI submission). _Takeaway:_ Personalized mobile-agent benchmark that scores true preference inference, consent negotiation, and intervention calibration via an LLM-driven user simulator. Operationalizes "did the agent learn your actual preferences?" beyond turn-level success rates. _Category:_ arXiv:2604.08455 (cs.AI). [https://arxiv.org/abs/2604.08455](https://arxiv.org/abs/2604.08455)

- **Act Wisely: Cultivating Meta-Cognitive Tool Use in Agentic Multimodal Models** — anonymous (cs.MA submission). _Takeaway:_ Argues most agentic-multimodal failures are meta-cognitive (when/whether to invoke a tool), not capability gaps. HDPO decouples accuracy and efficiency into separate optimization channels with a cognitive curriculum. Concrete pattern for the "stop calling tools you don't need" problem in production agent stacks. _Category:_ arXiv:2604.08545 (cs.MA). [https://arxiv.org/abs/2604.08545](https://arxiv.org/abs/2604.08545)

- **Graph of Skills: Dependency-Aware Structural Retrieval for Massive Agent Skills** — anonymous (cs.IR/cs.MA submission). _Takeaway:_ Builds an executable skill graph and retrieves dependency-aware bundles via reverse-weighted Personalized PageRank with context-budgeted hydration. SkillsBench + ALFWorld show reward gains alongside token reduction. Concrete answer to "how do you actually retrieve over a skill library at scale." _Category:_ arXiv:2604.05333 (cs.IR). [https://arxiv.org/abs/2604.05333](https://arxiv.org/abs/2604.05333)

- **Flux Attention: Context-Aware Hybrid Attention for Efficient LLM Inference** — anonymous (cs.LG submission). _Takeaway:_ Lightweight Layer Router decides per-layer whether to use full or sparse attention based on input context; parameter-efficient training with sizable long-context inference speedups. Sits alongside TriAttention as production-side hybrid-attention work. _Category:_ arXiv:2604.07394 (cs.LG). [https://arxiv.org/abs/2604.07394](https://arxiv.org/abs/2604.07394)

- **ImplicitMemBench: Measuring Unconscious Behavioral Adaptation in LLMs** — anonymous (cs.AI submission). _Takeaway:_ Imports cognitive-science constructs (procedural memory, priming, classical conditioning) into an agent benchmark probing implicit-memory effects via first-attempt scoring. Maps a previously invisible axis of agent behavior — relevant to the agent-memory and persona-stability threads. _Category:_ arXiv:2604.08064 (cs.AI). [https://arxiv.org/abs/2604.08064](https://arxiv.org/abs/2604.08064)

- **The Master Key Hypothesis: Cross-Model Capability Transfer via Linear Subspace Alignment** — anonymous (cs.LG submission). _Takeaway:_ Claims a post-trained capability lives in a low-dimensional latent subspace and can be transferred across model scales by linear alignment of "capability directions" — no retraining required. If it holds up, dramatically changes the economics of post-training. _Category:_ arXiv:2604.06377 (cs.LG). [https://arxiv.org/abs/2604.06377](https://arxiv.org/abs/2604.06377)

## Other interesting items

- **[Small Vision-Language Models are Smart Compressors for Long Video Understanding](https://arxiv.org/abs/2604.08120)** — cs.CV/cs.CL. Tempo uses a small VLM for temporal compression with adaptive token allocation; addresses the "lost-in-the-middle" problem in long-video MLLMs.
- **[Automating Database-Native Function Code Synthesis with LLMs](https://arxiv.org/abs/2604.06231)** — cs.SE. DBCooker: LLM pipeline for synthesizing SQLite/PostgreSQL/DuckDB native kernel functions with three-level progressive validation; +34.55% accuracy vs. baselines on real database codebases.
- **[Faithful GRPO: Constrained Policy Optimization for Visual Spatial Reasoning](https://arxiv.org/abs/2604.08476)** — cs.LG. Lagrangian-dual GRPO with explicit consistency and visual grounding constraints — addresses the "hallucinated grounding" failure of RLVR on visual tasks.
- **[OpenVLThinkerV2: Gaussian GRPO for Multimodal Reasoning](https://arxiv.org/abs/2604.08539)** — cs.LG. Distributional matching for advantage shaping in GRPO to ensure gradient equity across task types; generalist multimodal reasoning baseline.
- **[Towards Real-World Human Behavior Simulation (OmniBehavior)](https://arxiv.org/abs/2604.08362)** — cs.CL. Benchmark exposing how current LLMs simulate users with structural bias, hyper-activity, persona homogenization, and Utopian bias — counter-evidence for "LLM as user simulator" pipelines.
