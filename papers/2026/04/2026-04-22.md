# AI Papers — 2026-04-22

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **AgentSPEX: An Agent SPecification and EXecution Language** — anonymous (cs.AI submission). _Takeaway:_ Formal specification + execution language for agents — relevant to the "compile-once, execute-many" pattern (cf. MCP Workflow Engine from May 13) and to making agent behavior auditable. _Category:_ arXiv:2604.13346 (cs.AI). [https://arxiv.org/abs/2604.13346](https://arxiv.org/abs/2604.13346)

- **AJ-Bench: Benchmarking Agent-as-a-Judge for Environment-Aware Evaluation** — anonymous (cs.AI submission). _Takeaway:_ Benchmark for agent-as-a-judge specifically targeting environment-aware (rather than purely outcome-based) evaluation — useful as LLM-judge usage outgrows static rubrics. _Category:_ arXiv:2604.18240 (cs.AI). [https://arxiv.org/abs/2604.18240](https://arxiv.org/abs/2604.18240)

- **TEMPO: Scaling Test-time Training for Large Reasoning Models** — anonymous (cs.LG submission). _Takeaway:_ Test-time training (not just test-time search) for reasoning models, scaled. Concrete instantiation of the "post-training never ends" inference paradigm. _Category:_ arXiv:2604.19295 (cs.LG). [https://arxiv.org/abs/2604.19295](https://arxiv.org/abs/2604.19295)

- **Chat2Workflow: A Benchmark for Generating Executable Visual Workflows from Natural Language** — anonymous (cs.AI submission). _Takeaway:_ Natural-language → executable visual workflow generation — the n8n/Zapier-AI thread getting a proper benchmark. _Category:_ arXiv:2604.19667 (cs.AI). [https://arxiv.org/abs/2604.19667](https://arxiv.org/abs/2604.19667)

- **Dual-View Training for Instruction-Following Information Retrieval** — anonymous (cs.IR submission). _Takeaway:_ Two-view training for instruction-following retrievers — directly relevant to the "follow nuanced retrieval instructions" gap in current dense retrievers (companion to LLM-Based Dense Retriever Robustness from Apr 21). _Category:_ arXiv:2604.18845 (cs.IR). [https://arxiv.org/abs/2604.18845](https://arxiv.org/abs/2604.18845)

- **Code-Switching Information Retrieval: Benchmarks, Analysis, and the Limits of Current Retrievers** — anonymous (cs.IR submission). _Takeaway:_ Code-switched queries (multilingual within a single query) break current retrievers in characteristic ways; introduces benchmark + analysis. Real-world multilingual gap. _Category:_ arXiv:2604.17632 (cs.IR). [https://arxiv.org/abs/2604.17632](https://arxiv.org/abs/2604.17632)

- **SkillLearnBench: Benchmarking Continual Learning Methods for Agent Skill Generation** — anonymous (cs.AI submission). _Takeaway:_ Continual-learning benchmark for agent skill generation — pairs with SkillFlow (Apr 21) as the eval surface for the skill-bank/Voyager-style agent thread. _Category:_ arXiv:2604.20087 (cs.AI). [https://arxiv.org/abs/2604.20087](https://arxiv.org/abs/2604.20087)

- **ClawNet: Human-Symbiotic Agent Network for Cross-User Autonomous Cooperation** — anonymous (cs.MA submission). _Takeaway:_ Multi-agent network designed for cross-user cooperation (different users' agents collaborating) — concrete A2A-style direction with explicit attention to identity boundaries. _Category:_ arXiv:2604.19211 (cs.MA). [https://arxiv.org/abs/2604.19211](https://arxiv.org/abs/2604.19211)

- **Target-Oriented Pretraining Data Selection via Neuron-Activated Graph** — anonymous (cs.LG submission). _Takeaway:_ Pretraining data selection guided by neuron-activation patterns on target tasks — more principled than perplexity-based data filtering. _Category:_ arXiv:2604.15706 (cs.LG). [https://arxiv.org/abs/2604.15706](https://arxiv.org/abs/2604.15706)

- **What Makes an LLM a Good Optimizer? A Trajectory Analysis of LLM-Guided Evolutionary Search** — anonymous (cs.LG submission). _Takeaway:_ Trajectory-level analysis of LLM-as-optimizer behaviors in evolutionary search — relevant to the OPRO / LLM-guided-meta-learning thread and to AutoML-with-LLMs. _Category:_ arXiv:2604.19440 (cs.LG). [https://arxiv.org/abs/2604.19440](https://arxiv.org/abs/2604.19440)

## Other interesting items

- **[Evaluation-driven Scaling for Scientific Discovery](https://arxiv.org/abs/2604.19341)** — cs.LG/cs.AI. Argues evaluation, not compute, is the binding constraint for AI scientific discovery — sharp counter-position to scaling-only narratives.
- **[Micro Language Models Enable Instant Responses](https://arxiv.org/abs/2604.19642)** — cs.CL. Sub-1B models tuned specifically for latency-sensitive deployment — relevant to the SLM thread.
- **[Mitigating Multimodal Hallucination via Phase-wise Self-reward](https://arxiv.org/abs/2604.17982)** — cs.CL. Phase-wise self-reward as a training-free hallucination mitigation for MLLMs.
- **[Chain-of-Thought Degrades Visual Spatial Reasoning Capabilities of Multimodal LLMs](https://arxiv.org/abs/2604.16060)** — cs.CV/cs.CL. Empirical finding that CoT can *hurt* spatial reasoning in MLLMs — important counter-evidence to universal-CoT pro-prescription.
- **[MM-JudgeBias: A Benchmark for Evaluating Compositional Biases in MLLM-as-a-Judge](https://arxiv.org/abs/2604.18164)** — cs.CV/cs.AI. Bias eval for multimodal judges — relevant as MLLM-as-judge enters production.
