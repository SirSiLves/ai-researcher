# AI Papers — 2026-04-01

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **FIPO: Eliciting Deep Reasoning with Future-KL Influenced Policy Optimization** — anonymous (cs.LG submission). _Takeaway:_ RL post-training method using discounted future-KL divergence to fix credit-assignment over long reasoning chains. Argues that vanilla policy-gradient credit dilutes across chain length and proposes a dense advantage that pulls reward signal closer to the steps it actually grades — direct relevance to the "RL for reasoning vs. policy selection" debate. _Category:_ arXiv:2603.19835 (cs.LG). [https://arxiv.org/abs/2603.19835](https://arxiv.org/abs/2603.19835)

- **MonitorBench: A Comprehensive Benchmark for Chain-of-Thought Monitorability** — anonymous (cs.CL submission). _Takeaway:_ Benchmark measuring whether CoTs faithfully reveal the decision-critical factors a model used; finds monitorability drops sharply when structural reasoning isn't required and degrades further under stress-test conditions. Both open- and closed-weight models fail. Useful concrete artifact for the CoT-faithfulness thread (and policy debates that lean on CoT monitorability as a safety property). _Category:_ arXiv:2603.28590 (cs.CL). [https://arxiv.org/abs/2603.28590](https://arxiv.org/abs/2603.28590)

- **Meta-Harness: End-to-End Optimization of Model Harnesses** — anonymous (cs.CL/cs.AI submission). _Takeaway:_ Treats the agent "harness" (context manager, retriever, proposer, scheduler) as a searchable object — an outer-loop optimizer rewrites harness code from execution traces. Reports wins on TerminalBench-2 and retrieval-augmented math; concrete instantiation of "harness as a first-class artifact" rather than a hand-tuned afterthought. _Category:_ arXiv:2603.28052 (cs.CL). [https://arxiv.org/abs/2603.28052](https://arxiv.org/abs/2603.28052)

- **Think Anywhere in Code Generation** — anonymous (cs.CL submission). _Takeaway:_ Lets a code-generation model invoke "thinking" on-demand at high-entropy positions during generation rather than as a single up-front block. Cold-start SFT + outcome RL teaches when to think; reported gains across multiple coding benchmarks. Concrete pattern for adaptive inference-compute allocation that is starting to replace fixed-budget CoT. _Category:_ arXiv:2603.29957 (cs.CL). [https://arxiv.org/abs/2603.29957](https://arxiv.org/abs/2603.29957)

- **daVinci-LLM: Towards the Science of Pretraining** — anonymous (cs.CL submission). _Takeaway:_ Systematic pretraining study with an L0–L9 "Data Darwinism" taxonomy of data-processing depth and adaptive curriculum. Controlled ablations on token scaling and compositional balance — a rare open methodology paper rather than a model release. Useful baseline for pretraining-recipe arguments. _Category:_ arXiv:2603.27164 (cs.CL). [https://arxiv.org/abs/2603.27164](https://arxiv.org/abs/2603.27164)

- **Falcon Perception** — TII Falcon team (cs.CL/cs.CV submission). _Takeaway:_ Dense Transformer that processes image patches and text tokens in shared parameter space from layer 1, using hybrid bidirectional/causal attention. Companion 300M Falcon OCR hits 80.3% olmOCR / 88.64 OmniDocBench. Concrete unified-encoder-decoder design point for document-understanding stacks. _Category:_ arXiv:2603.27365 (cs.CL). [https://arxiv.org/abs/2603.27365](https://arxiv.org/abs/2603.27365)

- **FlowPIE: Test-Time Scientific Idea Evolution with Flow-Guided Literature Exploration** — anonymous (cs.IR/cs.CL submission). _Takeaway:_ Retrieval+generation pipeline for scientific ideation that combines GFlowNet-style flow-guided MCTS with a generative reward model; uses "isolation island" selection/crossover/mutation over literature-grounded candidates. Concrete instance of agentic literature exploration with explicit diversity machinery, beyond plain LLM brainstorming. _Category:_ arXiv:2603.29557 (cs.IR). [https://arxiv.org/abs/2603.29557](https://arxiv.org/abs/2603.29557)

- **GEMS: Agent-Native Multimodal Generation with Memory and Skills** — anonymous (cs.MA/cs.AI submission). _Takeaway:_ Multi-agent framework with persistent trajectory-level memory and domain-specific skills wired into a closed-loop optimizer over generative backends. A concrete agent-platform pattern for orchestrating multiple generation models with feedback — relevant to the agent-framework consolidation thread. _Category:_ arXiv:2603.28088 (cs.MA). [https://arxiv.org/abs/2603.28088](https://arxiv.org/abs/2603.28088)

- **All Roads Lead to Rome: Incentivizing Divergent Thinking in Vision-Language Models** — anonymous (cs.CL/cs.LG submission). _Takeaway:_ Identifies GRPO-style RL collapse into a narrow reasoning mode for VLMs and proposes Multi-Group Policy Optimization to maintain solution diversity. Useful counterweight to the "single best chain" framing of RL post-training. _Category:_ arXiv:2604.00479 (cs.CL). [https://arxiv.org/abs/2604.00479](https://arxiv.org/abs/2604.00479)

## Other interesting items

- **[LongCat-Next: Lexicalizing Modalities as Discrete Tokens](https://arxiv.org/abs/2603.27538)** — cs.CL. Discrete-token multimodal foundation model; argues for representing every modality in a shared discrete space rather than late-fusing encoders.
- **[Dynin-Omni: Omnimodal Unified Large Diffusion Language Model](https://arxiv.org/abs/2604.00007)** — cs.CL. Masked-diffusion omnimodal foundation model unifying text/image/speech/video in a shared discrete token space; alternative to AR omnimodal stacks.
- **[Unify-Agent: A Unified Multimodal Agent for World-Grounded Image Synthesis](https://arxiv.org/abs/2603.29620)** — cs.MA. Agent loop wraps prompt understanding, evidence search, and grounded recaptioning around a generation model — pattern that beats closed-source on FactIP.
