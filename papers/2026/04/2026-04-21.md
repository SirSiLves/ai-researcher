# AI Papers — 2026-04-21

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Agent-World: Scaling Real-World Environment Synthesis for Evolving General Agent Intelligence** — anonymous (cs.AI submission). _Takeaway:_ Synthesizes diverse real-world-like environments at scale for general-purpose agent training — the "environment is the bottleneck" thesis taken seriously. _Category:_ arXiv:2604.18292 (cs.AI). [https://arxiv.org/abs/2604.18292](https://arxiv.org/abs/2604.18292)

- **On the Reliability of Computer Use Agents** — anonymous (cs.AI submission). _Takeaway:_ Reliability-focused evaluation of computer-use agents (Operator, Claude-computer-use class) — moves the conversation from peak capability to failure-mode characterization needed for deployment. _Category:_ arXiv:2604.17849 (cs.AI). [https://arxiv.org/abs/2604.17849](https://arxiv.org/abs/2604.17849)

- **Symbolic Guardrails for Domain-Specific Agents: Stronger Safety and Security Guarantees** — anonymous (cs.AI submission). _Takeaway:_ Symbolic (rather than learned) guardrails for domain agents to obtain provable safety/security properties. Pairs with the ARGUS/AgentTrust line from May 13 reference as a complementary mechanism. _Category:_ arXiv:2604.15579 (cs.AI). [https://arxiv.org/abs/2604.15579](https://arxiv.org/abs/2604.15579)

- **Training LLM Agents for Spontaneous, Reward-Free Self-Evolution via World Knowledge Exploration** — anonymous (cs.AI submission). _Takeaway:_ Self-evolving agent training that proceeds without external reward via world-knowledge exploration — companion to GenericAgent and the broader "agents that improve themselves" thread. _Category:_ arXiv:2604.18131 (cs.AI). [https://arxiv.org/abs/2604.18131](https://arxiv.org/abs/2604.18131)

- **On the Robustness of LLM-Based Dense Retrievers: A Systematic Analysis of Generalizability** — anonymous (cs.IR submission). _Takeaway:_ Systematic robustness analysis of LLM-based dense retrievers — addresses the gap between leaderboard MTEB performance and production behavior under distribution shift. _Category:_ arXiv:2604.16576 (cs.IR). [https://arxiv.org/abs/2604.16576](https://arxiv.org/abs/2604.16576)

- **Terminal Wrench: A Dataset of 331 Reward-Hackable Environments and 3,632 Exploit Trajectories** — anonymous (cs.AI submission). _Takeaway:_ Adversarial dataset of reward-hackable RL environments plus 3.6K exploit trajectories — critical resource for the reward-hacking subfield (see also Apr 23 "Reward Hacking in the Era of Large Models" survey). _Category:_ arXiv:2604.17596 (cs.AI). [https://arxiv.org/abs/2604.17596](https://arxiv.org/abs/2604.17596)

- **EvoMaster: A Foundational Agent Framework for Building Evolving Autonomous Scientific Agents** — anonymous (cs.AI submission). _Takeaway:_ Framework for evolving autonomous scientific agents — meta-level scaffolding for the AI-scientist thread, complementing Mind DeepResearch (Apr 20) and Toward Autonomous Long-Horizon Engineering (Apr 15). _Category:_ arXiv:2604.17406 (cs.AI). [https://arxiv.org/abs/2604.17406](https://arxiv.org/abs/2604.17406)

- **GenericAgent: A Token-Efficient Self-Evolving LLM Agent via Contextual Information Density** — anonymous (cs.AI submission). _Takeaway:_ Self-evolving agent that explicitly optimizes for token-efficiency by densifying contextual information — directly relevant to the "MCP tax" / context-overhead thread. _Category:_ arXiv:2604.17091 (cs.AI). [https://arxiv.org/abs/2604.17091](https://arxiv.org/abs/2604.17091)

- **SkillFlow: Benchmarking Lifelong Skill Discovery and Evolution for Autonomous Agents** — anonymous (cs.AI submission). _Takeaway:_ Lifelong-learning benchmark focused on skill discovery + evolution rather than per-task fine-tuning. Sharp eval surface for the agent-skills-as-memory thread. _Category:_ arXiv:2604.17308 (cs.AI). [https://arxiv.org/abs/2604.17308](https://arxiv.org/abs/2604.17308)

- **When Can LLMs Learn to Reason with Weak Supervision?** — anonymous (cs.LG submission). _Takeaway:_ Identifies conditions under which weak supervision (sparse/noisy outcome signals) actually teaches reasoning vs. fails to. Important for cost-efficient RL post-training design. _Category:_ arXiv:2604.18574 (cs.LG). [https://arxiv.org/abs/2604.18574](https://arxiv.org/abs/2604.18574)

## Other interesting items

- **[Latent Preference Modeling for Cross-Session Personalized Tool Calling](https://arxiv.org/abs/2604.17886)** — cs.AI. Persistent preference modeling across sessions for tool-using agents — agent-memory at the preference level.
- **[Agents Explore but Agents Ignore: LLMs Lack Environmental Curiosity](https://arxiv.org/abs/2604.17609)** — cs.AI. Probes whether LLM agents exhibit anything like exploratory curiosity — finds they explore mechanically without integrating findings.
- **[The Continuity Layer: Why Intelligence Needs an Architecture for What It Carries Forward](https://arxiv.org/abs/2604.17273)** — cs.AI. Position paper on the need for a dedicated "continuity layer" in agent architectures — relevant to the agent-memory and identity thread.
- **[Precise Debugging Benchmark: Is Your Model Debugging or Regenerating?](https://arxiv.org/abs/2604.17338)** — cs.SE/cs.AI. Distinguishes precise localized debugging from full-rewrite regeneration in coding agents — important eval distinction.
- **[VoxMind: An End-to-End Agentic Spoken Dialogue System](https://arxiv.org/abs/2604.15710)** — cs.CL. End-to-end speech-in/speech-out agent — the agentic-voice thread continues to mature.
