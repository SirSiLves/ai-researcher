# AI Papers — 2026-04-14

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **CodeTracer: Towards Traceable Agent States** — anonymous (cs.AI submission). _Takeaway:_ Adds traceability primitives to coding-agent state so trajectories are auditable post-hoc. Directly relevant to the agent-observability radar thread and a building block for enterprise-grade agent platforms. _Category:_ arXiv:2604.11641 (cs.AI). [https://arxiv.org/abs/2604.11641](https://arxiv.org/abs/2604.11641)

- **CocoaBench: Evaluating Unified Digital Agents in the Wild** — anonymous (cs.AI submission). _Takeaway:_ Wild-distribution benchmark for unified digital agents (browser + OS + code) rather than narrow vertical agent benchmarks. Useful eval surface as Operator/Claude-computer-use-style agents proliferate. _Category:_ arXiv:2604.11201 (cs.AI). [https://arxiv.org/abs/2604.11201](https://arxiv.org/abs/2604.11201)

- **Agentic Aggregation for Parallel Scaling of Long-Horizon Agentic Tasks** — anonymous (cs.AI submission). _Takeaway:_ Parallel-scaling pattern specifically for long-horizon agentic tasks — aggregation primitive over multiple agent rollouts rather than single-trajectory deepening. A concrete answer to "what does test-time scaling look like for agents?" _Category:_ arXiv:2604.11753 (cs.AI). [https://arxiv.org/abs/2604.11753](https://arxiv.org/abs/2604.11753)

- **From Reasoning to Agentic: Credit Assignment in RL for LLMs** — anonymous (cs.LG submission). _Takeaway:_ Studies how credit assignment changes when moving from short-horizon reasoning rewards to long-horizon agentic rewards. Concrete RL-design issue that's hitting every team shipping agentic post-training. _Category:_ arXiv:2604.09459 (cs.LG). [https://arxiv.org/abs/2604.09459](https://arxiv.org/abs/2604.09459)

- **SWE-AGILE: A Software Agent Framework for Efficiently Managing Dynamic Reasoning Context** — anonymous (cs.AI submission). _Takeaway:_ Coding agent framework focused on dynamic context management rather than naive full-context injection — addresses the "MCP tax" / context-overhead pattern from a different angle. _Category:_ arXiv:2604.11716 (cs.AI). [https://arxiv.org/abs/2604.11716](https://arxiv.org/abs/2604.11716)

- **The Past Is Not Past: Memory-Enhanced Dynamic Reward Shaping (MEDS)** — Yang Liu, Enxi Wang, Yufei Gao et al. (cs.LG submission). _Takeaway:_ Standard entropy regularization doesn't penalize *recurrent* errors across rollouts. MEDS clusters past failure representations and penalizes rollouts in dense error clusters — up to 4.13 pass@1 gain. Useful fix for RL-collapsing-diversity failure mode. _Category:_ arXiv:2604.11297 (cs.LG). [https://arxiv.org/abs/2604.11297](https://arxiv.org/abs/2604.11297)

- **IceCache: Memory-efficient KV-cache Management for Long-Sequence LLMs** — anonymous (cs.LG submission). _Takeaway:_ KV-cache eviction/compression strategy explicitly designed for long-sequence serving rather than ad-hoc heuristics. Concrete plumbing win for long-context inference economics. _Category:_ arXiv:2604.10539 (cs.LG). [https://arxiv.org/abs/2604.10539](https://arxiv.org/abs/2604.10539)

- **Mobile GUI Agent Privacy Personalization with Trajectory-Induced Preference Optimization** — anonymous (cs.AI submission). _Takeaway:_ Personalizes mobile GUI agents under privacy constraints by deriving preferences from trajectories rather than explicit labels. Important for on-device agent deployment where user-trajectory leakage is a governance issue. _Category:_ arXiv:2604.11259 (cs.AI). [https://arxiv.org/abs/2604.11259](https://arxiv.org/abs/2604.11259)

- **Tracing the Roots: A Multi-Agent Framework for Uncovering Data Lineage in Post-Training LLMs** — anonymous (cs.MA submission). _Takeaway:_ Multi-agent system that reconstructs training data lineage from a post-trained model. Sharply relevant to the "what's in this model" governance/IP thread as open-weights post-training accelerates. _Category:_ arXiv:2604.10480 (cs.MA). [https://arxiv.org/abs/2604.10480](https://arxiv.org/abs/2604.10480)

- **Time is Not a Label: Continuous Phase Rotation for Temporal Knowledge Graphs and Agentic Memory** — anonymous (cs.CL submission). _Takeaway:_ Treats time as a continuous phase rotation rather than a discrete edge label in agent memory graphs — direct contribution to the agent-memory thread (companion to Mem0, MemPalace, etc.). _Category:_ arXiv:2604.11544 (cs.CL). [https://arxiv.org/abs/2604.11544](https://arxiv.org/abs/2604.11544)

## Other interesting items

- **[Low-rank Optimization Trajectories Modeling for LLM RLVR Acceleration](https://arxiv.org/abs/2604.11446)** — cs.LG. Identifies low-rank structure in RLVR optimization trajectories and exploits it to speed up training — practical infra for RL post-training.
- **[Attention Sink in Transformers: A Survey](https://arxiv.org/abs/2604.10098)** — cs.LG. Synthesizing survey of attention-sink phenomenon plus mitigation strategies — useful reference for KV-cache and long-context work.
- **[General365: Benchmarking General Reasoning in LLMs Across Diverse Tasks](https://arxiv.org/abs/2604.11778)** — cs.CL. Broad-coverage reasoning benchmark designed to resist overfitting that has hit narrower benchmarks.
- **[Playing Along: Learning a Double-Agent Defender for Belief Steering via Theory of Mind](https://arxiv.org/abs/2604.11666)** — cs.AI. Defender agent that maintains a model of the attacker's beliefs to steer them — interesting MAS-meets-safety formulation.
