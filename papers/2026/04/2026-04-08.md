# AI Papers — 2026-04-08

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Claw-Eval: Toward Trustworthy Evaluation of Autonomous Agents** — anonymous (cs.AI submission). _Takeaway:_ Multi-modal agent benchmark with trajectory-aware grading (not just final-state checking) and safety/robustness assessments. Uses Pass@k AND Pass^k (success on k consecutive runs) to penalize stochastic flakiness. Concrete eval artifact for the trustworthy-agent-deployment thread. _Category:_ arXiv:2604.06132 (cs.AI). [https://arxiv.org/abs/2604.06132](https://arxiv.org/abs/2604.06132)

- **Learning to Retrieve from Agent Trajectories** — anonymous (cs.IR submission). _Takeaway:_ Argues retrieval models for agentic search should be trained directly on agent interaction trajectories, with weighted optimization that respects "relevance intensity" (a retrieved doc may be partially used downstream). Direct contribution to the agentic-retrieval thread — moves beyond NQ-style labels for agent contexts. _Category:_ arXiv:2604.04949 (cs.IR). [https://arxiv.org/abs/2604.04949](https://arxiv.org/abs/2604.04949)

- **Beyond Accuracy: Unveiling Inefficiency Patterns in Tool-Integrated Reasoning** — anonymous (cs.CL submission). _Takeaway:_ Introduces PTE (Prefill Token Equivalents), a hardware-aware metric that accounts for KV-cache eviction and long tool responses — correlates with actual wall-clock latency far better than raw token counts. Concrete instrumentation for agent-observability stacks evaluating tool-integrated reasoning. _Category:_ arXiv:2604.05404 (cs.CL). [https://arxiv.org/abs/2604.05404](https://arxiv.org/abs/2604.05404)

- **How Well Do Agentic Skills Work in the Wild: Benchmarking LLM Skill Usage in Realistic Settings** — anonymous (cs.AI submission). _Takeaway:_ Skill utilization degrades sharply when skills must be retrieved and refined from a library rather than handcrafted in-context. Targeted query-specific refinement partially restores performance on Terminal-Bench 2.0. Counter-evidence for the optimistic SkillX-style "just build a skill base" framing. _Category:_ arXiv:2604.04323 (cs.AI). [https://arxiv.org/abs/2604.04323](https://arxiv.org/abs/2604.04323)

- **In-Place Test-Time Training** — anonymous (cs.LG submission). _Takeaway:_ Modifies the final projection matrix in MLP blocks via an efficient context-parallel update with a task-aligned next-token-prediction objective at inference. Light-weight version of TTT that fits inside an attention forward pass. Pairs naturally with the Learn-at-Test-Time agent line. _Category:_ arXiv:2604.06169 (cs.LG). [https://arxiv.org/abs/2604.06169](https://arxiv.org/abs/2604.06169)

- **ClawsBench: Evaluating Capability and Safety of LLM Productivity Agents in Simulated Workspaces** — anonymous (cs.AI submission). _Takeaway:_ Productivity-agent benchmark with high-fidelity mock services, deterministic snapshot/restore, and per-step unsafe-action scoring. Probes multi-step sandbox escalation and silent contract modification — failure modes specific to long-running enterprise agents. _Category:_ arXiv:2604.05172 (cs.AI). [https://arxiv.org/abs/2604.05172](https://arxiv.org/abs/2604.05172)

- **MegaTrain: Full-Precision Training of 100B+ Parameter LLMs on a Single GPU** — anonymous (cs.LG submission). _Takeaway:_ Pushes 100B+ full-precision training onto a single GPU via host-memory parameter streaming, gradient offloading, and pipelined double-buffered execution with persistent autograd graphs. Concrete answer to "what's after DeepSpeed ZeRO-3" for the long-tail of researchers training without clusters. _Category:_ arXiv:2604.05091 (cs.LG). [https://arxiv.org/abs/2604.05091](https://arxiv.org/abs/2604.05091)

- **DARE: Diffusion LLM Alignment and Reinforcement Executor** — anonymous (cs.CL/cs.LG submission). _Takeaway:_ Unified post-training stack (SFT + RL + preference optimization + PEFT) for the increasingly fragmented diffusion-LLM landscape (masked-diffusion and block-diffusion). Addresses the "no equivalent of TRL/Axolotl for dLLMs" gap — useful infra artifact for the dLLM thread. _Category:_ arXiv:2604.04215 (cs.LG). [https://arxiv.org/abs/2604.04215](https://arxiv.org/abs/2604.04215)

- **Context-Value-Action Architecture for Value-Driven LLM Agents** — anonymous (cs.AI submission). _Takeaway:_ Decouples action generation from cognitive reasoning via an explicit Value Verifier trained on Schwartz's Basic Human Values + real interaction traces. Argues prompt-driven reasoning amplifies behavioral rigidity and value polarization; CVABench operationalizes the claim. Relevant to the alignment/agent-behavior thread. _Category:_ arXiv:2604.05939 (cs.AI). [https://arxiv.org/abs/2604.05939](https://arxiv.org/abs/2604.05939)

- **REAM: Merging Improves Pruning of Experts in LLMs** — anonymous (cs.LG submission). _Takeaway:_ For MoE compression, router-weighted expert activation merging beats pruning on the Pareto frontier — preserves performance close to uncompressed at significant memory reduction. Concrete recipe for the MoE-on-edge thread. _Category:_ arXiv:2604.04356 (cs.LG). [https://arxiv.org/abs/2604.04356](https://arxiv.org/abs/2604.04356)

## Other interesting items

- **[Paper Circle: Open-source Multi-agent Research Discovery](https://arxiv.org/abs/2604.06170)** — cs.IR. Retrieval + knowledge graph multi-agent pipeline for arXiv discovery + structured review generation.
- **[ACES: Who Tests the Tests? Leave-One-Out AUC Consistency](https://arxiv.org/abs/2604.03922)** — cs.SE. LOO-AUC test ranking for selecting correct candidates from LLM-generated code without an oracle.
- **[MMEmb-R1: Reasoning-Enhanced Multimodal Embedding with Adaptive Control](https://arxiv.org/abs/2604.06156)** — cs.IR. Latent-variable reasoning selectively triggered via RL — fights "always think" overhead in multimodal embeddings.
- **[ThinkTwice: Jointly Optimizing LLMs for Reasoning and Self-Refinement](https://arxiv.org/abs/2604.01591)** — cs.CL. Two-phase GRPO curriculum that jointly trains reasoning and self-refinement rather than treating refinement as a separate pass.
- **[QiMeng-PRepair: Precise Code Repair via Edit-Aware Reward Optimization](https://arxiv.org/abs/2604.05963)** — cs.SE. Edit-aware GRPO that explicitly penalizes over-editing; addresses a real failure mode in coding agents.
