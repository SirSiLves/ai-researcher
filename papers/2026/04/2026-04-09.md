# AI Papers — 2026-04-09

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **RAGEN-2: Reasoning Collapse in Agentic RL** — anonymous (cs.LG submission). _Takeaway:_ Identifies "template collapse" in multi-turn LLM agents: outputs become structurally similar across inputs while entropy looks healthy. Proposes mutual-information proxies and SNR-aware filtering. Sharp diagnostic for the agentic-RL thread — explains why agent RL plateaus even when standard metrics say it shouldn't. _Category:_ arXiv:2604.06268 (cs.LG). [https://arxiv.org/abs/2604.06268](https://arxiv.org/abs/2604.06268)

- **MARS: Enabling Autoregressive Models Multi-Token Generation** — anonymous (cs.CL submission). _Takeaway:_ Fine-tunes off-the-shelf AR LLMs to predict multiple tokens per forward pass without architectural changes (no MTP-style head, no medusa). Maintains accuracy; supports dynamic speed adjustment via confidence thresholding. Practical inference-throughput win for production stacks. _Category:_ arXiv:2604.07023 (cs.CL). [https://arxiv.org/abs/2604.07023](https://arxiv.org/abs/2604.07023)

- **Neural Computers** — anonymous (cs.AI/cs.LG submission). _Takeaway:_ Position-and-prototype paper proposing models that act as runtime systems learning from I/O traces of screen frames and interface primitives — not from explicit programming. Argues this collapses the boundary between video/world models and computer-use agents. Useful framing reference for the world-model + agent convergence thread. _Category:_ arXiv:2604.06425 (cs.AI). [https://arxiv.org/abs/2604.06425](https://arxiv.org/abs/2604.06425)

- **Combee: Scaling Prompt Learning for Self-Improving Language Model Agents** — anonymous (cs.MA submission). _Takeaway:_ Parallel prompt-learning framework using parallel scans, augmented shuffle, and dynamic batch-size control. Cleanly parallelizes the "agent rewrites its own system prompt from traces" loop — addresses the wall-clock bottleneck of self-improving-agent loops. _Category:_ arXiv:2604.04247 (cs.MA). [https://arxiv.org/abs/2604.04247](https://arxiv.org/abs/2604.04247)

- **SEVerA: Verified Synthesis of Self-Evolving Agents** — anonymous (cs.AI submission). _Takeaway:_ Formally Guarded Generative Models combine planner-LLM proposals with first-order-logic specifications and a rejection sampler + verified fallback; integrated GRPO-style fine-tuning on Dafny verification, symbolic math, and policy-compliant tool use. Concrete instantiation of "verifier-in-the-loop" agents for safety-critical synthesis. _Category:_ arXiv:2603.25111 (cs.AI). [https://arxiv.org/abs/2603.25111](https://arxiv.org/abs/2603.25111)

- **Personalized RewardBench: Evaluating Reward Models with Human-Aligned Personalization** — anonymous (cs.LG submission). _Takeaway:_ Benchmark for reward models that scores ability to capture individual user preferences (not just population averages). Correlates with downstream PPO performance better than existing RM benchmarks. Direct relevance to the personalization-eval and RLHF-fragmentation threads. _Category:_ arXiv:2604.07343 (cs.LG). [https://arxiv.org/abs/2604.07343](https://arxiv.org/abs/2604.07343)

- **Qualixar OS: A Universal Operating System for AI Agent Orchestration** — anonymous (cs.MA submission). _Takeaway:_ Production-oriented agent runtime that explicitly bridges MCP, A2A, and a "Universal Command Protocol," with multi-agent topologies (grid/forest/mesh/maker), Q-learning + Bayesian POMDP model routing, JSD drift monitoring, HMAC-signed content attribution, and a skill marketplace. Long feature list, but a useful concrete reference for the agent-platform consolidation thread. _Category:_ arXiv:2604.06392 (cs.MA). [https://arxiv.org/abs/2604.06392](https://arxiv.org/abs/2604.06392)

- **AgentGL: Towards Agentic Graph Learning with LLMs via RL** — anonymous (cs.LG/cs.IR submission). _Takeaway:_ RL framework that exposes graph-native tools to an LLM agent for node classification and link prediction on text-attributed graphs; uses multi-scale exploration and a graph-conditioned curriculum. Sits at the intersection of GNN replacement and tool-using LLMs — concrete signal on whether LLM agents can subsume GNNs. _Category:_ arXiv:2604.05846 (cs.LG). [https://arxiv.org/abs/2604.05846](https://arxiv.org/abs/2604.05846)

- **Improving Semantic Proximity in Information Retrieval through Cross-Lingual Alignment** — anonymous (cs.IR submission). _Takeaway:_ Documents systematic English-bias in multilingual retrieval models for mixed-language pools and proposes a cross-lingual alignment training strategy that fixes it with minimal additional data. Practical for the multilingual-RAG production thread. _Category:_ arXiv:2604.05684 (cs.IR). [https://arxiv.org/abs/2604.05684](https://arxiv.org/abs/2604.05684)

- **The Depth Ceiling: On the Limits of LLMs in Discovering Latent Planning Strategies** — anonymous (cs.CL submission). _Takeaway:_ On graph path-finding, LLMs can execute latent reasoning at varying depths but consistently fail to discover the right multi-step planning strategies — discovery and execution dissociate. Direct evidence that CoT-monitoring captures execution but not strategy selection. _Category:_ arXiv:2604.06427 (cs.CL). [https://arxiv.org/abs/2604.06427](https://arxiv.org/abs/2604.06427)

## Other interesting items

- **[DeonticBench: Reasoning over Rules](https://arxiv.org/abs/2604.04443)** — cs.CL. Benchmark for context-specific deontic reasoning from real legal/policy domains; supports both symbolic (Prolog-style) and CoT approaches.
- **[Graph-Based CoT Pruning for Reducing Redundant Reflections](https://arxiv.org/abs/2604.05643)** — cs.CL. DAG-structured pruning over reasoning traces with explicit branch- and depth-level pruning + length-penalty GRPO; concrete tool for the overthinking thread.
- **[Learning to Hint for Reinforcement Learning](https://arxiv.org/abs/2604.00698)** — cs.LG. Adaptive hinter policy conditioned on reasoner errors to escape GRPO advantage collapse; transfer-weighted reward.
- **[Fast Spatial Memory with Elastic Test-Time Training](https://arxiv.org/abs/2604.07350)** — cs.LG. Fisher-weighted elastic prior plus fast-weight TTT updates resists catastrophic forgetting during long inference adaptation.
- **[On the Step Length Confounding in LLM Reasoning Data Selection](https://arxiv.org/abs/2604.06834)** — cs.CL. Naturalness-based reasoning-data selection silently prefers long traces over high-quality ones; causal debiasing regression fixes it.
