## Top picks

- **LatentRAG: Latent Reasoning and Retrieval for Efficient Agentic RAG** — anon. _Takeaway:_ Shifts agentic RAG's reasoning and subquery generation into continuous latent space, matching explicit agentic RAG quality while cutting inference latency ~90%. _Category:_ arXiv:2605.06285 [cs.IR]. [link](https://arxiv.org/abs/2605.06285)
- **Coordination as an Architectural Layer for LLM-Based Multi-Agent Systems** — anon. _Takeaway:_ Argues 41–87% of multi-agent prod failures are coordination defects, not model capability — proposes treating coordination as a configurable layer separable from agent logic and information access. _Category:_ arXiv:2605.03310 [cs.MA]. [link](https://arxiv.org/abs/2605.03310)
- **Beyond the Black Box: Interpretability of Agentic AI Tool Use** — anon. _Takeaway:_ Uses Sparse Autoencoders + linear probes on model hidden states to predict whether a tool call is needed and how consequential it will be, enabling internal observability for agent risk monitoring. _Category:_ arXiv:2605.06890 [cs.AI]. [link](https://arxiv.org/abs/2605.06890)
- **Bridging Protocol and Production: Design Patterns for Deploying AI Agents with Model Context Protocol** — anon. _Takeaway:_ Three production-deployment patterns for MCP at scale (identity-scoped broker, adaptive timeout budget allocation, structured error recovery) — addresses the gap between the spec and ~10k active servers / 97M monthly SDK downloads. _Category:_ arXiv:2603.13417 [cs.SE]. [link](https://arxiv.org/abs/2603.13417)
- **Embodied Multi-Agent Coordination by Aligning World Models Through Dialogue** — anon. _Takeaway:_ Extends PARTNR with a natural-language dialogue channel between two partially-observable household-robotics agents; shows world-model alignment via grounded dialogue is the bottleneck for collaborative embodied tasks. _Category:_ arXiv:2605.12920 [cs.MA]. [link](https://arxiv.org/abs/2605.12920)
- **TraceFix: Repairing Agent Coordination Protocols with TLA+ Counterexamples** — anon. _Takeaway:_ Verification-first pipeline that synthesizes a multi-agent coordination protocol then iteratively repairs it using TLA+ model-checker counterexamples — formal methods enter agent stacks. _Category:_ arXiv:2605.07935 [cs.MA]. [link](https://arxiv.org/abs/2605.07935)
- **AgentEscapeBench: Evaluating Out-of-Domain Tool-Grounded Reasoning in LLM Agents** — anon. _Takeaway:_ Escape-room-style benchmark probing whether agents can infer, execute, and revise novel tool-use procedures under long-horizon dependencies — targets the over-fit-to-familiar-workflows failure mode. _Category:_ arXiv:2605.07926 [cs.AI]. [link](https://arxiv.org/abs/2605.07926)
- **Learning Agent Routing From Early Experience (BoundaryRouter)** — anon. _Takeaway:_ Training-free router that uses early behavioral experience + rubric-guided reasoning to decide direct-LLM vs. full-agent execution, cutting latency/cost when queries sit inside the base model's capability boundary. _Category:_ arXiv:2605.07180 [cs.AI]. [link](https://arxiv.org/abs/2605.07180)
- **Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces** — anon. _Takeaway:_ Trains multi-agent orchestration end-to-end on orchestration traces rather than per-agent rewards; relevant context for Kimi K2.5's reported PARL stack scaling to 4,000 coordinated steps. _Category:_ arXiv:2605.02801 [cs.LG]. [link](https://arxiv.org/abs/2605.02801)
- **Benchmarking Retrieval Strategies for Biomedical Retrieval-Augmented Generation** — anon. _Takeaway:_ Head-to-head of dense / hybrid BM25+dense / cross-encoder rerank / multi-query expansion / MMR in a biomedical QA RAG pipeline; cross-encoder rerank wins on both composite score (0.827) and contextual precision (0.852). _Category:_ arXiv:2605.02520 [cs.IR]. [link](https://arxiv.org/abs/2605.02520)
- **AI Safety as Control of Irreversibility** — anon. _Takeaway:_ Reframes AI safety as governance of irreversibility under rising decision density — explicitly bridges alignment, security engineering, organizational economics, and institutional design. _Category:_ arXiv:2605.01415 [cs.CY]. [link](https://arxiv.org/abs/2605.01415)
- **Towards Robust LLM Post-Training: Automatic Failure Management for Reinforcement Fine-Tuning** — anon. _Takeaway:_ Practical pipeline for detecting and recovering from RFT failure modes (reward hacking, training collapse, oscillation) that block stable RL post-training at scale. _Category:_ arXiv:2605.04431 [cs.LG]. [link](https://arxiv.org/abs/2605.04431)
