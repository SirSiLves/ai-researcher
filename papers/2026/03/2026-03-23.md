# AI Papers — 2026-03-23

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **The Y-Combinator for LLMs: Solving Long-Context Rot with λ-Calculus** — Amartya Roy, Rasul Tutunov, Xiaotong Ji, Matthieu Zimmer. _Takeaway:_ Recasts long-context degradation as a fixed-point problem and proposes a recursion-based mitigation borrowed from λ-calculus — fresh conceptual angle on "context rot" beyond positional-encoding tweaks. _Category:_ arXiv:2603.20105 (cs.CL). [https://arxiv.org/abs/2603.20105](https://arxiv.org/abs/2603.20105)

- **Hyperagents** — Jenny Zhang, Bingchen Zhao, Wannan Yang, Jakob Foerster. _Takeaway:_ Framework treating agents as compositional functions over other agents — meta-agent architecture that pushes beyond ReAct-style monolithic loops. Relevant to the multi-agent / agent-platform thread. _Category:_ arXiv:2603.19461 (cs.AI). [https://arxiv.org/abs/2603.19461](https://arxiv.org/abs/2603.19461)

- **A Subgoal-driven Framework for Improving Long-Horizon LLM Agents** — Taiyi Wang, Sian Gooding, Florian Hartmann, Oriana Riva. _Takeaway:_ Explicit subgoal decomposition as a structural prior for long-horizon agents — counter to the "scale will solve it" stance with concrete gains on long-task benchmarks. _Category:_ arXiv:2603.19685 (cs.AI). [https://arxiv.org/abs/2603.19685](https://arxiv.org/abs/2603.19685)

- **Breaking the Capability Ceiling of LLM Post-Training by Reintroducing Markov States** — Yurun Yuan, Tengyang Xie. _Takeaway:_ Argues current RL post-training is bottlenecked by collapsing the trajectory into a single state, and reintroduces explicit Markov states to recover headroom — sharp framing for the "RL hits a wall" debate. _Category:_ arXiv:2603.19987 (cs.LG). [https://arxiv.org/abs/2603.19987](https://arxiv.org/abs/2603.19987)

- **LoopRPT: Reinforcement Pre-Training for Looped Language Models** — Guo Tang, Shixin Jiang, Heng Chang, Nuo Chen. _Takeaway:_ Adds RL signal during pretraining of looped/recurrent-depth language models — concrete recipe for the "compute-elastic" architecture line that lets inference spend more passes on hard inputs. _Category:_ arXiv:2603.19714 (cs.CL). [https://arxiv.org/abs/2603.19714](https://arxiv.org/abs/2603.19714)

- **WorldAgents: Can Foundation Image Models be Agents for 3D World Models?** — Ziya Erkoç, Angela Dai, Matthias Nießner. _Takeaway:_ Tests whether foundation image models can act as agents over 3D world models — a probe of where multimodal agents stop being VQA wrappers and start being actual environment-acting policies. _Category:_ arXiv:2603.19708 (cs.AI). [https://arxiv.org/abs/2603.19708](https://arxiv.org/abs/2603.19708)

- **BEAVER: A Training-Free Hierarchical Prompt Compression Method via Structure-Aware Page Selection** — Zhengpei Hu, Kai Li, Dapeng Fu, Chang Zeng. _Takeaway:_ Training-free prompt compression that selects pages hierarchically by structure rather than token-level importance — concrete inference-time mechanism for long-context RAG with realistic doc-chunked inputs. _Category:_ arXiv:2603.19635 (cs.CL). [https://arxiv.org/abs/2603.19635](https://arxiv.org/abs/2603.19635)

- **How Well Does Generative Recommendation Generalize?** — Yijie Ding, Zitian Guo, Jiacheng Li, Letian Peng. _Takeaway:_ Empirical study of generalization in generative recommenders — useful pushback on the rapid claims of "generative recsys replaces collaborative filtering" by quantifying where the gains do and don't transfer. _Category:_ arXiv:2603.19809 (cs.IR). [https://arxiv.org/abs/2603.19809](https://arxiv.org/abs/2603.19809)

- **Reasoning as Compression: Unifying Budget Forcing via the Conditional Information Bottleneck** — Fabio Valerio Massoli, Andrey Kuzmin, Arash Behboodi. _Takeaway:_ Unifies test-time budget-forcing techniques under a conditional information-bottleneck view — useful theoretical scaffold for the proliferating "early-exit / stop thinking" methods. _Category:_ arXiv:2603.08462 (cs.LG). [https://arxiv.org/abs/2603.08462](https://arxiv.org/abs/2603.08462)

- **ProactiveBench: Benchmarking Proactiveness in Multimodal Large Language Models** — Thomas De Min, Subhankar Roy, Stéphane Lathuilière, Elisa Ricci. _Takeaway:_ Evaluates whether multimodal models can initiate useful actions rather than just respond — fills a gap in agent eval where everything is currently passive turn-taking. _Category:_ arXiv:2603.19466 (cs.CL). [https://arxiv.org/abs/2603.19466](https://arxiv.org/abs/2603.19466)

## Other interesting items

- **[HopChain: Multi-Hop Data Synthesis for Generalizable Vision-Language Reasoning](https://arxiv.org/abs/2603.17024)** — Shenzhi Wang et al., cs.CL. Multi-hop synthetic-data recipe for VL reasoning, addressing the lack of explicit multi-hop traces in VL training corpora.
- **[EgoForge: Goal-Directed Egocentric World Simulator](https://arxiv.org/abs/2603.20169)** — Yifan Shen et al., cs.CV. Egocentric world simulator with goal conditioning; useful environment for embodied-agent training.
