## Top picks

- **FinMCP-Bench: Benchmarking LLM Agents for Real-World Financial Tool Use under the Model Context Protocol** — Jie Zhu, Yimin Tian. _Takeaway:_ First MCP-native benchmark with 613 samples across 33 financial scenarios and 65 real MCP servers; tests multi-turn, multi-tool reasoning where actual money would move. Concrete vertical eval that the `mcp-adoption` thread has been short on. _Category:_ arXiv:2603.24943. [https://arxiv.org/abs/2603.24943](https://arxiv.org/abs/2603.24943)
- **MSA: Memory Sparse Attention for Efficient End-to-End Memory Model Scaling to 100M Tokens** — Yu Chen, Runkai Chen. _Takeaway:_ Sparse attention scheme that pushes end-to-end memory models to 100M-token contexts at linear complexity, decoupling memory capacity from reasoning capacity. If it generalizes, it shifts the long-context-vs-RAG cost curve materially. _Category:_ arXiv:2603.23516. [https://arxiv.org/abs/2603.23516](https://arxiv.org/abs/2603.23516)
- **MemMA: Coordinating the Memory Cycle through Multi-Agent Reasoning and In-Situ Self-Evolution** — Minhua Lin, Zhiwei Zhang. _Takeaway:_ Treats memory as an end-to-end multi-agent cycle: a Meta-Thinker plans the forward path while in-situ probe-QA verifies and repairs memory on the backward path. Pairs cleanly with the STALE / Mem0 thread on memory-validity detection. _Category:_ arXiv:2603.18718. [https://arxiv.org/abs/2603.18718](https://arxiv.org/abs/2603.18718)
- **AVO: Agentic Variation Operators for Autonomous Evolutionary Search** — Terry Chen, Zhifan Ye. _Takeaway:_ Replaces hand-designed evolutionary operators with autonomous LLM agents that self-direct optimization; discovered attention kernels that outperform cuDNN and FlashAttention. A real-world demonstration that agentic search can beat expert-engineered systems code, not just write boilerplate. _Category:_ arXiv:2603.24517. [https://arxiv.org/abs/2603.24517](https://arxiv.org/abs/2603.24517)
- **SlopCodeBench: Benchmarking How Coding Agents Degrade Over Long-Horizon Iterative Tasks** — Gabriel Orlanski, Devjeet Roy. _Takeaway:_ First benchmark to directly measure code-quality degradation across sequential agent-driven extensions, finding agent-authored code grows verbose and structurally erodes versus human repos. Useful counterweight to SWE-bench-style single-shot leaderboards. _Category:_ arXiv:2603.24755. [https://arxiv.org/abs/2603.24755](https://arxiv.org/abs/2603.24755)
- **Reaching Beyond the Mode: RL for Distributional Reasoning in Language Models** — Isha Puri, Mehul Damani. _Takeaway:_ Multi-answer RL trains models to emit several candidate answers in a single forward pass, getting distributional reasoning without expensive repeated sampling. Cheap test-time uplift for any task where the modal answer is not the right answer. _Category:_ arXiv:2603.24844. [https://arxiv.org/abs/2603.24844](https://arxiv.org/abs/2603.24844)

## Other interesting items

- **[Revisiting On-Policy Distillation: Empirical Failure Modes and Simple Fixes](https://arxiv.org/abs/2603.25562)** — Fu, Huang. Identifies practical failure modes in token-level on-policy distillation and proposes "teacher top-K local support matching," a truncated reverse-KL fix that recovers ~20% on standard tasks. Tighter recipe for the post-training stack.
- **[SoK: Agentic Retrieval-Augmented Generation: Taxonomy, Architectures, Evaluation, and Research Directions](https://arxiv.org/abs/2603.07379)** — Mishra, Niroula. Formalizes agentic RAG as an MDP and names compounding hallucination propagation and memory poisoning as the open evaluation gaps current static benchmarks miss.
- **[A Coin Flip for Safety: LLM Judges Fail to Reliably Measure Adversarial Robustness](https://arxiv.org/abs/2603.06594)** — Schwinn, Ladenburger. With 6,642 human-verified labels, LLM-judge agreement on adversarial robustness collapses to near random — direct hit on the LLM-as-judge eval-stack.
- **[AgenticCyOps: Securing Multi-Agentic AI Integration in Enterprise Cyber Operations](https://arxiv.org/abs/2603.09134)** — Mitra, Patel. Names tool orchestration and memory management as the two dominant attack surfaces in multi-agent LLM systems and reports a 72% reduction in exploitable trust boundaries against a flat MAS baseline.
