## Top picks

- **CUA-Suite: Massive Human-annotated Video Demonstrations for Computer-Use Agents** — Xiangru Jian, Shravan Nayak, Kevin Qinghong Lin, Aarash Feizi et al. _Takeaway:_ Large-scale human-annotated demonstration corpus for computer-use agents — addresses the trajectory-data bottleneck that has kept open CUA work behind closed-lab systems. Concrete training artifact for the CUA stack. _Category:_ arXiv:2603.24440 (cs.CL). [https://arxiv.org/abs/2603.24440](https://arxiv.org/abs/2603.24440)

- **UI-Voyager: A Self-Evolving GUI Agent Learning via Failed Experience** — Zichuan Lin, Feiyu Liu, Yijun Yang, Jiafei Lyu. _Takeaway:_ Self-evolving GUI agent that learns specifically from failed trajectories — concrete instantiation of the "failure as training signal" line for the GUI/CUA thread. _Category:_ arXiv:2603.24533 (cs.AI). [https://arxiv.org/abs/2603.24533](https://arxiv.org/abs/2603.24533)

- **Why Does Self-Distillation (Sometimes) Degrade the Reasoning Capability of LLMs?** — Jeonghye Kim, Xufang Luo, Minbeom Kim, Sangmook Lee. _Takeaway:_ Diagnoses a recurring failure mode in self-distillation pipelines where reasoning degrades; useful counter-evidence for the "free lunch" framing of self-distill stacks. _Category:_ arXiv:2603.24472 (cs.CL). [https://arxiv.org/abs/2603.24472](https://arxiv.org/abs/2603.24472)

- **T-MAP: Red-Teaming LLM Agents with Trajectory-aware Evolutionary Search** — Hyomin Lee, Sangwoo Park, Yumin Choi, Sohyun An. _Takeaway:_ Red-team agent that uses trajectory-aware evolutionary search to find jailbreaks/exploits in target agents — concrete safety-eval instrument with relevance to the agent-governance radar. _Category:_ arXiv:2603.22341 (cs.CL). [https://arxiv.org/abs/2603.22341](https://arxiv.org/abs/2603.22341)

- **Understanding the Challenges in Iterative Generative Optimization with LLMs** — Allen Nie, Xavier Daull, Zhiyi Kuang, Abhinav Akkiraju. _Takeaway:_ Failure-mode analysis of iterative generative optimization (DSPy/MIPRO-style loops) — characterizes when the loop helps vs. when it churns. Useful empirical anchor for the agent-platform/prompt-search thread. _Category:_ arXiv:2603.23994 (cs.CL). [https://arxiv.org/abs/2603.23994](https://arxiv.org/abs/2603.23994)

- **Can LLM Agents Be CFOs? A Benchmark for Resource Allocation in Dynamic Enterprise Environments** — Yi Han, Lingfei Qian, Yan Wang, Yueru He. _Takeaway:_ Benchmark of dynamic resource-allocation under enterprise constraints — pushes agent eval past static toolbench into stateful budget-and-priority decisions. Useful for the enterprise-agent thread. _Category:_ arXiv:2603.23638 (cs.CL). [https://arxiv.org/abs/2603.23638](https://arxiv.org/abs/2603.23638)

- **CarePilot: A Multi-Agent Framework for Long-Horizon Computer Task Automation in Healthcare** — Akash Ghosh, Tajamul Ashraf, Rishu Kumar Singh, Numan Saeed. _Takeaway:_ Multi-agent CUA framework for long-horizon healthcare tasks — useful domain-specific stress test where compliance, audit, and stateful workflow are first-class. _Category:_ arXiv:2603.24157 (cs.CL). [https://arxiv.org/abs/2603.24157](https://arxiv.org/abs/2603.24157)

- **EVA: Efficient Reinforcement Learning for End-to-End Video Agent** — Yaolun Zhang, Ruohui Wang, Jiahao Wang, Yepeng Tang. _Takeaway:_ End-to-end RL recipe for video agents — concrete artifact for the still-thin literature on RL training of long-context multimodal agents. _Category:_ arXiv:2603.22918 (cs.CL). [https://arxiv.org/abs/2603.22918](https://arxiv.org/abs/2603.22918)

- **When Models Judge Themselves: Unsupervised Self-Evolution for Multimodal Reasoning** — Zhengxian Wu, Kai Shi, Chuanrui Zhang, Zirui Liao. _Takeaway:_ Self-judging unsupervised self-evolution for MLLM reasoning — relevant data point for the contested claim that models can bootstrap reasoning without external verifiers. _Category:_ arXiv:2603.21289 (cs.CL). [https://arxiv.org/abs/2603.21289](https://arxiv.org/abs/2603.21289)

- **GameplayQA: A Benchmarking Framework for Decision-Dense POV-Synced Multi-Video Understanding of 3D Virtual Agents** — Yunzhe Wang, Runhui Xu, Kexin Zheng, Tianyi Zhang. _Takeaway:_ Decision-dense multi-video QA for 3D virtual agents — fills the "decision rather than description" gap in video-LLM evaluation. _Category:_ arXiv:2603.24329 (cs.CL). [https://arxiv.org/abs/2603.24329](https://arxiv.org/abs/2603.24329)
