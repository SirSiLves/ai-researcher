## Top picks

- **Towards a Medical AI Scientist** — Hongtao Wu, Boyun Zheng, Dingjie Song, Yu Jiang. _Takeaway:_ Builds toward an AI-scientist agent specifically grounded in medical research workflows — useful pushback on the generic "deep research" framing by attaching the agent to domain-specific verification and audit. _Category:_ arXiv:2603.28589 (cs.CL). [https://arxiv.org/abs/2603.28589](https://arxiv.org/abs/2603.28589)

- **Emergent Social Intelligence Risks in Generative Multi-Agent Systems** — Yue Huang, Yu Jiang, Wenjie Wang, Haomin Zhuang. _Takeaway:_ Identifies emergent social-intelligence risks specific to multi-agent generative systems — direct contribution to the still-thin governance literature on agent-to-agent dynamics beyond single-agent jailbreaks. _Category:_ arXiv:2603.27771 (cs.CL). [https://arxiv.org/abs/2603.27771](https://arxiv.org/abs/2603.27771)

- **EpochX: Building the Infrastructure for an Emergent Agent Civilization** — Huacan Wang, Chaofa Yuan, Xialie Zhuang, Tu Hu. _Takeaway:_ Infrastructure paper for large-scale multi-agent systems with persistent state — concrete framework for the agent-platform / multi-agent-society thread that has been mostly toy environments. _Category:_ arXiv:2603.27304 (cs.MA). [https://arxiv.org/abs/2603.27304](https://arxiv.org/abs/2603.27304)

- **Marco DeepResearch: Unlocking Efficient Deep Research Agents via Verification-Centric Design** — Bin Zhu, Qianghuai Jia, Tian Lan, Junyang Ren. _Takeaway:_ Recenters deep-research agent design around verification rather than generation — concrete recipe for cutting the wall-clock and token cost of deep-research stacks. _Category:_ arXiv:2603.28376 (cs.CL). [https://arxiv.org/abs/2603.28376](https://arxiv.org/abs/2603.28376)

- **Gen-Searcher: Reinforcing Agentic Search for Image Generation** — Kaituo Feng, Manyuan Zhang, Shuang Chen, Yunlong Lin. _Takeaway:_ Adds agentic search loops with RL to image-generation pipelines — concrete extension of the agentic-RL paradigm beyond text into visual generation. _Category:_ arXiv:2603.28767 (cs.CV). [https://arxiv.org/abs/2603.28767](https://arxiv.org/abs/2603.28767)

- **Kernel-Smith: A Unified Recipe for Evolutionary Kernel Optimization** — He Du, Qiming Ge, Jiakai Hu, Aijun Yang. _Takeaway:_ Evolutionary optimization recipe for GPU kernels driven by LLMs — concrete entry in the "LLMs writing performance-critical systems code" line that has emerged alongside DeepSeek-V3-style kernel work. _Category:_ arXiv:2603.28342 (cs.LG). [https://arxiv.org/abs/2603.28342](https://arxiv.org/abs/2603.28342)

- **TAPS: Task Aware Proposal Distributions for Speculative Sampling** — Mohamad Zbib, Mohamad Bazzi, Ammar Mohanna, Hasan Abed Al Kader Hammoud. _Takeaway:_ Task-aware proposals for speculative decoding — concrete inference-stack mechanism that targets the well-known low-acceptance regime where speculative gains evaporate. _Category:_ arXiv:2603.27027 (cs.CL). [https://arxiv.org/abs/2603.27027](https://arxiv.org/abs/2603.27027)

- **HISA: Efficient Hierarchical Indexing for Fine-Grained Sparse Attention** — Yufei Xu, Fanxu Meng, Fan Jiang, Yuxuan Wang. _Takeaway:_ Hierarchical indexing for fine-grained sparse attention — concrete long-context architecture mechanism with claims of both fidelity and throughput. _Category:_ arXiv:2603.28458 (cs.LG). [https://arxiv.org/abs/2603.28458](https://arxiv.org/abs/2603.28458)

- **On Token's Dilemma: Dynamic MoE with Drift-Aware Token Assignment for Continual Learning of Large Vision Language Models** — Chongyang Zhao, Mingsong Li, Haodong Lu, Dong Gong. _Takeaway:_ Dynamic MoE routing with drift awareness for continual VLM training — relevant to the MoE / continual-learning intersection that production VLMs increasingly need. _Category:_ arXiv:2603.27481 (cs.LG). [https://arxiv.org/abs/2603.27481](https://arxiv.org/abs/2603.27481)

- **MuSEAgent: A Multimodal Reasoning Agent with Stateful Experiences** — Shijian Wang, Jiarui Jin, Runhao Fu, Zexuan Yan. _Takeaway:_ Multimodal reasoning agent built around explicit stateful experience memory — concrete instantiation of the "agent memory as first-class component" thread for the multimodal setting. _Category:_ arXiv:2603.27813 (cs.CL). [https://arxiv.org/abs/2603.27813](https://arxiv.org/abs/2603.27813)
