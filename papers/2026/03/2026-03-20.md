# AI Papers — 2026-03-20

_Collector: ai-papers. Slice: ArXiv (cs.CL, cs.AI, cs.LG, cs.MA, stat.ML, cs.IR), HF Papers, papers.cool._

## Top picks

- **Nemotron-Cascade 2: Post-Training LLMs with Cascade RL and Multi-Domain On-Policy Distillation** — Zhuolin Yang, Zihan Liu, Yang Chen et al. _Takeaway:_ NVIDIA post-training recipe combining cascade RL with multi-domain on-policy distillation — concrete reference for the "RL-first then distill" pipeline replacing the older SFT-then-RLHF default. _Category:_ arXiv:2603.19220 (cs.CL). [https://arxiv.org/abs/2603.19220](https://arxiv.org/abs/2603.19220)

- **Memento-Skills: Let Agents Design Agents** — Huichi Zhou, Siyuan Guo, Anjie Liu et al. _Takeaway:_ Meta-agent framework where agents construct skill modules that downstream agents reuse — concrete pattern for the "agents that build agents" thread in agent-platform research. _Category:_ arXiv:2603.18743 (cs.AI). [https://arxiv.org/abs/2603.18743](https://arxiv.org/abs/2603.18743)

- **F2LLM-v2: Inclusive, Performant, and Efficient Embeddings for a Multilingual World** — Ziyin Zhang, Zihan Liao, Hang Yu, Peng Di. _Takeaway:_ Updated open embedding model targeting multilingual coverage at production efficiency — relevant for the RAG/retrieval thread where MTEB-style English-only embeddings still dominate. _Category:_ arXiv:2603.19223 (cs.CL). [https://arxiv.org/abs/2603.19223](https://arxiv.org/abs/2603.19223)

- **AndroTMem: From Interaction Trajectories to Anchored Memory in Long-Horizon GUI Agents** — Yibo Shi, Jungang Li, Linghao Zhang et al. _Takeaway:_ Builds anchored memory representations from GUI agent interaction trajectories — direct response to the well-documented failure mode where mobile/computer-use agents lose context across sessions. _Category:_ arXiv:2603.18429 (cs.CL). [https://arxiv.org/abs/2603.18429](https://arxiv.org/abs/2603.18429)

- **ProRL Agent: Rollout-as-a-Service for RL Training of Multi-Turn LLM Agents** — Hao Zhang, Mingjie Liu, Shaokun Zhang et al. _Takeaway:_ Disaggregates rollout collection from policy updates for multi-turn agent RL training — addresses the throughput bottleneck that has limited agent-RL at scale. Concrete infrastructure paper for agent training platforms. _Category:_ arXiv:2603.18815 (cs.LG). [https://arxiv.org/abs/2603.18815](https://arxiv.org/abs/2603.18815)

- **VTC-Bench: Evaluating Agentic Multimodal Models via Compositional Visual Tool Chaining** — Xuanyu Zhu, Yuhao Dong, Rundong Wang, Yang Shi. _Takeaway:_ Benchmark for multimodal agents that must chain visual tools compositionally — the "tool-use eval for VLM agents" gap that LMM benchmarks haven't covered. _Category:_ arXiv:2603.15030 (cs.CL). [https://arxiv.org/abs/2603.15030](https://arxiv.org/abs/2603.15030)

- **LVOmniBench: Pioneering Long Audio-Video Understanding Evaluation for Omnimodal LLMs** — Keda Tao, Yuhua Zheng, Jia Xu, Wenjie Du. _Takeaway:_ First serious long-form joint AV evaluation for omnimodal LLMs — useful counterpart to the long-text-only context-rot literature now extending into multimodal. _Category:_ arXiv:2603.19217 (cs.CL). [https://arxiv.org/abs/2603.19217](https://arxiv.org/abs/2603.19217)

- **Tinted Frames: Question Framing Blinds Vision-Language Models** — Wan-Cyuan Fan, Jiayun Luo, Declan Kutscher, Leonid Sigal. _Takeaway:_ Shows VLM answers are dominated by linguistic framing of the question, with visual evidence overridden — sharp adversarial-eval signal for the "are VLMs actually looking?" debate. _Category:_ arXiv:2603.19203 (cs.CL). [https://arxiv.org/abs/2603.19203](https://arxiv.org/abs/2603.19203)

- **Cognitive Mismatch in Multimodal Large Language Models for Discrete Symbol Understanding** — Yinghui Li, Jiayi Kuang, Peng Xing, Daixian Liu. _Takeaway:_ Diagnoses systematic mismatch in how MLLMs encode discrete symbols across modalities — concrete failure-mode characterization rather than yet another benchmark number. _Category:_ arXiv:2603.18472 (cs.CL). [https://arxiv.org/abs/2603.18472](https://arxiv.org/abs/2603.18472)

## Other interesting items

- **[Loc3R-VLM: Language-based Localization and 3D Reasoning with Vision-Language Models](https://arxiv.org/abs/2603.18002)** — Kevin Qu et al., cs.CL. Grounds language-conditioned localization into 3D reasoning via a unified VLM interface.
- **[SimulU: Training-free Policy for Long-form Simultaneous Speech-to-Speech Translation](https://arxiv.org/abs/2603.16924)** — Amirbek Djanibekov et al., cs.CL. Training-free policy for long-form simultaneous S2ST; useful baseline for streaming-translation agent stacks.
