## Top picks

- **Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces** — _Takeaway:_ Formalizes "orchestration traces" (spawn/delegate/communicate/aggregate/stop) as the unit RL should optimize, and defines 8 reward families and 5 sub-decisions for multi-agent LLMs; ships an 84-paper tagged corpus + JSON trace schema. _Category:_ cs.MA / cs.AI (arXiv:2605.02801). [link](https://arxiv.org/abs/2605.02801)

- **ContextualJailbreak: Evolutionary Red-Teaming via Simulated Conversational Priming** — _Takeaway:_ Black-box evolutionary search over multi-turn primed dialogues; shows that multi-turn contextual priming consistently outperforms single-turn jailbreaks against frontier safety alignment. _Category:_ cs.CL / cs.CR (arXiv:2605.02647). [link](https://arxiv.org/abs/2605.02647)

- **Redefining AI Red Teaming in the Agentic Era: From Weeks to Hours** — _Takeaway:_ Treats red-teaming as an orchestratable agent task and ships a framework with 29 advanced adversarial attacks (AutoRedTeamer, NEXUS, Siren, CoT Jailbreak, Genetic Persona, JBFuzz) — collapses week-long red-team cycles into hours. _Category:_ cs.CR / cs.AI (arXiv:2605.04019). [link](https://arxiv.org/abs/2605.04019)

- **Frontier Lag: A Bibliometric Audit of Capability Misrepresentation in Academic AI Evaluation** — _Takeaway:_ Quantifies how far academic eval papers trail the deployed frontier — median paper evaluates models ~10.85 ECI behind contemporaneous SOTA (≈1.4× the Sonnet 3.7 → Opus 4.5 gap). Sharp critique of how the field measures progress. _Category:_ cs.CY / cs.AI (arXiv:2605.04135). [link](https://arxiv.org/abs/2605.04135)

- **Jailbroken Frontier Models Retain Their Capabilities** — _Takeaway:_ Tests whether complex jailbreaks degrade frontier capabilities; finds Boundary Point Jailbreaking (BPJ) is the strongest universal jailbreak against deployed safeguards while preserving downstream task quality — bad news for "safety as capability tax" assumptions. _Category:_ cs.CL / cs.CR (arXiv:2605.00267). [link](https://arxiv.org/abs/2605.00267)

- **Coordination as an Architectural Layer for LLM-Based Multi-Agent Systems** — _Takeaway:_ Empirical study (prediction-market testbed) treating coordination as a configurable layer separable from agent logic and information access; clean abstraction for orchestration designers. _Category:_ cs.MA / cs.AI (arXiv:2605.03310). [link](https://arxiv.org/abs/2605.03310)

- **Evaluating Retrieval-Augmented Generation for Explainable Malware Analysis** — _Takeaway:_ Domain-grounded RAG eval applied to malware analysis with explainability constraints — useful methodological template for high-stakes RAG deployments. _Category:_ cs.IR / cs.CR (arXiv:2605.03140). [link](https://arxiv.org/abs/2605.03140)

- **Securing the Model Context Protocol (MCP): Risks, Controls, and Governance** — _Takeaway:_ Threat model and control set for MCP server ecosystems (tool-name spoofing, prompt-injection at the tool boundary, schema-leakage), with proposed governance primitives. Most concrete MCP-security paper to date. _Category:_ cs.CR / cs.AI (arXiv:2511.20920). [link](https://arxiv.org/abs/2511.20920)

## Other interesting items

- **[Brief Is Better: Non-Monotonic Chain-of-Thought Budget Effects in Function-Calling Language Agents](https://arxiv.org/list/cs.CL/new)** — Function-calling agents don't monotonically benefit from longer CoT budgets — counterintuitive scaling result for tool-using agents.
- **[Your Agent is More Brittle Than You Think: Uncovering Indirect Injection Vulnerabilities in Agentic LLMs](https://arxiv.org/list/cs.CL/new)** — Systematic indirect-prompt-injection vulnerability study on agentic stacks.
- **[LatentRAG: Latent Tokens for Thoughts and Subqueries](https://arxiv.org/list/cs.CL/new)** — Generates latent thought/subquery tokens directly from hidden states; matches explicit agentic-RAG quality with ~90% lower inference latency.
- **[Beyond Single Embeddings: Capturing Diverse Targets with Multi-Query Retrieval (AMER)](https://arxiv.org/html/2511.02770v1)** — Autoregressive Multi-Embedding Retriever generates multiple query vectors and uses all of them at retrieval time.
- **[flexvec: SQL Vector Retrieval with Programmatic Embedding Modulation](https://arxiv.org/abs/2603.22587)** — Treats the embedding matrix and score array as a programmable surface for arithmetic transforms before top-k selection.
- **[Self-Aware Vector Embeddings for RAG (SmartVector)](https://arxiv.org/abs/2604.20598)** — Adds temporal awareness, confidence decay, and relational signals to dense embeddings used in RAG.
- **[MASPO: Joint Prompt Optimization for LLM-based Multi-Agent Systems](https://arxiv.org/list/cs.CL/new)** — ICML 2026 accepted; jointly optimizes prompts across agents in a multi-agent pipeline.
- **[Agent Capsules: Quality-Gated Granularity Control for Multi-Agent LLM Pipelines](https://arxiv.org/list/cs.CL/new)** — Capsule abstraction with quality gates between stages; structured composition primitive for agent pipelines.
- **[The Two Boundaries: Why Behavioral AI Governance Fails Structurally](https://arxiv.org/abs/2604.27292)** — Argues system-capability and governance-coverage boundaries are defined independently, creating ungoverned-capability and phantom-policy regions.
- **[AI Governance under Political Turnover: The Alignment Surface of Compliance Design](https://arxiv.org/abs/2604.21103)** — Formal model of how compliance-system design choices (automation scale, codification, iterative-use safeguards) become vectors for in-government strategic capture.
