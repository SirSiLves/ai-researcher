## Medium roundup

### model-context-protocol / mcp
- **[Securing LLM Agents with MCP: Threat Modeling, OAuth 2.1, and Defense-in-Depth in Practice](https://medium.com/@roanmonteiro/securing-llm-agents-with-mcp-threat-modeling-oauth-2-1-and-defense-in-depth-in-practice-0ab8fb7d4696)** — Roan Brasil Monteiro. Maps a "typical 2026" production agent topology — LLM client, foundation model, local + remote MCP tool servers, vector store for RAG, persistent memory, A2A — across three trust boundaries, with concrete OAuth 2.1 patterns.
- **[Your AI Has No Hands. An MCP Story.](https://medium.com/@nuno.roberto/your-ai-has-no-hands-an-mcp-story-7aa083fd88b1)** — Nuno Roberto. Plain-English framing of why MCP exists: closing the gap between what an LLM can reason about and what it can actually touch.

### llm / large-language-models
- **[Xiaomi MiMo-V2.5-Pro: The Best Open-Source LLM?](https://medium.com/@dhirendrachoudhary_96193/xiaomi-mimo-v2-5-pro-the-best-open-source-llm-e22d971ab843)** — Dhirendra Choudhary. ### xai / grok
- **[Grok 4.3 Becomes the Default Pick for Chat and Code, yet Older Builds Hold Ground in Narrow Spots](https://medium.com/@cognidownunder/grok-4-3-becomes-the-default-pick-for-chat-and-code-yet-older-builds-hold-ground-in-narrow-spots-afa98227bb57)** — Cogni Down Under.
