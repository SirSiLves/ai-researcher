## Long-form picks

- **Pretext** — Cheng Lou, via Simon Willison. _Takeaway:_ New tiny browser library from a React core alum that calculates wrapped-text height without touching the DOM. Splits work into `prepare()` (off-screen canvas measuring per word, cached) and `layout()` (emulates browser wrap rules). Tested against a corpus that includes the full Gatsby plus public-domain text in Thai, Chinese, Korean, Japanese, Arabic — Cheng credits weeks of Claude Code + Codex iterating against browser ground truth. A standout example of agent-assisted hardcore engineering. [https://simonwillison.net/2026/Mar/29/pretext/](https://simonwillison.net/2026/Mar/29/pretext/)

- **Responsible AI Weekly — March 29 to April 5, 2026** — Hamid Bagheri. _Takeaway:_ End-of-month responsible-AI roundup covering the Anthropic Automated Alignment Agent (A3) preview, Databricks coSTAR for agent testing, and the post-supply-chain conversation about pinning + provenance as governance primitives. [https://airesponsibly.substack.com/p/responsible-ai-weekly-march-29april](https://airesponsibly.substack.com/p/responsible-ai-weekly-march-29april)
